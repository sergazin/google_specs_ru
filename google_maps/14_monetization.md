# Монетизация и реклама -- Google Maps

## Описание

Модуль монетизации Google Maps управляет всеми потоками дохода платформы, которая является одновременно бесплатным потребительским продуктом (1+ млрд активных пользователей в месяц) и коммерческой B2B-платформой для разработчиков и рекламодателей. Выручка Google Maps достигла **$11.1 млрд** в 2023 году, из которых **82% приходится на рекламу**, а остальное -- на продажу API-доступа (Google Maps Platform) и партнёрские интеграции. Google Maps монетизируется по модели **freemium**: конечные пользователи получают полный доступ бесплатно, тогда как бизнесы платят за рекламу, API-вызовы и аналитические данные.

Ключевые принципы монетизации:
- **Freemium для потребителей**: навигация, поиск мест, отзывы, Street View -- бесплатны и без рекламных ограничений.
- **Рекламная модель (Google Ads в Maps)**: локальный бизнес платит за показ объявлений в результатах поиска и на карте (Promoted Pins, Local Search Ads, Performance Max).
- **API-платформа (Google Maps Platform)**: разработчики и компании платят за вызовы API (Maps, Routes, Places, Environment) по модели pay-as-you-go или подписке.
- **Партнёрские интеграции**: встраивание сторонних сервисов (Uber, Lyft, OpenTable и др.) с генерацией трафика и реферальных потоков.
- **Reserve with Google**: бесплатная для бизнеса система бронирований, монетизируемая через вовлечённость и удержание пользователей в экосистеме.
- **Аналитика данных (Places Insights, Business Insights)**: продажа агрегированных геопространственных данных для бизнес-аналитики.

## Участники экосистемы монетизации

### Стороны транзакций

| Участник | Роль | Описание |
|----------|------|----------|
| **Конечный пользователь** | Потребитель сервиса | Использует навигацию, поиск, отзывы бесплатно; видит рекламу |
| **Локальный бизнес (рекламодатель)** | Покупатель рекламы | Оплачивает рекламные размещения через Google Ads для привлечения клиентов |
| **Разработчик / Компания (API-клиент)** | B2B-покупатель | Оплачивает вызовы Google Maps Platform API для встраивания карт и данных в свои приложения |
| **Партнёр (Uber, Lyft, OpenTable и др.)** | Интегрированный сервис | Предоставляет свои услуги через интерфейс Google Maps; платит за использование Maps API |
| **Бизнес-профиль (Google Business Profile)** | Поставщик данных | Бесплатно создаёт и управляет профилем на карте; может стать рекламодателем |
| **Партнёр Reserve with Google** | Провайдер бронирований | Интегрирует систему бронирований с Google Maps (TIMIFY, Tableo, Octotable, Servme и др.) |
| **Аналитический клиент** | Покупатель данных | Приобретает доступ к Places Insights API и геоаналитике через BigQuery |
| **Google (платформа)** | Оператор экосистемы | Получает рекламную выручку, оплату API, данные для улучшения сервисов |

## Функциональные требования

### FR-MON-001: Рекламные размещения в Google Maps (Google Ads in Maps)

Система ДОЛЖНА поддерживать показ платных рекламных объявлений в результатах поиска и на карте Google Maps.

1. **Promoted Pins (Продвигаемые метки)**:
   - Рекламодатель МОЖЕТ разместить визуально выделенную метку на карте -- квадратный пин с логотипом бренда (в отличие от стандартных круглых пинов).
   - Promoted Pins отображаются при просмотре карты в общем режиме (без поискового запроса) и при навигации.
   - В 3D-иммерсивном виде карты Promoted Pins отображаются как фиолетовые визуально отличимые метки.
   - Действия пользователя при нажатии: звонок (click-to-call), построение маршрута, переход на сайт, просмотр карточки бизнеса.
   - Более **2.5 миллионов бизнесов** используют Promoted Pins.
2. **Local Search Ads (Локальные поисковые объявления)**:
   - Объявления отображаются в верхней части результатов поиска мест в Google Maps (например, по запросу «кофейня рядом»).
   - Объявления помечены меткой «Реклама» / «Ad».
   - Содержат: название бизнеса, рейтинг, расстояние, часы работы, краткое описание.
   - Отображаются в списке результатов и на карте одновременно.
3. **Map Suggest Ads (Объявления в подсказках)**:
   - Рекламные предложения отображаются в выпадающем списке автодополнения при вводе запроса в строку поиска Maps.
4. **Promoted Places in Navigation (Продвигаемые места в навигации)**:
   - Для рекламодателей, использующих Performance Max для целей магазинов (store goals), бизнес отображается как «Promoted Place» непосредственно на навигационной карте пользователя во время поездки.
   - Доступно для рекламодателей в США (с 2025 года).
5. **Performance Max (замена Local Campaigns)**:
   - С июля 2022 года все Local Campaigns автоматически мигрированы в Performance Max.
   - Performance Max -- единый тип кампании, оптимизирующий показ рекламы через AI/ML по каналам: Search, YouTube, Display, Discover, Gmail, Google Maps, Waze (с конца 2025 для США).
   - Привязка Google Business Profile обязательна для размещения на Maps.
   - Рекламодатель предоставляет текстовые, графические и видеоматериалы (assets); система автоматически адаптирует их под каждый канал, включая Maps.
6. **Google Ad Grants (для некоммерческих организаций)**:
   - Некоммерческие организации МОГУТ получить бесплатный рекламный бюджет ($10,000/мес) для Performance Max кампаний, включая размещения в Maps.
   - Доступно с начала 2025 года.

**Бизнес-правила**:
- BR-001: Рекламные размещения в Maps доступны ТОЛЬКО через платформу Google Ads. Прямая покупка размещений невозможна.
- BR-002: Рекламодатель ДОЛЖЕН иметь верифицированный Google Business Profile для размещения Promoted Pins и Local Search Ads.
- BR-003: Promoted Pins НЕ отображаются для каждого пользователя -- показ зависит от релевантности, bid, качества объявления и локации пользователя.
- BR-004: Реклама в Maps ДОЛЖНА соответствовать общим рекламным политикам Google Ads (запрет на контент для взрослых, оружие, запрещённые вещества и т.д.).

### FR-MON-002: Модели оплаты рекламы (Ad Pricing Models)

Система ДОЛЖНА поддерживать несколько моделей оплаты рекламных размещений в Maps.

1. **Pay-Per-Click (PPC / CPC)**:
   - Основная модель: рекламодатель платит только когда пользователь взаимодействует с объявлением (клик, звонок, запрос маршрута, переход на сайт).
   - Средний CPC в Maps: **~$5.26** (2025), для ресторанов и локальных сервисов -- **~$2.05**.
   - Ставка определяется аукционом Google Ads (второй по цене аукцион / Generalized Second Price).
2. **Pay-Per-View (CPV / CPM)**:
   - Promoted Pins МОГУТ тарифицироваться по показам (CPM) в зависимости от типа кампании.
   - Применимо для кампаний с целью повышения узнаваемости (awareness).
3. **Аукционная модель**:
   - Все рекламные размещения в Maps определяются через аукцион Google Ads.
   - Факторы ранжирования: bid (ставка), Quality Score (качество объявления), релевантность запросу, расстояние до пользователя, рейтинг бизнеса.
   - Рекламодатель задаёт максимальный бюджет (дневной, месячный) и максимальную ставку за взаимодействие.
4. **Smart Bidding / AI-оптимизация**:
   - Performance Max использует машинное обучение для автоматической оптимизации ставок по каналам.
   - Цели оптимизации: визиты в магазин (store visits), звонки, клики, конверсии на сайте.

**Бизнес-правила**:
- BR-005: Минимальный дневной бюджет для кампании Performance Max с Maps-размещениями устанавливается Google Ads (зависит от рынка).
- BR-006: Рекламодатель НЕ МОЖЕТ гарантировать показ Promoted Pin -- это зависит от аукциона, конкуренции и алгоритма.
- BR-007: CPC МОЖЕТ варьироваться в диапазоне $0.50--$50+ в зависимости от конкурентности ниши и геолокации.
- BR-008: Google НЕ раскрывает точную формулу Quality Score для Maps-размещений.

### FR-MON-003: Google Maps Platform -- API-монетизация (Pay-As-You-Go)

Система ДОЛЖНА предоставлять API-доступ к картографическим, маршрутным, поисковым и экологическим данным на коммерческой основе.

1. **Категории SKU**:
   - **Essentials**: базовые функции -- Dynamic Maps, Static Maps, Geocoding, Compute Routes, Autocomplete, Air Quality, Weather. Бесплатный лимит: **10,000 событий/мес** на SKU.
   - **Pro**: расширенные функции -- Aerial View, Dynamic Street View, Elevation, Address Validation, Nearby Search, Text Search, Pollen, Route Optimization. Бесплатный лимит: **5,000 событий/мес** на SKU.
   - **Enterprise**: премиальные функции -- Photorealistic 3D Tiles, Fleet Routing, Navigation SDK, Solar Data Layers, расширенные Place Details. Бесплатный лимит: **1,000 событий/мес** на SKU.
2. **Бесплатные SKU (без ограничений)**:
   - Maps Embed API, Maps SDK for Android/iOS, Street View Metadata, Place Details (IDs Only), Text Search (IDs Only), Autocomplete Session.
3. **Ценообразование (за 1,000 запросов, базовая цена без скидок)**:
   - **Maps**: Dynamic Maps -- $7.00; Static Maps -- $2.00; Static Street View -- $7.00; 2D Map Tiles -- $0.60; Street View Tiles -- $2.00.
   - **Maps Pro**: Aerial View -- $16.00; Dynamic Street View -- $14.00; Elevation -- $5.00; Immersive Maps -- $7.00.
   - **Maps Enterprise**: Photorealistic 3D Tiles -- $6.00.
   - **Routes Essentials**: Compute Routes / Route Matrix -- $5.00.
   - **Routes Pro**: Roads -- $10.00; Speed Limits -- $20.00; Route Optimization (Single Vehicle) -- $10.00; Compute Routes Pro -- $10.00.
   - **Routes Enterprise**: Fleet Routing -- $30.00; Navigation SDK -- $25.00; Compute Routes Enterprise -- $15.00.
   - **Places Essentials**: Autocomplete Requests -- $2.83; Geocoding / Geolocation -- $5.00; Place Details -- $5.00; UI Kit Query -- $1.00; Time Zone -- $5.00.
   - **Places Pro**: Address Validation -- $17.00; Nearby Search -- $32.00; Text Search -- $32.00; Place Details Pro -- $17.00.
   - **Places Enterprise**: Address Validation -- $25.00; Nearby Search -- $35.00; Nearby Search + Atmosphere -- $40.00; Place Details -- $20.00; Place Details + Atmosphere -- $25.00; Photos -- $7.00; Text Search -- $35.00; Text Search + Atmosphere -- $40.00.
   - **Environment Essentials**: Air Quality -- $5.00; Solar Building Insights -- $10.00; Weather -- $0.15.
   - **Environment Pro**: Pollen -- $10.00.
   - **Environment Enterprise**: Solar Data Layers -- $75.00.
4. **Объёмные скидки**:
   - Автоматические скидки при росте объёма использования.
   - Шкала скидок масштабируется до **5,000,000+ событий/мес** (с марта 2025, расширение с прежних 100,000+).
   - Скидки могут снижать цену до **85--93%** от базовой (например, Dynamic Maps: $7.00 -> $0.53 при максимальном объёме).
5. **Изменения с марта 2025**:
   - Универсальный ежемесячный кредит $200 заменён на бесплатные лимиты по каждому SKU.
   - Directions API, Distance Matrix API и Places API переведены в статус Legacy; рекомендуется миграция на Routes API и Places API (New).

**Бизнес-правила**:
- BR-009: Клиент ДОЛЖЕН привязать валидный биллинговый аккаунт Google Cloud для использования платных SKU.
- BR-010: При превышении бесплатного лимита тарификация начинается автоматически; сервис НЕ прерывается.
- BR-011: Уведомления отправляются при достижении **80%** и **90%** бесплатного лимита.
- BR-012: Legacy API (Directions, Distance Matrix, Places v1) продолжают работать, но по повышенным тарифам и без расширенных скидок.
- BR-013: Maps SDK для мобильных приложений (Android/iOS) и Maps Embed API -- бесплатны без ограничений объёма.

### FR-MON-004: Google Maps Platform -- Подписочные планы (Subscriptions)

Система ДОЛЖНА предоставлять подписочные планы как альтернативу модели pay-as-you-go.

1. **Starter Plan -- $100/мес**:
   - Включает **50,000 комбинированных вызовов** в месяц.
   - Эффективная стоимость: **$2.00 за 1,000 вызовов**.
   - Включённые SKU: Dynamic Maps, Static Maps, базовая маршрутизация, геокодирование.
2. **Essentials Plan -- $275/мес**:
   - Включает **100,000 комбинированных вызовов** в месяц.
   - Эффективная стоимость: **$2.75 за 1,000 вызовов**.
   - Все SKU Starter + поддержка Legacy API (Places, Directions, Distance Matrix), бесплатные SKU (Maps SDK, Embed) не расходуют лимит.
3. **Pro Plan -- $1,200/мес**:
   - Включает **250,000 комбинированных вызовов** в месяц.
   - Эффективная стоимость: **$4.80 за 1,000 вызовов**.
   - Все SKU Essentials + расширенные Places Search, Address Validation, Aerial View, Route Optimization, расширенные Environment API.
4. **Overage (превышение лимита)**:
   - Вызовы сверх включённого лимита тарифицируются по стандартным pay-as-you-go ценам.
   - Сервис НЕ прерывается при превышении.

**Бизнес-правила**:
- BR-014: Клиент МОЖЕТ переключиться между планами или отменить подписку в любой момент без штрафов.
- BR-015: При смене плана в середине биллингового цикла -- пропорциональный пересчёт (prorated).
- BR-016: Бесплатные SKU (Maps SDK, Embed, Place Details IDs Only) НЕ расходуют лимит подписки.
- BR-017: Неиспользованные вызовы НЕ переносятся на следующий месяц.

### FR-MON-005: Google Business Profile -- Бесплатная база монетизации

Система ДОЛЖНА предоставлять бесплатный инструмент управления бизнес-профилем как воронку для платных сервисов.

1. **Бесплатные возможности**:
   - Создание и управление профилем бизнеса на Google Maps и в поиске Google.
   - Публикация информации: адрес, часы работы, телефон, сайт, описание, категория.
   - Загрузка фотографий и видео.
   - Управление отзывами (ответы на отзывы).
   - Публикация новостей и предложений (Google Posts).
   - Просмотр статистики: количество просмотров профиля, звонков, запросов маршрутов, посещений сайта.
   - Добавление меню, каталога услуг, прайс-листа.
2. **Монетизационная воронка**:
   - Google Business Profile -- точка входа в рекламную экосистему: владелец профиля получает предложения запустить рекламу через Google Ads.
   - Статистика профиля стимулирует рекламодателей инвестировать в продвижение (показывая потенциальную аудиторию).
   - Верифицированный профиль -- обязательное условие для Promoted Pins и Local Search Ads.
3. **Бесплатная модель с монетизацией через апсейл**:
   - Google НЕ взимает плату за создание и ведение профиля.
   - Основная монетизация: конверсия владельцев профилей в рекламодателей Google Ads.

**Бизнес-правила**:
- BR-018: Бизнес-профиль ДОЛЖЕН пройти верификацию (открытка, телефон, email, видеозвонок) перед публикацией.
- BR-019: Один физический адрес МОЖЕТ иметь только один верифицированный профиль для одного бизнеса.
- BR-020: Google МОЖЕТ автоматически создавать профили на основе публичных данных (веб, справочники); владелец МОЖЕТ заявить права (claim) на существующий профиль.
- BR-021: Профиль, не прошедший верификацию в течение 12 месяцев, МОЖЕТ быть удалён.

### FR-MON-006: Reserve with Google -- Бронирования через Google Maps

Система ДОЛЖНА предоставлять возможность бронирования услуг (столиков, записей, встреч) непосредственно из Google Maps.

1. **Механизм**:
   - Пользователь видит кнопку «Забронировать» / «Reserve» в карточке бизнеса на Google Maps.
   - Бронирование выполняется через интегрированного партнёра (TIMIFY, Tableo, Octotable, Servme и др.) без перехода на внешний сайт.
   - Доступно из Google Search, Google Maps и Google Assistant.
2. **Вертикали**:
   - Рестораны (бронирование столиков).
   - Бьюти-салоны и спа (запись на услуги).
   - Фитнес (запись на занятия).
   - Медицинские услуги (запись к врачу).
   - Любые сервисные бизнесы с системой записи.
3. **Комиссионная модель**:
   - Бронирования через Reserve with Google -- **бесплатны для бизнеса** (без комиссии за бронирование со стороны Google).
   - Монетизация: через партнёров-провайдеров бронирований (TIMIFY, Tableo и др.), которые взимают подписочную плату с бизнесов; Google получает ценность в виде вовлечённости пользователей и данных.
   - С 2025 года поддержка прямых оплат через Reserve with Google (через интеграцию с Servme и др.).
4. **Требования к партнёрам**:
   - Партнёр ДОЛЖЕН иметь прямой контракт с обслуживаемыми бизнесами (merchants).
   - Список бизнесов партнёра ДОЛЖЕН совпадать с локациями в Google Maps.
   - Услуги ДОЛЖНЫ быть бронируемыми по стандартному определению Google Actions Center.
5. **Синхронизация**:
   - Доступность (available slots) синхронизируется в реальном времени между системой партнёра и Google Maps.
   - Подтверждение бронирования отправляется пользователю через Google (email, push-уведомление) и через систему партнёра.

**Бизнес-правила**:
- BR-022: Google НЕ взимает комиссию с бронирований через Reserve with Google.
- BR-023: Партнёр ДОЛЖЕН соответствовать интеграционным политикам Google Actions Center для сохранения статуса.
- BR-024: Бизнес МОЖЕТ подключить Reserve with Google через любого сертифицированного партнёра; смена партнёра -- без ограничений.
- BR-025: Данные о бронированиях используются Google для улучшения ранжирования бизнеса в результатах поиска (косвенная монетизация через вовлечённость).

### FR-MON-007: Партнёрские интеграции (Third-Party Integrations)

Система ДОЛЖНА поддерживать интеграции со сторонними сервисами, генерирующие прямые и косвенные доходы.

1. **Ride-Hailing интеграции (Uber, Lyft и др.)**:
   - Пользователь МОЖЕТ заказать поездку Uber / Lyft непосредственно из Google Maps при просмотре маршрута.
   - Google Maps отображает: время подачи (ETA), примерную стоимость, тип поездки.
   - Пользователь перенаправляется в приложение партнёра для завершения заказа.
   - Модель: Google получает доход от использования партнёрами Maps API (Uber платил Google **~$19M/год** за картографические сервисы, $58M за 2016--2018).
2. **Бронирование ресторанов (OpenTable и др.)**:
   - Кнопка бронирования столика в карточке ресторана на Google Maps.
   - Интеграция через Reserve with Google или прямой deep link в приложение партнёра.
3. **Доставка еды**:
   - Кнопки «Заказать доставку» / «Order delivery» в карточках ресторанов.
   - Интеграция с DoorDash, Uber Eats и другими сервисами доставки.
4. **Отели и размещение**:
   - Карточки отелей в Google Maps содержат цены, рейтинги и ссылки для бронирования.
   - Интеграция с Booking.com, Expedia, Hotels.com и прямыми бронированиями отелей.
   - Модель: CPC/CPA от партнёров за переходы и бронирования.
5. **Билеты и мероприятия**:
   - Информация о мероприятиях (концерты, выставки, шоу) отображается в карточках мест.
   - Ссылки на покупку билетов через партнёров (Ticketmaster и др.).
6. **Электромобильные зарядные станции**:
   - Отображение зарядных станций с данными о доступности, типе зарядки, ценах.
   - Интеграция с операторами (ChargePoint, EVgo, Tesla Supercharger).

**Бизнес-правила**:
- BR-026: Партнёрские интеграции отображаются на основе географической доступности сервиса.
- BR-027: Google МОЖЕТ показывать нескольких партнёров одновременно (например, Uber И Lyft для одного маршрута) для обеспечения пользовательского выбора.
- BR-028: Партнёр ДОЛЖЕН поддерживать deep link или API-интеграцию для бесшовного перехода.
- BR-029: Тарификация для партнёров определяется индивидуальными коммерческими соглашениями (не публичный прайс-лист).

### FR-MON-008: Монетизация данных и геоаналитика (Data Monetization)

Система ДОЛЖНА предоставлять платные аналитические продукты на основе агрегированных геопространственных данных.

1. **Places Insights API**:
   - Предоставляет агрегированные данные о местах в заданной области: типы заведений, операционный статус, ценовые уровни, пользовательские рейтинги, плотность POI (Points of Interest).
   - Применение: выбор локаций для открытия магазинов, оценка конкурентного окружения, стратегическое планирование.
   - Тарификация: по категории SKU (Pro/Enterprise), $10.00--$75.00 за 1,000 запросов.
2. **Places Insights в BigQuery**:
   - Интеграция данных Google Maps с BigQuery data clean rooms для безопасного объединения проприетарных данных клиента с геоданными Google.
   - Ритейл-сети анализируют корреляцию геопространственных характеристик (плотность POI, транспортная доступность) с показателями продаж магазинов.
3. **Business Insights (экспериментальная функция)**:
   - Анонимизированные данные о взаимодействии пользователей: просмотры карты, взаимодействие с POI, паттерны навигации.
   - Доступ по подписке для аналитических клиентов.
4. **Geospatial Analytics**:
   - Интеграция Google Maps Platform с BigQuery и Google Earth Engine для масштабной геоаналитики, прогнозирования и визуализации.
   - Доступна без специализированного GIS-образования (low-code/no-code интерфейс).
5. **Environment API как аналитический продукт**:
   - Air Quality API, Solar Building Insights, Pollen API, Weather API -- данные для строительных компаний, страховщиков, энергетических компаний.
   - Solar Data Layers (Enterprise) -- самый дорогой SKU: **$75.00 за 1,000 запросов** (базовая цена).

**Бизнес-правила**:
- BR-030: Все аналитические данные предоставляются в агрегированном и анонимизированном виде; персональные данные пользователей НЕ продаются.
- BR-031: Доступ к Places Insights в BigQuery требует активного аккаунта Google Cloud с BigQuery.
- BR-032: Data clean rooms обеспечивают изоляцию проприетарных данных клиента -- Google НЕ получает доступ к данным клиента.
- BR-033: Environment API данные обновляются с различной частотой: Weather -- каждые 15 минут, Air Quality -- ежечасно, Solar -- периодически.

### FR-MON-009: Freemium-модель для конечных пользователей

Система ДОЛЖНА предоставлять полный набор функций конечным пользователям бесплатно, монетизируя аудиторию через рекламу и данные.

1. **Полностью бесплатные функции**:
   - Поиск мест и адресов (без ограничений).
   - Пошаговая навигация (авто, пешеход, общественный транспорт, велосипед).
   - Просмотр карты, спутниковых снимков, Street View.
   - Чтение и написание отзывов.
   - Создание и сохранение списков мест.
   - Оффлайн-карты (скачивание карт для использования без интернета).
   - Информация об общественном транспорте, пробках, инцидентах.
   - Отправка геолокации друзьям (Location Sharing).
2. **Рекламные точки контакта с пользователем**:
   - Promoted Pins при просмотре карты.
   - Local Search Ads при поиске мест.
   - Рекламные предложения в подсказках поиска.
   - Promoted Places при навигации.
   - Партнёрские интеграции (кнопки заказа поездки, доставки, бронирования).
3. **Монетизация через данные**:
   - Анонимизированные данные о передвижении и поиске используются для улучшения рекламного таргетинга в экосистеме Google.
   - Данные о пробках, популярных временах посещения, загруженности мест -- производные продукты из агрегированных данных пользователей.
4. **Экосистемная ценность**:
   - Google Maps удерживает пользователей в экосистеме Google (Search, Gmail, YouTube, Android), увеличивая общую рекламную выручку корпорации.
   - Maps -- ключевой источник данных для Google Search Local Pack (блок из 3 бизнесов в результатах поиска Google), который также монетизируется через рекламу.

**Бизнес-правила**:
- BR-034: Конечный пользователь НЕ ДОЛЖЕН платить за любую функцию Google Maps (навигация, поиск, отзывы, Street View и т.д.).
- BR-035: Рекламные размещения ДОЛЖНЫ быть чётко помечены как реклама (метка «Ad» / «Реклама»).
- BR-036: Пользователь НЕ МОЖЕТ отключить рекламу в Google Maps (нет premium-версии без рекламы).
- BR-037: Оффлайн-карты доступны бесплатно, но партнёрские интеграции и актуальная реклама требуют подключения к интернету.

### FR-MON-010: Тарификация и биллинг Google Maps Platform

Система ДОЛЖНА обеспечивать прозрачную тарификацию и биллинг для API-клиентов.

1. **Биллинговый цикл**:
   - Ежемесячный биллинг через Google Cloud Billing.
   - Списание по факту использования (postpaid) ИЛИ предоплата через подписочные планы.
2. **Мониторинг расходов**:
   - Панель использования в Google Cloud Console: расход по каждому SKU в реальном времени.
   - Уведомления при достижении **80%** и **90%** от бюджетного лимита.
   - Клиент МОЖЕТ установить бюджетные лимиты (budget caps) для предотвращения непредвиденных расходов.
3. **Отчётность**:
   - Детализированный отчёт по каждому SKU: количество вызовов, стоимость, скидки, итого.
   - Экспорт данных биллинга в CSV и интеграция с финансовыми системами.
   - Данные об использовании API доступны через Google Maps Platform Reporting.
4. **Оплата**:
   - Кредитная/дебетовая карта, банковский перевод, Google Cloud billing account.
   - Для крупных клиентов -- индивидуальные контракты с постоплатой (net-30/net-60).
5. **Квоты и ограничения**:
   - Каждый API-проект имеет квоту (QPS -- Queries Per Second) по умолчанию.
   - Клиент МОЖЕТ запросить увеличение квоты через Google Cloud Console.
   - При превышении QPS -- HTTP 429 (Too Many Requests), запрос отклоняется.

**Бизнес-правила**:
- BR-038: Клиент ДОЛЖЕН включить биллинг для использования любых платных SKU; без биллинга API-ключ работает только для бесплатных SKU.
- BR-039: При неоплате счёта -- grace period **30 дней**, затем приостановка API-доступа.
- BR-040: Объёмные скидки применяются автоматически; клиенту НЕ нужно запрашивать скидку.
- BR-041: Возвраты (refunds) за ошибочные вызовы API не производятся; клиент несёт ответственность за оптимизацию использования.

### FR-MON-011: Монетизация навигации и маршрутизации

Система ДОЛЖНА монетизировать навигационные функции через рекламу и партнёрские интеграции.

1. **Реклама в навигационном режиме**:
   - Promoted Places in Navigation: бренды МОГУТ отображаться на маршруте пользователя как рекомендуемые остановки (заправки, рестораны, магазины).
   - Отображение только релевантных предложений (заправки при низком уровне топлива, кофейни при длительных поездках).
2. **Партнёрская монетизация маршрутов**:
   - Кнопка «Заказать поездку» при просмотре маршрута на общественном транспорте с пересадками -- предложение Uber/Lyft как альтернативы.
   - Сравнение стоимости: общественный транспорт vs. ride-hailing vs. собственный автомобиль.
3. **EV-маршрутизация**:
   - Для электромобилей: рекомендация зарядных станций по маршруту с учётом заряда батареи.
   - Партнёрские интеграции с операторами зарядных станций.
4. **Waze (дочерняя платформа)**:
   - Waze -- отдельное навигационное приложение, принадлежащее Google.
   - Waze монетизируется отдельно через Waze Ads (Zero-Speed Takeovers, Promoted Search, Branded Pins).
   - С конца 2025 года Performance Max включает размещения в Waze для рекламодателей в США.

**Бизнес-правила**:
- BR-042: Реклама в навигационном режиме НЕ ДОЛЖНА отвлекать водителя -- отображается только в безопасных ситуациях (остановка, низкая скорость).
- BR-043: Waze и Google Maps -- отдельные рекламные инвентари; объединение через Performance Max -- опционально.
- BR-044: EV-зарядные партнёрства тарифицируются индивидуально (не через публичный прайс).

### FR-MON-012: Корпоративные и Enterprise-решения

Система ДОЛЖНА предоставлять специализированные решения для крупных корпоративных клиентов.

1. **Google Maps Platform Enterprise контракты**:
   - Индивидуальные цены для компаний с большим объёмом API-вызовов (>5M/мес).
   - SLA с гарантированным uptime (**99.9%** для большинства API).
   - Выделенная техническая поддержка (Premium Support).
   - Кастомные интеграции и консалтинг через Google Cloud Partners.
2. **Fleet Management решения**:
   - Navigation SDK для коммерческих флотов (такси, доставка, логистика).
   - Fleet Routing (Enterprise SKU) -- оптимизация маршрутов для многоточечных доставок.
   - Route Optimization -- минимизация стоимости и времени для единичных транспортных средств.
   - Тарификация: Navigation SDK -- **$25.00 за 1,000 запросов** (базовая); Fleet Routing -- **$30.00 за 1,000 запросов** (базовая).
3. **Ритейл и недвижимость**:
   - Places Insights для анализа торговых локаций.
   - Solar Building Insights для оценки недвижимости.
   - Address Validation для чистки адресных баз.
4. **Партнёрская экосистема**:
   - Google Maps Platform Partners -- сеть сертифицированных интеграторов, помогающих внедрять решения.
   - Партнёры получают комиссию за привлечение и обслуживание клиентов.

**Бизнес-правила**:
- BR-045: Enterprise контракты заключаются через Google Cloud Sales; условия не публикуются.
- BR-046: Минимальный годовой commitment для Enterprise контрактов -- индивидуально (обычно от $10,000+/год).
- BR-047: SLA-нарушения компенсируются кредитами на будущее использование, НЕ денежным возвратом.

| **QPS** | Queries Per Second -- лимит запросов в секунду для API |
| **CPC** | Cost Per Click -- оплата за клик по рекламному объявлению |
| **CPM** | Cost Per Mille -- оплата за 1,000 показов рекламы |
| **Deep Link** | Прямая ссылка для перехода в конкретный экран мобильного приложения партнёра |
| **Data Clean Room** | Защищённая среда для объединения данных нескольких сторон без раскрытия исходных данных |

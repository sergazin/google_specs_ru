# Google Maps — Обзор спецификации

## Описание сервиса

Google Maps — картографическая платформа Google (Alphabet Inc.), запущенная в 2005 году. Крупнейший картографический сервис в мире, охватывающий 220+ стран и территорий. Предоставляет карты, навигацию, поиск мест, Street View, общественный транспорт, отзывы и бизнес-профили. Интегрируется с экосистемой Google (Search, Assistant, Calendar, Gmail, Wallet, Ads).

**Ключевые факты:**
- Основание: 2005 (приобретение Where 2 Technologies)
- Рынок: глобальный, 220+ стран
- MAU: ~2 млрд+ (2024)
- Покрытие Street View: 100+ стран, 220+ млрд изображений
- Выручка: ~$11.1 млрд (2023), 82% от рекламы
- Типы карт: стандартная, спутник, рельеф, 3D, Immersive View
- Навигация: авто, пешком, велосипед, общественный транспорт, перелёт
- API: Google Maps Platform (Maps, Routes, Places, Environment)

## Целевая аудитория

| Сегмент | Описание |
|---------|----------|
| **Гость (Guest)** | Неавторизованный пользователь, базовый просмотр карты и навигация |
| **Пользователь (User)** | Авторизованный через Google Account, полный функционал |
| **Local Guide** | Активный контрибьютор, 10 уровней, баллы и бейджи |
| **Владелец бизнеса (Business Owner)** | Управляет Google Business Profile |
| **Разработчик (Developer)** | Использует Google Maps Platform API |
| **Рекламодатель (Advertiser)** | Размещает рекламу через Google Ads |
| **Транспортный оператор** | Поставляет данные GTFS для общественного транспорта |

## Ключевые метрики

| Метрика | Описание |
|---------|----------|
| MAU | Ежемесячная активная аудитория |

| Local Guide Active Contributors | Активные контрибьюторы Local Guides |

| Transit Coverage | Количество интегрированных транспортных агентств (10 000+) |

| Ad Revenue per User | Средняя рекламная выручка на пользователя |

## Глоссарий

| Термин | Определение |
|--------|-------------|
| **POI** | Point of Interest — точка интереса (ресторан, магазин, достопримечательность) |
| **Place Details** | Карточка места с полной информацией |
| **Local Guide** | Участник программы контрибьюторов Google Maps |
| **GBP** | Google Business Profile — бизнес-профиль в Google |
| **GTFS** | General Transit Feed Specification — стандарт данных общественного транспорта |
| **GTFS-RT** | GTFS Realtime — расширение для данных в реальном времени |
| **ETA** | Estimated Time of Arrival — расчётное время прибытия |
| **Immersive View** | Фотореалистичный 3D-режим с симуляцией погоды и времени суток |
| **Street View** | Панорамные снимки улиц на уровне земли |
| **Photo Sphere** | 360-градусная фотография от пользователей |
| **Plus Code** | Открытый стандарт коротких адресных кодов (Open Location Code) |
| **Blue Dot** | Индикатор текущего местоположения пользователя на карте |
| **Timeline** | История перемещений пользователя |
| **Promoted Pin** | Рекламная метка на карте |
| **Reserve with Google** | Бронирование услуг через Google |
| **Pegman** | Иконка для перехода в Street View |
| **AQI** | Air Quality Index — индекс качества воздуха |
| **VPS** | Visual Positioning System — визуальное позиционирование для AR |

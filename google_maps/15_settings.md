# Настройки и приватность

## Описание

Модуль «Настройки и приватность» объединяет все функции управления персональными предпочтениями пользователя Google Maps: настройки навигации (голос, громкость, маршрутные предпочтения), параметры отображения карты, приватность и управление данными о местоположении (Location History / Timeline), управление Web & App Activity, офлайн-карты, уведомления, доступность, язык и региональные настройки.

Google Maps тесно интегрирован с экосистемой Google Account — многие настройки приватности управляются централизованно через Google Account и синхронизируются между устройствами. Модуль настроек реализует требования GDPR, CCPA и других региональных законов о защите персональных данных.

---

## Роли пользователей

| Роль | Описание | Права в модуле настроек |
|------|----------|------------------------|
| **Пользователь (Consumer)** | Конечный пользователь приложения Google Maps | Полное управление всеми настройками навигации, карты, приватности, уведомлений |
| **Пользователь без аккаунта** | Использует Google Maps без входа в аккаунт | Ограниченные настройки навигации и карты; без доступа к Timeline, синхронизации, персонализации |
| **Владелец бизнеса (Business Owner)** | Владелец верифицированного бизнес-профиля | Управление настройками бизнес-профиля через Google Business Profile |
| **Администратор Google Account** | Администратор организации (Google Workspace) | Может устанавливать политики Location History и Web & App Activity для пользователей организации |

## Функциональные требования

### Настройки навигации

**FR-SET-001: Выбор голоса навигации**
- Пользователь может выбрать голос для голосовых подсказок навигации
- Доступные голоса зависят от языка устройства и региона
- Бизнес-правило: по умолчанию голос определяется языком устройства
- Бизнес-правило: при отсутствии голоса для выбранного языка используется английский голос

**FR-SET-002: Громкость голосовых подсказок**
- Пользователь может выбрать уровень громкости голосовых подсказок: тише (Softer), обычная (Normal), громче (Louder)
- Бизнес-правило: по умолчанию установлен уровень «обычная»
- Бизнес-правило: громкость подсказок управляется независимо от системной громкости устройства

**FR-SET-003: Воспроизведение голоса через Bluetooth**
- Пользователь может включить/отключить воспроизведение голосовых подсказок через Bluetooth-устройство (автомобильная аудиосистема, наушники)
- Бизнес-правило: при подключённом Bluetooth-устройстве система предлагает включить данную настройку
- Бизнес-правило: если Bluetooth-устройство отключается во время навигации, звук автоматически переключается на динамик устройства

**FR-SET-004: Воспроизведение голоса во время телефонных звонков**
- Пользователь может включить/отключить голосовые подсказки навигации во время активного телефонного звонка
- Бизнес-правило: по умолчанию подсказки во время звонка отключены
- Бизнес-правило: при включении подсказки микшируются с аудио звонка

**FR-SET-005: Избегание платных дорог (Avoid Tolls)**
- Пользователь может включить постоянное избегание платных дорог при построении маршрутов
- Бизнес-правило: настройка применяется ко всем новым маршрутам автоматически
- Бизнес-правило: пользователь может переопределить настройку для конкретного маршрута при его построении
- Бизнес-правило: если маршрут без платных дорог существенно длиннее (более чем в 2 раза), система предупреждает пользователя

**FR-SET-006: Избегание автомагистралей (Avoid Highways)**
- Пользователь может включить постоянное избегание автомагистралей
- Бизнес-правило: настройка сохраняется между сессиями
- Бизнес-правило: может быть переопределена для конкретного маршрута

**FR-SET-007: Избегание паромов (Avoid Ferries)**
- Пользователь может включить постоянное избегание паромных переправ
- Бизнес-правило: при отсутствии альтернативного маршрута без парома система уведомляет пользователя и предлагает маршрут с паромом

**FR-SET-008: Отображение стоимости платных дорог**
- Система отображает ориентировочную стоимость проезда по платным дорогам перед началом навигации
- Бизнес-правило: стоимость рассчитывается на основе данных от местных операторов платных дорог
- Бизнес-правило: пользователь может указать наличие транспондера (toll pass) для получения более точных цен
- Бизнес-правило: цены отображаются в местной валюте

**FR-SET-009: Настройки спидометра**
- Пользователь может включить/отключить отображение текущей скорости на экране навигации
- Бизнес-правило: доступность функции зависит от региона
- Бизнес-правило: спидометр показывает скорость в единицах, выбранных пользователем (км/ч или миль/ч)

**FR-SET-010: Оповещения о камерах скорости**
- Пользователь может включить/отключить предупреждения о камерах контроля скорости на маршруте
- Бизнес-правило: доступность функции ограничена законодательством ряда стран (в некоторых регионах функция недоступна)
- Бизнес-правило: предупреждение выдаётся заблаговременно — за определённое расстояние до камеры

**FR-SET-011: Оповещение о превышении скорости**
- Система может предупреждать пользователя, когда текущая скорость превышает ограничение на данном участке дороги
- Бизнес-правило: ограничения скорости берутся из базы данных дорожных знаков и могут быть неточными
- Бизнес-правило: система отображает дисклеймер о том, что данные носят информационный характер

**FR-SET-012: Настройки транспондера (Toll Pass)**
- Пользователь может указать наличие и тип транспондера для платных дорог
- Поддерживаемые типы зависят от региона (E-ZPass, FasTrak, SunPass и др.)
- Бизнес-правило: при указанном транспондере стоимость проезда пересчитывается с учётом скидки
- Бизнес-правило: маршруты с платными дорогами могут получить приоритет, если пользователь имеет транспондер

**FR-SET-013: Настройки маршрута для электромобилей**
- Пользователь может указать тип двигателя транспортного средства (бензин, дизель, электрический, гибрид)
- Для электромобилей: пользователь указывает модель и тип разъёма зарядки
- Бизнес-правило: при выборе электромобиля маршрут учитывает расход энергии и предлагает остановки для зарядки
- Бизнес-правило: система предпочитает маршруты с энергоэффективным профилем (меньше подъёмов, более ровные дороги)

**FR-SET-014: Экомаршруты (Eco-friendly Routes)**
- Пользователь может включить/отключить предпочтение экологичных маршрутов
- Бизнес-правило: при включении система по умолчанию предлагает маршрут с наименьшим расходом топлива/энергии, если время в пути сопоставимо с самым быстрым маршрутом
- Бизнес-правило: пользователь всегда может выбрать альтернативный (более быстрый) маршрут
- Бизнес-правило: экономия топлива отображается в сравнении с самым быстрым маршрутом

### Настройки карты

**FR-SET-015: Тип карты по умолчанию**
- Пользователь может выбрать тип карты по умолчанию: стандартная, спутниковая, рельефная
- Бизнес-правило: по умолчанию выбрана стандартная карта
- Бизнес-правило: выбор сохраняется между сессиями

**FR-SET-016: Слои карты**
- Пользователь может включить/отключить дополнительные слои: пробки (Traffic), общественный транспорт (Transit), велодорожки (Biking), 3D-здания
- Бизнес-правило: одновременно может быть активен только один информационный слой (пробки / транспорт / велодорожки)
- Бизнес-правило: слой 3D-зданий может быть включён параллельно с любым информационным слоем

**FR-SET-017: Масштаб и ориентация карты**
- Пользователь может управлять масштабом карты жестами или кнопками
- Пользователь может переключить ориентацию карты: север вверху (North Up) или по направлению движения (Heading Up)
- Бизнес-правило: во время навигации по умолчанию включён режим «по направлению движения»
- Бизнес-правило: при просмотре карты без навигации по умолчанию используется «север вверху»

**FR-SET-018: Цветовая схема карты**
- Система автоматически переключается между дневной и ночной темой карты
- Бизнес-правило: переключение происходит на основе времени захода/восхода солнца в текущей локации
- Бизнес-правило: пользователь может принудительно выбрать дневной или ночной режим в настройках навигации

**FR-SET-019: Начальный экран (Start Screen)**
- Пользователь может настроить начальный экран Google Maps: вкладка «Обзор» (Explore), «Поездка» (Go), «Сохранённые» (Saved)
- Бизнес-правило: по умолчанию открывается вкладка «Обзор»
- Бизнес-правило: если у пользователя настроен маршрут до работы/дома, на начальном экране отображается карточка с предложением навигации

### Приватность и Location History

**FR-SET-020: Включение/отключение Location History (Timeline)**
- Пользователь может включить или отключить функцию Timeline (ранее — Location History)
- Бизнес-правило: Timeline выключена по умолчанию и активируется только по явному согласию пользователя (opt-in)
- Бизнес-правило: при включении устройство регулярно сохраняет точное местоположение, даже когда Google Maps не используется активно
- Бизнес-правило: данные Timeline хранятся локально на устройстве пользователя (изменение 2024 года)

**FR-SET-021: Хранение данных Timeline**
- Данные Timeline сохраняются на устройстве пользователя
- Пользователь может создать резервную копию Timeline в зашифрованном виде в Google Account
- Бизнес-правило: при смене устройства без резервной копии данные Timeline теряются
- Бизнес-правило: зашифрованная резервная копия доступна только с устройства пользователя (end-to-end encryption)

**FR-SET-022: Автоматическое удаление данных Timeline**
- Пользователь может настроить автоматическое удаление данных Timeline старше определённого периода
- Доступные периоды: 3 месяца, 18 месяцев, 36 месяцев
- Бизнес-правило: по умолчанию для новых пользователей установлен период автоудаления 3 месяца
- Бизнес-правило: при истечении срока данные удаляются безвозвратно
- Бизнес-правило: пользователь может отключить автоудаление и хранить данные бессрочно

**FR-SET-023: Ручное удаление данных Timeline**
- Пользователь может вручную удалить:
  - Отдельную запись о посещении конкретного места
  - Все данные за определённый день
  - Все данные за выбранный диапазон дат
  - Все данные Timeline полностью
- Бизнес-правило: удаление необратимо
- Бизнес-правило: после удаления данные перестают быть доступны немедленно, фактическое удаление из систем происходит в фоновом режиме

**FR-SET-024: Автоматическое удаление чувствительных посещений**
- Система автоматически удаляет из Timeline записи о посещении чувствительных мест
- К чувствительным местам относятся: медицинские учреждения (клиники репродуктивного здоровья, наркологические центры, центры психологической помощи), приюты для жертв домашнего насилия, центры снижения веса
- Бизнес-правило: удаление происходит автоматически, пользователь не может переопределить это поведение
- Бизнес-правило: категории чувствительных мест определяются Google и могут обновляться

**FR-SET-025: Просмотр Timeline**
- Пользователь может просматривать историю своих посещений на карте с привязкой ко времени
- Доступна фильтрация по дате, городу, стране
- Бизнес-правило: Timeline отображается только на устройстве, где данные были собраны (или при наличии резервной копии)

**FR-SET-026: Режим инкогнито (Incognito Mode)**
- Пользователь может включить режим инкогнито в Google Maps
- В режиме инкогнито:
  - Поисковые запросы не сохраняются в истории аккаунта
  - Посещённые места не добавляются в Timeline
  - Персонализированные рекомендации не формируются
  - Уведомления не отображаются
  - Местоположение не используется для обновления данных аккаунта
- Бизнес-правило: режим инкогнито активируется через меню профиля
- Бизнес-правило: при включении инкогнито отображается визуальный индикатор на всех экранах
- Бизнес-правило: инкогнито автоматически отключается через 24 часа бездействия (или при закрытии приложения, зависит от платформы)

### Web & App Activity

**FR-SET-027: Управление Web & App Activity для Maps**
- Пользователь может включить/отключить сохранение активности Google Maps в Web & App Activity
- При включении сохраняются: поисковые запросы, просмотренные маршруты, взаимодействия с карточками мест
- Бизнес-правило: Web & App Activity управляется на уровне Google Account и влияет на все сервисы Google
- Бизнес-правило: отключение снижает качество персонализации рекомендаций

**FR-SET-028: Автоудаление Web & App Activity**
- Пользователь может настроить автоматическое удаление Web & App Activity
- Доступные периоды: 3 месяца, 18 месяцев, 36 месяцев
- Бизнес-правило: настройка применяется ко всем сервисам Google, не только к Maps
- Бизнес-правило: по умолчанию для новых аккаунтов установлен период 18 месяцев

**FR-SET-029: Ручное удаление истории активности**
- Пользователь может вручную удалить записи об активности в Maps:
  - Отдельный поисковый запрос
  - Все данные за период
  - Всю историю Maps-активности
- Бизнес-правило: удаление из Web & App Activity также удаляет данные из персонализации рекомендаций

**FR-SET-030: Управление историей поиска**
- Пользователь может просматривать и удалять историю поисковых запросов в Maps
- Бизнес-правило: история поиска используется для автодополнения при вводе
- Бизнес-правило: при отключённой Web & App Activity история поиска хранится только локально на устройстве

### Персональные данные и Google Account

**FR-SET-031: Просмотр данных аккаунта**
- Пользователь может просмотреть данные связанного Google Account: имя, email, фото профиля
- Переход к редактированию данных происходит через Google Account Settings
- Бизнес-правило: Google Maps не предоставляет собственный интерфейс редактирования данных аккаунта — перенаправляет в Google Account

**FR-SET-032: Управление данными профиля в Maps**
- Пользователь может управлять публичной видимостью своих данных в Maps:
  - Отображаемое имя для отзывов (настоящее имя или псевдоним)
  - Фото профиля в отзывах
  - Уровень Local Guide
- Бизнес-правило: псевдоним (nickname) позволяет оставлять отзывы анонимно при сохранении подотчётности
- Бизнес-правило: смена между именем и псевдонимом доступна в любой момент

**FR-SET-033: Выгрузка данных (Google Takeout)**
- Пользователь может запросить выгрузку всех данных Google Maps через Google Takeout
- Выгрузка включает: Timeline, сохранённые места, отзывы, фотографии, вклады в карту, настройки
- Бизнес-правило: запрос обрабатывается в течение нескольких часов до нескольких дней
- Бизнес-правило: данные предоставляются в машиночитаемом формате (JSON, GeoJSON)
- Бизнес-правило: ссылка для скачивания действительна ограниченное время

**FR-SET-034: Удаление аккаунта и данных Maps**
- Пользователь может удалить все данные, связанные с Google Maps, без удаления Google Account
- Или пользователь может удалить Google Account полностью (включая все данные Maps)
- Бизнес-правило: при удалении данных Maps удаляются: Timeline, сохранённые места, отзывы, фотографии, вклады
- Бизнес-правило: удаление необратимо
- Бизнес-правило: перед удалением система запрашивает подтверждение и показывает, какие данные будут удалены

### Уведомления

**FR-SET-035: Категории уведомлений**
- Пользователь может включить/отключить уведомления по категориям:
  - **Перемещения (Getting Around)**: пробки на маршруте до дома/работы, задержки общественного транспорта, время выезда
  - **Места и рекомендации (Places)**: рекомендации ресторанов, магазинов, событий поблизости
  - **Обновления карты (Map Updates)**: запросы на подтверждение информации о местах, вклады в карту
  - **Навигация (Navigation)**: оповещения во время движения (камеры, аварии, полиция)
  - **Общественный транспорт (Transit)**: расписание избранных маршрутов, изменения в расписании
  - **Маркетинг и акции**: предложения от Google, Local Guide бонусы

**FR-SET-036: Уведомления о маршруте до дома/работы**
- Пользователь может включить уведомления с предложением оптимального времени выезда на работу/домой
- Бизнес-правило: для работы функции необходимо указать адреса «Дом» и «Работа» в сохранённых местах
- Бизнес-правило: время уведомлений определяется на основе анализа привычек пользователя (когда обычно выезжает)

**FR-SET-037: Уведомления об избранных маршрутах транспорта**
- Пользователь может добавить маршруты общественного транспорта в избранное и получать уведомления об изменениях
- Бизнес-правило: уведомления включают: задержки, отмены, изменения расписания
- Бизнес-правило: доступность зависит от наличия данных о транспорте в регионе

**FR-SET-038: Управление каналом уведомлений**
- Пользователь управляет push-уведомлениями через настройки операционной системы и настройки приложения
- Бизнес-правило: если push-уведомления отключены на уровне ОС, Google Maps не может их отправлять вне зависимости от настроек в приложении
- Бизнес-правило: email-уведомления управляются отдельно через Google Account

### Офлайн-карты

**FR-SET-039: Скачивание офлайн-карт**
- Пользователь может скачать область карты для использования без подключения к интернету
- Пользователь выбирает область на карте вручную, или система предлагает скачать область вокруг дома/работы
- Бизнес-правило: максимальный размер одной скачиваемой области ограничен (примерно 120 000 кв. км)
- Бизнес-правило: система отображает ориентировочный размер скачиваемых данных перед началом загрузки

**FR-SET-040: Автообновление офлайн-карт**
- Пользователь может включить/отключить автоматическое обновление скачанных офлайн-карт
- Бизнес-правило: при включении карты обновляются автоматически при подключении к Wi-Fi
- Бизнес-правило: обновление происходит примерно раз в 2 недели
- Бизнес-правило: если карта не обновлена более 30 дней, система уведомляет пользователя; через 365 дней без обновления карта удаляется

**FR-SET-041: Предпочтения скачивания офлайн-карт**
- Пользователь может выбрать режим скачивания: только через Wi-Fi или через Wi-Fi и мобильные данные
- Бизнес-правило: по умолчанию скачивание только через Wi-Fi
- Бизнес-правило: настройка применяется как к первичному скачиванию, так и к автообновлениям

**FR-SET-042: Хранилище офлайн-карт**
- Пользователь может выбрать место хранения скачанных карт: внутренняя память устройства или SD-карта (на устройствах с поддержкой)
- Пользователь может просмотреть объём, занимаемый каждой скачанной областью
- Бизнес-правило: при нехватке места система уведомляет пользователя и предлагает удалить неиспользуемые области
- Бизнес-правило: при извлечении SD-карты офлайн-карты на ней становятся недоступны

**FR-SET-043: Удаление офлайн-карт**
- Пользователь может удалить любую скачанную область карты
- Бизнес-правило: удаление освобождает дисковое пространство немедленно
- Бизнес-правило: пользователь может переименовать скачанные области для удобства

**FR-SET-044: Рекомендуемые офлайн-карты**
- Система может предлагать скачать карту области перед поездкой (на основе предстоящих бронирований из Google Calendar, Gmail или ручных запросов маршрутов)
- Бизнес-правило: рекомендация отображается как уведомление или карточка на главном экране
- Бизнес-правило: функция работает только при включённой Web & App Activity

### Доступность (Accessibility)

**FR-SET-045: Accessible Places (Доступные места)**
- Пользователь может включить функцию Accessible Places
- При включении в карточках мест отображается информация о доступности для инвалидных колясок:
  - Доступный вход
  - Доступные туалеты
  - Доступные посадочные места
  - Доступная парковка
- Бизнес-правило: информация о доступности доступна для миллионов мест по всему миру
- Бизнес-правило: данные собираются от владельцев бизнесов и через вклады пользователей
- Бизнес-правило: при включении функции иконка инвалидной коляски отображается на карточках доступных мест

**FR-SET-046: Маршруты для инвалидных колясок**
- При включённой функции Accessible Places навигация для пешеходов учитывает доступность маршрутов
- Бизнес-правило: система предпочитает маршруты без лестниц и с пандусами
- Бизнес-правило: доступность функции ограничена городами, где имеются данные о пешеходной инфраструктуре

**FR-SET-047: Совместимость с экранными дикторами**
- Google Maps поддерживает работу с TalkBack (Android) и VoiceOver (iOS)
- Бизнес-правило: все элементы интерфейса имеют текстовые описания для экранных дикторов
- Бизнес-правило: навигация в режиме экранного диктора предоставляет расширенные голосовые инструкции

### Язык и регион

**FR-SET-048: Язык приложения**
- Язык интерфейса Google Maps определяется настройками языка устройства
- Бизнес-правило: Google Maps поддерживает более 70 языков
- Бизнес-правило: смена языка устройства автоматически меняет язык Maps
- Бизнес-правило: на некоторых платформах пользователь может выбрать язык Maps отдельно от системного языка

**FR-SET-049: Язык карты (подписи на карте)**
- Пользователь может выбрать язык подписей на карте (названия улиц, районов, городов)
- Варианты: язык устройства, местный язык, оба языка одновременно
- Бизнес-правило: при выборе «местный язык» названия отображаются на языке страны, где находится объект
- Бизнес-правило: при выборе «оба языка» местное название отображается с транслитерацией или переводом

**FR-SET-050: Единицы измерения расстояния**
- Пользователь может выбрать единицы измерения: автоматически, километры, мили
- Бизнес-правило: в режиме «автоматически» единицы определяются по региону пользователя
- Бизнес-правило: настройка применяется ко всем расстояниям в приложении: маршруты, расстояние до места, масштаб карты

**FR-SET-051: Формат времени**
- Формат времени (12-часовой / 24-часовой) определяется настройками устройства
- Бизнес-правило: применяется к отображению времени прибытия, часов работы мест, расписания транспорта

**FR-SET-052: Региональные настройки**
- Регион пользователя влияет на: валюту отображения цен, доступность функций (камеры скорости, стоимость платных дорог), формат адресов
- Бизнес-правило: регион определяется автоматически по местоположению или IP-адресу
- Бизнес-правило: пользователь может переопределить регион вручную в настройках Google Account

## Бизнес-правила

**BR-001: Синхронизация настроек через Google Account**
- Настройки навигации (избегание дорог, громкость, голос) синхронизируются между устройствами через Google Account
- Данные Timeline НЕ синхронизируются — хранятся локально на каждом устройстве (если не включена зашифрованная резервная копия)

**BR-002: Настройки без аккаунта**
- Пользователь без Google Account может использовать настройки навигации и карты, но они хранятся только локально
- Функции Timeline, Web & App Activity, синхронизация недоступны без аккаунта

**BR-003: Приоритет настроек маршрута**
- Настройки конкретного маршрута (избегание платных дорог, автомагистралей) имеют приоритет над глобальными настройками
- Глобальные настройки применяются по умолчанию, если пользователь не переопределил их для конкретного маршрута

**BR-004: Зависимость функций от региона**
- Доступность функций зависит от региона: камеры скорости, стоимость платных дорог, спидометр, экомаршруты, расписание транспорта
- Google Maps не раскрывает полный список ограничений по регионам — функции появляются/скрываются автоматически

**BR-005: Данные о продаже**
- Google Maps не продаёт персональные данные пользователей третьим лицам, включая рекламодателей
- Данные о местоположении могут использоваться для показа релевантной рекламы внутри экосистемы Google

**BR-006: Чувствительные места**
- Посещения чувствительных медицинских и социальных учреждений автоматически удаляются из Timeline
- Пользователь не может отключить данное поведение — это принудительная политика конфиденциальности

**BR-007: Режим инкогнито и навигация**
- В режиме инкогнито навигация работает полноценно, но маршрут и пункт назначения не сохраняются в истории
- Персонализированные рекомендации (пробки на маршруте до работы, избранные маршруты транспорта) недоступны в режиме инкогнито

**BR-008: Офлайн-карты и функциональность**
- Офлайн-карты поддерживают навигацию на автомобиле и поиск мест
- Офлайн-карты НЕ поддерживают: данные о пробках в реальном времени, маршруты общественного транспорта, информацию о велодорожках
- Пешеходная навигация в офлайн-режиме имеет ограниченную функциональность

**BR-009: Влияние Web & App Activity на качество сервиса**
- При отключённой Web & App Activity снижается качество: автодополнение поиска, рекомендации мест, персонализация маршрутов
- Основные функции (навигация, поиск, просмотр карты) продолжают работать без Web & App Activity

**BR-010: Возрастные ограничения**
- Для пользователей младше 18 лет (определяется по Google Account) Location History отключена по умолчанию и не может быть включена без согласия родителя/опекуна через Family Link
- Автоудаление данных для аккаунтов несовершеннолетних установлено на минимальный срок (3 месяца) без возможности увеличения

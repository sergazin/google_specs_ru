## 1. Общее описание модуля

Модуль «Онбординг и первый опыт» охватывает все процессы, которые проходит пользователь от первого запуска приложения Google Maps до момента полноценного использования всех доступных функций. Модуль включает запрос системных разрешений, привязку Google-аккаунта, персонализацию (адреса, транспорт, уведомления), настройку конфиденциальности, обучение ключевым функциям, а также онбординг в специализированные программы (Local Guides, Business Profile).

Google Maps является бесплатным сервисом; подписка или абонентская плата для конечного пользователя отсутствует. Приложение доступно на платформах Android, iOS и через веб-браузер (maps.google.com).

## 2. Роли и права

| Роль | Описание | Ключевые права в контексте онбординга |
|------|----------|---------------------------------------|
| Неавторизованный пользователь (Guest) | Пользователь без входа в Google-аккаунт | Базовая навигация, просмотр карты, построение маршрутов. Ограниченный доступ к отзывам, фото, персонализации |
| Авторизованный пользователь (Signed-in User) | Пользователь, вошедший в Google-аккаунт | Полный доступ: сохранение мест, история, персонализация, отзывы, фото, офлайн-карты, уведомления |
| Пользователь в режиме Инкогнито (Incognito User) | Авторизованный пользователь, включивший режим Инкогнито | Навигация и поиск без сохранения истории. Недоступны: сохранённые места, история, рекомендации, офлайн-карты, голосовой ассистент |
| Local Guide | Авторизованный пользователь, вступивший в программу Local Guides | Все права авторизованного пользователя + начисление баллов за вклад, бейдж, ранний доступ к функциям |
| Владелец бизнес-профиля (Business Owner) | Пользователь, подтвердивший владение бизнесом | Управление карточкой бизнеса: редактирование информации, ответы на отзывы, загрузка фото, просмотр статистики |
| Менеджер бизнес-профиля (Business Manager) | Назначенный владельцем управляющий | Те же права, что у владельца, кроме добавления/удаления пользователей и удаления профиля |

## 3. Первый запуск и системные разрешения

### FR-ONB-001: Принятие условий использования

**Описание:** При первом запуске приложения система требует от пользователя принятия условий использования Google Maps.

**Бизнес-правила:**
- Пользователь должен принять Google Terms of Service и Google Maps Additional Terms of Service
- Без принятия условий использование приложения невозможно
- Условия доступны для ознакомления по ссылке перед принятием
- Принятие условий фиксируется однократно и не запрашивается повторно (за исключением обновления условий)

---

### FR-ONB-002: Запрос разрешения на доступ к геолокации

**Описание:** Система запрашивает у пользователя разрешение на доступ к местоположению устройства для обеспечения корректной навигации и персонализации.

**Бизнес-правила:**
- Запрос отображается при первом запуске или при первой попытке использовать функцию, требующую геолокации
- Доступные варианты ответа пользователя:
  - «Разрешить всегда» -- приложение может использовать геолокацию в любое время
  - «Разрешить только при использовании» -- приложение использует геолокацию только в активном режиме
  - «Спрашивать каждый раз» -- запрос при каждом открытии
  - «Запретить» -- приложение не получает доступ к геолокации
- Система поддерживает два уровня точности:
  - Приблизительное местоположение (область ~3 км²)
  - Точное местоположение (координаты устройства)
- При отказе от предоставления геолокации приложение остаётся функциональным: пользователь может вручную вводить адреса, строить маршруты, просматривать карту
- Система может повторно предложить включить геолокацию при использовании функций, зависящих от местоположения (навигация, «Рядом со мной»)

> **BR-001:** Приложение функционирует без доступа к геолокации, но с ограниченной функциональностью. Навигация в реальном времени и функция «мое местоположение» требуют как минимум приблизительного доступа к геолокации.

---

### FR-ONB-003: Запрос разрешения на фоновую геолокацию

**Описание:** Система запрашивает дополнительное разрешение на доступ к геолокации в фоновом режиме для обеспечения работы Timeline, уведомлений о трафике и навигации при свёрнутом приложении.

**Бизнес-правила:**
- Запрос фоновой геолокации отделён от запроса обычной геолокации (двухэтапный процесс, в соответствии с требованиями платформ)
- Фоновая геолокация требуется для:
  - Продолжения навигации при свёрнутом приложении
  - Записи маршрутов в Timeline
  - Проактивных уведомлений о трафике на маршруте коммьюта
- Система объясняет пользователю, зачем нужен фоновый доступ, перед показом системного диалога
- При отказе -- навигация работает только при активном приложении на экране

> **BR-002:** Фоновая геолокация является опциональной и не блокирует базовую функциональность приложения.

---

### FR-ONB-004: Запрос разрешения на push-уведомления

**Описание:** Система запрашивает разрешение на отправку push-уведомлений для информирования пользователя о трафике, маршрутах и обновлениях.

**Бизнес-правила:**
- Запрос отображается после первого значимого действия пользователя (построение маршрута, настройка коммьюта) или при первом запуске
- При предоставлении разрешения система активирует набор уведомлений по умолчанию (см. раздел 7)
- При отказе -- пользователь не получает проактивных уведомлений, но вся функциональность приложения сохраняется
- Пользователь может изменить решение в настройках устройства в любой момент

---

### FR-ONB-005: Запрос разрешения на доступ к камере

**Описание:** Система запрашивает доступ к камере устройства при первой попытке использовать функции, связанные с камерой.

**Бизнес-правила:**
- Запрос выполняется контекстно -- только при первом обращении к функциям:
  - Live View (AR-навигация)
  - Загрузка фотографий мест
  - Сканирование QR-кодов
- Доступ к камере не запрашивается при первом запуске приложения
- При отказе -- соответствующие функции недоступны, остальная функциональность не затрагивается

---

### FR-ONB-006: Запрос разрешения на доступ к микрофону

**Описание:** Система запрашивает доступ к микрофону для голосового поиска и голосового управления навигацией.

**Бизнес-правила:**
- Запрос выполняется при первой попытке использовать голосовой поиск или голосовые команды
- Микрофон используется для: голосового поиска мест и адресов, голосовых команд во время навигации (hands-free), взаимодействия с Google Assistant
- При отказе -- голосовые функции недоступны, ручной ввод и навигация работают в полном объёме

---

### FR-ONB-007: Запрос разрешения на доступ к контактам

**Описание:** Система может запросить доступ к контактам устройства для упрощения поиска адресов и отправки геолокации.

**Бизнес-правила:**
- Запрос выполняется контекстно -- при попытке поделиться местоположением или найти адрес контакта
- Доступ к контактам не является обязательным для работы приложения
- При предоставлении доступа -- имена и адреса контактов отображаются в подсказках при поиске
- При отказе -- пользователь может вручную вводить адреса и номера телефонов

> **BR-003:** Все запросы разрешений являются опциональными. Отказ от любого разрешения не блокирует доступ к приложению, но ограничивает отдельные функции.

## 4. Аутентификация и привязка аккаунта

### FR-ONB-008: Использование приложения без Google-аккаунта

**Описание:** Система позволяет использовать базовые функции Google Maps без входа в Google-аккаунт.

**Бизнес-правила:**
- Без авторизации доступны:
  - Просмотр карты (дороги, названия городов, базовые объекты)
  - Построение маршрутов (все виды транспорта)
  - Голосовая навигация
  - Поиск мест и адресов
- Без авторизации недоступны:
  - Сохранение мест и списков
  - Офлайн-карты
  - История поиска и маршрутов
  - Персонализированные рекомендации
  - Написание отзывов и загрузка фото
  - Настройка адресов «Дом» и «Работа»
  - Timeline (хронология перемещений)
  - Участие в программе Local Guides
  - Шаринг местоположения в реальном времени

> **BR-004:** Google Maps функционирует без авторизации, но с существенно ограниченной персонализацией и набором функций. Система периодически предлагает авторизоваться при попытке использовать функции, требующие аккаунта.

---

### FR-ONB-009: Вход в Google-аккаунт

**Описание:** Система предлагает пользователю войти в Google-аккаунт для получения полного доступа к функциям.

**Бизнес-правила:**
- Вход выполняется через стандартный механизм аутентификации Google (Google Sign-In)
- Если на устройстве уже выполнен вход в Google-аккаунт (через другие приложения Google), Maps автоматически использует этот аккаунт
- Пользователь может переключаться между несколькими Google-аккаунтами внутри приложения
- При первом входе система синхронизирует ранее сохранённые данные аккаунта:
  - Адреса «Дом» и «Работа» (если были установлены через другие сервисы Google)
  - Сохранённые места и списки
  - Предпочтения и настройки
- Создание отдельного аккаунта для Google Maps не требуется -- используется единый Google-аккаунт

> **BR-005:** Один Google-аккаунт предоставляет доступ ко всем функциям Google Maps. Отдельная регистрация в Google Maps не существует.

---

### FR-ONB-010: Переключение между аккаунтами

**Описание:** Система позволяет пользователю переключаться между несколькими Google-аккаунтами в рамках одного приложения.

**Бизнес-правила:**
- Переключение доступно через меню профиля (иконка аватара)
- При переключении загружаются сохранённые места, история, предпочтения и настройки соответствующего аккаунта
- Каждый аккаунт имеет независимые настройки: адреса, сохранённые места, историю, настройки уведомлений, настройки конфиденциальности
- Активным может быть только один аккаунт одновременно

## 5. Персонализация: адреса и маршруты

### FR-ONB-011: Настройка адреса «Дом»

**Описание:** Система предлагает авторизованному пользователю сохранить домашний адрес для быстрого доступа при построении маршрутов.

**Бизнес-правила:**
- Система предлагает настроить адрес «Дом» после первого входа в аккаунт или при первом построении маршрута
- Предложение отображается в строке поиска как быстрая кнопка «Дом» с подсказкой «Задать адрес»
- Адрес может быть задан:
  - Текстовым поиском в строке поиска
  - Указанием точки на карте вручную
- Сохранённый адрес «Дом» синхронизируется через Google-аккаунт и доступен во всех сервисах Google (Поиск, Ассистент, Maps)
- Адрес «Дом» виден только владельцу аккаунта (приватный)
- Пользователь может изменить или удалить адрес «Дом» в любой момент
- Максимум один адрес «Дом» на аккаунт

---

### FR-ONB-012: Настройка адреса «Работа»

**Описание:** Система предлагает авторизованному пользователю сохранить рабочий адрес для оптимизации ежедневных маршрутов.

**Бизнес-правила:**
- Логика аналогична адресу «Дом» (FR-ONB-011)
- Адрес «Работа» отображается рядом с адресом «Дом» в строке быстрого доступа
- Используется для:
  - Быстрого построения маршрутов «Дом -- Работа» и обратно
  - Расчёта времени коммьюта
  - Проактивных уведомлений о трафике на маршруте коммьюта
- Максимум один адрес «Работа» на аккаунт
- Адрес «Работа» приватен и виден только владельцу аккаунта

---

### FR-ONB-013: Сохранение дополнительных избранных мест

**Описание:** Система позволяет пользователю сохранять произвольные адреса с пользовательскими метками для быстрого доступа.

**Бизнес-правила:**
- Помимо «Дом» и «Работа» пользователь может создавать произвольные ярлыки (метки) для адресов
- Примеры: «Спортзал», «Школа», «Дача»
- Сохранённые метки отображаются в подсказках при поиске
- Количество дополнительных меток не ограничено
- Метки синхронизируются через Google-аккаунт
- Пользователь может организовывать сохранённые места в списки (Lists)

## 6. Персонализация: транспортные предпочтения

### FR-ONB-014: Выбор предпочтительного способа передвижения

**Описание:** Система позволяет пользователю установить предпочтительный вид транспорта, который будет предлагаться по умолчанию при построении маршрутов.

**Бизнес-правила:**
- Доступные виды транспорта:
  - Автомобиль (Driving)
  - Общественный транспорт (Transit)
  - Пешком (Walking)
  - Велосипед (Cycling)
  - Мотоцикл (Motorcycle) -- в поддерживаемых регионах
  - Райдшеринг (Ride-sharing) -- при наличии партнёрских сервисов
  - Авиаперелёт (Flight) -- для межгородских маршрутов
- Предпочтительный вид транспорта определяет, какой способ отображается первым при построении маршрута
- Система может автоматически предлагать оптимальный вид транспорта на основе расстояния и контекста
- Если время в пути пешком или на общественном транспорте сопоставимо с автомобилем, система показывает альтернативные варианты

> **BR-006:** Доступность видов транспорта зависит от региона. Мотоцикл, велосипед и общественный транспорт доступны не во всех городах.

---

### FR-ONB-015: Настройка параметров маршрута для автомобиля

**Описание:** Система позволяет пользователю задать предпочтения, влияющие на построение автомобильных маршрутов.

**Бизнес-правила:**
- Доступные параметры:
  - Избегать платных дорог (Avoid tolls)
  - Избегать автомагистралей (Avoid highways)
  - Избегать паромов (Avoid ferries)
- Параметры сохраняются и применяются ко всем последующим автомобильным маршрутам
- Пользователь может переопределить параметры для конкретного маршрута без изменения настроек по умолчанию

---

### FR-ONB-016: Настройка параметров общественного транспорта

**Описание:** Система позволяет пользователю задать предпочтения для маршрутов общественного транспорта.

**Бизнес-правила:**
- Доступные параметры:
  - Предпочтительные виды транспорта: автобус, метро, электричка, трамвай
  - Критерий оптимизации: минимум пересадок, минимум ходьбы, минимум времени
- Система учитывает расписание транспорта в реальном времени (при наличии данных)
- Параметры сохраняются в профиле и применяются по умолчанию

---

### FR-ONB-017: Настройка коммьюта (ежедневного маршрута)

**Описание:** Система предлагает пользователю настроить параметры ежедневного маршрута «Дом -- Работа» для проактивных рекомендаций.

**Бизнес-правила:**
- Настройка коммьюта доступна после установки адресов «Дом» и «Работа»
- Пользователь указывает:
  - Вид транспорта для коммьюта
  - Время отправления утром и время возвращения вечером (опционально)
  - Рабочие дни недели
- При настроенном коммьюте система:
  - Отображает время в пути до работы/дома на главном экране (вкладка «Коммьют»)
  - Отправляет проактивные уведомления о трафике, задержках, авариях на маршруте
  - Предлагает оптимальное время отправления
  - Предупреждает о нетипичных задержках заранее

> **BR-007:** Для работы уведомлений о коммьюте требуется: (1) настроенные адреса «Дом» и «Работа», (2) включённые push-уведомления, (3) предоставленная фоновая геолокация (для проактивных уведомлений).

---

## 7. Настройка уведомлений

### FR-ONB-018: Управление категориями уведомлений

**Описание:** Система позволяет пользователю гранулярно управлять типами получаемых уведомлений.

**Бизнес-правила:**
- Категории уведомлений, управляемые пользователем:
  - **Навигация:** пошаговые подсказки, предупреждения о камерах скорости, авариях
  - **Трафик и коммьют:** пробки на маршруте, задержки общественного транспорта, оптимальное время отправления
  - **Время отъезда:** напоминания «Пора выезжать» на основе запланированных событий (из Google Calendar)
  - **Места рядом:** рекомендации ресторанов, достопримечательностей, заправок поблизости
  - **Обновления мест:** изменения в часах работы, новые отзывы на сохранённые места
  - **Поездки и путешествия:** рекомендации для путешественников, офлайн-карты для предстоящих поездок
  - **Общественный транспорт:** расписание, задержки, отмены рейсов
  - **Google Maps обновления:** новые функции, подсказки по использованию
- Каждую категорию можно включить/выключить независимо
- По умолчанию при предоставлении разрешения на push-уведомления включены: навигация, трафик и коммьют, время отъезда

> **BR-008:** Уведомления навигации (во время активной навигации) не могут быть отключены, если навигация запущена -- это критические уведомления безопасности.

### FR-ONB-019: Проактивные уведомления на основе контекста

**Описание:** Система отправляет проактивные уведомления без явного запроса пользователя, основываясь на его поведении и контексте.

**Бизнес-правила:**
- Типы проактивных уведомлений:
  - Предупреждение о пробках на маршруте коммьюта (утром -- до работы, вечером -- до дома)
  - Напоминание о времени выезда на запланированные события (интеграция с Google Calendar)
  - Предупреждение о закрытии или изменении часов работы сохранённого места
  - Рекомендация скачать офлайн-карту перед предстоящей поездкой (на основе данных из Gmail/Calendar)
  - Уведомление о событиях, влияющих на маршрут (концерт, спортивное событие, дорожные работы)
- Проактивные уведомления требуют:
  - Входа в Google-аккаунт
  - Включённых push-уведомлений
  - Включённой функции Web & App Activity (для анализа контекста)
- Пользователь может отключить проактивные уведомления полностью или по категориям

## 8. Настройка конфиденциальности и данных

### FR-ONB-020: Настройка Timeline (хронология перемещений)

**Описание:** Система предлагает пользователю включить Timeline -- функцию записи и хранения истории перемещений.

**Бизнес-правила:**
- Timeline по умолчанию выключена для новых аккаунтов
- Включение Timeline требует явного согласия пользователя (opt-in)
- При включении Timeline:
  - Устройство записывает местоположение с определённой периодичностью (от нескольких раз в час до нескольких раз в минуту при навигации)
  - Данные сохраняются локально на устройстве пользователя
  - Пользователь может включить облачное резервное копирование (с end-to-end шифрованием)
- Пользователь управляет периодом хранения данных Timeline:
  - Автоудаление через 3 месяца
  - Автоудаление через 18 месяцев
  - Автоудаление через 36 месяцев
  - Хранить до ручного удаления
- Пользователь может удалить всю историю Timeline или отдельные записи в любой момент

> **BR-009:** Timeline является строго opt-in функцией. Система не записывает историю перемещений без явного согласия пользователя.

---

### FR-ONB-021: Настройка Web & App Activity

**Описание:** Система информирует пользователя о влиянии настройки Web & App Activity на работу Google Maps.

**Бизнес-правила:**
- Web & App Activity -- настройка уровня Google-аккаунта, влияющая на все сервисы Google
- При включённой Web & App Activity в Google Maps сохраняются:
  - История поиска мест
  - История просмотренных маршрутов
  - Данные для персонализированных рекомендаций
- При выключенной Web & App Activity:
  - Поисковые запросы не сохраняются
  - Рекомендации менее персонализированы
  - Timeline может продолжать работать независимо (если включена)
- Пользователь может удалить сохранённую активность в любой момент через настройки аккаунта

> **BR-010:** Даже при выключенном Timeline, данные о местоположении могут сохраняться через Web & App Activity (если она включена). Система информирует об этом пользователя.

### FR-ONB-022: Согласие на персонализированную рекламу в картах

**Описание:** Система информирует пользователя о показе персонализированной рекламы в Google Maps и предоставляет инструменты управления.

**Бизнес-правила:**
- Google Maps может отображать рекламные метки (Promoted Pins) и спонсированные результаты поиска
- Пользователь может управлять персонализацией рекламы через настройки Google-аккаунта (Ad Settings)
- Полное отключение рекламы в Google Maps невозможно -- но возможна деперсонализация
- Система маркирует рекламный контент явной пометкой «Реклама» / «Sponsored»

## 9. Офлайн-карты: первая загрузка

### FR-ONB-023: Предложение загрузить офлайн-карту

**Бизнес-правила:**
- Предложение загрузить офлайн-карту отображается:
  - При обнаружении предстоящей поездки (на основе данных из Gmail/Calendar)
  - При нахождении в зоне с нестабильным интернет-соединением
  - Через раздел «Офлайн-карты» в меню профиля
- Загрузка офлайн-карт доступна только авторизованным пользователям
- Загрузка в режиме Инкогнито недоступна

### FR-ONB-024: Процесс загрузки офлайн-карты

**Описание:** Система позволяет пользователю выбрать область карты и загрузить её для офлайн-использования.

**Бизнес-правила:**
- Два способа загрузки:
  1. Поиск конкретного места -- система предлагает загрузить область вокруг него
  2. Ручной выбор области на карте -- пользователь перемещает и масштабирует рамку
- Перед загрузкой система отображает:
  - Оценочный размер файла
  - Доступное место на устройстве
- Настройки загрузки:
  - Загрузка только через Wi-Fi (по умолчанию) или через мобильную сеть
  - Хранение на внутренней памяти устройства или на SD-карте (Android)
- Срок действия офлайн-карты -- до 15 дней без обновления
- При подключении к Wi-Fi система автоматически обновляет загруженные карты (при включённой настройке автообновления)
- Автообновление карт происходит примерно каждые 2 недели

> **BR-011:** Офлайн-карты требуют авторизации в Google-аккаунте. Неавторизованные пользователи не могут загружать офлайн-карты.

## 10. Обучение функциям (первый опыт)

### FR-ONB-025: Обучающие подсказки при первом использовании

**Описание:** Система показывает контекстные обучающие подсказки при первом взаимодействии пользователя с ключевыми функциями.

**Бизнес-правила:**
- Подсказки отображаются однократно для каждой функции:
  - Первое построение маршрута: объяснение выбора вида транспорта, альтернативных маршрутов
  - Первая навигация: объяснение голосовых подсказок, изменения маршрута, остановок в пути
  - Первое использование поиска: подсказка о фильтрах (часы работы, рейтинг, тип заведения)
  - Первый просмотр карточки места: объяснение функций сохранения, отзывов, фото
  - Первое использование Street View: подсказка об управлении панорамой
  - Первое использование Live View (AR): объяснение AR-навигации
- Пользователь может закрыть (пропустить) любую подсказку
- Пропущенные подсказки не показываются повторно
- Подсказки не отображаются для пользователей, ранее использовавших Google Maps (определяется по аккаунту)

### FR-ONB-026: Знакомство с ключевыми функциями через вкладки

**Описание:** Система знакомит нового пользователя со структурой приложения через основные вкладки навигации.

**Бизнес-правила:**

  - **Коммьют (Commute / Go):** ежедневные маршруты, время в пути, трафик
  - **Сохранённое (Saved):** сохранённые места, списки, офлайн-карты
  - **Вклад (Contribute):** добавление отзывов, фото, редактирование карт
  - **Обновления (Updates):** рекомендации, новости о местах
- При первом запуске система может выделить вкладки для привлечения внимания нового пользователя
- Порядок и наличие вкладок может варьироваться в зависимости от региона и версии приложения

### FR-ONB-027: Промо-предложения и партнёрские интеграции при первом опыте

## 11. Онбординг в программу Local Guides

**Бизнес-правила:**
- Предложение вступить отображается:
  - После написания первого отзыва
  - После загрузки первого фото места
  - Через раздел «Вклад» (Contribute) в приложении
- Вступление бесплатно и требует только Google-аккаунт

### FR-ONB-029: Система баллов и уровней Local Guides

**Описание:** Система начисляет баллы Local Guide за вклад пользователя и определяет уровень в программе.

**Бизнес-правила:**
- Начисление баллов за действия:
  - Отзыв -- 10 баллов; отзыв более 200 символов -- 10 бонусных баллов
  - Оценка (рейтинг) -- 1 балл
  - Фотография -- 5 баллов
  - Тег к фотографии -- 3 балла
  - Подпись к фотографии -- 10 баллов
  - Видео -- 7 баллов
  - Ответ на вопрос -- 1 балл
  - Ответ на Q&A -- 3 балла
  - Редактирование информации о месте -- 5 баллов
  - Добавление нового места -- 15 баллов
  - Проверка факта (верификация) -- 1 балл
- 10 уровней программы
- На уровне 4 (250 баллов) присваивается бейдж Local Guide
- Привилегии: бейдж в профиле, ранний доступ к новым функциям Google, приглашения на эксклюзивные мероприятия (для высоких уровней)

> **BR-012:** Участие в программе Local Guides строго добровольно. Неучастие не влияет на доступность функций Google Maps.

## 12. Онбординг бизнес-профиля (Google Business Profile)

### FR-ONB-030: Создание бизнес-профиля

**Описание:** Система позволяет владельцу бизнеса создать и верифицировать профиль своей организации на Google Maps.

**Бизнес-правила:**
- Создание профиля бесплатно
- Для создания требуется Google-аккаунт
- Информация, указываемая при создании:
  - Название бизнеса
  - Категория (тип бизнеса)
  - Адрес или зона обслуживания
  - Контактные данные (телефон, сайт)
  - Часы работы
- Один бизнес может иметь только один профиль на Google Maps
- Бизнес-профиль может иметь нескольких владельцев и менеджеров, но только одного основного владельца (Primary Owner)

---

### FR-ONB-031: Верификация бизнес-профиля

**Описание:** Система требует подтверждения права владения бизнесом перед публикацией полного профиля на Google Maps.

**Бизнес-правила:**
- Способы верификации:
  - Открытка по почте с верификационным кодом на физический адрес бизнеса
  - Телефонный звонок или SMS с кодом
  - Электронная почта (для некоторых категорий бизнеса)
  - Видеозвонок (для подтверждения реального существования бизнеса)
  - Мгновенная верификация (для бизнесов, уже подтверждённых через Google Search Console)
- До верификации профиль имеет ограниченную видимость
- После верификации профиль полностью опубликован и доступен всем пользователям Google Maps
- Верификация выполняется однократно (за исключением случаев смены владельца или подозрительной активности)

> **BR-013:** Бизнес-профиль должен соответствовать Правилам представления бизнеса на Google. Виртуальные офисы, несуществующие бизнесы и бизнесы, нарушающие правила, отклоняются.

---

### FR-ONB-032: Назначение менеджеров бизнес-профиля

**Описание:** Система позволяет владельцу бизнес-профиля добавлять менеджеров для совместного управления.

**Бизнес-правила:**
- Роли:
  - **Primary Owner** (основной владелец) -- полный контроль, включая передачу права владения и удаление профиля
  - **Owner** (владелец) -- полный контроль, кроме передачи права основного владения
  - **Manager** (менеджер) -- все операции, кроме добавления/удаления пользователей и удаления профиля
- Приглашение менеджера выполняется через email
- Основной владелец может быть только один
- Минимум один владелец обязателен

## 13. Режим Инкогнито

### FR-ONB-033: Активация режима Инкогнито

**Описание:** Система позволяет авторизованному пользователю включить режим Инкогнито для использования Google Maps без сохранения данных.

**Бизнес-правила:**
- Режим Инкогнито доступен только авторизованным пользователям
- Активация через меню профиля (иконка аватара) -> «Включить режим Инкогнито»
- В режиме Инкогнито:
  - Поисковые запросы не сохраняются в истории
  - Навигация не записывается в Timeline
  - Местоположение не используется для шаринга
  - Персонализированные рекомендации отключены
- В режиме Инкогнито недоступны:
  - Сохранённые места и списки
  - Офлайн-карты
  - Google Assistant (голосовой ассистент)
  - Вклад (отзывы, фото, редактирование)
  - Уведомления
- Режим Инкогнито сохраняется до явного отключения пользователем
- При отключении режима Инкогнито -- возврат к полной функциональности с персонализацией

> **BR-014:** В режиме Инкогнито Google Maps работает по принципу «нулевого следа» -- никакие данные о действиях пользователя не сохраняются в аккаунте.

## 15. Диаграммы состояний

### 15.1. Жизненный цикл пользователя Google Maps

```
[Первый запуск]
  │
  ▼ Принятие условий
[Неавторизованный пользователь (Guest)]
  │
  ├── Базовое использование (карта, маршруты, навигация)
  │
  ├── Попытка использовать функцию, требующую аккаунта
  │     │
  │     ▼
  │   [Предложение авторизоваться]
  │     │
  │     ├── Отказ ──► [Guest] (продолжение с ограничениями)
  │     │
  │     └── Вход в Google-аккаунт
  │           │
  │           ▼
  └────────► [Авторизованный пользователь]
               │
               ├── Настройка адресов (Дом, Работа)
               ├── Настройка транспортных предпочтений
               ├── Настройка уведомлений
               ├── Настройка конфиденциальности (Timeline, Web & App Activity)
               ├── Загрузка офлайн-карт
               │
               ├── Включение Инкогнито ──► [Пользователь Инкогнито]
               │                               │
               │                               └── Выключение ──► [Авторизованный пользователь]
               │
               ├── Вступление в Local Guides ──► [Local Guide]
               │                                    │
               │                                    └── Набор баллов ──► [Local Guide Level 2..10]
               │
               └── Создание бизнес-профиля ──► [Владелец бизнеса (неверифицированный)]
                                                  │
                                                  └── Верификация ──► [Владелец бизнеса (верифицированный)]
```

## Глоссарий

| Термин | Определение |
|--------|-------------|
| Timeline | Хронология перемещений пользователя, записываемая на устройстве (opt-in) |
| Web & App Activity | Настройка Google-аккаунта, управляющая сохранением поисковой активности |
| Local Guide | Участник программы вклада в Google Maps (отзывы, фото, правки) |
| Business Profile | Профиль бизнеса на Google Maps с информацией об организации |
| Коммьют (Commute) | Ежедневный маршрут «Дом -- Работа», настраиваемый для проактивных уведомлений |
| Офлайн-карта | Загруженная на устройство область карты для использования без интернета |
| Live View | AR-навигация с наложением стрелок направления на изображение с камеры |
| Режим Инкогнито | Режим использования Google Maps без сохранения данных в аккаунте |
| Promoted Pin | Рекламная метка на карте, оплаченная бизнесом |
| Street View | Панорамные фотографии улиц и мест, доступные в Google Maps |
| Точное местоположение | Координаты устройства с высокой точностью (GPS) |
| Приблизительное местоположение | Местоположение с точностью ~3 км² (по сетям Wi-Fi/сотовым) |

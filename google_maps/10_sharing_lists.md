# Google Maps — Сохранённые места, списки и совместное использование

## Описание модуля

Модуль управления сохранёнными местами, списками и функциями шеринга в Google Maps. Охватывает системные и пользовательские списки мест, метки (Labels), совместное редактирование списков, шеринг местоположения в реальном времени, отправку мест другим пользователям, Plus Codes и интеграцию с контактами Google.

---

## 1. Сохранённые места (Saved Places)

### 1.1. Системные (дефолтные) списки

**FR-LIST-001** — Система предоставляет три предустановленных списка, которые невозможно удалить:

| Список | Иконка | Назначение |
|--------|--------|------------|
| **Favorites** (Избранное) | Сердце | Лучшие места, которые пользователь рекомендует другим |
| **Want to go** (Хочу посетить) | Зелёный флаг | Места, которые пользователь планирует посетить |
| **Starred places** (Отмеченные) | Звезда | Временные закладки, места для быстрого доступа |

**FR-LIST-002** — Каждый системный список отображает уникальный маркер на карте (сердце, флаг, звезда) при включённой видимости.

**FR-LIST-003** — Starred places и Want to go — это разные списки с разной семантикой. Место может находиться одновременно в нескольких списках.

**BR-001** — Системные списки нельзя удалить, переименовать или изменить их иконку.

**BR-002** — Максимальное количество мест в одном списке — 500 записей.

### 1.2. Сохранение места

**FR-LIST-004** — Пользователь может сохранить место в список из следующих точек входа:
- Карточка места (Place Details)
- Результаты поиска
- Рекомендации от Gemini (Ask Maps)
- Скриншоты (Gemini автоматически распознаёт названия мест из скриншотов и предлагает создать список)

**FR-LIST-005** — При сохранении места пользователь выбирает целевой список (один или несколько). Если списков нет — предлагается создать новый.

**FR-LIST-006** — При сохранении места можно добавить текстовую заметку (note) к месту внутри конкретного списка.

**FR-LIST-007** — Сохранённые места отображаются на карте маркерами, соответствующими иконке списка, при условии включённой видимости.

**BR-003** — Одно и то же место может быть добавлено в несколько списков одновременно с разными заметками в каждом.

**BR-004** — Сохранение доступно только для авторизованных пользователей с аккаунтом Google.

### 1.3. Видимость списков на карте

**FR-LIST-008** — Для каждого списка пользователь может включить или выключить отображение маркеров на карте (Show on your map / Hide on your map).

**FR-LIST-009** — При включённой видимости маркеры мест из списка отображаются на всех уровнях зума при попадании в видимую область карты.

**BR-005** — По умолчанию системные списки (Favorites, Starred) отображаются на карте. Пользовательские списки по умолчанию скрыты.

## 2. Метки (Labels)

### 2.1. Системные метки

**FR-LIST-010** — Система предоставляет две предустановленные метки:
- **Home** (Дом) — домашний адрес пользователя
- **Work** (Работа) — рабочий адрес пользователя

**FR-LIST-011** — Метки Home и Work используются как быстрые точки назначения в навигации, построении маршрутов и поисковых подсказках.

**FR-LIST-012** — Пользователь может изменить иконку метки Home или Work через меню настроек метки.

**BR-006** — Метки Home и Work являются приватными и никогда не передаются другим пользователям и не отображаются публично.

### 2.2. Пользовательские метки

**FR-LIST-013** — Пользователь может создать произвольную метку для любого адреса (например: «Школа», «Дом родителей», «Спортзал»).

**FR-LIST-014** — При создании метки система предлагает автогенерированные варианты названий (Home, Work и другие контекстные).

**FR-LIST-015** — Метка привязывается к конкретному адресу и отображается при вводе этого адреса или при навигации.

**FR-LIST-016** — Метки доступны в поиске: при вводе названия метки в строку поиска отображается соответствующий адрес.

**BR-007** — Все метки являются приватными и видны только владельцу аккаунта.

**BR-008** — Метки отличаются от списков: метка — это именованный алиас для одного конкретного адреса, а не коллекция мест.

## 3. Пользовательские списки (Custom Lists)

### 3.1. Создание списка

**FR-LIST-017** — Пользователь может создать неограниченное количество пользовательских списков.

**FR-LIST-018** — При создании списка указываются:
- Название списка (обязательно)
- Иконка-эмодзи (опционально; выбор из полного набора эмодзи устройства)
- Описание списка (опционально)

**FR-LIST-019** — Иконка-эмодзи отображается как маркер на карте для мест из данного списка (при включённой видимости).

**FR-LIST-020** — Пользователь может изменить название, описание и иконку списка в любой момент.

### 3.2. Управление местами в списке

**FR-LIST-021** — Пользователь может добавлять и удалять места из списка.

**FR-LIST-022** — Для каждого места в списке можно добавить, отредактировать или удалить текстовую заметку.

**FR-LIST-023** — Места в списке отображаются с информацией: название, адрес, рейтинг, категория, фото, заметка пользователя.

**FR-LIST-024** — Пользователь может удалить весь список. При удалении списка все места из него удаляются из данного списка, но не из других списков и не из закладок.

### 3.3. Создание списка из скриншотов (Gemini)

**FR-LIST-025** — Пользователь может загрузить скриншоты (из социальных сетей, мессенджеров, статей), и Gemini автоматически распознаёт названия мест/заведений на изображениях.

**FR-LIST-026** — На основе распознанных мест Gemini предлагает создать персонализированный список с предварительно заполненными местами.

**FR-LIST-027** — Пользователь может отредактировать предложенный список перед сохранением: удалить нерелевантные места, добавить заметки.

**BR-009** — Распознавание мест из скриншотов доступно только при активной подписке или в рамках бесплатного лимита Gemini-функций (зависит от региона).

## 4. Совместные списки (Collaborative Lists)

### 4.1. Настройки приватности списка

**FR-LIST-028** — Каждый пользовательский список имеет один из трёх уровней доступа:

| Уровень | Видимость | Редактирование |
|---------|-----------|----------------|
| **Private** | Только владелец | Только владелец |
| **Shared (по ссылке)** | Любой по ссылке | Настраивается владельцем |
| **Public** | Виден на профиле владельца, доступен поиском | Только приглашённые коллабораторы |

**FR-LIST-029** — Для списка с доступом «Shared» владелец выбирает, могут ли просматривающие по ссылке также редактировать список или только просматривать.

**BR-010** — Системные списки (Favorites, Want to go, Starred) не могут быть расшарены или сделаны публичными.

### 4.2. Приглашение коллабораторов

**FR-LIST-030** — Владелец списка может пригласить коллабораторов через функцию «Invite collaborators».

**FR-LIST-031** — Приглашение отправляется через ссылку, которую можно передать любым способом (мессенджеры, email, соцсети).

**FR-LIST-032** — Приглашённый коллаборатор должен иметь аккаунт Google для присоединения к списку.

**FR-LIST-033** — Коллаборатор может:
- Добавлять новые места в список
- Удалять места, которые он добавил
- Добавлять и редактировать заметки к местам
- Ставить реакции (эмодзи) на места в списке

**FR-LIST-034** — Владелец списка может удалить любого коллаборатора из списка.

**BR-011** — Все участники списка видят имена и фото профиля других участников.

**BR-012** — Все участники видят, кто добавил или отредактировал каждое место и каждую заметку (атрибуция действий).

**BR-013** — Владелец сохраняет полный контроль: может удалить любое место, любую заметку, любого коллаборатора.

### 4.3. Реакции в совместных списках

**FR-LIST-035** — Участники совместного списка могут ставить эмодзи-реакции на отдельные места в списке.

**FR-LIST-036** — Реакции видны всем участникам списка и помогают приоритизировать места при совместном планировании.

## 5. Шеринг местоположения в реальном времени (Location Sharing)

### 5.1. Включение шеринга

**FR-LIST-037** — Пользователь может поделиться своим местоположением в реальном времени с выбранными контактами.

**FR-LIST-038** — При включении шеринга пользователь указывает:
- Получателя (контакт Google или ссылка)
- Продолжительность: фиксированное время (15 мин, 1 час, 3 часа и т.д.) или «До отключения»

**FR-LIST-039** — Шеринг можно инициировать двумя способами:
- **С контактом Google** — получатель видит местоположение в своём приложении Google Maps
- **По ссылке** — ссылку можно отправить через любой мессенджер; получателю не требуется аккаунт Google

**BR-014** — Шеринг по ссылке ограничен максимум 24 часами.

**BR-015** — Шеринг с контактом Google может быть бессрочным (до отключения вручную).

### 5.2. Данные, передаваемые при шеринге

**FR-LIST-040** — При активном шеринге получатель видит:
- Имя и фото профиля отправителя
- Текущее местоположение на карте (обновляется в реальном времени)
- Уровень заряда батареи устройства отправителя
- Статус зарядки (заряжается / не заряжается)
- Время последнего обновления местоположения

**FR-LIST-041** — Местоположение определяется комбинацией GPS, Wi-Fi и данных сотовой сети.

**BR-016** — Если устройство отправителя теряет связь, отображается последнее известное местоположение с меткой времени.

### 5.3. Уведомления о прибытии и убытии

**FR-LIST-042** — Получатель может настроить уведомления о прибытии (arrival) и убытии (departure) отправителя для конкретного места.

**FR-LIST-043** — Уведомления срабатывают каждый раз, когда отправитель прибывает в указанное место или покидает его (непрерывный мониторинг).

**FR-LIST-044** — Отправитель получает оповещение о том, что кто-то настроил уведомления о его прибытии/убытии:
- Push-уведомление в Google Maps
- Email-уведомление
- Ежемесячные напоминания по email о том, что уведомления активны

**FR-LIST-045** — Отправитель может заблокировать конкретному получателю возможность устанавливать уведомления о прибытии/убытии.

**BR-017** — Уведомления о прибытии/убытии можно настроить только для тех пользователей, которые добровольно делятся своим местоположением.

**BR-018** — Система гарантирует прозрачность: отправитель всегда знает, кто отслеживает его перемещения.

### 5.4. Шеринг поездки (Trip Sharing)

**FR-LIST-046** — Во время активной навигации (автомобиль, пешком, велосипед) пользователь может поделиться поездкой с выбранными контактами.

**FR-LIST-047** — При шеринге поездки получатель видит:
- Текущее местоположение на маршруте
- Пункт назначения
- Расчётное время прибытия (ETA)
- Прогресс по маршруту

**FR-LIST-048** — Шеринг поездки автоматически прекращается при прибытии в пункт назначения.

**BR-019** — Шеринг поездки — это отдельная функция от шеринга местоположения: он привязан к конкретной навигационной сессии и автоматически завершается.

### 5.5. Управление и индикация

**FR-LIST-049** — При активном шеринге местоположения на карте отправителя отображается иконка-индикатор над компасом, напоминающая об активном шеринге.

**FR-LIST-050** — Пользователь может в любой момент:
- Просмотреть список людей, с которыми делится местоположением
- Прекратить шеринг с конкретным контактом
- Прекратить шеринг со всеми контактами одновременно
- Изменить длительность шеринга

**FR-LIST-051** — Пользователь может просмотреть местоположения всех контактов, которые делятся с ним, на одной карте.

**BR-020** — Шеринг местоположения является двусторонним: пользователь A может видеть B, только если B добровольно включил шеринг с A. Взаимность не обязательна.

## 6. Отправка места другому пользователю

### 6.1. Шеринг карточки места

**FR-LIST-052** — Пользователь может отправить место (карточку POI, адрес, координаты) другому пользователю.

**FR-LIST-053** — Способы отправки:
- **Контакту Google** — место отображается в уведомлениях Google Maps получателя
- **Копирование ссылки** — генерируется короткая ссылка (goo.gl/maps/...) для отправки через любое приложение
- **Через системное меню шеринга** — выбор приложения-получателя (WhatsApp, Telegram, iMessage, email и т.д.)

**FR-LIST-054** — Ссылка на место содержит: название, адрес, координаты и превью (для поддерживаемых мессенджеров).

### 6.2. Отправка на своё устройство

**FR-LIST-055** — Пользователь может отправить место с десктопной версии Google Maps на своё мобильное устройство через функцию «Send to phone».

**FR-LIST-056** — Отправка на телефон работает при условии входа в один и тот же аккаунт Google на обоих устройствах.

**FR-LIST-057** — На мобильном устройстве отображается push-уведомление; при нажатии открывается карточка места в приложении Google Maps.

### 6.3. Шеринг маршрута

**FR-LIST-058** — Пользователь может отправить построенный маршрут (набор направлений) другому пользователю или на своё устройство.

**FR-LIST-059** — Получатель маршрута видит: начальную и конечную точки, промежуточные точки, расчётное время, способ передвижения.

## 7. Plus Codes

### 7.1. Отображение и использование

**FR-LIST-060** — Каждой точке на карте (каждой паре координат) соответствует уникальный Plus Code.

**FR-LIST-061** — Plus Code отображается в карточке места и при установке пина на произвольной точке карты.

**FR-LIST-062** — Plus Code имеет два формата:

| Формат | Пример | Описание |
|--------|--------|----------|
| **Global Code** (полный) | 7MJCH93V+7F | 8 символов до «+», уникальный глобально |
| **Local Code** (короткий) | H93V+7F Mountain View | Первые 4 символа опущены, добавлено название населённого пункта |

**FR-LIST-063** — Plus Code можно ввести в строку поиска Google Maps (и в Google Search) для навигации к точке.

**FR-LIST-064** — Пользователь может скопировать Plus Code в буфер обмена одним нажатием.

### 7.2. Шеринг через Plus Codes

**FR-LIST-065** — Plus Code можно передать текстовым сообщением, распечатать, нанести на вывеску или передать устно.

**FR-LIST-066** — Plus Code работает оффлайн: его можно записать и использовать позже для поиска на карте.

**BR-021** — Plus Codes — это открытый стандарт (open source); они не являются проприетарной технологией Google.

**BR-022** — Plus Codes особенно востребованы в регионах без формальной системы адресов: сельская местность, развивающиеся страны, удалённые территории.

**BR-023** — Plus Code обеспечивает точность до ~14 x 14 метров (для полного кода) или ~3 x 3 метров (для расширенного 11-символьного кода).

## 8. Интеграция с Google Contacts

**FR-LIST-067** — При шеринге местоположения или отправке места система предлагает список контактов Google пользователя.

**FR-LIST-068** — Контакты, которые делятся местоположением с пользователем, отображаются на карте с их аватарами.

**FR-LIST-069** — При нажатии на аватар контакта на карте отображается:
- Текущее местоположение контакта
- Время последнего обновления
- Уровень заряда батареи
- Возможность построить маршрут до контакта

**FR-LIST-070** — Система предлагает приоритетно те контакты, с которыми пользователь чаще всего взаимодействует (на основе частоты коммуникаций в Google-экосистеме).

**BR-024** — Для использования функций шеринга с контактами оба пользователя должны иметь аккаунт Google. Шеринг по ссылке не требует аккаунта у получателя.

---

## 9. Экспорт данных

**FR-LIST-071** — Пользователь может экспортировать все сохранённые места и списки через Google Takeout (takeout.google.com).

**FR-LIST-072** — При экспорте необходимо выбрать категорию «Saved» в списке данных для выгрузки.

**FR-LIST-073** — Экспорт поддерживает выбор формата файла, частоты выгрузки и места назначения (Google Drive, Dropbox, OneDrive, email).

**BR-025** — Экспорт выгружает все списки и места пользователя, но не включает места, добавленные другими коллабораторами в совместных списках.

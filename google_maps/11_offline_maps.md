# Офлайн-карты — Google Maps

> **Module ID**: GMAPS-011
> **Version**: 1.0.0
> **Last Updated**: 2026-03-19
> **Dependencies**: Навигация, Поиск, Хранилище устройства, Аккаунт Google

## Executive Summary

Модуль «Офлайн-карты» позволяет пользователям скачивать области карты на устройство для использования без интернет-соединения. Включает скачивание выбранной области карты, автоматическое обновление скачанных карт, навигацию в офлайн-режиме, ограниченный поиск без подключения, управление скачанными картами (переименование, удаление, ручное обновление), автоматическое скачивание рекомендованных карт, настройки хранилища (внутренняя память / SD-карта) и настройки загрузки (Wi-Fi / мобильная сеть). Модуль обеспечивает базовую навигационную функциональность при отсутствии стабильного подключения к интернету.

## Функциональные требования

### FR-OFF-001: Скачивание области карты вручную (выбор области)
**Приоритет**: P0

> Как пользователь, я хочу скачать выбранную область карты на своё устройство, чтобы использовать карту без подключения к интернету.

**Предусловия**:
- Приложение Google Maps установлено
- Доступно интернет-соединение для скачивания
- На устройстве достаточно свободного места

**Основной поток**:
1. Пользователь переходит в раздел «Офлайн-карты» через меню профиля
2. Пользователь нажимает «Выбрать свою карту» (Select your own map)
3. Система отображает карту с прямоугольной рамкой выделения
4. Пользователь перемещает и масштабирует рамку для покрытия нужной области
5. Система отображает:
   - Размер скачиваемых данных (в МБ/ГБ)
   - Предупреждение при недостаточном месте на устройстве
6. Пользователь нажимает «Скачать» (Download)
7. Система начинает загрузку в фоновом режиме
8. По завершении загрузки система отправляет уведомление
9. Карта появляется в списке скачанных карт с автоматическим именем (на основе основного города/региона в области)

**Альтернативный поток — Скачивание через поиск**:
1. Пользователь ищет город или место в строке поиска
2. Открывается карточка места
3. Пользователь нажимает на три точки (меню) в карточке
4. Выбирает «Скачать офлайн-карту» (Download offline map)
5. Система предлагает рамку, центрированную на найденном месте
6. Пользователь корректирует область при необходимости
7. Далее — как основной поток, шаг 5

**Критерии приёмки**:
- [ ] AC-001: Рамка выделения перемещается и масштабируется
- [ ] AC-002: Размер скачиваемых данных отображается до начала загрузки
- [ ] AC-003: Загрузка происходит в фоновом режиме
- [ ] AC-004: Уведомление по завершении загрузки
- [ ] AC-005: Карта доступна в списке скачанных карт

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-001 | Максимальная площадь одной скачиваемой области — ~120 000 км² |
| BR-002 | При превышении максимальной площади система блокирует кнопку «Скачать» и предлагает уменьшить область |
| BR-003 | Размер одной области варьируется от 10 МБ до 2 ГБ в зависимости от плотности данных (городские районы — больше, сельские — меньше) |
| BR-004 | Скачивание возможно при наличии достаточного свободного места на выбранном хранилище (внутренняя память или SD-карта) |
| BR-005 | Скачанная карта автоматически получает имя на основе основного географического объекта в области |

### FR-OFF-002: Ограничения по скачиванию карт
**Приоритет**: P0

> Как система, я должна информировать пользователя об ограничениях скачивания, чтобы он понимал, какие карты доступны и какие — нет.

**Предусловия**:
- Пользователь пытается скачать область карты

**Основной поток**:
1. При попытке скачать область, для которой офлайн-карты недоступны, система отображает сообщение об ограничении
2. Система проверяет:
   - Региональные ограничения (отдельные страны и регионы не поддерживают офлайн-карты)
   - Максимальный размер области
   - Свободное место на устройстве
3. При недостаточном месте — система предлагает:
   - Освободить место на устройстве
   - Удалить старые офлайн-карты
   - Уменьшить область скачивания

**Критерии приёмки**:
- [ ] AC-001: Информативное сообщение при региональном ограничении
- [ ] AC-002: Блокировка скачивания при превышении максимальной площади
- [ ] AC-003: Предупреждение при недостаточном месте

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-006 | Офлайн-карты недоступны в ряде стран и регионов из-за лицензионных ограничений, особенностей форматов адресов или недостаточной языковой поддержки |
| BR-007 | Система не устанавливает формальный лимит на количество скачанных карт — ограничение только по свободному месту на устройстве |
| BR-008 | При попытке скачать область, которая перекрывается с уже скачанной, система скачивает новую область отдельно (без объединения) |

### FR-OFF-003: Автообновление скачанных карт
**Приоритет**: P0

> Как пользователь, я хочу, чтобы скачанные карты обновлялись автоматически, чтобы данные оставались актуальными без моего участия.

**Предусловия**:
- Настройка «Автообновление офлайн-карт» включена
- Устройство подключено к сети (Wi-Fi или мобильная, в зависимости от настроек)

**Основной поток**:
1. Система периодически (примерно каждые 2 недели) проверяет наличие обновлений для скачанных областей
2. При наличии обновлений и соответствии условиям загрузки:
   - Подключение соответствует настройкам (Wi-Fi only или Wi-Fi + мобильная сеть)
   - Достаточно свободного места
3. Система скачивает обновления в фоновом режиме
4. Обновлённые данные заменяют устаревшие
5. Срок действия карты сбрасывается

**Альтернативный поток — Приближение к истечению срока**:
1. Когда до истечения срока карты остаётся 15 дней или менее
2. Система отправляет уведомление пользователю
3. При подключении к Wi-Fi система пытается обновить карту автоматически
4. Если автообновление невозможно — система напоминает пользователю обновить вручную

**Альтернативный поток — Автообновление выключено**:
1. Карта действует 30 дней с момента последнего обновления
2. За 15 дней до истечения — уведомление пользователю
3. По истечении 30 дней — карта удаляется автоматически для освобождения места

**Критерии приёмки**:
- [ ] AC-001: Автообновление работает в фоновом режиме
- [ ] AC-002: Обновление соблюдает настройки сети (Wi-Fi only)
- [ ] AC-003: Уведомление за 15 дней до истечения
- [ ] AC-004: При включённом автообновлении срок действия продлевается до 1 года
- [ ] AC-005: При выключенном автообновлении карта удаляется через 30 дней

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-009 | При включённом автообновлении карты остаются действительными до 1 года |
| BR-010 | При выключенном автообновлении карты истекают через 30 дней и удаляются |
| BR-011 | Автообновление по умолчанию использует только Wi-Fi для экономии мобильного трафика |
| BR-012 | Частота автообновления — примерно каждые 2 недели |
| BR-013 | Автообновление не начинается при низком заряде батареи (в зависимости от настроек ОС) |

### FR-OFF-004: Навигация в офлайн-режиме
**Приоритет**: P0

> Как пользователь, я хочу получать пошаговую навигацию без интернета, чтобы добраться до места назначения при отсутствии связи.

**Предусловия**:
- Область маршрута полностью покрыта скачанной офлайн-картой
- GPS устройства активен
- Интернет-соединение отсутствует или нестабильно

**Основной поток**:
1. Пользователь вводит адрес назначения или выбирает точку на карте
2. Система строит маршрут на основе скачанных данных
3. Навигация предоставляет:
   - Пошаговые инструкции (turn-by-turn)
   - Голосовые подсказки
   - Визуальный маршрут на карте
   - Расчётное время прибытия (ETA)
   - Оставшееся расстояние
4. При отклонении от маршрута — автоматический пересчёт на основе офлайн-данных
5. Навигация продолжается до прибытия к точке назначения

**Альтернативный поток — Маршрут частично за пределами скачанной области**:
1. Если точка назначения или часть маршрута находится за пределами скачанной области
2. Система информирует пользователя, что навигация может быть неполной
3. Если доступно хотя бы частичное покрытие — система строит маршрут в пределах скачанных данных

**Критерии приёмки**:
- [ ] AC-001: Пошаговая навигация работает без интернета
- [ ] AC-002: Голосовые подсказки воспроизводятся
- [ ] AC-003: ETA рассчитывается (без учёта трафика)
- [ ] AC-004: Автоматический пересчёт при отклонении от маршрута
- [ ] AC-005: Предупреждение при выходе за пределы скачанной области

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-014 | В офлайн-режиме доступна ТОЛЬКО автомобильная навигация (driving directions) |
| BR-015 | Пешеходная, велосипедная и навигация общественным транспортом НЕ доступны офлайн |
| BR-016 | Данные о трафике в реальном времени НЕ доступны офлайн — ETA рассчитывается без учёта пробок |
| BR-017 | Альтернативные маршруты НЕ предлагаются в офлайн-режиме |
| BR-018 | Весь маршрут от начала до конца должен находиться в пределах скачанной области для полноценной навигации |
| BR-019 | GPS-навигация использует встроенный GPS-приёмник устройства и не требует интернета для определения положения |

### FR-OFF-005: Поиск в офлайн-режиме
**Приоритет**: P1

- Область покрыта скачанной офлайн-картой
- Интернет-соединение отсутствует

**Основной поток**:
1. Пользователь вводит запрос в строку поиска
2. Система выполняет поиск по скачанным данным
3. Результаты включают:
   - Адреса в скачанной области

5. Система отображает точку на карте и предлагает построить маршрут

**Критерии приёмки**:
- [ ] AC-001: Поиск по адресам работает офлайн
- [ ] AC-002: Базовые POI доступны для поиска
- [ ] AC-003: Результаты ограничены скачанной областью
- [ ] AC-004: Построение маршрута к найденной точке

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-020 | Офлайн-поиск ограничен данными, скачанными вместе с картой |
| BR-021 | Детальная информация о бизнесах (отзывы, рейтинги, часы работы, фотографии) НЕ доступна офлайн |
| BR-022 | Street View НЕ доступен офлайн |
| BR-023 | Информация о загруженности мест (Busy Areas / Popular Times) НЕ доступна офлайн |

### FR-OFF-009: Управление скачанными картами — удаление
**Приоритет**: P1

> Как пользователь, я хочу удалить ненужные скачанные карты, чтобы освободить место на устройстве.

**Предусловия**:
- Карта скачана и доступна в списке

1. Пользователь выбирает карту из списка скачанных
2. Нажимает «Удалить» (Delete)
3. Система запрашивает подтверждение удаления
4. Пользователь подтверждает

   - Система автоматически переключается на офлайн-данные
   - Функционал сокращается до офлайн-возможностей
   - Пользователь уведомляется о переходе в офлайн-режим
3. При восстановлении интернета:
   - Система автоматически возвращается к онлайн-данным
   - Полный функционал восстанавливается

- [ ] AC-001: Бесшовное переключение между режимами
- [ ] AC-002: Навигация не прерывается при потере/восстановлении связи
- [ ] AC-003: Пользователь информирован о текущем режиме

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-049 | Переключение между онлайн и офлайн режимами происходит автоматически и прозрачно для пользователя |
| BR-050 | Если активная навигация прерывается потерей связи — система продолжает навигацию по офлайн-данным без остановки |

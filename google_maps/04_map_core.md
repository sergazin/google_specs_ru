# Карта (ядро) — Google Maps

> **Module ID**: GMAPS-004
> **Version**: 1.0.0
> **Last Updated**: 2026-03-19
> **Dependencies**: Search, Places, Navigation, User Profile

## Executive Summary

Модуль «Карта (ядро)» является центральным элементом Google Maps и управляет визуализацией географических данных, интерактивным взаимодействием пользователя с картой, отображением слоёв информации и точек интереса. Включает отображение карты в нескольких режимах (стандартная, спутник, рельеф, 3D, Immersive View), систему информационных слоёв (трафик, велодорожки, общественный транспорт, качество воздуха, пожары), масштабирование и навигацию по карте, точки интереса (POI), Indoor Maps для зданий, геолокацию пользователя (My Location / Blue Dot), Timeline (историю перемещений), измерение расстояний, офлайн-карты и Street View. Модуль обрабатывает миллиарды запросов в день и обеспечивает базовый визуальный интерфейс для всех остальных функций приложения.

## Функциональные требования

### FR-MAP-001: Отображение стандартной карты (Default Map)
**Приоритет**: P0

> Как пользователь, я хочу видеть карту местности с дорогами, зданиями и названиями, чтобы ориентироваться в пространстве.

**Предусловия**:
- Приложение запущено или открыта веб-версия
- Доступно интернет-соединение (или загружена офлайн-карта)

**Основной поток**:
1. При открытии приложения система отображает карту в стандартном режиме (Default/Normal)
2. Карта центрируется на:
   - Последнем известном местоположении пользователя (если геолокация включена)
   - Последней просмотренной области (если геолокация отключена)
   - Центре страны пользователя (при первом запуске без геолокации)
3. Стандартная карта отображает:
   - Дорожную сеть (автомагистрали, главные дороги, второстепенные, пешеходные)
   - Названия улиц и дорог
   - Номера домов (при достаточном масштабе)
   - Контуры зданий (при масштабе ~17+)
   - 3D-экструзию зданий (при масштабе ~17+ в поддерживаемых городах)
   - Водоёмы (реки, озёра, моря) — синим цветом
   - Парки и зелёные зоны — зелёным цветом
   - Административные границы (страны, регионы, города)
   - Названия населённых пунктов
   - POI (точки интереса) — иконки и названия
4. Цветовая кодировка дорог:
   - Оранжевый/жёлтый — автомагистрали
   - Белый — главные дороги
   - Серый — второстепенные дороги
   - Пунктир — пешеходные дорожки и тропы
5. Уровень детализации автоматически подстраивается под масштаб:
   - Глобальный вид — только страны, крупные водоёмы
   - Региональный — города, основные дороги, водоёмы
   - Городской — все дороги, парки, здания, POI
   - Детальный — номера домов, входы в здания, пешеходные переходы

**Критерии приёмки**:
- [ ] AC-001: Карта загружается и отображается в течение 3 секунд
- [ ] AC-002: Все типы дорог отрисованы с правильной цветовой кодировкой
- [ ] AC-003: Названия отображаются на языке устройства пользователя с возможностью локальных названий
- [ ] AC-004: Уровень детализации автоматически меняется при масштабировании
- [ ] AC-005: Контуры зданий появляются при масштабе ~17+

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-001 | Стандартная карта — режим по умолчанию для всех новых пользователей |
| BR-002 | Язык подписей карты определяется по настройкам устройства, но локальные названия могут отображаться параллельно |
| BR-003 | POI бизнесов отображаются на стандартной карте только в режиме Normal |
| BR-004 | Уровень детализации карты зависит от масштаба и не может быть переопределён пользователем вручную |

### FR-MAP-002: Спутниковый режим (Satellite View)
**Приоритет**: P0

> Как пользователь, я хочу видеть реальные спутниковые/аэрофотоснимки местности, чтобы получить визуальное представление о территории.

**Предусловия**:
- Карта отображена в любом режиме
- Доступно интернет-соединение

**Основной поток**:
1. Пользователь переключает режим карты на «Спутник» через меню слоёв
2. Система заменяет стандартную карту на спутниковые/аэрофотоснимки
3. Спутниковый режим отображает:
   - Реальные фотоснимки местности сверху
   - Названия улиц и дорог (наложенные поверх снимков)
   - Границы и подписи (опционально, можно скрыть)
   - POI (наложенные поверх снимков)
4. Пользователь может включить/отключить подписи (Labels) поверх спутникового снимка
5. При достаточном масштабе видны:
   - Отдельные здания и сооружения
   - Автомобили на парковках
   - Деревья, ландшафт
   - Тени зданий (индикатор высоты)
6. Свежесть снимков варьируется:
   - Крупные города — обновление каждые несколько месяцев
   - Пригороды — раз в 1-2 года
   - Сельская местность — раз в 2-5 лет

**Критерии приёмки**:
- [ ] AC-001: Переключение на спутниковый режим происходит за 2-5 секунд
- [ ] AC-002: Снимки отображаются без видимых швов между тайлами
- [ ] AC-003: Подписи улиц читаемы поверх снимков
- [ ] AC-004: Включение/отключение Labels работает без перезагрузки карты

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-005 | Спутниковые снимки загружаются с серверов Google и не кэшируются для офлайн-режима (кроме скачанных областей) |
| BR-006 | В отдельных регионах спутниковые снимки могут быть размыты по требованию местных законов или из соображений безопасности |
| BR-007 | Дата снимка не отображается пользователю по умолчанию, но доступна в Google Earth |
| BR-008 | Спутниковый режим потребляет значительно больше трафика, чем стандартная карта |

### FR-MAP-003: Режим рельефа (Terrain View)
**Приоритет**: P1

> Как пользователь, я хочу видеть рельеф местности с высотами и ландшафтом, чтобы оценить топографию территории.

**Предусловия**:
- Карта отображена в любом режиме
- Доступно интернет-соединение

**Основной поток**:
1. Пользователь переключает режим карты на «Рельеф» через меню слоёв
2. Система отображает топографическую карту с:
   - Цветовой кодировкой высот (зелёный — низины, коричневый — горы, белый — снежные вершины)
   - Изолиниями высот (контурные линии)
   - Отметками высот в ключевых точках
   - Затенением рельефа (hillshading) для 3D-эффекта
3. Дорожная сеть и названия накладываются поверх рельефа
4. Водоёмы отображаются стандартно (синим)
5. Режим полезен для:
   - Планирования пеших маршрутов
   - Оценки перепадов высот
   - Понимания географии местности

**Критерии приёмки**:
- [ ] AC-001: Изолинии высот отображаются при масштабе ~12+
- [ ] AC-002: Цветовая кодировка высот корректно отражает реальный рельеф
- [ ] AC-003: Hillshading создаёт визуально понятное 3D-ощущение

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-009 | Режим рельефа недоступен для водных территорий (океанское дно не отображается) |
| BR-010 | Изолинии высот отображаются с шагом, автоматически подобранным под масштаб |
| BR-011 | Данные о высотах получены из спутниковой радарной съёмки (SRTM) и аэросъёмки |

### FR-MAP-004: 3D-режим и Globe View
**Приоритет**: P1

> Как пользователь, я хочу видеть карту в трёхмерном виде с объёмными зданиями и ландшафтом, чтобы получить реалистичное представление о местности.

**Предусловия**:
- Устройство поддерживает 3D-рендеринг (WebGL/OpenGL)
- Достаточно производительности устройства

**Основной поток**:
1. Пользователь активирует 3D-режим:
   - На десктопе: нажатие кнопки «3D» или Ctrl+перетаскивание мышью
   - На мобильном: жест двумя пальцами вверх (tilt)
2. Карта наклоняется и отображает:
   - Объёмные здания с текстурами (в поддерживаемых городах)
   - Рельеф местности с реальными перепадами высот
   - Деревья и растительность (в ключевых зонах)
   - Тени от зданий в зависимости от времени суток
3. Globe View (вид глобуса):
   - При максимальном отдалении карта отображается как 3D-глобус
   - Вращение глобуса жестами или мышью
   - Плавный переход от глобуса к плоской карте при приближении
   - Реалистичное отображение кривизны Земли
4. Пользователь может:
   - Вращать камеру вокруг объектов
   - Изменять угол наклона (от 0 до ~80 градусов)
   - Масштабировать с сохранением 3D-перспективы

**Критерии приёмки**:
- [ ] AC-001: 3D-здания отображаются при масштабе ~15+ в поддерживаемых городах
- [ ] AC-002: Globe View активируется при максимальном отдалении
- [ ] AC-003: Переход между 2D и 3D плавный, без рывков
- [ ] AC-004: Угол наклона регулируется жестами

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-012 | 3D-здания с фотореалистичными текстурами доступны только в крупных городах |
| BR-013 | В городах без фотореалистичных 3D-моделей здания отображаются как серые экструзии по контуру |
| BR-014 | Globe View отображает Землю как сферу (заменив проекцию Меркатора на глобальном уровне) |
| BR-015 | 3D-режим потребляет больше ресурсов устройства и может быть автоматически отключён на слабых устройствах |

### FR-MAP-005: Immersive View
**Приоритет**: P1

> Как пользователь, я хочу увидеть фотореалистичную 3D-модель города с погодой, трафиком и временем суток, чтобы спланировать визит к определённому месту.

**Предусловия**:
- Функция доступна для данного города/места
- Доступно интернет-соединение
- Устройство поддерживает рендеринг

**Основной поток**:
1. Пользователь открывает карточку места (ресторан, достопримечательность, парк и т.д.)
2. Если доступен Immersive View, отображается превью
3. При активации Immersive View:
   - Место отображается в фотореалистичном 3D с высоты птичьего полёта
   - AI-модель создаёт 3D-сцену на основе Street View и аэрофотоснимков
   - Отображается текущая или прогнозируемая погода (солнце, дождь, снег, облачность)
   - Трафик показывается в реальном времени
   - Можно переключать время суток (утро, день, вечер, ночь)
4. Immersive View for Routes (для маршрутов):
   - Пользователь выбирает маршрут
   - Система показывает «пролёт» по маршруту в фотореалистичном 3D
   - Отображаются здания, мосты, эстакады по пути
   - Показываются сложные участки (развязки, съезды)
5. Пользователь может вращать камеру и масштабировать

**Критерии приёмки**:
- [ ] AC-001: Фотореалистичная 3D-модель загружается в течение 5 секунд
- [ ] AC-002: Переключение времени суток обновляет освещение и тени
- [ ] AC-003: Трафик отображается в реальном времени поверх 3D-модели
- [ ] AC-004: Погода соответствует реальному прогнозу

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-016 | Immersive View доступен только для ограниченного числа крупных городов (расширяется поэтапно) |
| BR-017 | 3D-модели создаются с помощью AI (Gemini) на основе Street View и аэрофотоснимков |
| BR-018 | Прогноз погоды в Immersive View использует данные от метеосервисов-партнёров |
| BR-019 | Данные трафика обновляются в реальном времени из тех же источников, что и обычный слой трафика |

### FR-MAP-006: Immersive Navigation (3D-навигация)
**Приоритет**: P1

> Как водитель, я хочу видеть маршрут навигации в фотореалистичном 3D, чтобы лучше понимать сложные участки дороги.

**Предусловия**:
- Навигация активна
- Функция доступна в текущем регионе
- Устройство поддерживает рендеринг

**Основной поток**:
1. При включении навигации система предлагает Immersive Navigation (если доступна)
2. Плоская карта навигации заменяется фотореалистичным 3D-видом:
   - Здания, эстакады и рельеф отображаются в 3D
   - Маршрут выделяется на дороге
   - Ориентиры (landmarks) помечаются для голосовых подсказок
3. Система подсвечивает критические элементы дороги:
   - Полосы движения и рекомендуемую полосу
   - Пешеходные переходы
   - Светофоры и знаки «СТОП»
   - Дорожные знаки
4. Перед сложными манёврами:
   - Камера «приближает» участок для лучшего обзора
   - Здания становятся полупрозрачными для видимости за углом
   - Стрелки показывают рекомендуемую траекторию
5. Голосовые подсказки привязаны к визуальным ориентирам: «Поверните направо после красного здания»

**Критерии приёмки**:
- [ ] AC-001: 3D-вид обновляется в реальном времени с движением автомобиля
- [ ] AC-002: Полосы движения подсвечиваются перед манёврами
- [ ] AC-003: Здания становятся полупрозрачными перед сложными поворотами
- [ ] AC-004: Ориентиры используются в голосовых подсказках

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-020 | Immersive Navigation доступна первоначально в США, расширяется поэтапно |
| BR-021 | 3D-модели для навигации генерируются AI (Gemini) на основе свежих изображений Street View и аэрофотоснимков |
| BR-022 | При недостаточной производительности устройства система автоматически переключается на стандартную 2D-навигацию |
| BR-023 | Подсказки с ориентирами (landmark-based guidance) генерируются AI и могут использовать цвет, форму, вывески зданий |

### FR-MAP-007: Слой трафика (Traffic Layer)
**Приоритет**: P0

> Как пользователь, я хочу видеть загруженность дорог в реальном времени, чтобы планировать маршрут и время выезда.

**Предусловия**:
- Карта отображена
- Доступно интернет-соединение

**Основной поток**:
1. Пользователь включает слой «Трафик» через меню слоёв
2. Система накладывает на дороги цветовую индикацию:
   - Зелёный — свободное движение, без задержек
   - Оранжевый — средняя загруженность, умеренные задержки
   - Красный — высокая загруженность, значительные задержки
   - Тёмно-красный — пробка, движение почти стоит
3. Цветовая индикация обновляется в реальном времени
4. Дополнительно отображаются:
   - Иконки ДТП и аварий
   - Иконки дорожных работ
   - Иконки перекрытий дорог
   - Иконки камер контроля скорости (в поддерживаемых регионах)
5. Пользователь может нажать на иконку инцидента для подробной информации:
   - Тип инцидента
   - Ожидаемая задержка
   - Альтернативные маршруты
6. Типичный трафик (Typical Traffic):
   - Пользователь может посмотреть типичную загруженность дорог для конкретного дня и времени
   - Полезно для планирования регулярных поездок

**Критерии приёмки**:
- [ ] AC-001: Цветовая кодировка отображается на всех видимых дорогах с доступными данными
- [ ] AC-002: Обновление данных трафика происходит непрерывно
- [ ] AC-003: Инциденты отображаются с иконками и описанием

### FR-MAP-016: Геолокация пользователя (My Location / Blue Dot)

> Как пользователь, я хочу видеть своё текущее местоположение на карте, чтобы ориентироваться и планировать перемещения.

- Пользователь предоставил разрешение на доступ к геолокации
- Геолокация включена на устройстве

**Основной поток**:
1. Пользователь нажимает кнопку «My Location» (иконка компаса/прицела)
2. Система определяет местоположение пользователя по доступным источникам:
   - GPS (точность ~5-20 м на открытом воздухе)
   - Wi-Fi (точность ~15-40 м)
   - Сотовые вышки (точность ~300 м — несколько км)
   - Bluetooth (для Indoor-позиционирования)
3. На карте отображается Blue Dot (синяя точка):
   - Синяя точка — текущее положение пользователя

7. Если геолокация недоступна:
   - Blue Dot отображается серым цветом
   - Показывается последнее известное местоположение
   - Система предлагает включить геолокацию

**Калибровка компаса**:
1. Если луч Blue Dot широкий или указывает неправильное направление
2. Система предлагает калибровку: движение устройства в виде «восьмёрки»
3. После калибровки луч становится узким и точным

**Критерии приёмки**:
- [ ] AC-001: Blue Dot отображается в течение 3 секунд после нажатия «My Location»
- [ ] AC-002: Зона неопределённости отражает реальную точность определения
- [ ] AC-003: Луч направления соответствует ориентации устройства
- [ ] AC-004: Режим «следовать за мной» отслеживает перемещения в реальном времени
- [ ] AC-005: Серый Blue Dot при недоступной геолокации

   - «Измерить расстояние»

### FR-MAP-023: Поделиться местоположением / точкой на карте (Share Location)
**Приоритет**: P1

> Как пользователь, я хочу поделиться точкой на карте или своим реальным местоположением с другими людьми.

**Предусловия**:
- Карта отображена или место выбрано

**Основной поток — Поделиться точкой на карте**:
1. Пользователь выбирает место или ставит маркер
2. Нажимает «Поделиться»
3. Система генерирует короткую ссылку (maps.google.com/...)
4. Пользователь отправляет ссылку через мессенджер, SMS, email или соцсети
5. Получатель открывает ссылку и видит карту с отмеченной точкой

**Основной поток — Поделиться реальным местоположением (Real-Time Location Sharing)**:
1. Авторизованный пользователь открывает «Поделиться геопозицией»
2. Выбирает контакты из:
   - Google-контактов
   - Любого контакта (через ссылку)
3. Устанавливает длительность:
   - 1 час
   - До выключения
   - Пользовательский период
4. Выбранные контакты видят Blue Dot пользователя в реальном времени на своей карте
5. Пользователь может:
   - Остановить шаринг в любой момент
   - Видеть, кто отслеживает его местоположение
   - Запросить местоположение другого пользователя в ответ

**Критерии приёмки**:
- [ ] AC-001: Короткая ссылка генерируется и открывается корректно
- [ ] AC-002: Реальное местоположение обновляется в реальном времени у получателя
- [ ] AC-003: Длительность шаринга соблюдается
- [ ] AC-004: Шаринг можно остановить мгновенно

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-097 | Шаринг реального местоположения требует авторизации в Google-аккаунте |
| BR-098 | Пользователь всегда видит, с кем он делится местоположением |

### FR-MAP-024: Сохранённые места и списки (Saved Places)
**Приоритет**: P1

> Как авторизованный пользователь, я хочу сохранять места и организовывать их в списки, чтобы быстро находить их позже.

**Предусловия**:
- Пользователь авторизован в Google-аккаунте

**Основной поток**:
1. Пользователь нажимает «Сохранить» на карточке места
2. Выбирает список для сохранения:
   - **Избранное** (Favorites) — помечается звездой на карте
   - **Хочу посетить** (Want to go) — помечается флагом на карте
   - **Помеченные места** (Starred places)
   - Пользовательские списки (произвольное название)
3. Место добавляется в выбранный список
4. Иконка сохранения на карте соответствует типу списка
5. Управление списками:
   - Создание нового списка с названием и описанием
   - Удаление мест из списка
   - Удаление списка целиком
   - Шаринг списка (публичный, по ссылке, приватный)
   - Совместное редактирование списка (collaborative list)
6. Сохранённые метки:
   - **Дом** — быстрый маршрут одним нажатием
   - **Работа** — быстрый маршрут одним нажатием
   - Пользовательские метки (Gym, School и т.д.)

**Критерии приёмки**:
- [ ] AC-001: Место сохраняется в выбранный список
- [ ] AC-002: Иконка на карте соответствует типу списка
- [ ] AC-003: Списки можно создавать, редактировать, удалять
- [ ] AC-004: Шаринг списка работает через ссылку
- [ ] AC-005: Метки «Дом» и «Работа» позволяют навигацию одним нажатием

**Бизнес-правила**:

| ID правила | Правило |
|------------|---------|
| BR-101 | Сохранённые места синхронизируются между устройствами через Google-аккаунт |
| BR-102 | Списки «Избранное», «Хочу посетить», «Помеченные» создаются по умолчанию и не могут быть удалены |
| BR-103 | Количество пользовательских списков и мест в них не ограничено |

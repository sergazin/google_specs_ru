# Модуль "Мобильное приложение и резервное копирование" в Google Drive

## Описание

Модуль мобильного приложения и резервного копирования обеспечивает доступ к Google Drive через мобильные устройства (Android и iOS) и автоматическое резервное копирование медиа-контента. Система предоставляет полный набор функций для работы с файлами на мобильных устройствах, включая просмотр, редактирование, создание документов, сканирование через камеру, офлайн-доступ, автоматическое резервное копирование фото и видео, push-уведомления о важных событиях и интеграцию с другими приложениями. Модуль синхронизирует все изменения в реальном времени между мобильным приложением и облачным хранилищем.

## Роли пользователей

- **Обычный пользователь (Free)** - 15 ГБ бесплатного хранилища, доступ ко всем базовым функциям мобильного приложения
- **Google One подписчик (Basic 100 ГБ)** - расширенное хранилище, приоритет синхронизации
- **Google One подписчик (Standard 200 ГБ)** - дополнительные функции резервного копирования
- **Google One подписчик (Premium 2 ТБ+)** - максимальное хранилище, приоритетная поддержка
- **Семейная группа** - совместное использование хранилища между членами семьи
- **Google Workspace пользователь** - корпоративные функции, неограниченное хранилище (Business Plus)

## Функциональные требования

### FR-MOBILE-001: Установка и первоначальная настройка мобильного приложения

**Описание:** Пользователь устанавливает мобильное приложение Google Drive и проходит первоначальную настройку.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь имеет устройство на Android 8.0+ или iOS 14.0+
- Пользователь имеет Google аккаунт
- Устройство подключено к интернету
- На устройстве достаточно свободного места (минимум 200 МБ)

**Основной сценарий:**
1. Пользователь открывает Google Play Store (Android) или App Store (iOS)
2. Пользователь ищет "Google Drive"
3. Система показывает приложение Google Drive от Google LLC
4. Пользователь нажимает "Установить" или "Загрузить"
5. Система запрашивает разрешения:
   - Доступ к хранилищу устройства
   - Доступ к камере (для сканирования)
   - Доступ к фотографиям и медиа
   - Уведомления
6. Пользователь предоставляет необходимые разрешения
7. Приложение устанавливается на устройство
8. Пользователь открывает приложение
9. Система показывает экран приветствия с основными функциями
10. Система предлагает выбрать Google аккаунт для входа
11. Пользователь выбирает существующий аккаунт или добавляет новый
12. Система показывает экран настройки резервного копирования:
    - "Резервное копирование и синхронизация"
    - "Выбор папок для резервного копирования"
    - "Использовать только Wi-Fi"
13. Пользователь настраивает параметры резервного копирования
14. Система начинает синхронизацию с облачным хранилищем
15. Главный экран приложения загружает список файлов

**Альтернативные сценарии:**
- Сценарий А (Отказ в разрешениях): Пользователь может отказать в разрешениях, некоторые функции будут недоступны
- Сценарий Б (Несколько аккаунтов): Пользователь может добавить несколько Google аккаунтов
- Сценарий В (Пропуск резервного копирования): Пользователь может пропустить настройку резервного копирования
- Сценарий Г (Недостаточно места): Система предупреждает о недостатке места на устройстве
- Сценарий Д (Офлайн установка): Если нет интернета, приложение может быть установлено, но не настроено

**Бизнес-правила:**
- BR-001: Минимальная версия Android 8.0, минимальная версия iOS 14.0
- BR-002: Приложение занимает около 150-200 МБ после установки
- BR-003: Требуется активный Google аккаунт для использования
- BR-004: Разрешения можно изменить в настройках устройства позже
- BR-005: Приложение может работать с несколькими аккаунтами одновременно
- BR-006: Первая синхронизация может занять от нескольких минут до нескольких часов

**Результат:** Приложение установлено и настроено, пользователь имеет доступ к своим файлам

### FR-MOBILE-002: Просмотр списка файлов и папок

**Описание:** Пользователь просматривает список своих файлов и папок в мобильном приложении с возможностью сортировки и фильтрации.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- Приложение синхронизировано с облачным хранилищем
- Устройство подключено к интернету (для онлайн-режима)

**Основной сценарий:**
1. Пользователь открывает мобильное приложение Google Drive
2. Система показывает главный экран с вкладками:
   - "Главная" (Home) - рекомендуемые и недавние файлы
   - "Мои файлы" (My Drive) - структура папок пользователя
   - "Общие файлы" (Shared with me) - файлы, которыми поделились
   - "Помеченные" (Starred) - избранные файлы
   - "Недавние" (Recent) - последние открытые файлы
   - "Офлайн" (Offline) - файлы доступные без интернета
3. Пользователь выбирает вкладку "Мои файлы"
4. Система отображает список файлов и папок:
   - Иконка типа файла
   - Название файла/папки
   - Дата изменения
   - Размер файла
   - Индикатор офлайн-доступности (значок булавки)
   - Индикатор общего доступа
5. Для каждого элемента доступно меню (три точки):
   - Открыть
   - Сделать доступным офлайн
   - Добавить в помеченные
   - Переименовать
   - Переместить
   - Скачать
   - Удалить
   - Детали
6. Пользователь может прокручивать список
7. Система подгружает файлы постранично (по 50 элементов)
8. Пользователь может нажать на файл для просмотра
9. Пользователь может нажать на папку для открытия

**Альтернативные сценарии:**
- Сценарий А (Пустая папка): Если папка пустая, показывается сообщение "Здесь пока нет файлов"
- Сценарий Б (Сортировка): Пользователь может сортировать по имени, дате изменения, размеру, типу
- Сценарий В (Вид списка/сетки): Пользователь может переключаться между списком и сеткой
- Сценарий Г (Поиск): Пользователь может использовать поиск для нахождения файлов
- Сценарий Д (Офлайн-режим): В офлайне показываются только кешированные файлы
- Сценарий Е (Обновление): Пользователь может потянуть вниз для обновления списка

**Бизнес-правила:**
- BR-007: Файлы отображаются в порядке последнего изменения по умолчанию
- BR-008: Список подгружается постранично (по 50 элементов за раз)
- BR-009: Миниатюры изображений кешируются локально
- BR-010: Файлы с офлайн-доступом помечаются значком булавки
- BR-011: Общие файлы имеют индикатор общего доступа
- BR-012: Синхронизация происходит автоматически при изменениях
- BR-013: В офлайн-режиме недоступны файлы без офлайн-доступа

**Результат:** Пользователь видит список своих файлов и папок с возможностью навигации

### FR-MOBILE-003: Предварительный просмотр файлов

**Описание:** Пользователь может открыть файл для предварительного просмотра без необходимости скачивания на устройство.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- Файл существует в хранилище
- Устройство подключено к интернету (для не-офлайн файлов)

**Основной сценарий:**
1. Пользователь находит нужный файл в списке
2. Пользователь нажимает на файл
3. Система определяет тип файла
4. Система открывает соответствующий просмотрщик:

   **Для документов (Google Docs, Sheets, Slides):**
   - Открывается в режиме чтения с возможностью редактирования
   - Показываются комментарии и предложения
   - Доступна навигация по документу

   **Для изображений (JPG, PNG, GIF, WEBP):**
   - Полноэкранный просмотр изображения
   - Возможность приближения (pinch to zoom)
   - Свайп для перехода к следующему/предыдущему изображению
   - Кнопка "Редактировать" для базового редактирования

   **Для видео (MP4, MOV, AVI):**
   - Встроенный видеоплеер с элементами управления
   - Перемотка, пауза, громкость
   - Полноэкранный режим
   - Показывается длительность и прогресс

   **Для PDF файлов:**
   - Постраничный просмотр с навигацией
   - Приближение и прокрутка
   - Поиск по тексту
   - Оглавление (если доступно)

   **Для других форматов:**
   - Показывается иконка файла и детальная информация
   - Предлагается скачать или открыть в другом приложении

5. Пользователь может взаимодействовать с файлом
6. В верхнем меню доступны действия:
   - Поделиться
   - Добавить в помеченные
   - Скачать
   - Открыть в другом приложении
   - Детали файла

**Альтернативные сценарии:**
- Сценарий А (Большой файл): Показывается индикатор загрузки перед просмотром
- Сценарий Б (Неподдерживаемый формат): Предлагается скачать или открыть в другом приложении
- Сценарий В (Офлайн-файл): Открывается мгновенно из локального кеша
- Сценарий Г (Ошибка загрузки): Показывается сообщение об ошибке с кнопкой "Повторить"
- Сценарий Д (Низкая скорость интернета): Показывается предупреждение и предложение скачать

**Бизнес-правила:**
- BR-014: Поддерживаемые форматы: Google Docs/Sheets/Slides, PDF, изображения, видео, аудио, текстовые файлы
- BR-015: Видео стримятся без полной загрузки на устройство
- BR-016: Изображения кешируются для быстрого повторного просмотра
- BR-017: PDF файлы до 100 МБ открываются в приложении
- BR-018: Файлы с офлайн-доступом открываются мгновенно
- BR-019: Неподдерживаемые форматы требуют внешнего приложения
- BR-020: Максимальный размер файла для просмотра в приложении - 500 МБ

**Результат:** Пользователь просматривает содержимое файла в мобильном приложении

### FR-MOBILE-004: Создание и редактирование документов

**Описание:** Пользователь может создавать новые документы, таблицы, презентации и редактировать существующие прямо в мобильном приложении.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- Устройство подключено к интернету (для синхронизации)

**Основной сценарий:**
1. Пользователь нажимает кнопку "+" (Добавить) в правом нижнем углу
2. Система показывает меню создания:
   - "Папка" - создать новую папку
   - "Загрузить" - загрузить файлы с устройства
   - "Сканировать" - сканировать документ через камеру
   - "Google Документы" - создать текстовый документ
   - "Google Таблицы" - создать таблицу
   - "Google Презентации" - создать презентацию
   - "Google Формы" - создать форму
3. Пользователь выбирает "Google Документы"
4. Система открывает приложение Google Docs (если установлено) или встроенный редактор
5. Пользователь видит пустой документ с курсором
6. Пользователь начинает печатать текст
7. Система автоматически сохраняет изменения каждые несколько секунд
8. Пользователь может форматировать текст:
   - Жирный, курсив, подчеркивание
   - Размер и тип шрифта
   - Цвет текста
   - Выравнивание
   - Списки (маркированные, нумерованные)
   - Вставка изображений
   - Вставка таблиц
   - Вставка ссылок
9. Пользователь может нажать "Поделиться" для совместной работы
10. Пользователь нажимает "Назад" или "Готово"
11. Документ автоматически сохраняется в Google Drive
12. Пользователь возвращается к списку файлов

**Альтернативные сценарии:**
- Сценарий А (Редактирование существующего): Пользователь открывает существующий документ и редактирует
- Сценарий Б (Офлайн-режим): В офлайне изменения сохраняются локально и синхронизируются при подключении
- Сценарий В (Совместное редактирование): Несколько пользователей редактируют документ одновременно
- Сценарий Г (Комментирование): Пользователь может оставлять комментарии к тексту
- Сценарий Д (История версий): Пользователь может просмотреть предыдущие версии документа
- Сценарий Е (Голосовой ввод): Пользователь может диктовать текст голосом

**Бизнес-правила:**
- BR-021: Автосохранение происходит каждые 3-5 секунд
- BR-022: История версий сохраняется автоматически
- BR-023: В офлайн-режиме доступны базовые функции редактирования
- BR-024: Совместное редактирование поддерживает до 100 одновременных пользователей
- BR-025: Комментарии синхронизируются в реальном времени
- BR-026: Голосовой ввод требует подключения к интернету
- BR-027: Форматирование синхронизируется между устройствами

**Результат:** Пользователь создал или отредактировал документ, изменения синхронизированы с облаком

### FR-MOBILE-005: Сканирование документов через камеру

**Описание:** Пользователь может сканировать физические документы с помощью камеры устройства и сохранять их как PDF в Google Drive.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- Предоставлен доступ к камере
- Устройство имеет камеру
- Достаточное освещение для сканирования

**Основной сценарий:**
1. Пользователь нажимает кнопку "+" (Добавить)
2. Пользователь выбирает "Сканировать"
3. Система открывает интерфейс камеры со специальным режимом сканирования
4. Система показывает рамку для выравнивания документа
5. Пользователь наводит камеру на документ
6. Система автоматически определяет границы документа
7. Система показывает подсветку краев документа
8. Когда документ правильно выровнен, система показывает индикатор готовности
9. Пользователь может:
   - Нажать кнопку захвата вручную
   - Дождаться автоматического захвата (если включено)
10. Система делает снимок документа
11. Система обрабатывает изображение:
    - Обрезка по границам
    - Коррекция перспективы
    - Улучшение контрастности
    - Удаление теней
    - Повышение четкости текста
12. Система показывает превью отсканированной страницы
13. Пользователь может:
    - Принять скан
    - Пересканировать
    - Повернуть изображение
    - Обрезать границы вручную
    - Применить фильтры (черно-белый, цветной, оттенки серого)
14. Пользователь нажимает "Добавить страницу" для сканирования следующей
15. Пользователь повторяет процесс для всех страниц
16. Пользователь нажимает "Сохранить"
17. Система показывает диалог сохранения:
    - Поле имени файла (автоматически генерируется с датой/временем)
    - Выбор папки для сохранения
    - Выбор формата (PDF по умолчанию, или отдельные изображения JPG)
18. Пользователь вводит имя файла
19. Пользователь выбирает папку назначения
20. Пользователь нажимает "Сохранить"
21. Система создает PDF файл из всех отсканированных страниц
22. Система загружает файл в Google Drive
23. Система показывает уведомление "Документ сохранен"

**Альтернативные сценарии:**
- Сценарий А (Автоматический захват): Система автоматически делает снимок при обнаружении документа
- Сценарий Б (Многостраничный документ): Пользователь сканирует несколько страниц в один PDF
- Сценарий В (Распознавание текста OCR): Система распознает текст в документе (доступно после сохранения)
- Сценарий Г (Плохое освещение): Система предлагает включить вспышку или улучшить освещение
- Сценарий Д (Кривой документ): Система корректирует перспективу автоматически
- Сценарий Е (Цветная/ЧБ конвертация): Пользователь может выбрать режим сканирования
- Сценарий Ж (Низкое качество): Система предупреждает о низком качестве и предлагает пересканировать

**Бизнес-правила:**
- BR-028: Автоматическое определение границ документа с точностью >90%
- BR-029: Поддержка многостраничных документов (до 100 страниц в одном PDF)
- BR-030: Автоматическая коррекция перспективы и обрезка
- BR-031: Доступны фильтры: оригинал, черно-белый, цветной улучшенный, оттенки серого
- BR-032: Максимальное разрешение сканирования - 3000x4000 пикселей
- BR-033: OCR распознавание текста происходит после загрузки в Drive
- BR-034: Отсканированные документы сохраняются как PDF по умолчанию
- BR-035: Размер одного отсканированного файла не должен превышать 100 МБ
- BR-036: Автоматическое имя файла: "Скан_ДД.ММ.ГГГГ_ЧЧ.ММ"

**Результат:** Физический документ отсканирован и сохранен как PDF в Google Drive

### FR-MOBILE-006: Автоматическое резервное копирование фото и видео

**Описание:** Пользователь может настроить автоматическое резервное копирование фотографий и видео с устройства в Google Drive.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- Предоставлен доступ к фотографиям и медиа
- На устройстве есть фотографии или видео
- Достаточно места в Google Drive

**Основной сценарий:**

- BR-048: Максимальный размер офлайн-хранилища ограничен свободным местом устройства

- BR-055: Папки с офлайн-доступом автоматически включают новые файлы

- Пользователь авторизован в приложении
- Предоставлено разрешение на уведомления
- Приложение установлено на устройстве
- Устройство подключено к интернету

- "@Вы упомянуты в комментарии к 'Презентация.pptx'"
- "Пользователь назначил вам задачу в 'Проект.docx'"

**2. Уведомления о доступе:**
- "Пользователь запрашивает доступ к 'Отчет.pdf'"

- "Резервное копирование завершено (127 элементов)"

- "Файл 'Документ.docx' успешно загружен"
- "Синхронизация завершена"

**4. Уведомления о безопасности:**
- "Обнаружена подозрительная активность в вашем аккаунте"
- "Новое устройство получило доступ к вашему Drive"

**Альтернативные сценарии:**

- Сценарий Б (Группировка): Несколько уведомлений от одного файла группируются в одно
- Сценарий В (Тихие уведомления): Некоторые уведомления не воспроизводят звук
- Сценарий Г (Приоритетные уведомления): Упоминания и запросы доступа имеют высокий приоритет
- Сценарий Д (Настройка частоты): Пользователь может настроить частоту уведомлений
- Сценарий Е (Не беспокоить): Уважение режима "Не беспокоить" устройства

**Бизнес-правила:**
- BR-056: Уведомления отправляются в реальном времени (задержка <5 секунд)
- BR-057: Пользователь может отключить любой тип уведомлений в настройках
- BR-058: Группировка похожих уведомлений (максимум 5 в группе)
- BR-059: Уведомления сохраняются в истории на устройстве 30 дней
- BR-060: Критические уведомления (безопасность) нельзя отключить
- BR-061: Звук и вибрация настраиваются отдельно для каждого типа
- BR-062: Уведомления синхронизируются между устройствами (прочитанные на одном не показываются на другом)
- BR-063: Максимум 50 уведомлений в день (защита от спама)

### FR-MOBILE-010: Отправка файлов в другие приложения

**Описание:** Пользователь может отправить файл из Google Drive в другие приложения на устройстве для дальнейшей работы.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- Файл существует в Google Drive
- На устройстве установлены приложения для работы с файлами

**Основной сценарий:**
1. Пользователь находит нужный файл в списке
2. Пользователь нажимает на меню файла (три точки)
3. Пользователь выбирает "Открыть в..."
4. Система показывает список приложений, которые могут открыть этот тип файла:
   - Для изображений: Instagram, WhatsApp, Фоторедакторы, Email
   - Для документов: Microsoft Word, PDF Reader, Email
   - Для видео: YouTube, VLC, Video Editor
   - Для аудио: Spotify, Music Player
5. Пользователь выбирает приложение (например, WhatsApp)
6. Система скачивает файл во временное хранилище (если не кеширован)
7. Система открывает выбранное приложение
8. Файл передается в приложение через системный механизм "Share" (Android) или "Share Sheet" (iOS)
9. Пользователь может продолжить работу с файлом в выбранном приложении

**Альтернативный сценарий - Поделиться:**
1. Пользователь нажимает на меню файла
2. Пользователь выбирает "Поделиться"
3. Система показывает системное меню "Поделиться" с опциями:
   - Отправить через WhatsApp, Telegram, Email
   - Скопировать ссылку
   - Поделиться в Google Drive (управление доступом)
   - Отправить файл напрямую (скачать и отправить)
   - AirDrop (iOS)
   - Nearby Share (Android)
4. Пользователь выбирает способ отправки
5. Для "Отправить файл напрямую":
   - Система скачивает файл во временное хранилище
   - Открывается выбранное приложение
   - Файл прикрепляется к сообщению/публикации
6. Для "Скопировать ссылку":
   - Система генерирует ссылку на файл
   - Ссылка копируется в буфер обмена
   - Показывается уведомление "Ссылка скопирована"
7. Для "Поделиться в Google Drive":
   - Открывается интерфейс управления доступом
   - Пользователь добавляет людей и права

**Альтернативные сценарии:**
- Сценарий А (Большой файл): Система предлагает отправить ссылку вместо файла
- Сценарий Б (Конвертация формата): Некоторые приложения требуют конвертации формата (например, HEIC в JPG)

### FR-MOBILE-017: Просмотр и управление корзиной

**Описание:** Пользователь может просматривать удаленные файлы в корзине и восстанавливать или окончательно удалять их.

**Роли:** Обычный пользователь, Google One подписчик

**Предусловия:**
- Пользователь авторизован в приложении
- В корзине есть удаленные файлы

**Основной сценарий:**
1. Пользователь открывает меню приложения (☰)
2. Пользователь выбирает "Корзина" (Trash)
3. Система показывает список удаленных файлов:
   - Иконка типа файла
   - Название файла
   - Дата удаления
   - Срок до автоматического удаления ("Удалится через 15 дней")
   - Кто удалил (если файл общий)
4. Пользователь видит информацию вверху: "Файлы в корзине удаляются через 30 дней"
5. Для каждого файла доступно меню (три точки):
   - Восстановить
   - Удалить навсегда
   - Детали
6. Пользователь может выбрать несколько файлов (длинное нажатие)
7. В верхней панели появляются действия:
   - Восстановить выбранное
   - Удалить навсегда
   - Выбрать все

**Восстановление файла:**
1. Пользователь нажимает меню файла
2. Пользователь выбирает "Восстановить"
3. Система восстанавливает файл в исходное местоположение
4. Показывается уведомление "Файл восстановлен"
5. Файл удаляется из корзины и появляется в исходной папке

**Окончательное удаление:**
1. Пользователь нажимает "Удалить навсегда"
2. Система показывает предупреждение: "Файл будет удален навсегда. Это действие нельзя отменить"
3. Пользователь подтверждает
4. Система безвозвратно удаляет файл
5. Освобождается место в квоте
6. Показывается уведомление "Файл удален навсегда"

**Очистка корзины:**
1. Пользователь нажимает "Очистить корзину" в меню
2. Система показывает предупреждение: "Удалить все файлы из корзины? Освободится XX ГБ"
3. Пользователь подтверждает
4. Система удаляет все файлы из корзины
5. Освобождается место в квоте
6. Показывается уведомление "Корзина очищена"

**Альтернативные сценарии:**
- Сценарий А (Восстановление в другое место): Можно восстановить файл в другую папку
- Сценарий Б (Исходная папка удалена): При восстановлении создается новая папка или файл перемещается в корень
- Сценарий В (Файлы владельца): Если владелец общего файла удалил его, другие пользователи теряют доступ
- Сценарий Г (Автоматическое удаление): Система автоматически удаляет файлы старше 30 дней
- Сценарий Д (Сортировка): Можно сортировать по дате удаления, имени, размеру
- Сценарий Е (Поиск в корзине): Можно искать файлы в корзине

**Бизнес-правила:**
- BR-129: Файлы в корзине хранятся 30 дней
- BR-130: После 30 дней файлы удаляются автоматически и безвозвратно
- BR-131: Файлы в корзине учитываются в квоте хранилища
- BR-132: При восстановлении файл возвращается в исходную папку
- BR-133: Если исходная папка удалена, файл восстанавливается в корень "Мой диск"
- BR-134: Окончательное удаление нельзя отменить
- BR-135: При очистке корзины освобождается место в квоте
- BR-136: Общие файлы можно удалить только владельцу (другие могут только удалить из своего Drive)
- BR-137: Счетчик дней до удаления обновляется ежедневно

**Результат:** Пользователь управляет удаленными файлами в корзине

- **Максимум аккаунтов в приложении**: 5 аккаунтов

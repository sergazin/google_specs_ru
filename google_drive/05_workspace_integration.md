# Интеграция с Google Workspace

## Описание

Модуль "Интеграция с Google Workspace" обеспечивает полную интеграцию Google Drive с инструментами Google Workspace (Docs, Sheets, Slides, Forms, Sites, Keep) и другими сервисами Google (Gmail, Calendar, Meet). Модуль позволяет создавать документы прямо в Drive, редактировать их в реальном времени с поддержкой до 100 одновременных редакторов, совместно работать с командой, управлять комментариями и предложениями, интегрировать файлы с электронной почтой, календарем и видеозвонками, а также импортировать и экспортировать файлы из форматов Microsoft Office без необходимости конвертации.

Система использует технологию операционной трансформации (operational transformation) для обработки сетевого взаимодействия, хранения, отслеживания присутствия пользователей и автоматического разрешения конфликтов при одновременном редактировании.

Цель модуля - создать единую экосистему для работы с документами, где все инструменты бесшовно интегрированы друг с другом, обеспечивая максимальную продуктивность и возможности совместной работы. В 2025 году интеграция дополнена возможностями AI через Gemini Deep Research, который может анализировать содержимое файлов Drive, Docs, Sheets и Slides для создания персонализированных отчетов.

## Роли пользователей

### Роли в контексте интеграции с Workspace:

1. **Владелец документа (Owner)** - пользователь, создавший документ
   - Может редактировать, удалять, переименовывать документ
   - Может управлять доступом к документу
   - Может передавать права владения другим пользователям
   - Может принимать/отклонять предложения редактирования
   - Может удалять комментарии других пользователей
   - Может настраивать права комментирования и предложений
   - Может настраивать интеграцию с Gmail, Calendar, Meet

2. **Редактор (Editor)** - пользователь с правами редактирования
   - Может редактировать содержимое документа
   - Может добавлять комментарии и предложения
   - Может видеть изменения других редакторов в реальном времени
   - Видит цветные курсоры других редакторов
   - Может принимать/отклонять предложения (если дано право)
   - Может экспортировать документ в другие форматы
   - Может инициировать Google Meet звонки из документа

3. **Комментатор (Commenter)** - пользователь с правами комментирования
   - Может просматривать документ
   - Может добавлять комментарии с упоминаниями (@mention)
   - Не может редактировать содержимое напрямую
   - Может делать предложения (Suggesting mode)
   - Может экспортировать документ
   - Может отвечать на комментарии других пользователей

4. **Читатель (Viewer)** - пользователь с правами просмотра
   - Может только просматривать документ
   - Может экспортировать документ в доступные форматы
   - Не может редактировать, комментировать или предлагать изменения
   - Может видеть присутствие других пользователей в документе

5. **Пользователь Google Workspace** - пользователь с аккаунтом Google
   - Может создавать новые документы Workspace
   - Может открывать и редактировать файлы Office без конвертации
   - Может использовать AI-функции Gemini (при наличии подписки)
   - Может интегрировать документы с Gmail, Calendar, Meet
   - Может работать с Shared Drives для командных файлов
   - Может использовать Smart Canvas для встраивания элементов

6. **Администратор Google Workspace** - корпоративный администратор
   - Управляет миграцией файлов из OneDrive в Google Drive
   - Настраивает политики доступа к инструментам Workspace
   - Может переносить до 100 пользователей одновременно
   - Настраивает права на использование Gemini AI

7. **Внешний пользователь (без аккаунта Google)** - пользователь без Google аккаунта
   - Может просматривать документы по ссылке (если разрешено)
   - Не может редактировать или комментировать
   - Может загружать документы в форматах Office

### FR-WS-001: Создание нового документа Google Docs из Drive

**Описание:** Позволяет пользователю создать новый документ Google Docs непосредственно из интерфейса Google Drive без необходимости конвертации или использования дополнительных инструментов.

**Роли:** Владелец документа, Пользователь Google Workspace

**Предусловия:**
- Пользователь аутентифицирован в Google Drive
- Пользователь имеет активный Google аккаунт
- У пользователя есть доступ к Google Docs (не заблокирован администратором)

**Основной сценарий:**
1. Пользователь открывает Google Drive через веб-интерфейс или мобильное приложение
2. Нажимает кнопку "+ Создать" (New) в левом верхнем углу
3. В выпадающем меню выбирает "Google Документы" (Google Docs)
4. Система создает новый пустой документ с названием "Документ без названия"
5. Документ автоматически открывается в новой вкладке браузера
6. Документ сохраняется в текущей папке или в корне "Мой диск" (My Drive)
7. Курсор устанавливается в первую строку для начала ввода

**Альтернативные сценарии:**
- Сценарий A (Создание из шаблона): Пользователь выбирает "+ Создать" -> "Google Документы" -> "Из шаблона", система открывает галерею шаблонов (Резюме, Письмо, Отчет, Брошюра), пользователь выбирает шаблон и получает предзаполненный документ
- Сценарий B (Создание в конкретной папке): Пользователь открывает нужную папку в Drive, нажимает правую кнопку мыши в пустом месте, выбирает "Создать" -> "Google Документы", документ создается непосредственно в этой папке
- Сценарий C (Создание с помощью Gemini AI): Пользователь создает новый документ, нажимает "Help me write", вводит запрос (например, "Напиши приглашение на встречу команды"), Gemini генерирует текст на основе запроса
- Сценарий D (Создание из Gmail): Пользователь открывает боковую панель Drive в Gmail, нажимает "Создать новый документ", документ создается и может быть сразу прикреплен к письму

**Бизнес-правила:**
- BR-WS-001: Документы Google Docs не занимают место в хранилище пользователя
- BR-WS-002: Максимальный размер одного документа: 1.02 миллиона символов
- BR-WS-003: Максимум 100 пользователей могут одновременно редактировать один документ
- BR-WS-004: Автосохранение происходит каждые несколько секунд без участия пользователя
- BR-WS-005: Каждый документ получает уникальный URL в формате: https://docs.google.com/document/d/{document_id}/edit
- BR-WS-006: История версий сохраняется автоматически (30 дней для бесплатных аккаунтов, неограниченно для Google Workspace)

**Результат:** Новый документ Google Docs создан, открыт для редактирования и сохранен в указанной папке Drive с активным автосохранением

### FR-WS-002: Создание Google Sheets (таблицы) из Drive

**Описание:** Позволяет пользователю создать новую таблицу Google Sheets из интерфейса Google Drive для работы с данными, формулами, графиками и совместного анализа информации.

**Роли:** Владелец документа, Пользователь Google Workspace

**Предусловия:**
- Пользователь аутентифицирован в Google Drive
- Пользователь имеет активный Google аккаунт
- Доступ к Google Sheets не ограничен администратором

**Основной сценарий:**
1. Пользователь открывает Google Drive
2. Нажимает кнопку "+ Создать" в левом верхнем углу
3. Выбирает опцию "Google Таблицы" (Google Sheets) из меню
4. Система создает новую пустую таблицу с названием "Таблица без названия"
5. Таблица открывается в новой вкладке браузера
6. Отображается первый лист (Sheet1) с сеткой 1000 строк × 26 столбцов (A-Z)
7. Курсор устанавливается в ячейку A1 для начала ввода данных

**Альтернативные сценарии:**
- Сценарий A (Создание из шаблона): Пользователь выбирает "Из шаблона", открывается галерея (Бюджет, График работы, Инвентарь, Трекер проектов), система создает таблицу с предзаполненными формулами и форматированием
- Сценарий B (Создание с Gemini AI): Пользователь создает таблицу, использует Gemini для генерации формул ("Создай формулу для расчета среднего значения"), AI предлагает готовую формулу с объяснением
- Сценарий C (Импорт данных из Excel): Пользователь перетаскивает файл .xlsx в Drive, система предлагает открыть в Google Sheets, данные импортируются с сохранением форматирования и формул
- Сценарий D (Интеграция с Forms): Пользователь создает Google Form, в настройках выбирает "Ответы" -> "Создать таблицу", система автоматически создает связанную таблицу для сбора ответов

**Бизнес-правила:**
- BR-WS-007: Таблицы Google Sheets не занимают место в хранилище
- BR-WS-008: Максимум 10 миллионов ячеек в одной таблице
- BR-WS-009: Максимум 100 одновременных редакторов в одной таблице
- BR-WS-010: Поддержка 400+ встроенных функций для работы с данными
- BR-WS-011: Автоматическая конвертация файлов Excel при импорте (опционально)
- BR-WS-012: Поддержка макросов и Apps Script для автоматизации

**Результат:** Новая таблица Google Sheets создана, открыта для работы и сохранена в Drive с возможностью совместного редактирования и интеграции с другими инструментами Workspace

### FR-WS-003: Создание Google Slides (презентации) из Drive

**Описание:** Позволяет пользователю создать новую презентацию Google Slides для создания профессиональных слайд-шоу с поддержкой совместного редактирования.

**Роли:** Владелец документа, Пользователь Google Workspace

**Предусловия:**
- Пользователь аутентифицирован в Google Drive
- Пользователь имеет активный Google аккаунт
- Доступ к Google Slides разрешен

**Основной сценарий:**
1. Пользователь открывает Google Drive
2. Нажимает "+ Создать" в левом верхнем углу
3. Выбирает "Google Презентации" (Google Slides) из выпадающего меню
4. Система создает новую пустую презентацию с названием "Презентация без названия"
5. Презентация открывается в новой вкладке с первым пустым слайдом
6. Отображается тема по умолчанию (Simple Light)
7. Пользователь может начать добавлять заголовок и содержимое

**Альтернативные сценарии:**
- Сценарий A (Создание из шаблона): Пользователь выбирает "Из шаблона", просматривает галерею (Питч, Портфолио, Обучение, Отчет), выбирает шаблон и получает презентацию с готовым дизайном
- Сценарий B (Импорт PowerPoint): Пользователь загружает файл .pptx в Drive, открывает его в Google Slides, система конвертирует презентацию с сохранением анимаций и переходов
- Сценарий C (Использование Gemini): Пользователь создает презентацию, использует Gemini для генерации слайдов ("Создай презентацию о проекте с 5 слайдами"), AI генерирует структуру и контент
- Sценарий D (Встраивание в Sites): Пользователь создает презентацию, открывает Google Sites, встраивает презентацию на страницу через блок "Встроить Drive файл"

**Бизнес-правила:**
- BR-WS-013: Презентации Google Slides не занимают место в хранилище
- BR-WS-014: Максимум 100 одновременных редакторов в одной презентации
- BR-WS-015: Поддержка до 200 слайдов в одной презентации (рекомендуется)
- BR-WS-016: Автоматическое сохранение каждого изменения
- BR-WS-017: Возможность представления презентации в Google Meet с совместным просмотром
- BR-WS-018: Поддержка импорта/экспорта PowerPoint форматов без потери качества

**Результат:** Новая презентация Google Slides создана, открыта для редактирования и может быть интегрирована с Meet для совместных презентаций в режиме реального времени

### FR-WS-004: Создание Google Forms из Drive

**Описание:** Позволяет пользователю создать новую форму Google Forms для сбора данных, опросов, тестирования с автоматической интеграцией результатов в Google Sheets.

**Роли:** Владелец документа, Пользователь Google Workspace

**Предусловия:**
- Пользователь аутентифицирован в Google Drive
- Пользователь имеет активный Google аккаунт
- Доступ к Google Forms разрешен

**Основной сценарий:**
1. Пользователь открывает Google Drive
2. Нажимает "+ Создать" в левом верхнем углу
3. Выбирает "Google Формы" (Google Forms) из меню
4. Система создает новую пустую форму с названием "Форма без названия"
5. Форма открывается в редакторе с одним вопросом по умолчанию
6. Пользователь может добавлять различные типы вопросов (текст, множественный выбор, шкала, дата)
7. Автоматически создается связь с Google Sheets для сбора ответов

**Альтернативные сценарии:**
- Сценарий A (Создание теста): Пользователь переключает режим на "Тест" в настройках, добавляет правильные ответы и баллы, система автоматически проверяет ответы и выставляет оценки
- Сценарий B (Использование шаблона): Пользователь выбирает шаблон (Опрос удовлетворенности, Регистрация на событие, Заказ), форма создается с предзаполненными вопросами
- Sценарий C (Интеграция с Calendar): Пользователь добавляет вопрос типа "Дата/время", включает опцию "Добавить в Calendar", ответы автоматически создают события в календаре
- Сценарий D (Просмотр результатов в Sheets): Пользователь открывает форму, переходит на вкладку "Ответы", нажимает иконку Sheets, система создает или открывает связанную таблицу с автообновлением

**Бизнес-правила:**
- BR-WS-019: Формы Google Forms не занимают место в хранилище
- BR-WS-020: Неограниченное количество ответов на одну форму
- BR-WS-021: Автоматическая синхронизация ответов с Google Sheets в реальном времени
- BR-WS-022: Поддержка 11 типов вопросов (текст, параграф, выбор, флажки, раскрывающийся список, шкала, сетка, дата, время, загрузка файла)
- BR-WS-023: Загруженные через форму файлы сохраняются в отдельную папку Drive владельца формы
- BR-WS-024: Возможность ограничения на один ответ на аккаунт Google

**Результат:** Новая форма Google Forms создана, настроена для сбора данных и автоматически интегрирована с Google Sheets для анализа ответов

### FR-WS-005: Редактирование в реальном времени (Real-time Collaboration)

**Описание:** Обеспечивает возможность одновременного редактирования документов, таблиц и презентаций несколькими пользователями с мгновенным отображением изменений, цветными курсорами и автоматическим разрешением конфликтов.

**Роли:** Владелец документа, Редактор

**Предусловия:**
- Документ открыт в Google Docs, Sheets или Slides
- Документ предоставлен в общий доступ минимум двум пользователям с правами редактирования
- Пользователи имеют активное интернет-соединение
- Включена опция "Show live edits" (по умолчанию активна)

**Основной сценарий:**
1. Первый пользователь открывает документ в режиме редактирования
2. Второй пользователь открывает тот же документ по ссылке или из своего Drive
3. Система отображает аватар второго пользователя в правом верхнем углу
4. При вводе текста вторым пользователем первый видит цветной курсор в месте редактирования
5. Изменения появляются в режиме реального времени (задержка < 1 секунды)
6. Система автоматически синхронизирует все изменения через операционную трансформацию
7. Конфликты редактирования разрешаются автоматически без потери данных

**Альтернативные сценарии:**
- Сценарий A (Множественное редактирование): До 100 пользователей одновременно редактируют документ, каждый видит цветные курсоры всех остальных, система масштабирует синхронизацию без потери производительности
- Сценарий B (Встроенный чат): Пользователи нажимают иконку комментариев, открывают боковую панель, обсуждают изменения в реальном времени не покидая документ
- Сценарий C (Запуск Meet из документа): Пользователь нажимает иконку видеокамеры в правом верхнем углу, система создает Google Meet звонок, все редакторы получают уведомление и могут присоединиться одним кликом
- Сценарий D (Отслеживание присутствия): Пользователь видит индикатор "Активен" рядом с аватаром другого редактора, при неактивности 5 минут статус меняется на "Неактивен"

**Бизнес-правила:**
- BR-WS-025: Максимум 100 одновременных редакторов для Docs и Slides, 100 для Sheets
- BR-WS-026: Каждому редактору присваивается уникальный цвет курсора автоматически
- BR-WS-027: Изменения синхронизируются через технологию операционной трансформации (Operational Transformation)
- BR-WS-028: Автоматическое сохранение происходит каждые 2-3 секунды
- BR-WS-029: История изменений фиксирует каждое изменение с указанием автора и времени
- BR-WS-030: При потере соединения изменения сохраняются локально и синхронизируются при восстановлении связи

**Результат:** Множественные пользователи могут одновременно редактировать документ, видеть изменения друг друга в реальном времени, общаться через встроенные инструменты без конфликтов и потери данных

### FR-WS-006: Комментарии в документах

**Описание:** Позволяет пользователям добавлять комментарии к любой части документа, упоминать коллег через @mention, обсуждать изменения и отмечать комментарии как решенные.

**Роли:** Владелец документа, Редактор, Комментатор

**Предусловия:**
- Документ открыт в Google Docs, Sheets или Slides
- Пользователь имеет права минимум Комментатора
- Документ находится в онлайн-режиме

**Основной сценарий:**
1. Пользователь выделяет фрагмент текста, ячейку или элемент слайда
2. Нажимает кнопку "Добавить комментарий" (иконка "+") или использует Ctrl+Alt+M
3. Открывается поле ввода комментария справа от выделенного фрагмента
4. Пользователь вводит текст комментария
5. Опционально добавляет упоминание коллеги через "@" + имя
6. Нажимает кнопку "Комментировать" (Comment)

- Sценарий C (Просмотр изменений конкретного пользователя): Пользователь в панели истории фильтрует изменения по имени редактора, видит только версии, созданные выбранным пользователем
- Сценарий D (Копирование версии): Вместо восстановления пользователь нажимает "Дополнительно" -> "Создать копию", система создает новый документ с содержимым выбранной версии, оригинал остается без изменений

**Бизнес-правила:**
- BR-WS-109: История версий сохраняется автоматически для всех документов Workspace
- BR-WS-110: Бесплатные аккаунты: история за последние 30 дней, Google Workspace: неограниченная история
- BR-WS-111: Система создает новую версию при изменении и неактивности > 30 минут
- BR-WS-112: Восстановление версии не удаляет последующие версии (они остаются в истории)
- BR-WS-113: Именованные версии никогда не удаляются автоматически
- BR-WS-114: Права на восстановление версий имеют только редакторы и владельцы

**Результат:** Пользователь просмотрел историю версий документа, проанализировал изменения, восстановил предыдущую версию или создал именованную версию для важного этапа работы

### FR-WS-020: Офлайн-режим для Google Workspace

**Описание:** Позволяет пользователям работать с документами Google Docs, Sheets и Slides без интернет-соединения с автоматической синхронизацией изменений при восстановлении связи.

**Роли:** Пользователь Google Workspace

**Предусловия:**
- Пользователь использует браузер Google Chrome
- Установлено расширение "Google Docs Offline" (устанавливается автоматически)
- Офлайн-режим включен в настройках Drive
- Документы предварительно открывались при наличии интернета

**Основной сценарий:**
1. Пользователь при наличии интернета открывает Google Drive
2. Нажимает на шестеренку настроек в правом верхнем углу
3. Выбирает "Settings" -> "Offline"
4. Включает переключатель "Create, open and edit your recent Google Docs, Sheets and Slides files on this device while offline"
5. Система начинает синхронизацию последних документов для офлайн-доступа
6. При потере интернета пользователь может продолжить работу с синхронизированными документами
7. После восстановления связи все изменения автоматически синхронизируются с облаком

**Альтернативные сценарии:**
- Сценарий A (Редактирование офлайн): Пользователь теряет интернет, открывает документ Docs, редактирует текст, видит индикатор "Offline" вместо "Saved to Drive", при восстановлении связи документ автоматически синхронизируется
- Сценарий B (Конфликт изменений): Два пользователя редактируют документ офлайн одновременно, при подключении система создает копию с конфликтом "Copy of [Document] (Conflicted copy)", пользователи вручную объединяют изменения
- Sценарий C (Мобильный офлайн-режим): Пользователь на телефоне включает офлайн-доступ в приложении Google Drive, выбирает документы для загрузки, работает без интернета, изменения синхронизируются при подключении к Wi-Fi
- Сценарий D (Автоматическая подготовка к офлайн-работе): Пользователь включает настройку "Make recent files available offline automatically", система автоматически синхронизирует все файлы, открытые за последние 30 дней

**Бизнес-правила:**
- BR-WS-115: Офлайн-режим доступен только в браузере Google Chrome и мобильных приложениях
- BR-WS-116: Автоматически синхронизируются файлы, открытые в последние 30 дней
- BR-WS-117: Максимальный размер офлайн-хранилища зависит от доступного места на устройстве
- BR-WS-118: Офлайн-файлы хранятся в зашифрованном виде на локальном устройстве
- BR-WS-119: При конфликтах создается копия с пометкой "Conflicted copy" для ручного объединения
- BR-WS-120: Синхронизация происходит автоматически в течение нескольких секунд после восстановления интернета

**Результат:** Пользователь может работать с документами Google Workspace без интернет-соединения, все изменения сохраняются локально и автоматически синхронизируются с облаком при восстановлении связи

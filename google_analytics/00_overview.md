# Google Analytics (GA4) — Обзор

## Общее описание

Google Analytics 4 (GA4) — платформа веб- и мобильной аналитики от Google, основанная на событийной модели данных. GA4 заменила Universal Analytics (UA) в июле 2023 года и является единственной поддерживаемой версией Google Analytics.

GA4 отслеживает взаимодействия пользователей с веб-сайтами и мобильными приложениями через единую событийную модель, объединяя данные из разных платформ в одном ресурсе (property). Платформа предоставляет стандартные и кастомные отчёты, инструменты исследования данных (Explorations), предиктивные метрики на основе машинного обучения и интеграции с экосистемой Google (Google Ads, BigQuery, Looker Studio и др.).

## Целевая аудитория

| Роль | Описание |
|------|----------|
| **Маркетолог** | Анализ эффективности кампаний, создание аудиторий, настройка конверсий |
| **Аналитик данных** | Глубокие исследования, воронки, когорты, экспорт в BigQuery |
| **Продакт-менеджер** | Отслеживание пользовательского поведения, A/B тесты, метрики продукта |
| **Веб-разработчик** | Установка тегов, настройка сбора данных, отладка (DebugView) |
| **Владелец бизнеса** | Обзорные дашборды, KPI, ROI рекламных кампаний |
| **Администратор** | Управление доступом, настройки ресурса, интеграции |

## Ключевые метрики платформы

- **Активные пользователи** — основная метрика пользователей (заменяет сессии из UA)
- **События** — базовая единица данных (page_view, scroll, click, purchase и др.)
- **Ключевые события (Key Events)** — события, отмеченные как конверсии
- **Вовлечённые сессии** — сессии длительностью >10 сек., с конверсией или 2+ просмотрами страниц
- **Engagement Rate** — доля вовлечённых сессий
- **Retention** — возврат пользователей по когортам
- **Предиктивные метрики** — Purchase Probability, Churn Probability, Predicted Revenue

## Тарифные планы

| | GA4 Standard (бесплатно) | GA4 360 (от $50K/год) |
|---|---|---|
| **Лимит событий** | 10M событий/отчёт | 1B событий/отчёт (unsampled) |
| **Хранение данных** | 2 или 14 месяцев | До 50 месяцев |
| **Свежесть данных** | 24-48 часов | <1 часа |
| **BigQuery Export** | 1M событий/день | 20B событий/день + streaming |
| **Custom Dimensions** | 50 event-scoped, 25 user-scoped | 125 event-scoped, 100 user-scoped |
| **Аудитории** | 100 | 400 |
| **Конверсии** | 30 | 50 |
| **Subproperties** | Нет | До 400 |
| **Roll-up Properties** | Нет | До 200 источников |
| **SLA** | Нет | 99%+ uptime |
| **Поддержка** | Сообщество | Приоритетная, P0 ответ 1ч |

## Иерархия сущностей

```
Google Marketing Platform Organization (опционально)
└── Account (до 100 на пользователя)
    └── Property (до 2000 на аккаунт)
        ├── Data Stream: Web (Measurement ID: G-XXXXXXX)
        ├── Data Stream: iOS (Firebase App ID)
        ├── Data Stream: Android (Firebase App ID)
        ├── Subproperty (только 360, до 400)
        └── Roll-up Property (только 360, до 200 источников)
```

## Глоссарий

| Термин | Описание |
|--------|----------|
| **GA4** | Google Analytics 4 — текущая версия Google Analytics на событийной модели |
| **Property** | Ресурс — основной контейнер для данных (один сайт/приложение) |
| **Data Stream** | Поток данных — источник данных (Web, iOS, Android) |
| **Measurement ID** | Идентификатор для Web-потока (формат G-XXXXXXX) |
| **Event** | Событие — базовая единица данных в GA4 |
| **Key Event** | Ключевое событие — событие, отмеченное как значимое для бизнеса (бывш. конверсия) |
| **Enhanced Measurement** | Расширенные измерения — автоматический сбор событий (прокрутка, клики и т.д.) |
| **Exploration** | Исследование — инструмент углублённого анализа данных |
| **Audience** | Аудитория — группа пользователей по заданным условиям |
| **Segment** | Сегмент — временная группировка пользователей в Explorations |
| **Custom Dimension** | Пользовательское измерение — дополнительный атрибут для анализа |
| **Custom Metric** | Пользовательская метрика — дополнительная числовая метрика |
| **BigQuery Export** | Экспорт сырых данных в Google BigQuery |
| **Consent Mode** | Режим согласия — управление сбором данных в зависимости от согласия пользователя |
| **Data-Driven Attribution (DDA)** | Атрибуция на основе ML, распределяющая ценность конверсии между точками касания |
| **Subproperty** | Подресурс (только 360) — фильтрованное подмножество данных ресурса |
| **Roll-up Property** | Сводный ресурс (только 360) — агрегация данных из нескольких ресурсов |
| **GA4 360** | Платная корпоративная версия Google Analytics |
| **GMP** | Google Marketing Platform — платформа для управления маркетинговыми продуктами Google |
| **gtag.js** | Библиотека JavaScript для отправки данных в GA4 |
| **GTM** | Google Tag Manager — система управления тегами |
| **DebugView** | Инструмент отладки событий в реальном времени |

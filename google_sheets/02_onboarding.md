# Google Sheets: Модуль "Онбординг и первый опыт"

## 1. Общее описание модуля

Модуль онбординга Google Sheets обеспечивает плавное знакомство новых пользователей с приложением для работы с электронными таблицами: от первого входа до уверенного использования всех базовых возможностей. Модуль включает автоматическую инициализацию при входе через Google-аккаунт, галерею шаблонов для быстрого старта, интерактивные подсказки и контекстную справку, AI-функцию Explore для анализа данных, а также доступ к обучающим материалам Google Workspace Learning Center.

### 1.1 Ключевые бизнес-цели модуля

- Минимизация времени от входа до создания первой таблицы
- Обеспечение быстрого старта через готовые шаблоны
- Снижение барьера входа для пользователей других табличных редакторов (Excel)
- Обучение ключевым функциям через контекстные подсказки и справку
- Интеграция с экосистемой Google Workspace для корпоративных пользователей
- Демонстрация уникальных возможностей Google Sheets (коллаборация, AI Explore)

## 2. Роли и права доступа

### 2.1 Уровни доступа к таблице

| Роль | Описание | Права |
|------|----------|-------|
| **Владелец (Owner)** | Создатель таблицы | Полный контроль: редактирование, удаление, управление доступом, передача владения |
| **Редактор (Editor)** | Может редактировать | Создание, редактирование, удаление данных, форматирование, добавление комментариев |
| **Комментатор (Commenter)** | Может комментировать | Просмотр всех данных, добавление комментариев, но без редактирования |
| **Читатель (Viewer)** | Только просмотр | Просмотр данных без возможности изменения или комментирования |

### 2.2 Уровни доступа в Google Workspace

| Роль | Описание | Права |
|------|----------|-------|
| **Администратор организации** | Управление Workspace | Настройка политик доступа и шаринга для организации |
| **Пользователь организации** | Стандартный сотрудник | Доступ согласно корпоративным политикам |
| **Личный аккаунт Google** | Индивидуальный пользователь | Полный контроль над своими таблицами |

### 2.3 Бизнес-правила для ролей

- Владелец может передать право владения только одному пользователю
- Пользователь может предоставить доступ только того уровня, который имеет сам или ниже
- Администратор Workspace может ограничить внешний шаринг для всей организации
- Шаблоны организации доступны только пользователям домена

## 3. Первый запуск приложения

### 3.1 User Story: Первый вход в Google Sheets

```
КАК новый пользователь Google
Я ХОЧУ начать использовать Google Sheets
ЧТОБЫ создавать электронные таблицы и анализировать данные

Критерии приёмки:
- Могу войти с существующим Google-аккаунтом
- Вижу домашний экран с шаблонами и недавними файлами
- Могу создать пустую таблицу одним кликом
- Могу выбрать шаблон для быстрого старта
```

### 3.2 Функциональные требования первого запуска

**FR-ONB-001**: При первом входе система отображает домашний экран Google Sheets (sheets.google.com) с секцией "Start a new spreadsheet"

**FR-ONB-002**: Домашний экран содержит следующие элементы:
- Кнопка создания пустой таблицы (Blank)
- Галерея популярных шаблонов (3-5 штук на первой строке)
- Кнопка "Template gallery" для доступа к полному каталогу
- Секция "Recent" с последними открытыми документами
- Секция "Owned by me" с собственными документами

**FR-ONB-003**: Система предоставляет быстрый доступ к созданию таблицы через:
- Ввод sheets.new в адресной строке браузера
- Кнопка "+" в Google Drive
- Меню File > New > Spreadsheet внутри существующей таблицы

**FR-ONB-004**: При входе через Workspace-аккаунт применяются корпоративные политики организации

**FR-ONB-005**: Система автоматически определяет язык интерфейса на основе:
- Настроек Google-аккаунта
- Настроек браузера
- Геолокации пользователя

### 3.3 Процесс первого запуска

```
[Вход через Google Account]
        ↓
[Переход на sheets.google.com]
        ↓
[Отображение домашнего экрана]
        ↓
[Выбор: Blank / Template / Recent файл]
        ↓
[Открытие редактора таблицы]
        ↓
[Готовность к работе]
```

### 3.4 Состояния первого запуска

| Состояние | Описание | Переходы |
|-----------|----------|----------|
| **Аутентификация** | Вход в Google-аккаунт | → Домашний экран |
| **Домашний экран** | Выбор действия (создать/открыть) | → Редактор |
| **Редактор** | Работа с таблицей | → Работа с функциями |

## 4. Галерея шаблонов

### 4.1 User Story: Использование шаблонов

```
КАК пользователь Google Sheets
Я ХОЧУ использовать готовые шаблоны
ЧТОБЫ быстро создать нужную таблицу без настройки с нуля

Критерии приёмки:
- Могу просматривать шаблоны по категориям
- Могу создать копию шаблона одним кликом
- Шаблон содержит готовую структуру, форматирование и примеры
- Созданная копия полностью редактируема
```

### 4.2 Функциональные требования галереи шаблонов

**FR-ONB-006**: Доступ к галерее шаблонов осуществляется несколькими способами:
- Клик на "Template gallery" на домашнем экране
- Меню File > New > From template gallery внутри редактора
- Через Google Drive: New > Google Sheets > From a template

**FR-ONB-007**: Система предоставляет шаблоны в следующих категориях:
- **Personal** (Личное): To-do list, Annual budget, Monthly budget, Expense report
- **Work** (Работа): Project tracker, Invoice, Employee schedule, Timesheet, Team roster
- **Education** (Образование): Grade book, Class schedule, Attendance tracker
- **Project Management** (Управление проектами): Gantt chart, Project timeline

**FR-ONB-008**: Каждый шаблон в галерее отображает:
- Миниатюру предпросмотра
- Название шаблона
- Краткое описание назначения

**FR-ONB-009**: При выборе шаблона система автоматически:
- Создаёт копию шаблона в Google Drive пользователя
- Открывает копию в редакторе
- Присваивает имя на основе названия шаблона с датой

**FR-ONB-010**: Для организаций с Google Workspace доступны корпоративные шаблоны:
- Администратор может добавлять шаблоны организации через кнопку "Submit template"
- Шаблоны организации отображаются в отдельной вкладке галереи
- Доступны только пользователям домена организации

### 4.3 Категории и примеры шаблонов

| Категория | Примеры шаблонов | Назначение |
|-----------|------------------|------------|
| **Personal** | To-do list, Monthly budget, Annual budget | Личная организация и финансы |
| **Work** | Invoice, Employee schedule, Timesheet | Рабочие документы и учёт |
| **Project Management** | Gantt chart, Project tracker, Timeline | Управление проектами |
| **Education** | Grade book, Attendance tracker | Учебный процесс |
| **Finance** | Expense report, Budget tracker | Финансовый учёт |

### 4.4 Бизнес-правила галереи шаблонов

**FR-ONB-011**: Шаблоны бесплатны для всех пользователей Google Sheets

**FR-ONB-012**: При создании копии шаблона пользователь становится владельцем новой таблицы

**FR-ONB-013**: Исходный шаблон не изменяется при редактировании копии

**FR-ONB-014**: Шаблоны содержат примеры данных, которые пользователь может заменить своими

**FR-ONB-015**: Пользователи Google Workspace могут сохранять собственные таблицы как шаблоны организации

### 4.5 Дополнительные источники шаблонов

**FR-ONB-016**: Система поддерживает расширение галереи через Add-ons:
- Template Gallery Add-on от сторонних разработчиков
- Доступ через Extensions > Add-ons > Get add-ons > Google Workspace Marketplace
- Расширенные шаблоны: календари, финансовые калькуляторы, инвойсы

## 6. Интерактивные подсказки и контекстная справка

### 6.1 User Story: Получение помощи в контексте

```
КАК пользователь Google Sheets
Я ХОЧУ получать подсказки при работе с функциями
ЧТОБЫ правильно использовать возможности приложения

Критерии приёмки:
- Вижу подсказки при вводе формул
- Могу получить справку по функции без выхода из редактора
- Клавиатурные сочетания доступны через меню
- Есть поиск по меню и функциям
```

### 6.2 Функциональные требования подсказок при вводе формул

**FR-ONB-022**: При вводе знака "=" в ячейке система активирует режим формулы с:
- Автодополнением названий функций
- Подсказкой синтаксиса при выборе функции
- Подсветкой ссылок на ячейки разными цветами

**FR-ONB-023**: Система отображает Formula Helper (помощник формул) при вводе:
- Всплывающее окно под ячейкой с информацией о функции
- Описание функции и её параметров
- Примеры использования
- Ссылка на полную документацию

**FR-ONB-024**: Formula Helper включает:
- Название функции
- Синтаксис с обязательными и опциональными параметрами
- Описание каждого параметра
- Пример результата

**FR-ONB-025**: Включение/отключение Formula Help осуществляется через:
- Menu Help > Turn on formula help / Turn off formula help
- Настройка сохраняется в профиле пользователя

### 6.3 Функциональные требования Tool Finder

**FR-ONB-026**: Tool Finder (поиск по меню) доступен через:
- Клавиатурное сочетание Alt + / (Windows/Chrome OS) или Option + / (Mac)
- Меню Help > Search the menus

**FR-ONB-027**: Tool Finder позволяет:
- Искать любую команду меню по названию
- Находить настройки форматирования
- Применять действие напрямую из результатов поиска
- Просматривать недавние использованные команды

**FR-ONB-028**: Результаты Tool Finder отображают:
- Название команды
- Путь в меню (например, Format > Number > Currency)
- Клавиатурное сочетание (если есть)

### 6.4 Функциональные требования клавиатурных сочетаний

**FR-ONB-029**: Список клавиатурных сочетаний доступен через:
- Клавиатурное сочетание Ctrl + / (Windows/Chrome OS) или Cmd + / (Mac)
- Меню Help > Keyboard shortcuts

**FR-ONB-030**: Окно Keyboard Shortcuts отображает сочетания по категориям:
- Navigation (навигация)
- Format (форматирование)
- Edit (редактирование)
- Data (данные)
- Comments (комментарии)

**FR-ONB-031**: Система поддерживает включение совместимых сочетаний из Excel:
- Переключатель "Enable compatible spreadsheet shortcuts" в окне сочетаний
- При включении работают привычные сочетания из Excel

**FR-ONB-032**: Основные клавиатурные сочетания для навигации:
- Ctrl + Home - переход к началу таблицы
- Ctrl + End - переход к последней заполненной ячейке
- Ctrl + Shift + End - выделение до последней заполненной ячейки
- Ctrl + стрелка - переход к краю данных в направлении

### 6.5 Функциональные требования подсказок в ячейках

**FR-ONB-033**: Система поддерживает добавление Notes (заметок) к ячейкам:
- Правый клик > Insert note
- Заметка отображается при наведении на ячейку
- Визуальный индикатор (треугольник в углу ячейки)

**FR-ONB-034**: Система поддерживает добавление Comments (комментариев) к ячейкам:
- Правый клик > Insert comment или Ctrl + Alt + M
- Комментарий привязан к автору и времени
- Поддержка @mentions для уведомления пользователей
- Возможность разрешить (resolve) обсуждение

**FR-ONB-035**: Система поддерживает Data Validation Help Text:
- При создании правила валидации можно добавить подсказку
- Подсказка отображается при выборе ячейки
- Настройка через Data > Data validation > Show validation help text

## 7. Функция Explore (AI-анализ данных)

### 7.1 User Story: Автоматический анализ данных

```
КАК пользователь с данными в таблице
Я ХОЧУ получить автоматические insights
ЧТОБЫ быстро понять ключевые метрики без создания формул вручную

Критерии приёмки:
- Могу открыть панель Explore одним кликом
- Вижу автоматические подсчёты (сумма, среднее, количество)
- Получаю предложения по визуализации данных
- Могу задать вопрос на естественном языке
```

### 7.2 Функциональные требования Explore

**FR-ONB-036**: Доступ к функции Explore осуществляется через:
- Кнопка Explore в правом нижнем углу редактора
- Меню Tools > Explore
- Выделение данных и клик на Explore

**FR-ONB-037**: При открытии панель Explore автоматически анализирует данные и показывает:
- Секция "Answers" - ключевые статистические показатели
- Секция "Analysis" - предложенные диаграммы
- Секция "Formatting" - рекомендации по оформлению

**FR-ONB-038**: Секция Answers отображает:
- SUM - сумма числовых значений в выделенном диапазоне
- AVERAGE - среднее значение
- COUNT - количество записей
- MIN/MAX - минимальное и максимальное значения
- Быстрая вставка результата в таблицу одним кликом

**FR-ONB-039**: Секция Analysis предлагает:
- Автоматически подобранные типы диаграмм (bar, line, pie)
- Визуализации на основе структуры данных
- Предпросмотр диаграммы в панели
- Вставка диаграммы в таблицу кликом

**FR-ONB-040**: Функция Natural Language Questions позволяет:
- Ввод вопроса на естественном языке
- Пример: "What is the total sales by region?"
- Система генерирует ответ или формулу
- Результат можно вставить в таблицу

**FR-ONB-041**: Explore использует Machine Learning для:
- Определения типов данных (даты, числа, категории)
- Выбора подходящего типа визуализации
- Генерации релевантных insights
- Понимания естественного языка

### 7.3 Бизнес-правила Explore

**FR-ONB-042**: Функция Explore доступна бесплатно для всех пользователей Google Sheets

**FR-ONB-043**: Качество анализа зависит от структуры данных:
- Данные с заголовками анализируются точнее
- Чистые данные без пустых строк дают лучшие результаты
- Последовательная типизация данных в столбцах

**FR-ONB-044**: Предложенные диаграммы учитывают:
- Количество категорий (pie chart для 2-7 категорий)
- Временные ряды (line chart для дат)
- Сравнение категорий (bar chart)

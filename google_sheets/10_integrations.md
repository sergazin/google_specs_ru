# Интеграции

## Описание

Модуль "Интеграции" обеспечивает взаимодействие Google Sheets с продуктами экосистемы Google Workspace (Forms, Docs, Slides, Calendar, BigQuery, Looker Studio), внешними платформами автоматизации (Zapier, Make), а также предоставляет возможности для встраивания таблиц на веб-сайты и интеграции через REST API. Модуль реализует двустороннюю синхронизацию данных, автоматическое обновление связанных объектов, импорт финансовых данных в реальном времени через функцию GOOGLEFINANCE и расширение функциональности через экосистему дополнений (Add-ons) из Google Workspace Marketplace.

Ключевая особенность Google Sheets как центрального хаба данных — способность быть источником данных для аналитики в Looker Studio, хранилищем ответов Google Forms, источником диаграмм для Docs и Slides, а также доступным через API интерфейсом для внешних систем. Благодаря Connected Sheets пользователи могут работать с миллиардами строк данных BigQuery в привычном интерфейсе таблиц без знания SQL.

## Роли пользователей

| Роль | Описание | Права доступа к интеграциям |
|------|----------|----------------------------|
| Владелец таблицы (Owner) | Пользователь, создавший таблицу | Полный доступ ко всем интеграциям, публикация в веб, установка add-ons, подключение к BigQuery, настройка API |
| Редактор (Editor) | Пользователь с правами редактирования | Использование установленных add-ons, создание связанных диаграмм, работа с формулами интеграции |
| Комментатор (Commenter) | Пользователь с правами комментирования | Просмотр связанных данных, без возможности изменения интеграций |
| Читатель (Viewer) | Пользователь только для просмотра | Просмотр данных и встроенных диаграмм, без доступа к настройке интеграций |
| Администратор Google Workspace | Корпоративный администратор | Управление политиками интеграций, разрешениями API, доступом к add-ons для организации |
| Разработчик (Developer) | Технический пользователь | Работа с Google Sheets API, Apps Script, создание кастомных интеграций, webhook |

### FR-INT-001: Автоматический сбор ответов Google Forms в таблицу

**Описание:** Позволяет автоматически собирать все ответы Google Forms в связанную таблицу Google Sheets в реальном времени, с автоматическим созданием столбцов для каждого вопроса формы и временной меткой каждого ответа.

**Роли:** Владелец формы, Редактор таблицы

**Предусловия:**
- Пользователь создал форму в Google Forms
- У пользователя есть доступ к Google Drive
- Форма содержит хотя бы один вопрос

**Основной сценарий:**
1. Пользователь открывает форму в Google Forms
2. Переходит на вкладку "Ответы" (Responses)
3. Нажимает на зеленую иконку Google Sheets "Создать таблицу"
4. Выбирает "Создать новую таблицу" или "Выбрать существующую"
5. При создании новой система автоматически присваивает имя "{Название формы} (Responses)"
6. Система создает таблицу со столбцом "Timestamp" и столбцами для каждого вопроса формы
7. При отправке формы респондентом новая строка мгновенно добавляется в таблицу
8. Данные синхронизируются в реальном времени (задержка менее 5 секунд)

**Альтернативные сценарии:**
- **A1: Выбор существующей таблицы** — Пользователь выбирает существующую таблицу из Drive, система создает новый лист "Form Responses 1" внутри этой таблицы
- **A2: Изменение структуры формы** — При добавлении нового вопроса в форму автоматически добавляется новый столбец в таблицу
- **A3: Переименование вопроса** — Заголовок столбца в таблице автоматически обновляется при изменении текста вопроса
- **A4: Удаление вопроса** — Столбец сохраняется в таблице с историческими данными, новые ответы содержат пустое значение
- **A5: Отключение связи** — Владелец может отключить сбор ответов в таблицу, существующие данные сохраняются

**Бизнес-правила:**
- BR-INT-001: Первый столбец всегда содержит временную метку (Timestamp) отправки формы
- BR-INT-002: Порядок столбцов соответствует порядку вопросов в форме
- BR-INT-003: Одна форма может быть связана только с одной таблицей одновременно
- BR-INT-004: Синхронизация ответов происходит в реальном времени (до 5 секунд задержки)
- BR-INT-005: Ответы с загруженными файлами содержат ссылки на файлы в Drive, а не сами файлы
- BR-INT-006: Таблицы с более чем 400 ячейками в ответах разбиваются на несколько листов

**Результат:** Таблица Google Sheets автоматически заполняется ответами формы в реальном времени с структурированной организацией данных по столбцам

### FR-INT-002: Подключение к Looker Studio (Google Data Studio) как источник данных

**Описание:** Позволяет использовать Google Sheets как источник данных для создания интерактивных дашбордов и отчетов в Looker Studio с автоматическим обновлением при изменении данных в таблице.

**Роли:** Владелец таблицы, Редактор

**Предусловия:**
- Таблица Google Sheets содержит структурированные данные
- Первая строка содержит заголовки столбцов
- У пользователя есть доступ к Looker Studio

**Основной сценарий:**
1. Пользователь открывает Looker Studio (lookerstudio.google.com)
2. Нажимает "Создать" → "Источник данных"
3. Выбирает коннектор "Google Таблицы"
4. Авторизует доступ к Google аккаунту (если требуется)
5. Выбирает таблицу и конкретный лист для подключения
6. Опционально указывает диапазон ячеек (по умолчанию весь лист)
7. Система автоматически определяет типы данных для каждого столбца
8. Пользователь может переименовать поля и изменить типы данных
9. Нажимает "Подключить" для создания источника данных
10. Источник данных доступен для использования в отчетах

**Альтернативные сценарии:**
- **A1: Без заголовков** — Пользователь отключает опцию "Первая строка как заголовки", столбцы получают метки A, B, C
- **A2: Указание диапазона** — Пользователь указывает конкретный диапазон (например, A1:F100) для ограничения данных
- **A3: Исключение скрытых ячеек** — Опция "Исключить скрытые и отфильтрованные ячейки" позволяет работать только с видимыми данными
- **A4: Обновление в реальном времени** — При каждом открытии отчета Looker Studio запрашивает актуальные данные из Sheets
- **A5: Переиспользуемый источник** — Созданный источник данных можно использовать в нескольких отчетах

**Бизнес-правила:**
- BR-INT-007: Looker Studio поддерживает подключение к одному листу таблицы за раз
- BR-INT-008: Данные автоматически обновляются при каждом запросе к отчету
- BR-INT-009: Все ячейки в столбце должны содержать данные одного типа
- BR-INT-010: Файлы на Google Team Drive не поддерживаются для подключения
- BR-INT-011: Максимальный размер данных ограничен квотами Looker Studio

**Результат:** Google Sheets подключен как источник данных в Looker Studio, данные автоматически обновляются для визуализации в отчетах и дашбордах

### FR-INT-003: Функция GOOGLEFINANCE для получения финансовых данных

**Описание:** Позволяет импортировать котировки акций, валютных курсов, исторические данные и финансовые показатели напрямую в ячейки Google Sheets с помощью встроенной функции GOOGLEFINANCE.

**Роли:** Все пользователи с правами редактирования

**Предусловия:**
- Пользователь имеет доступ к редактированию таблицы
- Таблица открыта в браузере с доступом к интернету

**Основной сценарий:**
1. Пользователь выбирает ячейку для ввода формулы
2. Вводит формулу =GOOGLEFINANCE("NASDAQ:GOOG", "price")
3. Система запрашивает данные с серверов Google Finance
4. Ячейка отображает текущую цену акции с задержкой до 20 минут
5. При изменении котировки значение в ячейке обновляется автоматически
6. Пользователь может использовать ссылку на ячейку с тикером для динамических запросов

**Альтернативные сценарии:**
- **A1: Исторические данные** — Формула =GOOGLEFINANCE("AAPL","close",DATE(2023,1,1),DATE(2023,12,31),"DAILY") возвращает массив данных с датами и ценами закрытия
- **A2: Валютные курсы** — Формула =GOOGLEFINANCE("CURRENCY:USDRUB") возвращает текущий курс доллара к рублю
- **A3: Криптовалюты** — Формула =GOOGLEFINANCE("BTCUSD") возвращает курс биткоина (ограниченная поддержка)
- **A4: Расширенные атрибуты** — Пользователь запрашивает marketcap, pe, eps, volume, high52, low52 для анализа
- **A5: Интервальные данные** — Параметр "DAILY" или "WEEKLY" определяет частоту исторических данных

**Бизнес-правила:**
- BR-INT-012: Данные цен акций задерживаются на 15-20 минут (не real-time)
- BR-INT-013: Если биржа не указана, Google выбирает наиболее вероятную автоматически
- BR-INT-014: Поддерживаются акции, ETF, взаимные фонды и валютные пары
- BR-INT-015: Для real-time данных требуются сторонние add-ons (Market Data, Wisesheets)
- BR-INT-016: Исторические данные возвращают массив значений, требующий нескольких ячеек
- BR-INT-017: Обновление данных происходит только при открытии таблицы

**Поддерживаемые атрибуты GOOGLEFINANCE:**
| Атрибут | Описание |
|---------|----------|
| price | Текущая цена (задержка 15-20 мин) |
| priceopen | Цена открытия торговой сессии |
| high | Максимальная цена за день |
| low | Минимальная цена за день |
| volume | Объем торгов за день |
| marketcap | Рыночная капитализация |
| pe | Коэффициент цена/прибыль (P/E) |
| eps | Прибыль на акцию |
| high52 | Максимум за 52 недели |
| low52 | Минимум за 52 недели |
| change | Изменение цены в процентах |
| closeyest | Цена закрытия предыдущего дня |

**Результат:** Финансовые данные импортированы в таблицу и автоматически обновляются при изменении котировок на рынке

### FR-INT-004: Connected Sheets — подключение к Google BigQuery

**Описание:** Позволяет подключаться к базам данных BigQuery и работать с миллиардами строк данных в интерфейсе Google Sheets без необходимости написания SQL-запросов, используя привычные инструменты: сводные таблицы, диаграммы и формулы.

**Роли:** Владелец таблицы, Редактор с доступом к BigQuery

**Предусловия:**
- У пользователя есть доступ к проекту Google Cloud с BigQuery
- Пользователь имеет права на чтение данных BigQuery
- Таблица открыта в веб-версии Google Sheets

**Основной сценарий:**
1. Пользователь открывает таблицу Google Sheets
2. Выбирает меню "Данные" → "Подключение к данным" → "Подключить к BigQuery"
3. Выбирает проект Google Cloud, набор данных (dataset) и таблицу BigQuery
4. Система создает подключение и отображает схему данных
5. Пользователь может создавать сводные таблицы с автоматическим выполнением запросов BigQuery
6. Строит диаграммы на основе агрегированных данных
7. Использует формулы для анализа больших объемов данных
8. Данные обновляются по запросу с помощью кнопки "Обновить"

**Альтернативные сценарии:**
- **A1: Кастомный SQL-запрос** — Пользователь пишет собственный SQL-запрос для подключения к произвольным данным
- **A2: Извлечение данных** — Пользователь извлекает подмножество данных в обычные ячейки Sheets для локальной работы
- **A3: Обновление данных** — Кнопка "Обновить" запрашивает актуальные данные из BigQuery
- **A4: Создание расписания** — Настройка автоматического обновления данных по расписанию
- **A5: Работа без SQL** — Пользователь использует только визуальный интерфейс сводных таблиц без написания запросов

**Бизнес-правила:**
- BR-INT-018: Connected Sheets доступен только в веб-версии Google Sheets
- BR-INT-019: Данные в BigQuery не изменяются из Google Sheets (только чтение)
- BR-INT-020: Запросы к BigQuery тарифицируются согласно прайсу Google Cloud
- BR-INT-021: Максимальный объем данных ограничен только BigQuery (миллиарды строк)
- BR-INT-022: Требуется подписка Google Workspace Enterprise или BigQuery permissions
- BR-INT-023: Сводные таблицы автоматически транслируются в оптимизированные SQL-запросы

**Результат:** Таблица Google Sheets подключена к BigQuery, пользователь может анализировать большие данные с помощью привычных инструментов Sheets

### FR-INT-005: Связывание диаграмм с Google Docs

**Описание:** Позволяет вставлять диаграммы из Google Sheets в документы Google Docs со связью с исходными данными и возможностью обновления диаграммы при изменении данных в таблице.

**Роли:** Владелец документа, Редактор

**Предусловия:**
- В Google Sheets создана диаграмма
- Пользователь имеет доступ к редактированию документа Google Docs
- Пользователь авторизован в Google аккаунте

**Основной сценарий:**
1. Пользователь открывает документ Google Docs
2. Устанавливает курсор в место вставки диаграммы
3. Выбирает меню "Вставка" → "Диаграмма" → "Из Таблиц"
4. Выбирает таблицу Google Sheets из списка
5. Выбирает конкретную диаграмму из таблицы
6. Отмечает опцию "Связать с таблицей" (Link to spreadsheet)
7. Нажимает "Импортировать"
8. Диаграмма вставляется в документ со связью с источником

**Альтернативные сценарии:**
- **A1: Обновление диаграммы** — При изменении данных в Sheets над диаграммой появляется кнопка "Обновить", клик обновляет диаграмму
- **A2: Обновить все связанные объекты** — Меню "Инструменты" → "Связанные объекты" → "Обновить все" обновляет все диаграммы в документе
- **A3: Отмена связи** — Пользователь может отменить связь, диаграмма становится статическим изображением
- **A4: Открытие источника** — Клик на связанной диаграмме → "Открыть источник" открывает таблицу Sheets
- **A5: Вставка без связи** — Снятие флажка "Связать с таблицей" вставляет статическую копию диаграммы

**Бизнес-правила:**
- BR-INT-024: Связь является односторонней: изменения в Sheets отражаются в Docs, но не наоборот
- BR-INT-025: Пользователи документа могут видеть диаграмму даже без доступа к исходной таблице
- BR-INT-026: Обновление диаграммы требует ручного действия (автоматическое обновление не поддерживается)
- BR-INT-027: При отмене связи изменения в таблице больше не влияют на диаграмму в документе
- BR-INT-028: Поддерживается связывание всех типов диаграмм Google Sheets

**Результат:** Диаграмма из Google Sheets вставлена в документ со связью с источником, обновляется по требованию при изменении данных

### FR-INT-006: Связывание таблиц с Google Docs

**Описание:** Позволяет вставлять диапазоны данных из Google Sheets в документы Google Docs в виде связанных таблиц с возможностью обновления при изменении исходных данных.

**Роли:** Владелец документа, Редактор

**Предусловия:**
- В Google Sheets имеются данные для вставки
- Пользователь имеет доступ к редактированию документа Google Docs

**Основной сценарий:**
1. Пользователь открывает Google Sheets и выделяет диапазон ячеек
2. Копирует данные (Ctrl+C / Cmd+C)
3. Переходит в документ Google Docs
4. Вставляет данные (Ctrl+V / Cmd+V)
5. В появившемся диалоге выбирает "Связать с таблицей" (Link to spreadsheet)
6. Нажимает "Вставить"
7. Таблица вставляется с сохранением связи с источником
8. При изменении данных в Sheets появляется кнопка "Обновить"

**Альтернативные сценарии:**
- **A1: Вставка без связи** — Выбор "Вставить без связи" создает статическую таблицу в документе
- **A2: Редактирование в Docs** — Данные можно редактировать в Docs, но изменения не отражаются в Sheets
- **A3: Синхронизация при обновлении** — При нажатии "Обновить" изменения в Docs перезаписываются данными из Sheets
- **A4: Частичное обновление** — Можно обновить только конкретные связанные таблицы через панель "Связанные объекты"

**Бизнес-правила:**
- BR-INT-029: Максимальный размер связанной таблицы — 400 ячеек
- BR-INT-030: Таблицы более 400 ячеек вставляются без связи
- BR-INT-031: Связь односторонняя: Sheets → Docs
- BR-INT-032: Форматирование (цвета, шрифты) сохраняется при вставке
- BR-INT-033: Объединенные ячейки корректно переносятся в документ

**Результат:** Данные из Google Sheets вставлены в документ как связанная таблица с возможностью обновления

### FR-INT-007: Связывание диаграмм и таблиц с Google Slides

**Описание:** Позволяет вставлять диаграммы и таблицы из Google Sheets в презентации Google Slides со связью с исходными данными для автоматического обновления.

**Роли:** Владелец презентации, Редактор

**Предусловия:**
- В Google Sheets имеются диаграммы или данные
- Пользователь имеет доступ к редактированию презентации

**Основной сценарий:**
1. Пользователь открывает презентацию Google Slides
2. Выбирает меню "Вставка" → "Диаграмма" → "Из Таблиц"
3. Выбирает таблицу Google Sheets
4. Выбирает диаграмму для вставки
5. Отмечает "Связать" (Link)
6. Нажимает "Импортировать"
7. Диаграмма появляется на слайде со связью с источником
8. При изменении данных в Sheets появляется кнопка "Обновить"

**Альтернативные сценарии:**

- **A1: Кастомная функция** — Создание собственных формул (=MYFUNC()) для использования в ячейках
- **A2: Кастомное меню** — Добавление пунктов в меню таблицы для запуска скриптов
- **A3: Webhook интеграция** — UrlFetchApp для отправки данных на внешние сервисы
- **A4: Email автоматизация** — MailApp для отправки писем на основе данных таблицы
- **A5: Web App** — Публикация скрипта как веб-приложения

**Бизнес-правила:**
- BR-INT-075: Время выполнения скрипта ограничено 6 минутами
- BR-INT-076: Дневная квота выполнения: 90 минут для бесплатных аккаунтов, 6 часов для Workspace
- BR-INT-077: Квота отправки email: 100/день (бесплатно), 1500/день (Workspace)
- BR-INT-078: Квота UrlFetchApp: 20,000 запросов в день
- BR-INT-079: Скрипты выполняются на серверах Google

**Результат:** Автоматизация настроена через Apps Script, выполняется по расписанию или триггерам

### FR-INT-017: IMPORTRANGE — импорт данных из других таблиц

**Описание:** Позволяет импортировать данные из одной таблицы Google Sheets в другую с помощью функции IMPORTRANGE с автоматической синхронизацией.

**Роли:** Все пользователи с правами редактирования

**Предусловия:**
- У пользователя есть доступ к обеим таблицам (источник и приемник)
- Таблица-источник содержит данные для импорта

**Основной сценарий:**
1. Пользователь открывает таблицу-приемник
2. Выбирает ячейку для вставки формулы
3. Вводит формулу =IMPORTRANGE("URL_или_ID_таблицы", "Лист1!A1:D100")
4. При первом использовании система запрашивает разрешение на доступ к внешней таблице
5. Пользователь нажимает "Разрешить доступ"
6. Данные импортируются и отображаются в таблице
7. При изменении данных в источнике они автоматически обновляются в приемнике

**Альтернативные сценарии:**
- **A1: Динамический диапазон** — Использование именованных диапазонов в источнике
- **A2: Комбинация с другими функциями** — =QUERY(IMPORTRANGE(...), "SELECT * WHERE Col1 > 100")
- **A3: Множественный импорт** — Импорт из нескольких таблиц в одну

**Бизнес-правила:**
- BR-INT-080: Разрешение на доступ запрашивается один раз для пары таблиц
- BR-INT-081: IMPORTRANGE создает одностороннюю связь (изменения в приемнике не влияют на источник)
- BR-INT-082: Обновление данных происходит автоматически (с небольшой задержкой)
- BR-INT-083: Ошибка #REF! появляется если доступ не предоставлен

**Результат:** Данные импортированы из внешней таблицы с автоматической синхронизацией

### FR-INT-018: IMPORTDATA/IMPORTXML/IMPORTHTML — импорт данных из веб

**Описание:** Позволяет импортировать данные из внешних веб-источников (CSV, XML, HTML таблицы) напрямую в ячейки Google Sheets с автоматическим обновлением.

**Роли:** Все пользователи с правами редактирования

**Предусловия:**
- URL источника данных публично доступен
- Данные в поддерживаемом формате (CSV, XML, HTML)

**Основной сценарий:**
1. Пользователь выбирает ячейку для вставки данных
2. Вводит одну из функций импорта с URL источника
3. Система загружает данные с указанного URL
4. Данные отображаются в таблице
5. При изменении данных на источнике они обновляются в Sheets (при пересчете)

**Функции импорта:**
| Функция | Описание |
|---------|----------|
| =IMPORTDATA("url") | Импорт данных из CSV или TSV файла |
| =IMPORTXML("url", "xpath") | Импорт данных из XML или HTML с использованием XPath |
| =IMPORTHTML("url", "table", index) | Импорт таблицы или списка из HTML страницы |
| =IMPORTFEED("url") | Импорт RSS или Atom ленты |

**Бизнес-правила:**
- BR-INT-084: Максимальное количество IMPORT-функций: 50 на таблицу
- BR-INT-085: Данные обновляются каждый час или при ручном пересчете
- BR-INT-086: URL должен быть публично доступен (без авторизации)
- BR-INT-087: Для защищенных источников требуется использование Apps Script

**Результат:** Данные из веб-источника импортированы в таблицу с периодическим обновлением

### FR-INT-019: Управление установленными дополнениями

**Описание:** Позволяет просматривать, настраивать, отключать и удалять установленные дополнения Google Sheets, а также управлять их разрешениями.

**Роли:** Владелец таблицы, Пользователь Google Workspace

**Предусловия:**
- У пользователя установлено хотя бы одно дополнение

4. Пользователь может включить/отключить дополнение для текущего документа
5. Может нажать "Удалить" для полного удаления дополнения
6. Изменения применяются немедленно

**Альтернативные сценарии:**

- **A2: Просмотр разрешений** — Клик на дополнение показывает список предоставленных разрешений
- **A3: Обновление дополнения** — Дополнения обновляются автоматически разработчиками

**Бизнес-правила:**

- BR-INT-090: Отключение для документа не удаляет дополнение из аккаунта

**Результат:** Дополнения управляются, ненужные удалены или отключены

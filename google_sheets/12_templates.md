# Шаблоны (Templates)

## Описание

Модуль шаблонов в Google Sheets предоставляет пользователям возможность быстро создавать структурированные таблицы на основе готовых образцов. Галерея шаблонов включает профессионально разработанные документы от Google, организационные шаблоны для корпоративных пользователей и сторонние решения через дополнения.

Система состоит из семи ключевых компонентов:
1. **Галерея шаблонов Google** - встроенная библиотека бесплатных шаблонов от Google
2. **Категории шаблонов** - структурированная организация по назначению (личное, работа, образование, проекты)
3. **Использование шаблона** - процесс создания документа на основе шаблона
4. **Создание своего шаблона** - возможность сохранения собственных документов как шаблонов
5. **Шаблоны организации** - корпоративная галерея для Google Workspace
6. **Сторонние шаблоны** - дополнительные шаблоны через Google Workspace Marketplace
7. **Популярные шаблоны** - наиболее востребованные типы документов

## Роли пользователей

### Для личных аккаунтов Google:
- **Обычный пользователь** - может использовать шаблоны из общей галереи Google, создавать копии и настраивать их

### Для Google Workspace:
- **Пользователь организации** - может использовать общие шаблоны Google и шаблоны своей организации
- **Участник с правом отправки** - может отправлять шаблоны в галерею организации (если разрешено)
- **Модератор шаблонов** - одобряет или отклоняет шаблоны, отправленные на модерацию
- **Администратор Google Workspace** - настраивает политики шаблонов, управляет категориями, определяет права отправки

### FR-TPL-001: Доступ к галерее шаблонов (Access Template Gallery)
**Описание:** Пользователь может открыть галерею шаблонов Google Sheets для просмотра и выбора готовых документов.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в Google-аккаунте
- Пользователь находится в Google Sheets

**Основной сценарий:**
1. Пользователь открывает Google Sheets (sheets.google.com)
2. На главной странице видит раздел "Start a new spreadsheet" (Создать таблицу)
3. В правом верхнем углу этого раздела нажимает "Template gallery" (Галерея шаблонов)
4. Открывается полная галерея шаблонов
5. Галерея отображает вкладки: "General" (Общие) и название организации (для Workspace)
6. Пользователь видит шаблоны, организованные по категориям
7. Каждый шаблон отображается с превью, названием и описанием

**Альтернативные сценарии:**
- Сценарий A (Через меню File): пользователь открывает любую таблицу, нажимает File → New → From template gallery
- Сценарий B (Быстрый доступ): на главной странице отображаются популярные шаблоны без открытия полной галереи
- Сценарий C (Прямая ссылка): переход по URL docs.google.com/spreadsheets/u/0/?ftv=1 открывает галерею

**Бизнес-правила:**
- BR-TPL-001: Галерея шаблонов Google доступна бесплатно всем пользователям Google
- BR-TPL-002: Для пользователей Workspace отображается дополнительная вкладка с шаблонами организации
- BR-TPL-003: Галерея загружается асинхронно для быстрого отображения
- BR-TPL-004: Превью шаблонов отображаются как миниатюры таблиц

**Результат:** Пользователь видит галерею доступных шаблонов

### FR-TPL-002: Просмотр категорий шаблонов (Browse Template Categories)
**Описание:** Пользователь может просматривать шаблоны, организованные по категориям для удобного поиска нужного типа документа.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь открыл галерею шаблонов
- Галерея загружена и отображает категории

**Основной сценарий:**
1. Пользователь открывает галерею шаблонов
2. Видит категории шаблонов, расположенные горизонтально или вертикально
3. Стандартные категории Google включают:
   - **Personal** (Личное) - бюджеты, списки дел, планировщики
   - **Work** (Работа) - инвойсы, табели, отчеты расходов
   - **Project Management** (Управление проектами) - диаграммы Ганта, таймлайны
   - **Education** (Образование) - журналы оценок, расписания
4. Нажимает на название категории для фильтрации
5. Отображаются только шаблоны выбранной категории
6. Может переключаться между категориями без перезагрузки страницы

**Альтернативные сценарии:**
- Сценарий A (Просмотр всех): нажимает "All templates" для отображения всех шаблонов без фильтрации
- Сценарий B (Прокрутка категории): прокручивает горизонтально для просмотра всех шаблонов категории
- Сценарий C (Категории организации): для Workspace отображаются кастомные категории, созданные администратором

**Бизнес-правила:**
- BR-TPL-005: Категория Personal включает шаблоны для личного использования: бюджеты, планировщики, списки
- BR-TPL-006: Категория Work содержит бизнес-шаблоны: инвойсы, табели учета времени, отчеты
- BR-TPL-007: Категория Project Management включает инструменты планирования: Gantt-диаграммы, таймлайны
- BR-TPL-008: Категория Education предназначена для учебных заведений: журналы оценок, расписания занятий
- BR-TPL-009: Администраторы Workspace могут создавать собственные категории

**Результат:** Пользователь видит шаблоны, отфильтрованные по выбранной категории

### FR-TPL-003: Использование шаблона (Use Template)
**Описание:** Пользователь может создать новую таблицу на основе выбранного шаблона, получив копию с готовой структурой, форматированием и формулами.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь просматривает галерею шаблонов
- Пользователь выбрал интересующий шаблон
- У пользователя достаточно места в Google Drive

**Основной сценарий:**
1. Пользователь находит нужный шаблон в галерее
2. Наводит курсор на превью шаблона
3. Нажимает на шаблон для выбора
4. Система создает копию шаблона в Google Drive пользователя
5. Новая таблица открывается в редакторе Google Sheets
6. Таблица содержит всю структуру, форматирование и формулы оригинала
7. Пользователь может сразу начать редактирование

**Альтернативные сценарии:**
- Сценарий A (Превью перед использованием): нажимает на шаблон правой кнопкой и выбирает "Preview" для просмотра без создания копии
- Сценарий B (Переименование при создании): после создания копии сразу переименовывает документ
- Сценарий C (Выбор папки сохранения): перемещает созданную таблицу в нужную папку на Google Drive
- Сценарий D (Множественное использование): создает несколько копий одного шаблона для разных целей

**Бизнес-правила:**
- BR-TPL-010: При использовании шаблона создается независимая копия, не связанная с оригиналом
- BR-TPL-011: Копия шаблона сохраняется в корневую папку "My Drive" пользователя
- BR-TPL-012: Название новой таблицы по умолчанию совпадает с названием шаблона
- BR-TPL-013: Все формулы и скрипты шаблона копируются в новый документ
- BR-TPL-014: Форматирование ячеек, условное форматирование и проверка данных сохраняются
- BR-TPL-015: Связанные данные (импорт из других источников) не копируются автоматически

**Результат:** Создана новая таблица на основе шаблона, готовая к редактированию

### FR-TPL-004: Настройка скопированного шаблона (Customize Template Copy)
**Описание:** После создания копии шаблона пользователь может изменять содержимое, структуру и форматирование под свои потребности.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь создал копию шаблона
- Таблица открыта в режиме редактирования
- Пользователь имеет права редактирования документа

**Основной сценарий:**
1. Пользователь открывает созданную копию шаблона
2. Заменяет placeholder-текст своими данными
3. Изменяет форматирование: шрифты, цвета, размеры
4. Добавляет или удаляет строки и столбцы по необходимости
5. Корректирует формулы для своих диапазонов данных
6. Добавляет собственную логотип или брендинг
7. Сохраняет изменения (автоматически)

**Альтернативные сценарии:**
- Сценарий A (Защита формул): устанавливает защиту на ячейки с важными формулами
- Сценарий B (Добавление листов): создает дополнительные листы в таблице
- Сценарий C (Удаление ненужных элементов): удаляет разделы шаблона, которые не требуются
- Сценарий D (Изменение валюты/формата): меняет формат чисел, дат, валюты под свой регион

**Бизнес-правила:**
- BR-TPL-016: Пользователь имеет полные права на редактирование своей копии шаблона
- BR-TPL-017: Изменения в копии не влияют на оригинальный шаблон
- BR-TPL-018: Можно использовать функцию "Protect range" для защиты важных формул
- BR-TPL-019: Условное форматирование можно изменять или удалять
- BR-TPL-020: При изменении структуры таблицы формулы автоматически обновляют ссылки

**Результат:** Шаблон настроен под конкретные потребности пользователя

### FR-TPL-005: Создание собственного шаблона для организации (Submit Custom Template)
**Описание:** Пользователь Google Workspace может отправить свою таблицу в галерею шаблонов организации для использования другими сотрудниками.

**Роли:** Пользователь организации, Участник с правом отправки

**Предусловия:**
- Пользователь имеет аккаунт Google Workspace
- Администратор включил функцию пользовательских шаблонов
- Пользователь создал таблицу, которую хочет сделать шаблоном
- Таблица соответствует требованиям организации

**Основной сценарий:**
1. Пользователь открывает Google Sheets и переходит в галерею шаблонов
2. Нажимает на вкладку с названием своей организации
3. Нажимает кнопку "Submit template" (Отправить шаблон)
4. Открывается диалог выбора документа
5. Выбирает таблицу из своего Google Drive
6. Выбирает категорию для шаблона из списка доступных
7. Опционально выбирает "Submit a copy" для отправки копии вместо оригинала
8. Нажимает "Submit" (Отправить)

**Альтернативные сценарии:**
- Сценарий A (Модерируемый режим): шаблон отправляется на рассмотрение модератору, пользователь получает уведомление о статусе
- Сценарий B (Открытый режим): шаблон сразу добавляется в галерею без модерации
- Сценарий C (Ограниченный режим): только администраторы могут добавлять шаблоны
- Сценарий D (Отклонение шаблона): модератор отклоняет шаблон, пользователь получает уведомление с причиной

**Бизнес-правила:**
- BR-TPL-021: Функция доступна для Business Standard, Business Plus, Enterprise, Education
- BR-TPL-022: Администратор определяет режим отправки: Open, Moderated или Restricted
- BR-TPL-023: При модерируемом режиме администраторы получают email с запросом на одобрение
- BR-TPL-024: Пользователь может отправить копию шаблона, чтобы оригинал оставался личным
- BR-TPL-025: Отправленный шаблон становится доступным всем пользователям организации
- BR-TPL-026: Пользователь остается владельцем отправленного шаблона и может его обновлять

**Результат:** Шаблон отправлен в галерею организации (или на модерацию)

### FR-TPL-006: Управление категориями шаблонов организации (Manage Template Categories)
**Описание:** Администратор Google Workspace может создавать, редактировать и удалять категории шаблонов для организации.

**Роли:** Администратор Google Workspace

**Предусловия:**
- Пользователь имеет права администратора в Google Workspace Admin Console
- Функция пользовательских шаблонов включена
- Организация использует поддерживаемую версию Google Workspace

**Основной сценарий:**
1. Администратор открывает Google Workspace Admin Console (admin.google.com)
2. Переходит в Apps → Google Workspace → Drive and Docs → Templates
3. Нажимает "Manage categories" (Управление категориями)
4. Видит список существующих категорий
5. Нажимает "Add category" для создания новой категории
6. Вводит название категории (например, "Маркетинг", "HR", "Финансы")
7. Нажимает "Save" (Сохранить)

**Альтернативные сценарии:**
- Сценарий A (Редактирование категории): выбирает существующую категорию и изменяет её название
- Сценарий B (Удаление категории): удаляет категорию, шаблоны перемещаются в "Uncategorized"
- Сценарий C (Изменение порядка): перетаскивает категории для изменения порядка отображения
- Сценарий D (Использование стандартных): оставляет категории по умолчанию: Basics, Finance & Accounting, Letters & Faxes, Reports & Proposals

**Бизнес-правила:**
- BR-TPL-027: По умолчанию доступны категории: Basics, Brochures & Newsletters, Finance & Accounting, Letters & Faxes, Reports & Proposals
- BR-TPL-028: Администратор может создавать неограниченное количество кастомных категорий
- BR-TPL-029: Название категории должно быть уникальным в пределах организации
- BR-TPL-030: При удалении категории шаблоны не удаляются, а перемещаются в "Без категории"
- BR-TPL-031: Категории применяются ко всем приложениям: Docs, Sheets, Slides, Forms, Sites

**Результат:** Категории шаблонов организации настроены согласно требованиям

### FR-TPL-007: Настройка политики отправки шаблонов (Configure Template Submission Policy)
**Описание:** Администратор Google Workspace определяет, кто в организации может отправлять шаблоны и требуется ли модерация.

**Роли:** Администратор Google Workspace

**Предусловия:**
- Пользователь имеет права администратора
- Функция пользовательских шаблонов включена
- Организация использует поддерживаемую версию Workspace

**Основной сценарий:**
1. Администратор открывает Google Workspace Admin Console
2. Переходит в Apps → Google Workspace → Drive and Docs → Templates
3. Нажимает "Template Gallery settings" (Настройки галереи шаблонов)
4. Устанавливает галочку "Enable custom templates for your organization"
5. Выбирает режим отправки шаблонов:
   - Open - все могут добавлять без одобрения
   - Moderated - требуется одобрение администратора
   - Restricted - только администраторы могут добавлять
6. Нажимает "Save"

**Альтернативные сценарии:**
- Сценарий A (Полное отключение): снимает галочку "Enable custom templates" - пользователи видят только шаблоны Google
- Сценарий B (Назначение модераторов): назначает конкретных пользователей с привилегией Docs Templates для модерации
- Сценарий C (Политика по подразделениям): настраивает разные политики для разных организационных единиц (OU)

**Бизнес-правила:**
- BR-TPL-032: При режиме Open любой пользователь может добавлять и удалять шаблоны
- BR-TPL-033: При режиме Moderated запрос на одобрение отправляется всем админам с привилегией Docs Templates
- BR-TPL-034: При режиме Restricted только админы с привилегией Docs Templates могут добавлять шаблоны
- BR-TPL-035: Модераторы могут просматривать связанные дополнения перед одобрением шаблона
- BR-TPL-036: Изменение политики вступает в силу немедленно

**Результат:** Политика отправки шаблонов настроена для организации

### FR-TPL-008: Модерация шаблонов (Moderate Templates)
**Описание:** Администратор или модератор рассматривает отправленные шаблоны и принимает решение об их публикации в галерее организации.

**Роли:** Администратор Google Workspace, Модератор шаблонов

**Предусловия:**
- Режим отправки шаблонов установлен как "Moderated"
- Пользователь отправил шаблон на рассмотрение
- Модератор имеет привилегию Docs Templates

**Основной сценарий:**
1. Модератор получает email-уведомление о новом шаблоне
2. Email содержит: название шаблона, имя отправителя, выбранную категорию
3. Нажимает ссылку в email для просмотра шаблона
4. Открывает шаблон и оценивает его качество и соответствие стандартам
5. Проверяет связанные дополнения (если есть)
6. Принимает решение:
   - Нажимает "Approve" для одобрения
   - Нажимает "Reject" для отклонения
7. При отклонении опционально указывает причину

**Альтернативные сценарии:**
- Сценарий A (Одобрение из Admin Console): модератор просматривает список ожидающих шаблонов в консоли администратора
- Сценарий B (Отложенное решение): модератор откладывает решение, запрос остается в очереди
- Сценарий C (Повторная отправка): после отклонения пользователь исправляет шаблон и отправляет снова
- Сценарий D (Множественные модераторы): первый ответивший модератор закрывает запрос

**Бизнес-правила:**
- BR-TPL-037: Запрос на модерацию отправляется всем администраторам с привилегией Docs Templates
- BR-TPL-038: Запрос закрывается после первого ответа любого модератора
- BR-TPL-039: Одобренные шаблоны сразу появляются в галерее организации
- BR-TPL-040: Отклоненные шаблоны можно повторно отправить после исправления
- BR-TPL-041: Модератор должен проверить связанные дополнения на безопасность
- BR-TPL-042: История модерации сохраняется в логах администратора

**Результат:** Шаблон одобрен и опубликован, или отклонен с уведомлением отправителю

### FR-TPL-009: Удаление шаблона из галереи организации (Remove Template from Gallery)
**Описание:** Владелец шаблона или администратор может удалить шаблон из галереи организации.

**Роли:** Владелец шаблона, Администратор Google Workspace

**Предусловия:**

### FR-TPL-019: Создание личного шаблона (Create Personal Template)
**Описание:** Пользователь личного аккаунта Google может сохранить свою таблицу как шаблон для повторного использования.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в личном Google-аккаунте
- Пользователь создал таблицу, которую хочет использовать как шаблон
- Таблица содержит структуру, форматирование и формулы

**Основной сценарий:**
1. Пользователь создает и настраивает таблицу
2. Очищает личные данные, оставляя структуру и формулы
3. Создает папку "Templates" в Google Drive
4. Переименовывает таблицу с префиксом "Template:" или "[TEMPLATE]"
5. Перемещает таблицу в папку Templates
6. Для использования: открывает таблицу и нажимает File → Make a copy
7. Копия создается с сохранением всей структуры

**Альтернативные сценарии:**
- Сценарий A (Starred templates): добавляет шаблоны в избранное для быстрого доступа
- Сценарий B (Организация по категориям): создает подпапки для разных типов шаблонов
- Сценарий C (Версионирование): сохраняет версии шаблона с датой в названии

**Бизнес-правила:**
- BR-TPL-093: Личные аккаунты не имеют доступа к галерее организации
- BR-TPL-094: Пользователь должен самостоятельно организовать хранение шаблонов
- BR-TPL-095: При копировании сохраняются все формулы, форматирование и скрипты
- BR-TPL-096: Оригинальный шаблон остается неизменным при создании копии
- BR-TPL-097: Можно поделиться шаблоном через ссылку с правами "Make a copy"

**Результат:** Создан личный шаблон для повторного использования

### FR-TPL-020: Защита формул в шаблоне (Protect Template Formulas)
**Описание:** При создании шаблона пользователь может защитить ячейки с формулами от случайного изменения.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь создает или редактирует шаблон
- Шаблон содержит важные формулы
- Пользователь хочет предотвратить случайное удаление формул

**Основной сценарий:**
1. Пользователь открывает таблицу-шаблон
2. Выделяет диапазон ячеек с формулами
3. Нажимает правой кнопкой и выбирает "View more cell actions"
4. Выбирает "Protect range" (Защитить диапазон)
5. В открывшемся панели вводит описание защиты
6. Нажимает "Set permissions" (Установить разрешения)
7. Выбирает:
   - "Only you can edit this range" - только владелец может редактировать
   - "Show a warning when editing this range" - показывать предупреждение
8. Нажимает "Done"

**Альтернативные сценарии:**
- Сценарий A (Предупреждение): выбирает показ предупреждения вместо полной блокировки
- Сценарий B (Защита всего листа): защищает весь лист, разрешая редактирование только определенных ячеек
- Сценарий C (Множественные диапазоны): защищает несколько несмежных диапазонов

**Бизнес-правила:**
- BR-TPL-098: Защищенные диапазоны сохраняются при копировании шаблона
- BR-TPL-099: Владелец копии становится владельцем защиты
- BR-TPL-100: Можно настроить список пользователей, которые могут редактировать защищенный диапазон
- BR-TPL-101: Защита работает только для пользователей без прав владельца

**Результат:** Формулы шаблона защищены от случайного изменения

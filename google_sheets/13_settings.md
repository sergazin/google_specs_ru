# Настройки (Settings)

## Описание

Модуль настроек в Google Sheets обеспечивает управление параметрами электронной таблицы, включая региональные настройки (локаль, часовой пояс), настройки вычислений (пересчёт формул, итеративные вычисления), параметры отображения (сетка, заголовки), настройки печати, уведомлений, офлайн-доступа, а также административные политики Google Workspace. Модуль позволяет настроить поведение таблицы для всех пользователей, имеющих к ней доступ.

Система состоит из девяти ключевых компонентов:
1. **Настройки таблицы** - управление локалью, часовым поясом и языком функций
2. **Настройки вычислений** - управление пересчётом формул и итеративными вычислениями
3. **Настройки отображения** - управление видимостью сетки и заголовков строк/столбцов
4. **Настройки печати** - конфигурация параметров вывода на печать
5. **Настройки уведомлений** - управление оповещениями о комментариях и изменениях
6. **Офлайн-доступ** - настройка работы без подключения к интернету
7. **Настройки доступа** - управление правами по умолчанию и защитой диапазонов
8. **Управление расширениями** - установка, настройка и удаление дополнений
9. **Настройки администратора Workspace** - корпоративные политики и ограничения

## Роли пользователей

### Индивидуальные пользователи:
- **Владелец таблицы (Owner)** - полный контроль над всеми настройками, включая удаление и передачу прав владения
- **Редактор (Editor)** - может изменять большинство настроек таблицы, кроме прав доступа (если ограничено владельцем)
- **Комментатор (Commenter)** - может только просматривать настройки, изменять настройки уведомлений для себя
- **Читатель (Viewer)** - может только просматривать таблицу, доступ к настройкам отображения для себя

### Корпоративные пользователи:
- **Администратор Google Workspace** - управление политиками безопасности, внешнего доступа и офлайн-режима на уровне организации
- **Конечный пользователь Workspace** - доступ к функциям согласно политикам, установленным администратором

### FR-SET-001: Настройка локали таблицы (Set Spreadsheet Locale)
**Описание:** Пользователь может изменить региональные настройки (локаль) таблицы, которые определяют форматирование чисел, валюты и дат по умолчанию для всей таблицы.

**Роли:** Владелец, Редактор

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере
- Пользователь имеет права редактирования

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Файл" (File) в верхней панели
3. Выбирает пункт "Настройки" (Settings) в выпадающем меню
4. В открывшемся диалоговом окне переходит на вкладку "Общие" (General)
5. Находит раздел "Локаль" (Locale) с выпадающим списком
6. Выбирает нужную локаль из списка (например, "Россия", "United States", "Germany")
7. Нажимает кнопку "Сохранить настройки" (Save settings)

**Альтернативные сценарии:**
- Сценарий A (Изменение валюты по умолчанию): выбор локали "United Kingdom" устанавливает фунт стерлингов () как валюту по умолчанию
- Сценарий B (Изменение формата даты): выбор локали "Россия" устанавливает формат ДД.ММ.ГГГГ вместо MM/DD/YYYY
- Сценарий C (Изменение разделителя чисел): выбор европейской локали меняет десятичный разделитель с точки на запятую (1.234,56 вместо 1,234.56)
- Сценарий D (Влияние на существующие данные): система спрашивает, нужно ли переформатировать существующие числа и даты

**Бизнес-правила:**
- BR-SET-001: Изменение локали применяется ко всей таблице и видно всем пользователям независимо от их местоположения
- BR-SET-002: Локаль влияет на форматирование новых данных; существующие данные могут потребовать ручного переформатирования
- BR-SET-003: Изменение локали не изменяет язык интерфейса Google Sheets
- BR-SET-004: При выборе локали с запятой в качестве десятичного разделителя аргументы функций разделяются точкой с запятой

**Результат:** Локаль таблицы изменена, что влияет на форматирование чисел, дат и валюты по умолчанию

### FR-SET-002: Настройка часового пояса таблицы (Set Spreadsheet Time Zone)
**Описание:** Пользователь может установить часовой пояс таблицы, который используется функциями работы с датой и временем (NOW, TODAY, DATEVALUE) для корректного отображения текущего времени.

**Роли:** Владелец, Редактор

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере
- Пользователь имеет права редактирования

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Файл" (File) в верхней панели
3. Выбирает пункт "Настройки" (Settings)
4. В диалоговом окне находит раздел "Часовой пояс" (Time zone)
5. Нажимает на выпадающий список часовых поясов
6. Вводит в поиске название города или UTC-смещение (например, "Moscow", "GMT+3")
7. Выбирает нужный часовой пояс из результатов поиска
8. Нажимает "Сохранить настройки" (Save settings)

**Альтернативные сценарии:**
- Сценарий A (Влияние на функцию NOW): после изменения на "(GMT+09:00) Tokyo" функция =NOW() показывает токийское время
- Сценарий B (Влияние на функцию TODAY): функция =TODAY() возвращает дату по выбранному часовому поясу
- Сценарий C (Учёт летнего времени): при выборе "(GMT-05:00) Eastern Time" система автоматически учитывает переход на летнее время
- Сценарий D (Совместная работа в разных поясах): все соавторы видят одинаковое время, независимо от их локального часового пояса

**Бизнес-правила:**
- BR-SET-005: Часовой пояс таблицы хранится в метаданных и применяется ко всем функциям даты/времени
- BR-SET-006: По умолчанию часовой пояс таблицы соответствует часовому поясу аккаунта Google создателя
- BR-SET-007: Изменение часового пояса не изменяет сохранённые значения дат, только влияет на вычисление текущего времени
- BR-SET-008: Google Sheets автоматически обрабатывает переходы на летнее/зимнее время для поддерживаемых регионов

**Результат:** Часовой пояс таблицы установлен, функции даты и времени используют указанный пояс

### FR-SET-003: Настройка языка функций (Set Function Language)
**Описание:** Пользователь может выбрать, на каком языке будут отображаться названия функций в формулах - на английском или на языке, соответствующем настройкам Google аккаунта.

**Роли:** Владелец, Редактор

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Язык Google аккаунта установлен на не английский язык
- Таблица открыта в браузере

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Файл" (File)
3. Выбирает "Настройки" (Settings)
4. В разделе "Язык отображения" (Display language) находит опцию
5. Видит чекбокс "Всегда использовать английские названия функций" (Always use English function names)
6. Снимает галочку для использования функций на языке локали
7. Нажимает "Сохранить настройки"

**Альтернативные сценарии:**
- Сценарий A (Перевод существующих формул): при изменении настройки на русский язык функция =SUM(A1:A10) автоматически становится =СУММ(A1:A10)
- Сценарий B (Использование английского): при включённой галочке функции остаются на английском независимо от локали
- Сценарий C (Совместимость с импортированными файлами): при импорте файла Excel с функциями на немецком они конвертируются в соответствии с настройкой
- Сценарий D (Поддерживаемые языки): функции доступны на 21+ языках, включая русский, немецкий, французский, испанский

**Бизнес-правила:**
- BR-SET-009: Google Sheets автоматически переводит существующие функции при изменении языка
- BR-SET-010: Разделитель аргументов зависит от локали: запятая для английского, точка с запятой для европейских языков
- BR-SET-011: Опция доступна только если язык Google аккаунта отличается от английского
- BR-SET-012: При копировании формулы между таблицами с разными языками происходит автоматическая конвертация

**Результат:** Язык названий функций в формулах изменён согласно предпочтениям пользователя

### FR-SET-004: Настройка частоты пересчёта формул (Set Recalculation Frequency)
**Описание:** Пользователь может настроить, как часто Google Sheets пересчитывает формулы, зависящие от внешних данных или времени (NOW, TODAY, IMPORTDATA, GOOGLEFINANCE).

**Роли:** Владелец, Редактор

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере
- Пользователь имеет права редактирования

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Файл" (File)
3. Выбирает "Настройки" (Settings)
4. Переходит на вкладку "Вычисления" (Calculation)
5. Находит раздел "Пересчёт" (Recalculation)
6. Видит выпадающий список с вариантами: "При изменении", "При изменении и каждую минуту", "При изменении и каждый час"
7. Выбирает нужную частоту пересчёта
8. Нажимает "Сохранить настройки"

**Альтернативные сценарии:**
- Сценарий A (При изменении): формулы пересчитываются только когда изменяются данные в ячейках, от которых они зависят
- Сценарий B (Каждую минуту): функции NOW(), GOOGLEFINANCE() и IMPORTDATA() обновляются каждую минуту
- Сценарий C (Каждый час): волатильные функции обновляются каждый час, снижая нагрузку на сервер
- Сценарий D (Влияние на производительность): частый пересчёт может замедлить работу таблиц с большим количеством формул

**Бизнес-правила:**
- BR-SET-013: Настройка пересчёта влияет только на "волатильные" функции (NOW, TODAY, RAND, RANDBETWEEN, IMPORTDATA, IMPORTHTML, IMPORTXML, IMPORTFEED, GOOGLEFINANCE)
- BR-SET-014: Обычные формулы (SUM, VLOOKUP и т.д.) всегда пересчитываются сразу при изменении зависимых ячеек
- BR-SET-015: По умолчанию установлен режим "При изменении"
- BR-SET-016: Принудительный пересчёт можно вызвать комбинацией Ctrl+Shift+F9 (Cmd+Shift+F9 на Mac)

**Результат:** Настроена частота автоматического пересчёта волатильных функций

### FR-SET-005: Настройка итеративных вычислений (Configure Iterative Calculation)
**Описание:** Пользователь может включить и настроить итеративные вычисления для разрешения циклических ссылок в формулах, указав максимальное количество итераций и порог сходимости.

**Роли:** Владелец, Редактор

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере
- Имеются формулы с циклическими ссылками или планируется их создание

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Файл" (File)
3. Выбирает "Настройки" (Settings)
4. Переходит на вкладку "Вычисления" (Calculation)
5. Находит раздел "Итеративное вычисление" (Iterative calculation)
6. Переключает опцию из "Выкл" (Off) в "Вкл" (On)
7. Устанавливает "Максимальное количество итераций" (Max number of iterations), например, 50
8. Устанавливает "Порог сходимости" (Convergence threshold), например, 0.001
9. Нажимает "Сохранить настройки"

**Альтернативные сценарии:**
- Сценарий A (Расчёт бонуса от прибыли): формула бонуса зависит от прибыли, а прибыль уменьшается на сумму бонуса - итерации находят баланс
- Сценарий B (Инженерные расчёты): решение уравнений методом последовательных приближений
- Сценарий C (Достижение порога): вычисления останавливаются, когда разница между итерациями меньше порога
- Сценарий D (Достижение лимита итераций): вычисления останавливаются после заданного числа итераций, даже если сходимость не достигнута

**Бизнес-правила:**
- BR-SET-017: По умолчанию итеративные вычисления отключены, циклические ссылки показывают ошибку #REF!
- BR-SET-018: Максимальное количество итераций определяет, сколько раз формула пересчитывается
- BR-SET-019: Порог сходимости - минимальная разница между результатами последовательных итераций для остановки
- BR-SET-020: Включение итеративных вычислений может замаскировать случайные циклические ссылки
- BR-SET-021: Рекомендуется использовать эту функцию только при намеренных циклических зависимостях

**Результат:** Включены и настроены итеративные вычисления для работы с циклическими ссылками

### FR-SET-006: Управление отображением сетки (Toggle Gridlines Display)
**Описание:** Пользователь может показать или скрыть линии сетки (gridlines) между ячейками для текущего листа таблицы.

**Роли:** Все авторизованные пользователи (настройка локальная для каждого пользователя)

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Вид" (View) в верхней панели
3. Наводит курсор на подменю "Показать" (Show)
4. Видит пункт "Сетка" (Gridlines) с галочкой (включено по умолчанию)
5. Нажимает на "Сетка" для снятия галочки
6. Линии сетки исчезают с текущего листа
7. Ячейки отображаются без видимых границ

**Альтернативные сценарии:**
- Сценарий A (Показать сетку): повторный клик на "Сетка" возвращает линии сетки
- Сценарий B (Настройка для каждого листа): изменение применяется только к активному листу, другие листы сохраняют свои настройки
- Сценарий C (Создание дашборда): скрытие сетки для создания "чистого" вида презентационных дашбордов
- Сценарий D (Использование границ ячеек): вместо сетки можно использовать форматирование границ (Borders) для выборочного отображения

**Бизнес-правила:**
- BR-SET-022: Настройка отображения сетки является локальной для каждого пользователя и не влияет на других соавторов
- BR-SET-023: Скрытие сетки не удаляет границы ячеек, установленные через форматирование
- BR-SET-024: Сетка - это визуальная подсказка, она не влияет на структуру данных
- BR-SET-025: При печати сетка отображается/скрывается в зависимости от настроек печати, а не от настроек отображения

**Результат:** Линии сетки показаны или скрыты на текущем листе

### FR-SET-007: Управление отображением заголовков строк и столбцов (Toggle Row & Column Headers)
**Описание:** Пользователь может показать или скрыть заголовки строк (1, 2, 3...) и столбцов (A, B, C...) для более чистого представления таблицы.

**Роли:** Все авторизованные пользователи (настройка локальная для каждого пользователя)

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Вид" (View)
3. Наводит курсор на подменю "Показать" (Show)
4. Видит пункт "Заголовки строк и столбцов" (Row & column headers) с галочкой
5. Нажимает на этот пункт для снятия галочки
6. Заголовки строк (числа) и столбцов (буквы) скрываются
7. Остаётся только чистая сетка данных

**Альтернативные сценарии:**
- Сценарий A (Показать заголовки): повторный клик возвращает отображение заголовков
- Сценарий B (Создание отчётов): скрытие заголовков для презентационного вида данных
- Сценарий C (Ограничение навигации): без заголовков пользователю сложнее определить адрес ячейки
- Сценарий D (Комбинация со скрытием сетки): скрытие и заголовков, и сетки для максимально "чистого" вида

**Бизнес-правила:**
- BR-SET-026: Настройка отображения заголовков является локальной для каждого пользователя
- BR-SET-027: Скрытие заголовков не влияет на возможность редактирования таблицы
- BR-SET-028: При скрытых заголовках адрес активной ячейки всё ещё отображается в строке формул
- BR-SET-029: Настройка применяется ко всей таблице (всем листам)

**Результат:** Заголовки строк и столбцов показаны или скрыты

### FR-SET-008: Настройка области печати (Set Print Area)
**Описание:** Пользователь может определить область таблицы, которая будет напечатана, выбирая между текущим листом, всей книгой или выделенным диапазоном ячеек.

**Роли:** Все авторизованные пользователи

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Таблица открыта в браузере
- Имеются данные для печати

**Основной сценарий:**
1. Пользователь открывает таблицу в Google Sheets
2. Нажимает меню "Файл" (File)
3. Выбирает "Печать" (Print) или использует Ctrl+P / Cmd+P
4. Открывается окно предпросмотра печати
5. В правой панели находит раздел "Печать" (Print)
6. Выбирает из вариантов: "Текущий лист" (Current sheet), "Книга" (Workbook), "Выбранные ячейки" (Selected cells)

**Предусловия:**
- Пользователь является администратором с правами управления шаблонами
- Доступ к консоли администратора

**Основной сценарий:**
1. Администратор входит в Google Admin Console
2. Переходит в "Приложения" → "Google Workspace" → "Диск и Документы"
3. Выбирает "Шаблоны" (Templates)
4. Настраивает режим отправки шаблонов:
   - "Открытый" - любой пользователь может добавить шаблон
   - "Модерируемый" - шаблоны требуют одобрения администратора
   - "Ограниченный" - только администраторы могут добавлять шаблоны
5. Просматривает и модерирует отправленные шаблоны
6. Нажимает "Сохранить"

**Альтернативные сценарии:**
- Сценарий A (Одобрение шаблона): при модерируемом режиме просматривает очередь и одобряет/отклоняет
- Сценарий B (Удаление шаблона): удаляет неактуальные или некачественные шаблоны из галереи
- Сценарий C (Категоризация): назначает категории шаблонам для удобной навигации
- Сценарий D (Корпоративные шаблоны): создаёт официальные шаблоны компании с брендингом

**Бизнес-правила:**
- BR-SET-106: Шаблоны организации отображаются отдельно от публичных шаблонов Google
- BR-SET-107: Удаление шаблона не влияет на документы, созданные на его основе
- BR-SET-108: Пользователи видят только шаблоны своей организации и публичные
- BR-SET-109: Администратор может настроить права на создание шаблонов по подразделениям

**Результат:** Галерея шаблонов организации настроена и модерируется

### FR-SET-027: Административное управление Connected Sheets (Admin: Configure Connected Sheets)
**Описание:** Администратор Enterprise-версии может настроить доступ к функции Connected Sheets, позволяющей подключать Google Sheets к BigQuery для анализа больших данных.

**Роли:** Администратор Google Workspace Enterprise

**Предусловия:**
- Организация использует Google Workspace Enterprise Standard/Plus или Education Plus
- Пользователь является администратором Workspace
- Настроен BigQuery для организации

**Основной сценарий:**
1. Администратор входит в Google Admin Console
2. Переходит в "Приложения" → "Google Workspace" → "Диск и Документы"
3. Выбирает "Интеграции" (Integrations) или находит раздел Connected Sheets
4. Включает или отключает Connected Sheets для организации
5. Настраивает, какие пользователи/группы имеют доступ к функции
6. Устанавливает политики безопасности для доступа к данным BigQuery
7. Нажимает "Сохранить"

**Альтернативные сценарии:**
- Сценарий A (Ограничение по OU): разрешает Connected Sheets только для отдела аналитики
- Сценарий B (Интеграция с IAM): настраивает права доступа через Google Cloud IAM
- Сценарий C (Аудит использования): просматривает логи использования Connected Sheets
- Сценарий D (Отключение функции): полностью отключает Connected Sheets для безопасности

**Бизнес-правила:**
- BR-SET-110: Connected Sheets доступен только для Enterprise и Education Plus подписок
- BR-SET-111: Требуется настроенный проект BigQuery для использования функции
- BR-SET-112: Пользователи видят только данные BigQuery, к которым имеют доступ
- BR-SET-113: Данные не копируются в Sheets, выполняются запросы к BigQuery

**Результат:** Connected Sheets настроен для организации согласно политикам безопасности

## Нефункциональные требования

### Производительность
- **NFR-SET-001:** Диалог настроек должен открываться менее чем за 1 секунду
- **NFR-SET-002:** Изменение настроек локали/часового пояса должно применяться мгновенно (до 500 мс)
- **NFR-SET-003:** Пересчёт формул при изменении настроек вычислений не должен блокировать интерфейс
- **NFR-SET-004:** Офлайн-синхронизация должна завершаться в фоновом режиме без влияния на работу

### Безопасность
- **NFR-SET-005:** Защита диапазонов должна надёжно блокировать редактирование неавторизованными пользователями
- **NFR-SET-006:** Расширения должны проходить верификацию Google перед публикацией в Marketplace
- **NFR-SET-007:** Офлайн-данные должны храниться в зашифрованном виде в кеше браузера
- **NFR-SET-008:** Административные настройки должны быть доступны только авторизованным администраторам

### Доступность
- **NFR-SET-009:** Интерфейс настроек должен быть доступен для пользователей со screen readers
- **NFR-SET-010:** Все настройки должны иметь текстовые подсказки и описания
- **NFR-SET-011:** Критичные действия должны требовать подтверждения

### Совместимость
- **NFR-SET-012:** Настройки должны синхронизироваться между веб-версией и мобильными приложениями
- **NFR-SET-013:** Экспорт в Excel должен сохранять форматирование и формулы с точностью 95%+
- **NFR-SET-014:** Офлайн-режим должен работать в Chrome версии 100+

### Локализация
- **NFR-SET-015:** Настройки должны быть доступны на всех языках, поддерживаемых Google Sheets
- **NFR-SET-016:** Функции должны корректно переводиться между языками
- **NFR-SET-017:** Форматы дат/чисел должны соответствовать выбранной локали

## Метрики успеха

### Бизнес-метрики:
- **Adoption of Settings** - процент пользователей, изменивших настройки по умолчанию
- **Offline Usage** - количество пользователей, активно использующих офлайн-режим
- **Add-on Installations** - количество установок расширений на пользователя
- **Protected Ranges Usage** - процент таблиц с защищёнными диапазонами

### Пользовательские метрики:
- **Time in Settings** - среднее время, проведённое в настройках
- **Print Success Rate** - процент успешных печатей без дополнительных настроек
- **Notification Opt-out Rate** - процент пользователей, отключивших уведомления
- **Locale Change Frequency** - частота изменения региональных настроек

### Технические метрики:
- **Settings Load Time** - время загрузки диалога настроек
- **Offline Sync Time** - время синхронизации офлайн-изменений
- **Export Success Rate** - процент успешных экспортов без ошибок
- **Protection Enforcement Rate** - процент успешных блокировок защищённых диапазонов

## Ограничения и зависимости

### Технические ограничения:
- Офлайн-режим работает только в браузерах Chrome и Edge
- Connected Sheets доступен только для Enterprise и Education Plus
- CSV экспорт поддерживает только один лист
- Защита диапазонов не является абсолютной безопасностью (данные можно скопировать)
- Некоторые функции Excel могут не конвертироваться корректно

### Платформенные ограничения:
- Мобильные приложения имеют ограниченный набор настроек
- Некоторые настройки уведомлений доступны только через веб-версию
- Административные настройки доступны только через консоль администратора

### Зависимости:
- Требуется Google аккаунт для всех функций
- Офлайн-режим требует расширение Google Docs Offline
- Connected Sheets требует настроенный BigQuery
- Корпоративные функции требуют соответствующую лицензию Workspace

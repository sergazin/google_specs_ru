# Функциональная спецификация: История версий (Google Sheets)

## Обзор модуля

Модуль "История версий" обеспечивает автоматическое сохранение всех изменений в таблице, отслеживание редакций, идентификацию авторов изменений и возможность восстановления предыдущих состояний документа. Это ключевой механизм для совместной работы и защиты данных от потери или нежелательных изменений.

---

## 1. Автоматическое сохранение

### FR-VER-001: Автоматическое сохранение изменений
Система ДОЛЖНА автоматически сохранять все изменения в таблице без необходимости ручного сохранения пользователем.

**Детали реализации:**
- Сохранение происходит автоматически при каждом изменении данных
- Отсутствует кнопка "Сохранить" - функция полностью автоматическая
- Сохраняются только внесённые изменения (инкрементальное сохранение), а не весь документ
- Статус сохранения отображается в заголовке документа

### FR-VER-002: Индикация статуса сохранения
Система ДОЛЖНА отображать текущий статус сохранения документа.

**Возможные состояния:**
- "Сохранение..." - процесс сохранения в процессе
- "Все изменения сохранены на Диске" - успешное сохранение
- "Не удалось сохранить" - ошибка сохранения (обычно из-за отсутствия интернета)

### FR-VER-003: Работа в офлайн-режиме
Система ДОЛЖНА поддерживать работу с документом при отсутствии интернет-соединения.

**Детали реализации:**
- Изменения сохраняются локально
- Синхронизация происходит автоматически при восстановлении соединения
- Пользователь информируется о работе в офлайн-режиме
- Требуется предварительное включение офлайн-режима в настройках

### FR-VER-004: Требование подключения для закрытия
Система ДОЛЖНА предупреждать пользователя, если он пытается закрыть документ с несохранёнными изменениями при отсутствии подключения к интернету.

## 2. Доступ к истории версий

### FR-VER-010: Открытие панели истории версий через меню
Система ДОЛЖНА предоставлять доступ к истории версий через меню Файл > История версий > Посмотреть историю версий.

### FR-VER-011: Быстрый доступ через клавиатурное сокращение
Система ДОЛЖНА поддерживать клавиатурные сокращения для открытия истории версий:
- Windows/ChromeOS: Ctrl + Alt + Shift + H
- macOS: Cmd + Option + Shift + H

### FR-VER-012: Доступ через индикатор последнего редактирования
Система ДОЛЖНА позволять открывать историю версий кликом на текст "Последнее изменение было..." под заголовком документа.

### FR-VER-013: Доступ через иконку часов
Система ДОЛЖНА отображать иконку часов в правом верхнем углу интерфейса для быстрого доступа к истории версий.

### FR-VER-014: Требования к правам доступа для просмотра истории
Система ДОЛЖНА предоставлять доступ к истории версий только пользователям с правами редактирования (Editor) или владельцам документа.

**Ограничения:**
- Пользователи с правами только на просмотр (Viewer) НЕ имеют доступа к истории версий
- Пользователи с правами на комментирование (Commenter) НЕ имеют доступа к истории версий

---

## 3. Отображение истории версий

### FR-VER-020: Панель истории версий
Система ДОЛЖНА отображать боковую панель с хронологическим списком всех версий документа.

**Содержимое панели:**
- Список версий в обратном хронологическом порядке (новые сверху)
- Дата и время каждой версии
- Имена редакторов для каждой версии
- Цветовая маркировка редакторов

### FR-VER-021: Группировка версий
Система ДОЛЖНА группировать версии по временным периодам для удобства навигации.

**Критерии группировки:**
- По дням (например, "Сегодня", "Вчера", конкретная дата)
- Возможность развернуть группу для просмотра детальных версий

### FR-VER-022: Сжатое отображение истории (Condensed View)
Система ДОЛЖНА по умолчанию отображать только строки с изменёнными ячейками в выбранной версии.

**Детали реализации:**
- Скрываются неизменённые строки для быстрого поиска изменений
- Доступна опция "Показать неизменённые строки" (Show unmodified rows) для просмотра полного документа
- Функция доступна с сентября 2025 года

### FR-VER-023: Предпросмотр версии
Система ДОЛЖНА отображать состояние таблицы на момент выбранной версии в основной области просмотра.

**Детали реализации:**
- При клике на версию в панели основная область показывает состояние документа
- Изменённые ячейки подсвечиваются цветом редактора
- Документ находится в режиме только для чтения при просмотре истории

## 4. Идентификация авторов изменений

### FR-VER-030: Цветовая маркировка редакторов
Система ДОЛЖНА присваивать уникальный цвет каждому редактору документа.

**Детали реализации:**
- Каждый редактор автоматически получает уникальный цвет
- Цвет используется для подсветки изменённых ячеек
- Цвет отображается рядом с именем редактора в списке версий
- Цвета назначаются системой автоматически

### FR-VER-031: Подсветка изменений по автору
Система ДОЛЖНА подсвечивать изменённые ячейки цветом редактора при просмотре версии.

**Детали реализации:**
- Ячейки, изменённые конкретным редактором, обводятся/заливаются его цветом
- Возможность включить/выключить подсветку изменений через чекбокс "Показать изменения"

### FR-VER-032: Информация о редакторе в списке версий
Система ДОЛЖНА отображать следующую информацию о редакторах для каждой версии:
- Имя редактора
- Цветовой индикатор (кружок) рядом с именем
- При наведении - email редактора (если доступен)

### FR-VER-033: Фильтрация по редактору
Система ДОЛЖНА позволять фильтровать историю версий по конкретному редактору.

**Детали реализации:**
- Опция "Показать всех пользователей" (Show all users) в верхней части панели
- Возможность снять выбор со всех пользователей
- Возможность выбрать конкретного пользователя для просмотра только его изменений

## 5. Именование версий

### FR-VER-040: Именование текущей версии
Система ДОЛЖНА позволять присваивать имя текущей версии документа.

**Способы именования:**
- Меню Файл > История версий > Назвать текущую версию
- Через контекстное меню (три точки) рядом с версией в панели истории

### FR-VER-041: Ограничение количества именованных версий
Система ДОЛЖНА ограничивать количество именованных версий:
- Для таблиц (Sheets): до 15 именованных версий
- Для документов (Docs): до 40 именованных версий

### FR-VER-042: Фильтр именованных версий
Система ДОЛЖНА предоставлять фильтр для отображения только именованных версий в списке истории.

**Детали реализации:**
- Опция "Только именованные версии" в панели истории
- Именованные версии отображаются с присвоенным именем вместо временной метки

### FR-VER-043: Редактирование имени версии
Система ДОЛЖНА позволять изменять имя ранее именованной версии.

### FR-VER-044: Удаление имени версии
Система ДОЛЖНА позволять удалять имя версии, при этом сама версия сохраняется как обычная (с временной меткой).

---

## 6. История изменений ячейки

### FR-VER-050: Просмотр истории изменений конкретной ячейки
Система ДОЛЖНА позволять просматривать историю изменений для отдельной ячейки.

**Способ доступа:**
- Правый клик на ячейке > "Показать историю изменений" (Show edit history)

### FR-VER-051: Содержимое истории ячейки
Система ДОЛЖНА отображать для каждого изменения ячейки:
- Предыдущее значение ячейки
- Новое значение ячейки
- Имя редактора, внёсшего изменение
- Дата и время изменения

### FR-VER-052: Навигация по истории ячейки
Система ДОЛЖНА предоставлять навигацию по истории изменений ячейки.

**Детали реализации:**
- Стрелки "вперёд" и "назад" для перемещения между изменениями
- Отображается самое последнее изменение по умолчанию

### FR-VER-053: Требования для просмотра истории ячейки
Система ДОЛЖНА предоставлять доступ к истории ячейки только пользователям с правами редактирования или владельцам документа.

---

## 7. Восстановление версий

### FR-VER-060: Восстановление предыдущей версии
Система ДОЛЖНА позволять восстанавливать документ до любой сохранённой версии.

**Способы восстановления:**
- Кнопка "Восстановить эту версию" в верхней части экрана при просмотре версии
- Контекстное меню (три точки) > "Восстановить эту версию"

### FR-VER-061: Сохранение полной истории при восстановлении
Система НЕ ДОЛЖНА удалять другие версии при восстановлении.

**Детали реализации:**
- Восстановленная версия становится новой "текущей" версией
- Все промежуточные версии сохраняются в истории
- Создаётся новая запись в истории версий для операции восстановления
- Возможность отменить восстановление путём восстановления другой версии

### FR-VER-062: Права на восстановление версий
Система ДОЛЖНА предоставлять возможность восстановления версий только пользователям с правами редактирования.

---

## 8. Копирование версий

### FR-VER-070: Создание копии из версии
Система ДОЛЖНА позволять создавать отдельную копию документа из любой версии в истории.

**Способ доступа:**
- Контекстное меню (три точки) рядом с версией > "Создать копию" (Make a copy)

### FR-VER-071: Свойства созданной копии
Система ДОЛЖНА создавать копию со следующими свойствами:
- Новый уникальный идентификатор файла
- Новый URL документа
- Собственная пустая история версий (начинающаяся с момента копирования)
- Отсутствие связи с оригинальным документом
- Возможность задать имя для копии

### FR-VER-072: Размещение копии
Система ДОЛЖНА позволять выбрать папку назначения для созданной копии в Google Drive.

---

## 9. Сравнение версий

### FR-VER-080: Визуальное сравнение версий
Система ДОЛЖНА подсвечивать изменения между версиями при просмотре истории.

**Детали реализации:**
- При выборе версии в панели показываются изменения относительно предыдущей версии
- Изменённые ячейки выделяются цветом редактора
- Добавленные данные выделяются зелёным
- Удалённые данные могут быть просмотрены в предыдущей версии

### FR-VER-081: Детализация группы версий
Система ДОЛЖНА позволять развернуть группу версий для просмотра более детальных изменений.

**Детали реализации:**
- Клик на стрелку рядом с датой разворачивает список отдельных правок
- Каждая правка показывает конкретные изменения этого редактирования

### FR-VER-082: Опция показа изменений
Система ДОЛЖНА предоставлять чекбокс "Показать изменения" (Show changes) для включения/выключения подсветки.

---

## 10. Хранение истории версий

### FR-VER-090: Период хранения для бесплатных аккаунтов
Система ДОЛЖНА хранить историю версий для бесплатных аккаунтов Google:
- Срок хранения: 30 дней или 100 версий (что наступит раньше)

### FR-VER-091: Период хранения для платных аккаунтов Google Workspace
Система ДОЛЖНА обеспечивать расширенное хранение истории версий для пользователей Google Workspace.

**Детали:**
- История версий хранится бессрочно
- Версии могут объединяться (merge) для экономии места хранения после 30 дней
- Именованные версии НЕ подлежат автоматическому объединению

### FR-VER-092: Объединение версий
Система МОЖЕТ автоматически объединять близкие по времени версии для оптимизации хранения.

**Детали реализации:**
- Объединение происходит для неименованных версий
- Объединение не влияет на возможность восстановления ключевых состояний
- Пользователь не управляет процессом объединения

### FR-VER-093: Хранение истории не учитывается в квоте
Система НЕ ДОЛЖНА учитывать историю версий в квоте хранилища пользователя, за исключением случаев, когда пользователь явно сохраняет старые версии.

---

## 11. Невозможность удаления истории

### FR-VER-100: Защита истории версий от удаления
Система НЕ ДОЛЖНА предоставлять возможность удаления или очистки истории версий существующего документа.

**Обоснование:**
- Защита от злонамеренного сокрытия изменений
- Обеспечение аудиторского следа
- Гарантия возможности восстановления данных

### FR-VER-101: Сброс истории через копирование
Система ДОЛЖНА позволять создать копию документа без истории версий как единственный способ "сбросить" историю.

**Последовательность действий:**
1. Файл > Создать копию
2. Копия создаётся с пустой историей версий
3. Оригинал можно удалить при необходимости

### FR-VER-102: Невозможность отключения автосохранения истории
Система НЕ ДОЛЖНА предоставлять возможность отключения функции истории версий.

---

## 12. Панель активности (Activity Dashboard)

### FR-VER-110: Просмотр активности документа
Система ДОЛЖНА предоставлять панель активности для отслеживания просмотров документа.

**Способ доступа:**
- Меню Инструменты > Панель активности (Activity Dashboard)
- Иконка графика в правом верхнем углу

### FR-VER-111: Информация о просмотрах
Система ДОЛЖНА отображать:
- Список пользователей, просмотревших документ
- Дата и время последнего просмотра каждым пользователем
- Тренд просмотров (количество просмотров по дням)

### FR-VER-112: Вкладки панели активности
Система ДОЛЖНА предоставлять следующие вкладки:
- "С кем поделились" (Shared with) - список пользователей с явным доступом
- "Все зрители" (All viewers) - все пользователи организации, просмотревшие документ

### FR-VER-113: Ограничения панели активности
Система ДОЛЖНА применять следующие ограничения:
- Функция доступна только для аккаунтов Google Workspace (Enterprise, Business, Education, Nonprofit)
- Недоступна для личных бесплатных аккаунтов
- Не отображает просмотры по публичным ссылкам ("любой со ссылкой")
- Пользователь должен иметь права редактирования для доступа к панели
- Панель доступна только для файлов внутри того же домена

### FR-VER-114: Приватность пользователя в Activity Dashboard
Система ДОЛЖНА позволять пользователям скрывать свою активность просмотра.

**Детали реализации:**
- Пользователь может отключить отображение своей активности в настройках приватности
- Скрытые пользователи отображаются с прочерком вместо времени просмотра
- Настройка влияет на все документы, просматриваемые пользователем

## 14. Google Vault (расширенное управление версиями)

### FR-VER-130: Политики хранения данных
Система ДОЛЖНА поддерживать настройку политик хранения данных через Google Vault для соответствующих тарифов.

**Типы политик:**
- Политика хранения по умолчанию - применяется ко всем данным сервиса
- Пользовательские политики хранения - для конкретных пользователей или организационных единиц

### FR-VER-131: Удержание данных (Legal Hold)
Система ДОЛЖНА поддерживать функцию удержания данных для юридических целей.

**Детали реализации:**
- Данные под удержанием не удаляются автоматически
- Применяется для расследований и судебных разбирательств
- Доступно только для Enterprise и Business Plus

### FR-VER-132: Поиск и экспорт через Vault
Система ДОЛЖНА поддерживать поиск и экспорт исторических данных через Google Vault.

**Возможности:**
- Поиск по содержимому документов
- Экспорт данных для юридических целей
- Сохранение данных после удаления пользователем (в пределах политики хранения)

## 15. Мобильные устройства

### FR-VER-140: Ограничения на мобильных устройствах
Система ДОЛЖНА применять следующие ограничения для мобильных приложений Google Sheets:

**Ограничения:**
- Полная история версий НЕ доступна в мобильном приложении
- Для доступа к полной истории версий необходимо использовать десктопный браузер
- Базовое автосохранение работает в мобильном приложении

### FR-VER-141: Альтернативы на мобильных устройствах
Система ДОЛЖНА предоставлять ограниченные возможности просмотра истории:
- Информация "Последнее изменение" доступна
- Для полного функционала рекомендуется переход на десктопную версию

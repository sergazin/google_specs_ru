# Модуль "Управление данными" - Google Sheets

## Обзор модуля

Модуль управления данными предоставляет полный набор инструментов для импорта, экспорта, анализа, фильтрации и трансформации данных в электронных таблицах Google Sheets.

---

## 1. Импорт данных

### FR-DAT-001: Импорт файлов через меню

**Описание:** Система должна позволять импортировать файлы различных форматов через меню "Файл > Импорт".

**Поддерживаемые форматы:**
- Microsoft Excel: .xls (версии новее Office 95), .xlsx, .xlsm
- Шаблоны Excel: .xlt, .xltx, .xltm
- OpenDocument: .ods
- Текстовые форматы: .csv, .txt, .tsv, .tab

**Параметры импорта:**
- Создать новую таблицу
- Вставить новые листы в текущую таблицу
- Заменить данные на текущем листе
- Добавить к текущему листу

**Источники импорта:**
- Загрузка с компьютера (Upload)
- Google Диск (My Drive)
- Общие файлы (Shared with me)
- Недавние файлы (Recent)

---

### FR-DAT-002: Настройка разделителей при импорте CSV/TXT

**Описание:** При импорте текстовых файлов система должна предоставлять выбор типа разделителя.

**Поддерживаемые разделители:**
- Автоопределение (Detect automatically) - рекомендуется для большинства случаев
- Запятая (Comma)
- Точка с запятой (Semicolon)
- Табуляция (Tab)
- Пробел (Space)
- Пользовательский разделитель (Custom)

**Дополнительные параметры:**
- Преобразование текста в числа и даты
- Сохранение как текст

---

### FR-DAT-003: Функция IMPORTDATA

**Описание:** Система должна предоставлять функцию для автоматического импорта данных из CSV или TSV файлов по URL.

**Синтаксис:**
```
=IMPORTDATA(url)
```

**Параметры:**
- `url` - URL файла CSV или TSV с указанием протокола (http:// или https://)

**Ограничения:**
- Максимум 50 000 ячеек данных за один импорт
- Поддерживаются только форматы CSV и TSV
- URL должен быть заключён в кавычки или быть ссылкой на ячейку
- Данные в других форматах (JSON, Excel) требуют предварительного преобразования

**Поведение обновления:**
- Автоматическая проверка обновлений каждый час при открытом документе
- Принудительное обновление при удалении и повторном добавлении формулы

---

### FR-DAT-004: Функция IMPORTHTML

**Описание:** Система должна предоставлять функцию для импорта данных из таблиц или списков на веб-страницах.

**Синтаксис:**
```
=IMPORTHTML(url, query, index)
```

**Параметры:**
- `url` - URL страницы с протоколом (например, https://)
- `query` - тип данных для импорта:
  - "table" - импорт HTML-таблицы
  - "list" - импорт HTML-списка (ul, ol)
- `index` - порядковый номер таблицы/списка на странице (начиная с 1)

**Ограничения:**
- Не поддерживается импорт с страниц, генерирующих контент через JavaScript
- Некоторые владельцы сайтов могут блокировать доступ к данным

**Примеры:**
```
=IMPORTHTML("https://example.com/data", "table", 1)
=IMPORTHTML(A1, "list", 2)
```

---

### FR-DAT-005: Функция IMPORTXML

**Описание:** Система должна предоставлять функцию для импорта данных из структурированных источников с использованием XPath-запросов.

**Синтаксис:**
```
=IMPORTXML(url, xpath_query)
```

**Параметры:**
- `url` - URL источника данных
- `xpath_query` - XPath-выражение для выбора нужных данных

**Поддерживаемые форматы источников:**
- XML
- HTML
- CSV
- TSV
- RSS-фиды
- ATOM-фиды

**Примеры использования:**
```
=IMPORTXML("https://example.com/page", "//h1")
=IMPORTXML(A1, "//div[@class='price']/text()")
=IMPORTXML("https://example.com/data.xml", "//item/title")
```

**Ограничения:**
- Требуется знание XPath для составления запросов
- Некоторые сайты могут блокировать доступ
- Не работает с динамически генерируемым контентом

---

### FR-DAT-006: Функция IMPORTFEED

**Описание:** Система должна предоставлять функцию для импорта данных из RSS и ATOM фидов.

**Синтаксис:**
```
=IMPORTFEED(url, [query], [headers], [num_items])
```

**Параметры:**
- `url` - URL RSS или ATOM фида (обязательный)
- `query` - тип запрашиваемых данных (необязательный, по умолчанию "items"):
  - "feed" - информация о фиде (название, описание, URL)
  - "feed title" - название фида
  - "feed description" - описание фида
  - "feed author" - автор фида
  - "feed url" - URL фида
  - "items" - все элементы фида
  - "items title" - заголовки элементов
  - "items summary" - краткое описание
  - "items url" - ссылки на элементы
  - "items created" - даты создания
- `headers` - включить заголовки столбцов (TRUE/FALSE, по умолчанию FALSE)
- `num_items` - количество возвращаемых элементов (начиная с последних)

**Примеры:**
```
=IMPORTFEED("https://news.google.com/?output=atom")
=IMPORTFEED("https://example.com/rss", "items title", TRUE, 5)
=IMPORTFEED(A1, "feed")
```

**Практическое применение:**
- Агрегация новостей из различных источников
- Мониторинг отраслевых публикаций
- Отслеживание обновлений конкурентов
- Мониторинг научных публикаций

---

### FR-DAT-007: Функция IMPORTRANGE

**Описание:** Система должна предоставлять функцию для импорта данных из другой таблицы Google Sheets.

**Синтаксис:**
```
=IMPORTRANGE(spreadsheet_url, range_string)
```

**Параметры:**
- `spreadsheet_url` - URL исходной таблицы или её идентификатор
- `range_string` - диапазон для импорта в формате "Лист!A1:C10" или "A1:C10"

**Примеры:**
```
=IMPORTRANGE("https://docs.google.com/spreadsheets/d/abc123/edit", "Лист1!A1:D100")
=IMPORTRANGE("abc123defg456", "Данные!B:B")
=IMPORTRANGE(A1, B1)
```

**Особенности:**
- Требует первоначального разрешения доступа от пользователя
- Работает только с таблицами Google Sheets
- Требуется подключение к интернету
- Ограничение на получение данных: 10 МБ за один запрос

**Авторизация:**
- При первом использовании появляется запрос на разрешение доступа
- После авторизации связь сохраняется для всех пользователей документа

---

### FR-DAT-008: Подтверждение доступа для IMPORT-функций

**Описание:** При ручном добавлении или редактировании функций IMPORTHTML, IMPORTDATA, IMPORTFEED, IMPORTXML и IMPORTRANGE система должна запрашивать подтверждение пользователя.

**Поведение:**
- Отображение предупреждающего баннера
- Блокировка отправки и получения данных до получения согласия
- Однократное подтверждение для каждого документа

**Ограничения IMPORT-функций:**
- Нельзя использовать ссылки на волатильные функции (NOW, RAND, RANDBETWEEN)
- Это ограничение предотвращает избыточную нагрузку на систему

## 3. Функция QUERY

### FR-DAT-012: Базовый синтаксис QUERY

**Описание:** Система должна предоставлять функцию QUERY для выполнения SQL-подобных запросов к данным.

**Синтаксис:**
```
=QUERY(data, query, [headers])
```

**Параметры:**
- `data` - диапазон данных для запроса
- `query` - строка запроса на языке Google Visualization API Query Language
- `headers` - количество строк заголовков (необязательный)

---

### FR-DAT-013: Клаузы SELECT в QUERY

**Описание:** Система должна поддерживать клаузу SELECT для выбора столбцов.

**Возможности:**
- Выбор конкретных столбцов: `SELECT A, B, C`
- Выбор всех столбцов: `SELECT *`
- Изменение порядка столбцов: `SELECT C, A, B`
- Ссылка на столбцы: по буквам (A, B, C) или Col1, Col2, Col3

**Примеры:**
```
=QUERY(A1:E100, "SELECT A, C, E")
=QUERY(A1:E100, "SELECT *")
```

---

### FR-DAT-014: Клауза WHERE в QUERY

**Описание:** Система должна поддерживать клаузу WHERE для фильтрации данных.

**Операторы сравнения для чисел:**
- `=` - равно
- `<>` или `!=` - не равно
- `>` - больше
- `>=` - больше или равно
- `<` - меньше
- `<=` - меньше или равно

**Операторы для текста:**
- `contains` - содержит подстроку
- `starts with` - начинается с
- `ends with` - заканчивается на
- `matches` - соответствует регулярному выражению
- `like` - соответствует шаблону с % и _

**Логические операторы:**
- `AND` - логическое И
- `OR` - логическое ИЛИ
- `NOT` - логическое отрицание

**Примеры:**
```
=QUERY(A1:D100, "SELECT * WHERE B > 100")
=QUERY(A1:D100, "SELECT * WHERE A contains 'Москва'")
=QUERY(A1:D100, "SELECT * WHERE B > 50 AND C < 200")
=QUERY(A1:D100, "SELECT * WHERE A starts with 'А' OR A starts with 'Б'")
```

---

### FR-DAT-015: Клауза ORDER BY в QUERY

**Описание:** Система должна поддерживать клаузу ORDER BY для сортировки результатов.

**Синтаксис:**
```
ORDER BY column [ASC|DESC] [, column2 [ASC|DESC], ...]
```

**Параметры:**
- `ASC` - сортировка по возрастанию (по умолчанию)
- `DESC` - сортировка по убыванию
- Поддержка сортировки по нескольким столбцам

**Примеры:**
```
=QUERY(A1:D100, "SELECT * ORDER BY B DESC")
=QUERY(A1:D100, "SELECT * ORDER BY A ASC, B DESC")
```

---

### FR-DAT-016: Клауза GROUP BY в QUERY

**Описание:** Система должна поддерживать клаузу GROUP BY для группировки данных с агрегатными функциями.

**Агрегатные функции:**
- `SUM()` - сумма
- `AVG()` - среднее
- `COUNT()` - количество
- `MAX()` - максимум
- `MIN()` - минимум

**Примеры:**
```
=QUERY(A1:C100, "SELECT A, SUM(B) GROUP BY A")
=QUERY(A1:C100, "SELECT A, AVG(B), MAX(C) GROUP BY A")
```

---

### FR-DAT-017: Клауза PIVOT в QUERY

**Описание:** Система должна поддерживать клаузу PIVOT для создания перекрёстных таблиц.

**Синтаксис:**
```
PIVOT column
```

**Пример:**
```
=QUERY(A1:D100, "SELECT A, SUM(C) GROUP BY A PIVOT B")
```

---

### FR-DAT-018: Клаузы LIMIT и OFFSET в QUERY

**Описание:** Система должна поддерживать ограничение и смещение результатов.

**Синтаксис:**
- `LIMIT n` - вернуть первые n строк
- `OFFSET n` - пропустить первые n строк

**Примеры:**
```
=QUERY(A1:D100, "SELECT * LIMIT 10")
=QUERY(A1:D100, "SELECT * ORDER BY B DESC LIMIT 5")
=QUERY(A1:D100, "SELECT * LIMIT 10 OFFSET 5")
```

---

### FR-DAT-019: Клауза LABEL в QUERY

**Описание:** Система должна поддерживать переименование заголовков столбцов в результатах.

**Синтаксис:**
```
LABEL column 'новое_название'
```

**Пример:**
```
=QUERY(A1:C100, "SELECT A, SUM(B) GROUP BY A LABEL A 'Категория', SUM(B) 'Итого'")
```

---

### FR-DAT-020: Работа с датами в QUERY

**Описание:** Система должна поддерживать специальный синтаксис для работы с датами.

**Синтаксис даты:**
```
date 'YYYY-MM-DD'
```

**Примеры:**
```
=QUERY(A1:D100, "SELECT * WHERE A > date '2025-01-15'")
=QUERY(A1:D100, "SELECT * WHERE A >= date '2025-01-01' AND A <= date '2025-12-31'")
```

---

### FR-DAT-021: Объединение данных в QUERY

**Описание:** Система должна позволять объединять данные из разных диапазонов и листов.

**Синтаксис объединения:**
```
{диапазон1; диапазон2}
```

**Примеры:**
```
=QUERY({Лист1!A:C; Лист2!A:C}, "SELECT * WHERE Col1 IS NOT NULL")
=QUERY({'Продажи 2024'!A:D; 'Продажи 2025'!A:D}, "SELECT Col1, SUM(Col4) GROUP BY Col1")
```

## 4. Сводные таблицы (Pivot Tables)

### FR-DAT-022: Создание сводной таблицы

**Описание:** Система должна позволять создавать сводные таблицы для анализа данных.

**Способы создания:**
- Меню: Вставка > Сводная таблица
- Контекстное меню на выделенном диапазоне

**Параметры создания:**
- Выбор исходного диапазона данных
- Размещение: новый лист / существующий лист

**Требования к данным:**
- Каждый столбец должен иметь заголовок
- Данные должны быть одного типа в каждом столбце
- Не должно быть пустых строк между данными

- Группировка по значениям

### FR-DAT-024: Настройка столбцов сводной таблицы

- VARP - дисперсия генеральной совокупности

**Опции отображения:**
- По умолчанию
- % от общего итога по строке
- % от общего итога по столбцу
- % от общего итога

## 5. Фильтры и представления фильтров

### FR-DAT-031: Создание фильтра

**Описание:** Система должна позволять создавать фильтры для отображения подмножества данных.

**Способы создания:**
- Меню: Данные > Создать фильтр
- Горячие клавиши: Ctrl+Shift+L (Windows) / Cmd+Shift+L (Mac)

### FR-DAT-052: Функция SPLIT

**Описание:** Система должна предоставлять функцию для разделения текста формулой.

**Синтаксис:**
```
=SPLIT(text, delimiter, [split_by_each], [remove_empty_text])
```

**Параметры:**
- `text` - текст для разделения
- `delimiter` - разделитель (один или несколько символов)

**Примеры:**

# AI-функции и Gemini в Google Sheets

## Executive Summary

### Overview
Модуль AI-функций Google Sheets представляет собой интегрированную систему искусственного интеллекта на базе Gemini, позволяющую пользователям автоматизировать анализ данных, генерировать текст, категоризировать информацию и получать инсайты непосредственно в ячейках таблицы. Запущенный в 2025 году, модуль стал одной из самых быстро адаптируемых функций Google, обеспечивая до 50% повышения эффективности работы с данными.

### Key Features
- **=AI() / =Gemini() функция**: Формулы для генерации текста, анализа и категоризации данных прямо в ячейках
- **Gemini Sidebar**: Боковая панель для диалогового анализа данных и получения инсайтов
- **Smart Fill**: Интеллектуальное заполнение данных на основе распознавания паттернов
- **Explore Tool**: Автоматический анализ данных с предложениями диаграмм и сводных таблиц
- **Multi-Step Tasks**: Выполнение сложных многоэтапных операций по одному запросу

### Business Value
- Сокращение времени на анализ данных на 40-50%
- Автоматизация рутинных задач категоризации и очистки данных
- Демократизация аналитики для пользователей без технических навыков
- Повышение качества принятия решений благодаря AI-инсайтам
- Мультиязычная поддержка (7+ языков с августа 2025)

### Target Audience
- **Маркетологи**: Анализ кампаний, категоризация отзывов, генерация контента
- **Аналитики данных**: Быстрый EDA, визуализация трендов, аномалии
- **Бизнес-пользователи**: Отчеты, сводки, автоматизация рутины
- **Sales-менеджеры**: Анализ воронки, категоризация лидов, прогнозы

## Описание модуля

Модуль AI-функций интегрирует возможности Gemini AI непосредственно в Google Sheets, предоставляя:
1. **Функции в ячейках** (=AI(), =Gemini()) для обработки данных промптами
2. **Боковую панель Gemini** для диалогового анализа и генерации
3. **Интеллектуальные инструменты** (Smart Fill, Explore) для автоматизации
4. **Многошаговые операции** для комплексных трансформаций данных

## Роли пользователей

- **Пользователь** - может использовать все AI-функции в рамках своей подписки
- **Администратор Google Workspace** - управляет политиками использования AI в организации
- **Редактор таблицы** - имеет доступ к AI-функциям при наличии подписки

## Требования к подписке

AI-функции доступны для пользователей с:
- Google Workspace с Gemini Business
- Google Workspace с Gemini Enterprise
- Google One AI Premium ($19.99/месяц)
- Gemini Education / Education Premium
- Google AI Pro / AI Ultra

## Функциональные требования

### FR-AI-001: Функция =AI() для генерации текста

**Приоритет:** P0 (Critical)

**Описание:** Использование формулы =AI() или =Gemini() для генерации текстового контента на основе промпта и данных таблицы

**Роли:** Пользователь

**User Stories:**

**Маркетолог:**
> "Как маркетолог, я хочу автоматически генерировать рекламные тексты для продуктов на основе их характеристик в таблице, чтобы ускорить создание кампаний и не писать каждый текст вручную"

**Контент-менеджер:**
> "Как контент-менеджер, я хочу создавать email-тексты для клиентов на основе данных их обращений, чтобы персонализировать коммуникацию без ручного написания каждого письма"

**Предусловия:**
- Пользователь имеет активную подписку с Gemini
- Таблица открыта в Google Sheets
- Данные для генерации присутствуют в указанных ячейках

**Основной сценарий:**
1. Пользователь вводит в ячейку формулу =AI() с промптом
2. Формат: =AI("промпт", [опциональный_диапазон])
3. Система передает промпт и данные диапазона в Gemini AI
4. AI анализирует контекст:
   - Содержимое указанного диапазона
   - Заголовки столбцов для понимания структуры
   - Историю таблицы для контекста
5. AI генерирует текстовый ответ
6. Результат отображается в ячейке как текст
7. Ячейка обновляется при изменении исходных данных

**Примеры использования:**

```
=AI("Напиши рекламный слоган для продукта в 10 слов", A2)
=AI("Создай email для клиента с ответом на отзыв", A2:G2)
=AI("Сгенерируй описание товара для маркетплейса", B2:D2)
=AI("Write a formal ad copy for the product. Cater to the objective and target audience", A2:C2)
```

**Альтернативные сценарии:**
- Сценарий А (=Gemini()): Пользователь использует =Gemini() вместо =AI() - функции идентичны
- Сценарий Б (без диапазона): =AI("промпт") работает только с промптом без данных таблицы
- Сценарий В (ошибка лимита): При достижении лимита генерации показывается ошибка, повтор через 24 часа
- Сценарий Г (горячая клавиша): После ввода = нажатие Ctrl+Alt+G (Windows) или Cmd+Ctrl+G (Mac) вызывает AI-генерацию

**Acceptance Criteria:**
- [ ] Формула =AI() принимает текстовый промпт как первый аргумент
- [ ] Формула =Gemini() работает идентично =AI()
- [ ] Опциональный второй аргумент принимает диапазон ячеек
- [ ] Результат отображается как текст в ячейке
- [ ] Генерация происходит за <3 секунды для простых запросов
- [ ] При изменении исходных данных результат обновляется
- [ ] Поддержка русского, английского и 5+ других языков
- [ ] Ошибки отображаются понятным сообщением в ячейке
- [ ] Лимит 350 ячеек с AI-функциями за одну генерацию

**Бизнес-правила:**
- BR-AI-001: Максимум 350 ячеек с AI-функциями генерируются одновременно
- BR-AI-002: Существует краткосрочный и долгосрочный лимит генерации
- BR-AI-003: При достижении долгосрочного лимита - ожидание 24 часа
- BR-AI-004: Кастомная функция с именем "=AI()" переопределяется системной
- BR-AI-005: Вложенные AI-функции не поддерживаются (=IF(AI()...))

**Ограничения:**
- Встроенные AI-функции внутри других формул не работают
- Нельзя использовать =IF(AI("sentiment", A2), "negative", 0)
- Только первые 350 выбранных ячеек с AI генерируются

**Метрики:**

| Метрика | Целевое значение | Описание |
|---------|------------------|----------|
| Время генерации | <3 сек | Среднее время ответа для простых промптов |
| Точность ответов | >80% релевантных | Соответствие промпту |
| Использование функции | >30% Workspace пользователей | Адаптация в первый год |
| Отключение функции | <5% | Пользователи, отключившие AI |

**Результат:** Текст сгенерирован AI на основе промпта и данных таблицы

### FR-AI-002: Суммаризация информации через =AI()

**Приоритет:** P0 (Critical)

**Описание:** Использование AI-функции для создания кратких сводок из больших объемов данных

**Роли:** Пользователь

**User Stories:**

**Аналитик:**
> "Как аналитик данных, я хочу автоматически получать краткие выводы из таблиц с сотнями строк, чтобы быстро понимать ключевые паттерны без ручного анализа"

**Менеджер:**
> "Как руководитель проекта, я хочу получать сводку по статусам задач из большой таблицы, чтобы быстро оценивать прогресс команды"

**Предусловия:**
- AI-функция доступна
- Данные для суммаризации присутствуют в таблице

**Основной сценарий:**
1. Пользователь выделяет диапазон с данными для анализа
2. Вводит формулу: =AI("Подведи итоги этих данных", A2:G100)
3. Gemini анализирует содержимое диапазона
4. AI извлекает ключевые takeaways:
   - Основные числовые показатели
   - Преобладающие категории
   - Выявленные тренды
   - Аномалии и исключения
5. Результат возвращается как структурированный текст
6. Сводка отображается в целевой ячейке

**Примеры использования:**

```
=AI("Summarize key findings from this sales data", A2:F50)
=AI("Выдели 3 главных вывода из отзывов клиентов", B2:B100)
=AI("What are the main themes in this feedback?", C2:C500)
```

**Альтернативные сценарии:**
- Сценарий А (большой диапазон): Для >1 млн ячеек производительность снижается
- Сценарий Б (пустые данные): AI сообщает об отсутствии данных для анализа
- Сценарий В (смешанные типы): AI адаптируется к комбинации текста и чисел

**Acceptance Criteria:**
- [ ] AI извлекает ключевые показатели из числовых данных
- [ ] AI определяет преобладающие категории из текстовых данных
- [ ] Сводка структурирована и читаема
- [ ] Работает с диапазонами до 1 млн ячеек (с предупреждением о производительности)
- [ ] Поддержка мультиязычных данных

**Бизнес-правила:**
- BR-AI-006: Для файлов >1 млн ячеек производительность может снижаться
- BR-AI-007: Сводка ограничена объемом вывода одной ячейки
- BR-AI-008: AI не раскрывает конфиденциальные данные в сводках

**Результат:** Краткая сводка ключевых выводов из данных таблицы

### FR-AI-003: Категоризация данных через =AI()

**Приоритет:** P0 (Critical)

**Описание:** Автоматическая классификация текстовых данных по категориям с помощью AI

**Роли:** Пользователь

**User Stories:**

**Маркетолог:**
> "Как маркетолог, я хочу автоматически категоризировать тысячи отзывов клиентов по темам (цена, качество, доставка), чтобы быстро понять основные проблемы"

**HR-специалист:**
> "Как HR-менеджер, я хочу классифицировать резюме кандидатов по уровню (Junior, Middle, Senior), чтобы ускорить первичный скрининг"

**Предусловия:**
- Данные для категоризации в таблице
- Определены категории (явно в промпте или AI определит сам)

**Основной сценарий:**
1. Пользователь вводит формулу с промптом категоризации
2. Формат: =AI("Категоризируй как [категория1, категория2, ...]", ячейка)
3. AI анализирует текст в указанной ячейке
4. AI определяет наиболее подходящую категорию
5. Категория возвращается как текст в ячейке результата
6. Пользователь протягивает формулу на весь столбец

**Примеры использования:**

```
=AI("Classify this review as Positive, Negative, or Neutral", A2)
=AI("Categorize expense as Travel, Software, Marketing, or Other", B2)
=AI("Определи тип обращения: Вопрос, Жалоба, Благодарность, Предложение", C2)
=AI("Categorize performance as Excellent, Good, Average, or Poor based on ROAS", A2:H2)
```

**Альтернативные сценарии:**
- Сценарий А (без предопределенных категорий): AI сам определяет подходящие категории
- Сценарий Б (множественные категории): AI может присвоить несколько меток через запятую
- Сценарий В (неопределенность): AI возвращает "Не определено" при невозможности классификации

**Acceptance Criteria:**
- [ ] AI корректно классифицирует по заданным категориям
- [ ] Точность категоризации >85% для типовых задач
- [ ] Поддержка пользовательских категорий в промпте
- [ ] Возможность множественной категоризации
- [ ] Консистентность результатов при повторном запуске

**Бизнес-правила:**
- BR-AI-009: AI использует только указанные категории, если они заданы
- BR-AI-010: При отсутствии категорий AI создает их на основе паттернов данных
- BR-AI-011: Результат категоризации детерминирован для одинаковых входных данных

**Результат:** Данные классифицированы по категориям автоматически

### FR-AI-004: Анализ настроений (Sentiment Analysis)

**Приоритет:** P1 (High)

**Описание:** Определение эмоциональной окраски текста (позитивный, негативный, нейтральный)

**Роли:** Пользователь

**User Stories:**

**Продакт-менеджер:**
> "Как продакт-менеджер, я хочу автоматически анализировать тональность отзывов на наш продукт, чтобы отслеживать динамику удовлетворенности клиентов"

**SMM-специалист:**
> "Как SMM-специалист, я хочу определять настроение комментариев в соцсетях, чтобы оперативно реагировать на негатив"

**Предусловия:**
- Текстовые данные для анализа в таблице

**Основной сценарий:**
1. Пользователь вводит формулу анализа настроений
2. =AI("Analyze sentiment", A2) или =AI("Определи тональность", A2)
3. AI анализирует текст на:
   - Эмоциональные маркеры (слова, фразы)
   - Контекст высказывания
   - Сарказм и иронию (в меру возможностей)
4. AI возвращает результат: Positive, Negative, Neutral
5. Опционально: числовая оценка от -1 до +1

**Примеры использования:**

```
=AI("Classify this review as Positive, Negative, or Neutral", A2)
=AI("Rate sentiment from -1 (very negative) to +1 (very positive)", B2)
=AI("Analyze sentiment and explain in one sentence", C2)
=AI("Определи тональность: Позитивная, Негативная, Нейтральная", D2)
```

**Альтернативные сценарии:**
- Сценарий А (смешанный сентимент): AI указывает "Mixed" или возвращает доминирующий
- Сценарий Б (многоязычный текст): AI работает с текстом на любом из поддерживаемых языков
- Сценарий В (короткий текст): Для очень коротких текстов AI может вернуть "Недостаточно данных"

**Acceptance Criteria:**
- [ ] Корректное определение Positive/Negative/Neutral в >85% случаев
- [ ] Поддержка числовой шкалы сентимента
- [ ] Работа с текстами на 7+ языках
- [ ] Возможность получить объяснение оценки
- [ ] Обработка смешанных сентиментов

**Бизнес-правила:**
- BR-AI-012: По умолчанию возвращается одна из трех категорий: Positive, Negative, Neutral
- BR-AI-013: Числовая оценка требует явного указания в промпте
- BR-AI-014: AI учитывает контекст, а не только отдельные слова

**Пример workflow анализа отзывов:**

1. Экспортировать отзывы в столбец A
2. В столбце B: =AI("Classify as Positive, Negative, Neutral", A2)
3. Протянуть формулу на все строки
4. Использовать COUNTIF для статистики:
   - =COUNTIF(B:B, "Positive") -> 312
   - =COUNTIF(B:B, "Neutral") -> 156
   - =COUNTIF(B:B, "Negative") -> 32

**Результат:** Тональность текста определена и классифицирована

### FR-AI-005: Доступ к актуальной информации через Google Search

**Приоритет:** P1 (High)

**Описание:** AI-функция с интеграцией Google Search для получения актуальных данных из интернета

**Роли:** Пользователь

**User Stories:**

**Финансовый аналитик:**
> "Как финансовый аналитик, я хочу получать актуальные курсы валют и биржевые данные прямо в таблице, чтобы автоматизировать обновление отчетов"

**Исследователь:**
> "Как исследователь рынка, я хочу автоматически собирать актуальную информацию о компаниях-конкурентах, чтобы не искать данные вручную"

**Предусловия:**
- AI-функция с доступом к Google Search (доступна с октября 2025)
- Пользователь имеет активную подписку

**Основной сценарий:**
1. Пользователь вводит формулу с вопросом, требующим актуальных данных
2. =AI("What is the current market cap of [company]?", A2)
3. AI определяет, что нужен поиск в интернете
4. Gemini выполняет Google Search
5. AI обрабатывает результаты поиска
6. Актуальная информация возвращается в ячейку
7. Данные обновляются при пересчете таблицы

**Примеры использования:**

```
=AI("Daily box office for newly released movies")
=AI("Market sentiment for product launch of " & A2)

=AI("Current weather in " & C2)
```

**Альтернативные сценарии:**
- Сценарий А (данные недоступны): AI сообщает об отсутствии актуальной информации
- Сценарий Б (противоречивые источники): AI указывает на расхождение данных
- Сценарий В (офлайн): Без интернета функция возвращает ошибку

**Acceptance Criteria:**
- [ ] AI корректно определяет необходимость поиска в интернете
- [ ] Результаты актуальны на момент запроса
- [ ] Источники информации надежны
- [ ] Ответ форматирован для отображения в ячейке
- [ ] Время ответа <5 секунд для поисковых запросов

**Бизнес-правила:**
- BR-AI-015: Google Search интеграция доступна с октября 2025
- BR-AI-016: AI использует только проверенные источники
- BR-AI-017: Данные не кешируются, каждый запрос актуален

**Результат:** Актуальная информация из интернета получена в ячейке таблицы

### FR-AI-006: Gemini Sidebar для диалогового анализа

**Приоритет:** P0 (Critical)

**Описание:** Боковая панель Gemini для интерактивного анализа данных через естественный язык

**Роли:** Пользователь

**User Stories:**

**Бизнес-аналитик:**
> "Как бизнес-аналитик без навыков программирования, я хочу задавать вопросы о данных на естественном языке и получать визуализации, чтобы быстро находить инсайты без написания формул"

**Руководитель:**
> "Как руководитель отдела, я хочу задать вопрос 'Какой тренд продаж за последние 6 месяцев?' и получить готовый график, чтобы не тратить время на ручное построение"

**Предусловия:**
- Пользователь авторизован с подпиской Gemini
- Таблица с данными открыта

**Основной сценарий:**
1. Пользователь кликает кнопку "Ask Gemini" (иконка искры) в правом верхнем углу
2. Открывается боковая панель Gemini справа
3. Пользователь вводит вопрос на естественном языке
4. Gemini анализирует:
   - Структуру данных в таблице
   - Заголовки столбцов
   - Типы данных
   - Контекст вопроса
5. Gemini генерирует ответ:
   - Текстовый анализ с выводами
   - Предложения диаграмм
   - Предложения формул
   - Сводные таблицы

### FR-AI-014: Автоматическая очистка данных

**Приоритет:** P2 (Medium)

**Описание:** AI-assisted очистка и нормализация данных

**Роли:** Пользователь

**User Stories:**

**Data Analyst:**
> "Как аналитик данных, я хочу автоматически очищать импортированные данные от дубликатов, пустых строк и несогласованных форматов, чтобы ускорить подготовку данных к анализу"

**Предусловия:**
- Данные с проблемами качества в таблице
- Gemini доступен

**Основной сценарий:**
1. Пользователь открывает Gemini Sidebar
2. Просит: "Clean up this data" или "Очисти эти данные"
3. Gemini анализирует данные и выявляет:
   - Дубликаты строк
   - Пустые/неполные строки
   - Несогласованные форматы (даты, числа)
   - Лишние пробелы
   - Опечатки в категориальных данных
4. Gemini предлагает план очистки
5. Пользователь подтверждает или корректирует
6. Gemini выполняет очистку
7. Отображается отчет о выполненных изменениях

| Несогласованные даты | Приведение к единому формату |
| Лишние пробелы | TRIM для всех текстовых ячеек |
| Разные написания | Унификация (NY, New York -> New York) |

**Альтернативные сценарии:**
- Сценарий А (выборочная очистка): Пользователь указывает конкретные проблемы для исправления
- Сценарий Б (preview): Gemini показывает изменения перед применением
- Сценарий В (отчет): Пользователь получает детальный отчет об изменениях

**Acceptance Criteria:**
- [ ] Автоматическое выявление проблем качества данных
- [ ] Предложения по очистке перед выполнением
- [ ] Поддержка основных операций очистки
- [ ] Сохранение оригинальных данных (версионирование)
- [ ] Отчет о выполненных изменениях

**Бизнес-правила:**
- BR-AI-044: Деструктивные операции требуют подтверждения
- BR-AI-045: Версия до очистки сохраняется в истории
- BR-AI-046: Smart Fill дополняет очистку для текстовых данных

**Результат:** Данные очищены и нормализованы с помощью AI

## Сущности данных

### AI-запрос
- **RequestID** - уникальный идентификатор запроса
- **UserID** - идентификатор пользователя
- **SpreadsheetID** - идентификатор таблицы
- **Prompt** - текст промпта
- **DataRange** - диапазон данных (если указан)
- **RequestType** - тип (generate, summarize, categorize, etc.)
- **Response** - ответ AI
- **Timestamp** - время запроса
- **ProcessingTime** - время обработки
- **Status** - успех/ошибка/лимит

### AI-генерация в ячейке
- **CellReference** - адрес ячейки
- **Formula** - формула =AI() или =Gemini()
- **GeneratedValue** - результат генерации
- **LastUpdated** - время последнего обновления
- **ErrorState** - состояние ошибки (если есть)

### Сессия Gemini Sidebar
- **SessionID** - идентификатор сессии
- **ConversationHistory** - история диалога
- **ContextData** - контекст таблицы
- **GeneratedArtifacts** - созданные артефакты (диаграммы, формулы)

## Ограничения и лимиты

### Лимиты AI-функций
- Максимум 350 ячеек с AI-функциями за одну генерацию
- Краткосрочный лимит генерации (детали не публикуются)
- Долгосрочный лимит: при достижении - ожидание 24 часа
- Рекомендуемый размер файла для анализа: <1 млн ячеек

### Лимиты Gemini Sidebar
- Оптимальная производительность для файлов <1 млн ячеек
- Длина промпта ограничена (детали не публикуются)
- Контекст диалога сохраняется в рамках сессии

### Ограничения диаграмм
- Диаграммы, созданные Gemini, статичны (не обновляются автоматически)
- Для обновления нужна регенерация

### Языковая поддержка
- =AI() функция поддерживает 7+ языков (с августа 2025):
  - Английский
  - Испанский
  - Португальский
  - Японский
  - Корейский
  - Итальянский
  - Французский
  - Немецкий

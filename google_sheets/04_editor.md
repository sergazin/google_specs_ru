## 1. Редактирование ячеек

### FR-EDT-001: Ввод данных в пустую ячейку
Система должна позволять пользователю вводить данные в пустую ячейку одним кликом по ячейке с последующим набором текста.

### FR-EDT-002: Редактирование непустой ячейки
Система должна позволять редактировать содержимое непустой ячейки двойным кликом по ней или нажатием клавиши F2.

### FR-EDT-003: Редактирование в строке формул
Система должна предоставлять строку формул для просмотра и редактирования содержимого выбранной ячейки.

### FR-EDT-004: Многострочный ввод
Система должна поддерживать многострочный ввод в одной ячейке при нажатии:
- Ctrl + Enter (Windows/Linux)
- Cmd + Enter (macOS)

### FR-EDT-005: Завершение ввода
Система должна завершать редактирование ячейки при:
- Нажатии Enter (переход к ячейке ниже)
- Нажатии Tab (переход к ячейке справа)
- Нажатии Escape (отмена изменений)
- Клике на другую ячейку

### FR-EDT-006: Отмена и повтор действий
Система должна поддерживать отмену (Ctrl/Cmd + Z) и повтор (Ctrl/Cmd + Y) действий с сохранением истории изменений.

### FR-EDT-007: Копирование и вставка
Система должна поддерживать операции:
- Копирование (Ctrl/Cmd + C)
- Вырезание (Ctrl/Cmd + X)
- Вставка (Ctrl/Cmd + V)
- Специальная вставка (Ctrl/Cmd + Shift + V) - только значения без форматирования

### FR-EDT-008: Выделение диапазона ячеек
Система должна позволять выделять:
- Одну ячейку (клик)
- Диапазон ячеек (клик и перетаскивание)
- Несмежные ячейки (Ctrl/Cmd + клик)
- Целую строку (клик по номеру строки)
- Целый столбец (клик по букве столбца)
- Весь лист (Ctrl/Cmd + A)

### FR-EDT-009: Перемещение содержимого
Система должна позволять перемещать содержимое ячеек методом drag-and-drop с автоматическим сдвигом данных.

### FR-EDT-010: Удаление содержимого
Система должна позволять удалять:
- Только содержимое ячейки (Delete/Backspace)
- Ячейку со сдвигом данных
- Форматирование (через меню "Формат" > "Очистить форматирование")

## 2. Типы данных

### FR-EDT-011: Автоматическое определение типа данных
Система должна автоматически определять тип вводимых данных:
- Текст
- Числа
- Даты
- Время
- Валюта
- Проценты
- Логические значения (TRUE/FALSE)

### FR-EDT-012: Текстовый формат
Система должна поддерживать текстовый формат данных со следующими возможностями:
- Хранение текста любой длины
- Поддержка Unicode символов
- Принудительное преобразование в текст (префикс ')

### FR-EDT-013: Числовой формат
Система должна поддерживать числовой формат:
- Целые числа
- Десятичные дроби
- Отрицательные числа
- Научная нотация (1.23E+10)
- Настраиваемое количество десятичных знаков (0-30)

### FR-EDT-014: Формат валюты
Система должна поддерживать форматирование валюты:
- Предустановленные валюты (USD, EUR, RUB, GBP и др.)
- Позиция символа валюты (до/после числа)
- Разделитель тысяч
- Настраиваемые десятичные знаки
- Пользовательские форматы валюты

### FR-EDT-015: Формат даты
Система должна поддерживать форматы дат:
- Краткий формат (01.01.2026)
- Длинный формат (1 января 2026 г.)
- ISO формат (2026-01-15)
- Американский формат (01/15/2026)
- Пользовательские форматы дат (д.М.гггг, дд-ммм-гг и др.)

### FR-EDT-016: Формат времени
Система должна поддерживать форматы времени:
- 12-часовой формат (2:30 PM)
- 24-часовой формат (14:30)
- Время с секундами (14:30:45)
- Комбинация даты и времени
- Длительность (чч:мм:сс)

### FR-EDT-017: Процентный формат
Система должна поддерживать процентный формат:
- Автоматическое умножение на 100 при отображении
- Настраиваемые десятичные знаки
- Символ процента (%)

### FR-EDT-018: Пользовательские числовые форматы
Система должна поддерживать создание пользовательских форматов с синтаксисом:
- До 4 секций: [положительные];[отрицательные];[ноль];[текст]
- Цветовые коды: [Red], [Blue], [Green], [Magenta] и др.
- Форматы: #,##0.00; 0.00%; #,##0" руб."
- Условное форматирование чисел: [>1000]#,##0"K";#,##0

## 3. Форматирование текста

### FR-EDT-019: Выбор шрифта
Система должна предоставлять выбор шрифта из списка доступных шрифтов:
- Стандартные шрифты (Arial, Times New Roman, Verdana и др.)
- Google Fonts
- Системные шрифты устройства

### FR-EDT-020: Размер шрифта
Система должна позволять изменять размер шрифта:
- Предустановленные размеры (8, 9, 10, 11, 12, 14, 16, 18, 20, 22, 24, 26, 28, 36, 48, 72)
- Произвольный размер (ввод вручную)
- Диапазон: от 6 до 400 пунктов

### FR-EDT-021: Начертание шрифта
Система должна поддерживать стили начертания:
- Полужирный (Ctrl/Cmd + B)
- Курсив (Ctrl/Cmd + I)
- Подчеркнутый (Ctrl/Cmd + U)
- Зачеркнутый (Alt + Shift + 5)
- Комбинации стилей

### FR-EDT-022: Цвет текста
Система должна позволять изменять цвет текста:
- Палитра стандартных цветов
- Пользовательские цвета (HEX, RGB)
- Применение к выделенному тексту внутри ячейки
- Цветовая пипетка для выбора цвета

### FR-EDT-023: Выравнивание текста по горизонтали
Система должна поддерживать горизонтальное выравнивание:
- По левому краю
- По центру
- По правому краю

### FR-EDT-024: Выравнивание текста по вертикали
Система должна поддерживать вертикальное выравнивание:
- По верхнему краю
- По центру
- По нижнему краю

### FR-EDT-025: Перенос текста
Система должна предоставлять опции переноса текста в ячейке:
- Без переноса (обрезка)
- Перенос по словам
- Обрезка с многоточием

### FR-EDT-026: Поворот текста
Система должна позволять поворачивать текст:
- Произвольный угол (от -90 до 90 градусов)
- Вертикальный текст
- Текст снизу вверх
- Текст сверху вниз

### FR-EDT-027: Форматирование части текста
Система должна позволять применять различное форматирование к отдельным частям текста внутри одной ячейки (rich text).

## 4. Форматирование ячеек

### FR-EDT-028: Цвет фона ячейки
Система должна позволять изменять цвет заливки ячейки:
- Палитра стандартных цветов
- Пользовательские цвета (HEX, RGB)
- Прозрачный фон (без заливки)
- Градиентная заливка через условное форматирование

### FR-EDT-029: Границы ячеек
Система должна поддерживать настройку границ ячеек:
- Типы границ: все границы, внешние, внутренние, верхняя, нижняя, левая, правая
- Стили линий: сплошная, пунктирная, штриховая, двойная
- Толщина линий: тонкая, средняя, толстая
- Цвет границ

### FR-EDT-030: Размер строк
Система должна позволять изменять высоту строк:
- Ручное изменение (перетаскивание границы)
- Автоматическая подгонка по содержимому
- Указание точного значения в пикселях
- Изменение высоты нескольких строк одновременно

### FR-EDT-031: Размер столбцов
Система должна позволять изменять ширину столбцов:
- Ручное изменение (перетаскивание границы)
- Автоматическая подгонка по содержимому
- Указание точного значения в пикселях
- Изменение ширины нескольких столбцов одновременно

### FR-EDT-032: Чередующиеся цвета строк
Система должна поддерживать автоматическое чередование цветов строк (banded rows):
- Предустановленные цветовые схемы
- Настраиваемые цвета для четных/нечетных строк
- Выделение заголовка и итоговой строки

### FR-EDT-033: Темы оформления
Система должна поддерживать темы оформления таблицы:
- Предустановленные темы
- Пользовательские темы
- Применение темы ко всему листу

### FR-EDT-034: Копирование форматирования
Система должна предоставлять инструмент "Формат по образцу":
- Копирование всех параметров форматирования
- Применение к одной или нескольким ячейкам
- Двойной клик для многократного применения

### FR-EDT-035: Очистка форматирования
Система должна позволять очищать форматирование:
- Очистка всего форматирования (Ctrl/Cmd + \)
- Сохранение содержимого при очистке
- Очистка только определенных параметров

## 5. Условное форматирование

### FR-EDT-036: Создание правила условного форматирования
Система должна позволять создавать правила условного форматирования для диапазона ячеек с указанием условия и стиля форматирования.

### FR-EDT-037: Типы условий для текста
Система должна поддерживать текстовые условия:
- Текст содержит
- Текст не содержит
- Текст начинается с
- Текст заканчивается на
- Текст точно равен
- Ячейка пуста
- Ячейка не пуста

### FR-EDT-038: Типы условий для чисел
Система должна поддерживать числовые условия:
- Больше
- Больше или равно
- Меньше
- Меньше или равно
- Равно
- Не равно
- Между
- Не между

### FR-EDT-039: Типы условий для дат
Система должна поддерживать условия для дат:
- Дата равна
- Дата до
- Дата после
- Дата сегодня
- Дата вчера
- Дата завтра
- За последние N дней
- За следующие N дней

### FR-EDT-040: Пользовательские формулы в условном форматировании
Система должна позволять использовать пользовательские формулы в качестве условий, возвращающие TRUE/FALSE.

### FR-EDT-041: Цветовая шкала
Система должна поддерживать условное форматирование с цветовой шкалой:
- Двухцветная шкала (минимум-максимум)
- Трехцветная шкала (минимум-середина-максимум)
- Настраиваемые точки (число, процент, процентиль)
- Пользовательские цвета

### FR-EDT-042: Стили условного форматирования
Система должна позволять настраивать стиль при выполнении условия:
- Цвет фона ячейки
- Цвет текста
- Полужирный/курсив/подчеркнутый/зачеркнутый

### FR-EDT-043: Приоритет правил
Система должна применять правила в порядке их следования; первое истинное правило определяет форматирование.

### FR-EDT-044: Управление правилами
Система должна позволять:
- Редактировать существующие правила
- Удалять правила
- Изменять порядок правил
- Дублировать правила
- Приостанавливать правила

### FR-EDT-045: Подстановочные символы
Система должна поддерживать подстановочные символы в текстовых условиях:
- ? - любой одиночный символ
- * - любое количество символов

## 6. Формулы и функции

### FR-EDT-046: Ввод формул
Система должна распознавать формулы по начальному символу "=" и выполнять их вычисление.

### FR-EDT-047: Автодополнение формул
Система должна предлагать автодополнение при вводе функций с отображением:
- Названия функции
- Синтаксиса (аргументов)
- Краткого описания
- Примеров использования

### FR-EDT-048: Ссылки на ячейки
Система должна поддерживать типы ссылок:
- Относительные (A1)
- Абсолютные ($A$1)
- Смешанные ($A1, A$1)
- Ссылки на другие листы ('Лист1'!A1)
- Ссылки на другие файлы (IMPORTRANGE)

### FR-EDT-049: Операторы
Система должна поддерживать операторы:
- Арифметические: +, -, *, /, ^, %
- Сравнения: =, <>, <, >, <=, >=
- Конкатенации: &
- Диапазона: :
- Объединения: ;

### FR-EDT-050: Математические функции
Система должна поддерживать математические функции:
- SUM, SUMIF, SUMIFS, SUMPRODUCT
- AVERAGE, AVERAGEIF, AVERAGEIFS
- COUNT, COUNTA, COUNTBLANK, COUNTIF, COUNTIFS
- MAX, MIN, LARGE, SMALL
- ROUND, ROUNDUP, ROUNDDOWN, CEILING, FLOOR
- ABS, SIGN, SQRT, POWER, EXP, LN, LOG, LOG10
- MOD, QUOTIENT, INT, TRUNC
- RAND, RANDBETWEEN
- SIN, COS, TAN, ASIN, ACOS, ATAN, PI, DEGREES, RADIANS
- PRODUCT, GCD, LCM
- MEDIAN, MODE, STDEV, VAR

### FR-EDT-051: Текстовые функции
Система должна поддерживать текстовые функции:
- CONCATENATE, CONCAT, TEXTJOIN
- LEFT, RIGHT, MID
- LEN, LENB
- FIND, SEARCH
- REPLACE, SUBSTITUTE
- UPPER, LOWER, PROPER
- TRIM, CLEAN
- TEXT, VALUE
- SPLIT, JOIN
- CHAR, CODE
- REPT
- EXACT
- REGEXMATCH, REGEXEXTRACT, REGEXREPLACE

### FR-EDT-052: Функции даты и времени
Система должна поддерживать функции даты и времени:
- DATE, DATEVALUE, TIME, TIMEVALUE
- TODAY, NOW
- YEAR, MONTH, DAY, WEEKDAY, WEEKNUM
- HOUR, MINUTE, SECOND
- DATEDIF, DAYS, DAYS360
- EDATE, EOMONTH
- NETWORKDAYS, WORKDAY
- ISOWEEKNUM

### FR-EDT-053: Логические функции
Система должна поддерживать логические функции:
- IF, IFS
- AND, OR, NOT, XOR
- TRUE, FALSE
- IFERROR, IFNA
- SWITCH
- LAMBDA, LET

### FR-EDT-054: Функции поиска и ссылок
Система должна поддерживать функции поиска:
- VLOOKUP, HLOOKUP, XLOOKUP
- INDEX, MATCH
- LOOKUP
- OFFSET
- INDIRECT, ADDRESS
- ROW, COLUMN, ROWS, COLUMNS
- CHOOSE
- GETPIVOTDATA

### FR-EDT-055: Информационные функции
Система должна поддерживать информационные функции:
- ISBLANK, ISERROR, ISERR, ISNA
- ISNUMBER, ISTEXT, ISLOGICAL, ISFORMULA
- TYPE, N, NA
- CELL, ERROR.TYPE

### FR-EDT-056: Функции работы с массивами
Система должна поддерживать функции массивов:
- ARRAY_CONSTRAIN
- ARRAYFORMULA
- FILTER
- SORT, SORTN
- UNIQUE
- FLATTEN
- TRANSPOSE
- SEQUENCE
- MAKEARRAY, MAP, REDUCE, SCAN

### FR-EDT-057: Статистические функции
Система должна поддерживать статистические функции:
- AVERAGE, AVERAGEA, AVERAGEIF, AVERAGEIFS
- COUNT, COUNTA, COUNTBLANK, COUNTIF, COUNTIFS
- MAX, MAXA, MAXIFS, MIN, MINA, MINIFS
- STDEV, STDEVP, VAR, VARP
- MEDIAN, MODE, PERCENTILE, QUARTILE
- CORREL, COVAR
- FORECAST, TREND, GROWTH
- FREQUENCY, RANK

### FR-EDT-058: Финансовые функции
Система должна поддерживать финансовые функции:
- FV, PV, NPV, IRR, MIRR
- PMT, PPMT, IPMT, NPER, RATE
- SLN, SYD, DB, DDB
- EFFECT, NOMINAL
- XNPV, XIRR

### FR-EDT-059: Функции базы данных
Система должна поддерживать функции базы данных:
- DSUM, DAVERAGE, DCOUNT, DCOUNTA
- DMAX, DMIN, DGET
- DVAR, DVARP, DSTDEV, DSTDEVP
- DPRODUCT

### FR-EDT-060: Специальные функции Google Sheets
Система должна поддерживать уникальные функции:
- QUERY - SQL-подобные запросы к данным
- IMPORTRANGE - импорт данных из других таблиц
- IMPORTHTML, IMPORTXML, IMPORTDATA, IMPORTFEED
- GOOGLEFINANCE - финансовые данные
- GOOGLETRANSLATE - перевод текста
- IMAGE - вставка изображения по URL
- SPARKLINE - миниатюрные диаграммы в ячейке
- HYPERLINK - создание гиперссылок

### FR-EDT-061: Обработка ошибок в формулах
Система должна отображать типы ошибок:
- #ERROR! - общая ошибка синтаксиса
- #VALUE! - неверный тип данных
- #REF! - недействительная ссылка
- #NAME? - нераспознанное имя функции
- #NUM! - недопустимое число
- #DIV/0! - деление на ноль
- #N/A - значение не найдено
- #NULL! - пустое пересечение

### FR-EDT-062: Вложенные формулы
Система должна поддерживать вложенные формулы с глубиной вложенности до 64 уровней.

## 7. Автозаполнение

### FR-EDT-063: Автозаполнение чисел
Система должна автоматически распознавать и продолжать числовые последовательности:
- Последовательные числа (1, 2, 3...)
- Арифметические прогрессии (2, 4, 6...)
- Десятичные дроби (0.5, 1.5, 2.5...)

### FR-EDT-064: Автозаполнение дат
Система должна продолжать последовательности дат:
- Последовательные дни
- Только рабочие дни
- Месяцы
- Годы
- Пользовательские интервалы

### FR-EDT-065: Автозаполнение текста
Система должна распознавать текстовые паттерны:
- Дни недели (Понедельник, Вторник...)
- Месяцы (Январь, Февраль...)
- Комбинации текста и чисел (Item1, Item2...)
- Сокращения (Пн, Вт, Ср... или Янв, Фев, Мар...)

### FR-EDT-066: Маркер автозаполнения
Система должна предоставлять маркер заполнения (синий квадрат в правом нижнем углу выделения) для перетаскивания.

### FR-EDT-067: Двойной клик для автозаполнения
Система должна заполнять столбец до последней строки смежных данных при двойном клике по маркеру заполнения.

### FR-EDT-068: Копирование без приращения
Система должна позволять копировать значение без приращения при удержании Ctrl/Cmd во время перетаскивания.

### FR-EDT-069: Автозаполнение формул
Система должна копировать формулы с автоматической корректировкой относительных ссылок.

### FR-EDT-070: Умное заполнение (Smart Fill)
Система должна предлагать автоматическое заполнение на основе распознанных паттернов в данных (Ctrl/Cmd + Shift + Y).

## 8. Объединение ячеек

### FR-EDT-071: Объединение всех ячеек
Система должна позволять объединять выделенные ячейки в одну с сохранением значения из верхней левой ячейки.

### FR-EDT-072: Горизонтальное объединение
Система должна позволять объединять ячейки по горизонтали в пределах каждой строки выделения.

### FR-EDT-073: Вертикальное объединение
Система должна позволять объединять ячейки по вертикали в пределах каждого столбца выделения.

### FR-EDT-074: Отмена объединения
Система должна позволять разъединять объединенные ячейки с возвратом к исходной структуре.

### FR-EDT-075: Предупреждение о потере данных
Система должна предупреждать пользователя о потере данных при объединении ячеек, содержащих значения (кроме верхней левой).

### FR-EDT-076: Ограничения объединенных ячеек
Система должна запрещать:
- Сортировку диапазонов с вертикально объединенными ячейками
- Создание фильтров для диапазонов с объединенными ячейками
- Объединение ячеек в таблицах с активными фильтрами

## 9. Заморозка строк и столбцов

### FR-EDT-077: Заморозка строк
Система должна позволять закреплять строки (1, 2 или произвольное количество) для постоянного отображения при прокрутке.

### FR-EDT-078: Заморозка столбцов
Система должна позволять закреплять столбцы (1, 2 или произвольное количество) для постоянного отображения при прокрутке.

### FR-EDT-079: Комбинированная заморозка
Система должна позволять одновременно закреплять строки и столбцы.

### FR-EDT-080: Заморозка до текущей ячейки
Система должна позволять замораживать строки/столбцы до текущей позиции курсора.

### FR-EDT-081: Визуальный индикатор заморозки
Система должна отображать жирную серую линию между замороженной и прокручиваемой областями.

### FR-EDT-082: Перетаскивание границы заморозки
Система должна позволять изменять количество замороженных строк/столбцов перетаскиванием разделительных линий.

### FR-EDT-083: Отмена заморозки
Система должна позволять снимать заморозку строк и столбцов через меню "Вид" > "Закрепить" > "Без строк/столбцов".

---

## 10. Фильтры и сортировка

### FR-EDT-084: Создание фильтра
Система должна позволять создавать фильтр для выбранного диапазона данных с автоматическим определением заголовков.

### FR-EDT-085: Фильтрация по значениям
Система должна позволять фильтровать данные по выбранным значениям из списка уникальных значений столбца.

### FR-EDT-086: Фильтрация по условию
Система должна поддерживать условную фильтрацию:
- Текстовые условия (содержит, начинается с, заканчивается на)
- Числовые условия (больше, меньше, между)
- Условия для дат (до, после, сегодня)
- Пользовательские формулы

### FR-EDT-087: Фильтрация по цвету
Система должна позволять фильтровать по цвету заливки или цвету текста.

### FR-EDT-088: Множественные фильтры
Система должна позволять применять фильтры к нескольким столбцам одновременно с логикой AND.

### FR-EDT-089: Сброс фильтра
Система должна позволять сбрасывать фильтры отдельно для каждого столбца или для всего диапазона.

### FR-EDT-090: Удаление фильтра
Система должна позволять полностью удалять фильтр с диапазона данных.

### FR-EDT-091: Режимы просмотра фильтров
Система должна поддерживать режимы просмотра фильтров:
- Создание именованного представления
- Сохранение нескольких представлений
- Переключение между представлениями
- Совместное использование представлений

### FR-EDT-092: Простая сортировка
Система должна позволять сортировать выбранный диапазон:
- По возрастанию (А-Я, 0-9)
- По убыванию (Я-А, 9-0)

### FR-EDT-093: Сортировка по нескольким столбцам
Система должна позволять задавать иерархическую сортировку по нескольким столбцам с указанием приоритета.

### FR-EDT-094: Сортировка с заголовком
Система должна учитывать строку заголовка и исключать её из сортировки.

### FR-EDT-095: Сохранение связей строк при сортировке
Система должна сохранять целостность данных в строках при сортировке (не сортировать столбцы независимо).

### FR-EDT-096: Функция SORT
Система должна поддерживать функцию SORT для создания отсортированного представления данных в другом месте.

### FR-EDT-097: Функция FILTER
Система должна поддерживать функцию FILTER для создания динамически обновляемых отфильтрованных данных.

---

## 11. Проверка данных

### FR-EDT-098: Создание правила проверки данных
Система должна позволять создавать правила проверки вводимых данных для ячейки или диапазона.

### FR-EDT-099: Критерий "Список элементов"
Система должна позволять задавать список допустимых значений вручную (через запятую).

### FR-EDT-100: Критерий "Список из диапазона"
Система должна позволять задавать допустимые значения из диапазона ячеек.

### FR-EDT-101: Критерий "Число"
Система должна позволять задавать числовые ограничения:
- Между
- Не между
- Равно
- Не равно
- Больше
- Меньше
- Больше или равно
- Меньше или равно

### FR-EDT-102: Критерий "Текст"
Система должна позволять задавать текстовые ограничения:
- Содержит
- Не содержит
- Равен
- Является допустимым email
- Является допустимым URL

### FR-EDT-103: Критерий "Дата"
Система должна позволять задавать ограничения по датам:
- Является допустимой датой
- Равна
- До
- После
- Между
- Не между

### FR-EDT-104: Критерий "Чекбокс"
Система должна позволять создавать чекбоксы с:
- Стандартными значениями (TRUE/FALSE)
- Пользовательскими значениями (Да/Нет, 1/0 и др.)

### FR-EDT-105: Критерий "Пользовательская формула"
Система должна позволять использовать формулу, возвращающую TRUE/FALSE, для проверки данных.

### FR-EDT-106: Критерий "Регулярное выражение"
Система должна поддерживать проверку соответствия регулярному выражению для сложных паттернов.

### FR-EDT-107: Действие при неверных данных
Система должна позволять настраивать реакцию на некорректные данные:
- Показать предупреждение (разрешить ввод)
- Отклонить ввод (запретить некорректные данные)

### FR-EDT-108: Текст справки
Система должна позволять задавать текст подсказки для пользователя, отображаемый при выборе ячейки.

### FR-EDT-109: Отображение текста справки
Система должна отображать текст справки в виде всплывающей подсказки при наведении или выделении ячейки.

## 12. Выпадающие списки

### FR-EDT-110: Создание выпадающего списка
Система должна позволять создавать выпадающий список в ячейке через меню "Вставка" > "Раскрывающийся список" или "Данные" > "Проверка данных".

### FR-EDT-111: Значения списка вручную
Система должна позволять задавать значения выпадающего списка вручную (ввод через запятую).

### FR-EDT-112: Значения списка из диапазона
Система должна позволять получать значения списка из диапазона ячеек с автоматическим обновлением.

### FR-EDT-113: Цветовая индикация значений
Система должна поддерживать назначение цветов для каждого значения в выпадающем списке (chip format).

### FR-EDT-114: Множественный выбор
Система должна поддерживать режим множественного выбора значений из списка (для формата "чипы").

### FR-EDT-115: Динамические списки
Система должна поддерживать динамические списки с использованием функций UNIQUE и FILTER для автоматического обновления значений.

### FR-EDT-116: Зависимые выпадающие списки
Система должна поддерживать создание зависимых (каскадных) списков с использованием INDIRECT и именованных диапазонов.

### FR-EDT-117: Отображение стрелки списка
Система должна отображать стрелку раскрывающегося списка в ячейке при её выборе.

### FR-EDT-118: Поиск в списке
Система должна поддерживать поиск по значениям в выпадающем списке при большом количестве элементов.

## 13. Именованные диапазоны

### FR-EDT-119: Создание именованного диапазона
Система должна позволять присваивать имя выбранному диапазону ячеек или отдельной ячейке.

### FR-EDT-120: Правила именования
Система должна применять правила к именам диапазонов:
- Начало с буквы или подчеркивания
- Допустимые символы: буквы, цифры, подчеркивание
- Максимальная длина: 250 символов
- Уникальность имени в пределах документа
- Регистронезависимость

### FR-EDT-121: Использование в формулах
Система должна позволять использовать именованные диапазоны в формулах вместо адресов ячеек (=SUM(Продажи)).

### FR-EDT-122: Управление именованными диапазонами
Система должна предоставлять панель управления именованными диапазонами:
- Просмотр списка всех именованных диапазонов
- Редактирование имени и диапазона
- Удаление именованных диапазонов
- Переход к диапазону по клику

### FR-EDT-123: Автоматическое расширение диапазона
Система должна предлагать функционал автоматического расширения именованного диапазона при добавлении данных (при использовании Tables).

### FR-EDT-124: Область видимости
Система должна поддерживать именованные диапазоны на уровне документа (глобальные), доступные со всех листов.

### FR-EDT-125: Ссылки между листами
Система должна позволять создавать именованные диапазоны, ссылающиеся на данные на разных листах.

---

## 14. Защита ячеек и диапазонов

### FR-EDT-126: Защита диапазона
Система должна позволять защищать выбранный диапазон ячеек от редактирования.

### FR-EDT-127: Защита листа
Система должна позволять защищать весь лист с возможностью указать исключения (незащищенные диапазоны).

### FR-EDT-128: Настройка разрешений
Система должна позволять настраивать права доступа:
- Только владелец может редактировать
- Указанные пользователи могут редактировать
- Предупреждение при редактировании (без блокировки)

### FR-EDT-129: Название защищенного диапазона
Система должна позволять присваивать описательное название защищенному диапазону для удобства управления.

### FR-EDT-130: Список защищенных диапазонов
Система должна предоставлять панель со списком всех защищенных диапазонов и листов в документе.

### FR-EDT-131: Визуальная индикация защиты
Система должна визуально отличать защищенные ячейки (при попытке редактирования отображать сообщение о защите).

### FR-EDT-132: Редактирование защиты
Система должна позволять редактировать настройки защиты:
- Изменять защищаемый диапазон
- Изменять список пользователей с правом редактирования
- Удалять защиту

### FR-EDT-133: Защита структуры
Система должна позволять защищать структуру листа:
- Запрет добавления/удаления строк и столбцов
- Запрет скрытия строк и столбцов
- Запрет изменения ширины столбцов и высоты строк

### FR-EDT-134: Копирование защищенных данных
Система должна разрешать копирование данных из защищенных ячеек при запрете их редактирования.

### FR-EDT-135: Наследование защиты
Система должна применять защиту к новым ячейкам, добавленным в защищенный диапазон (при вставке строк/столбцов внутри диапазона).

## Глоссарий

| Термин | Определение |
|--------|-------------|
| Ячейка | Минимальная единица хранения данных на пересечении строки и столбца |
| Диапазон | Группа смежных ячеек, обозначаемая адресами углов (A1:C10) |
| Формула | Выражение, начинающееся с "=", для вычислений |
| Функция | Предопределенная операция с именем и аргументами |
| Условное форматирование | Автоматическое применение стилей на основе правил |
| Именованный диапазон | Диапазон ячеек с присвоенным текстовым именем |
| Проверка данных | Правила ограничения допустимых значений в ячейках |
| Заморозка | Фиксация строк/столбцов при прокрутке |
| Фильтр | Инструмент для отображения подмножества данных |
| Защита | Ограничение прав редактирования для диапазонов |

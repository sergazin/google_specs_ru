# Создание объявлений (Ads & Creatives)

## Описание модуля

Модуль управления созданием рекламных объявлений в Google Ads, включающий все типы объявлений (текстовые, адаптивные, медийные, видео, товарные, приложения), группы объявлений, ассеты, модерацию, A/B тестирование и управление креативами.

---

## 1. Типы рекламных кампаний и объявлений

### 1.1 Поисковые кампании (Search Campaigns)

#### FR-SRCH-001: Адаптивные поисковые объявления (Responsive Search Ads)
**Описание:** Основной тип текстовых объявлений для поисковой сети
**Компоненты объявления:**

| Элемент | Обязательный | Лимит символов | Количество |
|---------|-------------|----------------|------------|
| Заголовок (Headline) | Да | 30 символов | 3-15 штук |
| Описание (Description) | Да | 90 символов | 2-4 штуки |
| Путь URL (Display Path) | Нет | 15 символов | 2 поля |
| Финальный URL | Да | - | 1 |

**Бизнес-правила:**
- BR-001: Минимум 3 заголовка и 2 описания для создания объявления
- BR-002: Google AI автоматически комбинирует заголовки и описания
- BR-003: Показываются одновременно до 3 заголовков и до 2 описаний
- BR-004: Символы двухбайтовых языков (корейский, японский, китайский) считаются за 2
- BR-005: Пробелы учитываются в лимите символов
- BR-006: Можно закрепить (pin) заголовок/описание на определенную позицию

**User Story:**
> Как рекламодатель, я хочу создать несколько вариантов заголовков и описаний, чтобы Google автоматически подбирал лучшие комбинации для каждого поискового запроса.

#### FR-SRCH-002: Динамические поисковые объявления (Dynamic Search Ads)
**Описание:** Объявления, генерируемые автоматически на основе контента сайта
**Компоненты:**

| Элемент | Генерация | Лимит символов |
|---------|-----------|----------------|
| Заголовок | Автоматическая (Google) | Динамический |
| Описание | Ручная (рекламодатель) | 90 символов |
| Финальный URL | Автоматическая (Google) | - |

**Бизнес-правила:**
- BR-007: Заголовки генерируются на основе поисковых запросов и контента страниц
- BR-008: URL выбирается автоматически из наиболее релевантных страниц сайта
- BR-009: Требуется указать домен или страницы для таргетинга

**User Story:**
> Как владелец интернет-магазина с тысячами товаров, я хочу автоматически генерировать объявления для каждого товара без ручного создания.

#### FR-SRCH-003: Объявления только с номером телефона (Call-Only Ads)
**Описание:** Объявления для мобильных устройств, генерирующие звонки
**Компоненты:**

| Элемент | Лимит символов | Количество |
|---------|----------------|------------|
| Заголовок | 30 символов | 2 штуки |
| Описание | 90 символов | 2 штуки |
| Название компании | 25 символов | 1 |
| Путь URL | 15 символов | 2 поля |
| Номер телефона | - | 1 |

**Бизнес-правила:**
- BR-010: Клик ведет непосредственно к звонку, не на сайт
- BR-011: Показываются только на мобильных устройствах с возможностью звонка
- BR-012: Можно настроить минимальную длительность звонка для конверсии (напр. 30 секунд)

### 1.2 Медийные кампании (Display Campaigns)

#### FR-DISP-001: Адаптивные медийные объявления (Responsive Display Ads)
**Описание:** Автоматически адаптируемые объявления для контекстно-медийной сети
**Компоненты:**

**Изображения:**
| Тип | Соотношение | Рекомендуемый размер | Минимальный размер | Макс. размер файла |
|-----|-------------|---------------------|-------------------|-------------------|
| Горизонтальное | 1.91:1 | 1200x628 px | 600x314 px | 5 МБ |
| Квадратное | 1:1 | 1200x1200 px | 300x300 px | 5 МБ |
| Вертикальное (опц.) | 4:5 | 1200x1500 px | 320x400 px | 5 МБ |

**Логотипы:**
| Тип | Соотношение | Рекомендуемый размер | Минимальный размер |
|-----|-------------|---------------------|-------------------|
| Квадратный | 1:1 | 1200x1200 px | 128x128 px |
| Горизонтальный | 4:1 | 1200x300 px | 512x128 px |

**Текстовые элементы:**
| Элемент | Лимит символов | Количество |
|---------|----------------|------------|
| Короткий заголовок | 30 символов | 1-5 |
| Длинный заголовок | 90 символов | 1 |
| Описание | 90 символов | 1-5 |
| Название компании | 25 символов | 1 |
| CTA (призыв к действию) | Выбор из списка | 1 |

**Бизнес-правила:**
- BR-013: Рекомендуется 5-10 изображений каждого соотношения сторон
- BR-014: Изображение может быть обрезано до 5% от краев
- BR-015: Текст не должен занимать более 20% изображения
- BR-016: Формат файлов: JPG или PNG (GIF не поддерживается)
- BR-017: Прозрачный фон рекомендуется для логотипов
- BR-018: Логотип должен быть читаем при размере 40x40 px

**User Story:**
> Как маркетолог, я хочу загрузить изображения разных форматов и тексты, чтобы система автоматически создавала объявления для разных мест размещения.

#### FR-DISP-002: Загружаемые медийные объявления (Uploaded Display Ads)
**Описание:** Статичные баннеры с фиксированным дизайном
**Популярные размеры:**

| Название | Размер | Применение |
|----------|--------|------------|

| Large Rectangle | 336x280 px | Десктоп, боковая панель |

| Half Page | 300x600 px | Боковая панель |
| Large Mobile Banner | 320x100 px | Мобильные устройства |
| Mobile Banner | 320x50 px | Мобильные устройства |
| Wide Skyscraper | 160x600 px | Боковая панель |
| Billboard | 970x250 px | Премиум размещения |

**Технические требования:**
| Параметр | Значение |
|----------|----------|
| Форматы файлов | JPG, PNG, GIF |
| Максимальный размер | 150 КБ |
| HTML5 формат | ZIP до 150 КБ |

**Бизнес-правила:**
- BR-019: Баннер должен быть создан для каждого размера отдельно

### 1.3 Видеокампании (Video Campaigns)

#### FR-VID-001: Пропускаемые объявления In-Stream (Skippable In-Stream Ads)
**Описание:** Видеореклама перед, во время или после видео на YouTube
**Спецификации:**

| Параметр | Требование |
|----------|-----------|
| Длительность | 12 секунд - 6 минут (рекомендуется до 3 мин) |
| Пропуск | После 5 секунд |
| Разрешение | Мин. 1280x720 (HD), рек. 1920x1080 |
| Соотношение сторон | 16:9 (горизонтальное), 9:16 (вертикальное), 1:1 (квадратное) |
| Форматы | MP4, MOV, AVI, WMV, MPEG-4, WebM |
| Заголовок | 15 символов |
| CTA | 10 символов |

**Модель оплаты:**
- CPV (Cost Per View): оплата за просмотр 30 секунд или до конца (если короче)
- Target CPM: оплата за 1000 показов
- Target CPA: оплата за конверсию

**Бизнес-правила:**
- BR-022: Видео должно быть загружено на YouTube перед использованием в рекламе
- BR-023: Оплата CPV взимается только при просмотре 30 сек или взаимодействии

#### FR-VID-002: Непропускаемые объявления In-Stream (Non-Skippable In-Stream Ads)
**Описание:** Короткие видео без возможности пропуска
**Спецификации:**

| Параметр | Требование |
|----------|-----------|
| Длительность | 7-15 секунд (до 20-30 сек в некоторых регионах) |
| Пропуск | Недоступен |
| Соотношение сторон | 16:9, 1:1, 4:3 (рекомендуется 16:9) |
| Модель оплаты | Target CPM, Fixed CPM |

**User Story:**
> Как бренд-менеджер, я хочу донести полное сообщение до аудитории без возможности пропуска для повышения узнаваемости бренда.

#### FR-VID-003: Объявления-заставки (Bumper Ads)
**Описание:** Сверхкороткие непропускаемые видео
**Спецификации:**

| Параметр | Требование |
|----------|-----------|
| Длительность | Максимум 6 секунд |
| Пропуск | Недоступен |
| Соотношение сторон | 16:9, 1:1, 4:3 |
| Модель оплаты | Target CPM |
| Устройства | Десктоп, мобильные, TV, игровые консоли |

**Бизнес-правила:**
- BR-024: Идеальны для запоминающихся коротких сообщений
- BR-025: Эффективны для мобильной аудитории "на ходу"

#### FR-VID-004: In-Feed видеообъявления
**Описание:** Видеообъявления в результатах поиска YouTube и в ленте рекомендаций
**Компоненты:**

| Элемент | Лимит |
|---------|-------|
| Превью-изображение | Автоматически из видео |
| Заголовок | 100 символов |
| Описание | 2 строки |

**Бизнес-правила:**
- BR-026: Оплата за клик для просмотра видео
- BR-027: Видео воспроизводится на странице YouTube

### 1.4 Торговые кампании (Shopping Campaigns)

#### FR-SHOP-001: Товарные объявления (Product Shopping Ads)
**Описание:** Объявления с изображением, ценой и информацией о товаре
**Требования к товарному фиду:**

**Обязательные атрибуты:**
| Атрибут | Описание | Требования |
|---------|----------|-----------|
| id | Уникальный ID товара | SKU продукта |
| title | Название товара | До 150 символов |
| description | Описание | До 5000 символов |
| link | URL страницы товара | Начинается с https:// |
| image_link | URL главного изображения | Мин. 100x100 px |
| price | Цена | Формат: 10.00 USD |
| availability | Наличие | in_stock, out_of_stock, preorder |
| brand | Бренд | Обязательно для новых товаров |
| gtin | Штрих-код | Обязательно если есть |
| condition | Состояние | new, refurbished, used |

**Условные атрибуты:**
| Атрибут | Когда требуется |
|---------|----------------|
| shipping | Обязательно для ряда стран |
| tax | Для США |
| color, size, gender | Для одежды |
| age_group | Для товаров с возрастными ограничениями |

**Бизнес-правила:**
- BR-028: Цена в объявлении должна совпадать с ценой на сайте
- BR-029: Изображения: без водяных знаков, без рекламных надписей
- BR-030: Фид должен обновляться минимум раз в 30 дней
- BR-031: Рекомендуется ежедневное обновление фида
- BR-032: Требуется связка Google Merchant Center с Google Ads

**User Story:**
> Как владелец интернет-магазина, я хочу показывать свои товары с фотографиями и ценами прямо в результатах поиска Google.

#### FR-SHOP-002: Локальные товарные объявления (Local Inventory Ads)
**Описание:** Объявления для товаров в физических магазинах
**Дополнительные требования:**
- Информация о наличии в конкретном магазине
- Адрес магазина
- Часы работы

## 2. Группы объявлений (Ad Groups)

### FR-ADGR-001: Структура и организация
**Описание:** Группировка объявлений по темам и ключевым словам
**Иерархия:**
```
Аккаунт
└── Кампания
    └── Группа объявлений
        ├── Ключевые слова
        ├── Объявления
        └── Расширения (ассеты)
```

**Рекомендации по структуре:**
| Параметр | Рекомендация |
|----------|--------------|
| Ключевых слов в группе | 5-15 штук |
| Объявлений в группе | 2-3 штуки (минимум) |
| Тематика | Узкая, связанная |

**Бизнес-правила:**
- BR-043: Одна тема = одна группа объявлений
- BR-044: Ключевые слова должны быть тесно связаны друг с другом
- BR-045: Объявления должны соответствовать ключевым словам группы
- BR-046: Избегать пересечения ключевых слов между группами
- BR-047: Использовать минус-слова для исключения нерелевантного трафика

### FR-ADGR-002: Таргетинг на уровне группы объявлений
**Описание:** Настройка аудитории и ставок на уровне группы
**Типы таргетинга:**
- Ключевые слова (для Search)
- Аудитории
- Демография
- Темы (для Display)
- Места размещения (для Display/YouTube)

**User Story:**
> Как PPC-специалист, я хочу разделить объявления по тематическим группам, чтобы показывать наиболее релевантные объявления для каждой группы ключевых слов.

## 3. Модерация и политики объявлений

### FR-MOD-001: Процесс проверки объявлений
**Описание:** Автоматическая и ручная проверка соответствия политикам
**Этапы проверки:**
1. Рекламодатель создает/редактирует объявление
2. Автоматическая проверка системой (AI + правила)
3. При необходимости - проверка модератором-человеком
4. Присвоение статуса
5. Уведомление рекламодателя

**Сроки проверки:**
| Тип | Срок |
|-----|------|
| Стандартная проверка | До 1 рабочего дня |
| Сложные случаи | До нескольких дней |

### FR-MOD-002: Статусы объявлений
**Описание:** Возможные состояния объявления после модерации

**Статусы до/во время проверки:**
| Статус | Описание | Показ |
|--------|----------|-------|
| Under review (На проверке) | Объявление проверяется | Нет |

**Статусы после одобрения:**
| Статус | Описание | Показ |
|--------|----------|-------|
| Eligible (Допущено) | Полностью одобрено | Да |
| Approved (Одобрено) | Соответствует политикам | Да |
| Eligible (limited) | Одобрено с ограничениями | Частично |
| Approved (limited) | Одобрено, но не для всех аудиторий | Частично |

**Статусы при отклонении:**
| Статус | Описание | Показ |
|--------|----------|-------|
| Disapproved (Отклонено) | Нарушает политики | Нет |
| Past Violation | Ранее отклонено, политика больше не применима | Нет |

### FR-MOD-003: Причины отклонения объявлений
**Описание:** Основные нарушения политик

**Запрещенный контент:**
| Категория | Примеры |
|-----------|---------|
| Контрафактные товары | Подделки брендов |
| Опасные товары/услуги | Наркотики, оружие |
| Нечестное поведение | Хакерские услуги, поддельные документы |
| Неприемлемый контент | Дискриминация, насилие |

**Ограниченный контент:**
| Категория | Ограничения |
|-----------|-------------|
| Алкоголь | Требуется сертификация, возрастные ограничения |
| Азартные игры | Лицензия, географические ограничения |
| Медицинские услуги | Сертификация, ограничения по странам |
| Финансовые услуги | Лицензия, требования к раскрытию информации |
| Политическая реклама | Верификация, требования к прозрачности |

**Редакционные нарушения:**
| Тип | Примеры |
|-----|---------|
| Некорректные заявления | Невозможные обещания, гарантии без возврата |
| Несоответствие назначения | URL не соответствует объявлению |
| Использование товарных знаков | Без разрешения правообладателя |
| Вредоносное ПО | Малварь на посадочной странице |

### FR-MOD-004: Апелляция решения модерации
**Описание:** Оспаривание отклонения объявления
**Процесс:**
1. Рекламодатель получает уведомление об отклонении
2. Исправляет нарушение или формирует апелляцию
3. Отправляет запрос на пересмотр в аккаунте
4. Google проводит повторную проверку
5. Статус обновляется в Policy Manager

**Бизнес-правила:**
- BR-048: Апелляция возможна только после исправления или при несогласии с решением
- BR-049: Результат апелляции отображается в разделе "Appeal history"
- BR-050: Повторные нарушения могут привести к приостановке аккаунта

**User Story:**
> Как рекламодатель, я хочу оспорить отклонение объявления, которое, по моему мнению, не нарушает политики.

## 4. A/B тестирование объявлений

### FR-TEST-001: Эксперименты с вариациями объявлений
**Описание:** Тестирование различных версий текстовых объявлений
**Типы экспериментов:**

| Тип эксперимента | Описание |
|------------------|----------|
| Optimize text ads | Тестирование заголовков/описаний RSA |
| Video experiments | Сравнение разных видео |
| Demand Gen experiments | Тестирование креативов, аудиторий, бидов |
| Custom experiments | Любые изменения кампании |

**Тестируемые переменные:**
- Заголовки
- Описания
- Изображения
- Видео
- Посадочные страницы (URL)
- Аудитории
- Стратегии ставок

### FR-TEST-002: Настройка эксперимента
**Описание:** Параметры проведения теста
**Настройки:**

| Параметр | Описание |
|----------|----------|
| Experiment split | Распределение трафика (напр. 50/50) |
| Cookie-based split | Пользователь видит один вариант постоянно |
| Random split | Случайное распределение при каждом показе |
| Длительность | Рекомендуется 2-4 недели |

**Бизнес-правила:**
- BR-051: Тестировать одну переменную за раз для чистоты результата
- BR-052: Дождаться статистической значимости перед принятием решения
- BR-053: Минимум 100 конверсий для видеоэкспериментов
- BR-054: Не останавливать тест преждевременно

### FR-TEST-003: Метрики оценки результатов
**Описание:** KPI для определения победителя
**Ключевые метрики:**

| Метрика | Описание |
|---------|----------|
| CTR (Click-Through Rate) | Процент кликов от показов |
| Conversion Rate | Процент конверсий от кликов |
| Cost per Conversion | Стоимость одной конверсии |
| CPC (Cost per Click) | Стоимость одного клика |
| ROAS | Возврат инвестиций в рекламу |

**User Story:**
> Как маркетолог, я хочу протестировать два варианта заголовка, чтобы определить какой из них приносит больше конверсий.

**Описание:** Дополнительные элементы, расширяющие объявление

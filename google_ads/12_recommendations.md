# Модуль "Рекомендации и оптимизация" — Google Ads

## 1. Общее описание модуля

Модуль "Рекомендации и оптимизация" является центральным инструментом для повышения эффективности рекламных кампаний в Google Ads. Он объединяет систему автоматических рекомендаций, метрику Optimization Score (оценку оптимизации), инструменты диагностики и AI-функции для автоматической оптимизации.

### Ключевые функции модуля:
- Расчёт и отображение Optimization Score (оценки оптимизации аккаунта)
- Генерация персонализированных рекомендаций по улучшению кампаний
- Автоматическое применение рекомендаций (Auto-apply)
- AI-оптимизация через Performance Max и AI Max
- Диагностика проблем кампаний
- Инсайты и анализ эффективности

## 2. Optimization Score (Оценка оптимизации)

### 2.1. Описание

Optimization Score — это числовая оценка от 0% до 100%, показывающая, насколько хорошо настроен аккаунт Google Ads для достижения максимальной эффективности.

### 2.2. Бизнес-логика расчёта

**Факторы, влияющие на оценку:**

| Фактор | Описание |
|--------|----------|
| Статистика аккаунта | Текущие показатели эффективности кампаний |
| Настройки кампаний | Конфигурация бюджетов, ставок, таргетинга |
| Статус компонентов | Активность объявлений, ключевых слов, групп |
| Доступные рекомендации | Потенциальное влияние нереализованных рекомендаций |
| История рекомендаций | Учёт ранее применённых/отклонённых рекомендаций |
| Машинное обучение | Анализ схожих аккаунтов в отрасли |

**Правила расчёта:**
- Оценка рассчитывается в реальном времени
- Каждая рекомендация имеет вес (uplift) в процентах
- При применении рекомендации оценка увеличивается на соответствующий uplift
- При отклонении рекомендации оценка также увеличивается (рекомендация убирается из списка)
- Отклонённые рекомендации показываются серым цветом в шкале прогресса

### 2.3. Уровни отображения

**Доступные уровни:**
- **Уровень аккаунта** — общая оценка всего аккаунта
- **Уровень кампании** — оценка отдельной кампании
- **Уровень управляющего аккаунта (MCC)** — агрегированная оценка по всем связанным аккаунтам

### 2.4. Поддерживаемые типы кампаний

Optimization Score рассчитывается для:
- Search (Поисковые кампании)
- Display (Медийные кампании)
- Video Action (Видеокампании на действие)
- App (Кампании для приложений)
- Performance Max (Максимальная эффективность)
- Demand Gen (Генерация спроса)
- Shopping (Товарные кампании)

### 2.5. Бизнес-значение оценки

| Диапазон | Интерпретация |
|----------|---------------|
| 0-50% | Аккаунт требует значительной оптимизации |
| 50-70% | Средний уровень оптимизации |
| 70-85% | Хорошая оптимизация (минимум для Google Partners) |
| 85-100% | Отличная оптимизация |

**Важные замечания:**
- Optimization Score не влияет на Quality Score
- Optimization Score не является фактором в рекламном аукционе
- Высокая оценка не гарантирует высокую эффективность бизнеса
- Оценка отражает соответствие рекомендациям Google, а не реальную прибыльность

### 2.6. Требования для Google Partners

- Минимальный Optimization Score для статуса Google Partner: **70%**
- Можно достичь 70% как применением, так и отклонением рекомендаций
- Рекламодатель сам выбирает, какие рекомендации применять

### 2.7. User Stories

```
КАК менеджер рекламного аккаунта
Я ХОЧУ видеть текущий Optimization Score
ЧТОБЫ понимать потенциал улучшения кампаний

Критерии приемки:
- Вижу числовую оценку от 0% до 100%
- Вижу визуальную шкалу прогресса
- Могу переключаться между уровнями (аккаунт/кампания)
- Оценка обновляется в реальном времени при изменениях
```

```
КАК агентство с партнёрским статусом
Я ХОЧУ поддерживать Optimization Score не ниже 70%
ЧТОБЫ сохранить статус Google Partner

Критерии приемки:
- Вижу агрегированную оценку по всем клиентским аккаунтам
- Получаю предупреждение при снижении ниже порога
- Могу сортировать аккаунты по уровню оптимизации
```

## 3. Типы рекомендаций

### 3.1. Категории рекомендаций

Google Ads предоставляет более **50 типов рекомендаций**, сгруппированных в следующие категории:

#### 3.1.1. Объявления и ресурсы (Ads & Assets)

**Цель:** Улучшение качества и разнообразия рекламных объявлений.

| Рекомендация | Описание | Влияние на Score |
|--------------|----------|------------------|
| Добавить адаптивные объявления | Создать адаптивные поисковые объявления | 5-15% |
| Улучшить силу объявления | Добавить заголовки/описания для повышения Ad Strength | 3-10% |
| Добавить расширения сайтлинков | Добавить ссылки на разделы сайта | 2-5% |
| Добавить расширения уточнений | Добавить callout extensions | 2-5% |
| Добавить структурированные описания | Добавить structured snippets | 2-5% |
| Добавить изображения | Добавить image extensions | 3-8% |
| Добавить логотипы | Загрузить логотипы для Performance Max | 2-5% |
| Добавить видео | Загрузить видеоактивы | 3-10% |
| Исправить отклонённые объявления | Исправить объявления, не прошедшие модерацию | 5-15% |

**Автоматически создаваемые ресурсы (Automatically Created Assets):**
- Система генерирует дополнительные заголовки и описания на основе контента сайта
- Требуют проверки перед использованием
- Улучшают Ad Strength за счёт большего количества комбинаций

#### 3.1.2. Ключевые слова и таргетинг (Keywords & Targeting)

**Цель:** Расширение охвата и повышение релевантности показов.

| Рекомендация | Описание | Влияние на Score |
|--------------|----------|------------------|
| Добавить новые ключевые слова | Ключевые слова на основе поисковых запросов | 5-15% |
| Добавить широкое соответствие | Перевести ключевые слова на broad match | 5-20% |
| Удалить избыточные ключевые слова | Убрать дублирующиеся ключевые слова | 2-5% |
| Удалить конфликтующие минус-слова | Убрать минус-слова, блокирующие целевые запросы | 3-10% |
| Расширить таргетинг | Добавить новые аудитории или темы | 5-15% |
| Добавить Brand Inclusions | Включить брендовые запросы | 3-8% |
| Добавить Search Themes | Добавить тематики поиска для Performance Max | 3-10% |

**Особенности рекомендаций по ключевым словам:**
- Основаны на анализе реальных поисковых запросов
- Учитывают сезонность и тренды
- Могут расширять охват за пределы текущей стратегии

#### 3.1.3. Ставки и бюджеты (Bidding & Budgets)

**Цель:** Оптимизация финансовых показателей кампаний.

| Рекомендация | Описание | Влияние на Score |
|--------------|----------|------------------|
| Повысить бюджет | Увеличить бюджет для получения большего трафика | 5-20% |
| Перераспределить бюджет | Перенести неиспользуемый бюджет | 3-10% |
| Перейти на Smart Bidding | Использовать автоматические стратегии | 10-25% |
| Установить Target CPA | Задать целевую стоимость конверсии | 5-15% |
| Установить Target ROAS | Задать целевую рентабельность | 5-15% |
| Использовать портфельную стратегию | Объединить кампании в портфельную стратегию | 5-10% |
| Оптимизировать корректировки ставок | Настроить bid adjustments | 3-8% |

**Типы бюджетных рекомендаций:**

1. **"Limited by Budget" (Ограничено бюджетом)**
   - Кампания могла получить больше трафика
   - Показывает упущенные клики/конверсии
   - Рекомендует конкретную сумму увеличения

2. **"Move unused budgets" (Перенести неиспользуемый бюджет)**
   - Бюджет одной кампании не расходуется полностью
   - Предлагает перенести в более активную кампанию
   - Показывает потенциальный прирост результатов

3. **"Raise budgets for upcoming traffic increases"**
   - Прогноз увеличения трафика (сезонность, тренды)
   - Рекомендация превентивно увеличить бюджет
   - Предотвращает упущенные возможности

#### 3.1.4. Ремонт и исправления (Repairs)

**Цель:** Устранение проблем, мешающих показу рекламы.

| Рекомендация | Описание | Приоритет |
|--------------|----------|-----------|
| Исправить отклонённые объявления | Объявления не прошли модерацию | Критический |
| Исправить неработающие ссылки | URL ведут на 404 страницы | Критический |
| Добавить способ оплаты | Проблемы с биллингом | Критический |
| Исправить отслеживание конверсий | Проблемы с кодом конверсии | Высокий |
| Активировать приостановленные кампании | Кампании на паузе без причины | Средний |
| Удалить неактивные ключевые слова | Ключевые слова без показов 13+ месяцев | Низкий |

**Особенности категории Repairs:**
- Фокус на устранении технических проблем
- Часто имеют высокий приоритет
- Могут автоматически применяться (автопауза неактивных ключевых слов)

#### 3.1.5. Автоматизированные кампании (Automated Campaigns)

**Цель:** Переход на автоматизированные типы кампаний.

| Рекомендация | Описание | Влияние на Score |
|--------------|----------|------------------|
| Создать Performance Max | Запустить PMax кампанию | 10-25% |
| Активировать AI Max | Включить AI Max для Search | 10-20% |
| Перейти на Demand Gen | Мигрировать с Discovery | 5-15% |
| Объединить кампании | Консолидировать похожие кампании | 5-10% |
| Добавить Final URL Expansion | Включить автоматический подбор URL | 5-10% |

#### 3.1.6. Измерение и аналитика (Measurement)

**Цель:** Улучшение отслеживания результатов.

| Рекомендация | Описание | Влияние на Score |
|--------------|----------|------------------|
| Настроить Enhanced Conversions | Улучшенное отслеживание конверсий | 5-15% |
| Добавить конверсию | Настроить дополнительные типы конверсий | 5-10% |
| Перейти на Data-Driven Attribution | Использовать DDA вместо Last Click | 3-8% |
| Связать Google Analytics | Интеграция с GA4 | 3-5% |
| Настроить Google Consent Mode | Настроить режим согласия | 3-5% |

## 4. Управление рекомендациями

### 4.1. Применение рекомендаций

**Варианты применения:**

1. **Применить одну рекомендацию**
   - Клик по кнопке "Apply" на карточке рекомендации
   - Немедленное применение изменений
   - Optimization Score увеличивается сразу

2. **Применить все рекомендации типа**
   - Массовое применение всех рекомендаций одного типа
   - Например, "Добавить все рекомендованные ключевые слова"
   - Ускоряет процесс оптимизации

3. **Просмотреть и отредактировать**
   - Возможность изменить параметры перед применением
   - Например, скорректировать бюджет или отфильтровать ключевые слова
   - Больше контроля над изменениями

### 4.2. Отклонение рекомендаций

**Бизнес-логика отклонения:**
- При отклонении рекомендация удаляется из списка
- Optimization Score увеличивается (рекомендация "обработана")
- Отклонённые рекомендации отображаются серым в прогресс-баре
- Фактическая эффективность кампаний не изменяется

**Правила повторного появления:**
- Отклонённые рекомендации могут появиться снова через определённое время
- Время зависит от типа рекомендации (от нескольких дней до месяцев)
- Если условия изменились, рекомендация может вернуться раньше

### 4.3. User Stories

```
КАК рекламодатель
Я ХОЧУ видеть все доступные рекомендации с оценкой их влияния
ЧТОБЫ приоритизировать оптимизацию

Критерии приемки:
- Вижу список рекомендаций с процентом влияния на Score
- Могу фильтровать по категориям
- Могу сортировать по влиянию
- Вижу детальное описание каждой рекомендации
```

```
КАК маркетолог
Я ХОЧУ отклонять нерелевантные рекомендации
ЧТОБЫ поддерживать высокий Optimization Score без ненужных изменений

Критерии приемки:
- Могу отклонить рекомендацию одним кликом
- Optimization Score увеличивается после отклонения
- Понимаю, когда рекомендация может появиться снова
- Не получаю штрафов за отклонение
```

## 5. Автоматическое применение рекомендаций (Auto-Apply)

### 5.1. Описание

Auto-Apply — функция автоматического применения выбранных типов рекомендаций без ручного подтверждения.

### 5.2. Категории Auto-Apply

Google Ads предлагает **24 типа** рекомендаций для автоприменения, разделённых на две группы:

#### 5.2.1. "Maintain your ads" (Поддержание объявлений)

Рекомендации, влияющие на ключевые слова и тексты объявлений:

| Настройка | Описание | Риск |
|-----------|----------|------|
| Добавить адаптивные объявления | Автоматическое создание RSA | Средний |
| Улучшить существующие объявления | Добавление заголовков/описаний | Средний |
| Удалить избыточные ключевые слова | Удаление дубликатов | Низкий |
| Удалить конфликтующие минус-слова | Устранение конфликтов | Низкий |
| Приостановить низкоэффективные объявления | Пауза плохих объявлений | Средний |
| Приостановить неактивные ключевые слова | Пауза слов без показов 13+ мес | Низкий |

#### 5.2.2. "Grow your business" (Рост бизнеса)

Рекомендации для масштабирования:

| Настройка | Описание | Риск |
|-----------|----------|------|
| Добавить новые ключевые слова | Расширение семантики | Высокий |
| Использовать широкое соответствие | Переход на broad match | Высокий |
| Использовать Smart Bidding | Переход на автостратегии | Высокий |
| Повысить бюджеты | Автоматическое увеличение бюджета | Критический |
| Добавить расширения объявлений | Автодобавление extensions | Средний |
| Оптимизировать таргетинг | Расширение аудиторий | Высокий |

### 5.3. Доступ к настройкам Auto-Apply

**Расположение:**
1. Через вкладку Recommendations → Auto-apply (правый верхний угол)
2. Через Account Settings → Auto-apply

**Выбор настроек:**
- Можно выбрать пресет "Maintain your ads" или "Grow your business"
- Можно настроить каждый тип индивидуально
- Изменения вступают в силу немедленно

### 5.4. Бизнес-правила Auto-Apply

**Ограничения:**
- Auto-apply **не увеличивает бюджет** автоматически (требует отдельного включения)
- Изменения применяются на основе ML-анализа аккаунта
- Можно просматривать историю автоматических изменений
- Отключение Auto-apply не отменяет уже применённые изменения

**Автоматическая пауза неактивных ключевых слов (с июня 2024):**
- Ключевые слова без показов 13+ месяцев приостанавливаются автоматически
- Это происходит независимо от настроек Auto-apply
- Можно вручную возобновить приостановленные ключевые слова

### 5.5. Риски и рекомендации по Auto-Apply

**Потенциальные риски:**
- Расширение таргетинга за пределы целевой аудитории
- Увеличение ставок и расходов
- Добавление нерелевантных ключевых слов
- Изменение текстов объявлений без согласования

**Рекомендации профессионалов:**
- Отключать Auto-apply для полного контроля над аккаунтом
- Если используете — выбирать только низкорисковые опции
- Регулярно проверять историю автоматических изменений
- Не полагаться на Auto-apply как на замену ручной оптимизации

### 5.6. User Stories

```
КАК занятой владелец бизнеса
Я ХОЧУ автоматически применять безопасные рекомендации
ЧТОБЫ поддерживать кампании без постоянного мониторинга

Критерии приемки:
- Могу выбрать конкретные типы рекомендаций для автоприменения
- Вижу историю автоматических изменений
- Могу отменить нежелательные изменения
- Бюджет не увеличивается без моего разрешения
```

```

ЧТОБЫ контролировать все изменения вручную

Критерии приемки:
- Могу отключить все Auto-apply опции
- Изменения не применяются автоматически
- Сохраняю полный контроль над аккаунтом
- Клиент не получает неожиданных изменений
```

## 6. AI Max для Search-кампаний

### 6.1. Описание

AI Max — набор AI-функций для Search-кампаний, активируемый одним кликом. Добавляет автоматическую оптимизацию поверх существующих настроек кампании.

### 6.2. Ключевые функции AI Max

#### 6.2.1. Search Term Matching (Расширенное соответствие запросам)

**Бизнес-логика:**
- Расширяет существующие ключевые слова с помощью broad match
- Использует "keywordless" технологию для поиска новых запросов
- Находит высокоэффективные запросы за пределами заданной семантики

**Возможности:**
- Анализ поисковых запросов в реальном времени
- Обнаружение новых релевантных запросов
- Автоматическое исключение нерелевантных запросов

#### 6.2.2. Text Customization (Кастомизация текстов)

**Бизнес-логика:**
- AI генерирует релевантные заголовки и описания
- Тексты адаптируются под поисковый запрос пользователя
- Повышает релевантность объявления каждому запросу

**Возможности:**
- Динамическая генерация заголовков
- Адаптация описаний под контекст
- Учёт намерения пользователя

#### 6.2.3. Final URL Expansion (Расширение конечных URL)

**Бизнес-логика:**
- Автоматически направляет пользователей на наиболее релевантную страницу
- Анализирует контент сайта для выбора лучшего URL
- Повышает вероятность конверсии

**Правила работы:**

## 9. Бизнес-правила модуля

### 9.1. Правила Optimization Score

1. **Расчёт в реальном времени:** Оценка обновляется при любом изменении в аккаунте
2. **Кумулятивный эффект:** Применение рекомендаций суммирует uplift
3. **Максимум 100%:** Оценка не может превысить 100%
4. **Равенство применения и отклонения:** Оба действия увеличивают Score
5. **Не влияет на аукцион:** Optimization Score не является фактором ранжирования

### 9.2. Правила рекомендаций

1. **Персонализация:** Рекомендации основаны на данных конкретного аккаунта
2. **Контекстуальность:** Учитывается отрасль, конкуренция, сезонность
3. **Обновление:** Рекомендации обновляются при изменении условий
4. **Возврат отклонённых:** Отклонённые рекомендации могут вернуться через время
5. **Приоритизация:** Рекомендации сортируются по потенциальному влиянию

### 9.3. Правила Auto-Apply

1. **Без влияния на бюджет (по умолчанию):** Auto-apply не увеличивает бюджет
2. **Выборочное применение:** Можно выбрать конкретные типы рекомендаций
3. **История изменений:** Все автоматические изменения логируются
4. **Отключение не отменяет изменения:** Уже применённые изменения сохраняются
5. **Автопауза ключевых слов:** Неактивные 13+ месяцев приостанавливаются независимо от настроек

### 9.4. Правила AI-оптимизации

1. **Требование качественных данных:** AI работает лучше с точными данными о конверсиях
2. **Период обучения:** AI-функции требуют времени для оптимизации
3. **Человеческий контроль:** Рекомендуется проверять AI-решения
4. **Бренд-контроль:** AI учитывает заданные ограничения по брендам
5. **Прозрачность:** Доступны отчёты о решениях AI

### 9.5. Приоритеты рекомендаций

| Приоритет | Тип | Примеры |
|-----------|-----|---------|
| Критический | Repairs | Отклонённые объявления, проблемы биллинга |
| Высокий | Конверсии | Настройка Enhanced Conversions, исправление тегов |
| Средний | Эффективность | Smart Bidding, расширение таргетинга |
| Низкий | Оптимизация | Добавление расширений, улучшение Ad Strength |

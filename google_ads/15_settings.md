# Настройки аккаунта Google Ads

## 1. Обзор модуля

Модуль настроек аккаунта Google Ads обеспечивает централизованное управление параметрами рекламного аккаунта, включая базовые настройки (язык, валюта, часовой пояс), интеграции с другими продуктами Google, настройки приватности и уведомлений. Данный модуль является критически важным для корректной работы всей рекламной системы.

### 1.1 Ключевые области настроек

- **Основные настройки аккаунта** — язык интерфейса, формат чисел, часовой пояс, валюта
- **Связанные аккаунты** — интеграции с Google Analytics, Search Console, YouTube, Merchant Center
- **Управление доступом** — пользователи, роли, права доступа
- **Уведомления** — email-уведомления, push-оповещения, биллинг-алерты
- **Отслеживание** — автоматическая разметка, шаблоны отслеживания
- **Приватность и данные** — настройки обмена данными с Google
- **Верификация рекламодателя** — подтверждение личности и бизнеса

## 2. Основные настройки аккаунта

### 2.1 Язык интерфейса

#### User Story: US-SET-001 — Изменение языка интерфейса
```
КАК пользователь Google Ads
Я ХОЧУ изменить язык интерфейса
ЧТОБЫ работать с системой на удобном мне языке
```

**Функциональность:**

| Параметр | Описание | Возможность изменения |
|----------|----------|----------------------|
| Язык интерфейса | Язык отображения меню, кнопок, справки | Можно изменить в любое время |
| Язык кампаний | Целевой язык аудитории для показа рекламы | Настраивается на уровне кампании |
| Язык коммуникаций | Язык email-уведомлений от Google | Привязан к языку интерфейса |

**Бизнес-правила:**

**BR-LANG-001**: Изменение языка интерфейса вступает в силу немедленно после сохранения.

**BR-LANG-002**: Язык интерфейса не влияет на язык таргетинга кампаний — это независимые настройки.

**BR-LANG-003**: Доступно более 40 языков интерфейса, включая русский, английский, немецкий, французский, испанский, китайский и другие.

**BR-LANG-004**: Некоторые функции и справка могут быть недоступны на всех языках — в таких случаях отображается английская версия.

**Бизнес-правила:**

**BR-NUM-001**: Доступные форматы чисел зависят от выбранного языка интерфейса.

**BR-NUM-002**: Некоторые языки поддерживают только один формат чисел — в этом случае настройка недоступна.

**BR-NUM-003**: Формат чисел влияет только на отображение в интерфейсе, не на экспортируемые отчёты.

### 2.3 Часовой пояс

#### User Story: US-SET-003 — Понимание часового пояса аккаунта
```
КАК владелец аккаунта
Я ХОЧУ понимать, как работает часовой пояс аккаунта
ЧТОБЫ корректно интерпретировать отчёты и расписание показов
```

**Критически важная информация:**

| Аспект | Описание |
|--------|----------|
| Установка | Часовой пояс устанавливается при создании аккаунта |
| Изменение | Можно изменить только ОДИН РАЗ за всё время существования аккаунта |
| Направление изменения | Разрешается сдвиг только на восток (UTC+) |
| Влияние | Отчётность, биллинг, расписание показов рекламы |

**Бизнес-правила:**

**BR-TZ-001**: Часовой пояс аккаунта — постоянная настройка, устанавливаемая при создании.

**BR-TZ-002**: Изменение часового пояса возможно только один раз за весь период существования аккаунта.

**BR-TZ-003**: При изменении часового пояса разрешён сдвиг только в восточном направлении (увеличение UTC-смещения).

**BR-TZ-004**: Для изменения часового пояса необходимо обращаться в поддержку Google Ads — функция недоступна в самообслуживании.

**BR-TZ-005**: Изменение часового пояса может существенно повлиять на историческую отчётность и показатели эффективности.

**BR-TZ-006**: Расписание показов объявлений (Ad Schedule) работает в часовом поясе аккаунта.

**Рекомендации:**
- При создании аккаунта тщательно выбирайте часовой пояс — это решение практически необратимо
- Используйте часовой пояс целевой аудитории или бизнес-офиса
- Для международных кампаний с разными часовыми поясами рекомендуется создавать отдельные аккаунты

### 2.4 Валюта аккаунта

#### User Story: US-SET-004 — Понимание валюты аккаунта
```
КАК финансовый директор
Я ХОЧУ понимать ограничения валюты аккаунта
ЧТОБЫ правильно планировать международные рекламные кампании
```

**Критически важная информация:**

| Аспект | Описание |
|--------|----------|
| Установка | Валюта устанавливается при создании аккаунта |
| Изменение | НЕВОЗМОЖНО изменить после создания аккаунта |
| Применение | Биллинг, отчётность, установка ставок, бюджеты |
| Конвертация | Автоматическая конвертация для международных показов |

**Бизнес-правила:**

**BR-CUR-001**: Валюта аккаунта — абсолютно постоянная настройка, не подлежащая изменению.

**BR-CUR-002**: Все финансовые операции (ставки, бюджеты, счета) производятся в валюте аккаунта.

**BR-CUR-003**: Для работы в другой валюте необходимо создать новый аккаунт Google Ads.

**BR-CUR-004**: При показе рекламы в регионах с другой валютой Google автоматически производит конвертацию по текущему курсу.

**BR-CUR-005**: Рекомендуется выбирать валюту, совпадающую с валютой бизнес-отчётности и платёжного метода.

**BR-CUR-006**: Конверсионные значения (Conversion Value) также фиксируются в валюте аккаунта.

**Поддерживаемые валюты:**
- Основные: USD, EUR, GBP, JPY, CHF, AUD, CAD
- Региональные: RUB, UAH, BYN, KZT, PLN, CZK, и другие
- Полный список зависит от страны биллинга

## 3. Связанные аккаунты (Linked Accounts)

### 3.1 Обзор интеграций

Связывание аккаунтов Google Ads с другими продуктами Google расширяет возможности рекламы и аналитики.

| Продукт | Основные преимущества интеграции |
|---------|----------------------------------|
| Google Analytics 4 | Импорт аудиторий, конверсий, понимание поведения пользователей |
| Search Console | Отчёт по платным и органическим результатам поиска |
| YouTube | Ремаркетинг по зрителям, расширенная аналитика |
| Merchant Center | Shopping-кампании, товарные фиды |
| Google Play | Продвижение мобильных приложений |
| Firebase | Конверсии и аудитории мобильных приложений |
| Salesforce | Импорт офлайн-конверсий из CRM |
| Zapier | Автоматизация рабочих процессов |

### 3.2 Google Analytics 4 (GA4)

#### User Story: US-LINK-001 — Связывание с Google Analytics 4
```
КАК маркетолог
Я ХОЧУ связать Google Ads с Google Analytics 4
ЧТОБЫ получить полную картину пользовательского поведения после клика по рекламе
```

**Преимущества интеграции:**

| Функция | Описание |
|---------|----------|
| Импорт конверсий | Использование событий GA4 как конверсий в Google Ads |
| Импорт аудиторий | Создание кампаний на основе сегментов GA4 |
| Атрибуция | Понимание многоканальной атрибуции |
| Отчёты об эффективности | Данные Google Ads в интерфейсе GA4 |
| Ремаркетинг | Создание аудиторий на основе поведения на сайте |

**Требования для связывания:**

| Требование | Описание |
|------------|----------|
| Права в Google Ads | Административный доступ к аккаунту |
| Права в GA4 | Роль Editor или Administrator в ресурсе GA4 |
| Google Account | Один и тот же Google Account для обоих продуктов |
| Auto-tagging | Рекомендуется включить автоматическую разметку |

**Бизнес-правила:**

**BR-GA4-001**: Для связывания необходимы административные права в обоих продуктах.

**BR-GA4-002**: Один ресурс GA4 можно связать с несколькими аккаунтами Google Ads.

**BR-GA4-003**: После связывания данные начинают собираться с момента интеграции — историческая синхронизация отсутствует.

**BR-GA4-004**: Для корректной работы интеграции рекомендуется включить автоматическую разметку (auto-tagging).

**BR-GA4-005**: Разрыв связи прекращает обмен данными, но уже импортированные аудитории и конверсии сохраняются.

## 4. Управление доступом

### 4.1 Уровни доступа

#### User Story: US-ACCESS-001 — Приглашение нового пользователя
```
КАК администратор аккаунта
Я ХОЧУ пригласить коллегу в аккаунт Google Ads
ЧТОБЫ он мог работать с рекламными кампаниями
```

**Уровни доступа:**

| Уровень | Кампании | Биллинг | Пользователи | Настройки |
|---------|----------|---------|--------------|-----------|
| Admin | Полный доступ | Полный доступ | Управление | Полный доступ |
| Standard | Редактирование | Просмотр | Нет | Ограниченный |
| Read-only | Просмотр | Просмотр | Нет | Просмотр |
| Billing | Нет | Полный доступ | Нет | Нет |
| Email-only | Нет | Нет | Нет | Нет |

**Бизнес-правила:**

**BR-ACCESS-001**: Права доступа назначаются на уровне всего аккаунта — нельзя ограничить доступ к отдельным кампаниям.

**BR-ACCESS-002**: Пользователь может выдавать права только своего уровня или ниже.

**BR-ACCESS-003**: Для выдачи Admin-доступа необходимо самому иметь Admin-права.

**BR-ACCESS-004**: При удалении пользователя его доступ прекращается немедленно.

**BR-ACCESS-005**: Можно установить срок истечения доступа (Access Expiration).

**BR-ACCESS-006**: Если в аккаунте один пользователь — он должен иметь Admin-права.

## 6. Настройки отслеживания

### 6.1 Автоматическая разметка (Auto-tagging)

#### User Story: US-TRACK-001 — Включение автоматической разметки
```
КАК специалист по аналитике
Я ХОЧУ включить автоматическую разметку
ЧТОБЫ корректно отслеживать конверсии и интегрировать с Google Analytics
```

**Что такое GCLID:**

| Аспект | Описание |
|--------|----------|
| Расшифровка | Google Click Identifier |
| Формат | Уникальный параметр, добавляемый к URL |
| Пример | www.example.com/?gclid=123xyz |
| Назначение | Идентификация источника клика для аналитики и конверсий |

**Преимущества auto-tagging:**

| Преимущество | Описание |
|--------------|----------|
| Конверсии | Точное отслеживание конверсий с рекламы |
| Интеграция с GA4 | Автоматическая передача данных в Google Analytics |
| Офлайн-конверсии | Возможность импорта офлайн-конверсий |
| Атрибуция | Детальная атрибуция по кампаниям, объявлениям, ключевым словам |

**Бизнес-правила:**

**BR-AUTOTAG-001**: Auto-tagging включён по умолчанию для новых аккаунтов.

**BR-AUTOTAG-002**: Auto-tagging обязателен для интеграции с Google Analytics 4.

**BR-AUTOTAG-003**: Auto-tagging обязателен для импорта офлайн-конверсий.

**BR-AUTOTAG-004**: Некоторые сайты не поддерживают произвольные URL-параметры — в этом случае необходимо тестирование.

**BR-AUTOTAG-005**: GCLID хранится в first-party cookie на домене сайта.

**BR-AUTOTAG-006**: При использовании редиректов необходимо убедиться, что GCLID передаётся на финальную страницу.

### 6.3 Модели атрибуции

#### User Story: US-TRACK-003 — Выбор модели атрибуции
```
КАК аналитик
Я ХОЧУ настроить модель атрибуции конверсий
ЧТОБЫ корректно оценивать вклад различных кампаний
```

**Доступные модели атрибуции:**

| Модель | Описание | Статус |
|--------|----------|--------|
| Data-driven | Распределение на основе ML и исторических данных | По умолчанию |
| Last click | Вся ценность последнему клику | Поддерживается |
| First click | Вся ценность первому клику | Устарела (deprecated) |
| Linear | Равное распределение по всем точкам | Устарела |
| Time decay | Больше ценности недавним взаимодействиям | Устарела |
| Position-based | 40-20-40 распределение | Устарела |

**Бизнес-правила:**

**BR-ATTR-001**: Data-driven attribution — модель по умолчанию для большинства конверсионных действий.

**BR-ATTR-002**: Модели First click, Linear, Time decay и Position-based устарели и были автоматически мигрированы на Data-driven.

**BR-ATTR-003**: Last click остаётся доступной как альтернатива Data-driven.

**BR-ATTR-004**: Модель атрибуции настраивается для каждого конверсионного действия отдельно.

**BR-ATTR-005**: Изменение модели атрибуции влияет только на будущие данные — исторические не пересчитываются.

## 8. Верификация рекламодателя

### 8.1 Обзор программы верификации

#### User Story: US-VERIFY-001 — Прохождение верификации
```
КАК новый рекламодатель
Я ХОЧУ пройти верификацию
ЧТОБЫ мои объявления могли показываться без ограничений
```

**Этапы верификации:**

| Этап | Описание | Срок |
|------|----------|------|
| Запрос на верификацию | Google отправляет уведомление | — |
| Начало верификации | Рекламодатель должен начать в течение 30 дней | 30 дней |
| Завершение верификации | Предоставить все требуемые документы | 30 дней после начала |
| Проверка Google | Google рассматривает документы | 3-5 рабочих дней (обычно) |

**Типы верификации:**

| Тип | Описание | Требования |
|-----|----------|------------|
| Identity Verification | Подтверждение личности | Паспорт, ID-карта, водительские права |
| Business Verification | Подтверждение бизнеса | Свидетельство о регистрации, учредительные документы |

**Необходимые документы:**

| Документ | Назначение | Примеры |
|----------|------------|---------|
| Удостоверение личности | Подтверждение представителя | Паспорт, ID-карта (действующие) |
| Регистрационные документы | Подтверждение юридического лица | Свидетельство о регистрации, выписка ЕГРЮЛ |
| Документы об адресе | Подтверждение местонахождения | Счета за коммунальные услуги, банковские выписки |

**Бизнес-правила:**

**BR-VERIFY-001**: Верификация обязательна для всех рекламодателей в большинстве регионов.

**BR-VERIFY-002**: Невыполнение верификации в установленный срок приводит к приостановке аккаунта.

**BR-VERIFY-003**: Предоставление ложной информации — нарушение политики, ведущее к приостановке.

**BR-VERIFY-004**: После верификации информация о рекламодателе отображается в Ads Transparency Center.

**BR-VERIFY-005**: Повторная верификация может потребоваться при изменении юридических данных.

## 10. Статус аккаунта

### 10.1 Состояния аккаунта

| Статус | Описание | Действия |
|--------|----------|----------|
| Active | Аккаунт работает нормально | Стандартные операции |
| Suspended | Приостановлен за нарушения | Апелляция, исправление |
| Canceled | Закрыт владельцем | Возможно восстановление |
| Pending | Ожидает активации/верификации | Завершить настройку |
| Limited | Ограниченная функциональность | Пройти верификацию |

### 10.2 Причины приостановки

| Причина | Описание | Решение |
|---------|----------|---------|
| Policy violation | Нарушение рекламных политик | Устранить нарушение, подать апелляцию |
| Unpaid balance | Неоплаченные счета | Оплатить задолженность |
| Suspicious activity | Подозрительная активность | Пройти верификацию |
| Verification failure | Не пройдена верификация | Предоставить корректные документы |

**Бизнес-правила:**

**BR-STATUS-001**: Приостановленный аккаунт переходит в режим "только чтение".

**BR-STATUS-002**: При приостановке все объявления немедленно прекращают показ.

**BR-STATUS-003**: Для восстановления необходимо устранить причину приостановки и подать апелляцию.

**BR-STATUS-004**: История аккаунта сохраняется даже после длительной приостановки.

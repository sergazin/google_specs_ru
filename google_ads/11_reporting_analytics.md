# Модуль "Отчёты и аналитика" — Google Ads

## 1. Общее описание модуля

Модуль "Отчёты и аналитика" — ключевой компонент Google Ads, обеспечивающий полный цикл анализа эффективности рекламных кампаний. Модуль предоставляет инструменты для создания стандартных и кастомных отчётов, визуализации данных на дашбордах, глубокой сегментации по множеству измерений, а также AI-рекомендации для оптимизации кампаний. Функциональность включает автоматизацию отправки отчётов, экспорт данных в различных форматах и интеграцию с Google Analytics для расширенной аналитики.

---

## 2. Ключевые метрики

### 2.1 Метрики охвата и вовлечённости

#### Показы (Impressions)
- **Определение:** Количество раз, когда реклама была показана на страницах поисковой выдачи Google, партнёрских сайтах или в приложениях
- **Применение:** Оценка видимости рекламы, анализ охвата аудитории
- **Особенности:** Учитываются все показы, включая те, где пользователь не взаимодействовал с рекламой

#### Клики (Clicks)
- **Определение:** Количество кликов по объявлениям
- **Применение:** Измерение интереса пользователей к рекламе
- **Типы:** Клики по заголовку, кнопкам, расширениям, изображениям

#### Показатель кликабельности (CTR — Click-Through Rate)
- **Формула:** (Клики / Показы) × 100%
- **Интерпретация:** Показывает релевантность рекламы для целевой аудитории
- **Бенчмарки (2025):**
  - Поисковая реклама: 4-6% (хороший показатель)
  - Медийная реклама: 0.46% (средний показатель по отраслям)
- **Бизнес-значение:** Высокий CTR снижает стоимость клика и улучшает Quality Score

#### Показатель вовлечённости (Engagement Rate)
- **Определение:** Процент взаимодействий с рекламой (лайки, расширения карточек, просмотры видео)
- **Применение:** Особенно важен для видеорекламы и медийных кампаний

---

### 2.2 Финансовые метрики

#### Стоимость клика (CPC — Cost Per Click)
- **Формула:** Общие расходы / Количество кликов
- **Факторы влияния:** Конкуренция по ключевым словам, Quality Score, время показа, таргетинг на устройства
- **Бенчмарки (2025):**
  - Юридические услуги: $8-12+
  - Финансы: $6-10
  - Путешествия: $1-3
  - Образование: $1-3

#### Стоимость за тысячу показов (CPM — Cost Per Mille)
- **Формула:** (Общие расходы / Показы) × 1000
- **Применение:** Основная метрика для медийных кампаний с целью узнаваемости бренда

#### Стоимость привлечения (CPA — Cost Per Acquisition)
- **Формула:** Общие расходы / Количество конверсий
- **Интерпретация:** Средняя стоимость получения одной конверсии (покупки, лида, регистрации)
- **Бизнес-значение:** Ключевой показатель эффективности инвестиций в рекламу

#### Общие расходы (Cost / Spend)
- **Определение:** Суммарные расходы на рекламу за выбранный период
- **Детализация:** Доступен разрез по кампаниям, группам объявлений, ключевым словам, объявлениям

---

### 2.3 Метрики конверсий

#### Конверсии (Conversions)
- **Определение:** Количество завершённых целевых действий (покупка, регистрация, заявка, звонок)
- **Типы:**
  - Первичные конверсии — используются для оптимизации ставок
  - Вторичные конверсии — только для отчётности, не влияют на ставки

#### Коэффициент конверсии (Conversion Rate)
- **Формула:** (Конверсии / Клики) × 100%
- **Бенчмарки (2025):** Медианное значение 4.61% (по данным агентств)
- **Интерпретация:** Показывает эффективность рекламы и посадочных страниц в превращении кликов в действия

#### Ценность конверсий (Conversion Value)
- **Определение:** Суммарная денежная ценность всех конверсий
- **Применение:** Для e-commerce — реальная выручка; для лидогенерации — присвоенная стоимость лида

#### Ценность конверсии по расходам (Value/Cost)
- **Формула:** Ценность конверсий / Расходы на рекламу
- **Интерпретация:** Показывает, сколько дохода приносит каждый рубль, вложенный в рекламу

---

### 2.4 Метрики рентабельности

#### Возврат на рекламные расходы (ROAS — Return on Ad Spend)
- **Формула:** (Доход от конверсий / Расходы на рекламу) × 100%
- **Пример:** ROAS 400% означает $4 дохода на каждый $1 расходов
- **Бизнес-значение:** Ключевой показатель прибыльности рекламных кампаний
- **Целевые значения:** Зависят от маржинальности бизнеса; типичный минимум 300-400%

#### Рентабельность инвестиций (ROI — Return on Investment)
- **Формула:** ((Доход - Расходы на рекламу) / Расходы на рекламу) × 100%
- **Отличие от ROAS:** Учитывает чистую прибыль, а не валовый доход

---

### 2.5 Метрики качества

#### Показатель качества (Quality Score)
- **Шкала:** От 1 до 10 (10 — максимальный)
- **Компоненты:**
  - **Ожидаемый CTR** — прогноз кликабельности на основе исторических данных
  - **Релевантность объявления** — соответствие текста объявления ключевым словам
  - **Качество посадочной страницы** — релевантность, скорость загрузки, удобство для пользователя
- **Влияние на показатели:**
  - Высокий Quality Score снижает CPC
  - Улучшает позиции объявлений при равных ставках
- **Целевое значение:** 7+ для оптимальной эффективности

#### Доля показов (Impression Share)
- **Определение:** Процент показов от общего количества возможных показов
- **Формула:** (Полученные показы / Доступные показы) × 100%
- **Типы потерь:**
  - Потери из-за рейтинга — низкий Ad Rank (Quality Score × ставка)
  - Потери из-за бюджета — исчерпание дневного бюджета

#### Доля показов на первой позиции (Top Impression Share)
- **Определение:** Процент показов над органической выдачей

#### Абсолютная доля показов на первой позиции (Abs. Top Impression Share)
- **Определение:** Процент показов на самой первой позиции в рекламном блоке

## 3. Модели атрибуции

### 3.1 Атрибуция на основе данных (Data-Driven Attribution)
- **Статус:** Модель по умолчанию для большинства конверсий
- **Принцип работы:** Использует машинное обучение для анализа всех рекламных взаимодействий на пути к конверсии
- **Распределение ценности:** Каждое взаимодействие (клик, просмотр) получает долю ценности конверсии пропорционально своему вкладу
- **Преимущества:**
  - Учитывает уникальные паттерны поведения для каждого рекламодателя
  - Отражает реальный путь клиента к покупке
  - Позволяет точнее оптимизировать ставки
- **Требования:** Достаточный объём данных для обучения модели

### 3.2 Атрибуция по последнему клику (Last Click)
- **Принцип работы:** 100% ценности конверсии присваивается последнему клику перед конверсией
- **Применение:** Подходит для бизнесов с коротким циклом принятия решения
- **Ограничения:** Не учитывает влияние предыдущих взаимодействий

### 3.3 Устаревшие модели (удалены с 2023)
Следующие модели больше не поддерживаются:
- **Первый клик (First Click)** — вся ценность первому взаимодействию
- **Линейная (Linear)** — равное распределение между всеми касаниями
- **С учётом давности (Time Decay)** — больший вес недавним взаимодействиям
- **На основе позиции (Position-Based)** — 40% первому, 40% последнему, 20% промежуточным

## 4. Типы отчётов

### 4.1 Предопределённые отчёты (Predefined Reports)

#### Описание
Готовые шаблоны отчётов, созданные Google для типичных задач анализа. Более 40 отчётов доступны в один клик. Ранее известны как "Dimensions reports".

#### Категории предопределённых отчётов

**Отчёты по времени:**
- Отчёт по дням (Day)
- Отчёт по дням недели (Day of Week)
- Отчёт по часам (Hour of Day)
- Отчёт по месяцам (Month)
- Отчёт по кварталам (Quarter)
- Отчёт по годам (Year)

**Отчёты по конверсиям:**
- Действия конверсий (Conversion Action)
- Категории конверсий (Conversion Category)
- Источник конверсий (Conversion Source)
- Время до конверсии (Time to Conversion)
- Путь к конверсии (Conversion Path)

**Отчёты по географии:**
- Страны (Country)
- Регионы (Region)
- Города (City)
- Местоположения пользователей (User Locations)
- Целевые местоположения (Targeted Locations)

**Отчёты по устройствам:**
- Тип устройства (Device Type)
- Операционная система (Operating System)

**Отчёты по расширениям:**
- Расширения звонков (Call Extensions)
- Расширения местоположений (Location Extensions)
- Расширения дополнительных ссылок (Sitelink Extensions)
- Структурированные описания (Structured Snippets)
- Расширения с уточнениями (Callout Extensions)

**Отчёты для Shopping:**
- Эффективность продуктов (Product Performance)
- Эффективность по категориям (Shopping Category Performance)
- Ценовая конкурентоспособность (Price Competitiveness)
- Сравнительная видимость (Competitive Visibility)

**Отчёты по ключевым словам:**
- Поисковые запросы (Search Terms)
- Эффективность ключевых слов (Keyword Performance)
- Типы соответствия (Match Types)

#### Бизнес-правила предопределённых отчётов
- Доступны всем пользователям аккаунта
- Можно настраивать колонки и фильтры
- Изменения можно сохранить как новый отчёт
- Поддерживают экспорт в CSV, Excel, PDF

---

### 4.2 Кастомные отчёты (Custom Reports)

#### Описание
Гибкие отчёты, создаваемые пользователем в Report Editor для специфических задач анализа.

#### Возможности кастомных отчётов
- Выбор произвольных измерений и метрик
- Добавление неограниченного количества строк и столбцов
- Фильтрация по данным, не включённым в отчёт
- Сохранение для повторного использования
- Планирование автоматической отправки

#### Примеры кастомных отчётов
- Эффективность по дням недели и часам для определения лучшего времени показа
- Сравнение конверсий по устройствам и географии
- Анализ качества ключевых слов с низким Quality Score
- Отчёт по неэффективным объявлениям (высокий CTR, низкий Conversion Rate)

---

### 4.3 Отчёты по поисковым запросам (Search Terms Reports)

#### Описание
Показывают реальные поисковые запросы, по которым были показаны объявления.

#### Содержимое отчёта
- Текст поискового запроса
- Ключевое слово, которое вызвало показ
- Тип соответствия
- Количество показов и кликов
- Расходы и конверсии

#### Применение
- Поиск новых ключевых слов для добавления
- Выявление нерелевантных запросов для минус-слов
- Анализ намерений пользователей

---

### 4.4 Отчёты по аукционам (Auction Insights)

#### Описание
Сравнение показателей с конкурентами, участвующими в тех же аукционах.

#### Доступные метрики
- **Доля показов (Impression Share)** — ваш % от общих показов
- **Частота пересечения (Overlap Rate)** — как часто реклама конкурента показывалась вместе с вашей
- **Доля выигрышей (Outranking Share)** — как часто ваше объявление занимало более высокую позицию
- **Позиция над конкурентом (Position Above Rate)** — как часто вы были выше конкретного конкурента
- **Доля показов на верхней позиции (Top of Page Rate)** — % показов над органикой
- **Абсолютная доля верхней позиции** — % показов на самой первой позиции

#### Бизнес-правила
- Отображаются только конкуренты с достаточным объёмом данных
- Конкуренты анонимизированы как "Competitor 1", "Competitor 2" и т.д.
- Доступен на уровне кампаний, групп объявлений, ключевых слов

## 5. Редактор отчётов (Report Editor)

### 5.1 Общее описание

Report Editor — встроенный инструмент Google Ads для создания, визуализации и анализа данных без необходимости экспорта в сторонние инструменты.

### 5.2 Функциональные возможности

#### Drag-and-Drop интерфейс
- Перетаскивание измерений в область строк
- Перетаскивание метрик в область столбцов
- Интуитивная настройка без кода

#### Типы визуализаций
- **Таблица (Table)** — классическое табличное представление
- **Линейный график (Line)** — тренды во времени
- **Столбчатая диаграмма (Column)** — сравнение категорий
- **Горизонтальная гистограмма (Bar)** — рейтинги и ранжирование
- **Круговая диаграмма (Pie)** — доли от целого
- **Точечная диаграмма (Scatter)** — корреляции между метриками

#### Иерархические таблицы (Tree Tables)
- Drill-down по уровням: Кампания → Группа объявлений → Ключевое слово → Объявление
- Раскрытие и сворачивание узлов
- Без ограничений на глубину иерархии

#### Drill-Down в диаграммах
- Клик по сегменту открывает детализацию
- Поддерживается для столбчатых, горизонтальных и круговых диаграмм
- Неограниченное количество уровней детализации

### 5.3 Фильтрация и сортировка

#### Типы фильтров
- Фильтры по колонкам отчёта (Campaign = "Brand Campaign")
- Фильтры по данным вне отчёта (показать только клики из определённой кампании)
- Множественные условия с операторами AND/OR
- Диапазоны значений (CPC > $1.00 AND CPC < $5.00)

#### Сортировка
- По возрастанию/убыванию для любой метрики
- Мультисортировка (сначала по CTR, затем по кликам)
- Сохранение параметров сортировки

### 5.4 Работа с несколькими аккаунтами (MCC)

#### Функционал для управляющих аккаунтов
- Консолидированные отчёты по нескольким аккаунтам
- Фильтрация по имени аккаунта или метке (label)
- Сравнение показателей между аккаунтами
- Единый отчёт для всех клиентов агентства

#### Настройка
1. Выбор иконки редактирования рядом с "All accounts"
2. Выбор способа отображения: по имени или по метке аккаунта
3. Выбор аккаунтов для включения в отчёт

### 5.5 Бизнес-правила Report Editor

- Отчёты видны всем пользователям с доступом к аккаунту
- Возможность фильтрации: все отчёты или только созданные мной
- Каждый отчёт можно редактировать, сохранять, планировать, делиться
- Лимит на количество отчётов: определяется уровнем аккаунта

## 6. Дашборды (Dashboards)

### 6.1 Общее описание

Дашборды предоставляют единое пространство для консолидированного просмотра ключевых показателей со всего аккаунта в реальном времени.

### 6.2 Компоненты дашборда

#### Scorecards (Карточки показателей)
- Отображение одной ключевой метрики крупным числом
- Процент изменения по сравнению с предыдущим периодом
- Цветовая индикация (рост/падение)
- Примеры: Общие расходы, Конверсии за сегодня, CTR за неделю

#### Reports (Отчёты/Графики)
- Любые отчёты из Report Editor
- Таблицы, графики, диаграммы
- Интерактивность сохраняется на дашборде

#### Notes (Заметки)
- Текстовые блоки с пояснениями
- Комментарии к изменениям
- Напоминания и цели

### 6.3 Управление компонентами

#### Размещение и размер
- Drag-and-drop для перемещения
- Изменение размера растягиванием краёв
- Адаптивная сетка

#### Добавление компонентов
- Кнопка "+" для добавления новых карточек
- Выбор типа: Scorecard, Report, Note
- Настройка параметров для каждого типа

### 6.4 Типовые дашборды

#### Обзорный дашборд (Overview)
- Общие расходы за период
- Количество кликов и показов
- CTR и средний CPC
- Количество конверсий и ROAS
- Тренд расходов за последние 30 дней

#### Дашборд эффективности кампаний
- Таблица топ-10 кампаний по расходам
- График динамики кликов по кампаниям
- Сравнение CTR между кампаниями
- Pie-chart распределения бюджета

#### Дашборд конверсий
- Количество конверсий по типам
- Стоимость конверсии (CPA) по кампаниям
- Conversion Rate по устройствам
- Тренд конверсий за месяц

#### Дашборд качества
- Quality Score по ключевым словам
- Impression Share и причины потерь
- Топ слов с низким Quality Score
- Динамика Quality Score во времени

### 6.5 Доступ к дашбордам
- Путь: Campaigns → Insights and reports → Dashboards
- Кнопка "+" для создания нового дашборда
- Присвоение имени и настройка макета

## 7. Сегментация данных

### 7.1 Сегментация по времени

#### Доступные временные сегменты
- **День (Day)** — разбивка по дням (доступно при диапазоне ≤16 дней)
- **День недели (Day of Week)** — понедельник-воскресенье
- **Час (Hour)** — 0-23 часа
- **Неделя (Week)** — понедельник-воскресенье
- **Месяц (Month)** — календарные месяцы
- **Квартал (Quarter)** — Q1, Q2, Q3, Q4
- **Год (Year)** — календарные годы

#### Применение временной сегментации
- Определение лучших дней и часов для показа рекламы
- Выявление сезонных паттернов
- Анализ влияния праздников и событий
- Оптимизация расписания показов (Ad Scheduling)

### 7.2 Сегментация по устройствам

#### Типы устройств
- **Компьютеры (Computers)** — десктопы и ноутбуки
- **Мобильные телефоны (Mobile Phones)** — смартфоны
- **Планшеты (Tablets)** — iPad и Android-планшеты
- **ТВ-экраны (TV Screens)** — Smart TV и подключённые устройства

#### Дополнительные измерения устройств
- Операционная система (iOS, Android, Windows, macOS)
- Модель устройства (при достаточном объёме данных)

#### Применение
- Корректировка ставок по типам устройств
- Адаптация объявлений под мобильные
- Анализ различий в конверсии по устройствам

### 7.3 Географическая сегментация

#### Уровни географии
- **Страна (Country)**
- **Регион/Штат/Область (Region)**
- **Город (City)**
- **Почтовый индекс (Postal Code)** — где доступно
- **Район мегаполиса (Metro Area)** — агломерации

#### Типы местоположений
- **Физическое местоположение (Physical Location)** — где находится пользователь
- **Интересующее местоположение (Location of Interest)** — что пользователь ищет
- **Целевое местоположение (Targeted Location)** — соответствие настройкам таргетинга

#### Применение
- Корректировка ставок по регионам
- Исключение неэффективных географий
- Локализация рекламных сообщений
- Анализ региональной конкуренции

### 7.4 Сегментация по аудиториям

#### Типы аудиторных сегментов
- **Аудитории по интересам (Affinity Audiences)** — долгосрочные интересы
- **Аудитории по намерениям (In-Market Audiences)** — активно ищущие товар/услугу
- **Похожие аудитории (Similar Audiences)** — пользователи, похожие на существующих клиентов
- **Аудитории ремаркетинга (Your Data / Remarketing)** — посетители сайта, покупатели
- **Кастомные аудитории (Custom Audiences)** — на основе ключевых слов, URL, приложений
- **Демографические сегменты** — возраст, пол, доход домохозяйства, родительский статус

#### Применение аудиторной сегментации
- Анализ эффективности по сегментам
- Корректировка ставок для ценных аудиторий
- Исключение неконвертирующих сегментов
- Создание отдельных кампаний для лучших аудиторий

### 7.5 Сегментация по сети

#### Сети показа
- **Поисковая сеть Google (Google Search)**
- **Поисковые партнёры (Search Partners)**
- **Контекстно-медийная сеть (Display Network)**
- **YouTube**
- **Gmail**
- **Discover**

#### Применение
- Сравнение эффективности между сетями
- Отключение неэффективных сетей
- Раздельный анализ Search и Display

### 7.6 Сегментация по конверсиям

#### Измерения конверсий
- **Действие конверсии (Conversion Action)** — конкретная конверсия
- **Категория конверсии (Conversion Category)** — покупка, лид, регистрация
- **Источник конверсии (Conversion Source)** — веб-сайт, приложение, звонок
- **Тип конверсии** — первичная/вторичная

#### Применение
- Анализ какие типы конверсий генерирует кампания
- Оптимизация под конкретные конверсии
- Понимание воронки продаж

### 9.2 Планирование отчётов (Scheduled Reports)

#### Настройка расписания
1. Открыть отчёт или таблицу статистики
2. Нажать иконку скачивания
3. Выбрать "Schedule" (Запланировать)
4. Указать частоту и формат

#### Частота отправки
- **Ежедневно (Daily)** — каждый день
- **Еженедельно (Weekly)** — выбранный день недели
- **Ежемесячно (Monthly)** — выбранный день месяца
- **По рабочим дням (Weekdays)** — понедельник-пятница

#### Время генерации отчётов
- Индивидуальные аккаунты: 1:00 по часовому поясу аккаунта
- Управляющие аккаунты (MCC): 5:00 по часовому поясу
- Аккаунты без часового пояса: 1:00 по времени сервера

#### Получатели
- Только пользователи с доступом к аккаунту Google Ads
- Получатели получают ссылку на скачивание (требуется авторизация)
- Ограничение: нельзя отправить внешним пользователям напрямую

## 10. Интеграция с Google Analytics 4

### 10.1 Связывание аккаунтов

#### Преимущества связывания
- Импорт целей GA4 как конверсий в Google Ads
- Создание аудиторий на основе поведения на сайте
- Расширенная аналитика пост-клик поведения
- Единая картина пути клиента

### 10.2 Расширенные метрики из GA4

#### Поведенческие метрики
- **Показатель отказов (Bounce Rate)** — доля сессий с одной страницей
- **Средняя продолжительность сессии (Avg. Session Duration)**
- **Страниц за сессию (Pages/Session)**
- **Доля новых пользователей (% New Users)**

#### Метрики вовлечённости GA4
- **Engaged Sessions** — сессии >10 секунд, с конверсией или >1 просмотра
- **Engagement Rate** — доля engaged sessions
- **Average Engagement Time** — среднее время активного взаимодействия

### 10.3 Кросс-канальная атрибуция

#### Возможности
- Анализ всех каналов трафика в одном отчёте
- Понимание вклада Google Ads в общую картину
- Сравнение с органическим трафиком, соцсетями, email

### 10.4 Predictive Audiences (Прогнозные аудитории)

#### Описание
Аудитории на основе машинного обучения GA4.

#### Типы
- **Likely to Purchase** — пользователи с высокой вероятностью покупки
- **Likely to Churn** — пользователи, которые могут уйти
- **Predicted Revenue** — прогноз дохода от пользователя

#### Применение
- Импорт прогнозных аудиторий в Google Ads
- Таргетинг на пользователей с высокой вероятностью конверсии
- Ремаркетинг для удержания

## 14. Глоссарий терминов

| Термин | Определение |
|--------|-------------|
| **Impression** | Показ — факт отображения рекламы пользователю |
| **Click** | Клик — взаимодействие пользователя с рекламой |
| **CTR** | Click-Through Rate — коэффициент кликабельности |
| **CPC** | Cost Per Click — стоимость одного клика |
| **CPM** | Cost Per Mille — стоимость 1000 показов |
| **CPA** | Cost Per Acquisition — стоимость привлечения |
| **ROAS** | Return on Ad Spend — возврат на рекламные расходы |
| **Conversion** | Конверсия — целевое действие пользователя |
| **Quality Score** | Показатель качества — оценка релевантности рекламы |
| **Impression Share** | Доля показов от доступных |
| **Attribution** | Атрибуция — распределение ценности конверсии по касаниям |
| **Segment** | Сегмент — измерение для разбивки данных |
| **Dashboard** | Дашборд — панель с консолидированными показателями |
| **Scorecard** | Карточка показателя — виджет с одной метрикой |
| **Report Editor** | Редактор отчётов — инструмент создания кастомных отчётов |
| **MCC** | My Client Center — управляющий аккаунт для нескольких аккаунтов |
| **DDA** | Data-Driven Attribution — атрибуция на основе данных |

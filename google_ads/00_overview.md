# Google Ads — Функциональная спецификация

## Общее описание

**Google Ads** (ранее Google AdWords) — крупнейшая в мире платформа контекстной и медийной рекламы, принадлежащая Google. Позволяет рекламодателям показывать объявления в поисковой выдаче Google, на YouTube, в Gmail, Google Maps, а также на миллионах партнёрских сайтов через контекстно-медийную сеть (Google Display Network).

### Ключевые характеристики платформы

| Параметр | Значение |
|----------|----------|
| Запуск | 23 октября 2000 (как AdWords) |
| Ребрендинг | 24 июля 2018 (Google Ads) |
| Доля рынка | ~28% мирового рынка digital-рекламы |
| Выручка (2024) | ~$237 млрд |
| Рекламодателей | 7+ млн активных аккаунтов |

### Бизнес-модель

- **Оплата за клик (CPC)** — основная модель для поисковой рекламы
- **Оплата за показы (CPM)** — для медийной и видеорекламы
- **Оплата за конверсии (CPA)** — для Performance-кампаний
- **Оплата за просмотр (CPV)** — для видеорекламы на YouTube

## Целевая аудитория

### Рекламодатели

| Сегмент | Описание | Типичный бюджет |
|---------|----------|-----------------|
| **Малый бизнес** | Локальные компании, стартапы | $100 — $5,000/мес |
| **Средний бизнес** | Региональные компании, e-commerce | $5,000 — $50,000/мес |

### Роли пользователей

| Роль | Описание |
|------|----------|
| **Владелец аккаунта** | Полный контроль, включая биллинг и доступы |
| **Администратор** | Управление кампаниями и пользователями |
| **Стандартный доступ** | Создание и редактирование кампаний |
| **Только чтение** | Просмотр отчётов без редактирования |
| **Биллинг** | Только управление платежами |
| **Email-only** | Только получение уведомлений |

## Ключевые метрики платформы

### Метрики эффективности

| Метрика | Описание | Формула |
|---------|----------|---------|
| **CTR** | Click-Through Rate | Clicks / Impressions × 100% |
| **CPC** | Cost Per Click | Cost / Clicks |
| **CPA** | Cost Per Acquisition | Cost / Conversions |
| **ROAS** | Return on Ad Spend | Conversion Value / Cost |
| **Quality Score** | Оценка качества (1-10) | CTR + Relevance + Landing Page |
| **Impression Share** | Доля показов | Impressions / Total Eligible Impressions |

## Глоссарий

| Термин | Определение |
|--------|-------------|
| **Ad Rank** | Позиция объявления = Max CPC × Quality Score |
| **Attribution** | Модель распределения ценности конверсии между точками касания |
| **Bid** | Максимальная сумма за клик/показ/конверсию |
| **Conversion** | Целевое действие пользователя (покупка, заявка) |
| **GCLID** | Google Click Identifier — уникальный ID клика |
| **Impression** | Показ объявления пользователю |
| **MCC** | Manager Account — управляющий аккаунт для агентств |
| **Performance Max** | AI-управляемый тип кампании для всех каналов |
| **Quality Score** | Оценка качества ключевого слова (1-10) |
| **ROAS** | Return on Ad Spend — возврат на рекламные расходы |
| **Smart Bidding** | Автоматические стратегии ставок на ML |
| **Remarketing** | Повторный таргетинг на посетителей сайта |

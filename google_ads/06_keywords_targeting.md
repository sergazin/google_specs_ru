# Ключевые слова и таргетинг

## Описание
Модуль управления ключевыми словами и таргетингом в Google Ads. Включает выбор типов соответствия ключевых слов, управление минус-словами, использование Планировщика ключевых слов, настройку показателя качества (Quality Score), геотаргетинг, языковой таргетинг, таргетинг по устройствам, аудиториям и расписанию показов.

---

## 1. Типы соответствия ключевых слов

### FR-KT-001: Широкое соответствие (Broad Match)
**Описание:** Максимальный охват аудитории с показом объявлений по связанным запросам
**Синтаксис:** Ключевое слово без модификаторов (например: `теннисные туфли`)
**Поведение:**
- Показ по синонимам, связанным поискам, ошибкам в написании
- Включает концептуально связанные запросы
- Является типом соответствия по умолчанию
- Рекомендуется использовать со Smart Bidding для оптимизации ставок

**Бизнес-правила:**
- BR-001: Smart Bidding обязателен для эффективного использования широкого соответствия
- BR-002: Требуется регулярный анализ отчета по поисковым запросам
- BR-003: Необходимо активное управление минус-словами

**User Story:**
> Как рекламодатель, я хочу использовать широкое соответствие, чтобы максимизировать охват потенциальных клиентов, которые ищут товары/услуги, связанные с моим бизнесом.

**Пример:**
| Ключевое слово | Возможные поисковые запросы |
|----------------|----------------------------|
| теннисные туфли | купить кроссовки для тенниса, спортивная обувь для корта, лучшие туфли для тенниса |

---

### FR-KT-002: Фразовое соответствие (Phrase Match)
**Описание:** Показ объявлений по запросам, содержащим смысл ключевой фразы
**Синтаксис:** Ключевое слово в кавычках (например: `"теннисные туфли"`)
**Поведение:**
- Показ по запросам, включающим значение ключевой фразы
- Учитывает подразумеваемый смысл и более конкретные формы
- Баланс между охватом и релевантностью
- Google учитывает контекст и намерение пользователя

**Бизнес-правила:**
- BR-004: Фразовое соответствие не требует буквального совпадения слов
- BR-005: Порядок слов в запросе не обязательно должен совпадать с ключевым словом
- BR-006: Система исключает запросы, не соответствующие намерению пользователя

**User Story:**
> Как рекламодатель, я хочу использовать фразовое соответствие, чтобы показывать объявления пользователям, ищущим именно мой тип продукта/услуги.

**Пример:**
| Ключевое слово | Показывается по запросам | Не показывается |
|----------------|-------------------------|-----------------|
| "теннисные туфли" | купить теннисные туфли, туфли для тенниса красные | туфли для бальных танцев |

---

### FR-KT-003: Точное соответствие (Exact Match)
**Описание:** Максимальный контроль над показами с точным совпадением значения запроса
**Синтаксис:** Ключевое слово в квадратных скобках (например: `[теннисные туфли]`)
**Поведение:**
- Показ только по запросам с точным или очень близким значением
- Включает близкие варианты: опечатки, множественное/единственное число
- Минимальный охват, максимальная релевантность
- Идеально для высокоприбыльных или высококонверсионных ключевых слов

**Бизнес-правила:**
- BR-007: "Точное" соответствие учитывает близкие варианты
- BR-008: Система показывает по запросам с тем же намерением
- BR-009: Рекомендуется для кампаний с фокусом на ROAS

**User Story:**
> Как рекламодатель, я хочу использовать точное соответствие для самых важных ключевых слов, чтобы привлекать только высококачественный трафик.

**Пример:**
| Ключевое слово | Показывается по запросам | Не показывается |
|----------------|-------------------------|-----------------|
| [красные туфли] | красные туфли, туфли красного цвета | красные кроссовки |

## 2. Минус-слова (Negative Keywords)

### FR-KT-004: Управление минус-словами на уровне группы объявлений
**Описание:** Точечное исключение запросов для конкретной группы объявлений
**Основной сценарий:**
1. Рекламодатель открывает группу объявлений
2. Переходит в раздел "Минус-слова"
3. Нажимает "Добавить минус-слово"
4. Выбирает "Минус-слово для группы объявлений"
5. Вводит минус-слово с выбранным типом соответствия
6. Сохраняет изменения

**Бизнес-правила:**
- BR-010: Минус-слова на уровне группы применяются только к этой группе
- BR-011: Используется для разделения трафика между группами в одной кампании
- BR-012: Позволяет направлять определенные запросы в нужную группу объявлений

**User Story:**
> Как рекламодатель, я хочу добавлять минус-слова на уровне группы объявлений, чтобы каждая группа получала только релевантный трафик.

---

### FR-KT-005: Управление минус-словами на уровне кампании
**Описание:** Исключение запросов для всех групп объявлений в кампании
**Основной сценарий:**
1. Рекламодатель открывает кампанию
2. Переходит в раздел "Минус-слова"
3. Нажимает "Добавить минус-слово"
4. Выбирает "Минус-слово для кампании"
5. Вводит минус-слово
6. Сохраняет изменения

**Бизнес-правила:**
- BR-013: Минус-слова кампании применяются ко всем группам объявлений
- BR-014: Приоритет над минус-словами на уровне аккаунта при конфликте
- BR-015: Используется для исключения нерелевантных тематик из всей кампании

**User Story:**
> Как рекламодатель, я хочу добавлять минус-слова на уровне кампании, чтобы исключить нерелевантные запросы из всех групп объявлений сразу.

---

### FR-KT-006: Управление минус-словами на уровне аккаунта
**Описание:** Глобальное исключение запросов для всего рекламного аккаунта
**Основной сценарий:**
1. Рекламодатель открывает настройки аккаунта
2. Переходит в раздел "Минус-слова на уровне аккаунта"
3. Добавляет минус-слова
4. Сохраняет изменения

**Ограничения:**
- Максимум 1,000 минус-слов на уровне аккаунта
- Применяется ко всем поисковым и торговым кампаниям

**Бизнес-правила:**
- BR-016: Минус-слова аккаунта применяются ко всем релевантным типам кампаний
- BR-017: Идеально для исключения брендов конкурентов или нецелевых запросов
- BR-018: Не применяется к Performance Max кампаниям

**User Story:**
> Как рекламодатель, я хочу управлять минус-словами на уровне аккаунта, чтобы исключить определенные запросы из всей рекламной активности.

---

### FR-KT-007: Списки минус-слов
**Описание:** Создание многоразовых списков минус-слов для применения к кампаниям
**Основной сценарий:**
1. Рекламодатель открывает "Общая библиотека" в Tools
2. Выбирает "Списки минус-слов"
3. Создает новый список
4. Добавляет минус-слова в список
5. Применяет список к одной или нескольким кампаниям

**Ограничения:**
- Максимум 20 списков минус-слов на аккаунт
- До 5,000 минус-слов в каждом списке

**Бизнес-правила:**
- BR-019: Один список может применяться к нескольким кампаниям
- BR-020: Изменения в списке автоматически применяются ко всем связанным кампаниям
- BR-021: Можно удалить список из кампании без удаления самого списка

**User Story:**
> Как рекламодатель, я хочу создавать списки минус-слов, чтобы эффективно применять одинаковые исключения к нескольким кампаниям.

---

### FR-KT-008: Типы соответствия для минус-слов
**Описание:** Настройка точности исключения запросов
**Типы соответствия:**
- **Широкое минус-соответствие:** Исключает запросы со всеми словами минус-слова (в любом порядке)
- **Фразовое минус-соответствие:** Исключает запросы с точной фразой
- **Точное минус-соответствие:** Исключает только точное совпадение запроса

**Бизнес-правила:**
- BR-022: Минус-слова НЕ учитывают близкие варианты автоматически (обновление 2025: Google расширил обработку опечаток)
- BR-023: Для Display и Video кампаний все минус-слова добавляются как широкое соответствие
- BR-024: Тип соответствия нельзя изменить для Display/Video кампаний

**User Story:**
> Как рекламодатель, я хочу выбирать тип соответствия для минус-слов, чтобы точно контролировать какие запросы исключаются.

## 3. Планировщик ключевых слов (Keyword Planner)

### FR-KT-009: Поиск новых ключевых слов
**Описание:** Генерация идей ключевых слов на основе слов или URL
**Основной сценарий (по словам):**
1. Рекламодатель открывает Keyword Planner в Tools
2. Выбирает "Найти новые ключевые слова"
3. Вводит слова, связанные с продуктом/услугой (до 10 слов)
4. Система генерирует список связанных ключевых слов
5. Для каждого ключевого слова показывается:
   - Среднее количество поисков в месяц
   - Конкуренция (низкая/средняя/высокая)
   - Диапазон ставки для показа вверху страницы
6. Рекламодатель фильтрует и выбирает нужные ключевые слова
7. Добавляет выбранные слова в план или кампанию

**Основной сценарий (по URL):**
1. Рекламодатель выбирает "Начать с сайта"
2. Вводит URL страницы
3. Система анализирует контент и генерирует релевантные ключевые слова
4. Далее как в сценарии по словам

**Бизнес-правила:**
- BR-025: Для доступа к Keyword Planner требуется Expert Mode в аккаунте
- BR-026: Данные обновляются ежедневно на основе последних 7-10 дней
- BR-027: Конкуренция показывает количество рекламодателей, а не органическую SEO конкуренцию

**User Story:**
> Как рекламодатель, я хочу находить новые идеи ключевых слов, чтобы расширить охват моих кампаний релевантными запросами.

---

### FR-KT-010: Прогноз объема поиска и эффективности
**Описание:** Получение прогнозов по ключевым словам
**Основной сценарий:**
1. Рекламодатель открывает Keyword Planner
2. Выбирает "Получить объем поиска и прогнозы"
3. Вводит список ключевых слов
4. Система показывает для плана:
   - Прогнозируемое количество кликов
   - Прогнозируемое количество показов
   - Ожидаемая стоимость
   - Прогнозируемые конверсии
   - Средняя позиция
5. Рекламодатель корректирует ставки и бюджет для оптимизации

**Настройки прогноза:**
- Географическое местоположение
- Язык
- Поисковая сеть (Google или Google + партнеры)
- Диапазон дат

**Бизнес-правила:**
- BR-028: Прогнозы основаны на исторических данных с учетом сезонности
- BR-029: При нестабильном рынке рекомендуется еженедельное планирование
- BR-030: Прогнозы - это оценки, фактические результаты могут отличаться

**User Story:**
> Как рекламодатель, я хочу получать прогнозы по ключевым словам, чтобы планировать бюджет и ожидаемые результаты кампаний.

---

### FR-KT-011: Автоматическая организация ключевых слов
**Описание:** Группировка ключевых слов в тематические группы объявлений
**Основной сценарий:**
1. Рекламодатель генерирует список ключевых слов
2. Нажимает "Автоматически организовать ключевые слова"
3. Система группирует слова по тематикам
4. Для каждой группы предлагается название
5. Рекламодатель может:
   - Принять предложенную структуру
   - Изменить группировку вручную
   - Переименовать группы
6. Добавляет организованные группы в кампанию

**Бизнес-правила:**
- BR-031: Автоматическая группировка основана на семантической близости
- BR-032: Рекомендуется проверить и скорректировать группировку вручную
- BR-033: Каждая группа должна содержать тематически связанные ключевые слова

**User Story:**
> Как рекламодатель, я хочу автоматически организовать ключевые слова в группы, чтобы создать структурированные кампании с релевантными объявлениями.

---

### FR-KT-012: Исторические тренды и сезонность
**Описание:** Анализ трендов поисковых запросов во времени
**Основной сценарий:**
1. Рекламодатель выбирает ключевое слово
2. Просматривает график объема поиска по месяцам
3. Система показывает:
   - Исторические данные за выбранный период
   - Сезонные пики и спады
   - Тренд роста/падения интереса
4. Рекламодатель использует данные для планирования сезонных кампаний

**Бизнес-правила:**
- BR-034: Диапазон дат влияет на отображение сезонных трендов
- BR-035: Данные доступны за последние 4 года
- BR-036: Сезонность учитывается в автоматических прогнозах

**User Story:**
> Как рекламодатель, я хочу видеть сезонные тренды по ключевым словам, чтобы планировать кампании в периоды максимального спроса.

## 4. Показатель качества (Quality Score)

### FR-KT-013: Расчет и отображение показателя качества
**Описание:** Оценка качества ключевых слов, объявлений и целевых страниц
**Шкала:** От 1 до 10 (10 - максимальное качество)
**Компоненты:**
1. **Ожидаемый CTR (39% веса):**
   - Вероятность клика на объявление
   - Статус: Выше среднего / Средний / Ниже среднего

2. **Релевантность объявления (22% веса):**
   - Соответствие объявления намерению пользователя
   - Статус: Выше среднего / Средний / Ниже среднего

3. **Качество целевой страницы (39% веса):**
   - Полезность и релевантность страницы
   - Статус: Выше среднего / Средний / Ниже среднего

**Бизнес-правила:**
- BR-037: Quality Score - диагностический инструмент, НЕ используется напрямую в аукционе
- BR-038: Оценка основана на сравнении с другими рекламодателями за последние 90 дней
- BR-039: Реальные компоненты (CTR, релевантность, страница) оцениваются в реальном времени на аукционе

**User Story:**
> Как рекламодатель, я хочу видеть показатель качества моих ключевых слов, чтобы понимать какие области требуют улучшения.

---

### FR-KT-014: Влияние показателя качества на аукцион
**Описание:** Связь качества с позицией объявления и стоимостью клика
**Механизм:**
- Ad Rank = Ставка x Quality Score (упрощенно)
- Высокий Quality Score может снизить CPC до 50%
- Низкий Quality Score увеличивает CPC и снижает позицию

**Влияние Quality Score на CPC:**
| Quality Score | Относительное изменение CPC |
|---------------|---------------------------|
| 10 | -50% |
| 8 | -25% |
| 6 | 0% (базовый) |
| 4 | +25% |
| 2 | +150% |
| 1 | +400% |

**Бизнес-правила:**
- BR-040: Высокий Quality Score = ниже стоимость за те же позиции
- BR-041: Quality Score влияет на право участия в аукционе
- BR-042: При Quality Score 1-3 объявления могут не показываться

**User Story:**
> Как рекламодатель, я хочу улучшать показатель качества, чтобы снизить стоимость кликов и повысить позицию объявлений.

---

### FR-KT-015: Оптимизация ожидаемого CTR
**Описание:** Улучшение вероятности клика на объявление
**Рекомендации:**
1. Использовать ключевые слова в заголовках объявлений
2. Создавать убедительные призывы к действию
3. Тестировать разные варианты объявлений
4. Использовать расширения объявлений
5. Выделять уникальные преимущества

**Основной сценарий:**
1. Рекламодатель видит статус "Ниже среднего" для CTR
2. Анализирует текущие объявления
3. Создает новые варианты с улучшенными текстами
4. Запускает A/B тест
5. Оставляет лучший вариант

**User Story:**
> Как рекламодатель, я хочу улучшить ожидаемый CTR моих объявлений, чтобы повысить показатель качества.

---

### FR-KT-016: Оптимизация релевантности объявления
**Описание:** Улучшение соответствия объявления поисковому запросу
**Рекомендации:**
1. Разделять группы объявлений по темам
2. Включать ключевые слова в текст объявления
3. Создавать отдельные объявления для разных намерений
4. Избегать слишком общих формулировок
5. Соответствовать ожиданиям пользователя

**Основной сценарий:**
1. Рекламодатель видит статус "Ниже среднего" для релевантности
2. Проверяет соответствие ключевых слов и объявлений
3. Разделяет большую группу на несколько тематических
4. Создает специфичные объявления для каждой группы
5. Отслеживает улучшение показателя

**User Story:**
> Как рекламодатель, я хочу улучшить релевантность объявлений, чтобы показывать пользователям именно то, что они ищут.

---

### FR-KT-017: Оптимизация качества целевой страницы
**Описание:** Улучшение посадочной страницы для пользователей
**Рекомендации:**
1. Соответствие контента страницы объявлению
2. Быстрая загрузка страницы (особенно на мобильных)
3. Удобная навигация
4. Мобильная адаптивность
5. Уникальный и полезный контент
6. Прозрачность и доверие (контакты, политики)

**Основной сценарий:**
1. Рекламодатель видит статус "Ниже среднего" для страницы
2. Проверяет скорость загрузки (PageSpeed Insights)
3. Анализирует мобильную версию
4. Улучшает соответствие контента объявлению
5. Оптимизирует пользовательский опыт

### FR-KT-036: Комбинированные аудитории
**Описание:** Создание аудиторий из комбинации нескольких сегментов
**Операторы:**
- **AND:** Пользователь должен быть во всех выбранных аудиториях
- **OR:** Пользователь должен быть хотя бы в одной аудитории
- **NOT:** Исключение пользователей из определенной аудитории

**Основной сценарий:**
1. Рекламодатель создает комбинированную аудиторию
2. Выбирает базовые сегменты
3. Применяет операторы (AND, OR, NOT)
4. Система рассчитывает охват
5. Применяет к кампаниям

**Пример:**
- In-market "Автомобили" AND Affinity "Люксовый образ жизни" NOT Customer Match "Существующие клиенты"

**User Story:**
> Как рекламодатель премиальных авто, я хочу таргетироваться на людей, ищущих автомобили И интересующихся люксом, исключая текущих клиентов.

### FR-KT-037: Режимы таргетинга аудиторий
**Описание:** Настройка способа применения аудиторий к кампаниям
**Режимы:**
1. **Наблюдение (Observation):**
   - Аудитория добавляется для сбора данных
   - Показы НЕ ограничиваются аудиторией
   - Можно настроить корректировки ставок

2. **Таргетинг (Targeting):**
   - Объявления показываются ТОЛЬКО этой аудитории
   - Ограничивает охват
   - Максимальная релевантность

**Бизнес-правила:**
- BR-094: Начинать рекомендуется с Observation для сбора данных
- BR-095: При Targeting трафик вне аудитории помечается как "unknown"
- BR-096: Корректировки ставок работают в обоих режимах

**User Story:**
> Как рекламодатель, я хочу сначала добавить аудитории в режиме наблюдения, чтобы понять их эффективность перед сужением таргетинга.

## Сущности данных

### Ключевое слово (Keyword)
- **Keyword ID**
- **Ad Group ID**
- **Текст ключевого слова**
- **Тип соответствия** - broad/phrase/exact
- **Ставка** (если ручная)
- **Статус** - enabled/paused/removed
- **Quality Score** - 1-10
- **Ожидаемый CTR** - above_average/average/below_average
- **Релевантность объявления** - above_average/average/below_average
- **Качество страницы** - above_average/average/below_average

### Минус-слово (Negative Keyword)
- **Negative Keyword ID**
- **Уровень** - account/campaign/ad_group/list
- **Текст минус-слова**
- **Тип соответствия** - broad/phrase/exact
- **Campaign ID** (если применимо)
- **Ad Group ID** (если применимо)
- **List ID** (если применимо)

### Список минус-слов (Negative Keyword List)
- **List ID**
- **Account ID**
- **Название**
- **Количество минус-слов**
- **Связанные кампании**

### Настройки таргетинга кампании (Campaign Targeting)
- **Campaign ID**
- **Локации** - массив целевых и исключенных
- **Языки** - массив языков
- **Устройства** - корректировки ставок
- **Расписание** - массив временных интервалов
- **Аудитории** - массив сегментов и режимов
- **Демография** - настройки возраста/пола/дохода

### Аудитория (Audience Segment)
- **Audience ID**
- **Тип** - affinity/in_market/remarketing/customer_match/combined
- **Название**
- **Размер**
- **Правила** (для remarketing)
- **Срок членства**

## Бизнес-правила (сводка)

### Ключевые слова
- BR-001: Smart Bidding обязателен для эффективного использования широкого соответствия
- BR-002: Требуется регулярный анализ отчета по поисковым запросам
- BR-003: Необходимо активное управление минус-словами
- BR-004: Фразовое соответствие не требует буквального совпадения слов
- BR-007: "Точное" соответствие учитывает близкие варианты
- BR-009: Точное соответствие рекомендуется для кампаний с фокусом на ROAS

### Минус-слова
- BR-010: Минус-слова на уровне группы применяются только к этой группе
- BR-013: Минус-слова кампании применяются ко всем группам объявлений
- BR-022: Минус-слова НЕ учитывали близкие варианты (обновление 2025: расширена обработка опечаток)

### Quality Score
- BR-037: Quality Score - диагностический инструмент, НЕ используется напрямую в аукционе
- BR-040: Высокий Quality Score = ниже стоимость за те же позиции
- BR-042: При Quality Score 1-3 объявления могут не показываться

### Геотаргетинг
- BR-048: 100% точность геолокации не гарантируется
- BR-052: Исключение локации имеет приоритет над включением
- BR-055: "Присутствие или интерес" дает +5% конверсий для travel/недвижимости

### Устройства и расписание
- BR-071: Нельзя исключить мобильные полностью (только до -90%)
- BR-076: Smart Bidding учитывает устройство автоматически
- BR-083: При Smart Bidding корректировки по времени НЕ работают

### Аудитории
- BR-088: Минимальный размер ремаркетинг списка: 100 для Display, 1000 для Search
- BR-094: Начинать рекомендуется с Observation для сбора данных
- BR-093: Match rate Customer Match обычно 20-50%

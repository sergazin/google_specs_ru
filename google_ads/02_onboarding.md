# Google Ads: Модуль "Онбординг и первая настройка"

## 1. Общее описание модуля

Модуль онбординга Google Ads обеспечивает полный цикл первичной настройки рекламного аккаунта: от регистрации до запуска первой рекламной кампании. Модуль включает создание аккаунта, настройку биллинга, верификацию рекламодателя, связывание с другими сервисами Google и создание первой кампании.

### 1.1 Ключевые бизнес-цели модуля

- Минимизация времени от регистрации до первого показа рекламы
- Снижение барьера входа для новых рекламодателей
- Автоматизация настройки для неопытных пользователей (Smart Mode)
- Обеспечение соответствия рекламодателей политикам платформы
- Интеграция с экосистемой Google для максимальной эффективности рекламы

## 2. Роли и права доступа

### 2.1 Уровни доступа к индивидуальному аккаунту

| Роль | Описание | Права |
|------|----------|-------|
| **Администратор (Admin)** | Полный контроль над аккаунтом | Управление пользователями, все настройки, биллинг, кампании |
| **Стандартный (Standard)** | Операционное управление | Создание/редактирование кампаний, просмотр отчётов, получение уведомлений |
| **Только чтение (Read-only)** | Просмотр информации | Просмотр кампаний, отчётов, настроек (без возможности изменений) |
| **Биллинг (Billing)** | Управление оплатой | Просмотр и редактирование платёжной информации |
| **Только email (Email-only)** | Получение уведомлений | Получение email-отчётов и уведомлений |

### 2.2 Уровни доступа к Manager Account (MCC)

| Роль | Описание | Права |
|------|----------|-------|
| **Административный** | Полный контроль | Управление иерархией, все функции |
| **Стандартный** | Управление без иерархии | Редактирование аккаунтов без управления структурой |
| **Только чтение** | Просмотр | Просмотр всех связанных аккаунтов |
| **Только email** | Уведомления | Получение уведомлений |
| **Биллинг** | Платежи | Управление биллингом связанных аккаунтов |

### 2.3 Бизнес-правила для ролей

- Пользователь может предоставить доступ только того уровня, который имеет сам или ниже
- Рекомендуется минимум 2 администратора на аккаунт
- Права устанавливаются на уровне аккаунта (не кампании)
- Доступ может иметь срок действия (auto-expire)
- Связанные аккаунты наследуют ограничения при блокировке основного

## 3. Режимы работы: Smart Mode vs Expert Mode

### 3.1 Smart Mode (для начинающих)

**Характеристики:**
- Упрощённый интерфейс
- Автоматический выбор ключевых слов
- Автоматическое управление ставками
- Ограниченный контроль над кампаниями
- Только одна цель на кампанию
- Автоматическое отслеживание конверсий

**Доступные типы кампаний:**
- Smart Campaigns

**Ограничения:**
- Нет доступа к типам соответствия ключевых слов
- Нет минус-слов
- Нет расширенных стратегий назначения ставок
- Нет детальной настройки таргетинга

### 3.2 Expert Mode (полный функционал)

**Характеристики:**
- Полный интерфейс Google Ads
- Все типы кампаний
- Детальный контроль над настройками
- Пользовательское отслеживание конверсий

**Доступные типы кампаний:**
- Search
- Display
- Shopping
- Video
- App
- Performance Max
- Smart Campaigns

### 3.3 Переключение режимов

| Действие | Возможность | Примечание |
|----------|-------------|------------|
| Smart → Expert | Да | Односторонний переход |
| Expert → Smart | Нет | Невозможно вернуться |
| Редактирование Smart-кампаний в Expert | Да | Существующие кампании доступны |

## 4. Процесс создания аккаунта

### 4.1 User Story: Создание первого аккаунта

```
КАК новый рекламодатель
Я ХОЧУ создать аккаунт Google Ads
ЧТОБЫ начать рекламировать свой бизнес

Критерии приёмки:
- Могу зарегистрироваться с существующим Google-аккаунтом
- Могу пропустить создание первой кампании
- Могу выбрать страну биллинга и валюту
- Получаю подтверждение создания аккаунта
```

### 4.2 Этапы создания аккаунта

```
[Вход через Google Account]
        ↓
[Выбор цели рекламы] ←→ [Пропуск: Switch to Expert Mode]
        ↓
[Настройка первой кампании]
        ↓
[Ввод бизнес-информации]
        ↓
[Настройка биллинга]
        ↓
[Подтверждение и активация]
```

### 4.3 Бизнес-правила создания аккаунта

1. **Обязательная привязка к Google Account**
   - Один Google Account может иметь несколько Google Ads аккаунтов
   - Email подтверждение не требуется (используется верифицированный Google Account)

2. **Выбор страны и валюты**
   - Страна биллинга определяет доступные способы оплаты
   - Валюта выбирается один раз и не может быть изменена
   - Часовой пояс фиксируется при создании

3. **Принудительное создание кампании**
   - По умолчанию система направляет на создание Smart Campaign
   - Можно пропустить через "Switch to Expert Mode"
   - При пропуске аккаунт создаётся без активных кампаний

## 5. Настройка биллинга

### 5.1 User Story: Настройка оплаты

```
КАК владелец аккаунта
Я ХОЧУ настроить способ оплаты
ЧТОБЫ мои объявления могли показываться

Критерии приёмки:
- Могу выбрать тип платежей (автоматические/ручные)
- Могу добавить платёжный метод
- Могу настроить резервный способ оплаты
- Получаю подтверждение настройки биллинга
```

### 5.2 Типы платёжных настроек

| Тип | Описание | Доступность |
|-----|----------|-------------|
| **Автоматические платежи** | Списание после накопления расходов | По умолчанию для большинства стран |
| **Ручные платежи** | Предоплата перед показом рекламы | Доступно в определённых странах |
| **Ежемесячное выставление счетов** | Кредитная линия с ежемесячной оплатой | Только для соответствующих требованиям |

### 5.3 Доступные способы оплаты

- **Банковские карты**: Visa, MasterCard, American Express (в отдельных регионах)
- **Прямое списание с банковского счёта**: Доступно в определённых странах
- **Банковский перевод**: Для ежемесячного выставления счетов
- **Локальные платёжные системы**: Зависит от страны

### 5.4 Бизнес-правила биллинга

1. **Пороговые значения для автоматических платежей**
   - Списание происходит при достижении порога или 1-го числа месяца
   - Начальный порог: низкий (зависит от страны)
   - Порог увеличивается при успешной истории платежей

2. **Лимиты расходов**
   - Дневной лимит: устанавливается на уровне кампании
   - Максимальный дневной расход: до 2x от дневного бюджета
   - Месячный лимит: 30.4 × дневной бюджет
   - Аккаунтный лимит: опционально для ежемесячного выставления счетов

3. **Резервный способ оплаты**
   - Рекомендуется для непрерывности показов
   - Автоматическое переключение при отклонении основного метода

4. **Блокировка при проблемах с оплатой**
   - Неоплаченный баланс → приостановка показов
   - Подозрительная платёжная активность → приостановка аккаунта
   - Злоупотребление промокодами → приостановка аккаунта

### 5.5 Промокоды и кредиты для новых рекламодателей

| Тип предложения | Условия | Сроки |
|-----------------|---------|-------|
| **Стандартное** | Потратьте $500 → получите $500 кредит | 60 дней на трату, 35 дней на верификацию |
| **Расширенное** | Потратьте $1500 → получите $1000 кредит | Аналогично |
| **Premium** | Потратьте $3000 → получите $1500 кредит | Аналогично |

**Правила использования промокодов:**
- Один промокод на рекламодателя
- Активация в течение 14 дней после первого показа
- Использование в течение 60 дней после активации
- Кредит только на рекламу (не возвращается при закрытии)
- Требуется статус "нового рекламодателя"

## 6. Верификация рекламодателя

### 6.1 User Story: Прохождение верификации

```
КАК рекламодатель
Я ХОЧУ пройти верификацию личности/бизнеса
ЧТОБЫ получить возможность показывать рекламу

Критерии приёмки:
- Получаю уведомление о необходимости верификации
- Могу загрузить необходимые документы
- Вижу статус проверки
- Получаю результат в установленные сроки
```

### 6.2 Типы верификации

| Тип | Для кого | Документы |
|-----|----------|-----------|
| **Верификация личности** | Физические лица, ИП | Паспорт, удостоверение личности |
| **Верификация бизнеса** | Юридические лица | Регистрационные документы, лицензии |
| **Операционная верификация** | Определённые категории | Дополнительные документы по запросу |

### 6.3 Процесс верификации

```
[Уведомление о верификации]
        ↓
[30 дней на начало процесса]
        ↓
[Заполнение информации о бизнесе]
        ↓
[Загрузка документов]
        ↓
[30 дней на завершение]
        ↓
[Проверка (3-5 рабочих дней)]
        ↓
[Результат: одобрено/отклонено/запрос доп. документов]
```

### 6.4 Состояния верификации

| Состояние | Описание | Возможные действия |
|-----------|----------|-------------------|
| **Не требуется** | Верификация не запрошена | Продолжение работы |
| **Ожидает начала** | Получено уведомление | Начать процесс (30 дней) |
| **В процессе** | Документы на проверке | Ожидание, добавление документов |
| **Требуются доп. документы** | Запрошена информация | Загрузка документов |
| **Одобрена** | Верификация пройдена | - |
| **Отклонена** | Верификация не пройдена | Апелляция |

### 6.5 Последствия непрохождения верификации

- Приостановка показа рекламы
- Возможная блокировка аккаунта
- Распространение на связанные аккаунты (тот же email, платёжный метод, MCC)

### 6.6 Повторная верификация

Требуется при:
- Изменении платёжного профиля
- Смене биллинг-адреса
- Обновлении бизнес-информации
- Периодические проверки для безопасности

## 10. Создание Manager Account (MCC)

### 10.1 User Story: Создание MCC

```
КАК агентство/крупный рекламодатель
Я ХОЧУ создать Manager Account
ЧТОБЫ управлять несколькими аккаунтами из одного места

Критерии приёмки:
- Могу создать MCC без существующего Google Ads аккаунта
- Могу пригласить существующие аккаунты
- Могу создавать новые аккаунты под MCC
- Вижу сводные данные по всем аккаунтам
```

### 10.2 Структура MCC

```
[Top-Level MCC]
    ├── [Sub-MCC 1]
    │       ├── Client Account A
    │       └── Client Account B
    ├── [Sub-MCC 2]
    │       └── Client Account C
    └── [Direct Client Account D]
```

### 10.3 Ограничения MCC

| Параметр | Лимит |
|----------|-------|
| Максимум аккаунтов в MCC | 85,000 |
| Связь с несколькими MCC в одной иерархии | Запрещено |
| Уровней вложенности MCC | Без ограничений |

### 10.4 Функционал владения аккаунтом

- **Ownership (владение)**: Полный контроль, включая удаление
- **Link (связывание)**: Ограниченный доступ по согласованию
- Владелец-MCC может передать владение другому MCC
- При приостановке MCC связанные аккаунты не затрагиваются

## 11. Состояния аккаунта

### 11.1 Жизненный цикл аккаунта

```
[Создание]
    ↓
[Активный] ←→ [На паузе]
    ↓          ↓
[Приостановлен] ←→ [Апелляция на рассмотрении]
    ↓
[Закрыт/Удалён]
```

### 11.2 Состояния и переходы

| Состояние | Описание | Показ рекламы | Переходы |
|-----------|----------|---------------|----------|
| **Создание** | Процесс регистрации | Нет | → Активный |
| **Активный** | Полнофункциональный | Да | → На паузе, → Приостановлен |
| **На паузе** | Пользователь приостановил | Нет | → Активный |
| **Приостановлен** | Google приостановил | Нет | → Апелляция, → Активный |
| **Апелляция на рассмотрении** | Идёт проверка | Нет | → Активный, → Приостановлен |
| **Закрыт** | Аккаунт закрыт | Нет | Невозможно восстановить |

### 11.3 Причины приостановки

| Категория | Примеры |
|-----------|---------|
| **Биллинг** | Неоплаченный баланс, chargeback, подозрительная активность |
| **Политики** | Нарушение рекламных политик, запрещённый контент |
| **Верификация** | Непройденная верификация в срок |
| **Безопасность** | Подозрительный доступ, взлом |

### 11.4 Правила блокировки связанных аккаунтов

При блокировке основного аккаунта могут быть заблокированы:
- Аккаунты с тем же email
- Аккаунты с тем же платёжным методом
- Аккаунты в той же MCC-иерархии

**Запрещено**: Создавать новый аккаунт для обхода блокировки

## 12. Состояния объявлений и кампаний

### 12.1 Статусы проверки объявлений

| Статус | Описание | Показ |
|--------|----------|-------|
| **Under review** | На проверке | Не показывается |
| **Eligible** | Проверка пройдена, но есть ограничения | Ограничен |
| **Approved** | Полностью одобрено | Показывается |
| **Approved (limited)** | Одобрено с ограничениями | Ограничен |
| **Disapproved** | Отклонено | Не показывается |

### 12.2 Сроки проверки

- Стандартная проверка: 1 рабочий день
- Сложные случаи: до нескольких дней
- Повторная проверка после редактирования: перезапуск процесса

### 12.3 Статусы кампаний

| Статус | Описание | Причины |
|--------|----------|---------|
| **Eligible** | Готова к показу, но не показывается | Биллинг не настроен, низкий бюджет |
| **Enabled** | Активна и показывается | Нормальная работа |
| **Paused** | Приостановлена пользователем | Ручная пауза |
| **Removed** | Удалена | Удаление пользователем |
| **Pending** | Запланирована | Будущая дата начала |
| **Ended** | Завершена | Прошла дата окончания |

## 14. Бизнес-правила модуля

### 14.1 Общие правила

1. **Одна валюта на аккаунт**: Выбирается при создании, изменить нельзя
2. **Один часовой пояс**: Фиксируется при создании
3. **Обязательный биллинг**: Реклама не показывается без настроенной оплаты
4. **Верификация по требованию**: Google может запросить в любой момент
5. **Соответствие политикам**: Нарушение ведёт к приостановке

### 14.2 Правила для новых рекламодателей

1. **Период обучения**: Первые 2-4 недели алгоритмы обучаются
2. **Начальные лимиты**: Низкие пороги биллинга, увеличиваются со временем
3. **Рекомендуемый бюджет**: Система предлагает на основе целей
4. **Smart Mode по умолчанию**: Направление на упрощённый режим

### 14.3 Правила Smart Campaigns

1. **Требуется Google Business Profile** для полного функционала
2. **Автоматический выбор ключевых слов** на основе тем
3. **Несколько кампаний** для разных аспектов бизнеса разрешены
4. **Отслеживание конверсий** настраивается автоматически или вручную

### 14.4 Правила Performance Max

1. **Минимум ассетов**: Требуются изображения, заголовки, описания
2. **Рекомендуемые конверсии**: 20-30 в месяц на кампанию
3. **Brand Guidelines**: Автоматически применяются с v21 API
4. **Период обучения**: 2-4 недели на оптимизацию

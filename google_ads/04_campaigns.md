# Модуль: Управление кампаниями (Campaign Management)

## Обзор модуля

Модуль управления кампаниями является центральным компонентом Google Ads, обеспечивающим создание, настройку и управление рекламными кампаниями различных типов. Кампания представляет собой контейнер верхнего уровня, который объединяет группы объявлений, настройки таргетинга, бюджет и стратегию назначения ставок.

---

## 1. Типы кампаний

### 1.1 Search (Поисковые кампании)

**Описание**: Текстовые объявления, отображаемые в результатах поиска Google, когда пользователи вводят релевантные запросы.

**Особенности**:
- Показ по ключевым словам с различными типами соответствия
- Работа на основе аукционной модели
- Оплата за клик (CPC)
- Возможность добавления расширений объявлений (sitelinks, callouts, structured snippets)

**Доступные цели**: Продажи, Лиды, Трафик на сайт

**Типы соответствия ключевых слов**:

| Тип соответствия | Синтаксис | Охват | Описание |
|-----------------|-----------|-------|----------|
| Широкое (Broad) | ключевое слово | Максимальный | Показы по синонимам, связанным запросам, опечаткам |
| Фразовое (Phrase) | "ключевое слово" | Средний | Показы по запросам, содержащим значение ключевого слова |
| Точное (Exact) | [ключевое слово] | Минимальный | Показы по запросам с тем же значением или намерением |

**Минус-слова**:
- Позволяют исключать нерелевантные поисковые запросы
- Поддерживают три типа соответствия (работают иначе, чем положительные)
- Лимит: до 10,000 минус-слов на кампанию (с 2025 года)
- Минус-слова автоматически блокируют опечатки (обновление 2025)
- НЕ блокируют автоматически синонимы и множественные формы

**AI Max (2025)**:
- Набор AI-функций внутри стандартных Search-кампаний
- Активируется одним кликом
- Добавляет дополнительную автоматизацию поверх существующих настроек

### 1.2 Display (Медийные кампании)

**Описание**: Визуальные объявления (баннеры, изображения), показываемые на миллионах сайтов и приложений контекстно-медийной сети Google.

**Особенности**:
- Охват более 2 миллионов сайтов и приложений
- Показ на YouTube (в ленте, на главной)
- Автоматическая оптимизация таргетинга
- Адаптивные медийные объявления (Responsive Display Ads)

**Доступные цели**: Продажи, Лиды, Трафик, Узнаваемость бренда

**Методы таргетинга**:

| Метод | Описание |
|-------|----------|
| Аудитории по интересам (Affinity) | Пользователи с устойчивыми интересами и хобби |
| Аудитории заинтересованных покупателей (In-market) | Пользователи, активно изучающие товары/услуги |
| Ремаркетинг | Пользователи, ранее взаимодействовавшие с брендом |
| Похожие аудитории (Lookalike) | Пользователи, похожие на существующих клиентов |
| Темы (Topics) | Размещение на сайтах определенной тематики |
| Места размещения (Placements) | Конкретные сайты, приложения, YouTube-каналы |
| Ключевые слова для контекста | Страницы с определенным содержанием |
| Демография | Возраст, пол, родительский статус, доход домохозяйства |

**Режимы таргетинга**:
- **Targeting (Таргетинг)**: Сужает показы только до выбранных аудиторий/контента
- **Observation (Наблюдение)**: Не ограничивает показы, но собирает статистику по выбранным критериям

**Оптимизированный таргетинг**:
- Включен по умолчанию для всех кампаний
- Автоматически находит пользователей с высокой вероятностью конверсии
- Может расширять показы за пределы заданных аудиторий

### 1.3 Video (Видеокампании)

**Описание**: Видеореклама на YouTube и сайтах-партнерах Google.

**Форматы объявлений**:

| Формат | Длительность | Пропуск | Модель оплаты |
|--------|-------------|---------|---------------|
| Skippable In-Stream | Любая | После 5 сек | CPV (за просмотр 30 сек или полностью) |
| Non-Skippable In-Stream | 7-15 сек | Нет | CPM (за показы) |
| Bumper Ads | До 6 сек | Нет | CPM (за показы) |
| YouTube Shorts | Любая | Свайп | CPM/CPV |
| In-Feed | Любая | N/A | CPC (за клик) |
| Masthead | До 30 сек | После 5 сек | CPD (за день) |

**Подтипы видеокампаний**:
- **Video Reach Campaign**: Максимизация охвата через bumper и non-skippable форматы
- **Video Action Campaign** (теперь Demand Gen): Фокус на кликах и конверсиях
- **Video Views Campaign**: Оптимизация для получения просмотров

**Особенности YouTube Shorts (2025)**:
- Около 70 миллиардов ежедневных просмотров
- Объявления показываются между органическими Shorts
- Пользователь пропускает свайпом вверх/вниз

### 1.4 Shopping (Товарные кампании)

**Описание**: Карточки товаров с изображением, ценой и названием в результатах поиска Google и на вкладке Shopping.

**Требования**:
- Аккаунт Google Merchant Center, связанный с Google Ads
- Загруженный товарный фид с актуальной информацией
- Соответствие политикам Google

**Обязательные атрибуты товарного фида**:

| Атрибут | Описание |
|---------|----------|
| id | Уникальный идентификатор товара |
| title | Название товара |
| description | Описание товара |
| link | URL страницы товара |
| image_link | URL изображения |
| availability | Наличие (in stock, out of stock, preorder) |
| price | Цена с валютой |
| brand | Бренд производителя |
| gtin | Глобальный номер товара |
| condition | Состояние (new, refurbished, used) |

**Типы товарных кампаний**:
- **Standard Shopping**: Ручной контроль, детальное управление группами товаров, гибкое назначение ставок
- **Performance Max**: Автоматизированное управление, кросс-канальный охват

**Бизнес-правила**:
- Минимальный интервал обновления фида: 30 минут
- Невозможно изменить merchant_id или страну продаж после создания кампании
- Для товаров с частыми изменениями цен рекомендуется ежедневное обновление фида
- С июля 2025: налоговые атрибуты не требуются для продавцов США

---

### 1.5 Performance Max (Максимальная эффективность)

**Описание**: Автоматизированный тип кампании с доступом ко всем рекламным каналам Google из одной кампании.

**Охватываемые каналы**:
- Google Search
- Google Shopping
- YouTube
- Gmail
- Google Discover
- Google Display Network
- Google Maps

**Доступные цели**: Продажи, Лиды, Посещения магазинов

**Ключевые компоненты**:

| Компонент | Описание |
|-----------|----------|
| Asset Groups | Группы креативов (тексты, изображения, видео, логотипы) |
| Audience Signals | Сигналы об аудитории (подсказки для алгоритма) |
| Search Themes | Тематики поиска (до 50 на группу активов) |
| Final URL Expansion | Автоматический подбор релевантных страниц |

**Функции 2025**:

- **Негативные ключевые слова на уровне кампании**: До 10,000 слов, применяются к Search и Shopping инвентарю
- **Расширение Search Themes**: Лимит увеличен с 25 до 50 на группу активов
- **Таргетинг по устройствам**: Возможность настройки на компьютеры, мобильные, планшеты (бета)
- **Демографические исключения**: Возможность исключать возрастные группы (бета)
- **Цели привлечения новых клиентов**: Оптимизация под привлечение новых/высокоценных клиентов
- **Цели удержания**: Повышенные ставки для возврата ушедших клиентов
- **Отчетность по каналам**: Сегментация результатов по каналам, устройствам, времени
- **Исключения брендов для ритейла**: Раздельные настройки для Search и Shopping
- **Интеграция с Waze** (ноябрь 2025): Для кампаний с целью посещения магазинов (США)

**Цели для офлайн-бизнеса (Store Goals)**:
- Store Visits (посещения магазинов)
- Store Sales (продажи в магазинах)
- Contacts (контакты через Google)
- Directions (запросы маршрута)

**Лучшие практики**:
- Начинать с широких настроек, сужать после получения 30-50 конверсий
- Использовать как дополнение к Search-кампаниям, не как замену
- Предоставлять качественные сигналы об аудитории

### 1.6 Demand Gen (Генерация спроса)

**Описание**: AI-управляемые кампании для визуально привлекательной рекламы на YouTube, Gmail и Google Discover.

**Места размещения**:
- YouTube (In-Stream, In-Feed, Shorts, Home Feed, Watch Next)
- Gmail (Promotions, Social tabs)
- Google Discover

**Особенности**:
- Заменяет Discovery Campaigns (с марта 2025)
- Поглотила Video Action Campaigns (с сентября 2025)
- Автогенерация видео из изображений и товарных фидов
- Вертикальные изображения 9:16 для Shorts (с февраля 2025)

**Настройки аудитории**:

| Тип аудитории | Описание |
|---------------|----------|
| Custom Segments | Собственные сегменты на основе интересов/намерений |
| Data Segments | Сегменты из данных рекламодателя (CRM, посетители) |
| Lookalike Segments | Похожие аудитории на основе seed-списков |
| In-market | Заинтересованные покупатели |
| Affinity | Аудитории по интересам |

**Настройки похожих аудиторий (Lookalike)**:
- **Balanced** (по умолчанию): 5% пользователей, похожих на seed-список
- **Broad**: 10% пользователей, похожих на seed-список

**Управление каналами (март 2025)**:
- Выбор конкретных поверхностей для показа
- Возможность настройки только на YouTube Shorts
- Контроль показа на YouTube, Discover, Gmail отдельно

**Оптимизированный таргетинг**:
- Позволяет Google расширять показы за пределы заданных аудиторий
- Рекомендуется отключать при ограниченных данных

**A/B тестирование креативов**:
- Тестирование эффективности изображений и видео кросс-канально

**Контроль безопасности бренда** (ноябрь 2025):
- Настройки типа инвентаря для YouTube Home, Watch Next, Discover

### 1.7 App Campaigns (Кампании для приложений)

**Описание**: Автоматизированные кампании для продвижения мобильных приложений iOS и Android.

**Подтипы**:

| Подтип | Цель | Требования |
|--------|------|------------|
| App Install | Установки приложения | Приложение в App Store/Google Play |
| App Engagement | Повторное вовлечение | Минимум 50,000 установок |
| App Pre-registration | Предрегистрация | Приложение на стадии pre-launch |

**Места размещения**:
- Google Search Network
- Google Play
- YouTube
- Google Display Network

**Маркетинговые цели для Engagement-кампаний**:

| Цель | Аудитория |
|------|-----------|
| Re-engage lapsed users | Установили, но не открывали 7+ дней |
| Re-engage lapsed purchasers | Покупали ранее, не открывали 7+ дней |
| Re-engage non-purchasers | Не покупали за 540 дней |
| Re-engage unnotified users | Не получали push 7+ дней |
| Re-engage all users | Все, кто использовал за 540 дней |

**Требования для App Engagement**:
- Минимум 50,000 установок приложения
- Настроенный deep linking (Universal Links для iOS, App Links для Android)
- Интеграция с Firebase или App Attribution Partner
- Политика конфиденциальности
- Согласие с EU User Consent Policy

**Обновления 2025**:
- Автоматический импорт конверсий (с декабря 2025)
- iOS ICM open beta доступна всем (с ноября 2025)
- Power Pack: Performance Max + Demand Gen + AI Max работают вместе

**Лучшие практики**:
- Разделять кампании по платформам (Android/iOS)
- Разделять по целям (установки/действия/вовлечение)
- Разделять по географическим регионам
- Вести Install и Engagement кампании в разных аккаунтах

### 1.8 Smart Campaigns (Умные кампании)

**Описание**: Упрощенный автоматизированный тип кампании для малого бизнеса с минимальным опытом в рекламе.

**Особенности**:
- Полная автоматизация: ключевые слова, ставки, показы
- Минимум настроек и времени на управление
- Показы на Search, Google Maps, Display Network, YouTube

**Доступные цели**:
- Звонки от клиентов
- Посещения локации
- Действия на сайте

**Целевая аудитория**:
- Малый и средний бизнес
- Локальный бизнес с физическими точками
- Рекламодатели с базовыми целями
- Начинающие пользователи Google Ads

**Ограничения**:
- Минимальный контроль над таргетингом и ставками
- Автоматические широкие ключевые слова (нет кастомизации)
- Ограниченная отчетность
- Невозможность детальной оптимизации

## 2. Цели кампаний (Campaign Objectives)

### 2.1 Основные цели

| Цель | Описание | Метрики успеха |
|------|----------|----------------|
| **Sales (Продажи)** | Увеличение онлайн/офлайн продаж | Транзакции, Revenue, ROAS |
| **Leads (Лиды)** | Сбор контактных данных потенциальных клиентов | Заявки, звонки, подписки |
| **Website Traffic (Трафик)** | Привлечение посетителей на сайт | Клики, сессии, вовлеченность |
| **App Promotion** | Установки и вовлечение в приложении | Установки, in-app действия |
| **Awareness & Consideration** | Повышение узнаваемости бренда | Охват, показы, просмотры |

**Обновление 2025**: Цели "Product and brand consideration" и "Brand awareness and reach" объединены в "Awareness and consideration".

### 2.2 Соответствие целей и типов кампаний

| Цель | Search | Display | Video | Shopping | PMax | Demand Gen | App | Smart |
|------|--------|---------|-------|----------|------|------------|-----|-------|
| Sales | + | + | + | + | + | + | - | + |
| Leads | + | + | + | - | + | + | - | + |
| Traffic | + | + | + | - | - | + | - | + |
| App Promotion | - | - | - | - | - | - | + | - |
| Awareness | - | + | + | - | - | + | - | - |

### 2.3 Воронка продаж и цели

**Awareness (Осведомленность)**:
- Цель: Максимальный охват и запоминание бренда
- Не фокус на конверсиях
- Типы: Display, Video (Reach), Demand Gen

**Consideration (Рассмотрение)**:
- Цель: Углубление интереса, взаимодействие с брендом
- Метрики: Просмотры видео, время на сайте, подписки
- Типы: Video (Views), Display, Demand Gen

**Conversion (Конверсия)**:
- Цель: Конкретные бизнес-результаты
- Метрики: Продажи, лиды, звонки
- Типы: Search, Shopping, Performance Max

## 3. Настройки кампаний

### 3.1 Географический таргетинг

**Уровни таргетинга**:
- Страны
- Регионы/Области/Штаты
- Города
- Почтовые индексы
- Радиус вокруг точки (1-500 миль)
- Группы локаций

**Опции локации**:

| Опция | Описание |
|-------|----------|
| Presence or interest | Люди в локации ИЛИ проявляющие интерес к ней |
| Presence only | Только люди, физически находящиеся в локации |

**Исключения локаций**:
- Возможность исключать нежелательные географические области
- Те же уровни детализации, что и для включений

**Ограничения**:
- Точность не гарантируется 100% из-за различных сигналов
- Основано на настройках пользователя, устройства, поведении

### 3.2 Расписание показов (Ad Schedule)

**Возможности**:
- Настройка дней недели для показа
- Настройка часов показа (с точностью до 15 минут)
- Корректировки ставок по времени (повышение/понижение)

**Примеры использования**:
- Показы только в рабочие часы для B2B
- Повышенные ставки в пиковые часы
- Отключение ночных показов

### 3.3 Таргетинг по устройствам

**Типы устройств**:
- Компьютеры (Desktop)
- Мобильные телефоны (Mobile)
- Планшеты (Tablet)
- ТВ-экраны (TV screens)

**Корректировки ставок**:
- Диапазон: от -100% до +900%
- Корректировка -100% полностью отключает показы на устройстве
- Множественные корректировки перемножаются (не суммируются)

**Performance Max (2025)**:
- Добавлена поддержка таргетинга по устройствам в бета-режиме

### 3.4 Языковой таргетинг

**Принцип работы**:
- Показы пользователям с выбранным языком интерфейса Google
- Можно выбрать несколько языков
- Язык сайта не учитывается автоматически

## 4. Бюджеты и ставки

### 4.1 Типы бюджетов

**Дневной бюджет (Daily Budget)**:
- Средняя сумма расходов в день за месяц
- Google может потратить до 2x дневного бюджета в высокотрафиковые дни
- За месяц расходы не превысят: дневной бюджет x 30.4

**Общий бюджет (Shared Budget)**:
- Один бюджет на несколько кампаний
- Автоматическое распределение между кампаниями по эффективности
- Подходит для кампаний с общими целями

### 4.2 Стратегии назначения ставок

**Ручные стратегии**:

| Стратегия | Описание |
|-----------|----------|
| Manual CPC | Ручное назначение ставок за клик |
| Enhanced CPC | Ручные ставки с автоматической корректировкой для конверсий |

**Автоматические стратегии (Smart Bidding)**:

| Стратегия | Цель | Требования |
|-----------|------|------------|
| Maximize Clicks | Максимум кликов в рамках бюджета | - |
| Maximize Conversions | Максимум конверсий | Настроенное отслеживание |
| Maximize Conversion Value | Максимум ценности конверсий | Настроенные ценности |
| Target CPA | Целевая стоимость конверсии | 15-30 конверсий/месяц |
| Target ROAS | Целевая рентабельность | Данные о ценности |

**Smart Bidding Exploration (2025)**:
- Гибкие цели ROAS для исследования нового трафика
- В среднем +18% уникальных поисковых категорий
- В среднем +19% конверсий

**Target CPC для Demand Gen**:
- Новая стратегия для оптимизации под клики и трафик

**Важные ограничения**:
- При Smart Bidding ручные корректировки ставок не применяются
- Исключение: корректировки по устройствам (-100% для отключения)

### 4.3 Корректировки ставок (Bid Adjustments)

**Типы корректировок**:
- По устройствам: -100% до +900%
- По локации: -90% до +900%
- По времени: -90% до +900%
- По аудиториям: -90% до +900%
- По демографии: -90% до +900%

**Правила комбинирования**:
- Корректировки перемножаются (не складываются)
- Максимум итоговой корректировки: +900%
- При Smart Bidding большинство корректировок игнорируется

## 5. Статусы кампаний

### 5.1 Базовые статусы (Campaign Status)

| Статус | Описание |
|--------|----------|
| **ENABLED** | Кампания активна и может показывать объявления |
| **PAUSED** | Кампания приостановлена вручную |
| **REMOVED** | Кампания удалена (безвозвратно) |

### 5.2 Расширенные статусы (Primary Status)

| Статус | Описание |
|--------|----------|
| **ELIGIBLE** | Кампания готова к показам |
| **ELIGIBLE (Limited)** | Показы ограничены из-за бюджета |
| **NOT_ELIGIBLE** | Кампания неактивна (нет групп/объявлений/ключевых слов) |
| **LEARNING** | Алгоритм обучается на новых данных |
| **LIMITED** | Показы ограничены (бюджет, ставки, таргетинг) |
| **MISCONFIGURED** | Ошибка в настройках кампании |
| **PENDING** | Кампания запланирована, но еще не началась |
| **ENDED** | Кампания завершилась (по дате окончания) |

### 5.3 Статус показа (Serving Status)

| Статус | Описание |
|--------|----------|
| **SERVING** | Объявления показываются |
| **PENDING** | Ожидание начала показов |
| **ENDED** | Показы завершены |
| **SUSPENDED** | Показы приостановлены (нарушение политик) |

### 5.4 Наследование статусов

- При паузе кампании все группы объявлений, объявления и ключевые слова наследуют статус "Paused"
- При паузе отдельной группы остальные группы кампании продолжают работать
- Объявление "Not Eligible", если кампания или группа приостановлены/удалены

## 6. Период обучения (Learning Period)

### 6.1 Описание

Период, в течение которого алгоритм Smart Bidding изучает данные для оптимальной работы.

**Длительность**:
- В среднем: 7 дней
- Или до получения 50 конверсий
- Может занять до 1 месяца

### 6.2 Факторы, влияющие на длительность

- Количество конверсий кампании
- Длительность цикла конверсии (время от клика до конверсии)
- Тип стратегии назначения ставок
- Размер бюджета (больший бюджет = быстрее)

### 6.3 Что запускает период обучения

- Создание новой стратегии
- Изменение стратегии назначения ставок
- Значительное изменение целевого CPA/ROAS
- Значительное изменение бюджета
- Добавление/удаление кампаний из стратегии
- Переключение с Manual CPC на Smart Bidding

### 6.4 Рекомендации

- Избегать изменений бюджета более 20% за раз
- Не вносить частые изменения в настройки
- Объединять кампании в портфельную стратегию для большего объема данных
- Не применяется к Manual CPC

## 7. Отслеживание конверсий

### 7.1 Типы конверсий

| Тип | Описание |
|-----|----------|
| Website Actions | Действия на сайте (покупки, заявки, звонки) |
| App Conversions | Действия в мобильном приложении |
| Phone Calls | Звонки с объявлений или сайта |
| Store Visits | Посещения физических магазинов |
| Store Sales | Продажи в офлайн-магазинах |

### 7.2 Модели атрибуции

**Актуальные модели (2025)**:

| Модель | Описание |
|--------|----------|
| **Data-Driven (DDA)** | Распределение кредита на основе ML-анализа данных |
| **Last Click** | 100% кредита последнему клику |

**Устаревшие модели** (автоматически переведены на DDA):
- First Click
- Linear
- Time Decay
- Position-based

**Data-Driven Attribution**:
- Модель по умолчанию для новых конверсий (с 2025)
- Анализирует Search, Shopping, YouTube, Display, Demand Gen
- Рекомендуемый минимум: 200 конверсий, 2000 взаимодействий за 30 дней
- Работает с любым объемом данных, но качество улучшается с ростом данных

### 7.3 Ценность конверсий

**Статическая ценность**: Фиксированное значение для типа конверсии
**Динамическая ценность**: Передается с каждой конверсией (например, сумма заказа)

**Original Conversion Value (ноябрь 2025)**:
- Новая метрика для отображения изначальной ценности
- До применения автоматических правил и корректировок
- Важно для стратегий Maximize Conversion Value и Target ROAS

### 7.4 Окно конверсии

**Click-Through Conversion Window**:
- По умолчанию: 30 дней
- Диапазон: 1-90 дней
- Рекомендуется настраивать под цикл продаж

**View-Through Conversion Window**:
- Конверсии после просмотра (без клика)
- По умолчанию: 1 день
- Диапазон: 1-30 дней

**Engaged-View Conversions**:
- Конверсии после взаимодействия с Display/Video
- По умолчанию: 3 дня

```

- Кампания создается в статусе Paused по умолчанию
```

```
- Система автоматически перераспределяет средства
```

## 9. Бизнес-правила и ограничения

### 9.1 Лимиты аккаунта

| Объект | Лимит |
|--------|-------|
| Кампаний на аккаунт | 10,000 |
| Групп объявлений на кампанию | 20,000 |
| Ключевых слов на группу | 20,000 |
| Ключевых слов на аккаунт | 5,000,000 |
| Негативных ключевых слов на кампанию | 10,000 |
| Общих негативных списков | 20 |
| Негативных слов в списке | 5,000 |

### 9.2 Требования к кампаниям

**Минимальные требования для запуска**:
- Активная группа объявлений
- Минимум одно активное объявление в группе
- Положительный баланс или настроенная оплата
- Заданный бюджет (дневной или общий)

**Требования для Smart Bidding**:
- Настроенное отслеживание конверсий
- Для Target CPA: 15-30 конверсий за 30 дней
- Для Target ROAS: данные о ценности конверсий

### 9.3 Правила совместимости

**Цели и типы кампаний**:
- Performance Max поддерживает только цели Sales и Leads
- App Campaigns только для цели App Promotion
- Awareness доступна только для Display, Video, Demand Gen

**Стратегии ставок**:
- Manual CPC не поддерживает период обучения
- Target ROAS требует передачу ценности конверсий
- Smart Bidding не совместим с ручными корректировками (кроме -100% по устройствам)

### 9.4 Политики и ограничения

**Время модерации**:
- Стандартные объявления: до 1 рабочего дня
- Видео: до 3 рабочих дней

**Статус Suspended**:
- Нарушение рекламных политик Google
- Требует исправления и повторной проверки

**Изменения в кампаниях**:
- Нельзя изменить тип кампании после создания
- Нельзя изменить Merchant Center ID или страну в Shopping
- Изменение стратегии запускает период обучения

### 9.5 Правила расходов бюджета

- Дневные расходы могут превышать дневной бюджет до 2x
- Месячные расходы не превысят: дневной бюджет x 30.4
- При исчерпании бюджета показы останавливаются до следующего дня
- При изменении бюджета в середине месяца пересчитывается лимит

### 9.6 Автоматические миграции (2025)

- Discovery Campaigns -> Demand Gen (март 2025)
- Video Action Campaigns -> Demand Gen (сентябрь 2025)
- Все данные и настройки сохраняются при миграции

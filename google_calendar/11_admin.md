# Модуль: Администрирование (Workspace) - Google Calendar

## Обзор модуля

Модуль администрирования Google Calendar предоставляет Super Admin и делегированным администраторам инструменты для управления календарными ресурсами организации, политиками доступа, аудитом действий пользователей и интеграцией с внешними системами. Модуль доступен через консоль администратора Google Workspace.

---

## 1. Управление ресурсами (переговорные комнаты, оборудование)

### FR-ADM-001: Иерархия ресурсов организации

**Описание:** Система поддерживает трехуровневую иерархию ресурсов: Здания -> Характеристики (Features) -> Ресурсы.

**Бизнес-правила:**
- Организация может создать до 10 000 зданий
- Организация может создать до 100 характеристик (features)
- Организация может создать до 10 000 ресурсов
- Здания являются обязательным родительским элементом для структурированных ресурсов
- Характеристики могут быть присвоены любому количеству ресурсов

**Роли и права:**
| Роль | Создание | Редактирование | Удаление | Просмотр |
|------|----------|----------------|----------|----------|
| Super Admin | Да | Да | Да | Да |
| Buildings and Resources Admin | Да | Да | Да | Да |
| Services Admin | Да | Да | Да | Да |
| User | Нет | Нет | Нет | Да* |

*Пользователи видят только ресурсы, к которым им предоставлен доступ

**User Stories:**
- US-ADM-001: Как администратор, я хочу создать здание с адресом и этажами, чтобы пользователи могли легко находить переговорные комнаты
- US-ADM-002: Как администратор, я хочу добавить характеристику "Видеоконференция" к переговорным, чтобы пользователи могли фильтровать комнаты по оборудованию
- US-ADM-003: Как пользователь, я хочу видеть вместимость комнаты при бронировании, чтобы выбрать подходящее помещение

---

### FR-ADM-002: Создание и настройка зданий

**Описание:** Администратор создает здания как базовую структуру для размещения ресурсов.

**Атрибуты здания:**
| Атрибут | Обязательность | Описание |
|---------|----------------|----------|
| Название | Да | Уникальное имя здания в организации |
| ID здания | Да | Уникальный идентификатор |
| Адрес | Нет | Физический адрес |
| Описание | Нет | Дополнительная информация |
| Этажи | Нет | Список этажей в здании |
| Географические координаты | Нет | Для location-based рекомендаций |

**Бизнес-правила:**
- ID здания должен быть уникальным в рамках организации/домена
- Название здания отображается пользователям при бронировании
- Здание может быть удалено только если в нем нет активных ресурсов
- Поддерживается массовый импорт зданий через CSV

**Состояния здания:**
```
[Черновик] -> [Активно] -> [Архивировано]
                  ^              |
                  |______________|
```

### FR-ADM-003: Создание и настройка ресурсов

**Описание:** Администратор создает бронируемые ресурсы (переговорные комнаты, оборудование, автомобили и т.д.).

**Типы ресурсов:**
| Тип | Описание | Примеры |
|-----|----------|---------|
| Conference room | Помещения для встреч и совещаний | Переговорные, телефонные будки |
| Other | Ресурсы не для встреч | Проекторы, автомобили, велосипеды |

**Атрибуты ресурса:**
| Атрибут | Обязательность | Описание |
|---------|----------------|----------|
| Название | Да | Отображаемое имя ресурса |
| Тип | Да | Conference room / Other |
| Здание | Да* | Привязка к зданию (*для структурированных) |
| Этаж | Нет | Расположение в здании |
| Вместимость | Нет | Количество человек |
| Характеристики | Нет | Список оборудования/особенностей |
| Email ресурса | Авто | Генерируется системой |
| Описание | Нет | Дополнительная информация |

**Бизнес-правила:**
- Ресурс становится доступным для бронирования в течение нескольких минут (до 24 часов в редких случаях)
- Email ресурса генерируется автоматически и используется для приглашений
- Вместимость влияет на рекомендации системы при бронировании
- Структурированные ресурсы предоставляют расширенные возможности поиска и рекомендаций

**User Stories:**
- US-ADM-004: Как администратор, я хочу создать переговорную комнату с указанием вместимости и оборудования, чтобы пользователи могли выбрать подходящее помещение
- US-ADM-005: Как администратор, я хочу импортировать 50 переговорных через CSV, чтобы не добавлять их по одной

---

### FR-ADM-004: Характеристики ресурсов (Features)

**Описание:** Администратор создает характеристики для описания оборудования и особенностей ресурсов.

**Примеры характеристик:**
- Видеоконференция (Zoom Room, Google Meet Hardware)
- Маркерная доска
- Проектор
- Телевизор
- Навигационная система (для автомобилей)
- Телефон для конференций

**Бизнес-правила:**
- Максимум 100 характеристик на организацию/домен
- Характеристика может быть присвоена неограниченному количеству ресурсов
- Пользователи могут фильтровать ресурсы по характеристикам при бронировании
- Характеристики отображаются в информации о ресурсе

### FR-ADM-005: Автоматическое освобождение комнат (Room Release)

**Описание:** Система автоматически освобождает забронированные переговорные комнаты, если все участники (кроме одного) отклонили приглашение.

**Доступность:** Enterprise Standard, Enterprise Plus, Education Fundamentals/Standard/Plus, G Suite Business

**Настройки:**
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| Глобальное включение | Включить/выключить для всего домена | Включено (с марта 2023) |
| Исключения для комнат | Отключить для отдельных комнат | Не установлено |

**Условия, при которых комната НЕ освобождается:**
- Встреча начинается в ближайшие 30 минут
- Встреча длится более 4 часов
- Вместимость комнаты 20+ человек
- Комната была ранее освобождена и повторно добавлена
- Нет гостей кроме организатора
- Есть внешние гости
- Встреча забронирована на вторичном календаре
- Бронирование сделано напрямую в календаре комнаты

**Рекомендации по исключениям:**
- Комнаты для руководства (CEO, директора)
- Критически важные функции (найм, встречи с клиентами, особые мероприятия)
- Комнаты с ограниченным доступом
- Комнаты для внешних гостей

**Уведомления:**
- Организатор получает email при освобождении комнаты

**User Stories:**
- US-ADM-006: Как администратор, я хочу автоматически освобождать неиспользуемые комнаты, чтобы повысить эффективность использования ресурсов
- US-ADM-007: Как администратор, я хочу исключить VIP-переговорную из автоматического освобождения, чтобы важные встречи не прерывались

---

### FR-ADM-006: Автоматическая замена отклоненных комнат

**Описание:** Когда забронированная комната отклоняет приглашение, система может автоматически найти и предложить аналогичную комнату.

**Условия работы:**
- Ресурсы должны быть определены как структурированные
- Ресурсы должны быть классифицированы как meeting spaces
- У пользователей должны быть настроены рабочие локации

**Причины отклонения комнатой:**
- Комната уже забронирована
- Комната отключена на обслуживание
- Конфликт в серии повторяющихся встреч

**Бизнес-правила:**
- Замена ищется среди комнат с аналогичной вместимостью
- Приоритет отдается комнатам в том же здании/на том же этаже
- Учитываются характеристики исходной комнаты

---

### FR-ADM-007: Менеджер ресурсов и согласование бронирований

**Описание:** Организация может назначить менеджера ресурсов для ручного согласования бронирований определенных комнат.

**Роли:**
| Роль | Описание | Требования |
|------|----------|-----------|
| Resource Manager | Принимает/отклоняет бронирования | Назначается Super Admin |
| Super Admin | Назначает менеджеров ресурсов | Системная роль |

**Сценарий согласования:**
```
[Запрос бронирования] -> [Ожидает согласования] -> [Одобрено] -> [Забронировано]
                                    |
                                    v
                              [Отклонено] -> [Уведомление организатору]
```

**Примеры использования:**
- Учебные классы, доступные только для тренеров утром
- VIP-переговорные с ограниченным доступом
- Дорогое оборудование, требующее контроля

**User Stories:**
- US-ADM-008: Как менеджер ресурсов, я хочу одобрять или отклонять запросы на бронирование учебного класса, чтобы обеспечить приоритет для официальных тренингов
- US-ADM-009: Как администратор, я хочу назначить офис-менеджера ответственным за согласование VIP-переговорных, чтобы разгрузить IT-отдел

---

### FR-ADM-008: Настройки общего доступа к ресурсам

**Описание:** Администратор настраивает уровни доступа к календарям ресурсов для пользователей организации.

**Уровни доступа:**
| Уровень | Описание | Возможности |
|---------|----------|-------------|
| See only free/busy | Только занятость | Бронирование, просмотр свободных слотов |
| See all event details | Детали событий | Бронирование, просмотр названий и участников |
| Make changes to events | Редактирование | Полный доступ к событиям (только для конкретных людей) |

**Бизнес-правила:**
- По умолчанию ресурсы доступны всей организации с уровнем "See only free/busy"
- Настройка "Make changes to events" доступна только для конкретных пользователей, не для всей организации
- По умолчанию ресурсы автоматически принимают приглашения без конфликтов

**Настройки автоматического принятия:**
| Режим | Описание |
|-------|----------|
| Auto-accept (no conflicts) | Автоматически принимать, если нет конфликтов |
| Auto-accept (all) | Принимать все приглашения |
| Require approval | Требовать ручного согласования |

## 2. Политики организации

### FR-ADM-010: Настройки внешнего доступа к календарям

**Описание:** Администратор определяет, как пользователи могут делиться своими календарями с людьми вне организации.

**Уровни внешнего доступа для основных календарей:**
| Уровень | Описание |
|---------|----------|
| Only free/busy information | Внешние видят только занятость |
| Share all information, outsiders cannot change | Внешние видят все события (кроме приватных), без редактирования |
| Share all information, outsiders can change | Полный доступ включая приватные события и редактирование |

**Бизнес-правила:**
- Настройки применяются к организационным единицам (OU) или группам конфигурации
- При понижении уровня доступа внешние пользователи теряют текущий доступ
- Публичный доступ возможен, но не для конкретного внешнего домена
- Для вторичных календарей настройки одинаковы для всей организации (без OU)
- Изменения вступают в силу в течение 24 часов

**Ограничения:**
- Календари можно делиться только с владельцами Google-аккаунтов
- Для не-Google пользователей календарь должен быть публичным

**User Stories:**
- US-ADM-010: Как администратор, я хочу ограничить внешний доступ для отдела HR только уровнем free/busy, чтобы защитить конфиденциальность
- US-ADM-011: Как администратор, я хочу разрешить отделу продаж делиться полной информацией с клиентами, чтобы упростить планирование встреч

---

### FR-ADM-011: Ограничение общего доступа между подразделениями

**Описание:** Администратор может ограничить доступ к календарям между различными организационными единицами (OU).

**Бизнес-правила:**
- Настройки не применяются на уровне корневого домена для изоляции OU
- Опции "Only free/busy" или "No sharing" предотвращают утечку данных между подразделениями
- Наследование настроек от родительского OU можно переопределить (Override) или сбросить (Inherit)

---

### FR-ADM-012: Длительность встреч по умолчанию

**Описание:** Администратор устанавливает длительность по умолчанию для новых событий в организации.

**Доступность:** Enterprise Standard, Enterprise Plus, Education Fundamentals/Standard/Plus, Nonprofits

**Параметры:**
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| Default duration | Длительность по умолчанию | 60 минут |
| Speedy meetings | Сокращенные встречи | Выключено |

**Сокращенные встречи (Speedy meetings):**
| Исходная длительность | Сокращенная |
|-----------------------|-------------|
| 30 минут | 25 минут |
| 45 минут | 40 минут |
| 60 минут | 50 минут |

**Бизнес-правила:**
- Если пользователь установил собственное значение по умолчанию, настройка организации игнорируется
- Настройки можно применить на уровне OU или домена
- Изменения применяются к пользователям, не менявшим личные настройки, и к новым пользователям

**User Stories:**
- US-ADM-012: Как администратор, я хочу установить 45 минут как длительность по умолчанию, чтобы встречи не затягивались
- US-ADM-013: Как администратор, я хочу включить Speedy meetings для всей компании, чтобы у сотрудников было время между встречами

---

### FR-ADM-013: Настройки рабочего времени и локации

**Описание:** Администратор может управлять доступностью функций рабочего времени и локации для пользователей.

**Функции:**
| Функция | Описание | Контроль админа |
|---------|----------|-----------------|
| Working hours | Рабочие часы пользователя | Включить/выключить |
| Working location | Рабочая локация (офис/удаленка) | Включить/выключить |
| Out of office | Статус "Нет на месте" | Доступно |
| Focus time | Время для сосредоточенной работы | Доступно |

**Доступность:** Business Plus, Enterprise, Education, Nonprofit

**Бизнес-правила:**
- Функции доступны только для рабочих/школьных аккаунтов
- Если администратор отключил функцию, пользователи не видят соответствующие настройки
- Working location может запрашиваться администратором для координации офисного присутствия
- Коллеги в той же организации видят рабочие часы и локацию

---

### FR-ADM-014: Time Insights (Аналитика времени)

**Описание:** Администратор управляет доступом пользователей к панели аналитики использования времени.

**Доступность:** Business Plus, Enterprise, Education Standard/Plus/Fundamentals, Nonprofit

**Настройки:**
| Параметр | Описание |
|----------|----------|
| Let users view analytics | Разрешить пользователям видеть аналитику времени |

**Бизнес-правила:**
- Администратор может включить/выключить для всей организации или отдельных OU
- Пользователи не могут самостоятельно отключить функцию, если она включена админом
- Time Insights показывает статистику по времени в встречах, 1:1, типам встреч

## 3. Управление доступом

### FR-ADM-020: Иерархия административных привилегий Calendar

**Описание:** Система предоставляет гранулярные права для делегирования управления календарем.

**Структура привилегий:**
```
Calendar (все привилегии)
├── Settings (настройки Calendar)
├── Manage Calendars (управление всеми календарями)
└── Buildings and Resources
    └── Manage Buildings and Resources
```

**Роли и привилегии:**
| Привилегия | Super Admin | Services Admin | Custom Role |
|------------|-------------|----------------|-------------|
| Calendar Settings | Да | Да | Настраиваемо |
| Manage Calendars | Да | Нет | Настраиваемо |
| Buildings and Resources | Да | Да | Настраиваемо |

**Бизнес-правила:**
- Super Admin и админы с "Manage Calendars" видят все детали всех календарей
- Привилегия "Settings" отделена от управления ресурсами
- Делегированные админы получают доступ к соответствующим разделам Admin Console
- Привилегии не дают доступа к календарям через Calendar App или Calendar API

**User Stories:**
- US-ADM-020: Как Super Admin, я хочу назначить офис-менеджера администратором ресурсов, чтобы он мог управлять переговорными без полного доступа
- US-ADM-021: Как Super Admin, я хочу создать роль "Calendar Settings Admin" для IT-поддержки, чтобы они могли менять политики без доступа к ресурсам

---

### FR-ADM-021: Делегирование доступа к календарям пользователей

**Описание:** Пользователи могут делегировать доступ к своим календарям другим пользователям (например, ассистентам).

**Уровни делегирования:**
| Уровень | Описание |
|---------|----------|
| See free/busy | Только занятость |
| See all event details | Все детали событий |
| Make changes to events | Редактирование событий |
| Make changes and manage sharing | Полное управление |

**Бизнес-правила:**
- Делегирование настраивается пользователем в Gmail/Calendar
- Делегат может управлять почтой и календарными приглашениями от имени владельца
- Делегат не может менять пароль или другие настройки аккаунта
- Делегирование работает с GWSMO (Google Workspace Sync for Microsoft Outlook)

**User Stories:**
- US-ADM-022: Как руководитель, я хочу дать ассистенту право управлять моим календарем, чтобы он мог планировать встречи от моего имени
- US-ADM-023: Как HR-менеджер, я хочу видеть календари всей команды, чтобы планировать собеседования

---

### FR-ADM-022: Изменения привилегий управления календарями (октябрь 2025)

**Описание:** С 15 октября 2025 года привилегия "Manage Google Meet hardware and calendars" больше не предоставляет доступ к пользовательским календарям.

**Изменения:**
| До 15.10.2025 | После 15.10.2025 |
|---------------|------------------|
| Доступ к календарям через Meet hardware privilege | Только назначение календарей устройствам |
| Полный контроль календарей | Требуется отдельная привилегия "Manage Calendars" |

**Действия администратора:**
- Проверить делегированных админов с Meet hardware privilege
- При необходимости добавить привилегию "Manage Calendars"
- Документировать изменения для пользователей

### FR-ADM-023: Multi-Party Approval для критических действий

**Описание:** Система поддерживает многоуровневое согласование для критически важных административных действий.

**Процесс согласования:**
```
[Запрос действия] -> [Уведомление approvers] -> [Ожидание (3 дня)] -> [Одобрено/Отклонено/Истекло]
```

**Роли:**
| Роль | Описание |
|------|----------|

**Бизнес-правила:**
- Запросы истекают через 3 дня без одобрения

## 6. Миграция календарей

### FR-ADM-050: Data Migration Service

**Описание:** Административный сервис для миграции данных в Google Workspace.

**Источники миграции:**
| Источник | Поддержка календарей |
|----------|---------------------|
| Microsoft Exchange Online | Да |
| IMAP-based webmail | Только email |
| Другой Workspace аккаунт | Да |
| Личный Gmail | Да |

**Доступ:** Admin console > Data > Data import & export > Data Migration (New)

**Возможности:**
- Delta-миграция для новых/обновленных данных
- Повторная миграция failed данных
- Данные не удаляются из Gmail/Calendar при остановке миграции

**Бизнес-правила:**
- GWMME мигрирует только email и labels (не календари)
- Для полной миграции календарей используется Data Migration Service
- Миграция между доменами требует дополнительных настроек

**User Stories:**
- US-ADM-050: Как администратор, я хочу мигрировать календари из Exchange Online, чтобы перевести компанию на Google Workspace
- US-ADM-051: Как администратор, я хочу запустить delta-миграцию, чтобы подхватить новые события после основной миграции

## 7. Calendar Interop (Интеграция с Exchange)

### FR-ADM-060: Настройка Calendar Interop

**Описание:** Администратор настраивает взаимодействие между Google Calendar и Microsoft Exchange для отображения доступности пользователей обеих систем.

**Поддерживаемые версии Exchange:**
| Версия | Аутентификация |
|--------|----------------|
| Exchange 2016+ | Basic authentication |
| Exchange Online (Microsoft 365) | OAuth 2.0 |

**Функции Interop:**
| Функция | Описание |
|---------|----------|
| Availability lookup | Просмотр занятости пользователей Exchange |
| Resource booking | Бронирование ресурсов Exchange из Google Calendar |
| Bi-directional sync | Exchange пользователи видят занятость Google |

**Настройка через Admin Console:**
1. Apps > Google Workspace > Calendar > Calendar Interop management
2. Exchange availability in Calendar
3. Add Exchange endpoint

**Требования:**
- Role account в Google Workspace для доступа Exchange
- Регистрация в Microsoft identity platform
- Application (client) ID и Directory (tenant) ID

**Ограничения видимости:**
| Тип данных | Видимость |
|------------|-----------|
| Availability | Только busy blocks |
| Event details | Только названия и локации |

**User Stories:**
- US-ADM-060: Как администратор, я хочу настроить Interop с Exchange, чтобы сотрудники видели занятость коллег из подразделения, еще не мигрировавшего на Google
- US-ADM-061: Как пользователь, я хочу бронировать переговорные Exchange из Google Calendar, чтобы не переключаться между системами

---

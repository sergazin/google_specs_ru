# Настройки (Settings)

## Описание

Модуль настроек Google Calendar предоставляет пользователям возможность персонализировать календарь: региональные параметры, часовой пояс, формат времени, рабочие часы, внешний вид, уведомления, клавиатурные сокращения, офлайн-режим и управление данными. Для организаций (Google Workspace) доступны расширенные административные настройки с контролем политик на уровне организации.

## Роли пользователей

- **Личный пользователь (Personal)** - полный доступ к персональным настройкам своего календаря
- **Workspace пользователь** - настройки в рамках политик организации
- **Администратор календаря (Calendar Admin)** - управление настройками календарей организации
- **Супер-администратор (Super Admin)** - полный контроль всех настроек и политик организации

### FR-SET-001: Язык интерфейса

**Описание:** Выбор языка отображения интерфейса Google Calendar.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → General → Language
2. Система отображает текущий язык интерфейса
3. Пользователь выбирает новый язык из списка
4. Система применяет изменения немедленно
5. Весь интерфейс календаря переключается на выбранный язык

**Доступные языки:**
- 40+ языков, включая: русский, английский, немецкий, французский, испанский, китайский, японский, арабский, иврит и др.

**User Stories:**
- Как пользователь из России, я хочу использовать календарь на русском языке, чтобы комфортно работать с интерфейсом
- Как эмигрант, я хочу переключить язык на родной, чтобы быстрее ориентироваться в настройках

**Бизнес-правила:**
- BR-001: Язык календаря наследуется из настроек Google Account по умолчанию
- BR-002: Изменение языка в Calendar не влияет на другие Google-сервисы
- BR-003: Для RTL-языков (арабский, иврит) интерфейс зеркалится

**Результат:** Интерфейс отображается на выбранном языке

### FR-SET-002: Часовой пояс

**Описание:** Настройка основного и дополнительного часовых поясов для корректного отображения событий.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → General → Time zone
2. Система отображает текущий основной часовой пояс
3. Пользователь выбирает новый часовой пояс из списка IANA
4. Опционально: включает "Display secondary time zone"
5. Выбирает дополнительный часовой пояс
6. Добавляет метки для ясности (например, "Дом", "Офис Токио")
7. Система сохраняет настройки
8. Оба часовых пояса отображаются вертикально рядом с сеткой календаря

**Альтернативный сценарий A: Настройка часового пояса отдельного календаря**
1. Пользователь открывает Settings → Settings for my calendars → [Calendar name]
2. В разделе "Time zone" выбирает пояс для конкретного календаря
3. Этот календарь отображает события в своём часовом поясе

**User Stories:**
- Как удалённый работник, я хочу видеть два часовых пояса, чтобы не путаться со временем команды в другой стране
- Как путешественник, я хочу быстро сменить часовой пояс календаря, чтобы видеть события в локальном времени

**Бизнес-правила:**
- BR-004: Все события хранятся в UTC, отображаются в локальном времени пользователя
- BR-005: При создании события можно указать отдельный часовой пояс
- BR-006: Максимум 2 часовых пояса для одновременного отображения
- BR-007: Часовой пояс влияет на расчёт даты/времени уведомлений

**Состояния:**
- **Primary only** - отображается только основной часовой пояс
- **Dual display** - отображаются оба часовых пояса с метками

**Результат:** Корректное отображение времени в выбранных часовых поясах

### FR-SET-003: Формат даты

**Описание:** Настройка порядка отображения дня, месяца и года в датах.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → General → Date format
2. Система отображает текущий формат даты
3. Пользователь выбирает один из форматов:
   - **MDY** - месяц/день/год (американский формат, по умолчанию)
   - **DMY** - день/месяц/год (европейский формат)
   - **YMD** - год/месяц/день (ISO формат)
4. Система применяет формат ко всему календарю

**User Stories:**
- Как европейский пользователь, я хочу видеть даты в формате DD/MM/YYYY, чтобы не путаться
- Как разработчик, я предпочитаю ISO формат YYYY-MM-DD для единообразия

**Бизнес-правила:**
- BR-008: Формат даты наследуется из региональных настроек Google Account
- BR-009: Изменение формата применяется ко всем календарям пользователя

**Результат:** Даты отображаются в выбранном формате

### FR-SET-004: Формат времени (12/24 часа)

**Описание:** Выбор между 12-часовым (AM/PM) и 24-часовым форматом отображения времени.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → General → Time format
2. Система отображает текущий формат времени
3. Пользователь выбирает:
   - **12-hour (1:00pm)** - с AM/PM индикатором
   - **24-hour (13:00)** - без AM/PM
4. Система применяет формат немедленно
5. Все времена в календаре отображаются в выбранном формате

**User Stories:**
- Как житель США, я привык к 12-часовому формату с AM/PM
- Как европеец, я предпочитаю 24-часовой формат для точности

**Бизнес-правила:**
- BR-010: Формат времени применяется ко всем представлениям календаря
- BR-011: При экспорте событий используется ISO 8601 независимо от настроек отображения

**Результат:** Время отображается в выбранном формате

### FR-SET-005: Первый день недели

**Описание:** Настройка дня, с которого начинается неделя в календаре.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → View options → Start week on
2. Система отображает текущий первый день недели
3. Пользователь выбирает:
   - **Sunday** (воскресенье) - по умолчанию для США
   - **Monday** (понедельник) - стандарт ISO 8601
   - **Saturday** (суббота) - для некоторых регионов
4. Система перестраивает сетку календаря

**User Stories:**
- Как работник в европейской компании, я хочу неделю с понедельника, как принято по стандарту
- Как пользователь из США, я привык к неделе с воскресенья

**Бизнес-правила:**
- BR-012: Изменение первого дня недели перестраивает представления Week и Month
- BR-013: Влияет на нумерацию недель (ISO vs US стандарт)

**Результат:** Неделя начинается с выбранного дня

### FR-SET-006: Рабочие часы и местоположение

**Описание:** Настройка рабочего графика для информирования коллег о доступности. Доступно только для Google Workspace.

**Роли:** Workspace пользователь

**Предусловия:** Пользователь имеет аккаунт Google Workspace (рабочий или учебный)

**Основной сценарий:**
1. Пользователь открывает Settings → General → Working hours
2. Включает опцию "Enable working hours"
3. Для каждого рабочего дня указывает:
   - Начало рабочего времени
   - Конец рабочего времени
   - Опционально: несколько временных периодов (split shifts)
4. Указывает рабочее местоположение (офис, дом, другое)
5. Система сохраняет настройки
6. При планировании встреч коллеги видят предупреждение о попытке назначить встречу вне рабочих часов

**Альтернативный сценарий: Разделённый рабочий день**
1. Пользователь добавляет несколько временных блоков для одного дня
2. Например: 09:00-12:00 и 14:00-18:00 (перерыв на обед)
3. Система учитывает все блоки при оценке доступности

**User Stories:**
- Как сотрудник с гибким графиком, я хочу указать свои рабочие часы, чтобы коллеги не назначали встречи в неудобное время
- Как удалённый работник, я хочу указать местоположение (дом/офис), чтобы команда знала, где меня найти

**Бизнес-правила:**
- BR-014: Рабочие часы доступны только для Google Workspace
- BR-015: Рабочие часы не блокируют создание событий, только предупреждают
- BR-016: Функция "Find a time" учитывает рабочие часы участников
- BR-017: Можно настроить разные часы для разных дней недели

**Состояния:**
- **Disabled** - рабочие часы не настроены
- **Enabled** - рабочие часы активны и видны коллегам

**Результат:** Коллеги видят доступность и получают предупреждения

### FR-SET-007: Вид по умолчанию

**Описание:** Выбор представления календаря, которое открывается по умолчанию.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → View options → Default view
2. Выбирает предпочтительный вид:
   - **Day** (День) - детальный вид одного дня
   - **Week** (Неделя) - 7 дней с почасовой сеткой
   - **Month** (Месяц) - обзор месяца
   - **Year** (Год) - годовой обзор
   - **Schedule** (Расписание) - список событий в виде agenda
   - **Custom** (Настраиваемый) - от 2 до 7 дней или от 2 до 4 недель
3. Система сохраняет выбор
4. При каждом открытии календаря загружается выбранный вид

**Настройки пользовательского вида (Custom):**
- 2, 3, 4, 5, 6 или 7 дней
- 2, 3 или 4 недели

**User Stories:**
- Как менеджер с плотным расписанием, я хочу видеть неделю по умолчанию, чтобы планировать встречи
- Как фрилансер, я предпочитаю месячный обзор для долгосрочного планирования

**Бизнес-правила:**
- BR-018: Клавиша X переключает на пользовательский вид
- BR-019: Вид по умолчанию применяется при открытии calendar.google.com

**Результат:** Календарь открывается в выбранном виде

**Описание:** Настройка дополнительных элементов, отображаемых в календаре.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → View options
2. Настраивает следующие опции:

**Опции:**

- **Set custom view** - настройка количества дней/недель для Custom view

**User Stories:**
- Как пользователь, который не работает по выходным, я хочу скрыть субботу и воскресенье
- Как координатор, я хочу видеть отклонённые события, чтобы понимать полную картину

**Бизнес-правила:**
- BR-020: Скрытие выходных компактифицирует недельный и месячный вид
- BR-021: Номера недель используют ISO 8601 или US стандарт в зависимости от первого дня недели

**Результат:** Календарь отображает выбранные элементы

### FR-SET-009: Плотность отображения и цвет

**Описание:** Настройка визуального стиля интерфейса календаря.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь нажимает на шестерёнку → "Density and color"
2. Выбирает плотность информации:
   - **Compact** (Компактный) - больше событий на экране, меньше деталей
   - **Cozy** (Комфортный) - баланс между компактностью и читаемостью
3. Выбирает цветовой набор (только для Light mode):
   - **Modern** - белый текст на цветном фоне событий
   - **Classic** - чёрный текст на цветном фоне событий
4. Система применяет изменения немедленно

**User Stories:**
- Как пользователь с плотным расписанием, я хочу компактный вид, чтобы видеть больше событий
- Как пользователь со слабым зрением, я предпочитаю Classic с чёрным текстом для читаемости

**Бизнес-правила:**
- BR-022: Цветовой набор недоступен в тёмном режиме
- BR-023: Плотность влияет на размер шрифта и отступы

**Результат:** Интерфейс отображается с выбранной плотностью и цветовой схемой

### FR-SET-010: Тёмный режим (Dark Mode)

**Описание:** Переключение между светлой и тёмной темой интерфейса.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь нажимает на шестерёнку → "Appearance" (Внешний вид)
2. Выбирает режим:
   - **Light** (Светлый) - белый фон, тёмный текст
   - **Dark** (Тёмный) - тёмный фон, светлый текст
   - **Device default** (Системный) - следует настройкам ОС
3. Система применяет тему немедленно
4. Настройка синхронизируется между устройствами

**User Stories:**
- Как пользователь, работающий ночью, я хочу тёмный режим, чтобы снизить нагрузку на глаза
- Как пользователь OLED-экрана, я хочу тёмную тему для экономии батареи

**Бизнес-правила:**
- BR-024: В тёмном режиме недоступна смена цветового набора (Modern/Classic)
- BR-025: Тёмный режим соответствует Material Design 3
- BR-026: Некоторые расширения Chrome могут конфликтовать с тёмным режимом

**Состояния:**
- **Light** - светлая тема активна
- **Dark** - тёмная тема активна
- **Device default** - тема следует системным настройкам

**Результат:** Интерфейс отображается в выбранной теме

### FR-SET-012: Клавиатурные сокращения (Keyboard Shortcuts)

**Описание:** Включение и использование горячих клавиш для быстрой навигации.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → General → Keyboard shortcuts
2. Включает опцию "Enable keyboard shortcuts"
3. Система активирует все клавиатурные сокращения
4. Пользователь может нажать "?" для просмотра списка сокращений

**Основные клавиатурные сокращения:**

| Клавиша | Действие |
|---------|----------|
| ? | Показать список сокращений |
| S | Открыть настройки |
| T | Перейти к сегодня |
| G | Перейти к конкретной дате |
| D | Переключиться на вид "День" |
| W | Переключиться на вид "Неделя" |
| M | Переключиться на вид "Месяц" |
| Y | Переключиться на вид "Год" |
| A | Переключиться на вид "Расписание" |
| X | Переключиться на пользовательский вид |
| C | Создать новое событие |
| E | Редактировать выбранное событие |
| Delete/Backspace | Удалить выбранное событие |
| P или K | Предыдущий период |
| N или J | Следующий период |
| Ctrl+Alt+. | Открыть боковую панель (Keep, Tasks) |

**User Stories:**
- Как опытный пользователь, я хочу использовать горячие клавиши для ускорения работы
- Как пользователь, переходящий с другого календаря, я хочу изучить доступные сокращения

**Бизнес-правила:**
- BR-030: По умолчанию клавиатурные сокращения отключены
- BR-031: Сокращения работают только когда фокус на календаре
- BR-032: Сокращения различаются для Mac (Cmd) и Windows (Ctrl)

**Результат:** Горячие клавиши активны для быстрой навигации

### FR-SET-013: Настройки уведомлений

**Описание:** Управление способами и временем получения напоминаний о событиях.

**Роли:** Личный пользователь, Workspace пользователь

**Основной сценарий:**
1. Пользователь открывает Settings → General → Notification settings
2. Настраивает глобальные параметры:
   - **Notifications** - способ доставки:
     - Off - уведомления отключены
     - Desktop notifications - уведомления ОС (требует открытый календарь)
     - Alerts - всплывающие окна в браузере
3. Настраивает параметры отложенных уведомлений:
   - Время "snooze" по умолчанию (5, 10, 15, 30 минут, 1 час)

**Настройки для отдельного календаря:**
1. Пользователь открывает Settings → Settings for my calendars → [Calendar]
2. Настраивает уведомления по умолчанию:
   - Для обычных событий (Event notifications)
   - Для событий на весь день (All-day event notifications)
3. Добавляет несколько напоминаний:
   - За X минут/часов/дней/недель до события
   - Способ: уведомление или email
4. Настройки применяются ко всем новым событиям в этом календаре

**Типы уведомлений:**
- **Email** - письмо на указанный адрес
- **Notification** - push-уведомление или desktop alert

**User Stories:**
- Как занятой человек, я хочу получать напоминание за 10 минут до встречи

### FR-SET-016: Импорт данных

**Описание:** Загрузка событий из внешних источников в формате ICS или CSV.

**Роли:** Личный пользователь, Workspace пользователь

**Предусловия:**
- Для импорта нужны права "Make changes" или "Make changes and manage sharing" на целевой календарь
- Файл должен быть в формате .ics или .csv

**Основной сценарий:**
1. Пользователь открывает Settings → Import & export → Import
2. Нажимает "Select file from your computer"
3. Выбирает файл .ics или .csv
4. Выбирает календарь, в который импортировать события
5. Нажимает "Import"
6. Система обрабатывает файл и добавляет события
7. Отображается отчёт: сколько событий импортировано

**Альтернативный сценарий: Импорт из .zip архива**
1. Пользователь получает .zip файл (например, от экспорта)
2. Распаковывает архив, получает отдельные .ics файлы
3. Импортирует каждый файл по отдельности

**Формат ICS:**
- Стандарт iCalendar (RFC 5545)
- Содержит: название, время, место, описание, повторения
- Не импортируются: гости события, данные видеоконференций

**Формат CSV:**
- Текстовый формат с разделителями
- Столбцы: Subject, Start Date, Start Time, End Date, End Time, All Day Event, Description, Location, Private

**User Stories:**
- Как пользователь, переходящий с Outlook, я хочу импортировать свои события
- Как организатор конференции, я хочу загрузить расписание из файла

**Бизнес-правила:**
- BR-045: Импорт доступен только с компьютера (не из мобильного приложения)
- BR-046: Гости и видеоконференции не импортируются из ICS
- BR-047: Дубликаты событий не проверяются автоматически
- BR-048: Максимальный размер файла ограничен

**Результат:** События из файла добавлены в календарь

## Сущности данных

### User Settings (Настройки пользователя)
- **user_id** - идентификатор пользователя
- **language** - язык интерфейса
- **timezone_primary** - основной часовой пояс
- **timezone_secondary** - дополнительный часовой пояс
- **timezone_secondary_enabled** - включён ли второй пояс
- **timezone_labels** - метки для часовых поясов
- **date_format** - формат даты (MDY, DMY, YMD)
- **time_format** - формат времени (12h, 24h)
- **week_start** - первый день недели
- **default_view** - вид по умолчанию
- **custom_view_days** - количество дней для Custom view
- **keyboard_shortcuts_enabled** - горячие клавиши
- **offline_enabled** - офлайн-режим
- **theme** - тема (light, dark, system)
- **density** - плотность (compact, cozy)
- **color_set** - цветовой набор (modern, classic)

### Calendar Settings (Настройки календаря)
- **calendar_id** - идентификатор календаря
- **owner_id** - владелец
- **name** - название
- **description** - описание
- **timezone** - часовой пояс календаря
- **color** - цвет
- **default_event_notifications** - уведомления по умолчанию
- **default_allday_notifications** - уведомления для событий на весь день
- **visibility** - видимость (private, shared, public)

### Sharing Permission (Права доступа)
- **calendar_id** - календарь
- **grantee_id** - кому предоставлен доступ (email или группа)
- **permission_level** - уровень доступа
- **granted_by** - кто предоставил
- **granted_at** - когда предоставлен

### Working Hours (Рабочие часы)
- **user_id** - пользователь
- **enabled** - включены ли
- **day_of_week** - день недели
- **periods** - массив периодов [{start, end}]
- **location** - местоположение (office, home, other)

### Notification Settings (Настройки уведомлений)
- **calendar_id** - календарь
- **notification_type** - тип (email, notification)
- **timing** - за сколько минут/часов/дней

## Ограничения и лимиты

### Общие ограничения
- **Часовые пояса:** максимум 2 для одновременного отображения
- **Уведомления на событие:** до 5 напоминаний
- **Время напоминания:** от 0 минут до 4 недель
- **Календари пользователя:** до 10,000 календарей
- **Цвета:** ~24 предустановленных цвета

### Ограничения импорта/экспорта
- **Размер ICS файла:** рекомендуется до 25 MB
- **Количество событий в файле:** до 40,000
- **Формат даты в CSV:** зависит от локали

### Ограничения для организаций
- **Организационные единицы:** неограниченное количество
- **Администраторы:** до 500 на организацию
- **Делегированные календари:** до 100 на пользователя

## Интеграции с другими модулями

### Модуль "События"
- Настройки по умолчанию применяются к новым событиям
- Часовой пояс влияет на отображение времени
- Цвета календарей определяют цвет событий

### Модуль "Приглашения"
- Рабочие часы влияют на предупреждения при планировании
- Уведомления отправляются согласно настройкам

### Модуль "Ресурсы"
- Администраторские политики влияют на бронирование
- Настройки доступа определяют видимость ресурсов

### Google Workspace Admin
- Политики организации переопределяют личные настройки
- Администратор управляет доступом к функциям

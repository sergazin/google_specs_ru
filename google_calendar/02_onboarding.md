# Google Calendar: Модуль "Онбординг и первичная настройка"

## 1. Общее описание модуля

Модуль онбординга Google Calendar обеспечивает полный цикл первичной настройки календарного приложения: от первого входа до полноценного использования с учётом личных предпочтений пользователя. Модуль включает настройку часового пояса, формата времени и даты, импорт существующих календарей, подключение к Google Workspace и обучение пользователя основным функциям.

### 1.1 Ключевые бизнес-цели модуля

- Минимизация времени от регистрации до создания первого события
- Обеспечение корректной синхронизации времени с учётом локации пользователя
- Упрощение миграции с других календарных систем
- Интеграция с корпоративной инфраструктурой Google Workspace
- Снижение барьера входа через обучающие подсказки и интерактивные туры

## 2. Роли и права доступа

### 2.1 Уровни доступа к календарю

| Роль | Описание | Права |
|------|----------|-------|
| **Владелец (Owner)** | Создатель календаря | Полный контроль: редактирование, удаление, управление доступом, передача владения |
| **Редактор (Make changes to events)** | Может изменять события | Создание, редактирование, удаление событий |
| **Редактор и общий доступ (Make changes and manage sharing)** | Расширенные права | Редактирование событий + управление доступом других пользователей |
| **Просмотр всех деталей (See all event details)** | Полный просмотр | Просмотр названия, времени, участников, описания, вложений |
| **Просмотр занятости (See only free/busy)** | Минимальный просмотр | Только информация о занятости (занят/свободен) |

### 2.2 Уровни доступа в Google Workspace

| Роль | Описание | Права |
|------|----------|-------|
| **Администратор организации** | Управление Workspace | Настройка политик календаря для всей организации |
| **Владелец ресурса** | Управление переговорками | Настройка бронирования комнат и оборудования |
| **Делегат** | Управление от имени другого | Создание и редактирование событий от имени другого пользователя |
| **Пользователь организации** | Стандартный сотрудник | Доступ согласно политикам организации |

### 2.3 Бизнес-правила для ролей

- Владелец может передать право владения только одному пользователю в той же организации
- Пользователь может предоставить доступ только того уровня, который имеет сам или ниже
- Администратор Workspace может ограничить внешний общий доступ для всей организации
- Делегирование доступа требует явного согласия владельца календаря
- Права на групповые календари наследуются от настроек группы

## 3. Первый запуск приложения

### 3.1 User Story: Первый вход в Google Calendar

```
КАК новый пользователь Google
Я ХОЧУ начать использовать Google Calendar
ЧТОБЫ организовать своё расписание и планировать события

Критерии приёмки:
- Могу войти с существующим Google-аккаунтом
- Система автоматически определяет мой часовой пояс
- Вижу свой основной календарь
- Получаю приветственное руководство (опционально)
```

### 3.2 Процесс первого запуска

```
[Вход через Google Account]
        ↓
[Автоматическое определение часового пояса]
        ↓
[Создание основного календаря пользователя]
        ↓
[Синхронизация с устройством]
        ↓
[Показ интерфейса календаря]
        ↓
[Обучающий тур (опционально)]
```

### 3.3 Бизнес-правила первого запуска

**FR-ONB-001**: При первом входе система автоматически создаёт основной календарь с именем пользователя

**FR-ONB-002**: Часовой пояс определяется автоматически на основе:
- Геолокации устройства (при разрешении)
- IP-адреса
- Настроек браузера
- Настроек операционной системы

**FR-ONB-003**: Пользователь может изменить автоматически определённый часовой пояс

**FR-ONB-004**: При входе через Workspace-аккаунт применяются корпоративные политики организации

**FR-ONB-005**: Основной календарь пользователя не может быть удалён, только скрыт

### 3.4 Состояния первого запуска

| Состояние | Описание | Переходы |
|-----------|----------|----------|
| **Аутентификация** | Проверка Google-аккаунта | → Инициализация |
| **Инициализация** | Создание календаря, определение настроек | → Синхронизация |
| **Синхронизация** | Загрузка существующих данных (если есть) | → Готов к работе |
| **Готов к работе** | Полнофункциональный режим | → Обучающий тур (опционально) |
| **Обучающий тур** | Интерактивное обучение | → Готов к работе |

## 4. Настройка часового пояса

### 4.1 User Story: Настройка часового пояса

```
КАК пользователь Google Calendar
Я ХОЧУ настроить правильный часовой пояс
ЧТОБЫ мои события отображались в корректное время

Критерии приёмки:
- Могу установить основной часовой пояс
- Могу добавить дополнительный часовой пояс
- Могу настроить мировые часы
- События автоматически конвертируются при смене зоны
```

### 4.2 Функциональные требования

**FR-ONB-006**: Система поддерживает настройку основного (Primary) часового пояса

**FR-ONB-007**: Система поддерживает настройку вторичного (Secondary) часового пояса для отображения в интерфейсе

**FR-ONB-008**: Функция "Мировые часы" позволяет добавить несколько часовых поясов для одновременного просмотра

**FR-ONB-009**: На мобильных устройствах доступна опция "Использовать часовой пояс устройства" для автоматической синхронизации при путешествиях

**FR-ONB-010**: Каждое событие может иметь индивидуальный часовой пояс начала и окончания

**FR-ONB-011**: Каждый календарь (не только событие) может иметь собственный часовой пояс

### 4.3 Бизнес-правила часовых поясов

**FR-ONB-012**: Все события хранятся в UTC и конвертируются в локальное время пользователя при отображении

**FR-ONB-013**: При изменении часового пояса существующие события пересчитываются для корректного отображения

**FR-ONB-014**: При просмотре события участниками из разных часовых поясов каждый видит время в своей зоне

**FR-ONB-015**: Изменение часового пояса календаря доступно только владельцу календаря

**FR-ONB-016**: Система автоматически учитывает переход на летнее/зимнее время

### 4.4 Типы настройки часового пояса

| Уровень | Описание | Приоритет |
|---------|----------|-----------|
| **Событие** | Индивидуальная настройка для конкретного события | Высший |
| **Календарь** | Настройка для всех событий календаря | Средний |
| **Аккаунт** | Основной часовой пояс пользователя | Базовый |
| **Устройство** | Автоматическое определение | При включении опции |

### 4.5 Специальные сценарии

**FR-ONB-017**: Для событий с путешествиями можно установить разные часовые пояса для начала и окончания

**FR-ONB-018**: Приглашения участникам отправляются с учётом их локального времени

## 5. Выбор формата времени и даты

### 5.1 User Story: Настройка формата времени

```
КАК пользователь из определённого региона
Я ХОЧУ настроить привычный формат времени и даты
ЧТОБЫ легко ориентироваться в своём расписании

Критерии приёмки:
- Могу выбрать 12-часовой или 24-часовой формат
- Могу выбрать порядок дня/месяца/года
- Могу выбрать первый день недели
- Настройки применяются ко всему интерфейсу
```

### 5.2 Функциональные требования

**FR-ONB-019**: Система поддерживает настройку формата времени:
- 12-часовой формат (1:00 PM)
- 24-часовой формат (13:00)

**FR-ONB-020**: Система поддерживает настройку порядка даты:
- MDY (Месяц/День/Год) - по умолчанию для США
- DMY (День/Месяц/Год) - по умолчанию для большинства стран
- YMD (Год/Месяц/День) - для Азии и международного формата

**FR-ONB-021**: Система поддерживает выбор первого дня недели:
- Воскресенье (по умолчанию для США)
- Понедельник (по умолчанию для Европы и России)
- Суббота (для ближневосточных стран)

**FR-ONB-022**: Настройка языка интерфейса влияет на отображение названий дней и месяцев

**FR-ONB-023**: Опция отображения номеров недель в календаре (Week numbers)

### 5.3 Бизнес-правила форматов

**FR-ONB-024**: Формат даты и времени определяется автоматически на основе языковых настроек, но может быть изменён вручную

**FR-ONB-025**: На мобильных устройствах формат наследуется от системных настроек устройства

**FR-ONB-026**: Изменение формата применяется только к отображению, не влияет на хранение данных

**FR-ONB-027**: В приглашениях по email время отображается в формате, понятном получателю

### 5.4 Доступные настройки отображения

| Настройка | Варианты | По умолчанию |
|-----------|----------|--------------|
| **Формат времени** | 12h / 24h | По языку региона |
| **Формат даты** | MDY / DMY / YMD | По языку региона |
| **Первый день недели** | Воскресенье / Понедельник / Суббота | По стране |
| **Номера недель** | Показать / Скрыть | Скрыть |
| **Альтернативные календари** | Китайский, Еврейский, Персидский и др. | Отключено |

## 6. Импорт существующих календарей

### 6.1 User Story: Импорт из другой системы

```
КАК пользователь, переходящий на Google Calendar
Я ХОЧУ импортировать свои существующие события
ЧТОБЫ не терять историю и запланированные мероприятия

Критерии приёмки:
- Могу импортировать файлы ICS и CSV
- Могу подписаться на внешний календарь по URL
- Могу синхронизировать с Outlook через Workspace Sync
- События сохраняют свои атрибуты (время, участники, описание)
```

### 6.2 Поддерживаемые форматы импорта

| Формат | Описание | Особенности |
|--------|----------|-------------|
| **ICS (iCalendar)** | Стандартный формат | Полная поддержка событий, повторений, напоминаний |
| **CSV** | Табличный формат | Ограниченный набор полей |
| **URL подписки** | Внешний календарь | Только чтение, автоматическое обновление |

### 6.3 Функциональные требования импорта

**FR-ONB-028**: Импорт ICS-файлов поддерживает:
- Одиночные события
- Повторяющиеся события
- События с несколькими участниками
- Напоминания
- Описания и вложения

**FR-ONB-029**: Импорт CSV-файлов поддерживает базовые поля:
- Название события
- Дата начала и окончания
- Время начала и окончания
- Описание
- Местоположение

**FR-ONB-030**: Подписка на внешний календарь по URL (iCal):
- Только для чтения
- Автоматическое обновление каждые несколько часов
- Нельзя редактировать события

**FR-ONB-031**: Экспорт всех календарей доступен через Settings → Import & Export → Export

### 6.4 Процесс импорта

```
[Settings → Import & Export]
        ↓
[Выбор файла (ICS/CSV) или ввод URL]
        ↓
[Выбор целевого календаря]
        ↓
[Обработка и валидация данных]
        ↓
[Подтверждение импорта]
        ↓
[События добавлены в календарь]
```

### 6.5 Бизнес-правила импорта

**FR-ONB-032**: При импорте в существующий календарь события добавляются, не заменяются

**FR-ONB-033**: Дубликаты событий не проверяются автоматически при импорте ICS/CSV

**FR-ONB-034**: Максимальный размер файла для импорта определяется системой

**FR-ONB-035**: Импорт доступен только через веб-версию (не в мобильных приложениях)

**FR-ONB-036**: При импорте события наследуют часовой пояс из файла или используют часовой пояс календаря

### 6.6 Миграция из популярных систем

| Источник | Метод миграции | Особенности |
|----------|----------------|-------------|
| **Outlook** | Экспорт ICS → Импорт в Google | Одноразовый импорт |
| **Outlook (Workspace)** | Google Workspace Sync for Microsoft Outlook | Двусторонняя синхронизация (платный Workspace) |
| **Apple iCloud** | Экспорт ICS с изменением webcal→http | Ручная конвертация URL |
| **Exchange** | Через Google Workspace Migration | Для корпоративных пользователей |

### 6.7 Подписка на внешние календари

**FR-ONB-037**: Подписка по URL поддерживает:
- Публичные календари организаций
- Праздничные календари
- Спортивные расписания
- Календари коллег (при наличии доступа)

**FR-ONB-038**: Обновление подписок происходит автоматически, периодичность определяется системой (обычно каждые несколько часов)

**FR-ONB-039**: Нельзя редактировать события в подписанных календарях

**FR-ONB-047**: Политики организации имеют приоритет над личными настройками

**FR-ONB-052**: Рабочее местоположение можно настроить по умолчанию для каждого дня недели

**FR-ONB-053**: Можно задать разное местоположение для разных частей дня

## 8. Обучающие подсказки

### 8.1 User Story: Обучение новых пользователей

```
КАК новый пользователь Google Calendar
Я ХОЧУ быстро освоить основные функции
ЧТОБЫ эффективно использовать приложение

Критерии приёмки:
- Вижу подсказки при первом использовании функций
- Могу пропустить обучение
- Могу вернуться к подсказкам позже
- Есть доступ к справочным материалам
```

### 8.2 Типы обучающих материалов

| Тип | Описание | Когда показывается |
|-----|----------|-------------------|
| **Приветственный тур** | Обзор основных функций | При первом входе |
| **Контекстные подсказки** | Пояснения к элементам интерфейса | При наведении/первом использовании |
| **Feature discovery** | Знакомство с новыми функциями | После обновлений |
| **Справочный центр** | Полная документация | По запросу пользователя |
| **Keyboard shortcuts** | Быстрые клавиши | Shift + / |

### 8.3 Функциональные требования обучения

**FR-ONB-054**: Приветственный тур показывается один раз при первом входе

**FR-ONB-055**: Пользователь может пропустить тур в любой момент

**FR-ONB-056**: Контекстные подсказки можно отключить в настройках

**FR-ONB-057**: Справочный центр доступен через иконку помощи (?)

**FR-ONB-058**: Keyboard shortcuts можно вызвать комбинацией Shift + /

### 8.4 Ключевые обучающие точки

1. **Создание события**
   - Быстрое создание кликом на временной слот
   - Полная форма через кнопку "Create"
   - Клавиша "C" для быстрого создания

2. **Навигация**
   - Переключение видов (день/неделя/месяц/расписание)
   - Клавиша "T" для перехода к сегодняшней дате
   - Мини-календарь для быстрого перехода

3. **Приглашение участников**
   - Добавление гостей к событию
   - Автоматический поиск свободного времени

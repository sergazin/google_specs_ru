# События (Events)

## Описание модуля

Модуль "События" является ядром Google Calendar. Обеспечивает создание, управление и координацию событий между пользователями. Поддерживает различные типы событий: обычные встречи, события на весь день, повторяющиеся события, Focus Time, Out of Office и Working Location.

---

## Роли и права доступа

### Организатор (Organizer)
- Создатель события или пользователь, которому передано право организатора
- Полный контроль над событием
- Может передавать права организатора другому пользователю

### Гость с правом редактирования (Guest with Modify Permission)
- Может изменять детали события (время, место, описание)
- Не может удалить событие
- Не может изменить организатора

### Гость с правом приглашения (Guest with Invite Permission)
- Может добавлять новых гостей
- Не может редактировать основные детали события

### Гость (Guest)
- Может видеть детали события
- Может отвечать на приглашение (RSVP)
- Может предлагать новое время
- Может видеть список гостей (если разрешено)

### Просмотр только свободен/занят (Free/Busy Viewer)
- Видит только факт занятости времени
- Не видит детали события

## Функциональные требования

### FR-EVT-001: Быстрое создание события

**Описание:** Создание события с минимальным количеством информации

**User Story:** Как пользователь, я хочу быстро создать событие, указав только название и время, чтобы не тратить время на заполнение всех деталей.

**Основной сценарий:**
1. Пользователь кликает на временной слот в календаре
2. Появляется компактная форма создания
3. Пользователь вводит название события
4. Система автоматически определяет:
   - Время начала (из клика)
   - Длительность (30 минут по умолчанию)
   - Календарь (основной календарь пользователя)
5. Пользователь нажимает "Сохранить"

**Альтернативный сценарий (Quick Add):**
1. Пользователь вводит текст в естественном формате
2. Примеры: "Встреча с Иваном завтра в 15:00", "Обед в пятницу 12:00-13:00"
3. Система парсит текст и создаёт событие

**Бизнес-правила:**
- BR-001: По умолчанию событие создаётся как "Занят" (Busy)
- BR-002: По умолчанию событие видно как "Default visibility"
- BR-003: Длительность по умолчанию — 30 минут для новых событий
- BR-004: Минимальная длительность события — 15 минут

**Результат:** Событие создано с минимальным набором полей

---

### FR-EVT-002: Детальное создание события

**Описание:** Создание события с полным набором параметров

**User Story:** Как организатор, я хочу создать полноценное событие со всеми деталями, чтобы участники имели всю необходимую информацию.

**Основной сценарий:**
1. Пользователь нажимает "Создать" или выбирает "Дополнительные параметры"
2. Заполняет детали события:
   - Название (обязательное)
   - Дата и время начала
   - Дата и время окончания
   - Часовой пояс (если отличается от основного)
   - Повторение (опционально)
   - Местоположение
   - Видеоконференция
   - Описание
   - Вложения
   - Гости
   - Настройки гостей
   - Напоминания
   - Цвет события
   - Статус занятости (Busy/Free)
   - Видимость (Default/Public/Private)
3. Нажимает "Сохранить"

**Бизнес-правила:**
- BR-010: Дата окончания не может быть раньше даты начала
- BR-011: Событие автоматически добавляется во все календари приглашённых гостей
- BR-012: При создании события с гостями автоматически отправляются приглашения

**Результат:** Событие создано со всеми указанными параметрами

### FR-EVT-003: Событие на весь день

**Описание:** Создание события без конкретного времени

**User Story:** Как пользователь, я хочу создать событие на весь день (например, отпуск или день рождения), чтобы оно отображалось вверху календаря.

**Основной сценарий:**
1. Пользователь создаёт событие
2. Активирует опцию "Весь день"
3. Выбирает дату (или диапазон дат)
4. Сохраняет событие

**Особенности:**
- Событие отображается в верхней части дня
- По умолчанию имеет статус "Free" (не блокирует время)
- Может длиться несколько дней

**Бизнес-правила:**
- BR-020: События на весь день по умолчанию не блокируют время (статус Free)
- BR-021: Максимальная длительность события на весь день — неограничена
- BR-022: События на весь день не имеют настроек часового пояса
- BR-023: При смене часового пояса пользователя событие на весь день остаётся на той же календарной дате

**Результат:** Событие на весь день создано

### FR-EVT-004: Событие с указанием времени

**Описание:** Создание события с конкретным временем начала и окончания

**User Story:** Как пользователь, я хочу создать встречу на определённое время, чтобы точно координироваться с участниками.

**Основной сценарий:**
1. Пользователь указывает дату
2. Указывает время начала
3. Указывает время окончания
4. Опционально указывает часовой пояс события

**Бизнес-правила:**
- BR-030: По умолчанию используется основной часовой пояс пользователя
- BR-031: Можно указать разные часовые пояса для начала и окончания
- BR-032: При изменении основного часового пояса пользователя время события сохраняется в UTC
- BR-033: Время события автоматически конвертируется для каждого гостя в его часовой пояс

**Результат:** Событие с точным временем создано

### FR-EVT-005: Повторяющиеся события (Recurrence)

**Описание:** Создание серии повторяющихся событий по расписанию

**User Story:** Как пользователь, я хочу создать регулярное событие (например, еженедельную встречу), чтобы не создавать каждое событие отдельно.

**Предустановленные варианты:**
- Ежедневно
- Еженедельно (по определённым дням)
- Ежемесячно (по дате или по дню недели)
- Ежегодно
- Каждый рабочий день (пн-пт)

**Пользовательские правила (Custom):**
1. Интервал повторения:
   - Каждые N дней
   - Каждые N недель (с выбором дней недели)
   - Каждые N месяцев (по дате или дню недели)
   - Каждые N лет
2. Условие завершения:
   - Никогда
   - После N повторений
   - До определённой даты

**Примеры правил RRULE:**
- `FREQ=WEEKLY;BYDAY=MO,WE,FR` — каждую неделю в понедельник, среду, пятницу
- `FREQ=MONTHLY;BYMONTHDAY=15` — каждый месяц 15-го числа
- `FREQ=MONTHLY;BYDAY=2FR` — каждую вторую пятницу месяца

**Бизнес-правила:**
- BR-040: Изменения можно применить к: только этому событию / этому и последующим / всем событиям
- BR-041: При изменении "только этого события" создаётся исключение (EXDATE)
- BR-042: Удаление серии удаляет все экземпляры
- BR-043: Нестандартные паттерны (произвольные даты) не поддерживаются нативно
- BR-044: Максимальное количество экземпляров серии для отображения — неограничено

**Результат:** Серия повторяющихся событий создана

### FR-EVT-006: Редактирование события

**Описание:** Изменение параметров существующего события

**User Story:** Как организатор, я хочу изменить детали события, чтобы скорректировать информацию.

**Основной сценарий:**
1. Пользователь открывает событие
2. Нажимает "Редактировать"
3. Изменяет необходимые поля
4. Сохраняет изменения
5. Гости получают уведомление об изменениях

**Редактирование повторяющегося события:**
1. При сохранении система спрашивает:
   - "Только это событие"
   - "Это и последующие события"
   - "Все события"
2. Применяются соответствующие изменения

**Бизнес-правила:**
- BR-050: Организатор может редактировать все поля
- BR-051: Гость с правом редактирования может изменять всё, кроме гостей и организатора
- BR-052: При изменении времени/места гости получают уведомление
- BR-053: История изменений не сохраняется (нет версионирования)
- BR-054: Изменения применяются немедленно

**Результат:** Событие обновлено, участники уведомлены

### FR-EVT-007: Удаление события

**Описание:** Удаление события из календаря

**User Story:** Как организатор, я хочу удалить событие, если оно больше не актуально.

**Основной сценарий (организатор):**
1. Организатор открывает событие
2. Выбирает "Удалить"
3. Для повторяющегося события выбирает опцию:
   - "Только это событие"
   - "Это и последующие события"
   - "Все события"
4. Подтверждает удаление
5. Событие удаляется из календарей всех гостей
6. Гости получают уведомление об отмене

**Сценарий (гость):**
1. Гость открывает событие
2. Выбирает "Удалить" или "Отклонить приглашение"
3. Событие удаляется только из его календаря
4. Событие остаётся у организатора и других гостей

**Бизнес-правила:**
- BR-060: Только организатор может удалить событие для всех
- BR-061: Удалённые события нельзя восстановить
- BR-062: При удалении события гость автоматически отмечается как "Отклонил"
- BR-063: Прошедшие события можно удалить

**Результат:** Событие удалено

### FR-EVT-008: Дублирование события

**Описание:** Создание копии существующего события

**User Story:** Как пользователь, я хочу быстро создать похожее событие на основе существующего.

**Основной сценарий (через меню):**
1. Пользователь открывает событие
2. Выбирает "Дублировать" (или "Копировать в...")
3. Открывается форма создания с предзаполненными данными
4. Пользователь изменяет дату/время и другие параметры
5. Сохраняет новое событие

**Быстрое дублирование (Ctrl/Cmd + перетаскивание):**
1. Пользователь зажимает Ctrl (Windows) или Cmd (Mac)
2. Перетаскивает событие на новый временной слот
3. Создаётся дубликат события на новое время

**Бизнес-правила:**
- BR-070: При дублировании создаётся новый уникальный код видеоконференции (с сентября 2025)
- BR-071: Гости из оригинального события не копируются автоматически
- BR-072: Вложения копируются как ссылки на те же файлы
- BR-073: Быстрое дублирование работает только в Day, Week, Month view

**Результат:** Создана копия события

### FR-EVT-009: Добавление гостей

**Описание:** Приглашение участников на событие

**User Story:** Как организатор, я хочу пригласить коллег на встречу, чтобы они могли присоединиться.

**Основной сценарий:**
1. Организатор создаёт или редактирует событие
2. В поле "Добавить гостей" вводит:
   - Email адрес
   - Имя из контактов
   - Группу Google Группы
3. Система показывает доступность гостя (если есть доступ к его календарю)
4. Организатор добавляет гостя
5. При сохранении отправляется приглашение

**Бизнес-правила:**
- BR-080: Можно приглашать по любому email адресу
- BR-081: Гости внутри организации видят доступность друг друга
- BR-082: Максимум гостей на событие — неограничено (но более 200 гостей отключает некоторые функции)
- BR-083: Можно приглашать группы Google Groups
- BR-084: Нельзя пригласить того же пользователя дважды

**Результат:** Гости добавлены и приглашены

### FR-EVT-010: Права гостей (Guest Permissions)

**Описание:** Настройка прав гостей события

**User Story:** Как организатор, я хочу контролировать, что могут делать приглашённые гости.

**Доступные разрешения:**
1. **Изменять событие (Modify event):**
   - Позволяет редактировать детали события
   - По умолчанию: выключено

2. **Приглашать других (Invite others):**
   - Позволяет добавлять новых гостей
   - По умолчанию: выключено (для рабочих аккаунтов) / включено (для личных)

3. **Видеть список гостей (See guest list):**
   - Позволяет видеть, кто приглашён
   - По умолчанию: включено

**Бизнес-правила:**
- BR-090: Настройки применяются ко всем гостям одинаково
- BR-091: Нельзя настроить права индивидуально для каждого гостя
- BR-092: Организатор всегда имеет полные права
- BR-093: Права можно изменить в любой момент до и после начала события

**Результат:** Права гостей настроены

### FR-EVT-011: RSVP — Ответ на приглашение

**Описание:** Подтверждение или отклонение участия в событии

**User Story:** Как гость, я хочу ответить на приглашение, чтобы организатор знал, приду я или нет.

**Варианты ответа:**
- **Да (Yes)** — подтверждаю участие
- **Нет (No)** — отклоняю приглашение
- **Возможно (Maybe)** — не уверен в участии

**Основной сценарий:**
1. Гость получает приглашение (email и/или уведомление в календаре)
2. Открывает событие или email
3. Выбирает один из вариантов ответа
4. Опционально добавляет комментарий к ответу
5. Ответ сохраняется

**Бизнес-правила:**
- BR-100: Можно изменить ответ в любое время
- BR-101: Организатор видит статистику ответов (X да, Y нет, Z возможно, W не ответили)
- BR-102: При ответе "Нет" событие не удаляется автоматически из календаря гостя
- BR-103: Если гость не ответил, он помечается как "Ожидает ответа"
- BR-104: Можно ответить прямо из email без входа в календарь

**Результат:** Ответ гостя зарегистрирован

### FR-EVT-012: Предложение нового времени

**Описание:** Гость может предложить альтернативное время для события

**User Story:** Как гость, я хочу предложить другое время для встречи, если не могу в указанное.

**Основной сценарий:**
1. Гость открывает приглашение на событие
2. Выбирает "Предложить новое время" (рядом с RSVP)
3. Выбирает новое время начала и окончания
4. Видит доступность других участников (если есть права)
5. Добавляет комментарий с объяснением
6. Отправляет предложение организатору
7. Организатор получает уведомление с предложением
8. Организатор может принять или отклонить предложение

**Бизнес-правила:**
- BR-110: Можно предложить только одно альтернативное время за раз
- BR-111: Функция недоступна для событий с более чем 200 гостями
- BR-112: Функция недоступна для групповых календарей или если нет прав
- BR-113: При принятии предложения время события меняется для всех
- BR-114: Организатор не обязан принимать предложение

**Результат:** Предложение нового времени отправлено организатору

### FR-EVT-013: Передача права организатора

**Описание:** Передача владения событием другому пользователю

**User Story:** Как организатор, я хочу передать управление событием коллеге, если уволился или ушёл из проекта.

**Основной сценарий:**
1. Организатор открывает событие
2. Выбирает меню "..." > "Сменить владельца"
3. Вводит email нового владельца
4. Добавляет сообщение (опционально)
5. Нажимает "Сменить владельца"
6. Новый владелец получает email с запросом
7. Новый владелец имеет 60 дней на принятие
8. После принятия — становится организатором

**Бизнес-правила:**
- BR-120: Только текущий организатор может передать права
- BR-121: Для рабочих аккаунтов новый владелец должен быть в той же организации
- BR-122: Запрос действителен 60 дней
- BR-123: До принятия запроса текущий организатор остаётся владельцем
- BR-124: Для повторяющихся событий передаётся вся серия
- BR-125: Функция недоступна в мобильном приложении
- BR-126: События типа Focus Time, Out of Office, Working Location нельзя передать

**Результат:** Право организатора передано новому пользователю

### FR-EVT-014: Местоположение события

**Описание:** Указание места проведения события

**User Story:** Как организатор, я хочу указать место встречи, чтобы участники знали, куда приходить.

**Типы местоположения:**
1. **Физический адрес:**
   - Текстовое поле с автодополнением из Google Maps
   - При указании адреса создаётся ссылка на карту

2. **Переговорная комната (для Workspace):**
   - Выбор из списка доступных комнат
   - Автоматическое бронирование ресурса

3. **Произвольный текст:**
   - "Кабинет директора", "Ресторан на углу"

**Бизнес-правила:**
- BR-130: При указании адреса Google показывает время в пути до места
- BR-131: Переговорные комнаты проверяются на доступность
- BR-132: Если комната занята — показывается предупреждение
- BR-133: Можно указать несколько мест (текстом)
- BR-134: Ссылка на карту создаётся автоматически для распознанных адресов

**Результат:** Место проведения указано

### FR-EVT-015: Видеоконференция

**Описание:** Добавление видеоконференции к событию

**User Story:** Как организатор, я хочу добавить видеозвонок к встрече, чтобы участники могли присоединиться удалённо.

**Поддерживаемые платформы:**
1. **Google Meet (встроенный):**

## Состояния события

### Статусы RSVP гостя

```
[Не ответил] → [Да] ↔ [Возможно] ↔ [Нет]
     ↓           ↑         ↑          ↑
     └───────────┴─────────┴──────────┘
```

- **Awaiting response** — приглашение отправлено, ответа нет
- **Yes (Accepted)** — гость подтвердил участие
- **Maybe (Tentative)** — гость не уверен
- **No (Declined)** — гость отказался

### Жизненный цикл события

```
[Черновик] → [Запланировано] → [В процессе] → [Завершено]
                   ↓
              [Отменено]
```

- **Запланировано (Scheduled)** — событие в будущем
- **В процессе (In Progress)** — текущее время попадает в период события
- **Завершено (Past)** — время события прошло
- **Отменено (Cancelled)** — организатор удалил событие

### Типы событий

| Тип | Создатель | Приватность | Передача прав |
|-----|-----------|-------------|---------------|
| Default Event | Любой | Настраиваемая | Да |
| Focus Time | Владелец календаря | Личная | Нет |
| Out of Office | Владелец календаря | Личная | Нет |
| Working Location | Владелец календаря | Организация | Нет |

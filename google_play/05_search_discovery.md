# Поиск и рекомендации (Search & Discovery)

## Описание модуля

Модуль поиска и рекомендаций Google Play Store -- центральный механизм обнаружения приложений и игр для более чем 2.5 миллиардов активных устройств Android. По данным Google, поиск является основным каналом обнаружения приложений: около 70% установок происходят после поискового взаимодействия (прямой поиск, рекомендации, browse). Google Play обрабатывает миллиарды поисковых запросов ежемесячно, используя семантическое индексирование, NLP и систему рекомендаций на базе DeepMind.

Ключевые особенности модуля:
- Текстовый поиск с семантическим анализом и NLP (не только keyword matching)
- Guided Search на базе Gemini AI -- поиск по намерению/цели, а не только по ключевым словам
- Голосовой поиск через Google Assistant
- Автодополнение и подсказки с учётом трендов и персонализации
- Фильтрация по цене, рейтингу, категории, возрастному рейтингу
- Персонализированные рекомендации на базе DeepMind ML (одна из крупнейших рекомендательных систем в мире)
- Рекомендации "Похожие приложения", "Вам также может понравиться"
- Curated Spaces и Collections -- курированные подборки
- Промо-контент (LiveOps / Promotional Content) в поисковых поверхностях
- Рекламные результаты (Google Ads for Apps)
- Контентная фильтрация и родительский контроль
- ASO (App Store Optimization) -- факторы ранжирования

| Роль | Описание |

## Функциональные требования

### FR-GPS-SRCH-001: Текстовый поиск приложений
**Приоритет:** P0-Critical

**Описание:** Основной механизм поиска приложений и игр по текстовому запросу. В отличие от Apple App Store, Google Play не имеет отдельного поля для ключевых слов разработчика, а использует семантическое индексирование и NLP для анализа всех текстовых метаданных приложения.

**Роли:** Все пользователи

**Основной сценарий:**
1. Пользователь нажимает на поисковую строку в верхней части Google Play
2. Вводит поисковый запрос (название приложения, категория, описание функции)
3. Система выполняет семантический анализ запроса с учётом NLP
4. Результаты отображаются в виде вертикального списка карточек приложений
5. Каждая карточка содержит: иконку, название, разработчика, рейтинг, размер, количество загрузок
6. Пользователь выбирает приложение или уточняет запрос

**Альтернативный сценарий -- пустые результаты:**
1. Пользователь вводит запрос, по которому нет точных совпадений
2. Система показывает наиболее релевантные альтернативы
3. Отображается сообщение "Ничего не найдено" только при полном отсутствии релевантных результатов

**Поля индексации и их вес:**
| Поле | Вес | Лимит символов | Описание |
|------|-----|----------------|----------|
| Название приложения (App Title) | Наивысший | 30 символов | Основной фактор ранжирования, семантический анализ |
| Краткое описание (Short Description) | Высокий | 80 символов | Индексируется полностью, видно в выдаче |
| Полное описание (Long Description) | Средний | 4000 символов | Семантический анализ NLP, keyword density |
| Название разработчика (Developer Name) | Низкий | -- | Учитывается при прямом поиске |
| Название пакета (Package Name) | Минимальный | -- | Техническое поле, учитывается при точном совпадении |
| Категория (Category) | Контекстный | -- | Влияет на ранжирование в рамках категории |

**Принципы работы семантического поиска:**
- Google Play использует NLP для понимания намерения запроса, а не простого совпадения слов
- Запрос "фоторедактор для селфи" найдёт приложения, даже если точная фраза отсутствует в метаданных
- Система понимает синонимы, связанные понятия, контекст использования
- Keyword stuffing (чрезмерное повторение ключевых слов) штрафуется

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-001 | Поиск учитывает орфографические ошибки, опечатки и транслитерацию |
| BR-002 | Результаты локализуются под регион и язык устройства пользователя |
| BR-003 | Поиск поддерживает все языки, на которых доступен Google Play (77+ языков) |
| BR-004 | Keyword stuffing в метаданных приводит к понижению ранжирования или удалению из индекса |
| BR-005 | Приложения, нарушающие политики Google Play, исключаются из поисковой выдачи |
| BR-006 | Приложения с неполными метаданными ранжируются ниже |
| BR-007 | Минимальная задержка отображения результатов -- менее 500 мс |

### FR-GPS-SRCH-002: Guided Search (AI-поиск по намерению)
**Приоритет:** P0-Critical

**Описание:** Новая функция (сентябрь 2025) на базе Gemini AI, позволяющая искать приложения по описанию цели или проблемы, а не по конкретному названию или ключевому слову. Система анализирует намерение пользователя и организует результаты в тематические категории.

**Роли:** Все пользователи

**Основной сценарий:**
1. Пользователь вводит описание цели, например: "найти квартиру для аренды"
2. Система с помощью Gemini AI интерпретирует намерение
3. Результаты организуются в тематические группы (например: "Аренда квартир", "Агрегаторы недвижимости", "Сервисы для переезда")
4. Пользователь выбирает наиболее подходящую группу
5. Внутри группы отображаются отсортированные по релевантности приложения

**Примеры запросов Guided Search:**
| Запрос пользователя | Интерпретация AI | Категории результатов |
|---------------------|------------------|----------------------|
| "find a home" | Поиск недвижимости | Аренда, Покупка, Агенты |
| "deck-building games" | Карточные стратегии | TCG, Roguelike, Board games |
| "learn to cook Italian" | Кулинарное обучение | Рецепты, Видеокурсы, Ингредиенты |
| "manage my money better" | Финансовое планирование | Бюджет, Инвестиции, Трекеры расходов |

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-008 | Guided Search доступен как дополнение к классическому поиску, не заменяет его |
| BR-009 | AI-группировка результатов основана на семантическом анализе намерения |
| BR-010 | Результаты Guided Search учитывают персонализацию авторизованного пользователя |
| BR-011 | Рекламные результаты в Guided Search помечаются отдельно |
| BR-012 | Guided Search постепенно разворачивается по регионам (первоначально -- англоязычные рынки) |
| BR-013 | Разработчики должны описывать в листинге решаемую проблему, а не только функции |

### FR-GPS-SRCH-003: Автодополнение поисковых запросов
**Приоритет:** P0-Critical

**Описание:** Система подсказок, появляющихся при вводе текста в поисковую строку. Подсказки основаны на популярных запросах, поведении пользователей и трендах. Пользователи мобильных устройств предпочитают выбирать из подсказок, а не вводить полный запрос.

**Роли:** Все пользователи

**Основной сценарий:**
1. Пользователь нажимает на поисковую строку
2. Начинает вводить текст
3. После ввода первых 1-2 символов появляется список подсказок
4. Список обновляется в реальном времени с каждым введённым символом
5. Пользователь может выбрать подсказку для мгновенного поиска
6. При выборе подсказки выполняется полный поиск по этому запросу

**Источники подсказок:**
- Популярные поисковые запросы других пользователей
- Названия приложений из каталога Google Play
- Названия категорий и жанров
- Имена известных разработчиков и издателей
- Тренды текущего региона
- История поиска текущего пользователя (если авторизован)

**Особенности ранжирования подсказок:**
- Подсказки ранжируются по комбинации: популярность запроса + персонализация + региональная релевантность
- Long-tail запросы (длинные специфичные фразы) появляются по мере уточнения ввода
- Подсказки могут различаться на мобильном устройстве и планшете

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-014 | Подсказки появляются после ввода минимум 1 символа |
| BR-015 | Максимальное количество подсказок на экране -- до 8 |
| BR-016 | Подсказки обновляются в реальном времени (debounce ~150 мс) |
| BR-017 | Подсказки не содержат запрещённого, нецензурного или взрослого контента |
| BR-018 | Подсказки локализуются под язык и регион устройства |
| BR-019 | Персонализированные подсказки (из истории) визуально отличаются от общих |

### FR-GPS-SRCH-004: Тренды поиска (Trending Searches)
**Приоритет:** P1-High

**Описание:** Отображение актуальных трендовых поисковых запросов до начала ввода текста. Помогает пользователям обнаружить популярные приложения и актуальные тенденции.

**Роли:** Все пользователи

**Основной сценарий:**
1. Пользователь нажимает на поисковую строку
2. До начала ввода отображается список трендовых запросов
3. Каждый тренд отображается с иконкой категории/приложения
4. Пользователь выбирает тренд
5. Выполняется поиск по выбранному запросу

**Факторы определения трендов:**
- Резкий рост количества запросов за короткий период
- Сезонные события (Новый год, летние каникулы, начало учебного года)
- Вирусные приложения и игры
- Крупные обновления популярных приложений
- Социальные и культурные события
- Маркетинговые кампании

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-020 | Тренды обновляются несколько раз в день |
| BR-021 | Тренды локализуются под регион и страну пользователя |
| BR-022 | Запрещённый и нецензурный контент фильтруется из трендов |
| BR-023 | Тренды могут включать как приложения, так и категориальные запросы |
| BR-024 | Тренды отображаются до начала ввода текста в поисковую строку |

### FR-GPS-SRCH-005: История поиска
**Приоритет:** P1-High

**Описание:** Сохранение и отображение недавних поисковых запросов пользователя для быстрого повторного доступа.

**Роли:** Авторизованный пользователь

**Основной сценарий:**
1. Пользователь выполняет поисковый запрос
2. Запрос автоматически сохраняется в истории
3. При следующем открытии поисковой строки история отображается
4. Пользователь выбирает запрос из истории для повторного поиска

**Управление историей:**
- Удаление отдельного запроса (свайп или кнопка удаления)
- Очистка всей истории поиска через настройки Google-аккаунта
- Отключение сохранения истории через Web & App Activity
- История синхронизируется между устройствами через Google-аккаунт

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-025 | История сохраняется только для авторизованных пользователей |
| BR-026 | История синхронизируется через Google-аккаунт между устройствами |
| BR-027 | Пользователь может отключить сохранение истории в настройках аккаунта |
| BR-028 | При отключении Web & App Activity история поиска не сохраняется |
| BR-029 | Недавние запросы отображаются первыми в списке подсказок |
| BR-030 | Для детских аккаунтов (Family Link) история может быть ограничена родителем |

### FR-GPS-SRCH-006: Голосовой поиск
**Приоритет:** P1-High

**Описание:** Поиск приложений и игр с помощью голосовых команд через Google Assistant или встроенный голосовой ввод. Позволяет найти и установить приложения без набора текста.

**Роли:** Все пользователи

**Основной сценарий:**
1. Пользователь нажимает иконку микрофона в поисковой строке Google Play
2. Произносит запрос голосом
3. Система распознает речь и преобразует в текст
4. Выполняется поиск по распознанному запросу
5. Результаты отображаются стандартным образом

**Альтернативный сценарий -- через Google Assistant:**
1. Пользователь активирует Google Assistant ("OK Google" или кнопка)
2. Произносит команду: "Найди приложение для медитации" / "Установи Telegram"
3. Assistant выполняет поиск в Google Play
4. Отображает результаты или предлагает установить конкретное приложение
5. Пользователь подтверждает установку голосом или нажатием

**Голосовые команды:**
| Команда | Действие |
|---------|----------|
| "Найди [название] в Play Store" | Поиск по названию |
| "Установи [название]" | Поиск + предложение установки |
| "Открой [название]" | Открытие уже установленного приложения |
| "Покажи приложения для [категория]" | Категориальный поиск |
| "Какие игры сейчас популярны" | Тренды игр |

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-031 | Голосовой поиск требует подключения к интернету |
| BR-032 | Поддерживаются все языки Google Assistant (40+ языков) |
| BR-033 | Установка платного приложения через голос требует подтверждения (биометрия/PIN) |
| BR-034 | Голосовые запросы сохраняются в истории Google-аккаунта (если включено) |
| BR-035 | Результаты голосового поиска соответствуют настройкам родительского контроля |
| BR-036 | При неточном распознавании система предлагает уточнить запрос |

### FR-GPS-SRCH-007: Факторы ранжирования (ASO -- App Store Optimization)
**Приоритет:** P0-Critical

**Описание:** Комплексный алгоритм ранжирования определяет порядок приложений в поисковой выдаче. В отличие от Apple App Store, Google Play активно использует семантический анализ полного описания приложения. Алгоритм учитывает как текстовую релевантность, так и поведенческие сигналы.

**Роли:** Разработчик, Система

**Прямые факторы ранжирования (On-Metadata):**

| Фактор | Вес | Описание |
|--------|-----|----------|
| Название приложения (Title) | Критический | Наиболее важный текстовый фактор; до 30 символов |
| Краткое описание (Short Description) | Высокий | До 80 символов; индексируется полностью |
| Полное описание (Full Description) | Средний | До 4000 символов; семантический NLP-анализ |
| Категория (Category) | Средний | Влияет на ранжирование внутри категории |
| URL / Package Name | Минимальный | Учитывается при точном совпадении |

**Поведенческие факторы ранжирования (Off-Metadata):**

| Фактор | Вес | Описание |
|--------|-----|----------|
| Объём загрузок (Install Volume) | Высокий | Общее количество установок как сигнал популярности |
| Скорость загрузок (Install Velocity) | Высокий | Темп роста установок за короткий период |
| Рейтинг пользователей (User Rating) | Высокий | Средняя оценка; приложения ниже 3.5 теряют видимость |
| Количество и качество отзывов (Reviews) | Средний | Количество, свежесть, детальность отзывов |
| Конверсия (Conversion Rate) | Высокий | % пользователей, установивших приложение после просмотра |
| Удержание (Retention Rate) | Высокий | Сколько пользователей сохраняют приложение после установки |
| Вовлечённость (Engagement) | Средний | Частота и длительность использования приложения |
| Частота обновлений (Update Frequency) | Средний | Регулярность выпуска обновлений |
| Техническое качество (Android Vitals) | Высокий | Crash rate, ANR rate, батарея; с марта 2026 -- обязательный порог |
| Деинсталляции (Uninstall Rate) | Средний-Высокий | Быстрые деинсталляции -- негативный сигнал |

**Дополнительные факторы:**

| Фактор | Описание |
|--------|----------|
| Локализация | Приложения с локализованными листингами ранжируются выше в соответствующих регионах |
| Бэклинки и внешние ссылки | Упоминания и ссылки на приложение из внешних источников |
| Социальное доказательство | Упоминания в соцсетях, медиа, блогах |
| Оценка "Выбор редакции" | Редакционные награды Google Play повышают видимость |
| Data Safety compliance | Заполненный раздел Data Safety Section |

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-037 | Keyword stuffing (повторение слов) приводит к понижению или удалению |
| BR-038 | Приложения с рейтингом ниже 3.5 значительно теряют видимость в поиске |
| BR-039 | Высокий crash rate (Android Vitals) понижает ранжирование |
| BR-040 | С марта 2026 приложения, не соответствующие порогам Android Vitals, могут быть исключены из featured-поверхностей |
| BR-041 | Естественный язык в описании ранжируется лучше, чем keyword-списки |
| BR-042 | Обновление метаданных (скриншоты, описание) 2-4 раза в год коррелирует с лучшими позициями |
| BR-043 | Быстрая деинсталляция (менее 2 дней после установки) -- сильный негативный сигнал |

### FR-GPS-SRCH-013: Персонализированные рекомендации "Для вас"
**Приоритет:** P0-Critical

**Описание:** Система персонализированных рекомендаций, основанная на технологиях DeepMind ML. Является одной из крупнейших рекомендательных систем в мире, обрабатывающей данные миллиардов пользователей ежемесячно. Состоит из трёх ключевых моделей: генератор кандидатов, реранкер и оптимизатор множественных целей.

**Роли:** Авторизованный пользователь

**Архитектура рекомендательной системы:**

**Этап 1 -- Генератор кандидатов (Candidate Generator):**
- Глубокая нейронная сеть анализирует более 1 миллиона приложений
- Предсказывает следующее приложение для установки на основе предыдущих установок пользователя
- Формирует пул потенциально релевантных приложений (сотни-тысячи)

**Этап 2 -- Реранкер (Reranker):**
- Обучается на парных сравнениях: если пользователю показали два приложения рядом, выбранное -- более релевантно
- Учитывает контекст показа: время суток, устройство, недавние действия
- Ранжирует кандидатов в финальный персонализированный список

**Этап 3 -- Оптимизатор множественных целей (Multi-Objective Optimization):**
- Аддитивная attention-модель учитывает вероятность установки
- Importance weighting: учитывается соотношение показов к установкам каждого приложения
- Балансирует между exploit (рекомендация знакомого) и explore (рекомендация нового)

**Результаты:**
- +20% увеличение install rate из секции "Вам также может понравиться" (по сравнению с контролем без реранкинга)

**Расположение рекомендаций:**
| Поверхность | Тип рекомендаций |
|-------------|-----------------|
| Главная страница (Home) | "Рекомендуется для вас", "Основано на ваших интересах" |
| Вкладка "Для тебя" (For You) | Персонализированная лента |
| Вкладка "Игры" | "Рекомендуемые игры" |
| Вкладка "Приложения" | "Рекомендуемые приложения" |
| Страница приложения | "Вам также может понравиться" |
| After Install | "Другие пользователи также установили" |

**Факторы персонализации:**
| Фактор | Описание |
|--------|----------|
| История установок | Какие приложения установлены на устройстве |
| История удалений | Какие приложения были деинсталлированы |
| Поисковые запросы | Что пользователь искал ранее |
| Просмотры страниц приложений | Какие листинги просматривал |
| Активность в приложениях | Какие категории приложений используются чаще |
| Данные Google-аккаунта | Интересы, демографика (в рамках privacy-policy) |
| Устройство | Тип устройства, размер экрана, версия Android |
| Регион и язык | Географическая и языковая привязка |

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-074 | Персонализация требует авторизации Google-аккаунтом |
| BR-075 | Пользователь может отключить персонализацию в настройках Google-аккаунта |
| BR-076 | Для детских аккаунтов персонализация ограничена (без поведенческих данных из других сервисов Google) |
| BR-077 | Рекомендации не включают приложения, нарушающие политики Google Play |
| BR-078 | Приложения с низким рейтингом (< 3.0) исключаются из рекомендаций |
| BR-079 | Рекомендательная система обрабатывает данные миллиардов пользователей ежемесячно |

### FR-GPS-SRCH-015: Рекомендации "Другие пользователи также установили"
**Приоритет:** P1-High

**Роли:** Все пользователи

1. Пользователь устанавливает приложение
2. После установки или на странице приложения появляется секция "Другие пользователи также установили"

4. Приложения ранжируются по вероятности установки для данного пользователя

**Механизм:**

### FR-GPS-SRCH-024: Store Listing Experiments (A/B-тесты листингов)

**Описание:** Инструмент Play Console, позволяющий разработчикам проводить A/B-тесты различных вариантов метаданных (иконка, скриншоты, описание) для оптимизации конверсии поиска в установку.

**Роли:** Разработчик

**Основной сценарий:**
1. Разработчик создаёт эксперимент в Play Console
2. Выбирает элементы для тестирования (иконка, скриншоты, описание, видео)
3. Загружает альтернативные варианты (вариант B, C, D)
4. Настраивает параметры: MDE (Minimum Detectable Effect), Confidence Level, цель
5. Запускает эксперимент
6. Google распределяет трафик между вариантами
7. По достижении статистической значимости определяется победитель
8. Разработчик применяет лучший вариант

**Параметры эксперимента:**
| Параметр | Описание |
|----------|----------|
| Minimum Detectable Effect (MDE) | Минимальный порог разницы для признания результата |
| Confidence Level | Уровень достоверности результата (обычно 95%) |
| Experiment Goal | "First-time installers" или "Retained first-time installers" (рекомендуется) |
| Duration | Обычно 7-14 дней для достижения статистической значимости |

**Тестируемые элементы:**
- Иконка приложения
- Feature Graphic (баннер)
- Скриншоты (набор и порядок)
- Промо-видео
- Краткое описание (Short Description)
- Полное описание (Full Description)

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-131 | Эксперименты доступны всем разработчикам в Play Console |
| BR-132 | Одновременно может быть активен один эксперимент на листинг |
| BR-133 | Результаты эксперимента не гарантируют улучшение в поиске (только конверсия) |
| BR-134 | Цель "Retained first-time installers" рекомендуется как более качественная метрика |

| BR-140 | Пользователи могут сообщать о неприемлемом контенте через кнопку "Жалоба" |
| BR-141 | Модераторы Google могут вручную удалять приложения из выдачи |

## Состояния поискового запроса

```
[Пустая строка] → [Ввод текста] → [Автодополнение] → [Выполнение поиска]
                                                              ↓
                                                    [Результаты найдены]
                                                              ↓
                                              ┌───────────────┼───────────────┐
                                              ↓               ↓               ↓
                                    [Выбор приложения] [Уточнение запроса] [Пустой результат]
                                              ↓               ↓               ↓
                                    [Страница приложения] [Новый поиск] [Рекомендации альтернатив]
```

**Состояния строки поиска:**

| Состояние | Отображение |
|-----------|-------------|
| Пустая строка (до нажатия) | Placeholder текст, иконка поиска, иконка микрофона |
| Фокус без ввода | Тренды, история поиска, предложения |
| Ввод текста (1+ символ) | Автодополнение, подсказки |
| Поиск выполнен | Результаты, рекламные позиции, Guided Search группы |
| Нет результатов | Альтернативные предложения, популярные приложения |
| Ошибка | Сообщение об ошибке, кнопка "Повторить" |

## Сущности данных

### Search Query (Поисковый запрос)

| Атрибут | Описание |
|---------|----------|
| query_id | Уникальный идентификатор запроса |
| query_text | Текст поискового запроса |
| query_type | Тип запроса: text, voice, guided |
| timestamp | Время выполнения запроса |
| user_id | ID пользователя (если авторизован) |
| device_type | Тип устройства (phone, tablet, chromebook, tv, auto) |
| region | Регион пользователя (ISO 3166) |
| language | Язык интерфейса |
| is_personalized | Использовалась ли персонализация |
| results_count | Количество результатов |

### Search Result (Результат поиска)

| Атрибут | Описание |
|---------|----------|
| result_id | Уникальный идентификатор результата |
| query_id | Связь с запросом |
| app_id | Уникальный идентификатор приложения (Package Name) |
| position | Позиция в результатах (1-based) |
| is_ad | Является ли рекламным результатом |
| ad_campaign_id | ID рекламной кампании (если is_ad) |
| relevance_score | Внутренняя оценка релевантности |
| impression | Факт показа |
| click | Факт клика |
| install | Факт установки после клика |

### App Metadata (Метаданные приложения для поиска)

| Атрибут | Описание |
|---------|----------|
| package_name | Уникальный идентификатор пакета |
| app_title | Название приложения (до 30 символов) |
| short_description | Краткое описание (до 80 символов) |
| full_description | Полное описание (до 4000 символов) |
| developer_name | Имя разработчика |
| primary_category | Основная категория |
| secondary_category | Дополнительная категория |
| content_rating | Возрастной рейтинг (IARC) |
| user_rating | Средний рейтинг (1.0-5.0) |
| rating_count | Количество оценок |
| install_count | Количество установок (диапазон) |
| price | Цена (0 для бесплатных) |
| contains_ads | Содержит рекламу |
| has_iap | Наличие встроенных покупок |
| last_updated | Дата последнего обновления |
| android_vitals_score | Оценка технического качества |
| data_safety_completed | Заполнен ли Data Safety Section |
| editors_choice | Имеет ли награду "Выбор редакции" |

### Recommendation (Рекомендация)

| Атрибут | Описание |
|---------|----------|
| recommendation_id | Уникальный идентификатор |
| user_id | ID пользователя |
| app_id | Рекомендованное приложение |
| recommendation_type | Тип: for_you, similar, also_installed, editorial |
| source_app_id | Исходное приложение (для similar/also_installed) |
| surface | Поверхность показа (home, search, app_page, games_tab) |
| score | Оценка релевантности рекомендации |
| position | Позиция в списке рекомендаций |
| impression | Факт показа |
| click | Факт клика |
| install | Факт установки |

### Promotional Content (Промо-контент)

| Атрибут | Описание |
|---------|----------|
| promo_id | Уникальный идентификатор промо |

| promo_type | Тип: offer, event, update, new_content, pre_reg |
| title | Заголовок промо |

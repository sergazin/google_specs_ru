# Страница приложения (App Details Page)

## Описание модуля

Страница приложения (App Details Page) -- центральный элемент Google Play Store, на котором пользователь принимает решение об установке, покупке или обновлении приложения. Страница аккумулирует всю ключевую информацию: идентификацию (название, иконка, разработчик), визуальные материалы (скриншоты, видео), текстовую информацию (описание, changelog), социальное доказательство (рейтинг, отзывы), конфиденциальность (Data Safety), метаданные (размер, совместимость, версия) и монетизационные маркеры ("Содержит рекламу", "Покупки в приложении").

Страница доступна как в мобильном приложении Google Play (Android), так и в веб-версии (play.google.com). Качество оформления страницы напрямую влияет на конверсию установок (CVR). По данным Google, оптимизация store listing может повысить конверсию на 20-30%.

С 2025 года Google активно внедряет AI-функции на базе Gemini: AI-резюме отзывов, функция "Ask Play about this app", обновлённый дизайн с безопасностными панелями и группировкой отзывов.

### Ключевые элементы страницы

- **Идентификация**: название, иконка, разработчик, категория
- **Визуальные материалы**: скриншоты, видео-превью (YouTube)
- **Текстовая информация**: краткое описание, полное описание, "Что нового"
- **Социальное доказательство**: рейтинг, количество оценок, отзывы, AI-резюме
- **Конфиденциальность**: Data Safety section, разрешения (permissions)
- **Метаданные**: размер, версия, дата обновления, совместимость, возрастной рейтинг (IARC)
- **Монетизация**: цена, метки "Содержит рекламу" / "Покупки в приложении"
- **Навигация**: похожие приложения, другие приложения разработчика
- **Специальные бейджи**: Google Play Pass, Teacher Approved, Pre-registration, Early Access
- **Промо-контент**: LiveOps карточки (Promotional Content)
- **AI-функции**: "Ask Play about this app" (Gemini)

## Роли пользователей

| Роль | Описание | Возможности |
|------|----------|-------------|
| **Гость (неавторизованный)** | Просмотр страницы без Google-аккаунта (веб-версия) | Просмотр всей информации, невозможность установки/оценки |
| **Авторизованный пользователь** | Пользователь с Google-аккаунтом | Установка, покупка, оценка, отзыв, wishlist, жалоба |
| **Владелец приложения** | Пользователь, установивший приложение | Открытие, обновление, удаление, написание отзыва |
| **Разработчик** | Управляет приложением через Play Console | Редактирование листинга, ответы на отзывы, промо-контент |
| **Участник Family Group** | Член семейной группы Google | Доступ к купленным приложениям через Family Library |
| **Ребёнок (контролируемый аккаунт)** | Аккаунт под родительским контролем (Family Link) | Ограниченный доступ, запрос разрешения родителя |
| **Подписчик Google Play Pass** | Пользователь с активной подпиской Play Pass | Доступ к приложениям каталога без рекламы и покупок |

## Функциональные требования

### FR-GPLAY-APP-001: Шапка страницы приложения (App Header)

**Priority**: P0-Critical

**Описание:** Верхняя часть страницы с ключевой идентификацией приложения. Является первым, что видит пользователь, и определяет первое впечатление.

**Роли:** Гость, Авторизованный пользователь

**Основной сценарий:**
1. Пользователь открывает страницу приложения (из поиска, каталога, ссылки, рекомендации)
2. Система отображает шапку с ключевыми элементами:

   **Иконка приложения:**
   - Размер исходника: 512x512 пикселей
   - Формат: 32-bit PNG с альфа-каналом
   - Обязательна для публикации
   - Отображается с закруглёнными углами (автоматическая маска Google Play)
   - Не должна содержать вводящие в заблуждение элементы (бейджи магазинов, "NEW", "SALE")

   **Название приложения:**
   - До 30 символов (с 2023 года, ранее -- 50)
   - Отображается крупным шрифтом рядом с иконкой
   - Должно быть уникальным в контексте разработчика
   - Запрещены: ключевые слова спама, нерелевантные слова, CAPS LOCK, эмодзи (кроме логотипа), упоминание рейтинга ("Best app")
   - Локализуется для каждого языка

   **Имя разработчика:**
   - Кликабельная ссылка на страницу разработчика
   - При нажатии -- переход к списку всех приложений разработчика
   - Для организаций -- юридическое название или бренд
   - Для индивидуальных разработчиков -- имя из Developer Account

   **Категория приложения:**
   - Основная категория (например, "Social", "Tools", "Games - Action")
   - Отображается рядом с именем разработчика
   - Кликабельна -- переход в раздел категории

   **Рейтинг (краткий):**
   - Средняя оценка (1.0--5.0, с точностью до десятых)
   - Визуализация звёздами (заполненные/частично заполненные)
   - Общее количество оценок (сокращённое: "4.5 (12K ratings)")
   - Количество скачиваний (например, "10M+ downloads")

   **Возрастной рейтинг IARC:**
   - Бейдж с рейтингом (Everyone, Everyone 10+, Teen, Mature 17+, Adults only 18+)
   - Отображается как компактный значок
   - При нажатии -- детальная информация о причинах рейтинга

   **Метки монетизации:**
   - "Contains ads" -- если приложение содержит рекламу
   - "In-app purchases" -- если есть встроенные покупки
   - Отображаются под кнопкой действия

3. Кнопка действия (основная CTA):
   - Определяется состоянием приложения (см. FR-GPLAY-APP-012)

**Альтернативные сценарии:**
- Сценарий А (Приложение с Play Pass): Дополнительный бейдж Play Pass
- Сценарий Б (Pre-registration): Кнопка "Pre-register" вместо "Install"
- Сценарий В (Недоступно в регионе): Сообщение "This app isn't available in your country"
- Сценарий Г (Несовместимо с устройством): Сообщение "Your device isn't compatible with this version"

**Бизнес-правила:**

| Rule | Description |
|------|-------------|
| BR-001 | Название приложения ограничено 30 символами |
| BR-002 | Название не должно содержать ключевые слова спама, вводящие в заблуждение фразы ("best", "#1", "free") |
| BR-003 | Иконка должна соответствовать Content Guidelines Google Play |
| BR-004 | Рейтинг отображается только при наличии достаточного количества оценок (порог определяется Google) |
| BR-005 | Возрастной рейтинг обязателен для всех приложений (определяется IARC-анкетой) |
| BR-006 | Метка "Contains ads" обязательна если приложение содержит рекламу, включая сторонние SDK |
| BR-007 | Метка "In-app purchases" обязательна при наличии любых покупок внутри приложения |
| BR-008 | Имя разработчика должно соответствовать верифицированному профилю в Play Console |

**Acceptance Criteria:**
- [ ] Все обязательные элементы шапки отображаются корректно
- [ ] Иконка имеет закруглённые углы
- [ ] Рейтинг соответствует текущим данным
- [ ] Метки монетизации отображаются при наличии рекламы/покупок
- [ ] Нажатие на имя разработчика ведёт к его странице
- [ ] Нажатие на категорию ведёт к разделу категории
- [ ] Возрастной рейтинг кликабелен и раскрывает детали

### FR-GPLAY-APP-002: Скриншоты и видео-превью (Screenshots & Video Preview)

**Priority**: P0-Critical

**Описание:** Галерея визуальных материалов, демонстрирующих интерфейс и возможности приложения. Скриншоты и видео являются ключевым фактором конверсии.

**Роли:** Гость, Авторизованный пользователь

**Основной сценарий:**
1. Система отображает горизонтальную галерею под шапкой приложения
2. Порядок отображения:
   - Видео-превью (если есть) -- первый элемент
   - Скриншоты -- в порядке, заданном разработчиком

   **Скриншоты:**

   Количество:
   - Минимум 2, максимум 8 скриншотов для каждого типа устройства
   - Первые 1--3 скриншота видны в результатах поиска и на странице каталога

   Типы устройств:
   - Телефон (обязательно)
   - 7-дюймовый планшет (рекомендовано)
   - 10-дюймовый планшет (рекомендовано)
   - Android TV (если поддерживается)
   - Wear OS (если поддерживается)
   - Chromebook (если поддерживается)

   Требования к изображениям:
   - Формат: JPEG или 24-bit PNG (без альфа-канала)
   - Минимальная сторона: 320 px
   - Максимальная сторона: 3840 px
   - Соотношение сторон: не более 2:1
   - Скриншоты должны отражать реальный пользовательский опыт
   - Допускаются текстовые оверлеи и рамки устройств
   - Запрещены: вводящие в заблуждение изображения, неактуальный интерфейс

   **Видео-превью:**
   - Источник: YouTube-видео (ссылка на YouTube)
   - Максимальная длительность: 120 секунд (рекомендуется 30--120 секунд)
   - Загрузка на YouTube, затем указание URL в Play Console
   - Отображается первым элементом в галерее
   - Миниатюра видео с кнопкой Play
   - При нажатии -- воспроизведение в плеере (встроенном или YouTube)
   - Не поддерживается прямая загрузка файла -- только YouTube-ссылка

3. Навигация по галерее:
   - Горизонтальный свайп
   - При нажатии на скриншот -- полноэкранный просмотр
   - В полноэкранном режиме -- свайп между скриншотами
   - Индикаторы позиции (точки)

**Альтернативные сценарии:**
- Сценарий А (Только телефон): Скриншоты телефона
- Сценарий Б (Игра): Преимущественно ландшафтные скриншоты
- Сценарий В (Нет видео): Галерея начинается со скриншотов
- Сценарий Г (Автовоспроизведение): В некоторых контекстах видео и скриншоты показываются как slideshow (тестирование Google, 2025)

**Бизнес-правила:**

| Rule | Description |
|------|-------------|
| BR-009 | Минимум 2 скриншота для телефона обязательны |
| BR-010 | Скриншоты должны показывать реальный текущий интерфейс приложения |
| BR-011 | Видео-превью не должно содержать вводящий в заблуждение контент |
| BR-012 | Скриншоты локализуются для каждого языка листинга |
| BR-013 | Видео должно быть YouTube-ссылкой, не прямой загрузкой |
| BR-014 | Скриншоты и видео отображаются на странице и в других поверхностях Google Play (поиск, главная) |
| BR-015 | Порядок скриншотов определяется разработчиком и влияет на конверсию |

**Acceptance Criteria:**
- [ ] Галерея отображает видео (если есть) первым элементом
- [ ] Скриншоты отображаются в заданном порядке
- [ ] Горизонтальный свайп работает плавно
- [ ] Нажатие открывает полноэкранный просмотр
- [ ] Видео воспроизводится при нажатии
- [ ] Скриншоты адаптированы под текущее устройство пользователя

### FR-GPLAY-APP-003: Описание приложения (App Description)

**Priority**: P0-Critical

**Описание:** Текстовая информация о функциональности и возможностях приложения. Делится на краткое описание (Short Description) и полное описание (Full Description).

**Роли:** Гость, Авторизованный пользователь

**Основной сценарий:**
1. Система отображает секцию "About this app":

   **Краткое описание (Short Description):**
   - До 80 символов
   - Отображается всегда, без необходимости раскрытия
   - Видно в некоторых поверхностях Google Play (поиск)
   - Краткая суть приложения

   **Полное описание (Full Description):**
   - До 4000 символов
   - По умолчанию отображается сокращённая версия (~3--4 строки)
   - Кнопка/ссылка "Read more" / стрелка для раскрытия полного текста
   - Поддерживает базовое форматирование (переносы строк)
   - Не поддерживает HTML/Markdown (рендерится как plain text)
   - Индексируется для поиска в Google Play

2. Пользователь нажимает на стрелку / "About this app" для перехода к полной информации
3. На развёрнутой странице отображается полное описание, а также секция "App info" с метаданными

**Альтернативные сценарии:**
- Сценарий А (Локализованное описание): Описание на языке пользователя
- Сценарий Б (Нет локализации): Описание на языке по умолчанию (основной язык приложения)
- Сценарий В (Gemini-перевод): С 2025 года -- автоматический перевод описания через Gemini (если разработчик включил)

**Бизнес-правила:**

| Rule | Description |
|------|-------------|
| BR-016 | Краткое описание ограничено 80 символами |
| BR-017 | Полное описание ограничено 4000 символами |
| BR-018 | Описание не должно содержать ложную или вводящую в заблуждение информацию |
| BR-019 | Запрещены: спам-ключевые слова, repetitive text, call-to-action ("Download now!") |
| BR-020 | Описание не должно ссылаться на другие приложения или магазины |
| BR-021 | Описание индексируется для поиска -- ключевые слова влияют на ASO |
| BR-022 | Локализация описания доступна для всех языков Google Play |
| BR-023 | Gemini Auto-translate доступен для автоматического перевода (с 2025) |

**Acceptance Criteria:**
- [ ] Краткое описание отображается в компактном виде
- [ ] Полное описание раскрывается по нажатию
- [ ] Описание корректно отображается на языке пользователя
- [ ] Текст не обрезается некорректно
- [ ] Ссылки в описании не кликабельны (plain text)

### FR-GPLAY-APP-005: Рейтинг и оценки (Rating & Reviews Summary)

**Priority**: P0-Critical

**Описание:** Сводная информация о рейтинге приложения: средний балл, распределение по звёздам, количество оценок. Ключевой элемент социального доказательства, влияющий на решение об установке.

**Роли:** Гость, Авторизованный пользователь

**Основной сценарий:**
1. Система отображает сводку рейтинга:

   **Средний рейтинг:**
   - Числовое значение от 1.0 до 5.0 (с точностью до десятых)
   - Крупный шрифт
   - Визуализация звёздами (5 звёзд, заполненные/частично заполненные)

   **Количество оценок:**
   - Общее число оценок (сокращённо: "1.2M reviews")
   - Формат: K (тысячи), M (миллионы), B (миллиарды)

   **Распределение по звёздам:**
   - Горизонтальная гистограмма: 5, 4, 3, 2, 1 звезда
   - Каждая строка показывает процентное соотношение (визуально -- длина полоски)
   - Позволяет быстро оценить паттерн отзывов

   **Количество установок:**
   - Диапазон (например, "10M+", "100K+", "1B+")
   - Показывается в шапке или рядом с рейтингом

2. AI-резюме отзывов (2025):
   - Автоматически сгенерированный текст на основе отзывов
   - Топ позитивных и критических тем
   - Обновляется регулярно
   - Машинное обучение фильтрует нерелевантные отзывы

3. Нажатие на рейтинг или "See all reviews" переводит к полному списку отзывов

**Альтернативные сценарии:**
- Сценарий А (Мало оценок): Рейтинг может не отображаться до набора минимального количества оценок
- Сценарий Б (Новое приложение): Показывается "Not enough ratings"
- Сценарий В (Сброс рейтинга): При major update Google может пересчитать рейтинг

**Бизнес-правила:**

| Rule | Description |
|------|-------------|
| BR-028 | Средний рейтинг рассчитывается на основе всех оценок с учётом весов (недавние оценки имеют больший вес) |
| BR-029 | Google использует алгоритмы для удаления спам-оценок и манипуляций с рейтингом |
| BR-030 | Рейтинг является глобальным (не региональным, в отличие от Apple) |
| BR-031 | Количество установок показывается диапазоном, а не точным числом |

- Short Description: 80 символов
- Full Description: 4000 символов
- Без спама и вводящей в заблуждение информации

**Changelog (BR-024 -- BR-027):**
- Release notes обновляются при каждом релизе
- Локализация

- Data Safety обязательна
- Ответственность на разработчике

- Email поддержки обязателен
- Адрес обязателен для организаций

- Developer Page агрегирует приложения

**Совместимость (BR-062 -- BR-066):**
- Определяется манифестом приложения
- Разработчик может исключать устройства
- Размер оптимизирован через App Bundle

- IARC обязателен
- Локализация рейтингов по регионам
- Parental Controls используют рейтинг

**Установка и покупка (BR-074 -- BR-081):**
- Бесплатные -- без оплаты

# Google Play: Модуль "Рейтинги и отзывы" (Ratings & Reviews)

## Обзор модуля

Система рейтингов и отзывов Google Play является ключевым механизмом обратной связи между пользователями и разработчиками приложений. Она определяет репутацию приложения, влияет на его позицию в поисковой выдаче и рекомендациях, а также напрямую воздействует на конверсию установок. Система построена на 5-звёздочной шкале оценки с возможностью добавления текстового отзыва.

Рейтинг приложения рассчитывается по взвешенному алгоритму, в котором недавние оценки имеют больший вес, чем исторические. С 2024 года публичный рейтинг варьируется в зависимости от устройства пользователя, страны и региона. Это означает, что одно и то же приложение может иметь разный рейтинг для пользователей из разных стран и на разных типах устройств.

48% пользователей не рассматривают приложения с рейтингом ниже 4.0 звёзд. 79% пользователей не нажимают "Установить", если рейтинг не вызывает доверия. Приложения с рейтингом ниже 3.0 отображаются в среднем на 27% ниже в результатах поиска.

### Ключевые принципы

- Один пользователь может оставить только один отзыв на одно приложение
- Пользователь может обновить свой рейтинг и отзыв в любое время
- Отзыв может содержать только рейтинг (звёзды) или рейтинг + текст
- Оставлять отзывы могут только пользователи, установившие приложение через Google Play
- Отзывы, оставленные через internal app sharing, не принимаются
- Разработчик может публично отвечать на отзывы через Play Console
- Google применяет автоматическую и ручную модерацию для защиты от спама и манипуляций
- Рейтинг рассчитывается по взвешенному алгоритму с приоритетом недавних оценок
- Публичный рейтинг зависит от устройства, страны и региона пользователя

### Глоссарий

| Термин | Описание |
|--------|----------|
| Rating (Рейтинг) | Числовая оценка от 1 до 5 звёзд, выставленная пользователем приложению |
| Review (Отзыв) | Текстовое сообщение пользователя с оценкой приложения |
| Average Rating (Средний рейтинг) | Взвешенное среднее всех оценок приложения |
| Public Rating (Публичный рейтинг) | Рейтинг, отображаемый пользователям в каталоге (зависит от устройства/страны) |
| Developer Reply (Ответ разработчика) | Публичный ответ разработчика на отзыв пользователя |
| Helpful Vote (Голос "Полезно") | Отметка пользователя, что отзыв был полезен |
| In-App Review | Механизм запроса оценки из приложения через специальный API |
| Review Flow | Процесс оставления отзыва через диалоговое окно In-App Review |
| Flag (Жалоба) | Отметка отзыва как нарушающего правила для проверки модераторами |
| Comment Posting Policy | Политика Google Play, определяющая допустимое содержание отзывов |
| Weighted Average | Алгоритм расчёта рейтинга, где недавние оценки имеют больший вес |
| Rating Histogram | Гистограмма распределения оценок по звёздам (1-5) |
| Spam Attack | Массовая атака фейковыми отзывами на приложение |
| Review Cluster | Группировка похожих отзывов для анализа в Play Console |
| Star Distribution | Процентное распределение оценок по каждой звезде |

## Функциональные требования

### FR-GP-RR-001: Оставление рейтинга (звёздной оценки)

**Приоритет**: P0

**Описание:** Пользователь, установивший приложение через Google Play, может выставить ему оценку от 1 до 5 звёзд. Рейтинг является обязательной частью отзыва — текст опционален, но звёзды обязательны. Рейтинг сразу учитывается в расчёте среднего рейтинга приложения.

**Роли:** Пользователь (установивший приложение)

**Основной сценарий:**
1. Пользователь переходит на страницу приложения в Google Play Store
2. Пользователь прокручивает до секции "Оценки и отзывы" или нажимает на область рейтинга
3. Система проверяет, что приложение установлено на устройстве пользователя
4. Пользователь нажимает на количество звёзд (от 1 до 5)
5. Система сохраняет рейтинг и связывает его с аккаунтом Google пользователя
6. Рейтинг учитывается во взвешенном среднем приложения
7. Отзыв публикуется с именем и аватаром профиля Google пользователя

**Альтернативные сценарии:**
- Если приложение не установлено — кнопка оценки недоступна или показывается предложение установить
- Если пользователь ранее уже оставлял оценку — система открывает редактирование существующего отзыва
- Если приложение установлено через internal app sharing — оценка не может быть оставлена

**Бизнес-правила:**
- BR-001: Один пользователь может поставить только одну оценку на одно приложение
- BR-002: Минимальная оценка — 1 звезда, максимальная — 5 звёзд
- BR-003: Дробные значения (например, 3.5) недоступны пользователю; только целые числа
- BR-004: Рейтинг может быть выставлен без текстового отзыва (только звёзды)
- BR-005: Оценка видна другим пользователям с привязкой к профилю Google (имя, аватар)
- BR-006: Пользователь не может оставить оценку на собственное приложение (аккаунт разработчика)
- BR-007: Повторная оценка перезаписывает предыдущую, а не создаёт новую запись

**Результат:** Рейтинг сохранён, средний рейтинг приложения пересчитан.

### FR-GP-RR-002: Написание текстового отзыва

**Приоритет**: P0

**Описание:** Пользователь может дополнить свою звёздную оценку текстовым отзывом, описывающим опыт использования приложения. Текстовый отзыв опционален — рейтинг можно оставить и без текста. Текст проходит автоматическую модерацию перед публикацией.

**Роли:** Пользователь (установивший приложение)

**Основной сценарий:**
1. Пользователь выставляет звёздную оценку (FR-GP-RR-001)
2. Система предлагает добавить текстовый отзыв
3. Пользователь вводит текст отзыва
4. Пользователь нажимает "Опубликовать" / "Post"
5. Система проверяет текст на соответствие Comment Posting Policy (автоматическая модерация)
6. При прохождении модерации — отзыв публикуется и становится видимым на странице приложения
7. Разработчик получает уведомление о новом отзыве в Play Console

**Альтернативные сценарии:**
- Если текст содержит запрещённый контент — отзыв блокируется автоматической модерацией и не публикуется
- Если текст содержит подозрительные признаки — отзыв помечается для ручной модерации
- Если пользователь решает не добавлять текст — сохраняется только рейтинг

**Бизнес-правила:**
- BR-008: Максимальная длина текста отзыва — 500 символов
- BR-009: Минимальная длина текста не установлена (может быть пустым, тогда это только рейтинг)
- BR-010: Текст отзыва привязан к конкретной оценке; нельзя оставить текст без звёзд
- BR-011: Отзыв публикуется от имени профиля Google пользователя (имя, фото)
- BR-012: Отзыв содержит метаданные: дата публикации, версия приложения, модель устройства, версия Android
- BR-013: После публикации отзыв проходит автоматическое сканирование на спам и нарушения
- BR-014: Отзыв, прошедший модерацию, становится видимым другим пользователям

**Результат:** Текстовый отзыв опубликован на странице приложения, видим другим пользователям и разработчику.

### FR-GP-RR-003: Редактирование отзыва

**Приоритет**: P1

**Описание:** Пользователь может отредактировать ранее оставленный рейтинг и/или текстовый отзыв в любое время. При редактировании история изменений сохраняется и доступна другим пользователям. Обновлённый отзыв снова проходит модерацию.

**Роли:** Пользователь (автор отзыва)

**Основной сценарий:**
1. Пользователь переходит на страницу приложения в Google Play Store
2. Пользователь находит свой существующий отзыв
3. Пользователь нажимает "Редактировать отзыв" / "Edit your review"
4. Пользователь изменяет количество звёзд и/или текст отзыва
5. Пользователь нажимает "Опубликовать" / "Post"
6. Система обновляет отзыв и пересчитывает средний рейтинг
7. Обновлённая дата отзыва отображается на странице приложения

**Бизнес-правила:**
- BR-015: Редактирование доступно только автору отзыва
- BR-016: При редактировании рейтинга средний рейтинг приложения пересчитывается (старая оценка заменяется новой)
- BR-017: История редактирований отзыва сохраняется и может быть просмотрена другими пользователями
- BR-018: Отредактированный отзыв повторно проходит автоматическую модерацию
- BR-019: Дата отзыва обновляется на дату последнего редактирования
- BR-020: Если разработчик уже ответил на отзыв — ответ разработчика сохраняется при редактировании отзыва
- BR-021: Разработчик получает уведомление об обновлении ранее написанного отзыва

**Результат:** Отзыв обновлён, рейтинг пересчитан, история изменений сохранена.

### FR-GP-RR-004: Удаление отзыва

**Приоритет**: P1

**Описание:** Пользователь может удалить свой собственный отзыв в любое время. При удалении рейтинг пользователя исключается из расчёта среднего рейтинга приложения. Удаление необратимо.

**Роли:** Пользователь (автор отзыва)

**Основной сценарий:**
1. Пользователь находит свой отзыв на странице приложения
2. Пользователь нажимает "Ещё" (три точки) и выбирает "Удалить" / "Delete"
3. Система запрашивает подтверждение удаления
4. Пользователь подтверждает удаление
5. Отзыв и рейтинг удаляются
6. Средний рейтинг приложения пересчитывается без учёта удалённой оценки

**Бизнес-правила:**
- BR-022: Удаление доступно только автору отзыва
- BR-023: Удаление необратимо — восстановить удалённый отзыв невозможно
- BR-024: При удалении отзыва рейтинг пользователя полностью исключается из расчёта среднего
- BR-025: Ответ разработчика на удалённый отзыв также удаляется
- BR-026: После удаления пользователь может написать новый отзыв заново
- BR-027: Google также может удалить отзыв при обнаружении нарушения политики (без запроса пользователя)

**Результат:** Отзыв удалён, рейтинг пересчитан, пользователь может оставить новый отзыв.

### FR-GP-RR-005: Сортировка отзывов

**Приоритет**: P1

**Описание:** Пользователь, просматривающий отзывы на странице приложения, может выбрать порядок сортировки. По умолчанию отзывы отсортированы по релевантности (алгоритм Google). Доступны альтернативные варианты сортировки.

**Роли:** Любой пользователь Google Play

**Основной сценарий:**
1. Пользователь открывает секцию "Оценки и отзывы" на странице приложения
2. Пользователь нажимает на выпадающий список "Сортировать по" / "Sort by"
3. Пользователь выбирает вариант сортировки
4. Система перезагружает список отзывов в соответствии с выбранной сортировкой

**Варианты сортировки:**

| Вариант | Описание |
|---------|----------|
| Самые релевантные (Most relevant) | Алгоритм Google учитывает полезность, новизну, длину текста, язык пользователя. По умолчанию |
| Самые новые (Newest) | Сортировка по дате публикации/редактирования, от новых к старым |
| Рейтинг (Rating) | Сортировка по количеству звёзд (от высшего к низшему или наоборот) |
| Полезность (Most helpful) | Сортировка по количеству голосов "Полезно" от других пользователей |

**Бизнес-правила:**
- BR-028: Сортировка "Самые релевантные" является значением по умолчанию
- BR-029: Алгоритм релевантности учитывает: количество голосов "Полезно", новизну отзыва, длину и детализацию текста, язык пользователя, наличие ответа разработчика
- BR-030: Сортировка применяется к отфильтрованным отзывам (если активен фильтр по звёздам)
- BR-031: Сортировка сохраняется только в текущей сессии просмотра

**Результат:** Отзывы отображаются в выбранном порядке сортировки.

### FR-GP-RR-006: Фильтрация отзывов по звёздам

**Приоритет**: P1

**Описание:** Пользователь может отфильтровать отзывы, отображая только те, которые имеют определённое количество звёзд. Это позволяет быстро ознакомиться, например, с негативными отзывами (1-2 звезды) или только с позитивными (4-5 звёзд).

**Роли:** Любой пользователь Google Play

**Основной сценарий:**
1. Пользователь открывает секцию "Оценки и отзывы" на странице приложения
2. Пользователь видит гистограмму распределения рейтингов (1-5 звёзд) с количеством оценок
3. Пользователь нажимает на конкретную полоску гистограммы (например, "1 звезда")
4. Система отображает только отзывы с выбранным количеством звёзд
5. Пользователь может снять фильтр, нажав повторно или выбрав "Все"

**Бизнес-правила:**
- BR-032: Фильтрация доступна по каждому значению: 1, 2, 3, 4, 5 звёзд
- BR-033: Можно выбрать только одно значение фильтра за раз
- BR-034: При активном фильтре отображается количество отзывов, соответствующих выбранному значению
- BR-035: Фильтрация сочетается с сортировкой (сначала фильтр, затем сортировка)
- BR-036: Фильтр применяется к текстовым отзывам; отзывы только со звёздами (без текста) могут не отображаться

**Результат:** Отображаются только отзывы с выбранным количеством звёзд.

### FR-GP-RR-007: Голосование "Полезно" за отзыв

**Приоритет**: P2

**Описание:** Пользователь может отметить чужой отзыв как "Полезно" (Helpful), если считает его информативным. Количество голосов "Полезно" влияет на позицию отзыва при сортировке по релевантности и полезности. Чем больше голосов — тем заметнее отзыв.

**Роли:** Любой пользователь Google Play (кроме автора отзыва)

**Основной сценарий:**
1. Пользователь просматривает отзыв на странице приложения
2. Пользователь нажимает кнопку "Полезно" / иконку палец вверх под отзывом
3. Система регистрирует голос и увеличивает счётчик полезности
4. Отзыв поднимается в выдаче при сортировке "Самые релевантные"

**Бизнес-правила:**
- BR-037: Один пользователь может проголосовать "Полезно" за один отзыв только один раз
- BR-038: Голос "Полезно" можно отменить повторным нажатием
- BR-039: Автор отзыва не может голосовать за свой собственный отзыв
- BR-040: Количество голосов "Полезно" отображается рядом с кнопкой (если более 0)
- BR-041: Голоса "Полезно" учитываются алгоритмом релевантности при формировании порядка отображения
- BR-042: Отзывы с большим количеством голосов "Полезно" выводятся выше в списке по умолчанию

**Результат:** Голос "Полезно" учтён, отзыв получает повышенную видимость.

### FR-GP-RR-008: Ответ разработчика на отзыв

**Приоритет**: P0

**Описание:** Разработчик приложения может публично ответить на отзыв пользователя через Google Play Console. Ответ отображается непосредственно под текстом отзыва и виден всем пользователям. Ответ разработчика увеличивает рейтинг негативного отзыва в среднем на +0.7 звезды (пользователь часто обновляет оценку после получения ответа). Разработчики, отвечающие на более 40% отзывов, в среднем занимают позиции на 23% выше в поиске.

**Роли:** Разработчик (Owner, Admin в Play Console)

**Основной сценарий:**
1. Разработчик открывает Play Console, переходит в раздел "Reviews"
2. Разработчик находит отзыв, на который хочет ответить
3. Разработчик вводит текст ответа
4. Разработчик нажимает "Ответить" / "Reply"
5. Ответ публикуется под текстом отзыва пользователя
6. Пользователь получает уведомление (email) об ответе разработчика

**Альтернативные сценарии:**
- Разработчик может отредактировать свой ранее отправленный ответ
- Разработчик может удалить свой ответ

**Бизнес-правила:**
- BR-043: Максимальная длина ответа разработчика — 350 символов
- BR-044: Разработчик может оставить только один ответ на один отзыв (но может его отредактировать)
- BR-045: Ответ разработчика должен соответствовать Developer Comment Posting Policy
- BR-046: Запрещено в ответах: просить пользователя повысить оценку, размещать рекламу, использовать оскорбления
- BR-047: Разработчик должен сосредоточить ответ на проблемах, поднятых в отзыве
- BR-048: Рекомендуется включать ссылки на поддержку (email, FAQ) для решения проблемы
- BR-049: Пользователь может пожаловаться на ответ разработчика, если он нарушает политику
- BR-050: При редактировании отзыва пользователем разработчик получает уведомление и может обновить свой ответ
- BR-051: Если разработчик удаляет свой ответ — он исчезает со страницы отзыва

**Результат:** Ответ разработчика опубликован, пользователь уведомлён.

### FR-GP-RR-009: Жалоба на отзыв (Flagging)

**Приоритет**: P1

**Описание:** Пользователь или разработчик может пожаловаться на отзыв, который нарушает правила Google Play (Comment Posting Policy). Жалоба инициирует процесс модерации — автоматической и, при необходимости, ручной проверки специалистом Google.

**Роли:** Любой пользователь, Разработчик

**Основной сценарий (пользователь):**
1. Пользователь находит отзыв, нарушающий правила
2. Пользователь нажимает на иконку флага / "Пожаловаться" рядом с отзывом
3. Система предлагает выбрать причину жалобы
4. Пользователь выбирает причину и подтверждает отправку
5. Жалоба передаётся в систему модерации Google

**Основной сценарий (разработчик через Play Console):**
1. Разработчик открывает Play Console, раздел "Reviews"
2. Разработчик находит отзыв, нарушающий правила
3. Разработчик нажимает иконку флага на отзыве
4. Разработчик выбирает "Пожаловаться" / "Report"
5. Жалоба передаётся в систему модерации Google

**Процесс модерации после жалобы:**
1. Жалоба регистрируется в системе
2. Специалист Google рассматривает жалобу в течение нескольких рабочих дней
3. Если отзыв нарушает Comment Posting Policy — он удаляется
4. Если нарушение не подтверждено — разработчик получает уведомление об отклонении жалобы

**Бизнес-правила:**
- BR-052: Жалоба не приводит к автоматическому удалению — она инициирует проверку
- BR-053: Если жалоба отклонена, повторная жалоба на тот же отзыв невозможна
- BR-054: Если разработчик превысил лимит жалоб — необходимо подождать 24 часа перед новой
- BR-055: Жалоба анонимна — автор отзыва не узнает, кто пожаловался
- BR-056: Срок рассмотрения жалобы — несколько рабочих дней (нет гарантированного SLA)

**Категории нарушений для жалобы:**

| Категория | Описание |
|-----------|----------|
| Спам и фейковый контент | Бессмысленный текст, повторные публикации, фейковые отзывы |
| Оскорбительный контент | Ненависть, дискриминация, угрозы |
| Нецензурная лексика | Использование ненормативной лексики |
| Сексуальный контент | Откровенный или непристойный контент |
| Не по теме | Отзыв не связан с приложением |
| Конфликт интересов | Отзыв от конкурента или заинтересованной стороны |
| Персональные данные | Отзыв содержит персональные данные третьих лиц |
| Реклама | Отзыв содержит рекламу или промо-ссылки |

**Результат:** Жалоба зарегистрирована, отзыв передан на модерацию.

### FR-GP-RR-010: Расчёт среднего рейтинга (Weighted Average)

**Приоритет**: P0

**Описание:** Средний рейтинг приложения рассчитывается по взвешенному алгоритму, а не простому арифметическому среднему. Недавние оценки имеют значительно больший вес, чем исторические. Точная формула расчёта является проприетарной и не раскрывается Google. Публичный рейтинг может различаться в зависимости от устройства, страны и региона пользователя.

**Роли:** Система (автоматический расчёт)

**Логика расчёта:**
1. Система получает новую оценку или обновление существующей
2. Система применяет временной коэффициент — более новые оценки получают больший вес
3. Рассчитывается взвешенное среднее с учётом всех активных оценок
4. Результат округляется до одного знака после запятой для публичного отображения
5. Рейтинг рассчитывается отдельно для каждой комбинации страна/устройство

**Бизнес-правила:**
- BR-057: Алгоритм взвешивания отдаёт приоритет недавним оценкам (точные веса не раскрываются)
- BR-058: Рейтинг не отображается публично до накопления минимального порога оценок (предположительно ~5-10 для начального отображения, ~500 для стабильного)
- BR-059: Публичный рейтинг зависит от страны/региона пользователя
- BR-060: Публичный рейтинг зависит от типа устройства пользователя (телефон, планшет, Chrome OS)
- BR-061: Рейтинг отображается с точностью до одного знака после запятой (например, 4.3)
- BR-062: При массовом удалении фейковых отзывов рейтинг пересчитывается немедленно
- BR-063: Разработчик в Play Console видит как глобальный рейтинг, так и разбивку по странам/устройствам
- BR-064: Взвешенный алгоритм позволяет быстро отразить улучшения в приложении — если после обновления оценки стали лучше, рейтинг растёт быстрее, чем при простом среднем

**Результат:** Средний рейтинг рассчитан и обновлён для всех комбинаций устройство/страна.

3. Общее количество отзывов

**Расширенная аналитика в Play Console:**
1. Гистограмма с абсолютными числами и процентами для каждой звезды

5. Экспорт данных в CSV

**Бизнес-правила:**
- BR-065: Гистограмма отображается всегда, если есть хотя бы одна оценка
- BR-066: Длина полоски пропорциональна количеству оценок данной звезды относительно максимальной
- BR-067: Нажатие на полоску активирует фильтрацию отзывов (FR-GP-RR-006)
- BR-068: В Play Console данные гистограммы доступны с разбивкой по множественным измерениям
- BR-069: Данные гистограммы обновляются в реальном времени при поступлении новых оценок
- BR-070: Разработчик может скачать данные рейтингов в формате CSV для внешнего анализа

**Результат:** Пользователь видит распределение оценок. Разработчик имеет доступ к детальной аналитике.

### FR-GP-RR-013: Верификация отзывов (Review Verification)

**Приоритет**: P0

**Описание:** Google Play применяет систему верификации, гарантирующую, что отзывы оставляют только реальные пользователи, действительно установившие и использовавшие приложение. Система предотвращает фейковые отзывы, манипуляции рейтингом и атаки конкурентов.

**Роли:** Система (автоматическая проверка)

**Механизмы верификации:**
1. Привязка к установке — отзыв можно оставить только если приложение установлено через Google Play на данном аккаунте
2. Привязка к Google-аккаунту — один аккаунт = один отзыв на приложение
3. Автоматическое обнаружение множественных аккаунтов — система выявляет кластеры фейковых аккаунтов
4. Анализ поведения — система отслеживает аномалии: массовые оценки за короткий период, одинаковые тексты, паттерны ботов
5. Блокировка отзывов из internal app sharing

**Бизнес-правила:**
- BR-077: Только пользователи с установленным приложением через Google Play могут оставить отзыв
- BR-078: Один Google-аккаунт может оставить только один отзыв на одно приложение
- BR-079: Отзывы от множественных фейковых аккаунтов обнаруживаются и удаляются автоматически
- BR-080: Разработчикам запрещено стимулировать пользователей оставлять положительные отзывы (incentivized reviews)
- BR-081: Запрещено: "Поставьте 5 звёзд и получите бонус" — нарушение политики Google Play
- BR-082: Разработчик не может покупать или заказывать фейковые отзывы — это приводит к санкциям вплоть до удаления приложения
- BR-083: При обнаружении массовой атаки фейковыми отзывами Google может временно заблокировать возможность оставлять отзывы и удалить подозрительные
- BR-084: Нарушение политики рейтингов может привести к: удалению отзывов, предупреждению, приостановке приложения, удалению аккаунта разработчика

**Результат:** Только верифицированные отзывы от реальных пользователей учитываются в рейтинге.

### FR-GP-RR-014: Модерация отзывов (Автоматическая и ручная)

**Приоритет**: P0

**Описание:** Google Play применяет многоуровневую систему модерации для обеспечения качества и безопасности отзывов. Автоматическая модерация работает в реальном времени с помощью AI, анализирующего сотни сигналов. Ручная модерация подключается при жалобах и сложных случаях.

**Роли:** Система (автоматическая), Google-модератор (ручная)

**Уровни модерации:**

| Уровень | Тип | Описание | Скорость |
|---------|-----|----------|----------|
| 1 | Автоматическая (AI) | Анализ текста на спам, ненависть, нецензурщину, манипуляции | Мгновенно |
| 2 | Автоматическая (поведенческая) | Анализ паттернов: множественные аккаунты, массовые оценки, ботнеты | Мгновенно — часы |
| 3 | Ручная (по жалобе) | Специалист Google рассматривает жалобу | Несколько рабочих дней |
| 4 | Ручная (проактивная) | Google инициирует проверку при подозрительной активности | Дни — недели |

**Автоматическая модерация (уровень 1-2):**
1. При публикации отзыва AI мгновенно анализирует текст
2. Проверяются: ненормативная лексика, угрозы, спам, промо-контент, бессмыслица, персональные данные
3. Анализируются поведенческие паттерны: время создания аккаунта, количество отзывов за период, схожесть текстов
4. При обнаружении нарушения — отзыв блокируется и не публикуется
5. При подозрении — отзыв помечается для дополнительной проверки

**Реагирование на спам-атаки:**
1. Система обнаруживает аномальный всплеск отзывов
2. Временно блокируется возможность оставлять новые отзывы
3. Подозрительные отзывы удаляются массово
4. После нормализации ситуации возможность оставлять отзывы восстанавливается

**Бизнес-правила:**
- BR-085: Автоматическая модерация работает 24/7 в реальном времени
- BR-086: AI анализирует сотни сигналов для каждого отзыва
- BR-087: Отзывы, заблокированные автоматически, не публикуются и не учитываются в рейтинге
- BR-088: При спам-атаке Google может временно приостановить приём отзывов для приложения
- BR-089: Удалённые при спам-атаке отзывы могут включать и легитимные — Google стремится минимизировать такие случаи
- BR-090: Ручная модерация подключается по жалобам (FR-GP-RR-009) или при проактивном обнаружении аномалий
- BR-091: Решения ручной модерации окончательны (нет механизма апелляции для удалённых отзывов)

**Запрещённый контент (Comment Posting Policy):**

| Категория | Примеры |
|-----------|---------|
| Спам | Бессмысленный текст, копипаст, массовые однотипные отзывы |
| Фейковые отзывы | Оплаченные, обменные, мотивированные отзывы |
| Ненависть и дискриминация | Нападки по признаку расы, пола, религии, ориентации |
| Нецензурная лексика | Ненормативная лексика даже в контексте критики |
| Сексуальный контент | Откровенные описания, непристойности |
| Персональные данные | Имена, адреса, телефоны третьих лиц |
| Реклама | Ссылки на другие приложения, услуги, товары |
| Нерелевантный контент | Политические высказывания, не связанные с приложением |
| Призывы к насилию | Угрозы, призывы к причинению вреда |
| Нелегальный контент | Продвижение нелегальных товаров или услуг |

**Результат:** Отзывы, нарушающие политику, блокируются или удаляются. Качество и безопасность контента обеспечены.

### FR-GP-RR-015: In-App Review API (Запрос оценки из приложения)

**Приоритет**: P0

**Описание:** Google Play In-App Review API позволяет разработчикам запросить у пользователя оценку и отзыв непосредственно из приложения, без необходимости переходить в Google Play Store. Система отображает нативный диалог оценки от Google Play поверх интерфейса приложения. Пользователь может поставить звёзды и написать отзыв, не покидая приложение.

**Роли:** Разработчик (интеграция), Пользователь (оценка), Система (управление квотой)

**Основной сценарий:**
1. Разработчик интегрирует In-App Review API в приложение
2. В определённый момент (после достаточного использования) приложение вызывает API
3. Система Google Play проверяет квоту показов для данного пользователя
4. Если квота не исчерпана — отображается нативный диалог оценки Google Play
5. Пользователь выставляет звёзды (1-5) и опционально пишет текст
6. Пользователь нажимает "Отправить" / "Submit"
7. Оценка отправляется в Google Play Store
8. Диалог закрывается, пользователь продолжает работу в приложении

**Альтернативные сценарии:**
- Если квота исчерпана — диалог не отображается (пользователь ничего не видит)
- Если пользователь закрывает диалог без оценки — вызов считается потраченным в рамках квоты
- Если на устройстве нет Google Play Store — API не работает

**Бизнес-правила:**
- BR-092: Квота показов: не более 3 показов диалога на одно приложение для одного пользователя за 365 дней
- BR-093: Google Play контролирует квоту; разработчик не может обойти ограничение
- BR-094: При вызове API нет гарантии, что диалог будет показан (квота может быть исчерпана)
- BR-095: Требования к устройству: Android 5.0+ (API level 21), установлен Google Play Store
- BR-096: Разработчик НЕ ДОЛЖЕН задавать предварительные вопросы пользователю перед показом диалога (например, "Нравится ли вам приложение?")
- BR-097: Разработчик НЕ ДОЛЖЕН создавать кнопку "Оценить приложение", привязанную к API — кнопка может не сработать из-за квоты, создавая сломанный UX. Для кнопки следует использовать редирект в Google Play Store
- BR-098: Нельзя стимулировать пользователя перед показом диалога: "Оцените нас на 5 звёзд" — нарушение политики
- BR-099: Диалог In-App Review управляется полностью Google Play — разработчик не может кастомизировать его внешний вид
- BR-100: Разработчик не получает обратную связь о том, какую оценку поставил пользователь (или поставил ли вообще)
- BR-101: При тестировании через internal test track квота не применяется (для отладки)
- BR-102: Рекомендуется вызывать API после того, как пользователь достаточно использовал приложение (не сразу после установки)

**Ограничения разработчика:**

| Что запрещено | Почему |
|---------------|--------|
| Предварительные вопросы ("Нравится?") | Манипуляция — показ диалога только "довольным" пользователям |
| Кнопка "Оценить", привязанная к API | Квота может быть исчерпана — кнопка не сработает |
| Обещание награды за оценку | Incentivized reviews запрещены политикой |
| Частые показы диалога | Google контролирует квоту, но частые вызовы API создают плохой UX |
| Определение оценки пользователя | API не возвращает оценку разработчику |

**Результат:** Пользователь оценивает приложение не покидая его. Оценка поступает в Google Play Store.

### FR-GP-RR-016: Влияние рейтинга на ранжирование в каталоге

**Приоритет**: P0

**Описание:** Рейтинг приложения является одним из ключевых факторов, определяющих его позицию в поисковой выдаче Google Play, разделах "Рекомендуемые" и "Топ-чарты". Google Play использует рейтинг как компонент более широкого алгоритма ранжирования, включающего вовлечённость пользователей, техническое качество и социальные сигналы.

**Роли:** Система (автоматический алгоритм ранжирования)

**Факторы ранжирования и вес рейтинга:**

| Категория фактора | Примерный вес | Описание |
|-------------------|---------------|----------|
| Релевантность ключевых слов | ~30% | Совпадение запроса с названием, описанием, метаданными |
| Метрики вовлечённости | ~35% | Количество установок, удержание, время использования, частота возвратов |
| Техническое качество | ~15% | Стабильность, скорость, размер APK, совместимость |
| Социальные сигналы (включая рейтинг) | ~20% | Рейтинг, количество отзывов, частота ответов разработчика |

**Бизнес-правила:**
- BR-103: Приложения с рейтингом ниже 3.0 получают значительный штраф в ранжировании (в среднем -27% позиций)
- BR-104: 85% приложений в разделе "Рекомендуемые" имеют рейтинг 4.0 и выше
- BR-105: Оптимальный диапазон рейтинга для максимального ранжирования: 4.2–4.6
- BR-106: Количество отзывов также влияет: приложение с 4.5 и 10,000 отзывов ранжируется выше, чем с 4.5 и 100 отзывов
- BR-107: Частота ответов разработчика на отзывы влияет на ранжирование: приложения с ответами на 40%+ отзывов в среднем на 23% выше
- BR-108: Повышение рейтинга с 3.5 до 4.5 увеличивает конверсию установок до 89%
- BR-109: Рейтинг является одним из критериев для включения в подборки Google Play Editorial
- BR-110: Алгоритм учитывает динамику рейтинга — стабильно растущий рейтинг предпочтительнее стабильного высокого

**Результат:** Рейтинг учитывается алгоритмом ранжирования, влияя на позицию приложения в поиске и рекомендациях.

### FR-GP-RR-017: Просмотр и управление отзывами в Play Console (Developer Tools)

**Приоритет**: P1

**Описание:** Google Play Console предоставляет разработчику расширенный инструментарий для работы с отзывами: просмотр, фильтрация, ответы, аналитика, кластеризация. Разработчик может эффективно управлять обратной связью, выявлять проблемы и отслеживать тренды.

**Роли:** Разработчик (Owner, Admin в Play Console)

**Возможности в Play Console:**

| Функция | Описание |
|---------|----------|
| Список отзывов | Все отзывы с возможностью прокрутки, поиска и фильтрации |
| Фильтры | По рейтингу (звёзды), версии приложения, устройству, типу устройства, языку, стране, наличию ответа |
| Ответ на отзыв | Публичный ответ до 350 символов |
| Кластеризация (Review clusters) | Автоматическая группировка похожих отзывов по темам |
| Жалоба (Flag) | Пометить отзыв как нарушающий политику |
| Уведомления | Email и push-уведомления о новых отзывах |
| Экспорт | Скачать отзывы в CSV |
| Поиск | Полнотекстовый поиск по тексту отзывов |

**Основной сценарий:**
1. Разработчик открывает Play Console
2. Переходит в раздел "Monitor and improve" > "Ratings and reviews" > "Reviews"
3. Разработчик видит список всех отзывов с метаданными
4. Разработчик применяет фильтры для выборки (например, только 1-2 звезды, только последняя версия)
5. Разработчик читает отзывы и отвечает на них
6. Разработчик использует кластеры для выявления массовых проблем
7. Разработчик экспортирует данные для внешнего анализа

**Кластеризация отзывов (Review Clusters):**
- Система автоматически группирует отзывы с похожим содержанием
- Каждый кластер имеет заголовок-тему (например, "Проблемы с загрузкой", "Просьба о новой функции")
- Разработчик видит количество отзывов в каждом кластере
- Помогает выявить системные проблемы и приоритизировать исправления

**Бизнес-правила:**
- BR-111: Доступ к управлению отзывами имеют только пользователи с соответствующими правами в Play Console
- BR-112: Кластеризация работает автоматически и не требует настройки от разработчика
- BR-113: Разработчик может настроить уведомления о новых отзывах (по email, по рейтингу — например, только 1-2 звезды)
- BR-114: Фильтр "Без ответа" позволяет быстро найти отзывы, на которые ещё не ответили
- BR-115: В отзыве отображаются метаданные: модель устройства, версия приложения, версия Android, дата, страна

**Результат:** Разработчик имеет полный инструментарий для управления обратной связью.

### FR-GP-RR-018: Жалоба на ответ разработчика

**Приоритет**: P2

**Описание:** Пользователь может пожаловаться на ответ разработчика, если он нарушает Developer Comment Posting Policy. Это защитный механизм от злоупотреблений со стороны разработчиков — оскорблений, манипуляций, нерелевантного контента в ответах.

**Роли:** Пользователь (получивший ответ)

**Основной сценарий:**
1. Пользователь получает email-уведомление об ответе разработчика на свой отзыв
2. Пользователь читает ответ и считает, что он нарушает политику
3. Пользователь нажимает "Пожаловаться на ответ разработчика" / "Report developer reply" в полученном email
4. Пользователь заполняет форму: прямая ссылка на ответ, имя разработчика, описание нарушения
5. Жалоба передаётся специалистам Google

**Бизнес-правила:**
- BR-116: Жалоба на ответ разработчика подаётся через email-уведомление или специальную форму
- BR-117: Жалоба проверяется специалистом Google
- BR-118: Если ответ нарушает политику — он удаляется
- BR-119: Разработчик уведомляется об удалении своего ответа
- BR-120: Запрещено в ответах разработчика: оскорбления, просьба изменить оценку, реклама, раскрытие персональных данных пользователя

**Результат:** Жалоба зарегистрирована, ответ разработчика передан на проверку.

### FR-GP-RR-019: Рейтинг по версии приложения (Version-Specific Rating)

**Приоритет**: P1

**Описание:** Google Play отслеживает рейтинг в разрезе версий приложения. Это позволяет разработчику понять, как каждое обновление влияет на удовлетворённость пользователей. Если новая версия получает значительно более низкие оценки — это сигнал о регрессии качества.

**Роли:** Разработчик (аналитика в Play Console)

**Основной сценарий:**
1. Разработчик открывает Play Console, раздел "Ratings"
2. Разработчик выбирает измерение "App version"
3. Система отображает средний рейтинг для каждой версии приложения
4. Разработчик сравнивает рейтинги версий, выявляя проблемные обновления
5. Разработчик переходит к отзывам конкретной версии для детального анализа

**Бизнес-правила:**
- BR-121: Каждый отзыв привязан к версии приложения, которая была установлена в момент написания
- BR-122: Если пользователь обновляет отзыв после обновления приложения — отзыв привязывается к новой версии
- BR-123: Рейтинг версии рассчитывается по тем же принципам взвешенного среднего
- BR-124: Низкий рейтинг новой версии относительно предыдущей сигнализирует о регрессии
- BR-125: Разработчик может фильтровать отзывы по конкретной версии в Play Console
- BR-126: Поскольку публичный рейтинг взвешен по времени, быстрый выпуск фикса и получение новых хороших оценок позволяет "перевесить" негатив проблемной версии

**Результат:** Разработчик видит влияние каждого обновления на рейтинг и может быстро реагировать на регрессии.

### FR-GP-RR-020: Уведомления о новых отзывах

**Приоритет**: P2

**Описание:** Разработчик может настроить уведомления о новых отзывах пользователей, чтобы оперативно реагировать на обратную связь. Уведомления помогают не пропустить негативные отзывы, требующие срочного ответа.

**Роли:** Разработчик (Owner, Admin в Play Console)

**Каналы уведомлений:**

| Канал | Описание |
|-------|----------|
| Email | Письмо на email разработчика при новом отзыве |
| Play Console | Уведомление внутри Play Console |
| Google Play Developer API | Автоматическое получение новых отзывов через API |

**Настройки фильтрации уведомлений:**
- По рейтингу: например, только 1-2 звезды (негативные)
- По наличию текста: только отзывы с текстом
- По версии приложения: только отзывы на последнюю версию
- По языку: только на определённом языке

**Бизнес-правила:**
- BR-127: Уведомления по email можно настроить для конкретных членов команды разработки
- BR-128: Фильтрация уведомлений позволяет не получать оповещения обо всех 5-звёздочных отзывах без текста
- BR-129: Через Developer API можно настроить автоматическую обработку отзывов (подключение CRM, helpdesk систем)
- BR-130: Оперативная реакция на отзывы (ответ в течение 24 часов) повышает вероятность того, что пользователь обновит оценку

**Результат:** Разработчик своевременно узнаёт о новых отзывах и может оперативно реагировать.

## Состояния отзыва (Review Lifecycle)

```
[Создание] → [Автоматическая модерация] → [Опубликован] → [Редактирован*] / [Удалён]
                      ↓                         ↓
               [Заблокирован]              [Пожалоба подана]
                                                ↓
                                    [Ручная модерация]
                                         ↓           ↓
                                  [Удалён Google]  [Жалоба отклонена]
```

### Таблица состояний

| Состояние | Описание | Переходы |
|-----------|----------|----------|
| Создан (Draft) | Пользователь нажал "Опубликовать" | → Автоматическая модерация |
| На модерации | Проверка автоматической системой | → Опубликован / → Заблокирован |
| Опубликован (Published) | Виден на странице приложения | → Отредактирован / → Удалён пользователем / → Жалоба подана |
| Отредактирован (Edited) | Пользователь изменил текст/рейтинг | → Автоматическая модерация (повторная) |
| С ответом разработчика (Replied) | Разработчик ответил на отзыв | Подсостояние "Опубликован" |
| Жалоба подана (Flagged) | На отзыв подана жалоба | → Ручная модерация |
| На ручной модерации (Under Review) | Специалист Google рассматривает | → Удалён Google / → Жалоба отклонена (возврат в "Опубликован") |
| Заблокирован (Blocked) | Автоматически заблокирован модерацией | Конечное состояние (не публикуется) |
| Удалён пользователем (Deleted by User) | Пользователь удалил свой отзыв | Конечное состояние |
| Удалён Google (Removed by Google) | Google удалил за нарушение политики | Конечное состояние |
| Удалён при спам-атаке (Spam Cleanup) | Массовое удаление при спам-атаке | Конечное состояние |

## Состояния рейтинга приложения (Rating States)

| Состояние | Описание | Условие |
|-----------|----------|---------|
| Не отображается | Рейтинг ещё не рассчитан / недостаточно данных | Менее минимального порога оценок |
| Отображается (стабильный) | Рейтинг отображается публично | Достаточно оценок для стабильного расчёта |
| Волатильный | Рейтинг быстро меняется из-за потока новых оценок | Много новых оценок за короткий период |
| Заблокирован (спам-атака) | Приём новых оценок временно приостановлен | Обнаружена спам-атака |

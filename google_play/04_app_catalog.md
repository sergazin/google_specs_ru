# Каталог приложений и игр Google Play

## Обзор модуля

Данный модуль описывает функциональные требования к системе каталога и витрины Google Play Store, включая основные разделы (Приложения и Игры), категории и жанры, топ-чарты, редакционный контент, персонализацию, предварительную регистрацию, Early Access, Google Play Pass, рекламные размещения, возрастные рейтинги (IARC), промо-контент (LiveOps), систему бейджей и отметок, а также программу лояльности Google Play Points.

---

## Роли и права доступа

| Роль | Описание | Права в контексте каталога |
|------|----------|---------------------------|
| Анонимный пользователь | Пользователь без Google-аккаунта | Просмотр каталога, чартов, категорий; НЕ может устанавливать, оценивать, предрегистрироваться |
| Авторизованный пользователь | Пользователь с Google-аккаунтом | Полный доступ: установка, покупка, оценка, предрегистрация, вишлист, персонализация |
| Подписчик Play Pass | Пользователь с подпиской Google Play Pass | Доступ к каталогу Play Pass без рекламы и IAP; семейный доступ до 5 участников |
| Участник Play Points | Пользователь, активировавший Play Points | Накопление баллов, обмен на вознаграждения, повышенные множители в зависимости от уровня |
| Разработчик | Владелец аккаунта Google Play Console | Публикация, управление листингом, категориями, тегами, промо-контентом, предрегистрацией |
| Редактор Google Play | Сотрудник команды Google Play Editorial | Курирование Editors' Choice, создание коллекций, присвоение бейджей, ежегодные награды |
| Рекламодатель | Разработчик/маркетолог через Google Ads | Размещение рекламных объявлений на поиске, главной, страницах приложений |
| Администратор Google Play | Сотрудник Google | Управление каталогом, модерация, настройка чартов, политик, IARC-рейтингов |
| Участник Family Group | Член семейной группы Google | Доступ к общим покупкам, Play Pass через Family Sharing |
| Детский профиль | Аккаунт под управлением Family Link | Ограниченный каталог по возрастному рейтингу, отсутствие персонализации, родительский контроль |

## 1. Основные разделы каталога

### FR-GP-CAT-001: Разделение на Приложения и Игры
**Priority**: P0-Critical

**Description**: Каталог Google Play должен быть разделён на два основных раздела: "Приложения" (Apps) и "Игры" (Games). Каждый раздел представляет собой самостоятельную витрину с собственной навигацией, чартами, категориями и редакционным контентом.

**Acceptance Criteria**:
- [ ] Пользователь видит две основных вкладки: "Приложения" и "Игры"
- [ ] Каждая вкладка имеет собственную структуру подразделов
- [ ] Переключение между вкладками сохраняет состояние прокрутки
- [ ] Разделение применяется ко всем устройствам: смартфоны, планшеты, Chromebook, Android TV, Wear OS, Android Auto

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-001 | Каждое приложение может принадлежать только к одному разделу: "Приложения" ИЛИ "Игры" |
| BR-002 | Разработчик определяет принадлежность к разделу при публикации через выбор категории |
| BR-003 | Google может переклассифицировать приложение при нарушении правил категоризации |
| BR-004 | Раздел "Игры" отображается приоритетно на устройствах с активным игровым профилем |

### FR-GP-CAT-002: Структура вкладки "Для вас" (For You)
**Priority**: P0-Critical

**Description**: Каждый раздел (Приложения и Игры) содержит вкладку "Для вас", отображающую персонализированный контент на основе истории пользователя, его устройства и контекста.

**Acceptance Criteria**:
- [ ] Персонализированные рекомендации приложений на основе установленных приложений
- [ ] Рекомендации на основе истории поиска и просмотров
- [ ] Рекомендации с учётом региона, языка, типа устройства
- [ ] Секция "Рекомендуемые для вас" с пояснением причины рекомендации
- [ ] Секция "Похожие на установленные" с указанием аналога
- [ ] Баннеры с промо-контентом (LiveOps) для установленных приложений
- [ ] Персонализированные подборки по интересам пользователя

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-005 | Персонализация работает только для авторизованных пользователей с включённой настройкой |
| BR-006 | Детские профили (Family Link) НЕ получают персонализированные рекомендации |
| BR-007 | Пользователь может отключить персонализацию в настройках Google Play |
| BR-008 | Система учитывает контекст: время суток, локацию, тип устройства |
| BR-009 | Приложения, которые пользователь уже установил, НЕ отображаются в рекомендациях к установке |
| BR-010 | Приложения, которые пользователь удалил, могут быть показаны повторно не ранее чем через 30 дней |

### FR-GP-CAT-003: Структура вкладки "Топ-чарты" (Top Charts)
**Priority**: P0-Critical

**Description**: Вкладка "Топ-чарты" предоставляет рейтинги приложений по различным критериям с возможностью фильтрации по категориям.

**Acceptance Criteria**:
- [ ] Отображаются четыре типа чартов: "Лучшие бесплатные", "Лучшие платные", "Самые популярные", "Хит продаж"
- [ ] Чарты доступны для каждой категории/жанра отдельно
- [ ] Чарты обновляются с регулярной периодичностью (несколько раз в день)
- [ ] Позиция приложения отображается с порядковым номером
- [ ] Отображение до 200 позиций в каждом чарте

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-011 | Чарты рассчитываются отдельно для каждой страны/региона |
| BR-012 | "Лучшие бесплатные" ранжируются по количеству установок за скользящий период |
| BR-013 | "Лучшие платные" ранжируются по количеству платных покупок приложения |
| BR-014 | "Самые популярные" (Top Trending) ранжируются по скорости роста установок |
| BR-015 | "Хит продаж" (Top Grossing) ранжируются по совокупному доходу (покупки + IAP + подписки) |
| BR-016 | Доход от рекламы внутри приложений НЕ учитывается в "Хит продаж" |
| BR-017 | Приложения, заблокированные или приостановленные, автоматически исключаются из чартов |
| BR-018 | Манипуляции с чартами (накрутка установок, фейковые покупки) приводят к исключению и санкциям |

### FR-GP-CAT-004: Структура вкладки "Категории" (Categories)
**Priority**: P0-Critical

**Description**: Вкладка "Категории" предоставляет полный список категорий приложений или жанров игр для навигации по каталогу.

**Acceptance Criteria**:
- [ ] Отображается полный список категорий (для приложений) или жанров (для игр)
- [ ] Каждая категория ведёт на отдельную страницу с топ-чартами и подборками
- [ ] Визуальное представление категорий с иконками
- [ ] Возможность просмотра всех категорий единым списком

### FR-GP-CAT-005: Структура вкладки "Выбор редакции" (Editors' Choice)
**Priority**: P1-High

**Description**: Вкладка "Выбор редакции" содержит курированные редакцией Google Play подборки лучших приложений и игр.

**Acceptance Criteria**:
- [ ] Отображение приложений и игр с бейджем "Editors' Choice"
- [ ] Тематические коллекции с редакционным описанием
- [ ] Ежемесячное обновление коллекций
- [ ] Редакционные обзоры с пояснением выбора

- [ ] Теги не отображаются пользователям напрямую, но влияют на алгоритмы

**Business Rules**:
| Rule | Description |
|------|-------------|

| BR-027 | Теги должны точно отражать функциональность приложения |
| BR-028 | Некорректные теги могут быть изменены Google при модерации |

### FR-GP-CAT-021: Отчёты по жанрам игр (Game Genre Reports)
**Priority**: P2-Medium

- [ ] Доступ через Google Play Console (только для разработчиков)

## 4. Топ-чарты

### FR-GP-CAT-030: Чарт "Лучшие бесплатные" (Top Free)
**Priority**: P0-Critical

**Description**: Рейтинг наиболее скачиваемых бесплатных приложений за скользящий период.

**Acceptance Criteria**:
- [ ] Отображение до 200 приложений с порядковыми номерами
- [ ] Доступен для раздела "Приложения" и "Игры" отдельно
- [ ] Фильтрация по категориям/жанрам
- [ ] Отображение иконки, названия, разработчика, рейтинга, отметок ("Содержит рекламу", "Покупки в приложении")

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-040 | Ранжирование на основе количества новых установок за скользящий период (24-72 часа) |
| BR-041 | Скорость прироста установок (velocity) имеет больший вес, чем абсолютное число |
| BR-042 | Обновление чарта происходит несколько раз в сутки |
| BR-043 | Чарт рассчитывается индивидуально для каждой страны |
| BR-044 | Предустановленные приложения и системные приложения НЕ попадают в чарт |

### FR-GP-CAT-031: Чарт "Лучшие платные" (Top Paid)
**Priority**: P0-Critical

**Description**: Рейтинг наиболее покупаемых платных приложений.

**Acceptance Criteria**:
- [ ] Отображение до 200 приложений с порядковыми номерами
- [ ] Указание цены приложения
- [ ] Доступен для раздела "Приложения" и "Игры" отдельно
- [ ] Фильтрация по категориям/жанрам

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-045 | Ранжирование по количеству платных покупок за скользящий период |
| BR-046 | Цена приложения НЕ влияет на позицию в чарте (только объём продаж) |
| BR-047 | Приложения с бесплатным пробным периодом попадают в чарт только после покупки |
| BR-048 | Возвраты (рефанды) уменьшают позицию в чарте |

### FR-GP-CAT-032: Чарт "Хит продаж" (Top Grossing)
**Priority**: P0-Critical

**Description**: Рейтинг приложений с наибольшим совокупным доходом.

**Acceptance Criteria**:
- [ ] Учитывается доход от прямых покупок приложения
- [ ] Учитывается доход от покупок внутри приложения (IAP)
- [ ] Учитывается доход от подписок
- [ ] Доступен для раздела "Приложения" и "Игры" отдельно
- [ ] Фильтрация по категориям/жанрам

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-050 | Доход от рекламы (Ad Revenue) НЕ учитывается |
| BR-051 | Ранжирование на основе совокупного дохода через Google Play Billing |
| BR-052 | Рефанды уменьшают позицию |
| BR-053 | Промо-код активации НЕ считаются доходом |

### FR-GP-CAT-033: Чарт "Самые популярные" (Top Trending)
**Priority**: P1-High

**Description**: Рейтинг приложений с наибольшей скоростью роста установок, позволяющий обнаружить набирающие популярность приложения.

**Acceptance Criteria**:
- [ ] Учитывается скорость прироста установок (velocity) по сравнению с предыдущим периодом
- [ ] Приоритет отдаётся относительному росту, а не абсолютным числам
- [ ] Доступен для раздела "Приложения" и "Игры" отдельно
- [ ] Новые приложения чаще попадают в этот чарт

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-055 | Ранжирование по процентному росту установок за последние 24-48 часов |
| BR-056 | Приложения с подозрительным всплеском (бот-установки) автоматически исключаются |
| BR-057 | Приложения, уже находящиеся в топе "Лучшие бесплатные", получают пониженный приоритет |

### FR-GP-CAT-034: Региональные чарты
**Priority**: P0-Critical

### FR-GP-CAT-150: Программа лояльности Google Play Points
**Priority**: P1-High

**Description**: Google Play Points -- программа лояльности, вознаграждающая пользователей за покупки и активность в Google Play.

**Acceptance Criteria**:
- [ ] Пользователь накапливает баллы за каждую покупку в Google Play
- [ ] Баллы начисляются за покупку приложений, IAP, подписки, книги, фильмы
- [ ] Баллы можно обменять на Google Play Credit или внутриигровые предметы
- [ ] Программа бесплатна для участия

**Система уровней**:
| Уровень | Порог (баллов/год) | Множитель | Привилегии |
|---------|-------------------|-----------|------------|
| Bronze | 0 | 1.0x | Базовый обмен баллов |
| Silver | 200 | 1.1x | Еженедельные розыгрыши баллов |
| Gold | 600 | 1.2x | Еженедельные розыгрыши, скидки |
| Platinum | 2000 | 1.4x | Розыгрыши, скидки, ранний доступ к предложениям, премиум-поддержка |
| Diamond | 10000 | 1.6x | Все привилегии Platinum + эксклюзивные награды |

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-230 | 1 балл начисляется за каждый $1 USD покупок |
| BR-231 | Уровень определяется по количеству баллов, заработанных за календарный год |
| BR-232 | Уровень сохраняется до конца следующего календарного года |
| BR-233 | Бонусные баллы можно заработать за установку рекомендованных бесплатных приложений |
| BR-234 | Еженедельные множители (2x, 3x) могут применяться к отдельным приложениям |
| BR-235 | Баллы нельзя передать другому пользователю |
| BR-236 | Баллы имеют срок действия (обычно 1 год с момента начисления) |
| BR-237 | Программа доступна не во всех регионах |

## 20. Семейный контент и детская безопасность

### FR-GP-CAT-190: Программа "Одобрено преподавателями" (Teacher Approved)
**Priority**: P1-High

**Description**: Специальная программа, в рамках которой независимые эксперты-педагоги оценивают приложения для детей.

**Acceptance Criteria**:
- [ ] Приложения с бейджем "Одобрено преподавателями" выделены в каталоге
- [ ] Фильтр по возрастным группам детей (до 5, 6-8, 9-12)
- [ ] Описание от педагогов о ценности приложения
- [ ] Звёздный рейтинг от преподавателей

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-270 | Оценка проводится независимыми педагогами и специалистами по детскому развитию |
| BR-271 | Приложения оцениваются по критериям: качество, вовлечённость, развивающий потенциал |
| BR-272 | Бейдж "Teacher Approved" присваивается только приложениям для детей |
| BR-273 | Бейдж может быть отозван при нарушении стандартов или жалобах |

### FR-GP-CAT-191: Семейный раздел каталога
**Priority**: P1-High

**Description**: Отдельный раздел каталога, содержащий приложения и игры, подходящие для детей и семей.

**Acceptance Criteria**:
- [ ] Раздел "Семейное" / "Family" с приложениями, подходящими для детей
- [ ] Фильтрация по возрастным группам
- [ ] Только приложения, прошедшие проверку на соответствие семейным политикам
- [ ] Отсутствие рекламы неподходящего содержания

**Business Rules**:
| Rule | Description |
|------|-------------|
| BR-274 | Приложения в семейном разделе обязаны соответствовать "Families Policy" Google Play |
| BR-275 | Реклама в детских приложениях должна соответствовать дополнительным требованиям |
| BR-276 | Приложения для детей до 13 лет обязаны соответствовать COPPA и аналогичным законам |
| BR-277 | Сбор персональных данных в детских приложениях строго ограничен |

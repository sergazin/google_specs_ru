# Настройки

## Описание

Модуль "Настройки" предоставляет пользователям Google Keep возможность персонализировать работу приложения под свои предпочтения. Модуль охватывает настройки отображения заметок, управление темой оформления, конфигурацию напоминаний по умолчанию, параметры синхронизации и поведения списков. Настройки применяются к аккаунту пользователя и синхронизируются между всеми устройствами, на которых используется Google Keep.

Модуль доступен на всех платформах: веб-версия (keep.google.com), мобильные приложения Android и iOS, а также расширение для Chrome. Некоторые настройки могут отличаться в зависимости от платформы и версии приложения.

## Роли пользователей

| Роль | Описание | Доступ к настройкам |
|------|----------|---------------------|
| **Обычный пользователь** | Владелец личного аккаунта Google | Полный доступ ко всем персональным настройкам |
| **Пользователь Google Workspace** | Пользователь корпоративного аккаунта | Доступ к настройкам ограничен политиками администратора организации |
| **Администратор Google Workspace** | Администратор организации | Управление политиками общего доступа и ограничениями для пользователей организации |

## Функциональные требования

### FR-SETTINGS-001: Переключение режима отображения заметок (сетка/список)

**Описание:** Пользователь может переключаться между двумя режимами отображения заметок на главном экране: режим сетки (Grid View) и режим списка (List View). Режим сетки отображает заметки в виде карточек, расположенных в несколько колонок. Режим списка отображает заметки в одну колонку, что позволяет видеть больше содержимого каждой заметки.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Пользователь находится на главном экране с заметками

**Основной сценарий:**
1. Пользователь нажимает на иконку переключения вида (расположена справа от строки поиска)
2. Система мгновенно переключает режим отображения
3. Иконка изменяется для отражения текущего режима:
   - Четыре квадрата — активен режим сетки
   - Две горизонтальные линии — активен режим списка
4. Все заметки перестраиваются в соответствии с выбранным режимом
5. Выбранный режим сохраняется для текущего устройства

**Альтернативные сценарии:**
- А1: При медленном интернет-соединении перестроение заметок может занять несколько секунд
- А2: На мобильных устройствах с узким экраном режим сетки может отображать только две колонки

**Бизнес-правила:**
- BR-001: Режим отображения по умолчанию — сетка (Grid View)
- BR-002: Настройка режима отображения сохраняется отдельно для каждого устройства
- BR-003: Режим отображения не синхронизируется между устройствами

**Результат:** Заметки отображаются в выбранном пользователем режиме (сетка или список)

### FR-SETTINGS-002: Настройка темы оформления

**Описание:** Пользователь может выбрать тему оформления интерфейса Google Keep: светлая тема, темная тема или автоматическое переключение в зависимости от системных настроек устройства или режима энергосбережения.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Пользователь имеет доступ к меню настроек

**Основной сценарий:**
1. Пользователь открывает меню настроек:
   - **Веб:** нажимает на иконку шестеренки в правом верхнем углу
   - **Android/iOS:** нажимает на меню-гамбургер → "Настройки"
2. Пользователь находит раздел "Тема" (Theme)
3. Система отображает доступные варианты:
   - Светлая (Light)
   - Темная (Dark)
   - По умолчанию системы / По режиму энергосбережения (System default / Set by Battery saver)
4. Пользователь выбирает желаемую тему
5. Система немедленно применяет выбранную тему к интерфейсу
6. Настройка сохраняется

**Альтернативные сценарии:**
- А1: На устройствах с Android 10+ при выборе "По умолчанию системы" тема автоматически переключается вместе с системной темой
- А2: При выборе "По режиму энергосбережения" темная тема активируется при включении режима энергосбережения на устройстве
- А3: На веб-версии доступен только переключатель "Включить темный режим" без опции автоматического переключения

**Бизнес-правила:**
- BR-001: Светлая тема использует пастельные цвета для заметок
- BR-002: Темная тема использует приглушенные, более глубокие цвета для заметок
- BR-003: Темная тема использует два оттенка серого для фона интерфейса (не чистый черный) для снижения нагрузки на глаза
- BR-004: Настройка темы применяется на уровне устройства
- BR-005: Цвета заметок автоматически адаптируются к выбранной теме

**Результат:** Интерфейс Google Keep отображается в выбранной теме оформления

### FR-SETTINGS-003: Настройка времени напоминаний по умолчанию

**Описание:** Пользователь может настроить время по умолчанию для быстрых опций напоминаний: "Утро", "День", "Вечер" и "Ночь". Эти значения используются при создании напоминаний с помощью быстрого выбора времени.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Пользователь имеет доступ к меню настроек

**Основной сценарий:**
1. Пользователь открывает меню настроек
2. Пользователь находит раздел "Напоминания по умолчанию" (Reminder Defaults)
3. Система отображает текущие настройки времени:
   - Утро (Morning): [текущее значение]
   - День (Afternoon): [текущее значение]
   - Вечер (Evening): [текущее значение]
   - Ночь (Night): [текущее значение]
4. Пользователь нажимает на время, которое хочет изменить
5. Система отображает диалог выбора времени
6. Пользователь устанавливает желаемое время
7. Пользователь подтверждает выбор
8. Система сохраняет новое значение

**Альтернативные сценарии:**
- А1: Пользователь может отменить изменение, закрыв диалог без сохранения
- А2: При вводе некорректного времени система показывает ошибку валидации

**Бизнес-правила:**
- BR-001: Значения по умолчанию (типичные):
  - Утро: 08:00
  - День: 13:00
  - Вечер: 18:00
  - Ночь: 20:00
- BR-002: Время задается в 12-часовом или 24-часовом формате в зависимости от региональных настроек устройства
- BR-003: Настройки времени напоминаний синхронизируются между устройствами через аккаунт Google
- BR-004: При создании напоминания пользователь всегда может выбрать произвольное время вместо предустановленного

**Результат:** При создании напоминаний отображаются настроенные пользователем значения времени для быстрого выбора

### FR-SETTINGS-004: Настройка поведения списков — позиция новых элементов

**Описание:** Пользователь может настроить, где будут добавляться новые элементы в чек-листах: в начало списка (сверху) или в конец списка (снизу).

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Пользователь имеет доступ к меню настроек

**Основной сценарий:**
1. Пользователь открывает меню настроек
2. Пользователь находит раздел "Поведение списков" (List behavior)
3. Система отображает опцию "Добавлять новые элементы снизу" (Add new items to the bottom)
4. Пользователь включает или выключает данную опцию
5. Система сохраняет настройку
6. Новые элементы в чек-листах будут добавляться согласно выбранной настройке

**Альтернативные сценарии:**
- Нет

**Бизнес-правила:**
- BR-001: По умолчанию опция выключена — новые элементы добавляются сверху
- BR-002: Настройка применяется ко всем существующим и новым чек-листам
- BR-003: Настройка синхронизируется между устройствами

**Результат:** Новые элементы в чек-листах добавляются в выбранную позицию (сверху или снизу)

### FR-SETTINGS-005: Настройка поведения списков — перемещение отмеченных элементов

**Описание:** Пользователь может настроить автоматическое перемещение отмеченных (выполненных) элементов чек-листа в отдельную секцию внизу списка.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Пользователь имеет доступ к меню настроек

**Основной сценарий:**
1. Пользователь открывает меню настроек
2. Пользователь находит раздел "Поведение списков" (List behavior)
3. Система отображает опцию "Перемещать отмеченные элементы вниз" (Move checked items to the bottom)
4. Пользователь включает или выключает данную опцию
5. Система сохраняет настройку

**Альтернативные сценарии:**
- А1: При включении опции уже отмеченные элементы во всех списках автоматически группируются внизу
- А2: При выключении опции элементы остаются на своих текущих позициях

**Бизнес-правила:**
- BR-001: По умолчанию опция включена
- BR-002: Отмеченные элементы группируются в сворачиваемую секцию "Отмеченные элементы" (Checked items)
- BR-003: Пользователь может развернуть/свернуть секцию отмеченных элементов
- BR-004: Снятие отметки с элемента возвращает его в основной список
- BR-005: Настройка синхронизируется между устройствами

**Результат:** Отмеченные элементы в чек-листах автоматически перемещаются вниз или остаются на месте в зависимости от настройки

### FR-SETTINGS-006: Управление отображением превью ссылок

**Описание:** Пользователь может включить или отключить отображение расширенных превью (Rich Link Previews) для URL-ссылок, добавленных в заметки. Превью включают заголовок страницы, описание и миниатюру изображения.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Пользователь имеет доступ к меню настроек

**Основной сценарий:**
1. Пользователь открывает меню настроек
2. Пользователь находит опцию "Показывать расширенные превью ссылок" (Display rich link previews)
3. Пользователь включает или выключает данную опцию
4. Пользователь сохраняет изменения (на веб — нажимает "Сохранить")
5. Система применяет настройку

**Альтернативные сценарии:**
- А1: При отключении опции существующие превью ссылок удаляются из всех заметок
- А2: При включении опции система автоматически загружает превью для всех ссылок в заметках

**Бизнес-правила:**
- BR-001: По умолчанию опция включена
- BR-002: Превью ссылок отображаются в нижней части заметки
- BR-003: Настройка синхронизируется между устройствами через аккаунт Google
- BR-004: Пользователь может удалить превью для отдельной ссылки, не отключая функцию глобально
- BR-005: Для удаления превью отдельной ссылки: нажать три точки на превью → "Удалить"

**Результат:** Превью ссылок отображаются или скрываются в соответствии с настройкой пользователя

### FR-SETTINGS-007: Настройка создания текстовых заметок по умолчанию

**Описание:** Пользователь может настроить поведение кнопки создания заметки (FAB — Floating Action Button) так, чтобы при одном нажатии сразу создавалась текстовая заметка, без промежуточного выбора типа.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep (Android)
- Версия приложения поддерживает данную функцию (с 2025 года)

**Основной сценарий:**
1. Пользователь открывает меню настроек
2. Пользователь находит опцию "Создавать текстовые заметки по умолчанию" (Create text notes by default)
3. Пользователь включает данную опцию
4. Система сохраняет настройку
5. При нажатии на кнопку "+" на главном экране сразу создается текстовая заметка

**Альтернативные сценарии:**
- А1: При выключенной опции нажатие на "+" открывает меню выбора типа заметки (текст, список, рисунок, изображение, аудио)
- А2: Данная функция может быть недоступна на iOS и веб-версии

**Бизнес-правила:**
- BR-001: По умолчанию опция выключена (двухшаговое создание заметки)
- BR-002: Функция доступна начиная с версии приложения, выпущенной в 2025 году
- BR-003: Даже при включенной опции пользователь может создать другие типы заметок через длительное нажатие на FAB или через панель быстрых действий

**Результат:** Создание текстовой заметки происходит в один клик без дополнительного выбора типа

### FR-SETTINGS-008: Управление синхронизацией с Google-аккаунтом

**Описание:** Пользователь может управлять синхронизацией заметок Google Keep с аккаунтом Google. Синхронизация обеспечивает доступ к заметкам на всех устройствах и их резервное копирование в облаке.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Устройство подключено к интернету

**Основной сценарий:**
1. Пользователь переходит в системные настройки устройства
2. Пользователь открывает раздел "Аккаунты" → "Google"
3. Пользователь выбирает аккаунт Google
4. Пользователь находит раздел "Синхронизация аккаунта" (Account sync)
5. Пользователь находит переключатель "Keep" в списке сервисов
6. Пользователь включает или отключает синхронизацию Keep

**Альтернативные сценарии:**
- А1: При отключенной синхронизации заметки сохраняются только локально на устройстве
- А2: При повторном включении синхронизации происходит объединение локальных заметок с облачными
- А3: При конфликте изменений (одна заметка отредактирована на разных устройствах офлайн) система показывает уведомление "Обнаружены конфликтующие правки" (Conflicting edits found)

**Бизнес-правила:**
- BR-001: Синхронизация включена по умолчанию
- BR-002: Синхронизация происходит автоматически при наличии интернет-соединения
- BR-003: При создании/редактировании заметок офлайн изменения сохраняются локально и синхронизируются при появлении соединения
- BR-004: При слабом интернет-соединении могут возникать конфликты синхронизации
- BR-005: Принудительную синхронизацию можно вызвать нажатием на кнопку "Обновить" (Refresh) на веб-версии

**Результат:** Заметки синхронизируются или сохраняются только локально в соответствии с настройкой

### FR-SETTINGS-009: Работа в офлайн-режиме

**Описание:** Google Keep поддерживает работу в офлайн-режиме, позволяя просматривать, создавать и редактировать заметки без подключения к интернету. Все изменения автоматически синхронизируются при восстановлении соединения.

**Роли:** Все пользователи

**Предусловия:**
- Приложение Google Keep установлено на устройстве
- Заметки были ранее синхронизированы (для просмотра существующих)

**Основной сценарий:**
1. Пользователь открывает Google Keep без подключения к интернету
2. Система отображает заметки из локального кэша
3. Пользователь может:
   - Просматривать существующие заметки
   - Создавать новые заметки
   - Редактировать существующие заметки
   - Отмечать элементы в чек-листах
4. Система сохраняет изменения локально
5. При восстановлении интернет-соединения:
   - Система автоматически синхронизирует изменения
   - Новые заметки загружаются в облако
   - Изменения с других устройств загружаются на текущее устройство

**Альтернативные сценарии:**
- А1: На Chromebook для работы офлайн необходимо предварительно синхронизировать заметки при наличии интернета
- А2: Если заметка была отредактирована на нескольких устройствах офлайн, при синхронизации появится уведомление о конфликте

**Бизнес-правила:**
- BR-001: Локальный кэш обновляется при каждой синхронизации
- BR-002: Размер локального кэша ограничен памятью устройства
- BR-003: Изображения и вложения кэшируются отдельно и могут быть недоступны офлайн при ограниченной памяти
- BR-004: Напоминания, созданные офлайн, активируются после синхронизации

**Результат:** Пользователь может работать с заметками без подключения к интернету

### FR-SETTINGS-010: Настройка геолокаций для напоминаний

**Описание:** Пользователь может настроить сохраненные местоположения (Дом, Работа) для быстрого создания напоминаний по геолокации.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Приложению предоставлен доступ к геолокации
- Функция доступна до миграции на Google Tasks (2025)

**Основной сценарий:**
1. Пользователь создает напоминание для заметки
2. Пользователь выбирает опцию "Выбрать место" (Pick place)
3. Система предлагает быстрые варианты:
   - Дом (Home) — если настроен
   - Работа (Work) — если настроена
   - Выбрать место (Pick place) — для ввода произвольного адреса
4. Пользователь выбирает сохраненное место или вводит новый адрес
5. Система сохраняет напоминание

**Альтернативные сценарии:**
- А1: Если местоположения "Дом" и "Работа" не настроены, отображается только опция "Выбрать место"
- А2: Местоположения можно настроить через Google Maps
- А3: После миграции на Google Tasks (2025) напоминания по геолокации становятся недоступными

**Бизнес-правила:**
- BR-001: Местоположения "Дом" и "Работа" синхронизируются с аккаунтом Google
- BR-002: Напоминание срабатывает при входе в радиус указанного местоположения
- BR-003: Для работы геолокационных напоминаний требуется постоянный доступ к местоположению устройства
- BR-004: Функция постепенно выводится из эксплуатации с 2025 года в связи с миграцией на Google Tasks

**Результат:** Пользователь получает напоминание при приближении к настроенному местоположению

### FR-SETTINGS-011: Просмотр горячих клавиш

**Описание:** Пользователь может просмотреть список доступных горячих клавиш (клавиатурных сокращений) для быстрой работы с Google Keep на веб-версии.

**Роли:** Все пользователи (веб-версия)

**Предусловия:**
- Пользователь авторизован в веб-версии Google Keep
- Пользователь открыл меню настроек

**Основной сценарий:**
1. Пользователь нажимает на иконку шестеренки в правом верхнем углу
2. Пользователь выбирает пункт "Сочетания клавиш" (Keyboard shortcuts)
3. Система отображает диалоговое окно со списком горячих клавиш
4. Пользователь просматривает доступные сочетания
5. Пользователь закрывает диалог

**Альтернативные сценарии:**
- А1: Пользователь может вызвать справку горячих клавиш нажатием "?" на клавиатуре

**Бизнес-правила:**
- BR-001: Основные горячие клавиши:
  - `C` — создать новую заметку
  - `L` — создать новый список
  - `J` / `K` — навигация между заметками
  - `E` — архивировать заметку
  - `#` — удалить заметку
  - `/` — перейти к поиску
  - `Ctrl+Z` / `Cmd+Z` — отменить действие
  - `Ctrl+Shift+Z` / `Cmd+Shift+Z` — повторить действие
- BR-002: Горячие клавиши работают только в веб-версии
- BR-003: Список горячих клавиш нельзя редактировать или настраивать

**Результат:** Пользователь видит полный список доступных горячих клавиш

### FR-SETTINGS-012: Управление общим доступом (для администраторов Google Workspace)

**Описание:** Администратор Google Workspace может настраивать политики общего доступа к заметкам Google Keep для пользователей организации.

**Роли:** Администратор Google Workspace

**Предусловия:**
- Пользователь имеет права администратора Google Workspace
- Доступ к консоли администратора Google

**Основной сценарий:**
1. Администратор входит в консоль администратора Google (admin.google.com)
2. Администратор переходит: Приложения → Google Workspace → Drive и Документы
3. Администратор открывает "Настройки общего доступа" (Sharing settings)
4. Администратор настраивает политику:
   - ВКЛ: разрешить пользователям делиться заметками с пользователями вне организации
   - ВЫКЛ: запретить внешний общий доступ
5. Администратор сохраняет изменения
6. Политика применяется ко всем пользователям организации

**Альтернативные сценарии:**
- А1: Изменения политики могут применяться с задержкой до 24 часов
- А2: Администратор может применить политику только к определенным организационным подразделениям

**Бизнес-правила:**
- BR-001: По умолчанию внешний общий доступ включен
- BR-002: Google Keep не поддерживает whitelist-ы доменов для общего доступа
- BR-003: Политики влияют только на создание нового общего доступа, существующие совместные заметки сохраняются

**Результат:** Политика общего доступа применена к пользователям организации

### FR-SETTINGS-013: Отмена и повтор действий

**Описание:** Пользователь может отменять и повторять последние действия редактирования при работе с заметками.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь находится в режиме редактирования заметки
- Были выполнены действия редактирования

**Основной сценарий:**
1. Пользователь редактирует заметку
2. Пользователь хочет отменить последнее действие
3. Пользователь выполняет отмену:
   - **Веб:** нажимает `Ctrl+Z` (Windows) или `Cmd+Z` (Mac)
   - **Android:** нажимает кнопку "Отменить" на панели инструментов или встряхивает устройство
   - **iOS:** встряхивает устройство
4. Система отменяет последнее действие
5. Для повтора отмененного действия:
   - **Веб:** `Ctrl+Shift+Z` или `Cmd+Shift+Z`
   - **Android:** кнопка "Повторить" на панели инструментов

**Альтернативные сценарии:**
- А1: Если история действий пуста, кнопки отмены/повтора неактивны
- А2: При закрытии заметки история действий очищается

**Бизнес-правила:**
- BR-001: История отмены сохраняется только в рамках текущей сессии редактирования
- BR-002: После закрытия заметки или выхода из приложения история очищается
- BR-003: Восстановить изменения из предыдущих сессий невозможно
- BR-004: Кнопки отмены/повтора на Android появляются после начала редактирования

**Результат:** Последнее действие отменено или повторено

### FR-SETTINGS-014: Просмотр истории версий заметки

**Описание:** Пользователь может просмотреть историю изменений заметки и восстановить предыдущие версии.

**Роли:** Все пользователи

**Предусловия:**
- Пользователь авторизован в приложении Google Keep
- Заметка имеет историю изменений

**Основной сценарий:**
1. Пользователь открывает заметку
2. Пользователь нажимает на меню (три точки)
3. Пользователь выбирает "Посмотреть историю версий" (See revision history)
4. Система отображает список предыдущих версий заметки с датами изменений
5. Пользователь выбирает версию для просмотра
6. Система отображает содержимое выбранной версии
7. Пользователь может восстановить выбранную версию

**Альтернативные сценарии:**
- А1: Если история версий недоступна, пункт меню скрыт или неактивен
- А2: История версий может храниться ограниченное время

**Бизнес-правила:**
- BR-001: История версий сохраняется автоматически при значительных изменениях
- BR-002: Мелкие изменения могут объединяться в одну версию
- BR-003: При восстановлении предыдущей версии текущая версия сохраняется в истории

**Результат:** Пользователь просмотрел или восстановил предыдущую версию заметки

## Сущности данных

### UserSettings (Настройки пользователя)

| Поле | Тип | Описание |
|------|-----|----------|

|------|-----|----------|

| Поле | Тип | Описание |
|------|-----|----------|

| `longitude` | decimal | Долгота |

## Состояния и статусы

### Состояния синхронизации

| Состояние | Описание | Индикатор |
|-----------|----------|-----------|
| `SYNCED` | Все данные синхронизированы | Нет индикатора (норма) |
| `SYNCING` | Идет синхронизация | Анимация загрузки |
| `PENDING` | Есть несинхронизированные изменения | Значок ожидания |
| `OFFLINE` | Нет подключения к интернету | Значок офлайн |
| `CONFLICT` | Обнаружен конфликт синхронизации | Уведомление с предупреждением |

|-----------|----------|

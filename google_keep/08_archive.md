# Архив и корзина

## Описание

Модуль "Архив и корзина" обеспечивает управление жизненным циклом заметок в Google Keep после их первоначального создания. Модуль предоставляет два основных механизма организации контента:

1. **Архив** - долгосрочное хранилище для заметок, которые пользователь хочет сохранить, но не отображать на главном экране. Заметки в архиве сохраняются бессрочно и остаются полностью функциональными.

2. **Корзина** - временное хранилище для удаленных заметок с автоматической очисткой через 7 дней. Позволяет восстановить случайно удаленные заметки.

Ключевые отличия архива от корзины:
- Архив: заметки хранятся бессрочно, полностью доступны для редактирования и поиска
- Корзина: заметки автоматически удаляются через 7 дней, недоступны для редактирования

Модуль интегрирован с системой ярлыков, совместного доступа и напоминаний, обеспечивая непрерывность работы с заметками независимо от их местоположения.

## Роли пользователей

### Владелец заметки (Owner)
- Полный контроль над заметкой на всех этапах жизненного цикла
- Может архивировать и разархивировать заметки
- Может удалять заметки и перемещать их в корзину
- Может восстанавливать заметки из корзины
- Может безвозвратно удалять заметки из корзины
- Может очищать всю корзину
- Решения об удалении влияют на всех соавторов

### Соавтор заметки (Collaborator)
- Имеет доступ к совместной заметке, даже если владелец её архивировал
- Может самостоятельно архивировать совместную заметку (только для своего отображения)
- Может удалить свой доступ к совместной заметке
- Не может удалить совместную заметку для всех - только отказаться от доступа
- При удалении заметки владельцем теряет к ней доступ

### Член семейной группы (Family Member)
- Аналогичные права соавтора для заметок, расшаренных в семейную группу
- Может редактировать и удалять заметки семейной группы (для всех членов)
- Архивирование семейной заметки влияет только на свой аккаунт

## Функциональные требования

### FR-ARCHIVE-001: Архивирование отдельной заметки

**Описание:** Пользователь перемещает заметку в архив, чтобы скрыть её с главного экрана, сохраняя полный доступ к ней.

**Роли:** Владелец заметки, Соавтор, Член семейной группы

**Предусловия:**
- Пользователь авторизован в Google Keep
- Заметка существует и не находится в корзине
- Заметка отображается на главном экране (не в архиве)

**Основной сценарий:**
1. Пользователь открывает заметку или наводит на неё курсор
2. Пользователь нажимает иконку "Архивировать" (стрелка вниз в прямоугольник)
3. Система перемещает заметку в раздел "Архив"
4. Заметка исчезает с главного экрана
5. Система показывает уведомление "Заметка архивирована" с кнопкой "Отменить"

**Альтернативные сценарии:**
- **Сценарий А (Быстрая отмена):** В течение нескольких секунд после архивирования пользователь нажимает "Отменить" - заметка возвращается на главный экран
- **Сценарий Б (Архивирование совместной заметки):** При архивировании совместной заметки она скрывается только у текущего пользователя, соавторы продолжают видеть её в своих аккаунтах
- **Сценарий В (Архивирование с мобильного):** На мобильных устройствах можно использовать свайп для архивирования (если настроено)

**Бизнес-правила:**
- BR-001: Архивирование заметки не влияет на её отображение у соавторов
- BR-002: Архивированные заметки сохраняют все свои свойства: цвет, ярлыки, напоминания, изображения
- BR-003: Архивированные заметки продолжают отображаться при фильтрации по ярлыкам
- BR-004: Напоминания на архивированных заметках продолжают работать
- BR-005: Срок хранения заметок в архиве не ограничен

**Результат:** Заметка перемещена в архив, скрыта с главного экрана, но остается доступной для просмотра, редактирования и поиска.

### FR-ARCHIVE-002: Массовое архивирование заметок

**Описание:** Пользователь перемещает несколько заметок в архив одновременно.

**Роли:** Владелец заметки, Соавтор, Член семейной группы

**Предусловия:**
- Пользователь авторизован в Google Keep
- На главном экране есть хотя бы одна заметка
- Заметки не находятся в корзине

**Основной сценарий:**
1. **На компьютере:**
   - Пользователь наводит курсор на первую заметку и нажимает чекбокс
   - Пользователь выбирает дополнительные заметки (клик на чекбокс каждой)
   - Появляется панель действий с количеством выбранных заметок
   - Пользователь нажимает иконку "Архивировать"
   - Все выбранные заметки перемещаются в архив

2. **На мобильном устройстве (Android/iOS):**
   - Пользователь долго удерживает первую заметку
   - Заметка выделяется, появляется режим выбора
   - Пользователь касается дополнительных заметок для выбора
   - Пользователь нажимает меню (три точки) > "Архивировать"
   - Все выбранные заметки перемещаются в архив

**Альтернативные сценарии:**
- **Сценарий А (Выбор всех заметок):** На компьютере пользователь может нажать Ctrl+A для выбора всех видимых заметок, затем архивировать
- **Сценарий Б (Частичный выбор):** Пользователь может снять выделение с некоторых заметок перед архивированием

**Бизнес-правила:**
- BR-006: Все выбранные заметки архивируются одновременно
- BR-007: Для каждой совместной заметки правило BR-001 применяется индивидуально
- BR-008: Отображается общее количество заархивированных заметок в уведомлении
- BR-009: Кнопка "Отменить" восстанавливает все заметки сразу

**Результат:** Все выбранные заметки перемещены в архив одной операцией.

### FR-ARCHIVE-003: Просмотр архива

**Описание:** Пользователь просматривает все свои архивированные заметки.

**Роли:** Владелец заметки, Соавтор, Член семейной группы

**Предусловия:**
- Пользователь авторизован в Google Keep

**Основной сценарий:**
1. Пользователь открывает боковое меню (три горизонтальные линии / "гамбургер")
2. Пользователь выбирает пункт "Архив"
3. Система отображает все архивированные заметки пользователя
4. Заметки показываются с сохранением всех визуальных свойств (цвет, изображения)
5. Пользователь может прокручивать список для просмотра всех заметок

**Альтернативные сценарии:**
- **Сценарий А (Пустой архив):** Если архив пуст, отображается сообщение "Здесь появятся архивированные заметки"
- **Сценарий Б (Поиск в архиве):** Пользователь может использовать поиск для нахождения конкретной заметки в архиве

**Бизнес-правила:**
- BR-010: Архивированные заметки отображаются в том же формате, что и на главном экране
- BR-011: В архиве доступны те же операции, что и на главном экране (кроме закрепления)
- BR-012: Порядок сортировки заметок в архиве соответствует общим настройкам отображения
- BR-013: Архивированные заметки включаются в результаты глобального поиска

**Результат:** Пользователь видит список всех своих архивированных заметок с возможностью взаимодействия.

### FR-ARCHIVE-004: Разархивирование заметки

**Описание:** Пользователь возвращает заметку из архива на главный экран.

**Роли:** Владелец заметки, Соавтор, Член семейной группы

**Предусловия:**
- Пользователь авторизован в Google Keep
- Заметка находится в архиве

**Основной сценарий:**
1. Пользователь открывает раздел "Архив"
2. Пользователь открывает заметку или наводит на неё курсор
3. Пользователь нажимает иконку "Разархивировать" (стрелка вверх из прямоугольника)
4. Система перемещает заметку на главный экран
5. Заметка исчезает из раздела "Архив"
6. Система показывает уведомление "Заметка разархивирована"

**Альтернативные сценарии:**
- **Сценарий А (Разархивирование из открытой заметки):** Пользователь открывает заметку и нажимает иконку разархивирования в верхнем меню
- **Сценарий Б (Массовое разархивирование):** Пользователь выбирает несколько заметок и разархивирует их одновременно

**Бизнес-правила:**
- BR-014: Разархивированная заметка появляется на главном экране в соответствии с её датой изменения
- BR-015: Все свойства заметки (цвет, ярлыки, напоминания) сохраняются
- BR-016: Разархивирование совместной заметки влияет только на текущего пользователя

**Результат:** Заметка возвращена на главный экран и удалена из архива.

### FR-ARCHIVE-005: Удаление заметки (перемещение в корзину)

**Описание:** Пользователь удаляет заметку, перемещая её в корзину для последующего автоматического или ручного удаления.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- Пользователь является владельцем заметки
- Заметка не находится в корзине

**Основной сценарий:**
1. Пользователь открывает заметку
2. Пользователь нажимает меню (три вертикальные точки)
3. Пользователь выбирает "Удалить"
4. Система перемещает заметку в корзину
5. Заметка исчезает с главного экрана или из архива
6. Система показывает уведомление "Заметка перемещена в корзину" с кнопкой "Отменить"

**Альтернативные сценарии:**
- **Сценарий А (Удаление с главного экрана):** Пользователь удаляет заметку напрямую с главного экрана через меню
- **Сценарий Б (Удаление из архива):** Заметка перемещается из архива в корзину
- **Сценарий В (Удаление совместной заметки):** При удалении совместной заметки владельцем она удаляется у всех соавторов
- **Сценарий Г (Отказ соавтора):** Соавтор может "удалить" совместную заметку для себя - это удаляет только его доступ, не затрагивая других

**Бизнес-правила:**
- BR-017: Только владелец может удалить заметку для всех
- BR-018: Удаленные совместные заметки немедленно исчезают у всех соавторов
- BR-019: Соавторы теряют доступ к удаленной заметке, даже находящейся в корзине владельца
- BR-020: Заметки в корзине автоматически удаляются через 7 дней
- BR-021: Напоминания на удаленных заметках деактивируются

**Результат:** Заметка перемещена в корзину и будет автоматически удалена через 7 дней.

### FR-ARCHIVE-006: Массовое удаление заметок

**Описание:** Пользователь удаляет несколько заметок одновременно.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- Пользователь является владельцем выбранных заметок
- Заметки не находятся в корзине

**Основной сценарий:**
1. **На компьютере:**
   - Пользователь выбирает несколько заметок (чекбоксы)
   - Появляется панель действий
   - Пользователь нажимает меню (три точки) > "Удалить"
   - Все выбранные заметки перемещаются в корзину

2. **На мобильном устройстве:**
   - Пользователь долго удерживает первую заметку
   - Пользователь выбирает дополнительные заметки
   - Пользователь нажимает меню > "Удалить"
   - Все выбранные заметки перемещаются в корзину

**Альтернативные сценарии:**
- **Сценарий А (Смешанный выбор):** При выборе как собственных, так и совместных заметок, собственные удаляются, а для совместных удаляется только доступ пользователя

**Бизнес-правила:**
- BR-022: Все выбранные заметки обрабатываются согласно правам пользователя на каждую
- BR-023: Отображается уведомление с количеством удаленных заметок
- BR-024: Кнопка "Отменить" восстанавливает все заметки

**Результат:** Все выбранные заметки перемещены в корзину.

### FR-ARCHIVE-007: Просмотр корзины

**Описание:** Пользователь просматривает удаленные заметки в корзине.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep

**Основной сценарий:**
1. Пользователь открывает боковое меню
2. Пользователь выбирает пункт "Корзина"
3. Система отображает все удаленные заметки
4. Заметки показываются с визуальной индикацией (возможно, приглушенный вид)
5. Отображается информация о времени до автоудаления

**Альтернативные сценарии:**
- **Сценарий А (Пустая корзина):** Отображается сообщение "Корзина пуста" или "Удаленные заметки будут храниться здесь 7 дней"
- **Сценарий Б (Информационное сообщение):** В верхней части раздела отображается информация: "Заметки удаляются навсегда через 7 дней"

**Бизнес-правила:**
- BR-025: В корзине отображаются только заметки, владельцем которых является пользователь
- BR-026: Заметки в корзине нельзя редактировать
- BR-027: Заметки в корзине не отображаются в поиске
- BR-028: Заметки в корзине не отображаются при фильтрации по ярлыкам

**Результат:** Пользователь видит список удаленных заметок с возможностью восстановления или окончательного удаления.

### FR-ARCHIVE-008: Восстановление заметки из корзины

**Описание:** Пользователь восстанавливает удаленную заметку из корзины.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- Заметка находится в корзине
- С момента удаления прошло менее 7 дней

**Основной сценарий:**
1. Пользователь открывает раздел "Корзина"
2. Пользователь нажимает на заметку для её открытия
3. Пользователь нажимает меню (три точки) или иконку "Восстановить"
4. Пользователь выбирает "Восстановить"
5. Система перемещает заметку на главный экран
6. Заметка исчезает из корзины
7. Система показывает уведомление "Заметка восстановлена"

**Альтернативные сценарии:**
- **Сценарий А (Восстановление без открытия):** На компьютере пользователь может восстановить заметку через контекстное меню без её открытия
- **Сценарий Б (Массовое восстановление):** Пользователь выбирает несколько заметок и восстанавливает их одновременно
- **Сценарий В (Восстановление совместной заметки):** При восстановлении совместной заметки соавторы снова получают к ней доступ

**Бизнес-правила:**
- BR-029: Восстановленная заметка возвращается на главный экран, а не в архив (даже если была удалена из архива)
- BR-030: Все свойства заметки восстанавливаются (цвет, ярлыки, содержимое)
- BR-031: Напоминания восстанавливаются, если время еще не прошло
- BR-032: При восстановлении совместной заметки уведомления соавторам не отправляются
- BR-033: Соавторы, которые были удалены из заметки до её удаления, не восстанавливаются

**Результат:** Заметка восстановлена из корзины и доступна на главном экране.

### FR-ARCHIVE-009: Безвозвратное удаление заметки из корзины

**Описание:** Пользователь окончательно удаляет заметку без возможности восстановления.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- Заметка находится в корзине

**Основной сценарий:**
1. Пользователь открывает раздел "Корзина"
2. Пользователь нажимает на заметку для её открытия
3. Пользователь нажимает меню (три точки)
4. Пользователь выбирает "Удалить навсегда"
5. Система запрашивает подтверждение (опционально, зависит от платформы)
6. Заметка безвозвратно удаляется
7. Система показывает уведомление "Заметка удалена навсегда"

**Альтернативные сценарии:**
- **Сценарий А (Массовое безвозвратное удаление):** Пользователь выбирает несколько заметок и удаляет их навсегда
- **Сценарий Б (Отмена подтверждения):** Пользователь отменяет действие в диалоге подтверждения - заметка остается в корзине

**Бизнес-правила:**
- BR-034: После безвозвратного удаления заметка не может быть восстановлена стандартными средствами
- BR-035: Все связанные данные (изображения, рисунки, аудио) удаляются вместе с заметкой
- BR-036: Действие не может быть отменено после выполнения

**Результат:** Заметка безвозвратно удалена из системы.

### FR-ARCHIVE-010: Очистка всей корзины

**Описание:** Пользователь безвозвратно удаляет все заметки из корзины.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- В корзине есть хотя бы одна заметка

**Основной сценарий:**
1. Пользователь открывает раздел "Корзина"
2. Пользователь нажимает "Очистить корзину" (или меню > "Очистить корзину")
3. Система запрашивает подтверждение: "Удалить все заметки навсегда?"
4. Пользователь подтверждает действие
5. Все заметки в корзине безвозвратно удаляются
6. Система показывает уведомление "Корзина очищена"

**Альтернативные сценарии:**

**Бизнес-правила:**

- BR-038: Требуется обязательное подтверждение пользователя
- BR-039: Действие не может быть отменено после выполнения

### FR-ARCHIVE-011: Автоматическое удаление из корзины

**Описание:** Система автоматически удаляет заметки из корзины по истечении 7 дней.

**Роли:** Система (автоматический процесс)

**Предусловия:**
- Заметка находится в корзине
- С момента перемещения в корзину прошло 7 дней

**Основной сценарий:**
1. Система периодически проверяет корзины всех пользователей
2. Для каждой заметки вычисляется время с момента удаления
3. Если прошло 7 или более дней, заметка безвозвратно удаляется
4. Освобождаются связанные ресурсы (изображения, файлы)

**Альтернативные сценарии:**
- **Сценарий А (Заметка восстановлена до истечения срока):** Таймер сбрасывается, заметка не удаляется
- **Сценарий Б (Повторное удаление):** При повторном удалении ранее восстановленной заметки 7-дневный таймер начинается заново

**Бизнес-правила:**
- BR-041: Период хранения в корзине составляет ровно 7 дней (168 часов)
- BR-042: Автоудаление происходит без уведомления пользователя
- BR-043: Отсчет начинается с момента перемещения в корзину, а не с момента создания заметки
- BR-044: Нет возможности изменить срок хранения в корзине
- BR-045: После автоматического удаления восстановление невозможно

**Результат:** Заметки старше 7 дней автоматически удаляются из корзины.

4. Архивированные заметки отображаются в результатах поиска

### FR-ARCHIVE-015: Архивирование и совместный доступ

**Описание:** Управление взаимодействием между архивированием и совместным доступом к заметкам.

**Роли:** Владелец заметки, Соавтор, Член семейной группы

**Предусловия:**
- Заметка имеет соавторов или расшарена в семейную группу
- Один из участников архивирует заметку

**Основной сценарий:**
1. Владелец или соавтор архивирует совместную заметку
2. Заметка перемещается в архив только у этого пользователя
3. У других участников заметка остается на главном экране
4. Все участники сохраняют доступ к редактированию
5. Изменения синхронизируются между всеми участниками

**Альтернативные сценарии:**
- **Сценарий А (Архивирование разными пользователями):** Каждый участник может независимо архивировать заметку для себя
- **Сценарий Б (Добавление цвета/ярлыка):** Любой участник может изменить цвет или добавить ярлык, это влияет на всех
- **Сценарий В (Установка напоминания):** Напоминания устанавливаются индивидуально и не влияют на других участников

**Бизнес-правила:**
- BR-056: Архивирование - это персональное действие, не влияющее на других участников
- BR-057: Удаление владельцем влияет на всех участников
- BR-058: Цвет, ярлыки и содержимое синхронизируются между всеми участниками
- BR-059: Напоминания - персональные для каждого участника

**Результат:** Архивирование совместной заметки влияет только на аккаунт выполнившего действие пользователя.

                    v           |

                 |

## Интеграции с другими модулями

### Модуль "Заметки и списки"
- Архивированные заметки сохраняют все типы контента (текст, списки, изображения, рисунки)
- Чекбоксы в списках остаются функциональными в архиве
- При удалении удаляются все вложения заметки

### Модуль "Ярлыки"
- Архивированные заметки отображаются при фильтрации по ярлыкам
- Ярлыки сохраняются при архивировании и восстановлении
- При удалении заметки связи с ярлыками удаляются
- Удаленные заметки (в корзине) не отображаются в ярлыках

### Модуль "Напоминания"
- Напоминания активны для архивированных заметок
- При удалении заметки напоминания деактивируются
- При восстановлении из корзины напоминания восстанавливаются (если время не прошло)

### Модуль "Совместный доступ"
- Архивирование персонально для каждого пользователя
- Удаление владельцем затрагивает всех соавторов
- При удалении соавторы теряют доступ без возможности восстановления
- Соавтор может "удалить" заметку только для себя (отказ от доступа)

### Модуль "Поиск"
- Архивированные заметки индексируются и доступны в поиске
- Заметки в корзине исключаются из поиска
- Фильтры работают с архивированными заметками

### Модуль "Синхронизация"
- Архивирование синхронизируется между устройствами
- Удаление синхронизируется мгновенно на всех устройствах
- Восстановление из корзины синхронизируется
- Автоудаление через 7 дней происходит серверно

### Модуль "Цвета и оформление"
- Цвет заметки сохраняется при архивировании
- Цвет отображается в корзине (read-only)
- При восстановлении цвет сохраняется

### Модуль "Изображения и медиа"
- Изображения сохраняются в архиве
- При безвозвратном удалении освобождается место в хранилище
- Изображения отображаются в корзине (read-only)

### Интеграция с Google Drive
- Google Keep не интегрирован напрямую с корзиной Google Drive
- Заметки Keep не появляются в корзине Drive
- Разные сроки хранения (Keep: 7 дней, Drive: 30 дней)

### Интеграция с Google Assistant
- Голосовые команды для архивирования: "Окей Google, архивируй заметку [название]"
- Голосовые команды для удаления: "Окей Google, удали заметку [название]"
- Восстановление голосом недоступно

## Восстановление данных

### Стандартные способы восстановления
1. **Из корзины** (в течение 7 дней): полное восстановление заметки
2. **Отмена действия** (сразу после): кнопка "Отменить" в уведомлении
3. **Из архива**: разархивирование в любой момент

### После безвозвратного удаления
- Стандартного способа восстановления не существует
- Возможно обращение в поддержку Google (без гарантий)
- Рекомендуется использовать Google Takeout для резервного копирования

### Резервное копирование
- Google Takeout позволяет экспортировать все заметки Keep
- Экспорт включает архивированные заметки
- Заметки в корзине не включаются в экспорт

## Безопасность и приватность

### Удаление данных
- При безвозвратном удалении данные удаляются с серверов Google
- Освобождается место в хранилище Google аккаунта
- Удаление происходит без возможности восстановления

### Совместные заметки
- Соавторы не могут восстановить удаленную владельцем заметку
- История изменений не сохраняется для совместных заметок
- При удалении аккаунта владельца заметки удаляются для всех

### Корпоративные аккаунты (Google Workspace)

- Возможно расширенное хранение в корзине для соответствия требованиям
- Аудит действий с заметками (для администраторов)

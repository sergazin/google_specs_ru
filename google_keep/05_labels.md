# Метки и организация

## Описание

Модуль "Метки и организация" предоставляет пользователям Google Keep набор инструментов для систематизации, категоризации и визуальной дифференциации заметок. Модуль включает функции управления метками (labels), цветового кодирования заметок, закрепления важных заметок, а также механизмы фильтрации и поиска по различным критериям.

Ключевые возможности модуля:
- **Метки (Labels)** — текстовые теги для категоризации заметок по темам, проектам или любым другим критериям
- **Цветовое кодирование** — 12 цветов для визуальной дифференциации заметок
- **Фоновые изображения** — иллюстративные фоны для тематической маркировки заметок
- **Закрепление (Pin)** — фиксация важных заметок в верхней части списка
- **Архивация** — скрытие неактуальных заметок с сохранением доступа
- **Поиск и фильтрация** — быстрый доступ к заметкам по различным параметрам

## Роли пользователей

### Владелец заметки (Note Owner)
- Полный доступ ко всем функциям организации
- Создание, редактирование и удаление меток
- Назначение меток, цветов и фонов заметкам
- Закрепление и архивация заметок
- Изменение порядка заметок

### Участник общей заметки (Collaborator)
- Просмотр содержимого заметки
- Редактирование содержимого (если разрешено)
- **Не видит** метки, цвета и статус закрепления, установленные владельцем
- Может применять собственные метки, цвета и закрепление к общей заметке (видимые только ему)

### Гостевой пользователь (Guest)
- Только просмотр заметок, доступных по ссылке
- Без доступа к функциям организации

## Функциональные требования

### FR-LABELS-001: Создание новой метки

**Описание:** Пользователь может создать новую метку для категоризации заметок. Метка представляет собой текстовый тег, который можно присвоить одной или нескольким заметкам.

**Роли:** Владелец заметки, Участник общей заметки (для личных меток)

**Предусловия:**
- Пользователь авторизован в Google Keep
- Количество существующих меток менее 50

**Основной сценарий:**

1. **Desktop — через боковое меню:**
   1. Пользователь нажимает на иконку меню (☰) в левом верхнем углу
   2. Выбирает "Изменить ярлыки" (Edit labels)
   3. В поле "Создать ярлык" вводит название новой метки
   4. Нажимает иконку галочки (✓) или Enter для сохранения
   5. Система создает метку и отображает её в списке меток

2. **Desktop — из заметки:**
   1. Пользователь открывает заметку
   2. Нажимает меню действий (⋮) внизу заметки
   3. Выбирает "Добавить ярлык" (Add label)
   4. В поле поиска вводит название новой метки
   5. Нажимает "+ Создать [название метки]"
   6. Система создает метку и сразу присваивает её заметке

3. **Mobile — быстрое создание через хэштег:**
   1. Пользователь открывает заметку
   2. В тексте заметки вводит символ # и название метки (например, #Работа)
   3. Система показывает подсказку "Создать [название]"
   4. Пользователь нажимает на подсказку
   5. Система создает метку и присваивает её заметке

**Альтернативные сценарии:**

- **AS-001-A:** Если достигнут лимит в 50 меток, система отображает сообщение об ошибке и не позволяет создать новую метку
- **AS-001-B:** Если метка с таким именем уже существует, система предлагает выбрать существующую метку вместо создания дубликата
- **AS-001-C:** Если пользователь отменяет создание (нажимает Escape или кнопку отмены), метка не создается

**Бизнес-правила:**
- BR-001: Максимальное количество меток — 50
- BR-002: Название метки не может быть пустым
- BR-003: Название метки регистронезависимо при проверке дубликатов
- BR-004: Метки сортируются в алфавитном порядке в списке
- BR-005: Метки являются персональными — другие пользователи не видят ваших меток даже в общих заметках

**Результат:** Создана новая метка, доступная для присвоения заметкам. Метка отображается в боковом меню и в списке меток при редактировании заметок.

### FR-LABELS-002: Присвоение метки заметке

**Описание:** Пользователь может присвоить одну или несколько меток заметке для её категоризации. Одна заметка может иметь несколько меток одновременно.

**Роли:** Владелец заметки, Участник общей заметки (для личных меток)

**Предусловия:**
- Пользователь авторизован
- Существует хотя бы одна метка
- Заметка существует и доступна пользователю

**Основной сценарий:**

1. **Присвоение одной заметке:**
   1. Пользователь открывает заметку
   2. Нажимает меню действий (⋮) внизу заметки
   3. Выбирает "Добавить ярлык" или "Изменить ярлыки"
   4. Система отображает список доступных меток с чекбоксами
   5. Пользователь отмечает нужные метки (можно несколько)
   6. Нажимает вне диалога или кнопку подтверждения
   7. Система присваивает метки и отображает их внизу заметки

2. **Массовое присвоение нескольким заметкам:**
   1. Пользователь наводит на заметку и нажимает чекбокс (✓) в углу
   2. Выбирает дополнительные заметки аналогичным способом
   3. В появившейся панели инструментов нажимает меню (⋮)
   4. Выбирает "Изменить ярлыки"
   5. Отмечает нужные метки
   6. Система присваивает метки всем выбранным заметкам

**Альтернативные сценарии:**

- **AS-002-A:** При создании новой заметки находясь в разделе метки — заметка автоматически получает эту метку
- **AS-002-B:** При вводе хэштега (#) в тексте заметки — система предлагает существующие метки для быстрого присвоения

**Бизнес-правила:**
- BR-006: Одна заметка может иметь неограниченное количество меток (ограничение только общим количеством меток — 50)
- BR-007: Присвоенные метки отображаются под текстом заметки в виде небольших тегов
- BR-008: Порядок отображения меток на заметке — алфавитный

**Результат:** Заметка ассоциирована с выбранными метками. Метки отображаются под заметкой и заметка появляется при фильтрации по этим меткам.

### FR-LABELS-003: Удаление метки с заметки

**Описание:** Пользователь может удалить присвоенную метку с конкретной заметки, сохранив саму метку для использования с другими заметками.

**Роли:** Владелец заметки, Участник общей заметки (для личных меток)

**Предусловия:**
- Заметка имеет хотя бы одну присвоенную метку
- Пользователь имеет доступ к заметке

**Основной сценарий:**

1. Пользователь открывает заметку с присвоенными метками
2. Нажимает меню действий (⋮) и выбирает "Изменить ярлыки"
3. В списке меток снимает галочку с нужной метки
4. Закрывает диалог
5. Система удаляет метку с заметки

**Альтернативные сценарии:**

- **AS-003-A:** Пользователь нажимает крестик (×) рядом с меткой под заметкой для быстрого удаления (доступно в развернутом виде заметки)

**Бизнес-правила:**
- BR-009: Удаление метки с заметки не удаляет саму метку из системы
- BR-010: Заметка может остаться без меток

**Результат:** Метка удалена с заметки. Заметка больше не отображается при фильтрации по этой метке.

### FR-LABELS-004: Редактирование метки

**Описание:** Пользователь может изменить название существующей метки. Изменение применяется ко всем заметкам, использующим эту метку.

**Роли:** Владелец заметки

**Предусловия:**
- Существует хотя бы одна метка
- Пользователь авторизован

**Основной сценарий:**

1. Пользователь нажимает иконку меню (☰) в левом верхнем углу
2. Выбирает "Изменить ярлыки" (Edit labels)
3. Наводит курсор на нужную метку
4. Нажимает иконку карандаша (✏️) рядом с меткой
5. Вводит новое название метки
6. Нажимает иконку галочки (✓) для сохранения
7. Система обновляет название метки на всех заметках

**Альтернативные сценарии:**

- **AS-004-A:** Если новое название совпадает с существующей меткой — система показывает ошибку
- **AS-004-B:** Если пользователь нажимает Escape — изменения отменяются

**Бизнес-правила:**
- BR-011: Переименование метки автоматически обновляет её на всех заметках
- BR-012: Название метки не может быть пустым
- BR-013: Названия меток уникальны (регистронезависимо)

**Результат:** Метка переименована. Все заметки с этой меткой теперь отображают новое название.

---

### FR-LABELS-005: Удаление метки

**Описание:** Пользователь может полностью удалить метку из системы. При удалении метки она снимается со всех заметок.

**Роли:** Владелец заметки

**Предусловия:**
- Существует хотя бы одна метка
- Пользователь авторизован

**Основной сценарий:**

1. Пользователь нажимает иконку меню (☰)
2. Выбирает "Изменить ярлыки"
3. Наводит курсор на метку для удаления
4. Нажимает иконку корзины (🗑️) рядом с меткой
5. Система показывает диалог подтверждения
6. Пользователь подтверждает удаление
7. Система удаляет метку и снимает её со всех заметок

**Альтернативные сценарии:**

- **AS-005-A:** Если пользователь отменяет подтверждение — метка сохраняется
- **AS-005-B:** На мобильных устройствах — свайп влево по метке для удаления

**Бизнес-правила:**
- BR-014: Удаление метки НЕ удаляет заметки, которым она была присвоена
- BR-015: Удаленную метку нельзя восстановить (кроме создания новой с тем же именем)
- BR-016: Заметки, имевшие только эту метку, остаются без меток

**Результат:** Метка удалена из системы. Все заметки теряют ассоциацию с этой меткой, но сами заметки сохраняются.

### FR-LABELS-006: Фильтрация заметок по метке

**Описание:** Пользователь может отфильтровать заметки, отображая только те, которые имеют определенную метку.

**Роли:** Владелец заметки, Участник общей заметки

**Предусловия:**
- Существует хотя бы одна метка
- Есть заметки с присвоенными метками

**Основной сценарий:**

1. Пользователь нажимает иконку меню (☰)
2. В списке меток нажимает на нужную метку
3. Система отображает только заметки с выбранной меткой
4. В заголовке отображается название активной метки
5. Новые заметки, созданные в этом режиме, автоматически получают эту метку

**Альтернативные сценарии:**

- **AS-006-A:** Клик по метке под заметкой — быстрая фильтрация по этой метке
- **AS-006-B:** Использование поиска с названием метки — фильтрация через поисковую строку

**Бизнес-правила:**
- BR-017: В режиме фильтрации по метке отображаются и неархивированные, и архивированные заметки (архивированные внизу)
- BR-018: Создание заметки в режиме фильтрации автоматически присваивает ей текущую метку
- BR-019: Закрепленные заметки остаются вверху списка даже при фильтрации

**Результат:** Отображаются только заметки с выбранной меткой.

### FR-LABELS-007: Изменение цвета заметки

**Описание:** Пользователь может изменить цвет фона заметки для визуальной дифференциации и категоризации.

**Роли:** Владелец заметки, Участник общей заметки (для личного отображения)

**Предусловия:**
- Заметка существует
- Пользователь имеет доступ к заметке

**Основной сценарий:**

1. Пользователь открывает заметку
2. Нажимает на иконку палитры (🎨) внизу заметки
3. Система отображает панель выбора цвета и фонов
4. Пользователь выбирает один из 12 доступных цветов:
   - По умолчанию (белый/серый)
   - Коралловый (Coral)
   - Персиковый (Peach)
   - Песочный (Sand)
   - Мятный (Mint)
   - Шалфейный (Sage)
   - Туманный (Fog)
   - Штормовой (Storm)
   - Сумеречный (Dusk)
   - Цветочный (Blossom)
   - Глиняный (Clay)
   - Меловой (Chalk)
5. Система мгновенно применяет выбранный цвет к заметке
6. Изменение сохраняется автоматически

**Альтернативные сценарии:**

- **AS-007-A:** Массовое изменение цвета:
  1. Выбрать несколько заметок (чекбоксы)
  2. Нажать иконку палитры в панели инструментов
  3. Выбрать цвет — применяется ко всем выбранным заметкам

- **AS-007-B:** Быстрое изменение без открытия заметки:
  1. Навести на заметку в сетке
  2. Нажать иконку палитры в появившейся панели
  3. Выбрать цвет

**Бизнес-правила:**
- BR-020: Цвет заметки персонален — соавторы не видят ваш выбор цвета
- BR-021: Цвет сохраняется при синхронизации между устройствами
- BR-022: В темной теме цвета отображаются приглушенно
- BR-023: Можно выбрать только один цвет (нельзя комбинировать)

**Результат:** Заметка отображается с новым цветом фона на всех устройствах пользователя.

### FR-LABELS-008: Установка фонового изображения

**Описание:** Пользователь может установить декоративное фоновое изображение для заметки вместо или в дополнение к цвету.

**Роли:** Владелец заметки, Участник общей заметки (для личного отображения)

**Предусловия:**
- Заметка существует
- Пользователь имеет доступ к заметке

**Основной сценарий:**

1. Пользователь открывает заметку
2. Нажимает на иконку палитры (🎨) внизу заметки
3. Система отображает два ряда опций:
   - Верхний ряд: сплошные цвета
   - Нижний ряд: фоновые изображения
4. Пользователь свайпает/прокручивает нижний ряд для просмотра вариантов
5. Доступные категории фоновых изображений:
   - Продукты (Groceries)
   - Еда (Food)
   - Музыка (Music)
   - Рецепты (Recipes)
   - Заметки (Notes)
   - Места (Places)
   - Путешествия (Travel)
   - Видео (Video)
   - Праздник/Торжество (Celebration)
6. Пользователь выбирает фоновое изображение
7. Система применяет фон к заметке

**Альтернативные сценарии:**

- **AS-008-A:** Комбинация цвета и фона:
  1. Если выбрать и цвет, и фоновое изображение
  2. Верхняя часть заметки отображает изображение
  3. Нижняя часть заметки отображает выбранный цвет

- **AS-008-B:** Удаление фонового изображения:
  1. Открыть панель палитры
  2. Выбрать первую опцию (без фона/по умолчанию)

**Бизнес-правила:**
- BR-024: Фоновые изображения имеют приглушенные цвета для читаемости текста
- BR-025: Фоновое изображение персонально — соавторы не видят его
- BR-026: В темной теме фоновые изображения адаптируются к темному стилю
- BR-027: Фон отображается только в верхней части развернутой заметки

**Результат:** Заметка отображается с декоративным фоновым изображением, облегчающим визуальную идентификацию.

### FR-LABELS-009: Закрепление заметки

**Описание:** Пользователь может закрепить важную заметку, чтобы она всегда отображалась в верхней части списка заметок.

**Роли:** Владелец заметки, Участник общей заметки (для личного отображения)

**Предусловия:**
- Заметка существует
- Пользователь имеет доступ к заметке

**Основной сценарий:**

1. Пользователь открывает заметку
2. Нажимает на иконку канцелярской кнопки (📌) в верхней панели заметки
3. Система закрепляет заметку
4. Заметка перемещается в секцию "Закрепленные" вверху экрана
5. Иконка кнопки меняется на "закрепленную" (заполненная)

**Альтернативные сценарии:**

- **AS-009-A:** Закрепление без открытия заметки:
  1. Навести курсор на заметку в сетке
  2. Нажать иконку кнопки (📌) в углу заметки

- **AS-009-B:** Массовое закрепление:
  1. Выбрать несколько заметок (чекбоксы)
  2. Нажать иконку кнопки в панели инструментов
  3. Все выбранные заметки закрепляются

- **AS-009-C:** Закрепление на мобильном устройстве:
  1. Долгое нажатие на заметку
  2. Нажать иконку кнопки в появившейся панели

**Бизнес-правила:**
- BR-028: Закрепленные заметки всегда отображаются выше незакрепленных
- BR-029: Количество закрепленных заметок не ограничено
- BR-030: Закрепление персонально — соавторы не видят ваш статус закрепления
- BR-031: Закрепленные заметки группируются в секции "Закрепленные", остальные — в секции "Другие"
- BR-032: Внутри секции "Закрепленные" заметки сортируются по дате изменения (новые выше)

**Результат:** Заметка отображается в верхней части экрана в секции "Закрепленные" на всех устройствах пользователя.

---

### FR-LABELS-010: Открепление заметки

**Описание:** Пользователь может открепить ранее закрепленную заметку, вернув её в общий список.

**Роли:** Владелец заметки, Участник общей заметки

**Предусловия:**
- Заметка закреплена
- Пользователь имеет доступ к заметке

**Основной сценарий:**

1. Пользователь открывает закрепленную заметку
2. Нажимает на иконку заполненной кнопки (📌) в верхней панели
3. Система откреплять заметку
4. Заметка перемещается из секции "Закрепленные" в секцию "Другие"
5. Заметка занимает позицию согласно дате последнего изменения

**Альтернативные сценарии:**

- **AS-010-A:** Открепление без открытия — нажать на иконку кнопки, наведя курсор на закрепленную заметку в сетке

**Бизнес-правила:**
- BR-033: Открепление не влияет на метки, цвета или содержимое заметки
- BR-034: Откреплённая заметка сортируется по дате изменения среди других заметок

**Результат:** Заметка перемещена в общий список и более не отображается в секции "Закрепленные".

### FR-LABELS-011: Архивация заметки

**Описание:** Пользователь может архивировать заметку, скрыв её с главного экрана, но сохранив возможность доступа через раздел "Архив" или по меткам.

**Роли:** Владелец заметки, Участник общей заметки

**Предусловия:**
- Заметка существует и не удалена
- Заметка не находится в архиве

**Основной сценарий:**

1. Пользователь открывает заметку
2. Нажимает иконку архива (📥) в нижней панели заметки
3. Система перемещает заметку в архив
4. Заметка исчезает с главного экрана
5. Отображается уведомление "Заметка архивирована" с опцией "Отменить"

**Альтернативные сценарии:**

- **AS-011-A:** Архивация свайпом (мобильные):
  1. Свайп влево или вправо по заметке в списке
  2. Заметка архивируется

- **AS-011-B:** Массовая архивация:
  1. Выбрать несколько заметок
  2. Нажать иконку архива в панели инструментов
  3. Все выбранные заметки архивируются

- **AS-011-C:** Горячая клавиша (Desktop): нажать "E" при выбранной заметке

**Бизнес-правила:**
- BR-035: Архивированные заметки доступны через раздел "Архив" в боковом меню
- BR-036: Архивированные заметки отображаются в соответствующих метках (внизу списка)
- BR-037: Архивированные заметки участвуют в поиске
- BR-038: Архивация сохраняет все свойства заметки (метки, цвет, напоминания)
- BR-039: Архивированные заметки можно редактировать

**Результат:** Заметка скрыта с главного экрана, но доступна через раздел "Архив" и при фильтрации по меткам.

### FR-LABELS-012: Разархивация заметки

### FR-LABELS-013: Изменение порядка заметок

**Описание:** Пользователь может изменять порядок отображения заметок путем перетаскивания.

**Роли:** Владелец заметки

**Предусловия:**
- На главном экране есть несколько заметок
- Пользователь находится на главном экране (не в режиме метки)

**Основной сценарий:**

1. Пользователь наводит курсор на заметку в режиме сетки
2. Зажимает и удерживает заметку (клик + удержание)
3. Перетаскивает заметку в новое положение
4. Другие заметки сдвигаются, освобождая место
5. Пользователь отпускает заметку
6. Новый порядок сохраняется

**Альтернативные сценарии:**

- **AS-013-A:** В режиме списка — перетаскивание аналогично, но заметки выстраиваются вертикально
- **AS-013-B:** На мобильных устройствах — долгое нажатие для активации режима перетаскивания

**Бизнес-правила:**
- BR-042: Ручная сортировка работает только на главном экране ("Заметки")
- BR-043: В режиме фильтрации по метке ручная сортировка недоступна
- BR-044: Закрепленные заметки перетаскиваются только внутри секции "Закрепленные"
- BR-045: Незакрепленные заметки перетаскиваются только внутри секции "Другие"
- BR-046: Пользовательский порядок сохраняется при синхронизации

**Результат:** Заметки отображаются в новом порядке, заданном пользователем.

### FR-LABELS-014: Переключение вида отображения

**Описание:** Пользователь может переключаться между режимами отображения заметок: сетка и список.

**Роли:** Владелец заметки, Участник общей заметки

**Предусловия:**
- Пользователь авторизован
- На экране есть заметки

**Основной сценарий:**

1. Пользователь находится на главном экране или в разделе меток
2. Нажимает иконку переключения вида в верхней панели:
   - Иконка сетки (⊞) — для списочного вида
   - Иконка списка (☰) — для сеточного вида
3. Система переключает режим отображения
4. Заметки перестраиваются согласно новому виду

**Альтернативные сценарии:**

- **AS-014-A:** Горячая клавиша: Ctrl/Cmd + G для переключения вида

**Бизнес-правила:**
- BR-047: Режим сетки: заметки отображаются в несколько колонок, компактно
- BR-048: Режим списка: заметки отображаются в одну колонку, полная ширина
- BR-049: Выбранный режим сохраняется между сессиями
- BR-050: Режим применяется ко всем разделам (заметки, метки, архив)

**Результат:** Заметки отображаются в выбранном режиме (сетка или список).

### FR-LABELS-015: Поиск заметок

**Описание:** Пользователь может искать заметки по тексту, меткам, цветам, типу контента и другим параметрам.

**Роли:** Владелец заметки, Участник общей заметки

**Предусловия:**
- Пользователь авторизован
- Существуют заметки для поиска

**Основной сценарий:**

1. Пользователь нажимает на поисковую строку "Поиск заметок"
2. Система отображает панель быстрых фильтров:
   - **Типы**: Напоминания, Записи, URL, Изображения
   - **Метки**: Список всех меток пользователя
   - **Категории**: Книги, Музыка, Путешествия и др.
   - **Люди**: Соавторы заметок
   - **Цвета**: Палитра из 12 цветов
3. Пользователь может:
   - Ввести текст для поиска
   - Нажать на быстрый фильтр
   - Комбинировать текст и фильтры
4. Система отображает результаты в реальном времени
5. Заметки, соответствующие критериям, отображаются в списке результатов

**Альтернативные сценарии:**

- **AS-015-A:** Поиск текста на изображениях — Google Keep распознает текст на фотографиях и включает его в поиск
- **AS-015-B:** Поиск по нескольким критериям — например, "работа" + синий цвет

**Бизнес-правила:**
- BR-051: Поиск охватывает заголовки, текст, списки и распознанный текст на изображениях
- BR-052: Поиск включает как активные, так и архивированные заметки
- BR-053: Поиск регистронезависимый
- BR-054: Результаты сортируются по релевантности
- BR-055: Удаленные заметки (в корзине) не участвуют в поиске

**Результат:** Отображается список заметок, соответствующих критериям поиска.

# Списки и чек-листы

## Описание

Модуль "Списки и чек-листы" является одной из ключевых функциональностей Google Keep, позволяющей пользователям создавать структурированные списки задач с возможностью отметки выполнения. Списки поддерживают иерархическую структуру с одним уровнем вложенности, drag-and-drop перетаскивание элементов, автоматическую группировку выполненных пунктов, а также совместную работу нескольких пользователей в реальном времени.

Модуль интегрирован с AI-функцией "Magic Lists" (Помощь в создании списка), которая использует Gemini для автоматической генерации списков на основе текстового описания пользователя.

## Роли пользователей

| Роль | Описание | Права доступа |
|------|----------|---------------|
| **Владелец** | Пользователь, создавший заметку-список | Полный доступ: создание, редактирование, удаление, архивирование, добавление/удаление соавторов, настройка напоминаний |
| **Соавтор (Collaborator)** | Пользователь, получивший доступ к списку от владельца | Чтение, добавление/редактирование/удаление пунктов, отметка выполнения. Не может удалить заметку для всех, только покинуть совместную работу |
| **Только просмотр** | Пользователь, просматривающий общий семейный список без редактирования | Только чтение (для семейных групп Google) |

## Функциональные требования

### FR-LISTS-001: Создание нового списка

**Описание:** Пользователь может создать новую заметку в формате списка с чекбоксами для отметки выполнения пунктов.

**Роли:** Владелец

**Предусловия:**
- Пользователь авторизован в Google Keep
- Пользователь находится на главной странице или в разделе заметок

**Основной сценарий:**
1. Пользователь нажимает на иконку чек-листа (галочка в квадрате) в поле "Заметка..."
2. Система создает пустую заметку с полем для заголовка и первым пустым пунктом списка
3. Пользователь опционально вводит заголовок списка
4. Пользователь вводит текст первого пункта
5. Пользователь нажимает Enter для перехода к следующему пункту
6. Система создает новый пустой пункт списка
7. Пользователь повторяет шаги 4-6 для добавления остальных пунктов
8. Пользователь нажимает вне области заметки или кнопку "Закрыть"
9. Система сохраняет список

**Альтернативные сценарии:**

*A1: Создание списка через меню существующей заметки*
1. Пользователь открывает текстовую заметку
2. Пользователь нажимает на меню (три точки)
3. Пользователь выбирает "Показать флажки"
4. Система преобразует каждую строку текста в отдельный пункт списка с чекбоксом

*A2: Создание списка с помощью AI (Magic Lists)*
1. Пользователь нажимает кнопку "Помощь в создании списка"
2. Пользователь вводит описание желаемого списка (например, "Список вещей для кемпинга на семью из 4 человек")
3. Система отправляет запрос в Gemini AI
4. AI генерирует структурированный список пунктов
5. Система создает заметку-список с сгенерированными пунктами
6. Пользователь может редактировать полученный список

*A3: Отмена создания*
1. Пользователь нажимает вне области заметки, не введя ни одного пункта
2. Система не сохраняет пустую заметку

**Бизнес-правила:**
- BR-001: Новый пункт создается при нажатии Enter в конце текущего пункта
- BR-002: Пустые пункты автоматически удаляются при сохранении заметки
- BR-003: Magic Lists доступна только для пользователей с Google Pixel или подпиской Google One AI Premium
- BR-004: Заголовок списка опционален
- BR-005: Позиция новых пунктов (вверху или внизу списка) определяется глобальной настройкой пользователя

**Результат:** Создана новая заметка-список с чекбоксами, доступная для просмотра и редактирования.

### FR-LISTS-002: Добавление пунктов в существующий список

**Описание:** Пользователь может добавлять новые пункты в уже созданный список.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка в формате списка
- Пользователь имеет права на редактирование

**Основной сценарий:**
1. Пользователь открывает заметку-список
2. Пользователь нажимает на поле "+ Элемент списка" (в конце или начале списка, в зависимости от настроек)
3. Пользователь вводит текст нового пункта
4. Система сохраняет новый пункт
5. Пользователь нажимает Enter для добавления следующего пункта или нажимает вне области

**Альтернативные сценарии:**

*A1: Добавление пункта между существующими*
1. Пользователь устанавливает курсор в конец любого пункта списка
2. Пользователь нажимает Enter
3. Система создает новый пустой пункт непосредственно под текущим
4. Пользователь вводит текст нового пункта

*A2: Добавление пункта в начало списка*
1. Пользователь устанавливает курсор в начало первого пункта
2. Пользователь нажимает Enter
3. Система создает новый пункт и сдвигает существующий первый пункт вниз

**Бизнес-правила:**
- BR-006: Положение поля "+ Элемент списка" (вверху или внизу) определяется настройкой "Добавлять новые элементы снизу"
- BR-007: Изменения синхронизируются в реальном времени для всех соавторов
- BR-008: Максимальная длина текста пункта ограничена общим лимитом заметки (20,000 символов)

**Результат:** Новый пункт добавлен в список в указанной позиции.

### FR-LISTS-003: Отметка выполнения пункта

**Описание:** Пользователь может отмечать пункты списка как выполненные, нажимая на чекбокс.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с невыполненными пунктами
- Пользователь имеет права на редактирование

**Основной сценарий:**
1. Пользователь нажимает на пустой чекбокс рядом с пунктом
2. Система отмечает чекбокс как выполненный (галочка)
3. Текст пункта перечеркивается
4. Если включена настройка "Перемещать отмеченные элементы вниз":
   - Пункт перемещается в раздел "Отмеченные элементы" внизу списка
5. Система сохраняет изменение

**Альтернативные сценарии:**

*A1: Отметка родительского пункта с подпунктами*
1. Пользователь нажимает на чекбокс родительского пункта (имеющего вложенные элементы)
2. Система отмечает как выполненный родительский пункт
3. Система автоматически отмечает все вложенные подпункты как выполненные
4. Вся группа (родитель + подпункты) перемещается в раздел "Отмеченные элементы"

*A2: Отметка только подпункта*
1. Пользователь нажимает на чекбокс вложенного подпункта
2. Система отмечает только этот подпункт как выполненный
3. Подпункт перемещается в раздел "Отмеченные элементы", но остается в иерархии под заголовком родительского пункта

*A3: Настройка отключена - элементы остаются на месте*
1. Пользователь нажимает на чекбокс
2. Система отмечает пункт как выполненный
3. Пункт остается на своем месте в списке (не перемещается)
4. Текст перечеркивается

**Бизнес-правила:**
- BR-009: Визуальное оформление выполненного пункта: галочка в чекбоксе + зачеркнутый текст
- BR-010: Поведение при отметке (перемещать вниз или оставлять на месте) определяется настройкой "Перемещать отмеченные элементы вниз"
- BR-011: При отметке родительского элемента автоматически отмечаются все его дочерние элементы
- BR-012: Отметка дочернего элемента не влияет на статус родительского

**Результат:** Пункт отмечен как выполненный, визуально обозначен и опционально перемещен в раздел выполненных.

---

### FR-LISTS-004: Снятие отметки выполнения

**Описание:** Пользователь может снять отметку выполнения с ранее отмеченного пункта.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует пункт списка, отмеченный как выполненный

**Основной сценарий:**
1. Пользователь нажимает на отмеченный чекбокс (с галочкой)
2. Система снимает отметку выполнения
3. Текст пункта перестает быть зачеркнутым
4. Если настройка перемещения включена:
   - Пункт возвращается из раздела "Отмеченные элементы" в основной список
   - Пункт помещается в конец невыполненных элементов

**Альтернативные сценарии:**

*A1: Снятие отметки с родительского пункта*
1. Пользователь нажимает на отмеченный чекбокс родительского пункта
2. Система снимает отметку с родительского пункта
3. Система автоматически снимает отметки со всех дочерних подпунктов
4. Вся группа возвращается в основной список

**Бизнес-правила:**
- BR-013: При снятии отметки с родителя автоматически снимаются отметки со всех дочерних элементов
- BR-014: Снятие отметки с дочернего элемента не влияет на статус других элементов

**Результат:** Отметка выполнения снята, пункт возвращен в активное состояние.

### FR-LISTS-005: Перетаскивание и изменение порядка пунктов (Drag & Drop)

**Описание:** Пользователь может изменять порядок пунктов списка путем перетаскивания.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с двумя и более пунктами

**Основной сценарий (веб/десктоп):**
1. Пользователь наводит курсор на пункт списка
2. Слева от пункта появляется иконка перетаскивания (шесть точек)
3. Пользователь нажимает и удерживает иконку
4. Пользователь перетаскивает пункт в желаемую позицию
5. Система отображает визуальный индикатор места вставки
6. Пользователь отпускает кнопку мыши
7. Система перемещает пункт в новую позицию и сохраняет изменения

**Альтернативные сценарии:**

*A1: Перетаскивание на мобильном устройстве*
1. Иконка перетаскивания (шесть точек) всегда видна рядом с каждым пунктом
2. Пользователь нажимает и удерживает иконку
3. Пользователь перетаскивает пункт в новое место
4. Пользователь отпускает палец
5. Система сохраняет новый порядок

*A2: Перетаскивание пункта с подпунктами*
1. Пользователь перетаскивает родительский пункт
2. Система перемещает родительский пункт вместе со всеми его дочерними элементами

*A3: Отмена перетаскивания*
1. Пользователь начинает перетаскивание
2. Пользователь перемещает элемент за пределы списка или отпускает в недопустимой зоне
3. Система возвращает элемент на исходную позицию

**Бизнес-правила:**
- BR-015: Иконка перетаскивания на десктопе появляется при наведении курсора
- BR-016: Иконка перетаскивания на мобильных устройствах всегда видима
- BR-017: При перетаскивании родительского элемента дочерние перемещаются вместе с ним
- BR-018: Нельзя переместить невыполненный пункт в раздел "Отмеченные элементы" и наоборот (только через изменение статуса)

**Результат:** Порядок пунктов в списке изменен согласно действиям пользователя.

### FR-LISTS-006: Создание вложенных пунктов (отступы/иерархия)

**Описание:** Пользователь может создавать иерархическую структуру списка с одним уровнем вложенности.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с минимум двумя пунктами

**Основной сценарий (веб/десктоп - перетаскивание):**
1. Пользователь наводит курсор на пункт, который хочет сделать подпунктом
2. Пользователь нажимает и удерживает иконку перетаскивания
3. Пользователь перетаскивает пункт вправо под другой пункт
4. Система отображает визуальный индикатор вложенности
5. Пользователь отпускает кнопку мыши
6. Система делает пункт вложенным (с отступом) под вышестоящим пунктом

**Альтернативные сценарии:**

*A1: Создание отступа с помощью клавиатуры (веб/десктоп)*
1. Пользователь устанавливает курсор в нужный пункт
2. Пользователь нажимает Ctrl + ]
3. Система добавляет отступ, делая пункт вложенным под вышестоящим элементом

*A2: Создание отступа свайпом (мобильное устройство)*
1. Пользователь выполняет свайп вправо по пункту
2. Система делает пункт вложенным под вышестоящим элементом

*A3: Удаление отступа перетаскиванием (веб/десктоп)*
1. Пользователь перетаскивает вложенный пункт влево
2. Система убирает вложенность, делая пункт обычным элементом списка

*A4: Удаление отступа клавиатурой (веб/десктоп)*
1. Пользователь нажимает Ctrl + [
2. Система убирает вложенность с текущего пункта

*A5: Удаление отступа свайпом (мобильное устройство)*
1. Пользователь выполняет свайп влево по вложенному пункту
2. Система убирает вложенность

**Бизнес-правила:**
- BR-019: Максимальный уровень вложенности - 1 (подпункты не могут иметь собственных подпунктов)
- BR-020: Вложенные пункты группируются с первым невложенным пунктом над ними (родителем)
- BR-021: Отступ визуально обозначается сдвигом пункта вправо
- BR-022: Нельзя сделать первый пункт списка вложенным (нет родителя)

**Результат:** Создана иерархическая структура с родительским пунктом и вложенными подпунктами.

### FR-LISTS-007: Редактирование текста пункта

**Описание:** Пользователь может изменять текст существующего пункта списка.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с пунктами

**Основной сценарий:**
1. Пользователь нажимает на текст пункта
2. Система активирует режим редактирования (появляется курсор)
3. Пользователь вносит изменения в текст
4. Пользователь нажимает Enter или нажимает вне области пункта
5. Система сохраняет изменения

**Альтернативные сценарии:**

*A1: Редактирование выполненного пункта*
1. Пользователь нажимает на перечеркнутый текст выполненного пункта
2. Система активирует редактирование (курсор внутри зачеркнутого текста)
3. Пользователь вносит изменения
4. Статус выполнения сохраняется

**Бизнес-правила:**
- BR-023: Редактирование не влияет на статус выполнения пункта
- BR-024: Изменения синхронизируются в реальном времени для соавторов

**Результат:** Текст пункта обновлен.

---

### FR-LISTS-008: Удаление пункта списка

**Описание:** Пользователь может удалить отдельный пункт из списка.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с пунктами

**Основной сценарий:**
1. Пользователь нажимает на пункт для редактирования
2. Пользователь выделяет весь текст и удаляет его (или использует Backspace)
3. Пользователь нажимает Backspace еще раз на пустом пункте
4. Система удаляет пустой пункт из списка

**Альтернативные сценарии:**

*A1: Удаление пункта через курсор в начале*
1. Пользователь устанавливает курсор в начало текста пункта
2. Пользователь нажимает Backspace
3. Текст текущего пункта объединяется с предыдущим пунктом

**Бизнес-правила:**
- BR-025: Пустые пункты автоматически удаляются
- BR-026: Удаление родительского пункта не удаляет автоматически его подпункты (они становятся обычными пунктами или присоединяются к предыдущему родителю)

**Результат:** Пункт удален из списка.

### FR-LISTS-009: Массовое снятие отметок (Uncheck all)

**Описание:** Пользователь может снять отметки выполнения со всех пунктов списка одновременно.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с отмеченными (выполненными) пунктами

**Основной сценарий:**
1. Пользователь открывает заметку-список
2. Пользователь нажимает на меню (три точки) в нижней части заметки
3. Пользователь выбирает "Снять все флажки" (Uncheck all items)
4. Система снимает отметки со всех выполненных пунктов
5. Все пункты перемещаются из раздела "Отмеченные элементы" в основной список
6. Зачеркивание текста убирается

**Альтернативные сценарии:**

*A1: Опция недоступна*
1. В списке нет выполненных пунктов
2. Опция "Снять все флажки" в меню неактивна или отсутствует

**Бизнес-правила:**
- BR-027: Функция полезна для повторяющихся списков (ежедневные задачи, еженедельные покупки)
- BR-028: Порядок пунктов после снятия отметок может измениться (все возвращаются в основной список)

**Результат:** Все пункты списка переведены в невыполненное состояние.

---

### FR-LISTS-010: Массовое удаление выполненных пунктов

**Описание:** Пользователь может удалить все выполненные пункты из списка одновременно.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с отмеченными (выполненными) пунктами

**Основной сценарий:**
1. Пользователь открывает заметку-список
2. Пользователь нажимает на меню (три точки)
3. Пользователь выбирает "Удалить отмеченные" (Delete checked items)
4. Система удаляет все пункты, отмеченные как выполненные
5. Раздел "Отмеченные элементы" очищается или исчезает

**Альтернативные сценарии:**

*A1: Опция недоступна*
1. В списке нет выполненных пунктов
2. Опция "Удалить отмеченные" в меню неактивна или отсутствует

**Бизнес-правила:**
- BR-029: Удаление необратимо (нет корзины для отдельных пунктов, только для целых заметок)
- BR-030: Удаляются все выполненные пункты, включая вложенные

**Результат:** Все выполненные пункты удалены из списка.

### FR-LISTS-011: Скрытие/показ раздела выполненных элементов

**Описание:** Пользователь может скрывать или показывать раздел с выполненными пунктами для фокусировки на невыполненных задачах.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Существует заметка-список с выполненными пунктами
- Настройка "Перемещать отмеченные элементы вниз" включена

**Основной сценарий:**
1. Внизу списка отображается раздел "Отмеченные элементы" со стрелкой
2. Пользователь нажимает на стрелку (или заголовок раздела)
3. Система сворачивает раздел, скрывая выполненные пункты
4. Отображается только заголовок "N отмеченных элементов"
5. Пользователь повторно нажимает на стрелку
6. Система разворачивает раздел, показывая все выполненные пункты

**Бизнес-правила:**
- BR-031: Состояние свернут/развернут сохраняется для каждой заметки индивидуально
- BR-032: Скрытые элементы остаются частью списка и могут быть восстановлены

**Результат:** Раздел выполненных элементов скрыт или показан.

### FR-LISTS-015: Совместная работа над списком

**Описание:** Владелец может пригласить других пользователей для совместного редактирования списка.

**Роли:** Владелец (для приглашения), Соавтор (для работы)

**Предусловия:**
- Существует заметка-список
- Пользователь является владельцем

**Основной сценарий:**
1. Пользователь открывает заметку-список
2. Пользователь нажимает на иконку соавтора (силуэт человека с плюсом)
3. Пользователь вводит email-адрес или выбирает контакт
4. Пользователь нажимает "Сохранить"
5. Система отправляет приглашение (или мгновенно добавляет, если пользователь Google)
6. Приглашенный пользователь получает доступ к списку
7. Изменения от любого соавтора синхронизируются в реальном времени

**Альтернативные сценарии:**

*A1: Добавление Google Group*
1. Пользователь вводит адрес Google Group
2. Все участники группы получают доступ

*A2: Совместный доступ для семейной группы*
1. Пользователь выбирает "Поделиться с семейной группой"
2. Все члены семейной группы Google получают доступ

*A3: Удаление соавтора*
1. Владелец открывает настройки соавторов
2. Владелец удаляет email соавтора
3. Соавтор теряет доступ к списку

**Бизнес-правила:**
- BR-044: Соавторы могут редактировать, но не могут удалить заметку для всех
- BR-045: Соавтор может только "покинуть" совместную заметку (удаляет для себя)
- BR-046: Изменения синхронизируются в реальном времени
- BR-047: Видно, какие соавторы добавлены (иконки аватаров)

**Результат:** Список доступен для совместного редактирования приглашенным пользователям.

### FR-LISTS-016: Настройки поведения списков

**Описание:** Пользователь может настраивать глобальное поведение списков через настройки приложения.

**Роли:** Все пользователи (для своего аккаунта)

**Предусловия:**
- Пользователь авторизован в Google Keep

**Основной сценарий:**
1. Пользователь открывает настройки (шестеренка в правом верхнем углу)
2. Пользователь находит раздел "Заметки и списки"
3. Пользователь настраивает параметры:
   - "Добавлять новые элементы снизу" (вкл/выкл)
   - "Перемещать отмеченные элементы вниз" (вкл/выкл)
4. Система применяет настройки ко всем спискам пользователя

**Бизнес-правила:**
- BR-048: Настройка "Добавлять новые элементы снизу":
  - Включено: новые пункты появляются внизу списка
  - Выключено: новые пункты появляются вверху списка
- BR-049: Настройка "Перемещать отмеченные элементы вниз":
  - Включено: выполненные пункты перемещаются в отдельный раздел внизу
  - Выключено: выполненные пункты остаются на своих местах
- BR-050: Настройки применяются глобально для всех списков пользователя

**Результат:** Настройки поведения списков изменены.

## Состояния и статусы

### Состояния пункта списка

```
[Не создан]
    │
    ▼ (создание)
[Невыполненный] ◄──────────────────────┐
    │                                   │
    │ (отметка чекбокса)                │ (снятие отметки)
    ▼                                   │
[Выполненный] ─────────────────────────►┘
    │
    │ (удаление / очистка)
    ▼
[Удален]
```

| Состояние | Описание | Визуальное отображение |
|-----------|----------|------------------------|
| **Невыполненный** | Пункт не отмечен | Пустой чекбокс, обычный текст |
| **Выполненный** | Пункт отмечен как выполненный | Галочка в чекбоксе, зачеркнутый текст, серый цвет |
| **Удален** | Пункт удален из списка | Не отображается |

### Состояния заметки-списка

| Состояние | Описание |
|-----------|----------|
| **Активная** | Заметка на главной странице |
| **Закрепленная** | Заметка прикреплена в верхней части |
| **Архивированная** | Заметка в архиве |
| **В корзине** | Заметка в корзине (удалится через 7 дней) |
| **Удалена** | Заметка окончательно удалена |

### Состояния раздела "Отмеченные элементы"

| Состояние | Описание |
|-----------|----------|
| **Развернут** | Все выполненные пункты видны |
| **Свернут** | Видна только строка "N отмеченных элементов" |
| **Отсутствует** | Нет выполненных пунктов или настройка отключена |

# Интеграции

## Описание

Модуль "Интеграции" обеспечивает взаимодействие Google Keep с другими продуктами и сервисами экосистемы Google, а также с внешними платформами. Модуль реализует бесшовную синхронизацию данных, обмен контентом между приложениями и расширение функциональности через дополнительные интерфейсы (Chrome Extension, виджеты, Wear OS). Ключевая особенность — единая экосистема Google Workspace, где заметки и напоминания доступны из Gmail, Calendar, Docs, Sheets, Slides, Tasks и Gemini.

## Роли пользователей

| Роль | Описание | Права доступа к интеграциям |
|------|----------|----------------------------|
| Владелец заметки | Пользователь, создавший заметку | Полный доступ ко всем интеграциям, экспорт в Docs, настройка виджетов, голосовые команды |
| Соавтор (Collaborator) | Пользователь с доступом к общей заметке | Просмотр и редактирование через интеграции, ограниченный экспорт |
| Viewer (только чтение) | Пользователь с правами просмотра | Просмотр через боковые панели, без экспорта и модификации |
| Google Workspace Admin | Администратор организации | Управление политиками интеграций, включение/отключение функций для домена |

### FR-INTEG-001: Интеграция с Google Docs — Копирование заметки в документ

**Описание:** Пользователь может скопировать содержимое заметки Google Keep в новый документ Google Docs одним действием. При копировании создается новый файл в Google Drive с полным содержимым заметки.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Заметка существует и доступна пользователю
- У пользователя есть достаточно места в Google Drive

**Основной сценарий:**
1. Пользователь открывает заметку в Google Keep
2. Пользователь нажимает на меню "Ещё" (три точки)
3. Пользователь выбирает пункт "Копировать в Google Документы"
4. Система создает новый документ Google Docs в корневой папке Drive
5. Система копирует заголовок заметки как название документа
6. Система копирует содержимое заметки (текст, списки, изображения)
7. Система открывает созданный документ в новой вкладке
8. Исходная заметка в Keep сохраняется без изменений

**Альтернативные сценарии:**
- **A1: Заметка содержит чек-листы** — Чек-листы конвертируются в маркированные списки с сохранением статуса (выполнено/не выполнено через зачеркивание)
- **A2: Заметка содержит изображения** — Изображения вставляются в документ с оригинальным разрешением
- **A3: Заметка содержит рисунки** — Рисунки экспортируются как встроенные изображения
- **A4: Ошибка создания документа** — Система показывает уведомление об ошибке, заметка остается неизменной
- **A5: Недостаточно места в Drive** — Система уведомляет о необходимости освободить место

**Бизнес-правила:**
- BR-001: Созданный документ не связан с исходной заметкой (изменения в одном не отражаются в другом)
- BR-002: Документ создается с правами доступа только для владельца
- BR-003: Название документа = заголовок заметки или "Заметка без названия" если заголовок пуст
- BR-004: Метаданные заметки (метки, цвет, напоминания) не копируются в документ
- BR-005: Аудиозаписи из заметок не переносятся в Docs

**Результат:** Создан новый документ Google Docs с содержимым заметки в Google Drive пользователя

### FR-INTEG-002: Интеграция с Google Docs — Боковая панель Keep в редакторе

**Описание:** В Google Docs, Sheets и Slides доступна боковая панель Google Keep, позволяющая просматривать заметки, создавать новые и добавлять содержимое заметок непосредственно в документ.

**Роли:** Все авторизованные пользователи

**Предусловия:**
- Пользователь редактирует документ в Google Docs/Sheets/Slides
- У пользователя есть доступ к Google Keep

**Основной сценарий:**
1. Пользователь открывает документ в Google Docs
2. Пользователь нажимает иконку Google Keep в правой боковой панели
3. Система отображает список заметок пользователя
4. Пользователь может:
   - Просматривать существующие заметки
   - Искать заметки по содержимому
   - Создавать новые заметки
   - Добавлять заметку в документ

**Альтернативные сценарии:**
- **A1: Добавление заметки в документ через меню** — Пользователь наводит курсор на заметку, нажимает меню (три точки), выбирает "Добавить в документ"
- **A2: Добавление заметки перетаскиванием** — Пользователь перетаскивает заметку из панели в нужное место документа
- **A3: Сохранение текста из документа в Keep** — Пользователь выделяет текст, нажимает ПКМ, выбирает "Сохранить в Keep"
- **A4: Фильтрация заметок** — Пользователь выбирает метку для фильтрации заметок в панели

**Бизнес-правила:**
- BR-006: Боковая панель доступна только в веб-версии Google Docs/Sheets/Slides
- BR-007: Изменения в заметках через панель синхронизируются с основным Keep
- BR-008: При добавлении заметки в документ вставляется содержимое, а не ссылка
- BR-009: Изображения из заметок добавляются в документ inline
- BR-010: Панель поддерживает темную тему при включенном dark mode в Docs

**Результат:** Пользователь может работать с заметками Keep не покидая редактор документов

### FR-INTEG-003: Интеграция с Google Calendar — Напоминания через Tasks

**Описание:** Напоминания, созданные в Google Keep, синхронизируются с Google Tasks и отображаются в Google Calendar. С 2025 года все напоминания Keep автоматически сохраняются как задачи Google Tasks.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google аккаунте
- Заметка существует
- Функция напоминаний включена для аккаунта

**Основной сценарий:**
1. Пользователь создает напоминание для заметки в Google Keep
2. Пользователь устанавливает дату и/или время напоминания
3. Система автоматически создает задачу в Google Tasks
4. Задача отображается в Google Calendar в разделе Tasks
5. При наступлении времени напоминания пользователь получает уведомление
6. Пользователь может отметить задачу выполненной в Keep, Tasks или Calendar

**Альтернативные сценарии:**
- **A1: Изменение напоминания в Keep** — Изменения синхронизируются в Tasks и Calendar в реальном времени
- **A2: Изменение задачи в Tasks** — Изменения отражаются в связанной заметке Keep
- **A3: Удаление напоминания** — Задача удаляется из Tasks и Calendar
- **A4: Повторяющееся напоминание** — Система создает серию задач согласно расписанию
- **A5: Просроченное напоминание** — Задача отмечается как просроченная, уведомление показывается повторно

**Бизнес-правила:**
- BR-011: Напоминания по местоположению (location-based) больше не поддерживаются с миграцией на Tasks
- BR-012: Для получения уведомлений необходимо приложение Google Calendar или Google Tasks
- BR-013: Keep больше не отправляет push-уведомления для напоминаний напрямую
- BR-014: Синхронизация напоминаний происходит в реальном времени
- BR-015: Выполнение задачи в любом приложении (Keep/Tasks/Calendar) синхронизируется везде

**Результат:** Единая система управления задачами и напоминаниями через Google Workspace

### FR-INTEG-004: Интеграция с Google Assistant — Голосовое создание заметок

**Описание:** Пользователь может создавать заметки и списки в Google Keep с помощью голосовых команд Google Assistant на смартфонах, умных колонках и других устройствах с поддержкой Assistant.

**Роли:** Все авторизованные пользователи

**Предусловия:**
- Google Keep установлен как провайдер заметок и списков в настройках Google Assistant
- Устройство поддерживает Google Assistant
- Пользователь авторизован в Google аккаунте

**Основной сценарий:**
1. Пользователь активирует Google Assistant ("Окей, Google" или "Hey Google")
2. Пользователь произносит команду для создания заметки
3. Google Assistant распознает речь и создает заметку в Google Keep
4. Assistant подтверждает создание заметки голосом
5. Заметка синхронизируется на все устройства пользователя

**Альтернативные сценарии:**
- **A1: Создание списка** — Пользователь говорит "Создай список [название]"
- **A2: Добавление элемента в список** — Пользователь говорит "Добавь [элемент] в список [название]"
- **A3: Удаление элемента из списка** — Пользователь говорит "Удали [элемент] из списка [название]"
- **A4: Озвучивание списка** — Пользователь говорит "Покажи/прочитай мой список [название]"
- **A5: Завершение диктовки** — Пользователь говорит "Готово" или "Это все"

**Бизнес-правила:**
- BR-016: Google Keep должен быть выбран как провайдер заметок в настройках Assistant
- BR-017: На умных колонках без экрана недоступен просмотр заметок ("Покажи мои заметки")
- BR-018: Голосовые команды работают на всех устройствах с Google Assistant (телефоны, колонки, дисплеи, часы)
- BR-019: Интеграция доступна для всех пользователей Google Workspace и личных аккаунтов
- BR-020: Диктуемый текст сохраняется как обычная текстовая заметка (не голосовая запись)

**Поддерживаемые голосовые команды:**
| Команда | Действие |
|---------|----------|
| "Сделай заметку" / "Take a note" | Создание новой заметки с диктовкой содержимого |
| "Создай список [название]" | Создание нового списка покупок/дел |
| "Добавь [элемент] в список [название]" | Добавление элемента в существующий список |
| "Удали [элемент] из списка [название]" | Удаление элемента из списка |
| "Покажи мои заметки" | Отображение списка заметок (только на устройствах с экраном) |
| "Прочитай мой список [название]" | Озвучивание содержимого списка |
| "Напомни мне [текст] в [время]" | Создание заметки с напоминанием |

**Результат:** Заметка или список создана в Google Keep и синхронизирована на все устройства

### FR-INTEG-005: Chrome Extension — Быстрое сохранение веб-контента

**Описание:** Расширение Google Keep для браузера Chrome позволяет сохранять веб-страницы, текст, изображения и ссылки в заметки Keep без открытия отдельной вкладки.

**Роли:** Все авторизованные пользователи

**Предусловия:**
- Браузер Chrome установлен
- Расширение Google Keep Chrome Extension установлено
- Пользователь авторизован в Google аккаунте в браузере

**Основной сценарий:**
1. Пользователь находится на веб-странице, которую хочет сохранить
2. Пользователь нажимает на иконку Google Keep в панели расширений
3. Система автоматически заполняет URL и заголовок страницы
4. Пользователь опционально добавляет текст и метки
5. Пользователь нажимает "Сохранить" или закрывает popup для автоматического сохранения
6. Заметка синхронизируется с Google Keep

**Альтернативные сценарии:**
- **A1: Сохранение выделенного текста** — Пользователь выделяет текст, ПКМ → "Сохранить выделение в Keep"
- **A2: Сохранение изображения** — Пользователь нажимает ПКМ на изображении → "Сохранить изображение в Keep"
- **A3: Создание пустой заметки** — ПКМ на иконке расширения → "Новая пустая заметка"
- **A4: Просмотр существующих заметок** — Клик на расширение открывает popup со списком заметок
- **A5: Добавление хэштега** — Пользователь вводит #метка для быстрого присвоения метки

**Бизнес-правила:**
- BR-021: С 5 декабря 2022 года заметки в Chrome Extension не сохраняются автоматически — требуется явное сохранение
- BR-022: При сохранении страницы создается заметка с URL, заголовком и превью изображения (если доступно)
- BR-023: Хэштег в тексте заметки автоматически конвертируется в метку Keep
- BR-024: Заметки, созданные в расширении, синхронизируются на все платформы (Web, Android, iOS, Wear OS)
- BR-025: Расширение работает в режиме offline, синхронизируя заметки при восстановлении соединения

**Функции popup расширения:**
| Функция | Описание |
|---------|----------|
| Сохранить страницу | Одним кликом сохранить URL, заголовок и превью |
| Добавить заметку | Написать текст к сохраняемой странице |
| Добавить метки | Присвоить существующие или создать новые метки |
| Поиск заметок | Искать по существующим заметкам в popup |
| Открыть в Keep | Переход к полной версии keep.google.com |

**Результат:** Веб-контент сохранен в Google Keep с возможностью быстрой организации

### FR-INTEG-006: Android Widget — Заметка на главном экране

**Описание:** Пользователь Android может добавить виджеты Google Keep на домашний экран для быстрого доступа к заметкам и создания новых.

**Роли:** Все пользователи Android

**Предусловия:**
- Устройство на базе Android
- Приложение Google Keep установлено
- Пользователь авторизован в Google аккаунте

**Основной сценарий:**
1. Пользователь удерживает палец на пустом месте домашнего экрана
2. Пользователь выбирает "Виджеты"
3. Пользователь прокручивает до виджетов Google Keep
4. Пользователь выбирает тип виджета и перетаскивает на экран
5. Пользователь настраивает виджет (выбирает заметку или параметры)
6. Виджет отображается на домашнем экране

**Альтернативные сценарии:**
- **A1: Виджет "Одна заметка"** — Пользователь выбирает конкретную заметку для отображения на экране
- **A2: Виджет "Список заметок" (3x2)** — Отображает последние заметки с превью
- **A3: Виджет "Быстрые действия" (3x1)** — Кнопки для создания заметки, списка, голосовой записи
- **A4: Редактирование с виджета** — Пользователь отмечает чекбокс прямо на виджете
- **A5: Изменение размера** — Пользователь изменяет размер виджета перетаскиванием границ

**Бизнес-правила:**
- BR-026: Виджет "Одна заметка" позволяет редактировать чек-листы прямо с домашнего экрана
- BR-027: Для редактирования текста требуется переход в приложение Keep
- BR-028: Виджеты обновляются в реальном времени при синхронизации
- BR-029: Цвет виджета соответствует цвету заметки в Keep
- BR-030: Один виджет = одна закрепленная заметка (для single-note widget)

**Типы виджетов Android:**
| Виджет | Размер | Функции |
|--------|--------|---------|
| Single Note | Гибкий | Отображение одной заметки, редактирование чек-листов |
| Note List (3x2) | 3x2 | Превью последних заметок, быстрый доступ |
| Quick Actions (3x1) | 3x1 | Кнопки создания: заметка, список, фото, голос, рисунок |

**Результат:** Заметки Google Keep доступны на домашнем экране Android с возможностью быстрого взаимодействия

### FR-INTEG-007: iOS Widget — Виджет для iPhone и iPad

**Описание:** Пользователи iOS могут добавить виджет Google Keep в Today View (панель уведомлений) для быстрого доступа к заметкам и создания новых.

**Роли:** Все пользователи iOS

**Предусловия:**
- Устройство iPhone/iPad с iOS 14+
- Приложение Google Keep установлено
- Пользователь авторизован в Google аккаунте

**Основной сценарий:**
1. Пользователь свайпает вниз от верхней части экрана (Notification Center)
2. Пользователь свайпает слева направо для открытия Today View
3. Пользователь нажимает "Изменить" в нижней части
4. Пользователь нажимает "+" рядом с Google Keep
5. Виджет добавляется в Today View
6. Пользователь нажимает "Готово"

**Альтернативные сценарии:**
- **A1: Компактный виджет** — Отображает только кнопки создания заметок
- **A2: Развернутый виджет** — Нажатие "Показать больше" отображает последние заметки
- **A3: Создание заметки из виджета** — Нажатие открывает Keep с формой новой заметки
- **A4: Переход к заметке** — Нажатие на заметку в виджете открывает ее в приложении

**Бизнес-правила:**
- BR-031: Виджет закрепленной одной заметки (single-note) недоступен на iOS — только на Android
- BR-032: Виджет Today View показывает до 5 последних заметок в развернутом режиме
- BR-033: Редактирование заметок с виджета невозможно — только просмотр и переход
- BR-034: Виджет поддерживает Dark Mode iOS
- BR-035: Виджет не поддерживает редактирование чек-листов напрямую (в отличие от Android)

**Результат:** Быстрый доступ к Google Keep из Today View на iOS устройствах

### FR-INTEG-008: Wear OS — Заметки на смарт-часах

**Описание:** Приложение Google Keep для Wear OS позволяет просматривать, создавать и редактировать заметки прямо на смарт-часах, включая голосовой ввод.

**Роли:** Все пользователи Wear OS

**Предусловия:**
- Смарт-часы с Wear OS (рекомендуется Wear OS 3+)
- Приложение Google Keep установлено на часах
- Часы синхронизированы с телефоном
- Пользователь авторизован в Google аккаунте

**Основной сценарий:**
1. Пользователь открывает приложение Google Keep на часах
2. Система отображает список заметок, синхронизированных с телефоном
3. Пользователь может просматривать содержимое заметок
4. Пользователь может создать новую заметку голосом или текстом
5. Изменения синхронизируются с телефоном и облаком

**Альтернативные сценарии:**
- **A1: Голосовой ввод** — Пользователь нажимает микрофон, диктует заметку
- **A2: Текстовый ввод** — Пользователь использует экранную клавиатуру или T9
- **A3: Отметка элемента списка** — Пользователь нажимает на чекбокс для отметки выполнения
- **A4: Просмотр напоминаний** — Пользователь видит заметки с напоминаниями
- **A5: Использование Tile** — Пользователь свайпает к Tile Keep для быстрого доступа

**Бизнес-правила:**

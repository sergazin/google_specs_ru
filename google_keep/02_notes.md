# Заметки

## Описание

Модуль "Заметки" является ядром сервиса Google Keep и предоставляет пользователям возможность создавать, редактировать, организовывать и хранить заметки различных типов. Модуль поддерживает мультимедийный контент: текст с форматированием, изображения, рисунки от руки и голосовые записи с автоматической транскрипцией.

Google Keep позиционируется как инструмент для быстрых заметок "в моменте" с мгновенной синхронизацией между всеми устройствами пользователя. Сервис занимает нишу между простыми приложениями для быстрых заметок и полнофункциональными органайзерами (такими как Evernote), делая акцент на простоте использования и интеграции с экосистемой Google.

**Ключевые характеристики модуля:**
- Поддержка различных типов контента в одной заметке
- Мгновенная синхронизация между устройствами (веб, Android, iOS, расширение Chrome)
- Интеграция с другими сервисами Google (Docs, Calendar, Assistant)
- Бесплатное использование без ограничений по количеству заметок
- Отсутствие влияния на лимит хранилища Google Drive

## Роли пользователей

### Владелец заметки (Owner)
- Создает заметку
- Имеет полный контроль над заметкой
- Может добавлять и удалять соавторов
- Может удалить заметку навсегда
- Может архивировать и восстанавливать заметку
- Устанавливает цвет, ярлыки и закрепление (видны только владельцу)

### Соавтор (Collaborator)
- Добавляется владельцем по email или через Google Group
- Может редактировать текст, списки, изображения, рисунки и аудиозаписи
- Видит изменения в реальном времени
- Может удалить заметку из своего представления
- НЕ видит цвета, ярлыки и закрепления владельца
- НЕ может добавлять других соавторов

### Член семейной группы (Family Member)
- Автоматически получает доступ к заметкам, которыми поделились с семейной группой
- Может редактировать и удалять заметки семейной группы
- Владелец может добавлять людей, не входящих в семейную группу

## Функциональные требования

### FR-NOTES-001: Создание текстовой заметки

**Описание:** Пользователь может создать новую текстовую заметку с заголовком и содержимым.

**Роли:** Владелец

**Предусловия:**
- Пользователь авторизован в Google-аккаунте
- Приложение открыто (веб, мобильное или расширение)

**Основной сценарий:**
1. Пользователь нажимает на поле "Заметка..." или кнопку "+" (FAB на мобильных)
2. Система открывает редактор новой заметки
3. Пользователь вводит заголовок (опционально)
4. Пользователь вводит текст заметки
5. Пользователь нажимает "Закрыть" или кликает вне заметки
6. Система автоматически сохраняет заметку
7. Заметка появляется в главном списке

**Альтернативные сценарии:**
- A1: Пользователь закрывает пустую заметку -> Заметка не сохраняется
- A2: Пользователь теряет соединение -> Заметка сохраняется локально и синхронизируется при восстановлении связи
- A3: Пользователь создает заметку через голосового ассистента -> Заметка создается с транскрипцией голоса

**Бизнес-правила:**
- BR-001: Заголовок не обязателен
- BR-002: Максимальная длина заметки — 19 999 символов
- BR-003: Заметка сохраняется автоматически при каждом изменении
- BR-004: Новая заметка получает белый цвет по умолчанию
- BR-005: Время создания фиксируется автоматически

**Результат:** Создана новая заметка, доступная на всех устройствах пользователя

### FR-NOTES-002: Редактирование заметки

**Описание:** Пользователь может изменить содержимое существующей заметки.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Заметка существует и не удалена
- Пользователь имеет доступ к заметке (владелец или соавтор)

**Основной сценарий:**
1. Пользователь открывает заметку кликом/тапом
2. Система открывает заметку в режиме редактирования
3. Пользователь изменяет заголовок и/или текст
4. Система автоматически сохраняет изменения
5. Пользователь закрывает заметку

**Альтернативные сценарии:**
- A1: Два соавтора редактируют одновременно -> Изменения синхронизируются в реальном времени
- A2: Пользователь редактирует offline -> Изменения синхронизируются при восстановлении связи

**Бизнес-правила:**
- BR-006: Автосохранение происходит при каждом изменении
- BR-007: История изменений доступна на веб-версии (базовая версия)
- BR-008: Информация о том, кто внес изменения, НЕ отображается

**Результат:** Заметка обновлена, изменения синхронизированы на всех устройствах

### FR-NOTES-003: Форматирование текста

**Описание:** Пользователь может применять форматирование к тексту заметки.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Заметка открыта в режиме редактирования
- Выделен текст для форматирования

**Основной сценарий:**
1. Пользователь выделяет текст в заметке
2. Система отображает панель форматирования
3. Пользователь выбирает тип форматирования
4. Система применяет форматирование к выделенному тексту
5. Изменения автоматически сохраняются

**Доступные опции форматирования:**
- **Полужирный (Bold)** — выделение текста жирным шрифтом
- **Курсив (Italic)** — наклонный шрифт
- **Подчеркивание (Underline)** — линия под текстом
- **Зачеркивание (Strikethrough)** — линия через текст
- **Заголовок 1 (H1)** — крупный заголовок
- **Заголовок 2 (H2)** — подзаголовок
- **Очистить форматирование** — удаление всех стилей

**Альтернативные сценарии:**
- A1: Веб-версия — кнопка с подчеркнутой "A" открывает панель форматирования
- A2: Мобильная версия — панель форматирования в настройках приложения

**Бизнес-правила:**
- BR-009: Форматирование ретроактивно применяется к ранее созданным заметкам
- BR-010: Ссылки (гиперссылки) в тексте НЕ поддерживаются
- BR-011: Форматирование синхронизируется между всеми платформами

**Результат:** Текст отформатирован согласно выбранным стилям

### FR-NOTES-004: Создание списка с чекбоксами

**Описание:** Пользователь может создать список задач с флажками (чекбоксами).

**Роли:** Владелец, Соавтор

**Предусловия:**
- Пользователь авторизован

**Основной сценарий:**
1. Пользователь нажимает "Новый список" или иконку списка
2. Система создает заметку с одним чекбоксом
3. Пользователь вводит элемент списка
4. При нажатии Enter создается новый элемент
5. Пользователь добавляет необходимое количество элементов
6. Заметка сохраняется автоматически

**Альтернативные сценарии:**
- A1: Преобразование существующей заметки в список:
  1. Пользователь открывает текстовую заметку
  2. Нажимает меню (три точки) -> "Показать флажки"
  3. Система добавляет чекбокс к каждой строке
- A2: Преобразование списка обратно в текст:
  1. Пользователь нажимает меню -> "Скрыть флажки"
  2. Чекбоксы удаляются, текст сохраняется

**Бизнес-правила:**
- BR-012: Отмеченные элементы зачеркиваются и перемещаются вниз списка
- BR-013: Повторное нажатие на чекбокс возвращает элемент в основной список
- BR-014: Поддерживается два уровня вложенности (основные и подпункты)
- BR-015: Настройка: новые элементы добавляются сверху или снизу списка
- BR-016: Элементы можно перетаскивать для изменения порядка (drag-and-drop)

**Результат:** Создан список с интерактивными чекбоксами

### FR-NOTES-005: Управление элементами списка

**Описание:** Пользователь может манипулировать элементами списка: переупорядочивать, вкладывать, отмечать.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Заметка содержит список с чекбоксами

**Основной сценарий перестановки:**
1. Пользователь наводит курсор на элемент списка
2. Появляется иконка с шестью точками (drag handle)
3. Пользователь захватывает иконку и перетаскивает элемент
4. Элемент занимает новую позицию

**Сценарий создания вложенного элемента:**
1. Пользователь захватывает элемент за drag handle
2. Перетаскивает элемент вправо
3. Элемент становится подпунктом предыдущего элемента

**Сценарий отметки выполнения:**
1. Пользователь нажимает на чекбокс элемента
2. Элемент зачеркивается
3. Элемент перемещается в раздел "Отмеченные" внизу списка

**Бизнес-правила:**
- BR-017: Максимум два уровня вложенности
- BR-018: При отметке родительского элемента дочерние НЕ отмечаются автоматически
- BR-019: Отмеченные элементы группируются отдельно от неотмеченных

**Результат:** Список реорганизован согласно действиям пользователя

### FR-NOTES-006: Добавление изображения в заметку

**Описание:** Пользователь может прикрепить изображения к заметке.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Заметка существует или создается новая
- На устройстве есть изображения или доступна камера

**Основной сценарий (добавление из галереи):**
1. Пользователь открывает заметку или создает новую
2. Нажимает иконку "+" (на мобильном) или иконку изображения
3. Выбирает "Добавить изображение"
4. Система открывает галерею устройства
5. Пользователь выбирает изображение
6. Изображение добавляется в заметку

**Сценарий (съемка фото):**
1. Пользователь нажимает "+" -> "Сделать фото"
2. Система открывает камеру
3. Пользователь делает снимок
4. Фото добавляется в заметку

**Альтернативные сценарии:**
- A1: Создание заметки с изображением через виджет камеры
- A2: Drag-and-drop изображения в веб-версии

**Бизнес-правила:**
- BR-020: Максимум 20 000 изображений на аккаунт
- BR-021: Изображения НЕ учитываются в лимите Google Drive
- BR-022: Поддерживаются форматы: JPG, PNG, GIF, WebP
- BR-023: Одна заметка может содержать несколько изображений
- BR-024: Изображения отображаются в превью заметки

**Результат:** Изображение прикреплено к заметке и синхронизировано

### FR-NOTES-007: Распознавание текста на изображении (OCR)

**Описание:** Система может извлечь текст из изображения и добавить его в заметку как редактируемый текст.

**Роли:** Владелец, Соавтор

**Предусловия:**
- В заметке есть изображение с текстом

**Основной сценарий:**
1. Пользователь открывает заметку с изображением
2. Нажимает на изображение для просмотра
3. Выбирает "Распознать текст" / "Grab Image Text"
4. Система анализирует изображение с помощью OCR
5. Распознанный текст добавляется в тело заметки
6. Текст становится редактируемым и доступным для поиска

**Альтернативные сценарии:**
- A1: Текст не распознан -> Система уведомляет об ошибке
- A2: Частичное распознавание -> Добавляется то, что удалось распознать

**Бизнес-правила:**
- BR-025: OCR поддерживает множество языков
- BR-026: Распознанный текст добавляется в конец заметки
- BR-027: Исходное изображение сохраняется
- BR-028: Распознанный текст индексируется для поиска

**Результат:** Текст с изображения доступен как редактируемый контент

### FR-NOTES-008: Создание рисунка от руки

**Описание:** Пользователь может создать рисунок или рукописную заметку.

**Роли:** Владелец, Соавтор

**Предусловия:**
- Устройство поддерживает ввод (сенсорный экран, стилус или мышь)

**Основной сценарий:**
1. Пользователь нажимает иконку кисти/рисунка или "+" -> "Рисунок"
2. Система открывает холст для рисования
3. Пользователь выбирает инструмент рисования:
   - Ручка (разные толщины и цвета)
   - Маркер
   - Выделитель
   - Ластик
4. Пользователь рисует на холсте
5. Нажимает "Готово" / стрелку назад
6. Рисунок сохраняется как часть заметки

**Альтернативные сценарии:**
- A1: Добавление рисунка к существующей заметке
- A2: Комбинирование рисунка с текстом и изображениями

**Бизнес-правила:**
- BR-029: Рисование поддерживается пальцем и стилусом
- BR-030: Доступен выбор цветов и толщины линий
- BR-031: Рисунки можно экспортировать как изображения для шаринга
- BR-032: OCR работает с рукописным текстом в рисунках
- BR-033: В разработке: режим рукописного ввода с экспортом в PDF

**Результат:** Рисунок сохранен в заметке

**Роли:** Владелец

**Предусловия:**
- Устройство имеет микрофон
- Предоставлено разрешение на запись аудио

**Основной сценарий:**
1. Пользователь нажимает иконку микрофона (в виджете или "+" -> "Запись")
2. Система начинает запись аудио
3. Пользователь говорит
4. Запись автоматически останавливается при паузе или пользователь нажимает "Стоп"
5. Система транскрибирует аудио в текст
6. Создается заметка с:
   - Текстовой транскрипцией
   - Аудиофайлом для воспроизведения

**Альтернативные сценарии:**
- A1: Создание голосовой заметки через Google Assistant
- A2: Ошибка распознавания -> Сохраняется только аудиофайл

**Бизнес-правила:**
- BR-034: Аудиозапись сохраняется вместе с транскрипцией
- BR-035: Транскрипцию можно редактировать вручную
- BR-036: Аудио можно прослушать в любой момент
- BR-037: Транскрипция индексируется для поиска
- BR-038: Ограничение только на запись аудио (без транскрипции) НЕ поддерживается

**Результат:** Создана заметка с аудиозаписью и текстовой транскрипцией

### FR-NOTES-012: Добавление ярлыков к заметке

2. Нажимает меню (три точки) -> "Добавить ярлык"
3. Система отображает список существующих ярлыков

1. Пользователь вводит название нового ярлыка

**Бизнес-правила:**
- BR-047: Максимум 50 ярлыков на аккаунт
- BR-048: Одна заметка может иметь несколько ярлыков
- BR-049: Ярлыки видны только владельцу
- BR-050: Подпапки/иерархия ярлыков НЕ поддерживаются нативно
- BR-051: Можно имитировать иерархию: "Работа/Проект1", "Работа/Проект2"

## Состояния и статусы

### Состояния заметки

```
                    ┌─────────────┐
                    │   ACTIVE    │ (Главный экран)
                    └──────┬──────┘
                           │
           ┌───────────────┼───────────────┐
           │               │               │
           ▼               ▼               ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │  PINNED  │    │ ARCHIVED │    │ DELETED  │
    └──────────┘    └──────────┘    └────┬─────┘
           │               │              │
           │               │              │ (7 дней)
           └───────────────┼──────────────│
                           │              ▼
                           │       ┌──────────────┐
                           │       │ PERMANENTLY  │
                           │       │   DELETED    │
                           │       └──────────────┘
                           ▼
                    ┌─────────────┐
                    │   ACTIVE    │ (при разархивировании)
                    └─────────────┘
```

| Состояние | Описание | Переходы |
|-----------|----------|----------|
| ACTIVE | Заметка на главном экране | -> PINNED, ARCHIVED, DELETED |
| PINNED | Закреплена вверху экрана | -> ACTIVE, ARCHIVED, DELETED |
| ARCHIVED | В архиве, скрыта с главного экрана | -> ACTIVE, DELETED |
| DELETED | В корзине, ожидает удаления | -> ACTIVE, ARCHIVED, PERMANENTLY_DELETED |
| PERMANENTLY_DELETED | Удалена навсегда | (финальное состояние) |

### Состояния элемента списка

| Состояние | Описание |
|-----------|----------|
| UNCHECKED | Не выполнен, в основном списке |
| CHECKED | Выполнен, зачеркнут, внизу списка |

### Состояния напоминания

| Состояние | Описание |
|-----------|----------|
| PENDING | Ожидает срабатывания |
| TRIGGERED | Сработало, показано уведомление |
| SNOOZED | Отложено |
| COMPLETED | Выполнено/удалено |

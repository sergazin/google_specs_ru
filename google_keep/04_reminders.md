# Напоминания

## Описание

Модуль "Напоминания" в Google Keep предоставляет пользователям возможность получать уведомления о заметках в определенное время или при достижении определенного местоположения. Напоминания являются ключевой функцией для трансформации простых заметок в активные задачи с временной привязкой.

**Важное обновление (2024-2025):** Во второй половине 2025 года Google осуществляет миграцию напоминаний из Google Keep в Google Tasks. Это означает:
- Новые напоминания автоматически сохраняются как задачи в Google Tasks
- Уведомления приходят через Google Tasks, Google Calendar или Gemini, а не напрямую из Keep
- Геолокационные напоминания более не поддерживаются (функция удалена)
- Напоминания синхронизируются между Keep, Tasks, Calendar и Gemini

### Типы напоминаний

1. **Напоминания по времени** — срабатывают в указанную дату и время
2. **Повторяющиеся напоминания** — срабатывают по расписанию (ежедневно, еженедельно, ежемесячно, ежегодно)
3. **Напоминания по местоположению** *(устаревшая функция)* — срабатывали при приближении к указанному месту

## Роли пользователей

| Роль | Описание | Права доступа |
|------|----------|---------------|
| **Владелец заметки** | Пользователь, создавший заметку | Полный доступ: создание, редактирование, удаление напоминаний |
| **Соавтор (Collaborator)** | Пользователь, приглашенный к совместной работе над заметкой | Просмотр напоминаний, получение уведомлений о напоминаниях, создание собственных напоминаний для заметки |
| **Гость с ограниченным доступом** | Пользователь со ссылкой на заметку (если поддерживается) | Только просмотр, без доступа к напоминаниям |

## Функциональные требования

### FR-REMIND-001: Создание напоминания по времени

**Описание:** Пользователь может установить напоминание для заметки, указав конкретную дату и время срабатывания.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Пользователь авторизован в Google Keep
- Существует заметка (новая или ранее созданная)
- Пользователь имеет доступ к редактированию заметки

**Основной сценарий:**
1. Пользователь открывает заметку
2. Нажимает на иконку колокольчика (Reminder)
3. Система отображает панель выбора напоминания
4. Пользователь выбирает "Pick date & time" (Выбрать дату и время)
5. Система показывает календарь и выбор времени
6. Пользователь выбирает дату
7. Пользователь выбирает время
8. Пользователь нажимает "Save" (Сохранить)
9. Система сохраняет напоминание и отображает его на заметке
10. Напоминание синхронизируется с Google Tasks и Calendar

**Альтернативные сценарии:**

*A1: Использование быстрых опций времени*
1. После шага 3 пользователь выбирает одну из быстрых опций:
   - "Later today" — сегодня вечером (18:00)
   - "Tomorrow" — завтра утром (08:00)
   - "Next week" — следующий понедельник утром
2. Система автоматически устанавливает соответствующие дату и время
3. Продолжение с шага 9

*A2: Отмена создания напоминания*
1. На любом шаге пользователь нажимает за пределами панели или кнопку отмены
2. Система закрывает панель без сохранения
3. Заметка остается без напоминания

*A3: Создание через голосовой ввод*
1. Пользователь активирует Google Assistant
2. Произносит: "Hey Google, remind me about [заметка] at [время]"
3. Система создает напоминание через интеграцию с Assistant

**Бизнес-правила:**
- BR-001: Время напоминания не может быть в прошлом
- BR-002: Дата напоминания может быть установлена на любой день в будущем
- BR-003: Часовой пояс определяется по настройкам устройства или аккаунта
- BR-004: После миграции в Tasks уведомление приходит дважды: в момент срабатывания и через 24 часа (если не отмечено как выполненное)
- BR-005: Напоминание привязывается к заметке, а не к пользователю

**Результат:** Заметка имеет установленное напоминание, которое отображается как метка с датой и временем. Напоминание видно в Google Tasks и Google Calendar.

### FR-REMIND-002: Настройка предустановленных значений времени

**Описание:** Пользователь может настроить значения по умолчанию для быстрых опций времени ("Утро", "День", "Вечер").

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- Пользователь имеет доступ к настройкам приложения

**Основной сценарий:**
1. Пользователь открывает меню (три горизонтальные линии)
2. Выбирает "Settings" (Настройки)
3. Находит раздел "Reminder defaults" (Значения напоминаний по умолчанию)
4. Видит три временных слота:
   - Morning (Утро) — по умолчанию 08:00
   - Afternoon (День) — по умолчанию 13:00
   - Evening (Вечер) — по умолчанию 18:00
5. Нажимает на нужный слот
6. Выбирает новое время
7. Система сохраняет настройку

**Альтернативные сценарии:**

*A1: Сброс к значениям по умолчанию*
1. Пользователь может вернуть стандартные значения через меню сброса
2. Система восстанавливает значения: 08:00, 13:00, 18:00

**Бизнес-правила:**
- BR-006: Настройки привязаны к аккаунту Google и синхронизируются между устройствами
- BR-007: Время указывается в 12-часовом или 24-часовом формате в зависимости от локали
- BR-008: Предустановленные значения влияют на быстрые опции при создании напоминаний

**Результат:** Персонализированные значения времени используются при создании новых напоминаний через быстрые опции.

### FR-REMIND-003: Создание повторяющегося напоминания

**Описание:** Пользователь может настроить напоминание на регулярное повторение по заданному расписанию.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Пользователь находится в процессе создания или редактирования напоминания
- Выбраны дата и время для напоминания

**Основной сценарий:**
1. Пользователь открывает панель создания напоминания
2. Выбирает дату и время
3. Нажимает на выпадающий список "Does not repeat" (Не повторяется)
4. Система отображает опции повторения:
   - Does not repeat (Не повторяется)
   - Daily (Ежедневно)
   - Weekly (Еженедельно)
   - Monthly (Ежемесячно)
   - Yearly (Ежегодно)
   - Custom (Настроить)
5. Пользователь выбирает нужную опцию
6. Нажимает "Save"
7. Система создает повторяющееся напоминание

**Альтернативные сценарии:**

*A1: Настройка пользовательского расписания (Custom)*
1. Пользователь выбирает "Custom"
2. Система отображает расширенные настройки:
   - Интервал повторения (каждые N дней/недель/месяцев/лет)
   - Дни недели (для еженедельного повторения)
   - День месяца (для ежемесячного повторения)
   - Дата окончания повторений (опционально)
3. Пользователь настраивает параметры
4. Нажимает "Save"
5. Система создает напоминание с пользовательским расписанием

*A2: Отключение повторения для существующего напоминания*
1. Пользователь редактирует повторяющееся напоминание
2. Выбирает "Does not repeat"
3. Система убирает повторение, сохраняя ближайшее срабатывание

**Бизнес-правила:**
- BR-009: При выборе "Weekly" напоминание срабатывает в тот же день недели
- BR-010: При выборе "Monthly" напоминание срабатывает в тот же день месяца
- BR-011: Если день месяца не существует (например, 31 февраля), система использует последний день месяца
- BR-012: Повторяющееся напоминание создает новое срабатывание после отметки текущего как выполненного
- BR-013: Можно установить дату окончания повторений через "Custom"

**Результат:** Напоминание срабатывает регулярно по заданному расписанию. После каждого выполнения автоматически планируется следующее срабатывание.

### FR-REMIND-004: Создание напоминания по местоположению (устаревшая функция)

**Описание:** Пользователь мог установить напоминание, которое срабатывает при приближении к определенному географическому местоположению.

**Роли:** Владелец заметки, Соавтор

**Статус:** УСТАРЕВШАЯ ФУНКЦИЯ — удалена при миграции в Google Tasks (2025)

**Предусловия:**
- Пользователь авторизован в Google Keep
- Приложение имеет разрешение на доступ к геолокации
- Включены службы определения местоположения на устройстве
- Разрешен фоновый доступ к местоположению

**Основной сценарий (исторический):**
1. Пользователь открывает заметку
2. Нажимает на иконку колокольчика
3. Выбирает "Pick a place" (Выбрать место)
4. Система отображает опции:
   - Home (Дом) — если настроен в Google
   - Work (Работа) — если настроен в Google
   - Edit location (Указать место) — ручной ввод
5. Пользователь выбирает или вводит место
6. Система показывает карту с меткой
7. Пользователь подтверждает выбор
8. Система сохраняет геолокационное напоминание

**Альтернативные сценарии:**

*A1: Ручной ввод адреса*
1. Пользователь выбирает "Edit location"
2. Вводит адрес или название места
3. Система предлагает варианты через Google Maps
4. Пользователь выбирает нужный вариант
5. Продолжение с шага 6

*A2: Использование текущего местоположения*
1. Система может предложить места поблизости
2. Пользователь выбирает одно из них

**Бизнес-правила (исторические):**
- BR-014: Геозона (geofence) имела фиксированный радиус, настройка радиуса не поддерживалась
- BR-015: Напоминание срабатывало при входе в геозону
- BR-016: Требовался постоянный доступ к GPS, что увеличивало расход батареи
- BR-017: Home и Work синхронизировались из настроек Google аккаунта

**Результат:** Функция более недоступна. При миграции существующие геолокационные напоминания переносятся в Tasks с адресом в описании задачи.

### FR-REMIND-005: Редактирование напоминания

**Описание:** Пользователь может изменить параметры существующего напоминания.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Заметка имеет установленное напоминание
- Пользователь имеет права на редактирование

**Основной сценарий:**
1. Пользователь открывает заметку с напоминанием
2. Нажимает на отображаемое напоминание (метка с датой/временем)
3. Система открывает панель редактирования напоминания
4. Пользователь изменяет параметры:
   - Дату
   - Время
   - Повторение
5. Нажимает "Save"
6. Система обновляет напоминание
7. Изменения синхронизируются с Tasks и Calendar

**Альтернативные сценарии:**

*A1: Редактирование через Google Tasks*
1. Пользователь открывает Google Tasks
2. Находит напоминание (помечено "From Keep")
3. Редактирует дату/время
4. Изменения синхронизируются обратно в Keep

*A2: Редактирование через Google Calendar*
1. Пользователь открывает Google Calendar
2. Находит напоминание
3. Изменяет дату/время или название
4. Изменения отражаются в Keep (кроме названия заметки)

**Бизнес-правила:**
- BR-018: При изменении названия в Tasks/Calendar название заметки в Keep не обновляется
- BR-019: При изменении названия заметки в Keep название напоминания в Tasks не обновляется автоматически
- BR-020: Изменения времени синхронизируются между всеми сервисами

**Результат:** Напоминание обновлено с новыми параметрами во всех связанных сервисах.

### FR-REMIND-006: Удаление напоминания

**Описание:** Пользователь может удалить напоминание с заметки, сохранив саму заметку.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Заметка имеет установленное напоминание

**Основной сценарий:**
1. Пользователь открывает заметку с напоминанием
2. Нажимает на отображаемое напоминание
3. Нажимает кнопку "Delete reminder" (Удалить напоминание) или иконку корзины
4. Система удаляет напоминание
5. Заметка остается без напоминания
6. Напоминание удаляется из Tasks и Calendar

**Альтернативные сценарии:**

*A1: Удаление через Tasks или Calendar*
1. Пользователь удаляет напоминание в Google Tasks или Calendar
2. Напоминание удаляется из всех сервисов
3. Заметка в Keep сохраняется

**Бизнес-правила:**
- BR-021: Удаление напоминания не удаляет связанную заметку
- BR-022: Удаление заметки автоматически удаляет связанное напоминание
- BR-023: Удаление повторяющегося напоминания удаляет все будущие срабатывания

**Результат:** Напоминание удалено, заметка сохранена без напоминания.

### FR-REMIND-007: Получение уведомления о напоминании

**Описание:** Система отправляет пользователю уведомление при наступлении времени напоминания.

**Роли:** Владелец заметки, Соавтор (все участники заметки получают уведомления)

**Предусловия:**
- Напоминание установлено и активно
- Пользователь установил приложение для получения уведомлений (Tasks, Calendar или Gemini)
- Уведомления разрешены в настройках устройства

**Основной сценарий:**
1. Наступает время срабатывания напоминания
2. Система Google Tasks/Calendar отправляет push-уведомление
3. На устройстве пользователя появляется уведомление с:
   - Заголовком напоминания (текст заметки)
   - Временем напоминания
   - Кнопками действий
4. Пользователь может:
   - Открыть уведомление для просмотра полной заметки
   - Отложить (snooze) напоминание
   - Отметить как выполненное
   - Отклонить уведомление

**Альтернативные сценарии:**

*A1: Пользователь не реагирует на уведомление*
1. Через 24 часа система отправляет повторное уведомление
2. Напоминание остается активным до явного действия пользователя

*A2: Устройство офлайн*
1. Уведомление доставляется при восстановлении соединения
2. Если время прошло, уведомление показывает, что напоминание просрочено

*A3: Соавтор получает уведомление*
1. Все соавторы заметки получают уведомление о напоминании
2. Каждый соавтор может независимо отреагировать на уведомление

**Бизнес-правила:**
- BR-024: После миграции уведомления приходят через Tasks/Calendar, не через Keep
- BR-025: Пользователь должен установить хотя бы одно приложение (Tasks, Calendar, Gemini) для получения уведомлений
- BR-026: Уведомления синхронизируются между всеми устройствами пользователя
- BR-027: При совместной работе все соавторы получают уведомления

**Результат:** Пользователь получил уведомление и может выполнить действие с напоминанием.

### FR-REMIND-008: Отложить напоминание (Snooze)

**Описание:** Пользователь может отложить сработавшее напоминание на более позднее время.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Получено уведомление о напоминании

**Основной сценарий:**
1. Пользователь получает уведомление
2. Выбирает опцию "Snooze" (Отложить) или свайпает уведомление
3. Система предлагает варианты:
   - 10 минут
   - 1 час
   - Завтра утром
   - Выбрать время
4. Пользователь выбирает вариант
5. Система перепланирует напоминание на выбранное время
6. Уведомление исчезает

**Альтернативные сценарии:**

*A1: Пользовательское время отложения*
1. Пользователь выбирает "Pick a time" (Выбрать время)
2. Указывает конкретную дату и время
3. Система перепланирует напоминание

**Бизнес-правила:**
- BR-028: Отложенное напоминание сохраняет связь с исходной заметкой
- BR-029: История откладываний не сохраняется
- BR-030: Отложение не влияет на расписание повторяющихся напоминаний

**Результат:** Напоминание перенесено на более позднее время.

### FR-REMIND-009: Отметить напоминание как выполненное

**Описание:** Пользователь может отметить напоминание как выполненное, завершив его жизненный цикл.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Существует активное напоминание

**Основной сценарий:**
1. Пользователь получает уведомление или открывает заметку
2. Выбирает опцию "Mark as done" / "Complete" (Выполнено)
3. Система отмечает напоминание как выполненное
4. Для однократного напоминания: напоминание удаляется
5. Для повторяющегося напоминания: планируется следующее срабатывание
6. Заметка сохраняется

**Альтернативные сценарии:**

*A1: Выполнение через Google Assistant / Gemini*
1. Пользователь говорит: "Hey Google, mark my reminder as complete"
2. Assistant находит напоминание и отмечает его выполненным

*A2: Выполнение через Tasks/Calendar*
1. Пользователь отмечает задачу выполненной в Tasks или Calendar
2. Статус синхронизируется с Keep

**Бизнес-правила:**
- BR-031: Выполнение напоминания не архивирует и не удаляет заметку
- BR-032: Для повторяющегося напоминания автоматически создается следующее срабатывание
- BR-033: Выполненные напоминания нельзя восстановить (кроме повторяющихся)

**Результат:** Напоминание завершено. Для повторяющихся напоминаний — запланировано следующее.

### FR-REMIND-010: Просмотр списка всех напоминаний

**Описание:** Пользователь может просмотреть все заметки с активными напоминаниями в едином списке.

**Роли:** Владелец заметки

**Предусловия:**
- Пользователь авторизован в Google Keep
- Существуют заметки с напоминаниями

**Основной сценарий:**
1. Пользователь открывает боковое меню (гамбургер-меню)
2. Выбирает "Reminders" (Напоминания)
3. Система отображает список всех заметок с напоминаниями
4. Заметки отсортированы по дате/времени напоминания (ближайшие первые)
5. Каждая заметка отображает:
   - Содержимое заметки (превью)
   - Дату и время напоминания
   - Статус (предстоящее / просроченное)

**Альтернативные сценарии:**

*A1: Нет активных напоминаний*
1. Система отображает пустой список
2. Показывает подсказку о создании напоминаний

**Бизнес-правила:**
- BR-034: Просроченные напоминания отображаются в начале списка
- BR-035: В списке отображаются только предстоящие и просроченные напоминания, не выполненные

**Результат:** Пользователь видит все свои активные напоминания в одном месте.

---

### FR-REMIND-011: Обработка просроченных напоминаний

**Описание:** Система управляет напоминаниями, время которых уже прошло.

**Роли:** Система (автоматически)

**Предусловия:**
- Существует напоминание с прошедшей датой/временем

**Основной сценарий:**
1. Время напоминания наступило и прошло
2. Пользователь не отметил напоминание как выполненное
3. Система:
   - Сохраняет напоминание как просроченное
   - Отправляет повторное уведомление через 24 часа
   - Отображает напоминание с меткой "Overdue" (Просрочено)
4. Напоминание остается активным до действия пользователя

**Бизнес-правила:**
- BR-036: Просроченные напоминания не удаляются автоматически
- BR-037: После миграции старые напоминания (старше 1 года, без повторения) переносятся в список "Old Google Keep Reminders" в Tasks

**Результат:** Просроченные напоминания остаются видимыми и напоминают пользователю о невыполненных задачах.

---

### FR-REMIND-012: Совместное использование напоминаний

**Описание:** При совместной работе над заметкой все соавторы получают уведомления о напоминаниях.

**Роли:** Владелец заметки, Соавтор

**Предусловия:**
- Заметка имеет напоминание
- К заметке добавлены соавторы

**Основной сценарий:**
1. Владелец создает заметку с напоминанием
2. Добавляет соавтора (Collaborator) через меню заметки
3. Соавтор принимает приглашение
4. При срабатывании напоминания:
   - Владелец получает уведомление
   - Соавтор получает уведомление
5. Каждый может независимо:
   - Отложить напоминание для себя
   - Отметить как выполненное (влияет на всех)

**Альтернативные сценарии:**

*A1: Соавтор создает собственное напоминание*
1. Соавтор может создать дополнительное напоминание для той же заметки
2. Это напоминание также видно всем участникам

**Бизнес-правила:**
- BR-038: Отметка "Выполнено" одним пользователем завершает напоминание для всех
- BR-039: Откладывание (snooze) действует индивидуально
- BR-040: Соавтор не может удалить напоминание, созданное владельцем

**Результат:** Все участники заметки синхронизированы по напоминаниям.

## Состояния и статусы

### Жизненный цикл напоминания

```
┌─────────────┐
│   PENDING   │◄────────────────────────────────┐
│  (Ожидает)  │                                 │
└──────┬──────┘                                 │
       │ Время наступило                        │
       ▼                                        │
┌─────────────┐                                 │
│  TRIGGERED  │─────┬───────────────────────────┤
│ (Сработало) │     │                           │
└──────┬──────┘     │                           │
       │            │ Snooze                    │ Повторяющееся
       │            ▼                           │ напоминание
       │     ┌─────────────┐                    │
       │     │   SNOOZED   │────────────────────┘
       │     │ (Отложено)  │  Время отложки истекло
       │     └─────────────┘
       │ Mark as complete
       ▼
┌─────────────┐
│  COMPLETED  │
│ (Выполнено) │
└─────────────┘
```

### Статусы напоминания

| Статус | Описание | Возможные переходы |
|--------|----------|-------------------|
| `PENDING` | Ожидает срабатывания | TRIGGERED (время наступило) |
| `TRIGGERED` | Время наступило, ожидается действие пользователя | SNOOZED, COMPLETED |
| `SNOOZED` | Отложено на более позднее время | TRIGGERED (новое время наступило) |
| `COMPLETED` | Выполнено пользователем | — (конечное состояние) |

### Типы напоминаний

| Тип | Описание | Статус поддержки |
|-----|----------|-----------------|
| `TIME` | Напоминание по дате и времени | Активно |
| `LOCATION` | Напоминание по геолокации | Устарело (2025) |

## Ограничения и лимиты

### Количественные ограничения

| Параметр | Значение | Описание |
|----------|----------|----------|
| Максимум напоминаний | 100,000 | После миграции в Tasks. При превышении старые напоминания не мигрируют |
| Напоминаний на заметку | 1 | Одно напоминание на одну заметку |
| Минимальный интервал | 1 минута | Минимальное время до срабатывания |
| Максимальная дата | Нет ограничения | Можно установить на любую дату в будущем |
| Символов в заметке | 20,000 | Влияет на отображение в уведомлении |

### Технические ограничения

| Ограничение | Описание |
|-------------|----------|
| Геолокация | Функция удалена при миграции в Tasks (2025) |
| Настройка радиуса геозоны | Никогда не поддерживалась |
| Уведомления из Keep | Требуется установка Tasks, Calendar или Gemini |
| Синхронизация названий | Изменение названия заметки не обновляет название в Tasks |
| Офлайн создание | Напоминания синхронизируются при подключении к сети |

### Ограничения повторений

| Параметр | Ограничение |
|----------|-------------|
| Минимальный интервал | 1 день |
| Максимальный интервал | 99 лет (для yearly) |
| Дни недели | 1-7 дней (для weekly) |
| Дата окончания | Опционально, любая дата в будущем |

```

{
  "type": "TIME",
  "trigger": {
    "datetime": "2025-01-15T09:00:00Z",
    "timezone": "Europe/Moscow"
  },
  "recurrence": {

    "interval": 1,

{

}
```

## Примечания по миграции (2024-2025)

### Что изменилось

1. **Уведомления** — больше не приходят напрямую из Google Keep. Требуется установка Tasks, Calendar или Gemini.

2. **Геолокационные напоминания** — функция полностью удалена. Существующие напоминания по месту переносятся в Tasks с адресом в описании задачи.

3. **Синхронизация** — все напоминания автоматически синхронизируются с Google Tasks и отображаются в Calendar.

4. **Лимиты** — при превышении 100,000 задач старые напоминания из Keep не мигрируют.

5. **Старые напоминания** — непериодические напоминания старше 1 года попадают в отдельный список "Old Google Keep Reminders" в Tasks.

### Рекомендации для пользователей

- Установите Google Tasks или Google Calendar для получения уведомлений
- Проверьте настройки уведомлений в новых приложениях
- Для геолокационных напоминаний рассмотрите альтернативы (Tasks.org и др.)
- Регулярно проверяйте список "Old Google Keep Reminders" в Tasks

# Шаблоны форм

## Описание

Модуль "Шаблоны форм" предоставляет пользователям Google Forms доступ к обширной галерее готовых шаблонов форм для различных сценариев использования, а также возможность создавать и управлять собственными шаблонами. Система включает встроенную галерею шаблонов Google, организованную по трем основным категориям (Personal, Work, Education), функционал создания форм на основе шаблонов с последующей кастомизацией, возможность сохранения собственных форм как шаблонов для повторного использования, и для организаций Google Workspace - централизованное управление корпоративными шаблонами с настройкой прав доступа, модерацией и категоризацией. Шаблоны ускоряют создание форм, обеспечивают единообразие дизайна и структуры, содержат лучшие практики формулировки вопросов и помогают пользователям быстро создавать профессиональные формы без необходимости проектирования с нуля.

## Роли пользователей

- **Обычный пользователь Google Forms** - может просматривать и использовать встроенные шаблоны Google, создавать формы на их основе, сохранять свои формы как личные шаблоны
- **Пользователь Google Workspace** - дополнительно имеет доступ к корпоративным шаблонам организации, может предлагать свои шаблоны для добавления в галерею организации
- **Администратор Google Workspace** - управляет настройками шаблонов организации, модерирует предлагаемые шаблоны, создает категории, настраивает права доступа
- **Модератор шаблонов** - пользователь с привилегией "Docs Templates" в Google Workspace, имеет право одобрять или отклонять предложенные шаблоны
- **Создатель корпоративного шаблона** - пользователь организации с правами на создание шаблонов для общего использования

## Функциональные требования

### FR-TMPL-001: Просмотр галереи встроенных шаблонов Google

**Описание:** Пользователь может просматривать галерею готовых шаблонов, предоставленных Google, организованных по категориям.

**Роли:** Все пользователи Google Forms

**Предусловия:**
- Пользователь аутентифицирован через Google аккаунт
- Пользователь открыл главную страницу Google Forms (forms.google.com)

**Основной сценарий:**
1. Пользователь заходит на главную страницу Google Forms
2. Система отображает в верхней части страницы секцию "Template gallery" с превью шаблонов
3. Система показывает по умолчанию 6-8 наиболее популярных шаблонов в виде миниатюр
4. Пользователь видит для каждого шаблона:
   - Превью формы (визуальное представление)
   - Название шаблона (например, "Event Registration", "Contact Information")
   - Категорию шаблона (отображается цветовой меткой или текстом)
5. Пользователь нажимает кнопку "Template gallery" или прокручивает галерею вправо
6. Система открывает полную галерею шаблонов с категориями:
   - **Personal** (Личные):
     - Party Invite (Приглашение на вечеринку)
     - RSVP (Подтверждение присутствия)
     - Event Registration (Регистрация на событие)
     - Customer Feedback (Обратная связь клиентов)
     - Contact Information (Контактная информация)
   - **Work** (Рабочие):
     - Event Feedback (Отзыв о мероприятии)
     - Job Application (Заявка на работу)
     - Time Off Request (Запрос на отпуск)
     - Work Request (Рабочий запрос)
     - Meeting Feedback (Обратная связь о встрече)
   - **Education** (Образовательные):
     - Assessment (Оценивание)
     - Exit Ticket (Выходной билет)
     - Worksheet (Рабочий лист)
     - Course Evaluation (Оценка курса)
     - Student Feedback (Обратная связь студентов)
7. Пользователь может переключаться между категориями, нажимая на вкладки категорий
8. Каждая категория отображает релевантные шаблоны в виде сетки карточек
9. Пользователь может наводить курсор на шаблон для просмотра краткого описания (всплывающая подсказка)

**Альтернативные сценарии:**
- Сценарий А (Поиск шаблона): Если доступна функция поиска, пользователь может ввести ключевое слово для фильтрации шаблонов
- Сценарий Б (Недавно использованные шаблоны): Система может показывать секцию "Recently used templates" для быстрого доступа к ранее использованным шаблонам

**Бизнес-правила:**
- BR-001: Галерея шаблонов доступна всем пользователям Google Forms бесплатно
- BR-002: Встроенные шаблоны Google нельзя удалить или изменить (только создать копию)
- BR-003: Шаблоны обновляются Google периодически для добавления новых вариантов
- BR-004: Превью шаблонов генерируются автоматически на основе первых вопросов формы
- BR-005: Количество отображаемых шаблонов в каждой категории может варьироваться

**Результат:** Пользователь видит доступные шаблоны и может выбрать подходящий для использования

### FR-TMPL-002: Предварительный просмотр шаблона

**Описание:** Пользователь может предварительно просмотреть содержимое шаблона перед созданием формы на его основе.

**Роли:** Все пользователи Google Forms

**Предусловия:**
- Пользователь находится в галерее шаблонов
- Шаблон доступен для просмотра

**Основной сценарий:**
1. Пользователь наводит курсор на карточку шаблона в галерее
2. Система выделяет карточку (добавляет тень, изменяет фон)
3. Пользователь кликает на карточку шаблона
4. Система открывает предварительный просмотр шаблона в режиме чтения
5. Пользователь видит:
   - Название и описание формы
   - Все вопросы шаблона в том порядке, в котором они будут в создаваемой форме
   - Типы вопросов (множественный выбор, короткий ответ, шкала и т.д.)
   - Варианты ответов для вопросов с выбором
   - Разделы и логику ветвления (если настроена)
   - Тему оформления (цветовая схема, шрифты, заголовочное изображение)
6. Интерфейс предварительного просмотра отображает:
   - Кнопку "Use template" (Использовать шаблон) - основное действие
   - Кнопку "Preview" (Предпросмотр формы для респондента)
   - Кнопку закрытия (X) или "Back" для возврата к галерее
7. Пользователь может прокручивать форму для просмотра всех вопросов
8. При нажатии "Preview" система показывает форму в режиме, как её увидит респондент

**Альтернативные сценарии:**
- Сценарий А (Быстрое использование): Пользователь сразу нажимает "Use template" без детального просмотра
- Сценарий Б (Закрытие просмотра): Пользователь нажимает ESC или кликает вне области просмотра для закрытия

**Бизнес-правила:**
- BR-006: Предварительный просмотр доступен в режиме только для чтения
- BR-007: Пользователь не может редактировать шаблон напрямую из режима просмотра
- BR-008: Предварительный просмотр показывает актуальную версию шаблона

**Результат:** Пользователь получает полное представление о содержимом шаблона перед его использованием

### FR-TMPL-003: Создание формы на основе шаблона

**Описание:** Пользователь создает новую редактируемую форму на основе выбранного шаблона.

**Роли:** Все пользователи Google Forms

**Предусловия:**
- Пользователь выбрал шаблон из галереи или из предварительного просмотра
- Пользователь имеет доступ к Google Drive для сохранения формы

**Основной сценарий:**
1. Пользователь находится в галерее шаблонов или в режиме предварительного просмотра
2. Пользователь нажимает на шаблон или кнопку "Use template"
3. Система создает копию шаблона:
   - Генерирует новый уникальный ID формы
   - Копирует все элементы шаблона:
     - Заголовок формы (может быть помечен как "Копия [название шаблона]" или оригинальное название)
     - Описание формы
     - Все вопросы с их типами, вариантами ответов, настройками валидации
     - Логику ветвления и условные переходы
     - Разделы и страницы
     - Тему оформления (цвет, шрифт, заголовочное изображение)
     - Настройки формы (требование входа, ограничение на один ответ и т.д.)
4. Система сохраняет новую форму в Google Drive пользователя:
   - Расположение: корневая папка "My Drive" или недавно используемая папка
   - Название файла: соответствует заголовку формы
5. Система открывает форму в режиме редактирования
6. Пользователь видит уведомление: "Your form has been created" или "Template copied"
7. Форма полностью редактируема - пользователь может:
   - Изменить заголовок и описание
   - Добавить, удалить или изменить вопросы
   - Изменить тему оформления
   - Настроить параметры формы
   - Добавить логику ветвления
8. Все изменения автоматически сохраняются в Google Drive

**Альтернативные сценарии:**
- Сценарий А (Переименование при создании): Пользователь сразу видит выделенный заголовок и может его переименовать
- Сценарий Б (Выбор папки сохранения): Система может предложить выбрать папку в Drive перед созданием (в некоторых интерфейсах)
- Сценарий В (Создание в общей папке): Если пользователь создает форму из интерфейса общей папки Google Drive, форма сохраняется в эту папку

**Бизнес-правила:**
- BR-009: Созданная форма является полностью независимой копией, не связанной с оригинальным шаблоном
- BR-010: Изменения в оригинальном шаблоне не влияют на уже созданные формы
- BR-011: Пользователь становится владельцем созданной формы
- BR-012: Форма получает права доступа по умолчанию: только владелец может редактировать
- BR-013: Все медиа-файлы из шаблона (изображения, видео) копируются в новую форму
- BR-014: Связи с таблицами ответов не копируются (пользователь должен настроить новую)
- BR-015: Квизовые настройки (правильные ответы, баллы) копируются, если они были в шаблоне

**Результат:** Новая редактируемая форма создана на основе шаблона и сохранена в Google Drive пользователя

### FR-TMPL-004: Сохранение формы как личного шаблона

**Описание:** Пользователь может сохранить созданную форму в отдельную папку для использования в качестве личного шаблона.

**Роли:** Все пользователи Google Forms

**Предусловия:**
- Пользователь создал и отредактировал форму
- Форма находится в Google Drive пользователя
- Пользователь хочет использовать эту форму как основу для будущих форм

**Основной сценарий:**
1. Пользователь создает и настраивает форму, которую хочет использовать как шаблон
2. Пользователь открывает Google Drive (drive.google.com)
3. Пользователь создает папку для хранения шаблонов (например, "Form Templates", "Мои шаблоны")
4. Пользователь находит нужную форму в списке файлов Drive
5. Пользователь перетаскивает форму в папку шаблонов или:
   - Правый клик на файле формы
   - Выбирает "Move to" или "Organize" > "Move"
   - Выбирает папку шаблонов
   - Нажимает "Move" или "Move here"
6. Форма перемещается в папку шаблонов
7. Для использования шаблона в будущем:
   - Пользователь открывает папку с шаблонами
   - Правый клик на файле шаблона
   - Выбирает "Make a copy"
   - Система создает копию формы с названием "Copy of [название]"
   - Пользователь переименовывает и редактирует копию
8. Альтернативно, пользователь может открыть форму-шаблон:
   - Нажать меню (три точки) в правом верхнем углу редактора
   - Выбрать "Make a copy"
   - Указать название новой формы и папку для сохранения
   - Нажать "Make copy"

**Альтернативные сценарии:**
- Сценарий А (Помечание звездочкой): Пользователь может пометить шаблонные формы звездочкой в Drive для быстрого доступа через "Starred"
- Сценарий Б (Создание папочной структуры): Пользователь может создать несколько подпапок для категоризации шаблонов (Опросы, Регистрации, Квизы и т.д.)
- Сценарий В (Цветовое кодирование): Пользователь может назначить цвета папкам с шаблонами для визуального разделения

**Бизнес-правила:**
- BR-016: Google Forms не имеет встроенной функции "Сохранить как шаблон" для личных шаблонов
- BR-017: Личные шаблоны - это обычные формы, организованные пользователем в папки Drive
- BR-018: Копирование формы создает полностью независимую копию
- BR-019: Пользователь может поделиться ссылкой на шаблон с другими для копирования
- BR-020: При копировании формы ответы на оригинальную форму не копируются
- BR-021: Права доступа к форме-шаблону можно настроить как "Anyone with the link can view" для распространения

**Результат:** Пользователь имеет организованную библиотеку личных шаблонов для повторного использования

### FR-TMPL-005: Доступ к корпоративным шаблонам организации (Google Workspace)

**Описание:** Пользователи Google Workspace могут просматривать и использовать шаблоны, созданные и одобренные их организацией.

**Роли:** Пользователь Google Workspace

**Предусловия:**
- Пользователь является членом Google Workspace организации
- Администратор включил функцию "Custom templates" для организации
- В организации созданы и одобрены корпоративные шаблоны

**Основной сценарий:**
1. Пользователь заходит на главную страницу Google Forms (forms.google.com)
2. Система отображает дополнительную секцию в галерее шаблонов:
   - Вкладка "[Название организации]" или "Organization" рядом с Personal/Work/Education
   - Или отдельная секция "Organization templates" выше стандартной галереи
3. Пользователь нажимает на вкладку организации
4. Система отображает корпоративные шаблоны, организованные по категориям:
   - Категории создаются администратором (например: HR, Marketing, Sales, IT Support)
   - Каждая категория содержит релевантные шаблоны
5. Для каждого корпоративного шаблона отображается:
   - Название шаблона
   - Описание (если добавлено)
   - Превью формы
   - Категория
   - Автор шаблона (имя сотрудника, создавшего шаблон)
   - Дата последнего обновления (опционально)
6. Пользователь может:
   - Просмотреть шаблон (как в FR-TMPL-002)
   - Использовать шаблон для создания формы (как в FR-TMPL-003)
   - Фильтровать шаблоны по категориям
7. Корпоративные шаблоны отображаются с визуальной меткой организации (логотип или специальный бейдж)

**Альтернативные сценарии:**
- Сценарий А (Рекомендуемые шаблоны): Администратор может пометить определенные шаблоны как "Featured" или "Recommended" для приоритетного отображения
- Сценарий Б (Поиск по корпоративным шаблонам): Пользователь может искать шаблоны по ключевым словам в пределах организационной галереи
- Сценарий В (Недавно добавленные): Система может показывать секцию "Recently added" для новых корпоративных шаблонов

**Бизнес-правила:**
- BR-022: Корпоративные шаблоны доступны только пользователям домена организации
- BR-023: Пользователи могут использовать (копировать) шаблоны, но не могут изменять оригиналы
- BR-024: Администратор контролирует видимость шаблонов через настройки категорий
- BR-025: Шаблоны могут быть ограничены определенными группами пользователей или подразделениями
- BR-026: Корпоративные шаблоны отображаются в дополнение к стандартным шаблонам Google

**Результат:** Пользователь имеет доступ к утвержденным организацией шаблонам, соответствующим корпоративным стандартам

### FR-TMPL-006: Предложение шаблона для добавления в галерею организации

**Описание:** Пользователь Google Workspace может предложить свою форму в качестве шаблона для всей организации.

**Роли:** Пользователь Google Workspace, Создатель корпоративного шаблона

**Предусловия:**
- Пользователь является членом Google Workspace организации
- Администратор включил функцию создания корпоративных шаблонов
- Режим модерации настроен как "Open" (открытый) или "Moderated" (с модерацией)
- Пользователь создал форму, которую хочет предложить как шаблон

**Основной сценарий:**

**Вариант А - Режим "Open" (открытое добавление):**
1. Пользователь открывает форму, которую хочет сделать шаблоном
2. Пользователь нажимает меню (три точки) в правом верхнем углу редактора
3. Система отображает опцию "Submit as template" или "Add to organization templates"
4. Пользователь выбирает эту опцию
5. Система открывает диалоговое окно "Submit template":
   - Поле "Template name" (название шаблона) - предзаполнено текущим названием формы
   - Поле "Description" (описание) - для краткого описания назначения шаблона
   - Выпадающий список "Category" - выбор категории из созданных администратором
   - Опция "Create new category" (если разрешено администратором)
   - Чекбокс "Featured template" (рекомендуемый) - если у пользователя есть права
6. Пользователь заполняет информацию:
   - Вводит или корректирует название шаблона (обязательное поле)
   - Добавляет описание назначения и сценариев использования (рекомендуется, может быть обязательным)
   - Выбирает подходящую категорию из списка (например: HR, Marketing, IT, Events)
7. Пользователь нажимает "Submit" или "Add to gallery"
8. Система немедленно добавляет шаблон в галерею организации:
   - Создает копию формы как шаблон
   - Присваивает метаданные (автор, дата создания, категория)
   - Делает шаблон видимым всем пользователям организации (или выбранным группам)
9. Пользователь видит уведомление: "Your template has been added to the organization gallery"
10. Шаблон появляется в соответствующей категории галереи организации

**Вариант Б - Режим "Moderated" (с модерацией):**
1. Шаги 1-7 аналогичны варианту А
2. После нажатия "Submit" система:
   - Сохраняет шаблон в статусе "Pending approval" (ожидает одобрения)
   - Отправляет уведомление администраторам с привилегией "Docs Templates"
3. Пользователь видит уведомление: "Your template has been submitted for review"
4. Шаблон не отображается в галерее до одобрения модератором
5. Модератор получает email с ссылкой на предложенный шаблон
6. После одобрения/отклонения пользователь получает уведомление

**Альтернативные сценарии:**
- Сценарий А (Создание новой категории): Если разрешено, пользователь может создать новую категорию при добавлении шаблона
- Сценарий Б (Отклонение шаблона): Модератор отклоняет шаблон с комментарием, пользователь получает feedback

**Бизнес-правила:**

- BR-030: Изменения в оригинальной форме не влияют на опубликованный шаблон

- BR-032: Форма-шаблон хранится в специальном репозитории организации, а не в личном Drive автора
- BR-033: Обязательные поля при публикации: название, категория

### FR-TMPL-007: Модерация предложенных шаблонов (для модераторов)

**Описание:** Модераторы с привилегией "Docs Templates" могут просматривать, одобрять или отклонять шаблоны, предложенные пользователями.

**Роли:** Модератор шаблонов, Администратор Google Workspace

**Предусловия:**
- Пользователь имеет привилегию "Docs Templates" в Admin Console
- Режим модерации настроен как "Moderated"
- Есть шаблоны, ожидающие одобрения

**Основной сценарий:**
1. Пользователь предлагает шаблон (как описано в FR-TMPL-006)
2. Система отправляет email-уведомление всем модераторам:
   - Тема: "[User Name] submitted a new form template for approval"
   - Содержит: название шаблона, описание, категорию, ссылку на предпросмотр
3. Модератор кликает на ссылку в письме или:
   - Открывает Admin Console (admin.google.com)
   - Переходит в Apps > Google Workspace > Drive and Docs > Templates
   - Открывает вкладку "Pending templates" или "Template submissions"
4. Система отображает список шаблонов в статусе "Pending":
   - Название шаблона
   - Автор (имя и email)
   - Дата отправки
   - Предложенная категория
   - Описание
   - Действия: Preview (Просмотр), Approve (Одобрить), Reject (Отклонить)
5. Модератор нажимает "Preview" для просмотра шаблона
6. Система открывает предпросмотр формы в режиме чтения:
   - Показывает все вопросы, логику, оформление
   - Отображает метаданные (автор, дата создания)
   - Позволяет пролистать всю форму
7. Модератор оценивает шаблон по критериям:
   - Полезность для организации
   - Качество формулировок вопросов
   - Соответствие корпоративным стандартам
   - Правильность выбранной категории
   - Отсутствие конфиденциальной информации

**Путь А - Одобрение:**
8. Модератор нажимает "Approve"
9. Система открывает диалог подтверждения:
   - Позволяет изменить категорию
   - Позволяет пометить как "Featured" (рекомендуемый)
   - Позволяет добавить комментарий для автора
10. Модератор подтверждает одобрение
11. Система:
    - Публикует шаблон в галерее организации
    - Отправляет уведомление автору: "Your template has been approved and added to the gallery"
    - Удаляет шаблон из списка "Pending"
12. Шаблон становится доступным всем пользователям организации в соответствующей категории

**Путь Б - Отклонение:**
8. Модератор нажимает "Reject"
9. Система открывает диалог с обязательным полем "Reason for rejection"
10. Модератор вводит причину отклонения (например: "Шаблон слишком специфичен для одного отдела", "Требуется переработка формулировок")
11. Модератор подтверждает отклонение
12. Система:
    - Удаляет шаблон из списка ожидания
    - Отправляет уведомление автору с причиной отклонения
    - Может предложить возможность исправить и отправить повторно
13. Шаблон не публикуется в галерее

**Альтернативные сценарии:**
- Сценарий А (Запрос изменений): Модератор может отправить шаблон обратно автору с комментариями для доработки
- Сценарий Б (Пакетное одобрение): Модератор может выбрать несколько шаблонов и одобрить их одновременно
- Сценарий В (Автоматические напоминания): Система отправляет напоминания модераторам о необработанных шаблонах через определенное время

**Бизнес-правила:**
- BR-034: Шаблоны в статусе "Pending" не видны обычным пользователям
- BR-035: Модераторы видят всю историю отправок шаблонов (одобренные, отклоненные, ожидающие)
- BR-036: Можно настроить автоматическое одобрение шаблонов от доверенных пользователей
- BR-037: Модераторы могут редактировать метаданные шаблона (название, описание, категорию) при одобрении
- BR-038: Причина отклонения обязательна для предоставления обратной связи автору
- BR-039: SLA времени модерации может быть установлен администратором (например, 3 рабочих дня)

**Результат:** Шаблон одобрен и опубликован в галерее или отклонен с обратной связью для автора

### FR-TMPL-008: Управление категориями шаблонов организации

**Описание:** Администраторы Google Workspace могут создавать, редактировать и удалять категории для организации корпоративных шаблонов.

**Роли:** Администратор Google Workspace

**Предусловия:**
- Пользователь имеет роль администратора в Google Workspace
- Доступ к Admin Console
- Функция корпоративных шаблонов включена

**Основной сценарий:**
1. Администратор входит в Google Admin Console (admin.google.com)
2. Администратор переходит в Apps > Google Workspace > Drive and Docs
3. Администратор выбирает раздел "Templates"
4. Система отображает страницу управления шаблонами с вкладками:
   - Template Gallery settings (Настройки галереи)
   - Categories (Категории)
   - Published templates (Опубликованные шаблоны)
   - Pending templates (Ожидающие одобрения)
5. Администратор открывает вкладку "Categories"
6. Система отображает список существующих категорий:
   - Название категории
   - Описание
   - Количество шаблонов в категории
   - Дата создания
   - Действия: Edit (Редактировать), Delete (Удалить)

**Создание новой категории:**
7. Администратор нажимает кнопку "+ Add category" или "Create category"
8. Система открывает диалоговое окно "Create category":
   - Поле "Category name" (название категории) - обязательное
   - Поле "Description" (описание) - опциональное
   - Поле "Icon" (иконка) - выбор из предустановленных или загрузка своей
   - Выпадающий список "Visibility" (видимость):
     - All users (Все пользователи организации)
     - Specific groups (Определенные группы/подразделения)
   - Поле "Order" (порядок отображения) - число для сортировки категорий
9. Администратор заполняет данные:
   - Вводит название, например: "HR Forms", "Marketing Campaigns", "Customer Support"
   - Добавляет описание: "Формы для процессов управления персоналом"
   - Выбирает иконку (например, иконка "person" для HR)
   - Выбирает видимость (по умолчанию "All users")
10. Администратор нажимает "Create" или "Save"
11. Система:
    - Создает новую категорию
    - Добавляет её в список категорий
    - Делает категорию доступной при публикации шаблонов
12. Новая категория появляется в галерее шаблонов организации (пустая, если нет шаблонов)

**Редактирование категории:**
13. Администратор нажимает "Edit" рядом с категорией
14. Система открывает диалог редактирования с текущими значениями
15. Администратор изменяет название, описание, иконку или видимость
16. Администратор нажимает "Save"
17. Система обновляет категорию и все связанные шаблоны

**Удаление категории:**
18. Администратор нажимает "Delete" рядом с категорией
19. Система проверяет наличие шаблонов в категории:
    - Если категория пустая: показывает подтверждение "Delete category [Name]?"
    - Если есть шаблоны: показывает предупреждение "This category contains [N] templates. Move them or delete?"
20. Администратор выбирает действие:
    - Move to another category (Переместить в другую категорию) - выбирает целевую категорию
    - Delete category and templates (Удалить категорию и все шаблоны) - требует дополнительного подтверждения
21. Администратор подтверждает удаление
22. Система удаляет категорию и выполняет выбранное действие с шаблонами

**Альтернативные сценарии:**
- Сценарий А (Перемещение категорий): Администратор может изменить порядок отображения категорий drag-and-drop
- Сценарий Б (Архивация категории): Вместо удаления можно сделать категорию неактивной (скрытой)
- Сценарий В (Импорт категорий): Администратор может импортировать стандартный набор категорий из шаблона Google

**Бизнес-правила:**
- BR-040: Название категории должно быть уникальным в рамках организации
- BR-041: Минимальная длина названия категории: 1 символ, максимальная: 50 символов
- BR-042: Нельзя удалить категорию с активными шаблонами без перемещения или удаления шаблонов
- BR-043: Системные категории (Personal, Work, Education) нельзя редактировать или удалить
- BR-044: Максимальное количество категорий: 50 на организацию
- BR-045: Изменения в категориях применяются немедленно для всех пользователей
- BR-046: При ограничении видимости категории по группам, шаблоны видны только членам этих групп

**Результат:** Категории созданы, изменены или удалены согласно структуре организации

### FR-TMPL-009: Настройка прав доступа к корпоративным шаблонам

**Описание:** Администраторы настраивают политики доступа к функциям работы с шаблонами для пользователей организации.

**Роли:** Администратор Google Workspace

**Предусловия:**
- Пользователь имеет роль администратора
- Доступ к Google Admin Console
- Организация использует Google Workspace

**Основной сценарий:**
1. Администратор входит в Admin Console (admin.google.com)
2. Администратор переходит в Apps > Google Workspace > Drive and Docs > Templates
3. Система отображает страницу "Template Gallery settings"
4. Администратор видит следующие настройки:

**Настройка: Включение/отключение корпоративных шаблонов**
5. Чекбокс "Enable custom templates for your organization"
   - Описание: "Allow users to find and use organization-specific templates from the Docs, Sheets, Slides, Vids, Forms, and Sites home screens"
6. Администратор устанавливает чекбокс для включения функции
7. После включения становятся доступны дополнительные настройки

**Настройка: Режим модерации шаблонов**
8. Радиокнопки "Template submission mode":
   - **Open** (Открытый):
     - Описание: "Anyone in your organization can add or remove templates without approval"
     - Любой пользователь может сразу публиковать шаблоны в галерею
     - Шаблоны появляются немедленно после отправки
   - **Moderated** (С модерацией):
     - Описание: "Admins with the Docs Templates privilege get an email request to approve each new template. Approved templates are added to the custom gallery"
     - Пользователи отправляют шаблоны на одобрение
     - Модераторы получают уведомления и должны одобрить перед публикацией
   - **Restricted** (Ограниченный):
     - Описание: "Only admins with the Docs Templates privilege can submit templates"
     - Только администраторы с привилегией могут публиковать шаблоны
     - Обычные пользователи не видят опции добавления шаблонов
9. Администратор выбирает подходящий режим для организации

**Настройка: Назначение модераторов**
10. Если выбран режим "Moderated" или "Restricted", доступна секция "Template moderators"
11. Администратор нажимает "Add moderator" или "Manage privilege"
12. Система открывает интерфейс назначения привилегии "Docs Templates":
    - Поиск пользователей по имени или email
    - Выбор пользователей или групп
13. Администратор добавляет пользователей, которые будут модераторами
14. Выбранные пользователи получают права:
    - Одобрять/отклонять предложенные шаблоны
    - Создавать и публиковать шаблоны в режиме "Restricted"
    - Управлять опубликованными шаблонами

**Настройка: Видимость галереи шаблонов**
15. Выпадающий список "Template gallery visibility":
    - All organization members (Все сотрудники организации)
    - Specific organizational units (Определенные подразделения)
    - Specific groups (Определенные группы пользователей)
16. Администратор выбирает, кто может видеть галерею корпоративных шаблонов
17. При выборе "Specific" открывается интерфейс выбора подразделений/групп

**Настройка: Разрешения на создание категорий**
18. Чекбокс "Allow users to create categories"
    - Если включен: пользователи могут создавать новые категории при отправке шаблонов
    - Если выключен: только администраторы создают категории
19. Администратор устанавливает нужное значение

**Настройка: Уведомления**
20. Секция "Notification settings":
    - Чекбокс "Notify moderators when new template is submitted"
    - Чекбокс "Notify authors when template is approved/rejected"
    - Выбор канала уведомлений (Email, в будущем - Chat)
21. Администратор настраивает предпочтения уведомлений

**Сохранение настроек:**
22. Администратор нажимает кнопку "Save" внизу страницы
23. Система:
    - Сохраняет все настройки
    - Применяет изменения для всей организации
    - Отображает подтверждение: "Template settings saved"
24. Изменения вступают в силу в течение нескольких минут
25. Пользователи видят обновленные настройки при следующем обращении к шаблонам

**Альтернативные сценарии:**
- Сценарий А (Отмена изменений): Администратор нажимает "Cancel" для отмены несохраненных изменений
- Сценарий Б (Настройки по умолчанию): Администратор нажимает "Reset to defaults" для возврата к стандартным настройкам
- Сценарий В (Настройка по подразделениям): Администратор может настроить разные политики для разных organizational units

**Бизнес-правила:**
- BR-047: Функция корпоративных шаблонов доступна только в платных версиях Google Workspace (Business, Enterprise, Education)
- BR-048: При отключении "Enable custom templates" существующие шаблоны сохраняются, но становятся невидимыми
- BR-049: Изменение режима модерации не влияет на уже опубликованные шаблоны
- BR-050: Привилегия "Docs Templates" может быть назначена только внутри домена организации
- BR-051: Модераторы не могут изменять настройки шаблонов, только администраторы
- BR-052: При удалении привилегии у модератора, его ожидающие решения шаблоны передаются другим модераторам
- BR-053: Настройки применяются ко всем приложениям Google Workspace (Forms, Docs, Sheets, Slides)

**Результат:** Настройки прав доступа сохранены и применены для всей организации

### FR-TMPL-010: Управление опубликованными шаблонами организации

**Описание:** Администраторы и модераторы могут просматривать, редактировать метаданные и удалять опубликованные корпоративные шаблоны.

**Роли:** Администратор Google Workspace, Модератор шаблонов

**Предусловия:**
- Пользователь имеет права администратора или модератора
- В организации есть опубликованные шаблоны
- Функция корпоративных шаблонов включена

**Основной сценарий:**

2. Переходит в Apps > Google Workspace > Drive and Docs > Templates
3. Открывает вкладку "Published templates" или "Organization templates"
4. Система отображает список всех опубликованных шаблонов в виде таблицы:
   - Колонка "Name" (Название шаблона)
   - Колонка "Category" (Категория)
   - Колонка "Author" (Автор - кто создал/отправил)
   - Колонка "Published date" (Дата публикации)
   - Колонка "Usage count" (Количество использований) - сколько раз был скопирован
   - Колонка "Featured" (Рекомендуемый) - бейдж/чекбокс
   - Колонка "Actions" (Действия)
5. Модератор может:
   - Фильтровать шаблоны по категории
   - Сортировать по дате, популярности, названию

   - Просматривать детали каждого шаблона

6. Модератор нажимает на название шаблона или кнопку "View details"
7. Система открывает страницу деталей шаблона:
   - Превью формы
   - Метаданные:
     - Название
     - Описание
     - Категория
     - Автор
     - Дата создания и публикации
     - Дата последнего обновления
     - Статистика использования (сколько раз скопирован, когда последний раз)
   - Кнопки действий: Edit metadata, Preview form, Remove from gallery, Make featured/Remove featured
8. Модератор может нажать "Preview form" для просмотра формы как пользователь

**Редактирование метаданных:**
9. Модератор нажимает "Edit metadata"
10. Система открывает диалог редактирования:
    - Поле "Template name" (текущее название)
    - Поле "Description" (текущее описание)
    - Выпадающий список "Category" (текущая категория)
    - Чекбокс "Featured" (отметить как рекомендуемый)
    - Поле "Tags" (теги для поиска) - опционально
11. Модератор вносит изменения:
    - Изменяет название для большей ясности
    - Улучшает описание
    - Перемещает в другую категорию, если необходимо
    - Помечает как Featured для выделения в галерее
12. Модератор нажимает "Save changes"
13. Система:
    - Обновляет метаданные шаблона
    - Сохраняет историю изменений (кто, когда, что изменил)
    - Обновляет отображение в галерее для пользователей
    - Отправляет уведомление автору об изменениях (опционально)
14. Изменения отображаются в галерее в течение нескольких минут

**Удаление шаблона из галереи:**
15. Модератор нажимает "Remove from gallery" или иконку удаления
16. Система открывает диалог подтверждения:
    - "Remove template '[Name]' from organization gallery?"
    - Предупреждение: "This template will no longer be available to users. Forms created from this template will not be affected."
    - Поле "Reason for removal" (причина) - опционально
17. Модератор подтверждает удаление
18. Система:
    - Удаляет шаблон из галереи организации
    - Сохраняет копию в архиве (на случай восстановления)
    - Отправляет уведомление автору (если настроено)
    - Логирует действие в audit log
19. Шаблон исчезает из галереи для пользователей
20. Формы, уже созданные на основе этого шаблона, остаются без изменений

**Пометка как рекомендуемого (Featured):**
21. Модератор может быстро пометить шаблон как Featured прямо из списка
22. Нажимает иконку звезды или чекбокс "Featured" в таблице
23. Система помечает шаблон для приоритетного отображения:
    - Отображается в секции "Featured templates" в верхней части галереи
    - Имеет специальный бейдж "Recommended" или "Featured"
    - Может быть закреплен на главной странице шаблонов

**Альтернативные сценарии:**
- Сценарий А (Массовые действия): Модератор может выбрать несколько шаблонов и применить действие (изменить категорию, удалить) ко всем сразу
- Сценарий Б (Восстановление удаленного): Администратор может восстановить удаленный шаблон из архива
- Сценарий В (Экспорт списка): Модератор может экспортировать список шаблонов в CSV для отчетности
- Сценарий Г (Обновление шаблона): Автор или модератор может обновить содержимое шаблона, загрузив новую версию формы

**Бизнес-правила:**
- BR-054: Модераторы могут редактировать метаданные любых шаблонов, включая созданные другими
- BR-055: Только администраторы могут окончательно удалить шаблоны из системы (модераторы убирают из галереи)
- BR-056: История изменений шаблона сохраняется для аудита
- BR-057: Удаление шаблона не влияет на формы, созданные на его основе
- BR-058: Максимальное количество Featured шаблонов: 10 одновременно
- BR-059: Статистика использования обновляется в реальном времени
- BR-060: Модераторы не могут редактировать содержимое формы-шаблона, только метаданные
- BR-061: При изменении категории шаблон перемещается в новую категорию в галерее

**Результат:** Опубликованные шаблоны эффективно управляются, метаданные актуальны, неактуальные шаблоны удалены

### FR-TMPL-011: Поиск и фильтрация шаблонов

**Описание:** Пользователи могут искать нужные шаблоны по ключевым словам и фильтровать их по категориям для быстрого нахождения подходящего варианта.

**Роли:** Все пользователи Google Forms, Пользователи Google Workspace

**Предусловия:**
- Пользователь находится в галерее шаблонов
- Существуют доступные шаблоны (встроенные Google или корпоративные)

**Основной сценарий:**

**Фильтрация по категориям:**
1. Пользователь открывает галерею шаблонов на главной странице Google Forms
2. Система отображает вкладки категорий:
   - Personal (Личные)
   - Work (Рабочие)
   - Education (Образовательные)
   - [Organization Name] (Корпоративные - для Workspace пользователей)
3. Пользователь нажимает на вкладку категории
4. Система фильтрует и отображает только шаблоны выбранной категории
5. Для корпоративных шаблонов могут быть подкатегории:
   - HR, Marketing, Sales, IT Support, Events и т.д.
6. Пользователь может нажать на подкатегорию для дальнейшей фильтрации
7. Система отображает шаблоны только выбранной подкатегории

**Поиск по ключевым словам:**
8. Пользователь видит строку поиска в верхней части галереи шаблонов
9. Пользователь кликает на поле поиска
10. Пользователь вводит ключевое слово или фразу, например:
    - "registration" (регистрация)
    - "feedback" (обратная связь)
    - "survey" (опрос)
    - "order" (заказ)
    - "application" (заявка)
11. Система в реальном времени (после паузы в 0.5 сек) фильтрует шаблоны:
    - Поиск по названию шаблона
    - Поиск по описанию шаблона
    - Поиск по тегам (если настроены)
    - Поиск по содержимому вопросов (опционально)
12. Система отображает результаты поиска:
    - Шаблоны, соответствующие критериям поиска
    - Подсветка найденных ключевых слов в названии/описании
    - Количество найденных результатов: "Found 5 templates matching 'feedback'"
13. Если результатов нет:
    - Система показывает сообщение "No templates found for '[keyword]'"
    - Предлагает: "Try different keywords or browse categories"
    - Может показать похожие предложения "Did you mean: [suggestion]?"

**Комбинированная фильтрация:**
14. Пользователь может комбинировать поиск и фильтры:
    - Сначала выбирает категорию (например, "Work")
    - Затем вводит ключевое слово (например, "request")
    - Система показывает только рабочие шаблоны, содержащие "request"
15. Пользователь может применить дополнительные фильтры (если доступны):
    - Сортировка: "Most popular", "Recently added", "Alphabetical"
    - Для Workspace: "Organization templates only" или "Google templates only"
    - Featured templates (Рекомендуемые)

**Очистка фильтров:**
16. Пользователь может нажать "Clear" или иконку "X" в поле поиска для сброса
17. Система сбрасывает фильтры и показывает все доступные шаблоны
18. Пользователь может нажать "All" в вкладках категорий для просмотра всех шаблонов

**Альтернативные сценарии:**
- Сценарий А (Автодополнение): При вводе в поиск система предлагает популярные поисковые запросы
- Сценарий Б (История поиска): Система может показывать недавние поисковые запросы пользователя
- Сценарий В (Рекомендации): После поиска система может показать "Related templates" (Похожие шаблоны)
- Сценарий Г (Расширенный поиск): Пользователь может открыть панель расширенного поиска с дополнительными критериями

**Бизнес-правила:**
- BR-062: Поиск не чувствителен к регистру (case-insensitive)
- BR-063: Поиск поддерживает частичное совпадение слов
- BR-064: Результаты поиска сортируются по релевантности (точное совпадение в названии выше)
- BR-065: Поиск работает только по доступным пользователю шаблонам (с учетом прав доступа)
- BR-066: Минимальная длина поискового запроса: 2 символа
- BR-067: Поиск сохраняется в истории браузера для быстрого повтора
- BR-068: Featured шаблоны имеют приоритет в результатах поиска
- BR-069: Для Workspace пользователей корпоративные шаблоны могут иметь приоритет в поиске

**Результат:** Пользователь быстро находит нужный шаблон с помощью фильтрации и поиска

### FR-TMPL-012: Статистика использования шаблонов (для администраторов)

**Описание:** Администраторы Google Workspace могут просматривать аналитику и статистику использования корпоративных шаблонов.

**Роли:** Администратор Google Workspace, Модератор шаблонов

**Предусловия:**
- Пользователь имеет права администратора или модератора
- В организации есть корпоративные шаблоны
- Пользователи создают формы на основе шаблонов

**Основной сценарий:**
1. Администратор входит в Admin Console
2. Переходит в Apps > Google Workspace > Drive and Docs > Templates
3. Открывает вкладку "Analytics" или "Template usage"
4. Система отображает дашборд статистики с ключевыми метриками:

**Общая статистика:**
5. Верхняя панель с карточками KPI:
   - **Total templates** (Всего шаблонов): общее количество опубликованных шаблонов
   - **Total usage** (Всего использований): сколько раз шаблоны были использованы для создания форм
   - **Active users** (Активные пользователи): сколько уникальных пользователей использовали шаблоны
   - **Templates added this month** (Добавлено в этом месяце): новые шаблоны за текущий месяц
6. Каждая метрика показывает:
   - Текущее значение
   - Изменение относительно предыдущего периода (↑ 15% или ↓ 5%)
   - Мини-график тренда

**Топ популярных шаблонов:**
7. Секция "Most used templates" (Самые используемые шаблоны):
   - Таблица с рейтингом топ-10 шаблонов
   - Колонки:
     - Rank (Место в рейтинге)
     - Template name (Название)
     - Category (Категория)
     - Usage count (Количество использований)
     - Unique users (Уникальные пользователи)
     - Last used (Последнее использование)
8. Администратор может кликнуть на шаблон для детальной статистики

**Статистика по категориям:**
9. Секция "Usage by category" (Использование по категориям):
   - Круговая диаграмма или столбчатая диаграмма
   - Показывает распределение использования шаблонов по категориям
   - Например: HR - 35%, Marketing - 25%, Sales - 20%, IT - 15%, Other - 5%
10. Администратор может нажать на сегмент для детализации

**Временная динамика:**
11. Секция "Usage over time" (Использование со временем):
    - Линейный график за последние 30/90/365 дней (переключаемый период)
    - Показывает количество использований шаблонов по дням/неделям/месяцам
    - Может отображать несколько линий для разных категорий
12. Администратор может выбрать период для анализа:
    - Last 7 days (Последние 7 дней)
    - Last 30 days (Последние 30 дней)
    - Last 90 days (Последние 90 дней)
    - Custom range (Выбрать даты)

**Детальная статистика по шаблону:**
13. Администратор нажимает на конкретный шаблон из списка
14. Система открывает детальную страницу статистики шаблона:
    - Название и описание шаблона
    - Превью шаблона
    - Метрики:
      - Total times used (Всего использований)
      - Unique users (Уникальные пользователи)
      - First used date (Дата первого использования)
      - Last used date (Дата последнего использования)
      - Average usage per month (Среднее использование в месяц)
    - График использования во времени
    - Список пользователей, использовавших шаблон:
      - Имя пользователя
      - Дата использования
      - Название созданной формы (если доступно)
    - Подразделения/группы, использующие шаблон больше всего

**Экспорт данных:**
15. Администратор может нажать кнопку "Export" для выгрузки данных
16. Система предлагает формат экспорта:
    - CSV (для таблиц)
    - PDF (для отчета с графиками)
17. Администратор выбирает данные для экспорта:
    - All templates statistics (Вся статистика)
    - Specific template (Конкретный шаблон)
    - Custom date range (Определенный период)
18. Система генерирует файл и предлагает скачать

**Альтернативные сценарии:**
- Сценарий А (Scheduled reports): Администратор может настроить автоматическую отправку еженедельных/ежемесячных отчетов на email
- Сценарий Б (Неиспользуемые шаблоны): Система может показывать шаблоны, которые не использовались более 90 дней для ревизии
- Сценарий В (Сравнение периодов): Администратор может сравнить использование текущего месяца с предыдущим

**Бизнес-правила:**
- BR-070: Статистика обновляется с задержкой до 24 часов
- BR-071: Учитываются только формы, созданные пользователями организации
- BR-072: Данные статистики хранятся минимум 1 год
- BR-073: Администратор видит статистику всех шаблонов организации
- BR-074: Модераторы видят статистику только шаблонов, которые они одобрили (или всех - зависит от настроек)
- BR-075: Личная информация пользователей защищена (отображаются только имена из directory)
- BR-076: Статистика не включает формы, созданные из личных шаблонов пользователей
- BR-077: Графики обновляются в реальном времени при изменении фильтров

**Результат:** Администратор получает полное представление об использовании корпоративных шаблонов для принятия решений об управлении галереей

### FR-TMPL-013: Обновление существующего шаблона организации

**Описание:** Автор шаблона или модератор может обновить содержимое опубликованного корпоративного шаблона новой версией.

**Роли:** Создатель корпоративного шаблона, Модератор шаблонов, Администратор Google Workspace

**Предусловия:**
- Шаблон опубликован в галерее организации
- Пользователь является автором шаблона или имеет права модератора
- Необходимо внести изменения в шаблон (добавить вопросы, исправить ошибки, обновить дизайн)

**Основной сценарий:**

**Вариант А - Обновление через Admin Console (для модераторов/администраторов):**
1. Модератор входит в Admin Console
2. Переходит в Apps > Google Workspace > Drive and Docs > Templates > Published templates
3. Находит шаблон, который нужно обновить
4. Нажимает на шаблон для открытия деталей
5. Система показывает кнопку "Update template" или "Replace template"
6. Модератор нажимает "Update template"
7. Система открывает диалог "Update template":
   - Опция A: "Update from existing form" - выбрать форму из Drive для замены
   - Опция B: "Edit template directly" - открыть текущий шаблон для редактирования
8. Модератор выбирает опцию:

**Опция A - Замена из существующей формы:**
9. Модератор нажимает "Update from existing form"
10. Система открывает файловый браузер Google Drive
11. Модератор выбирает обновленную форму, которая заменит текущий шаблон
12. Модератор нажимает "Select"
13. Система показывает превью обеих версий для сравнения:
    - Текущий шаблон (слева)
    - Новая версия (справа)
14. Модератор может добавить "Update notes" (примечания об обновлении):
    - Например: "Добавлены новые вопросы о департаменте", "Исправлены опечатки", "Обновлен дизайн"
15. Модератор нажимает "Update template"
16. Система:
    - Архивирует предыдущую версию шаблона
    - Заменяет содержимое шаблона новой версией
    - Сохраняет метаданные (название, описание, категорию)
    - Обновляет дату последнего изменения
    - Увеличивает номер версии (v1 → v2)
17. Обновленный шаблон сразу доступен в галерее

**Опция B - Прямое редактирование:**
18. Модератор нажимает "Edit template directly"
19. Система открывает форму-шаблон в режиме редактирования Google Forms
20. Модератор вносит необходимые изменения:
    - Добавляет/удаляет/изменяет вопросы
    - Обновляет логику ветвления
    - Меняет тему оформления
    - Корректирует описание
21. Все изменения автоматически сохраняются
22. Модератор закрывает редактор
23. Система автоматически обновляет шаблон в галерее
24. Увеличивается номер версии

**Вариант Б - Обновление автором шаблона:**
25. Автор открывает Google Forms
26. Создает обновленную версию формы или редактирует существующую
27. Открывает меню формы (три точки) > "Update organization template"
28. Если автор имеет несколько опубликованных шаблонов:
    - Система показывает список: "Which template do you want to update?"
    - Автор выбирает нужный шаблон
29. Система показывает подтверждение:
    - "Update template '[Name]' with this form?"
    - Поле для примечаний об обновлении
30. Автор подтверждает
31. В зависимости от режима модерации:
    - **Open mode**: обновление применяется немедленно
    - **Moderated mode**: обновление отправляется на одобрение модераторам
    - **Restricted mode**: доступно только модераторам
32. Если требуется модерация:
    - Модераторы получают уведомление
    - Одобряют или отклоняют обновление
    - После одобрения обновленная версия публикуется

**Уведомления об обновлении:**
33. Система может уведомить пользователей об обновлении шаблона:
    - Пользователям, которые использовали этот шаблон в прошлом
    - Email с описанием изменений и возможностью просмотреть обновленную версию
    - Уведомление при следующем посещении галереи шаблонов
34. Уведомление содержит:
    - Название шаблона
    - Что изменилось (из примечаний об обновлении)
    - Ссылку на новую версию шаблона
    - Информацию, что уже созданные формы не затронуты

**Альтернативные сценарии:**
- Сценарий А (Откат к предыдущей версии): Модератор может откатить обновление, выбрав предыдущую версию из архива
- Сценарий Б (Просмотр истории версий): Модератор может просмотреть все версии шаблона и их изменения
- Сценарий В (Отклонение обновления): Модератор отклоняет предложенное обновление с объяснением причины

**Бизнес-правила:**
- BR-078: Обновление шаблона не влияет на формы, уже созданные пользователями на основе предыдущей версии
- BR-079: Метаданные (название, описание, категория) сохраняются при обновлении содержимого
- BR-080: Предыдущие версии шаблонов сохраняются в архиве минимум 1 год
- BR-081: Максимальное количество версий шаблона: 50
- BR-082: Статистика использования сбрасывается при обновлении или сохраняется - зависит от настроек
- BR-083: URL шаблона остается неизменным при обновлении
- BR-084: Обновления могут требовать модерации в зависимости от настроек организации
- BR-085: Featured статус сохраняется при обновлении шаблона

**Результат:** Шаблон обновлен с новой версией, пользователи получают доступ к улучшенному шаблону

### FR-TMPL-014: Копирование шаблона для кастомизации

**Описание:** Пользователь может создать копию существующего корпоративного или личного шаблона для дальнейшей кастомизации под свои нужды.

**Роли:** Все пользователи Google Forms, Пользователи Google Workspace

**Предусловия:**
- Пользователь имеет доступ к шаблону (встроенному, корпоративному или личному)
- Пользователь хочет создать модифицированную версию для другого случая использования

**Основной сценарий:**
1. Пользователь находит подходящий шаблон в галерее
2. Пользователь открывает предварительный просмотр шаблона
3. Вместо "Use template" пользователь видит опцию "Make a copy for customization" (в некоторых интерфейсах)
4. Или пользователь сначала создает форму из шаблона стандартным способом (FR-TMPL-003)
5. После создания формы пользователь вносит существенные изменения:
   - Добавляет специфичные для своего департамента вопросы
   - Меняет структуру разделов
   - Настраивает уникальную логику ветвления
   - Применяет кастомный дизайн
   - Адаптирует под конкретный проект
6. Пользователь решает сохранить эту кастомизированную версию как свой личный шаблон
7. Пользователь использует один из методов:

**Метод А - Сохранение в папку шаблонов (как в FR-TMPL-004):**
8. Пользователь перемещает кастомизированную форму в свою папку "Templates" в Google Drive
9. Форма становится доступной для повторного копирования

**Метод Б - Предложение как нового корпоративного шаблона (для Workspace):**
10. Если кастомизированная версия полезна для всей организации
11. Пользователь может предложить её как новый шаблон (FR-TMPL-006)
12. Шаблон проходит модерацию и добавляется в галерею организации как отдельный вариант

**Создание вариантов шаблона:**
13. Пользователь может создать несколько вариантов одного базового шаблона:
    - Например, базовый шаблон "Event Registration"
    - Вариант 1: "Conference Registration" (с вопросами о сессиях)
    - Вариант 2: "Workshop Registration" (с вопросами о материалах)
    - Вариант 3: "Webinar Registration" (с вопросами о часовом поясе)
14. Пользователь создает каждый вариант, начиная с базового шаблона
15. Кастомизирует под конкретный сценарий
16. Сохраняет в свою библиотеку или предлагает в корпоративную галерею

**Альтернативные сценарии:**
- Сценарий А (Remix шаблона): Пользователь комбинирует элементы из нескольких шаблонов в одной форме
- Сценарий Б (Шаблон из существующей формы): Пользователь создает шаблон из успешно использованной формы для будущих событий
- Сценарий В (Запрос на вариант): Пользователь может запросить у модераторов создание варианта существующего шаблона

**Бизнес-правила:**
- BR-086: Копия шаблона является полностью независимой формой
- BR-087: Пользователь может свободно изменять свою копию без ограничений
- BR-088: Связь с оригинальным шаблоном не поддерживается (нет автообновления)
- BR-089: Кастомизированные копии не учитываются в статистике использования оригинального шаблона
- BR-090: Пользователь может создать неограниченное количество вариантов
- BR-091: При копировании сохраняется структура, вопросы, логика, но не ответы
- BR-092: Копия получает новый уникальный ID формы

**Результат:** Пользователь создал кастомизированную версию шаблона для своих специфических нужд

### FR-TMPL-015: Рекомендации шаблонов на основе контекста

**Описание:** Система предлагает релевантные шаблоны пользователю на основе его предыдущей активности, роли в организации или текущего контекста.

**Роли:** Все пользователи Google Forms, Пользователи Google Workspace

**Предусловия:**
- Пользователь аутентифицирован
- Система имеет данные о предыдущей активности пользователя
- Доступны шаблоны для рекомендации

**Основной сценарий:**

**Рекомендации на главной странице:**
1. Пользователь заходит на главную страницу Google Forms (forms.google.com)
2. Система анализирует контекст пользователя:
   - Предыдущие созданные формы и использованные шаблоны
   - Роль в организации (из Google Workspace Directory)
   - Департамент/группа (HR, Marketing, Sales и т.д.)
   - Недавние события в календаре Google Calendar (опционально)
   - Время года/период (начало учебного года, сезон отпусков и т.д.)
3. Система отображает секцию "Recommended for you" (Рекомендовано для вас)
4. Секция содержит 3-5 персонализированных шаблонов:
   - Для HR менеджера: "Job Application", "Time Off Request", "Employee Feedback"
   - Для преподавателя: "Quiz Template", "Student Feedback", "Course Evaluation"
   - Для event-менеджера: "Event Registration", "RSVP", "Post-Event Survey"
5. Каждая рекомендация показывает:
   - Название и превью шаблона
   - Краткое объяснение: "Based on your role in HR" или "Popular in your organization"
   - Кнопку "Use template"

**Рекомендации на основе истории:**
6. Если пользователь ранее создавал определенный тип форм:
   - Например, несколько регистрационных форм
   - Система предлагает: "You might also like these registration templates"
7. Показываются похожие или более продвинутые шаблоны того же типа

**Контекстные рекомендации:**
8. При создании новой формы с нуля:
   - Пользователь нажимает "Create blank form"
   - После добавления 2-3 вопросов система анализирует содержание
   - Если вопросы похожи на существующий шаблон, система показывает подсказку:
     "💡 Tip: Looks like you're creating a feedback form. Would you like to use our Event Feedback template as a starting point?"
   - Кнопки: "Switch to template" или "Continue from scratch"
9. Если пользователь выбирает "Switch to template":
   - Система предлагает сохранить текущий прогресс
   - Открывает шаблон с возможностью перенести уже созданные вопросы

**Сезонные и временные рекомендации:**
10. Система учитывает время года и показывает актуальные шаблоны:
    - Сентябрь (начало учебного года): "Course Evaluation", "Student Information"
    - Декабрь: "Holiday Party RSVP", "Year-End Feedback"
    - Январь: "New Year Goals Survey", "Annual Performance Review"
11. Для организаций - учет корпоративных циклов:
    - Перед кварталом: "Quarterly Planning Survey"
    - Время performance reviews: "Employee Self-Assessment"

**Рекомендации "Часто используются вместе":**
12. Если пользователь использовал определенный шаблон, система предлагает:
    "Teams using '[Template A]' also found these helpful:"
13. Показывает 2-3 комплементарных шаблона
    - Например, после "Event Registration" предлагает "Event Feedback" и "Post-Event Survey"

**Альтернативные сценарии:**
- Сценарий А (Отключение рекомендаций): Пользователь может скрыть секцию рекомендаций в настройках
- Сценарий Б (Feedback на рекомендации): Пользователь может отметить рекомендацию как полезную/неполезную для улучшения алгоритма
- Сценарий В (Организационные рекомендации): Администратор может настроить приоритетные шаблоны для определенных ролей

**Бизнес-правила:**
- BR-093: Рекомендации основаны на агрегированных данных, личная информация защищена
- BR-094: Пользователь может отключить персонализированные рекомендации через настройки приватности
- BR-095: Система не использует содержимое ответов на формы для рекомендаций
- BR-096: Featured шаблоны организации имеют приоритет в рекомендациях для Workspace пользователей
- BR-097: Алгоритм учитывает успешность шаблонов (rate of completion, low abandonment)
- BR-098: Рекомендации обновляются в реальном времени при изменении контекста
- BR-099: Максимальное количество рекомендаций на странице: 5, чтобы не перегружать интерфейс

**Результат:** Пользователь получает персонализированные рекомендации шаблонов, ускоряющие создание нужных форм

## Нефункциональные требования

### NFR-TMPL-001: Производительность галереи шаблонов

**Описание:** Галерея шаблонов должна загружаться и отображаться быстро для обеспечения хорошего пользовательского опыта.

**Требования:**
- Время загрузки главной страницы с галереей шаблонов: не более 2 секунд
- Превью шаблонов генерируются и кешируются для мгновенного отображения
- Ленивая загрузка (lazy loading) для шаблонов, не видимых на экране
- Переключение между категориями: менее 500 мс
- Отклик на поисковый запрос: в реальном времени (менее 300 мс задержки)
- Открытие предварительного просмотра шаблона: не более 1.5 секунд
- Поддержка до 500 корпоративных шаблонов без деградации производительности

---

### NFR-TMPL-002: Масштабируемость системы шаблонов

**Описание:** Система должна поддерживать работу с большим количеством шаблонов и пользователей.

**Требования:**
- Поддержка до 1000 корпоративных шаблонов на организацию
- Одновременная работа до 10,000 пользователей с галереей шаблонов
- Обработка до 100 запросов на модерацию в день
- Масштабирование при росте количества шаблонов без ухудшения поиска
- Эффективная индексация для быстрого поиска среди тысяч шаблонов

---

### NFR-TMPL-003: Доступность и совместимость

**Описание:** Галерея шаблонов должна быть доступна на различных платформах и устройствах.

**Требования:**
- Адаптивный дизайн для работы на desktop, tablet, mobile устройствах
- Поддержка браузеров: Chrome, Firefox, Safari, Edge (последние 2 версии)
- Соответствие стандартам веб-доступности WCAG 2.1 уровня AA
- Поддержка навигации с клавиатуры (Tab, Enter, Esc)
- Screen reader совместимость для пользователей с ограниченными возможностями
- Оффлайн кеширование списка недавно просмотренных шаблонов (PWA функциональность)

---

### NFR-TMPL-004: Безопасность и приватность шаблонов

**Описание:** Система должна обеспечивать защиту конфиденциальности и безопасность шаблонов.

**Требования:**
- Корпоративные шаблоны видны только пользователям домена организации
- Шифрование данных шаблонов при передаче (HTTPS/TLS)
- Контроль доступа на уровне категорий и групп пользователей
- Аудит логирование всех действий с шаблонами (создание, изменение, удаление, модерация)
- Защита от injection атак при поиске и фильтрации
- Предотвращение утечки конфиденциальной информации через публичные шаблоны
- Автоматическое сканирование шаблонов на наличие чувствительных данных (номера карт, SSN и т.д.)

---

### NFR-TMPL-005: Надежность и доступность системы

**Описание:** Система шаблонов должна быть надежной и доступной.

**Требования:**
- Uptime (доступность) галереи шаблонов: 99.9% (SLA)
- Автоматическое резервное копирование корпоративных шаблонов (daily backups)
- Возможность восстановления удаленных шаблонов в течение 30 дней
- Graceful degradation: при недоступности корпоративных шаблонов встроенные Google шаблоны остаются доступными
- Обработка ошибок с понятными сообщениями пользователю
- Автоматическое сохранение прогресса при создании/редактировании шаблонов

---

### NFR-TMPL-006: Локализация и интернационализация

**Описание:** Галерея шаблонов должна поддерживать множество языков и локалей.

**Требования:**
- Поддержка интерфейса на всех языках, поддерживаемых Google Forms (100+ языков)
- Встроенные шаблоны Google доступны на основных языках (английский, испанский, французский, немецкий, русский, японский, китайский и др.)
- Корпоративные шаблоны могут быть созданы на любом языке
- Правильное отображение RTL языков (арабский, иврит)
- Локализация названий категорий и описаний шаблонов
- Поиск работает с учетом локали и специфики языка

---

### NFR-TMPL-007: Юзабилити и пользовательский опыт

**Описание:** Работа с шаблонами должна быть интуитивной и удобной.

**Требования:**
- Превью шаблонов должны точно отражать финальный вид формы
- Понятные названия и описания шаблонов для быстрого выбора
- Визуальная индикация различий между Google шаблонами и корпоративными
- Подсказки и tooltips для объяснения функций (например, что такое Featured)
- Онбординг для администраторов при первой настройке корпоративных шаблонов
- Отмена действий (undo) при случайном удалении шаблона
- Прогресс-индикаторы при длительных операциях (загрузка большого шаблона)

---

### NFR-TMPL-008: Интеграция с экосистемой Google Workspace

**Описание:** Шаблоны должны интегрироваться с другими сервисами Google.

**Требования:**
- Бесшовная работа с Google Drive для хранения форм-шаблонов
- Интеграция с Google Admin Console для управления настройками
- Синхронизация прав доступа с Google Groups и Organizational Units
- Единый SSO (Single Sign-On) через Google аккаунты
- Использование Google Cloud для хранения и обработки шаблонов
- Совместимость с Google Workspace APIs для программного доступа к шаблонам (для enterprise интеграций)

## Ограничения и зависимости

### Ограничения
- Встроенная галерея Google содержит ограниченное количество шаблонов (около 15-20)
- Google Forms не имеет нативной функции "сохранить как личный шаблон" - пользователи управляют через Google Drive
- Корпоративные шаблоны доступны только в платных тарифах Google Workspace
- Шаблоны не могут содержать предзаполненные ответы респондентов
- Изменения в оригинальном шаблоне не распространяются на созданные формы
- Максимальное количество категорий: 50 на организацию
- Максимальное количество Featured шаблонов: 10 одновременно

### Зависимости
- **Google Drive**: для хранения форм-шаблонов и личных библиотек
- **Google Admin Console**: для управления корпоративными шаблонами (только Workspace)
- **Google Cloud Platform**: для серверной инфраструктуры и хранения
- **Google Workspace Directory**: для определения ролей и подразделений пользователей
- **Система аутентификации Google**: для контроля доступа к шаблонам
- **Модуль создания форм**: шаблоны используют те же ограничения (300 элементов, 75 разделов)

## Глоссарий

- **Шаблон (Template)** - предварительно созданная форма с готовой структурой вопросов, которую можно использовать как основу для новых форм
- **Галерея шаблонов (Template Gallery)** - коллекция доступных шаблонов, организованная по категориям
- **Встроенные шаблоны Google (Google built-in templates)** - шаблоны, предоставленные Google для всех пользователей
- **Корпоративные шаблоны (Organization templates)** - шаблоны, созданные и управляемые организацией для своих сотрудников
- **Featured шаблон (Featured/Recommended template)** - шаблон, отмеченный как рекомендуемый для приоритетного отображения
- **Модерация (Moderation)** - процесс одобрения/отклонения предложенных шаблонов перед публикацией
- **Категория (Category)** - группа шаблонов, объединенных по назначению (например, HR, Marketing)
- **Привилегия Docs Templates** - специальное право в Google Workspace для модерации и управления шаблонами
- **Кастомизация (Customization)** - процесс изменения шаблона под конкретные нужды
- **Use template** - действие создания новой формы на основе выбранного шаблона
- **Template submission** - отправка шаблона для добавления в галерею организации
- **Template version** - версия шаблона при обновлении содержимого
- **Personal templates** - личные шаблоны пользователя, хранящиеся в его Google Drive

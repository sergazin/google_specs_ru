# 03. Типы вопросов и поля ввода

## Обзор модуля
Модуль типов вопросов предоставляет разнообразные форматы для сбора информации от респондентов. Google Forms поддерживает 12 различных типов вопросов, каждый из которых имеет свои настройки, правила валидации и ограничения.

---

## Функциональные требования

### FR-QUEST-001: Короткий ответ (Short Answer)
**Приоритет:** Высокий
**Описание:** Предоставление текстового поля для ввода короткого однострочного ответа.

**Детальная спецификация:**
- Однострочное текстовое поле для ввода
- Рекомендуется для ответов из нескольких слов
- Максимальная длина ответа не ограничена системой (но может быть задана валидацией)
- Поддержка автозаполнения браузера

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Подсказка внутри поля (placeholder)
- Обязательный/необязательный вопрос
- Валидация ответа
- Перемешивание порядка вопросов

**Правила валидации:**
1. **Число (Number)**
   - Больше чем (Greater than)
   - Меньше чем (Less than)
   - Равно (Equal to)
   - Не равно (Not equal to)
   - Между (Between)
   - Является числом (Is number)
   - Целое число (Whole number)
   - Настраиваемое сообщение об ошибке

2. **Текст (Text)**
   - Содержит (Contains)
   - Не содержит (Doesn't contain)
   - Email-адрес (Email)
   - URL-адрес (URL)
   - Настраиваемое сообщение об ошибке

3. **Длина (Length)**
   - Максимальное количество символов (Maximum character count)
   - Минимальное количество символов (Minimum character count)
   - Настраиваемое сообщение об ошибке

4. **Регулярное выражение (Regular Expression)**
   - Содержит (Contains)
   - Не содержит (Doesn't contain)
   - Совпадает (Matches)
   - Не совпадает (Doesn't match)
   - Настраиваемое сообщение об ошибке

**Примеры использования:**
- Имя, фамилия
- Номер телефона
- Email
- Город
- Краткий комментарий

**Ограничения:**
- Нет встроенного ограничения длины (только через валидацию)
- Не поддерживает форматированный текст
- Не поддерживает многострочный ввод

### FR-QUEST-002: Абзац (Paragraph)
**Приоритет:** Высокий
**Описание:** Предоставление многострочного текстового поля для развернутых ответов.

**Детальная спецификация:**
- Многострочное текстовое поле с автоматическим расширением
- Поддержка переносов строк
- Рекомендуется для длинных текстовых ответов
- Автоматическое изменение высоты поля при вводе

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Подсказка внутри поля
- Обязательный/необязательный вопрос
- Валидация ответа

**Правила валидации:**
1. **Длина (Length)**
   - Максимальное количество символов
   - Минимальное количество символов
   - Настраиваемое сообщение об ошибке

2. **Текст (Text)**
   - Содержит
   - Не содержит
   - Настраиваемое сообщение об ошибке

3. **Регулярное выражение (Regular Expression)**
   - Содержит
   - Не содержит
   - Совпадает
   - Не совпадает
   - Настраиваемое сообщение об ошибке

**Примеры использования:**
- Развернутые комментарии
- Описание проблемы
- Отзывы
- Предложения
- Эссе

**Ограничения:**
- Не поддерживает форматированный текст (жирный, курсив, списки)
- Не поддерживает вставку изображений
- Нет встроенной проверки орфографии (зависит от браузера)

### FR-QUEST-003: Один из списка (Multiple Choice)
**Приоритет:** Высокий
**Описание:** Предоставление списка вариантов, из которых можно выбрать только один.

**Детальная спецификация:**
- Список радиокнопок (radio buttons)
- Возможность выбрать только один вариант
- Визуальное отображение всех вариантов одновременно
- Поддержка добавления изображений к каждому варианту

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Список вариантов ответа (минимум 2)
- Обязательный/необязательный вопрос
- Перемешивание вариантов ответа
- Опция "Другое" с текстовым полем
- Изображения для каждого варианта

**Настройки вариантов:**
- Текст варианта
- Изображение варианта (необязательное)
- Переход к определенному разделу на основе выбора (условная логика)
- Отправка формы после выбора

**Дополнительные функции:**
- Условная логика (branching) - переход к разным разделам формы в зависимости от выбранного ответа
- Опция "Перейти к разделу на основе ответа"
- Возможность добавления неограниченного количества вариантов
- Быстрое добавление вариантов через Enter

**Примеры использования:**
- Выбор пола
- Возрастная категория
- Да/Нет вопросы
- Выбор предпочтения из списка
- Выбор одного продукта/услуги

**Ограничения:**
- Только один выбор (для множественного выбора используйте Checkboxes)
- Максимум 1000 вариантов ответа (практическое ограничение)

---

### FR-QUEST-004: Несколько из списка (Checkboxes)
**Приоритет:** Высокий
**Описание:** Предоставление списка вариантов с возможностью выбора нескольких пунктов.

**Детальная спецификация:**
- Список чекбоксов (checkboxes)
- Возможность выбрать несколько вариантов одновременно
- Визуальное отображение всех вариантов
- Поддержка изображений для каждого варианта

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Список вариантов ответа (минимум 2)
- Обязательный/необязательный вопрос
- Перемешивание вариантов ответа
- Опция "Другое" с текстовым полем
- Изображения для вариантов

**Правила валидации:**
1. **Количество выборов (Checkbox Validation)**
   - Выбрать как минимум (Select at least) N вариантов
   - Выбрать не более (Select at most) N вариантов
   - Выбрать точно (Select exactly) N вариантов
   - Настраиваемое сообщение об ошибке

**Дополнительные функции:**
- Условная логика на основе комбинации выбранных вариантов
- Возможность добавления неограниченного количества вариантов
- Быстрое добавление вариантов через Enter

**Примеры использования:**
- Интересы пользователя
- Множественный выбор навыков
- Выбор нескольких продуктов
- Дни недели
- Языки программирования

**Ограничения:**
- Максимум 1000 вариантов (практическое ограничение)
- Сложность условной логики при большом количестве комбинаций

---

### FR-QUEST-005: Раскрывающийся список (Dropdown)
**Приоритет:** Средний
**Описание:** Предоставление выпадающего списка для выбора одного варианта.

**Детальная спецификация:**
- Компактное отображение в виде выпадающего списка
- Экономия места на форме
- Один выбор из списка
- Идеально для длинных списков вариантов

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Список вариантов ответа (минимум 2)
- Обязательный/необязательный вопрос
- Перемешивание вариантов ответа

**Настройки вариантов:**
- Текст варианта
- Переход к определенному разделу на основе выбора

**Дополнительные функции:**
- Условная логика (переход к разделам)
- Автоматический поиск при вводе (для длинных списков)
- Возможность добавления большого количества вариантов
- Первый вариант может быть подсказкой ("Выберите опцию...")

**Примеры использования:**
- Выбор страны
- Выбор штата/региона
- Выбор из длинного списка категорий
- Выбор года
- Выбор месяца

**Ограничения:**
- Не поддерживает изображения для вариантов
- Не поддерживает множественный выбор
- Менее очевидный для пользователя чем Radio buttons
- Требует дополнительный клик для просмотра вариантов

### FR-QUEST-006: Сетка (множественный выбор) - Multiple Choice Grid
**Приоритет:** Средний
**Описание:** Матричная таблица с вопросами в строках и вариантами ответов в столбцах, один выбор на строку.

**Детальная спецификация:**
- Табличный формат вопроса
- Строки представляют подвопросы/утверждения
- Столбцы представляют варианты ответов
- Один выбор на каждую строку (радиокнопки)
- Компактное представление множества похожих вопросов

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Строки (подвопросы) - минимум 1
- Столбцы (варианты ответов) - минимум 2
- Обязательный/необязательный вопрос
- Требовать ответ на каждую строку
- Перемешивание строк
- Ограничение по одному ответу в столбце

**Настройки строк и столбцов:**
- Текст для каждой строки
- Текст для каждого столбца
- Возможность добавления/удаления строк и столбцов
- Быстрое копирование строк/столбцов

**Дополнительные функции:**
- Опция "Ограничить до одного ответа в столбце" - гарантирует уникальность выбора в каждом столбце
- Перемешивание порядка строк
- Настройка обязательности для каждой строки

**Примеры использования:**
- Оценка нескольких параметров по одной шкале
- Ранжирование нескольких элементов
- Матрица соответствия
- Расписание (дни недели × временные слоты)
- Оценка удовлетворенности по нескольким критериям

**Ограничения:**
- Максимум 1000 строк
- Максимум 75 столбцов
- Не поддерживает изображения в ячейках
- Не поддерживает условную логику на основе ответов
- Может быть сложным для заполнения на мобильных устройствах
- Не поддерживает валидацию ответов

---

### FR-QUEST-008: Линейная шкала (Linear Scale)
**Приоритет:** Высокий
**Описание:** Числовая шкала для оценки с настраиваемыми границами и подписями.

**Детальная спецификация:**
- Горизонтальная числовая шкала
- Выбор одного значения на шкале
- Визуальное представление в виде радиокнопок с числами
- Поддержка подписей для минимального и максимального значений

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Начальное значение шкалы: 0 или 1
- Конечное значение шкалы: от 2 до 10
- Подпись для минимального значения (обязательное)
- Подпись для максимального значения (обязательное)
- Обязательный/необязательный вопрос

**Доступные диапазоны шкалы:**
- От 0 до 2, 3, 4, 5, 6, 7, 8, 9, 10
- От 1 до 2, 3, 4, 5, 6, 7, 8, 9, 10

**Дополнительные функции:**
- Автоматическое вычисление баллов в режиме викторины
- Визуальное выделение при наведении
- Мгновенная обратная связь при выборе

**Примеры использования:**
- Оценка удовлетворенности (1-5)
- NPS (Net Promoter Score) - шкала 0-10
- Шкала согласия (категорически не согласен - категорически согласен)
- Уровень боли (медицинские формы)
- Оценка важности (низкая - высокая)
- Вероятность рекомендации

**Стандартные шкалы:**
- **Шкала Likert:** 1-5 (Категорически не согласен - Категорически согласен)
- **NPS:** 0-10 (Совсем не вероятно - Очень вероятно)
- **Удовлетворенность:** 1-5 (Очень неудовлетворен - Очень удовлетворен)

**Ограничения:**
- Максимальная шкала: 0-10 или 1-10
- Минимальная шкала: 2 значения
- Только целые числа
- Нет промежуточных значений (например, 3.5)
- Нельзя использовать отрицательные числа
- Нельзя изменить шаг шкалы (всегда +1)

### FR-QUEST-009: Дата (Date)
**Приоритет:** Средний
**Описание:** Поле для выбора или ввода даты с встроенным календарем.

**Детальная спецификация:**
- Интерактивный виджет календаря
- Ввод даты в формате, соответствующем локали пользователя
- Возможность ручного ввода или выбора из календаря
- Автоматическая валидация корректности даты

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Обязательный/необязательный вопрос
- Опция включения года

**Форматы даты:**
- С годом: MM/DD/YYYY (в зависимости от локали)
- Без года: MM/DD (только месяц и день)

**Дополнительные функции:**
- Встроенный календарь для выбора даты
- Навигация по месяцам и годам в календаре
- Автоматическая валидация формата
- Поддержка различных локальных форматов даты
- Возможность выбора даты в прошлом или будущем

**Примеры использования:**
- Дата рождения
- Дата события
- Дата начала/окончания
- Предпочтительная дата встречи
- Дата регистрации

**Ограничения:**
- Нет встроенной валидации диапазона дат (например, только будущие даты)
- Нельзя установить минимальную/максимальную дату
- Формат зависит от локали пользователя
- Не поддерживает выбор диапазона дат

---

### FR-QUEST-010: Время (Time)
**Приоритет:** Средний
**Описание:** Поле для ввода времени с поддержкой различных форматов.

**Детальная спецификация:**
- Поле ввода времени
- Поддержка 12-часового и 24-часового формата (зависит от локали)
- Выбор часов и минут
- Опциональное указание секунд и продолжительности

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Обязательный/необязательный вопрос
- Выбор типа времени:
  - Время дня (Time of day)
  - Продолжительность (Duration)

**Типы времени:**

1. **Время дня (Time of day)**
   - Формат: HH:MM AM/PM или HH:MM (24-часовой)
   - Выбор часов (0-23 или 1-12)
   - Выбор минут (0-59)
   - Выбор AM/PM (для 12-часового формата)

2. **Продолжительность (Duration)**
   - Часы
   - Минуты
   - Секунды
   - Формат: HH:MM:SS

**Дополнительные функции:**
- Автоматическое форматирование ввода
- Поддержка локальных форматов времени
- Валидация корректности времени

**Примеры использования:**
- Предпочтительное время звонка
- Время встречи
- Продолжительность активности
- Время начала/окончания работы
- Длительность проекта

**Ограничения:**
- Нет встроенного выбора временных слотов
- Нет валидации диапазона времени
- Формат зависит от локали пользователя
- Не поддерживает часовые пояса

---

### FR-QUEST-011: Загрузка файлов (File Upload)
**Приоритет:** Высокий
**Описание:** Возможность загрузки файлов респондентами с настройками ограничений.

**Детальная спецификация:**
- Загрузка файлов в Google Drive владельца формы
- Требует авторизации Google для респондентов
- Автоматическое создание папки для хранения файлов
- Поддержка различных типов файлов

**Настройки вопроса:**
- Текст вопроса (обязательное)
- Описание вопроса (необязательное)
- Обязательный/необязательный вопрос
- Разрешенные типы файлов
- Максимальное количество файлов
- Максимальный размер файла

**Типы файлов:**
- Документы (Documents)
- Таблицы (Spreadsheets)
- PDF
- Презентации (Presentations)
- Рисунки (Drawings)
- Изображения (Images)
- Видео (Videos)
- Аудио (Audio)
- Любой тип файла (Any file type)
- Настраиваемый выбор типов

### FR-QUEST-014: Валидация ответов
**Приоритет:** Высокий
**Описание:** Система проверки корректности введенных данных.

**Поддержка валидации по типам вопросов:**
- Short Answer: ✓ (все типы валидации)
- Paragraph: ✓ (ограниченная)
- Checkboxes: ✓ (только количество выборов)
- Multiple Choice: ✗
- Dropdown: ✗
- Linear Scale: ✗
- Multiple Choice Grid: ✗
- Checkbox Grid: ✗
- Date: ✗ (встроенная валидация формата)
- Time: ✗ (встроенная валидация формата)
- File Upload: ✓ (тип и размер файла)
- Rating: ✗

**Типы валидации:**

1. **Число (Number) - для Short Answer**
   - Является числом (Is number)
   - Целое число (Whole number)
   - Больше чем (Greater than)
   - Больше или равно (Greater than or equal to)
   - Меньше чем (Less than)
   - Меньше или равно (Less than or equal to)
   - Равно (Equal to)
   - Не равно (Not equal to)
   - Между (Between)
   - Не между (Not between)

2. **Текст (Text) - для Short Answer и Paragraph**
   - Содержит (Contains)
   - Не содержит (Doesn't contain)
   - Email-адрес (Email)
   - URL-адрес (URL)

3. **Длина (Length) - для Short Answer и Paragraph**
   - Максимальное количество символов (Maximum character count)
   - Минимальное количество символов (Minimum character count)

4. **Регулярное выражение (Regular Expression) - для Short Answer и Paragraph**
   - Содержит (Contains)
   - Не содержит (Doesn't contain)
   - Совпадает (Matches)
   - Не совпадает (Doesn't match)
   - Примеры регулярных выражений:
     - Номер телефона: `^\d{3}-\d{3}-\d{4}$`
     - Почтовый индекс (США): `^\d{5}(-\d{4})?$`
     - Имя пользователя: `^[a-zA-Z0-9_]{3,16}$`

5. **Количество выборов (Checkbox Validation) - для Checkboxes**
   - Выбрать как минимум (Select at least) N
   - Выбрать не более (Select at most) N
   - Выбрать точно (Select exactly) N

**Настраиваемое сообщение об ошибке:**
- Поле "Custom error text"
- Максимальная длина: 256 символов
- Отображается при несоблюдении правила валидации
- Поддержка Unicode (любые языки)
- Красный цвет текста для визуального выделения

**Популярные примеры валидации:**

1. **Email-адрес:**
   - Валидация: Text → Email
   - Сообщение: "Введите корректный email-адрес"

2. **Номер телефона (международный формат):**
   - Валидация: Regular Expression → Matches → `^\+?[1-9]\d{1,14}$`
   - Сообщение: "Введите номер телефона в формате +XXXXXXXXXXX"

3. **Номер телефона (США):**
   - Валидация: Regular Expression → Matches → `^(\+1|1)?[-.\s]?\(?[2-9]\d{2}\)?[-.\s]?\d{3}[-.\s]?\d{4}$`
   - Сообщение: "Введите номер телефона в формате XXX-XXX-XXXX"

4. **Почтовый индекс (Россия):**
   - Валидация: Regular Expression → Matches → `^\d{6}$`
   - Сообщение: "Введите 6-значный почтовый индекс"

5. **Возраст (18-120):**
   - Валидация: Number → Between → 18 and 120
   - Сообщение: "Возраст должен быть от 18 до 120 лет"

6. **Пароль (минимум 8 символов, буквы и цифры):**
   - Валидация: Regular Expression → Matches → `^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d]{8,}$`
   - Сообщение: "Пароль должен содержать минимум 8 символов, включая буквы и цифры"

7. **URL-адрес:**
   - Валидация: Text → URL
   - Сообщение: "Введите корректный URL-адрес"

8. **Короткий ответ (не более 100 символов):**
   - Валидация: Length → Maximum character count → 100
   - Сообщение: "Ответ не должен превышать 100 символов"

9. **Развернутый ответ (минимум 50 символов):**
   - Валидация: Length → Minimum character count → 50
   - Сообщение: "Пожалуйста, напишите не менее 50 символов"

10. **Выбрать минимум 3 варианта:**
    - Валидация: Select at least → 3
    - Сообщение: "Выберите как минимум 3 варианта"

### FR-QUEST-015: Условная логика (Branching)
**Приоритет:** Средний
**Описание:** Переход к различным разделам формы на основе ответов респондента.

**Поддержка условной логики:**
- Multiple Choice: ✓ (полная поддержка)
- Dropdown: ✓ (полная поддержка)
- Checkboxes: ✗
- Short Answer: ✗
- Paragraph: ✗
- Linear Scale: ✗
- Grids: ✗
- Date/Time: ✗
- File Upload: ✗

**Типы переходов:**
1. **Продолжить к следующему разделу (Continue to next section)**
   - Переход к следующему разделу по порядку
   - Стандартное поведение

2. **Перейти к разделу (Go to section)**
   - Выбор конкретного раздела для перехода
   - Настраивается для каждого варианта ответа

3. **Отправить форму (Submit form)**
   - Завершение заполнения формы
   - Пропуск оставшихся вопросов

**Настройка условной логики:**
1. Создание разделов в форме
2. Добавление вопроса Multiple Choice или Dropdown
3. Клик на "⋮" (три точки) → "Go to section based on answer"
4. Для каждого варианта ответа выбрать:
   - Раздел для перехода
   - "Submit form" для завершения
   - "Continue to next section" для стандартного поведения

**Логика на уровне раздела:**
- Настройка перехода после завершения раздела
- Опции:
  - Continue to next section
  - Go to section X
  - Submit form

**Примеры использования:**
1. **Квалификационные вопросы:**
   - "Вам есть 18 лет?" → Да (продолжить) / Нет (завершить форму)

2. **Релевантные вопросы:**
   - "Вы студент или работаете?" → Студент (вопросы об учебе) / Работаю (вопросы о работе)

3. **Персонализация опыта:**
   - "Выберите категорию продукта" → Каждая категория ведет к специфичным вопросам

4. **Сложные опросы:**
   - Многоуровневая логика с несколькими точками ветвления

**Ограничения:**
- Только для вопросов типа Multiple Choice и Dropdown
- Нельзя настроить условия на основе комбинации ответов
- Нельзя вернуться к предыдущим разделам
- Сложность отслеживания логики в больших формах
- Нет визуального представления дерева логики

**Лучшие практики:**
- Использовать описательные названия разделов
- Документировать логику отдельно для сложных форм
- Тестировать все возможные пути
- Минимизировать количество уровней ветвления
- Использовать логику только когда действительно необходимо

### FR-QUEST-017: Опция "Другое"
**Приоритет:** Средний
**Описание:** Добавление текстового поля для произвольного ответа в списковых вопросах.

**Поддерживаемые типы:**
- Multiple Choice: ✓
- Checkboxes: ✓
- Dropdown: ✗
- Grids: ✗

- Добавляет вариант "Other..." с текстовым полем
- Всегда отображается последним (даже при перемешивании)
- Текстовое поле активируется при выборе опции
- Ответ сохраняется как отдельное значение

**Настройка:**
- Чекбокс "Add 'Other'" в настройках вопроса
- Автоматическое добавление варианта

**Текстовое поле:**
- Однострочное поле ввода
- Placeholder: "Other..."
- Обязательно для заполнения, если выбрана опция "Другое"
- Максимальная длина не ограничена

**Валидация:**
- Если вопрос обязательный и выбрано "Другое", текстовое поле должно быть заполнено

- Чекбокс для "Другое"
- Можно выбрать "Другое" вместе с другими вариантами

**Примеры использования:**
- Сбор неожиданных вариантов ответов
- Дополнение к предопределенному списку
- Обратная связь с открытыми комментариями

**Анализ результатов:**
- Ответы "Другое" отображаются отдельно
- Возможность экспорта всех текстовых ответов
- Группировка похожих ответов вручную

- REST API для программного создания и управления формами

CHECKBOX_GRID

## Лучшие практики

### FR-QUEST-022: Рекомендации по использованию типов вопросов
**Приоритет:** Низкий
**Описание:** Руководство по эффективному использованию различных типов вопросов.

**Выбор правильного типа вопроса:**

1. **Для коротких ответов (1-3 слова):**
   - Используйте Short Answer
   - Примеры: имя, город, должность

2. **Для развернутых ответов (несколько предложений):**
   - Используйте Paragraph
   - Примеры: комментарии, описания, отзывы

3. **Для выбора одного варианта:**
   - **Multiple Choice** - если вариантов 2-7 и важна видимость всех опций
   - **Dropdown** - если вариантов более 7 или важна компактность
   - Примеры: пол, возраст, категория

4. **Для множественного выбора:**
   - Используйте Checkboxes
   - Добавьте валидацию, если нужно ограничить количество
   - Примеры: интересы, навыки, дни недели

5. **Для оценок:**
   - **Linear Scale** - для числовых оценок с подписями
   - **Rating** - для визуальной оценки звездами
   - **Multiple Choice Grid** - для оценки нескольких параметров
   - Примеры: удовлетворенность, NPS, качество

6. **Для табличных данных:**
   - **Multiple Choice Grid** - один выбор на строку
   - **Checkbox Grid** - множественный выбор на строку
   - Примеры: расписание, матрицы соответствия

7. **Для загрузки файлов:**
   - Используйте File Upload
   - Четко укажите требования к файлам
   - Установите разумные ограничения
   - Примеры: резюме, портфолио, документы

**Улучшение пользовательского опыта:**

1. **Используйте описания вопросов:**
   - Для дополнительных инструкций
   - Для примеров ожидаемых ответов
   - Для пояснения формата

2. **Настраивайте валидацию:**
   - Email для электронной почты
   - Number для числовых значений
   - Length для ограничения объема ответа
   - Пользовательские сообщения об ошибках

3. **Используйте обязательные вопросы разумно:**
   - Не делайте все вопросы обязательными
   - Обязательные только критически важные
   - Увеличивает процент завершения формы

4. **Оптимизируйте длину формы:**
   - Группируйте вопросы в разделы
   - Используйте условную логику для релевантности
   - Показывайте прогресс-бар для длинных форм

5. **Перемешивайте для объективности:**
   - В тестах и викторинах
   - В исследовательских опросах
   - Для устранения bias

6. **Добавляйте изображения:**
   - Для визуального контекста
   - Для выбора на основе изображений
   - Для инструкций и примеров

**Оптимизация для мобильных устройств:**
- Избегайте широких Grid (более 5 столбцов)
- Используйте Dropdown вместо длинных Multiple Choice
- Тестируйте форму на мобильных устройствах
- Минимизируйте обязательный ввод текста

**Анализ и улучшение:**
- Отслеживайте процент завершения
- Анализируйте, на каких вопросах пользователи останавливаются
- Упрощайте сложные вопросы
- A/B тестирование формулировок вопросов

- Отслеживание истории изменений

- Опция "Limit to 1 response"
- Требует авторизации Google
- Предотвращает множественные отправки
- Использует Google аккаунт для идентификации

**Собирать email-адреса:**
- Автоматический сбор email респондентов
- Требует авторизации Google
- Отображается как отдельное поле
- Используется для отправки копии ответа

- Визуальный индикатор прогресса заполнения

- Показывает процент выполнения

**Подтверждение отправки:**
- Настраиваемое сообщение после отправки
- Ссылка для отправки еще одного ответа
- Опция показа ссылки на результаты
- Опция отправки копии ответа на email

## Сценарии использования

### FR-QUEST-027: Типовые сценарии применения
**Приоритет:** Информационный
**Описание:** Примеры использования различных типов вопросов для разных целей.

**1. Регистрация на мероприятие:**
- Short Answer: Имя, Фамилия, Email, Телефон
- Multiple Choice: Тип билета (VIP/Standard/Free)
- Checkboxes: Интересующие секции (с валидацией минимум 1)
- Dropdown: Страна
- Date: Дата прибытия
- Paragraph: Дополнительные пожелания
- File Upload: Фото для бейджа (опционально)

**2. Опрос удовлетворенности клиентов:**
- Linear Scale 1-10: NPS - вероятность рекомендации
- Multiple Choice Grid: Оценка различных аспектов сервиса
  - Строки: Качество, Скорость, Цена, Поддержка
  - Столбцы: Очень плохо - Отлично (1-5)
- Paragraph: Комментарии и предложения
- Multiple Choice: Вероятность повторной покупки

**3. Викторина/Тест:**
- Multiple Choice: Вопросы с одним правильным ответом
- Checkboxes: Вопросы с несколькими правильными ответами (с валидацией exact count)
- Short Answer: Краткие ответы с валидацией текста
- Linear Scale: Оценка уверенности в ответе
- Автоматическая оценка и обратная связь

**4. Заявка на работу:**
- Short Answer: ФИО, Email (с валидацией)
- Short Answer: Номер телефона (с regex валидацией)
- Dropdown: Желаемая позиция
- Checkboxes: Навыки и технологии
- Paragraph: Мотивационное письмо (с минимальной длиной)
- File Upload: Резюме (PDF, максимум 10MB)
- File Upload: Портфолио (опционально, несколько файлов)
- Linear Scale 1-5: Готовность к командировкам
- Date: Возможная дата начала работы

**5. Исследование рынка:**
- Multiple Choice: Демографические вопросы (с branching logic)
- Checkboxes: Используемые продукты конкурентов
- Multiple Choice Grid: Важность различных характеристик продукта
- Linear Scale: Готовность платить (шкала цен)
- Rating: Оценка текущего решения
- Paragraph: Главная проблема, которую нужно решить

**6. Бронирование услуг:**
- Short Answer: Имя, Email, Телефон
- Date: Предпочтительная дата
- Time: Предпочтительное время
- Dropdown: Тип услуги
- Multiple Choice: Длительность сессии (30мин/60мин/90мин)
- Checkboxes: Дополнительные опции
- Paragraph: Особые пожелания

**7. Обратная связь об обучении:**
- Multiple Choice: Курс/программа
- Rating: Общая оценка курса (звезды 1-5)
- Multiple Choice Grid: Оценка преподавателей
  - Строки: Имена преподавателей
  - Столбцы: Знание предмета, Доступность объяснений, Взаимодействие
- Linear Scale: Рекомендация курса коллегам (1-10)
- Checkboxes: Что понравилось больше всего
- Paragraph: Предложения по улучшению
- Short Answer: Какие темы хотели бы изучить дополнительно

**8. Регистрация участников проекта:**
- Short Answer: ФИО, Организация
- Short Answer: Email (валидация email)
- Checkboxes: Дни участия (с валидацией минимум 1 день)
- Multiple Choice: Роль в проекте → branching к специфичным вопросам
  - Если "Спикер" → вопросы о презентации
  - Если "Участник" → вопросы о предпочтениях
- Checkbox Grid: Доступность по времени
  - Строки: Дни недели
  - Столбцы: Временные слоты
- File Upload: Презентация (для спикеров)

## Заключение

5. Тестируйте формы перед публикацией
6. Анализируйте результаты для непрерывного улучшения

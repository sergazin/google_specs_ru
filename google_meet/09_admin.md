# Модуль: Административная панель Google Meet

## 1. Описание модуля

Модуль административной панели Google Meet предоставляет инструменты управления видеоконференциями на уровне организации через Google Workspace Admin Console. Модуль обеспечивает централизованный контроль над политиками безопасности, функциональными возможностями пользователей, аналитикой использования и соответствием нормативным требованиям.

Административная панель позволяет:
- Управлять доступом к функциям Google Meet для различных групп пользователей
- Настраивать политики безопасности и конфиденциальности
- Контролировать взаимодействие с внешними участниками
- Отслеживать использование сервиса и качество соединений
- Настраивать автоматические правила и оповещения
- Управлять лицензиями и подписками
- Обеспечивать соответствие корпоративным и регуляторным требованиям

## 2. Роли пользователей

### 2.1. Супер-администратор (Super Admin)
**Описание**: Полный доступ ко всем настройкам Google Workspace, включая Google Meet.

**Возможности**:
- Полный доступ ко всем настройкам Meet
- Управление всеми организационными единицами
- Настройка глобальных политик безопасности
- Доступ к инструментам безопасности и расследований
- Управление лицензиями и подписками
- Удаление участников из любых встреч
- Настройка интеграций с внешними сервисами

### 2.2. Администратор сервисов (Service Settings Administrator)
**Описание**: Управление настройками отдельных сервисов Google Workspace.

**Возможности**:
- Настройка параметров Meet для организационных единиц
- Включение/отключение функций Meet
- Управление политиками записи и трансляций
- Настройка параметров безопасности встреч
- Доступ к Meet Quality Tool

**Требуемые привилегии**: Service Settings

### 2.3. Администратор аудита и расследований (Audit & Investigation Administrator)
**Описание**: Доступ к журналам событий и инструментам расследования.

**Возможности**:
- Просмотр журналов событий Meet
- Экспорт данных аудита
- Создание отчетов об использовании
- Использование инструмента расследований безопасности

**Требуемые привилегии**: Audit & Investigation

### 2.4. Администратор центра безопасности (Security Center Administrator)
**Описание**: Расширенный доступ к инструментам безопасности.

**Возможности**:
- Использование Security Investigation Tool
- Принудительное завершение встреч
- Настройка правил автоматизации
- Управление оповещениями безопасности
- Удаление участников из встреч

**Требуемые привилегии**: Security Center

### 2.5. Администратор отчетов (Reports Administrator)
**Описание**: Доступ к аналитике и отчетам.

**Возможности**:
- Просмотр статистики использования
- Доступ к Meet Quality Tool
- Генерация отчетов
- Экспорт данных в BigQuery

**Требуемые привилегии**: Reports

### 2.6. Администратор групп (Groups Administrator)
**Описание**: Управление группами конфигурации.

**Возможности**:
- Создание конфигурационных групп
- Назначение пользователей в группы
- Настройка исключений для групп

**Требуемые привилегии**: Groups

### 2.7. Администратор оборудования Meet (Meet Hardware Administrator)
**Описание**: Управление устройствами Google Meet Hardware.

**Возможности**:
- Настройка устройств Meet Hardware
- Назначение календарей устройствам
- Мониторинг состояния устройств
- Управление обновлениями прошивки

**Требуемые привилегии**: Manage Google Meet hardware and calendars

## 3. Функциональные требования

### 3.1. Управление доступом к сервису

#### FR-ADMIN-001: Включение/отключение Google Meet для организации
**Описание**: Администратор может полностью включить или отключить сервис Google Meet для всей организации или отдельных организационных единиц.

**Бизнес-правила**:
- Изменение статуса сервиса применяется к выбранной организационной единице
- Дочерние организационные единицы наследуют настройки родительской, если не переопределены
- Изменения вступают в силу в течение 24 часов (обычно быстрее)
- При отключении сервиса пользователи теряют возможность создавать и присоединяться к встречам

**Возможные значения**:
- `Включено для всех` - все пользователи организационной единицы могут использовать Meet
- `Отключено` - сервис недоступен для пользователей организационной единицы

#### FR-ADMIN-002: Управление организационными единицами
**Описание**: Настройки Meet могут применяться к различным организационным единицам (OU) для дифференциации политик по департаментам.

**Бизнес-правила**:
- Изначально все пользователи находятся в корневой организационной единице
- Дочерние OU наследуют настройки родительской OU
- Можно переопределить унаследованные настройки для дочерней OU
- Рекомендуется создавать OU по департаментам (Finance, HR, Engineering и т.д.)

**Пример иерархии**:
```
Корневая организация
├── Руководство
├── Финансы
├── HR
├── Инженерия
│   ├── Backend
│   ├── Frontend
│   └── DevOps
└── Продажи
```

#### FR-ADMIN-003: Управление конфигурационными группами
**Описание**: Для исключений из политик OU используются конфигурационные группы, которые позволяют переопределить настройки для отдельных пользователей.

**Бизнес-правила**:
- Настройки группы имеют приоритет над настройками OU
- Пользователь может принадлежать к нескольким группам
- При конфликте применяются настройки группы с наивысшим приоритетом
- Группы используются для исключений, не меняя структуру OU

### 3.2. Настройки видео и функций встреч

#### FR-ADMIN-004: Управление функцией записи встреч
**Описание**: Администратор контролирует возможность записи встреч для пользователей организации.

**Бизнес-правила**:
- Запись доступна только для определенных редакций: Business Standard, Business Plus, Enterprise Standard, Enterprise Plus, Education Plus, Essentials, Enterprise Essentials, Enterprise Essentials Plus
- Администратор может включить/отключить запись для OU или группы
- Записи сохраняются в Google Drive организатора встречи
- Для записи требуется достаточное пространство в Drive
- Максимальное разрешение записи при демонстрации экрана - 1080p
- Администратор может отключить записи в разрешении 1080p

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `let_people_record` | Разрешить пользователям записывать встречи | Зависит от редакции |
| `1080p_recordings` | Разрешить записи в разрешении 1080p | Включено |

#### FR-ADMIN-005: Управление автоматической записью
**Описание**: Настройка автоматического запуска записи для всех встреч определенных пользователей.

**Бизнес-правила**:
- Автоматическая запись может быть включена по умолчанию для OU/группы
- Организаторы и со-организаторы могут отключить автозапись для конкретной встречи
- Участники уведомляются о начале записи
- Настройка доступна в календарном приглашении

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `meetings_recorded_by_default` | Встречи записываются по умолчанию | Отключено |

#### FR-ADMIN-006: Управление отчетами о посещаемости
**Описание**: Контроль доступа организаторов к отчетам о посещаемости встреч.

**Бизнес-правила**:
- Доступно для: Essentials, Business Plus, Enterprise Starter/Essentials/Standard/Plus, Education Plus, Teaching and Learning Upgrade
- Организатор получает отчет по email после завершения встречи
- Отчет содержит: имена участников, время входа, продолжительность присутствия
- Для участников по телефону отображаются частичные цифры номера
- Для участников из комнат Meet отображается название комнаты

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `attendance_reporting` | Предоставлять модераторам отчеты о посещаемости | Включено |

#### FR-ADMIN-007: Управление функцией демонстрации экрана
**Описание**: Контроль возможности участников демонстрировать экран во время встреч.

**Бизнес-правила**:
- Администратор может разрешить/запретить демонстрацию экрана для OU/группы
- При включенном Host Management организатор встречи контролирует эту функцию
- Одновременно может быть до 10 демонстраций экрана
- Можно демонстрировать: вкладку браузера, окно приложения, весь экран

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `screen_sharing` | Разрешить пользователям демонстрировать экран | Включено |

#### FR-ADMIN-008: Управление функцией чата
**Описание**: Контроль возможности отправки сообщений в чате встречи.

**Бизнес-правила**:
- Организатор всегда может отправлять сообщения
- При включенном Host Management организатор контролирует чат участников
- Чат можно отключить для всей OU/группы

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `meeting_chat` | Разрешить участникам отправлять и просматривать сообщения чата | Включено |

### 3.3. Настройки безопасности встреч

#### FR-ADMIN-009: Управление Host Management по умолчанию
**Описание**: Настройка состояния Host Management по умолчанию для новых встреч.

**Бизнес-правила**:
- Host Management доступен для всех редакций Google Workspace
- Когда Host Management включен, организатор контролирует: демонстрацию экрана, чат, отключение микрофонов участников
- Без Host Management любой внутренний участник может управлять встречей
- Организатор может изменить настройку во время встречи

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `host_management_default` | Начинать встречи с включенным Host Management | Зависит от редакции |

#### FR-ADMIN-010: Управление Quick Access по умолчанию
**Описание**: Настройка автоматического доступа к встречам для участников из организации.

**Бизнес-правила**:
- Quick Access позволяет участникам из организации присоединяться без одобрения
- Внешние участники всегда должны запрашивать доступ
- Организатор может изменить настройку для конкретной встречи

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `quick_access_default` | Разрешить быстрый доступ для участников организации | Включено |

#### FR-ADMIN-011: Управление уровнями доступа к встречам
**Описание**: Настройка политик доступа к встречам по умолчанию.

**Уровни доступа**:
| Уровень | Описание |
|---------|----------|
| `Open` | Любой с ссылкой может присоединиться без одобрения |
| `Trusted` | Участники организации входят без одобрения; внешние приглашенные через Calendar - тоже; остальные запрашивают доступ |
| `Restricted` | Только приглашенные через Calendar или во время встречи могут присоединиться |

**Бизнес-правила**:
- Администратор устанавливает уровень по умолчанию для организации
- Организатор может изменить уровень для своих встреч
- Для Trusted и Restricted можно отключить запрос на присоединение

#### FR-ADMIN-012: Управление доступом внешних участников
**Описание**: Контроль возможности приглашения и участия пользователей вне организации.

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `invite_external` | Разрешить пользователям приглашать внешних участников |
| `join_external_meetings` | Разрешить пользователям присоединяться к внешним встречам |
| `external_meeting_types` | Типы внешних встреч: только Workspace, включая личные аккаунты |

**Варианты для присоединения к внешним встречам**:
- Только встречи своей организации
- Встречи любых организаций Google Workspace
- Все встречи, включая личные Google-аккаунты

**Варианты для присоединения внешних участников**:
- Только пользователи организации и телефонные звонки
- Пользователи с Google-аккаунтом или телефонные звонки
- Все пользователи, включая не вошедших в аккаунт

#### FR-ADMIN-013: Управление присоединением до организатора
**Описание**: Контроль возможности участников присоединиться к встрече до прихода организатора.

**Бизнес-правила**:
- По умолчанию участники могут присоединиться до организатора
- Можно требовать присутствия организатора для начала встречи
- Настройка применяется к OU/группе

### 3.4. Шифрование и конфиденциальность

#### FR-ADMIN-014: Управление клиентским шифрованием (CSE)
**Описание**: Настройка дополнительного слоя шифрования с использованием ключей организации.

**Требования**:
- Редакции: Frontline Plus, Enterprise Plus, Education Standard/Plus
- Требуется интеграция с внешним провайдером идентификации (IdP)
- Требуется настройка внешнего сервиса управления ключами

**Бизнес-правила**:
- CSE шифрует данные на стороне клиента перед отправкой
- Google не имеет доступа к ключам шифрования
- Все участники CSE-встреч должны быть приглашены
- Телефонное присоединение недоступно для CSE-встреч
- Внешние участники требуют настройки гостевого IdP

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `cse_enabled` | Включить клиентское шифрование для OU/группы |
| `cse_default` | Сделать CSE настройкой по умолчанию для новых встреч |
| `guest_idp` | Настройка гостевого провайдера идентификации |

#### FR-ADMIN-015: Управление водяными знаками
**Описание**: Настройка отображения водяных знаков на видео и демонстрации экрана для защиты конфиденциальности.

**Бизнес-правила**:
- Водяные знаки помогают идентифицировать источник утечки
- Могут содержать информацию об участнике
- Настраивается для OU/группы

### 3.5. Функции AI и Gemini

#### FR-ADMIN-016: Управление Gemini в Meet
**Описание**: Контроль доступа к AI-функциям Gemini во время встреч.

**Доступные функции Gemini**:
- Take notes for me - автоматическое ведение заметок
- Ask Gemini - вопросы к AI во время встречи
- Studio Look/Sound/Light - улучшение видео и звука
- Translated captions - переведенные субтитры

**Бизнес-правила**:
- Доступно для Business Plus, Enterprise Standard/Plus
- Gemini включен по умолчанию для поддерживаемых редакций
- Администратор может отключить для OU/группы
- Организатор может отключить для конкретной встречи
- Участники уведомляются об активных AI-функциях
- Контент не используется для обучения моделей вне домена

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `gemini_enabled` | Включить функции Gemini для OU | Включено (если доступно) |
| `take_notes_enabled` | Разрешить AI вести заметки | Включено |
| `ask_gemini_enabled` | Разрешить Ask Gemini | Включено |
| `auto_notes_default` | Автоматические заметки по умолчанию | Отключено |

#### FR-ADMIN-017: Управление автоматическими артефактами встреч
**Описание**: Настройка автоматического создания записей, транскриптов и заметок.

**Бизнес-правила**:
- Можно включить автоматическую запись, транскрипт, заметки по умолчанию
- Организатор/со-организатор могут изменить настройки в приглашении
- Участники уведомляются об активных автоматических функциях

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `auto_recording_default` | Автозапись по умолчанию |
| `auto_transcript_default` | Автотранскрипция по умолчанию |
| `auto_notes_default` | Автозаметки по умолчанию |

### 3.6. Трансляции и расширенные встречи

#### FR-ADMIN-018: Управление прямыми трансляциями
**Описание**: Контроль возможности проведения прямых трансляций встреч.

**Требования к редакциям**:
- Enterprise Standard/Plus
- Education Plus

**Бизнес-правила**:
- Трансляция доступна только для пользователей организации по умолчанию
- Можно разрешить трансляции на YouTube
- При Host Management только организаторы/со-организаторы могут начать трансляцию
- Количество зрителей трансляции не ограничено

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `live_streaming_enabled` | Включить прямые трансляции |
| `youtube_streaming_enabled` | Разрешить трансляции на YouTube |
| `cross_domain_streaming` | Разрешить просмотр трансляций доверенными доменами |
| `external_live_stream_viewers` | Разрешить внешних зрителей трансляций |

#### FR-ADMIN-019: Управление Enterprise CDN (eCDN)
**Описание**: Настройка распределенной сети доставки контента для крупных трансляций.

**Возможности**:
- Поддержка до 100,000 зрителей
- Снижение потребления пропускной способности до 95%
- P2P-обмен между зрителями в локальной сети

**Бизнес-правила**:
- eCDN включается автоматически после настройки администратором
- Пользователям не требуются дополнительные действия
- Настраивается на уровне OU

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `ecdn_enabled` | Включить Enterprise CDN |
| `ecdn_policy` | Политика eCDN для OU |

#### FR-ADMIN-020: Управление доверенными доменами для трансляций
**Описание**: Настройка доменов, пользователи которых могут смотреть трансляции организации.

**Бизнес-правила**:
- Добавлять следует только домены, принадлежащие организации (дочерние компании, школы округа)
- Пользователи доверенных доменов могут смотреть трансляции без дополнительной авторизации

### 3.7. Телефонное подключение

#### FR-ADMIN-021: Управление телефонным доступом
**Описание**: Настройка возможности подключения к встречам по телефону.

**Типы телефонного доступа**:
- Dial-in - входящие звонки на номер встречи
- Dial-out - исходящие звонки участникам из встречи

**Бизнес-правила**:
- Звонки в США и Канаду бесплатны для всех редакций
- Global Dialing требует отдельной подписки
- Оплата тарифицируется по минутам
- Счета выставляются организации, создавшей встречу

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `phone_dial_in_enabled` | Разрешить входящие телефонные звонки |
| `phone_dial_out_enabled` | Разрешить исходящие звонки из встречи |
| `global_dialing_enabled` | Включить международные звонки |

### 3.8. Инструменты для модераторов

#### FR-ADMIN-022: Управление функцией опросов (Polls)
**Описание**: Контроль возможности создания опросов во время встреч.

**Бизнес-правила**:
- Опросы сохраняются при использовании одной и той же ссылки Meet
- Результаты могут быть видны участникам (настраивается организатором)
- После встречи организатор получает отчет по опросам

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `polls_enabled` | Разрешить создание опросов | Включено |

#### FR-ADMIN-023: Управление функцией Q&A
**Описание**: Контроль возможности использования функции вопросов и ответов.

**Бизнес-правила**:
- Q&A включен по умолчанию для всех, кроме Education
- Для Education организатор включает Q&A вручную
- Можно разрешить анонимные вопросы
- Модерируемый Q&A требует одобрения вопросов организатором
- После встречи организатор получает отчет по Q&A

**Параметры**:
| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `qa_enabled` | Разрешить Q&A | Включено (кроме Education) |
| `anonymous_questions` | Разрешить анонимные вопросы | Включено |

#### FR-ADMIN-024: Управление Breakout Rooms
**Описание**: Контроль возможности создания комнат для групповой работы.

**Бизнес-правила**:
- Максимум 100 Breakout Rooms на встречу
- Создавать может только организатор (или до 25 со-организаторов)
- Breakout Rooms нельзя транслировать или записывать
- Можно создать заранее в Google Calendar

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `breakout_rooms_enabled` | Разрешить создание Breakout Rooms |
| `limit_creation_to_hosts` | Ограничить создание Breakout Rooms организаторами |

#### FR-ADMIN-025: Управление со-организаторами
**Описание**: Настройка возможности назначения со-организаторов встречи.

**Бизнес-правила**:
- Максимум 25 со-организаторов на встречу
- Со-организаторы получают доступ к Host Controls
- Организатор может назначить со-организаторов во время встречи

## 4. Сущности данных

### 4.1. Организационная единица (Organizational Unit)
```
OrganizationalUnit {
  id: string                    // Уникальный идентификатор
  name: string                  // Название OU
  path: string                  // Полный путь в иерархии
  parent_id: string?            // ID родительской OU
  description: string?          // Описание
  meet_settings: MeetSettings   // Настройки Meet для OU
  created_at: timestamp
  updated_at: timestamp
}
```

### 4.2. Конфигурационная группа (Configuration Group)
```
ConfigurationGroup {
  id: string                    // Уникальный идентификатор
  name: string                  // Название группы
  email: string                 // Email группы
  description: string?          // Описание
  priority: integer             // Приоритет при конфликте
  meet_settings: MeetSettings   // Настройки Meet
  members: string[]             // ID участников
  created_at: timestamp
  updated_at: timestamp
}
```

### 4.3. Настройки Meet (Meet Settings)
```
MeetSettings {
  // Базовые настройки
  service_enabled: boolean

  // Запись и артефакты
  recording_enabled: boolean
  auto_recording_default: boolean
  recording_1080p_enabled: boolean
  attendance_reporting_enabled: boolean
  transcription_enabled: boolean
  auto_transcript_default: boolean

  // Безопасность
  host_management_default: boolean
  quick_access_default: boolean
  default_access_level: AccessLevel
  external_participants_allowed: boolean
  join_external_meetings: ExternalMeetingType
  join_before_host: boolean

  // Функции
  screen_sharing_enabled: boolean
  chat_enabled: boolean
  polls_enabled: boolean
  qa_enabled: boolean
  breakout_rooms_enabled: boolean

  // Трансляции
  live_streaming_enabled: boolean
  youtube_streaming_enabled: boolean
  cross_domain_streaming: boolean
  ecdn_enabled: boolean

  // Телефония
  dial_in_enabled: boolean
  dial_out_enabled: boolean
  global_dialing_enabled: boolean

  // AI/Gemini
  gemini_enabled: boolean
  take_notes_enabled: boolean
  ask_gemini_enabled: boolean
  auto_notes_default: boolean

  // Шифрование
  cse_enabled: boolean
  cse_default: boolean

  // Media API
  media_api_enabled: boolean
}
```

```
MeetAuditEvent {
  id: string                    // Уникальный идентификатор события
```

|---------|----------|

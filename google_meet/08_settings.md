# Модуль "Настройки пользователя" (User Settings)

## Обзор модуля

Модуль "Настройки пользователя" предоставляет участникам Google Meet полный контроль над аудио- и видеооборудованием, визуальными эффектами, субтитрами, уведомлениями, доступностью и персональными предпочтениями во время видеовстреч. Настройки применяются как до присоединения к встрече (в "зеленой комнате" предпросмотра), так и непосредственно во время видеоконференции. Модуль тесно интегрирован с административными политиками Google Workspace для корпоративных пользователей.

## Роли пользователей

| Роль | Описание | Доступ к настройкам |
|------|----------|---------------------|
| Личный пользователь (Personal Account) | Пользователь с личным аккаунтом Google | Базовые настройки аудио/видео, субтитры, визуальные эффекты |
| Бизнес-пользователь (Google Workspace) | Пользователь корпоративного аккаунта | Расширенные функции в зависимости от плана подписки |
| Организатор встречи (Host) | Создатель встречи или владелец события в Calendar | Управление настройками встречи, host controls |
| Со-организатор (Co-host) | Назначенный участник с расширенными правами | Делегированные права хоста (до 25 человек) |
| Участник (Participant) | Обычный участник встречи | Только персональные настройки |
| Администратор Workspace (Admin) | IT-администратор организации | Управление политиками для всей организации |

## 1. Настройки аудио (Audio Settings)

### FR-SET-001: Выбор микрофона
**Описание:** Выбор устройства ввода аудио из списка доступных микрофонов.

**Доступ к настройке:**
1. До встречи: Предпросмотр > Кнопка "Настройки" или три точки > Настройки > Аудио
2. Во время встречи: Три точки (Дополнительные параметры) > Настройки > Аудио
3. Быстрый доступ: Стрелка рядом с кнопкой микрофона

**Отображаемая информация:**
- Название устройства (системное имя)
- Тип устройства (встроенный, USB, Bluetooth)
- Индикатор активности (визуальная полоса при захвате звука)

**Поведение:**
| Сценарий | Действие системы |
|----------|-----------------|
| Подключение нового микрофона | Добавление в список, опциональное автопереключение |
| Отключение активного микрофона | Автоматическое переключение на следующий доступный |
| Нет доступных микрофонов | Уведомление об ошибке, предложение проверить подключение |

**Правила:**
- Выбранный микрофон сохраняется между сессиями
- При недоступности сохраненного микрофона система выбирает системный по умолчанию
- Изменение применяется мгновенно без перезапуска

### FR-SET-002: Выбор динамиков (спикера)
**Описание:** Выбор устройства вывода аудио для воспроизведения звука от других участников.

**Доступ к настройке:**
- Настройки > Аудио > Спикер (динамики)
- Стрелка рядом с кнопкой динамика (мобильные устройства)

**Функция тестирования:**
1. Нажать "Тестировать динамики" (Test Speakers)
2. Система воспроизводит тестовый звук
3. Пользователь подтверждает, что слышит звук

**Мобильные устройства:**
| Источник звука | Описание |
|----------------|----------|
| Динамик телефона | Громкая связь через встроенный динамик |
| Разговорный динамик | Динамик у уха (как при звонке) |
| Bluetooth-устройство | Подключенные беспроводные наушники/колонки |
| Проводные наушники | 3.5mm jack или USB-C аудио |

### FR-SET-003: Тестирование микрофона
**Описание:** Проверка работоспособности микрофона до присоединения к встрече.

**Механизм работы:**
1. Пользователь говорит в микрофон
2. Визуальный индикатор (полоса уровня звука) показывает захват аудио
3. Если полоса двигается — микрофон работает корректно

**Расположение индикатора:**
- Предпросмотр (Green Room): Под превью видео, рядом с кнопкой микрофона
- Настройки: Рядом с выпадающим списком микрофонов

**Диагностика:**
| Проблема | Индикация | Рекомендация |
|----------|-----------|--------------|
| Микрофон не захватывает звук | Полоса не двигается | Проверить подключение, разрешения |
| Слишком тихий звук | Полоса едва двигается | Приблизить микрофон, увеличить усиление |
| Перегрузка (клиппинг) | Полоса постоянно на максимуме | Уменьшить усиление, отдалить микрофон |

### FR-SET-004: Шумоподавление (Noise Cancellation)
**Описание:** Автоматическое удаление фонового шума из аудиопотока пользователя.

**Расположение:** Настройки > Аудио > Шумоподавление

**Типы подавляемого шума:**
- Стук клавиатуры
- Звук закрывающейся двери
- Эхо помещения
- Строительные работы
- Шум кондиционера/вентилятора
- Фоновые разговоры (частично)

**Что НЕ подавляется:**
- Голоса других людей рядом с пользователем
- Звук телевизора
- Музыка (намеренно не фильтруется для музыкальных встреч)

**Визуальная индикация:**
- При активном шумоподавлении отображается индикатор с кольцом вокруг иконки голоса
- Размер кольца показывает интенсивность фильтрации шума

**Ограничения по подписке:**
| План Google Workspace | Шумоподавление |
|-----------------------|----------------|
| Business Starter | Включено по умолчанию |
| Business Standard | Включено по умолчанию |
| Business Plus | Включено по умолчанию |
| Enterprise | Включено по умолчанию |
| Education Fundamentals | Ручное включение |
| Education Plus | Включено по умолчанию |
| Личный аккаунт | Доступно |

**Примечание:** При демонстрации экрана со звуком шумоподавление не влияет на передаваемый системный звук.

### FR-SET-005: Studio Sound (Улучшенное качество звука)
**Описание:** Продвинутая обработка аудио с использованием облачных технологий для профессионального качества звука.

**Доступность:** Только для пользователей Gemini for Google Workspace

**Функционал:**
- Автоматически включает шумоподавление
- Применяет обработку для эффекта "студийного" звука
- Оптимизирует голос для лучшей разборчивости
- Адаптивная обработка между устройством и облаком

**Активация:**
1. Настройки > Аудио > Studio Sound (Вкл/Выкл)
2. При включении Noise Cancellation активируется автоматически

### FR-SET-006: Горячая клавиша микрофона
**Описание:** Быстрое включение/выключение микрофона с клавиатуры.

**Комбинации клавиш:**
| Платформа | Клавиши |
|-----------|---------|
| Windows/Linux | Ctrl + D |
| macOS | Cmd + D |

**Поведение:**
- Мгновенное переключение состояния (mute/unmute)
- Работает только при активной вкладке Google Meet
- Не работает в режиме инкогнито с отключенными уведомлениями

### FR-SET-007: Push-to-Talk (Нажми-чтобы-говорить)
**Описание:** Режим, при котором микрофон активен только при удержании клавиши.

**Требования:**
- Предварительное включение в настройках встречи
- Поддерживается только в браузерной версии

**Использование:**
- Удерживать пробел для активации микрофона
- Отпустить для возврата в режим mute

## 2. Настройки видео (Video Settings)

### FR-SET-010: Выбор камеры
**Описание:** Выбор устройства захвата видео из списка доступных камер.

**Расположение:** Настройки > Видео > Камера

**Отображаемая информация:**
- Название камеры (системное имя)
- Превью с выбранной камеры

**Переключение на мобильных устройствах:**
- Кнопка "Переключить камеру" (Switch camera) в правом верхнем углу
- Переключение между фронтальной и основной камерой

**Поведение при изменении:**
| Сценарий | Действие системы |
|----------|-----------------|
| Подключение новой камеры | Добавление в список, сохранение текущей |
| Отключение активной камеры | Переключение на следующую доступную |
| Отключение камеры организатором | Камера остается выключенной до ручного включения |

### FR-SET-011: Качество отправляемого видео (Send Resolution)
**Описание:** Выбор разрешения видеопотока, отправляемого другим участникам.

**Расположение:** Настройки > Видео > Разрешение отправки

**Доступные опции:**
| Разрешение | Описание | Рекомендуемая скорость |
|------------|----------|------------------------|
| Full HD (1080p) | Максимальное качество | 3.2 Mbps+ |
| HD (720p) | Высокое качество | 1.5-2 Mbps |
| SD (360p) | Стандартное качество | 0.5-1 Mbps |
| Audio only | Только аудио | < 0.5 Mbps |

**Ограничения:**
- 1080p доступен только на компьютерах с 1080p камерой и достаточной производительностью
- Система может автоматически понижать качество при слабом соединении

### FR-SET-012: Качество получаемого видео (Receive Resolution)
**Описание:** Выбор максимального разрешения видеопотоков от других участников.

**Расположение:** Настройки > Видео > Разрешение получения

**Доступные опции:**
| Разрешение | Применение |
|------------|------------|
| HD (720p) | Максимальное качество от других участников |
| SD (360p) | Экономия трафика |
| Audio only | Только аудио от всех участников |

**Влияние:**
- Уменьшение разрешения снижает потребление трафика и нагрузку на процессор
- Применяется ко всем входящим потокам одновременно

### FR-SET-013: Автоматическое кадрирование (Video Framing)
**Описание:** Автоматическое центрирование и масштабирование изображения пользователя в кадре.

**Расположение:** Настройки > Видео > Кадрирование видео

**Функционал:**
- Автоматическое центрирование при смещении от центра
- Масштабирование при слишком далеком/близком расположении
- Отслеживание движения пользователя

**Статус по умолчанию:**
- Включено для настольных компьютеров и ноутбуков
- Требуется ручное включение на некоторых устройствах

**Требования:**
- Камера с достаточным разрешением для кроппинга
- Поддержка обработки изображений браузером

### FR-SET-014: Горячая клавиша камеры
**Описание:** Быстрое включение/выключение камеры с клавиатуры.

**Комбинации клавиш:**
| Платформа | Клавиши |
|-----------|---------|
| Windows/Linux | Ctrl + E |
| macOS | Cmd + E |

### FR-SET-015: Зеркальное отображение
**Описание:** Управление зеркальным отображением собственного видео.

**Поведение:**
- Собственное видео отображается зеркально для естественности (как в зеркале)
- Другие участники видят неотзеркаленное изображение
- Тексты и надписи отображаются корректно для зрителей

## 3. Визуальные эффекты (Visual Effects)

### FR-SET-020: Размытие фона (Background Blur)
**Описание:** Размытие заднего плана для сокрытия окружающей обстановки.

**Расположение:**
- До встречи: Кнопка "Применить визуальные эффекты" в предпросмотре
- Во время встречи: Наведение на свое видео > "Применить визуальные эффекты"

**Уровни размытия:**
| Уровень | Описание |
|---------|----------|
| Слегка размыть (Slightly blur) | Мягкое размытие, детали видны |
| Размыть (Blur) | Сильное размытие, фон неразличим |

**Технические требования:**
| Браузер | Минимальная версия |
|---------|-------------------|
| Chrome | 114+ |
| Firefox | 110+ |
| Edge (Chromium) | 114+ |

**Требования устройства:**
- Поддержка WebGL
- Включенное аппаратное ускорение
- Актуальные драйверы видеокарты

### FR-SET-021: Виртуальный фон (Virtual Background)
**Описание:** Замена реального фона на изображение или анимацию.

**Типы виртуальных фонов:**
| Тип | Описание |
|-----|----------|
| Статические фоны | Неподвижные изображения (офис, природа, нейтральные) |
| Иммерсивные фоны | Анимированные фоны с эффектом присутствия |
| Сезонные фоны | Тематические фоны (праздники, события) |
| Пользовательские | Загруженные пользователем изображения |

**Загрузка собственного фона:**
1. Нажать "Применить визуальные эффекты"
2. Вкладка "Фоны"
3. Кнопка "Загрузить" (Upload)
4. Выбрать изображение с устройства

**Требования к изображению:**
- Рекомендуемое разрешение: 1920x1080 или выше
- Поддерживаемые форматы: JPG, PNG
- Максимальный размер: не указан явно (рекомендуется до 5 MB)

**Мобильные устройства (Android):**
- Требуется Android 9.0+
- Поддерживаемые устройства: Samsung Galaxy S9+, Pixel 3 и новее

### FR-SET-022: Коррекция освещения
**Описание:** Автоматическое улучшение освещения изображения пользователя.

**Расположение:** Применить визуальные эффекты > Внешний вид

**Функционал:**
- Компенсация недостаточного освещения
- Выравнивание яркости лица
- Устранение резких теней

### FR-SET-023: Цветовые фильтры
**Описание:** Применение художественных фильтров к видеоизображению.

**Расположение:** Применить визуальные эффекты > Фильтры

**Типы фильтров:**
- Теплые тона
- Холодные тона
- Черно-белый
- Винтаж
- И другие художественные эффекты

### FR-SET-024: Обработка эффектов
**Описание:** Система автоматически распределяет обработку между устройством и облаком.

**Преимущества облачной обработки:**
- Экономия заряда батареи
- Снижение нагрузки на процессор
- Стабильное качество эффектов

**Поведение:**
- Автоматическое переключение в зависимости от возможностей устройства
- Прозрачно для пользователя

## 4. Настройки субтитров и перевода (Captions & Translation)

### FR-SET-030: Включение субтитров
**Описание:** Отображение автоматических субтитров во время встречи.

**Активация:**
- Кнопка "Включить субтитры" (Turn on captions) в нижней панели
- Клавиша C на клавиатуре
- Настройки > Субтитры

**Поведение:**
- Субтитры отображаются только для пользователя, который их включил
- Другие участники не видят, что субтитры включены

### FR-SET-031: Выбор языка субтитров
**Описание:** Выбор языка распознавания речи для субтитров.

**Расположение:** Настройки > Субтитры > Язык субтитров

**Доступные языки (зависит от региона):**
| Регион | Доступные языки |
|--------|-----------------|
| Все регионы | Английский |
| Северная и Латинская Америка | Английский, Немецкий, Португальский, Испанский |
| Европа и Азиатско-Тихоокеанский регион | Английский, Французский, Немецкий, Португальский, Испанский |

**Расширенная поддержка:**
- Всего поддерживается 80+ языков (некоторые в бета-режиме)
- Доступность зависит от плана подписки

### FR-SET-032: Переведенные субтитры
**Описание:** Автоматический перевод субтитров на другой язык.

**Доступность:**
- Business Plus
- Enterprise Standard/Plus
- Education Plus
- Gemini for Google Workspace

**Количество языковых пар:** 4,600+ комбинаций перевода

**Настройка:**
1. Настройки > Субтитры
2. Выбрать исходный язык (язык говорящего)
3. Выбрать целевой язык (язык субтитров)

**Ограничения:**
- Одновременно поддерживается один язык перевода
- Многоязычные встречи (несколько языков одновременно) не поддерживаются

### FR-SET-033: Настройка внешнего вида субтитров
**Описание:** Персонализация отображения субтитров.

**Расположение:** Настройки > Субтитры > Настроить субтитры

**Параметры настройки:**
- Размер шрифта
- Расположение субтитров на экране
- Контрастность фона

**Сохранение:**
- Настройки автоматически сохраняются для будущих встреч

### FR-SET-034: История субтитров
**Описание:** Просмотр субтитров за прошедшую часть встречи.

**Функционал:**
- Прокрутка вверх/вниз для просмотра истории
- Доступны только субтитры за время присутствия пользователя
- Отображаются только при включенных субтитрах

### FR-SET-035: Субтитры в записи
**Описание:** Встраивание субтитров в запись встречи.

**Настройка:**
- При запуске записи выбрать "Записать субтитры" (Record captions)
- Субтитры будут вшиты в видеофайл

## 5. Настройки отображения (Layout Settings)

### FR-SET-040: Выбор макета отображения
**Описание:** Выбор способа отображения участников на экране.

**Расположение:**
- Три точки > Изменить макет
- Нижняя панель (некоторые версии)

**Доступные макеты:**
| Макет | Описание |
|-------|----------|
| Авто (Dynamic) | Адаптивный макет с портретными плитками, автоматический кроппинг |
| Плиточный (Tiled/Legacy) | Фиксированная сетка без обрезки, до 49 участников |
| Прожектор (Spotlight) | Активный говорящий или презентация на весь экран |
| Боковая панель (Sidebar) | Основной контент + боковая панель с участниками |

### FR-SET-041: Количество плиток
**Описание:** Настройка количества одновременно отображаемых участников.

**Расположение:** Изменить макет > Ползунок количества плиток

**Диапазон:**
- Минимум: 1 участник
- По умолчанию: 16 участников
- Максимум: 49 участников (плиточный макет)

**Сохранение:**
- Выбранное количество становится значением по умолчанию для будущих встреч

### FR-SET-042: Закрепление участника (Pin)
**Описание:** Фиксация конкретного участника на экране.

**Способы закрепления:**
- Наведение на плитку участника > Кнопка "Закрепить"
- Правый клик на плитке > "Закрепить"
- Мобильные: Нажать на экран > Три точки на плитке > "Закрепить"

**Поведение:**
- Закрепленный участник всегда отображается на главной позиции
- Можно закрепить несколько участников
- Закрепление сохраняется до ручного открепления или выхода

**Открепление:**
- Нажать "Открепить" на плитке участника
- Мобильные: Три точки > "Открепить"

### FR-SET-043: Скрытие собственного видео
**Описание:** Скрытие превью собственной камеры с экрана.

**Функционал:**
- Скрывает только для самого пользователя
- Другие участники продолжают видеть видео
- Освобождает место на экране для других участников

## 6. Настройки реакций (Reactions Settings)

### FR-SET-050: Использование реакций
**Описание:** Отправка эмодзи-реакций во время встречи.

**Способы отправки:**
- Кнопка "Отправить реакцию" в нижней панели
- Выбор эмодзи из появившейся панели

**Доступные реакции:**
- Полный набор эмодзи (включено по умолчанию для подходящих планов)
- Базовые реакции: аплодисменты, сердце, смех, удивление, грусть, палец вверх/вниз

### FR-SET-051: Персонализация реакций
**Описание:** Настройка личных предпочтений для реакций.

**Расположение:** Настройки > Реакции

**Доступные настройки:**
| Настройка | Описание |
|-----------|----------|
| Показывать реакции других | Включить/выключить отображение реакций |
| Анимации | Включить/выключить анимацию реакций |
| Звуки уведомлений | Звуковое сопровождение реакций |
| Тон кожи эмодзи | Выбор предпочитаемого оттенка |

### FR-SET-052: Выбор тона кожи
**Описание:** Персонализация оттенка кожи для эмодзи-реакций.

**Настройка:**
1. При наведении на реакцию появляется палитра оттенков
2. Выбрать предпочитаемый оттенок
3. Настройка сохраняется для всех реакций

### FR-SET-053: Поднятие руки (Raise Hand)
**Описание:** Виртуальное поднятие руки для привлечения внимания.

**Активация:**
- Кнопка "Поднять руку" в панели реакций (может быть в меню "Дополнительно" на мобильных)
- Горячие клавиши: Ctrl + Alt + H (Windows) / Ctrl + Cmd + H (macOS)

**Поведение:**
- Иконка поднятой руки отображается на плитке участника
- Уведомление всем участникам
- Рука остается поднятой до ручного опускания

**Ограничения:**
- Реакции недоступны во встречах с клиентским шифрованием (Client-side Encryption)

## 7. Настройки хоста (Host Controls)

### FR-SET-060: Управление хостом
**Описание:** Включение/выключение расширенного контроля над встречей.

**Расположение:** Три точки > Настройки хоста (Host controls)

**Активация:**
- Переключатель "Управление хостом" (Host management)
- При включении хост и со-хосты получают расширенные права

### FR-SET-061: Управление микрофонами участников
**Описание:** Возможность отключать микрофоны участников.

**Действия:**
- Отключить микрофон конкретного участника
- Отключить микрофоны всех участников одновременно (Mute all)

**Правила:**
- Из соображений приватности нельзя ВКЛЮЧИТЬ микрофон другого участника
- Можно только попросить участника включить микрофон

### FR-SET-062: Управление камерами участников
**Описание:** Возможность отключать камеры участников.

**Ограничения:**
- Хост может только отключить камеру
- Включение камеры — только самим участником

### FR-SET-063: Управление демонстрацией экрана
**Описание:** Контроль над возможностью участников делиться экраном.

**Настройка (при включенном Host Management):**
- Разрешить всем участникам
- Только хосты и со-хосты
- Полностью отключить

### FR-SET-064: Управление чатом
**Описание:** Контроль над возможностью участников отправлять сообщения в чат.

**Настройка:**
- Разрешить всем
- Только хосты (хосты всегда могут отправлять сообщения)
- Полностью отключить

### FR-SET-065: Управление реакциями
**Описание:** Включение/выключение полного набора эмодзи-реакций.

**Расположение:** Настройки хоста > Модерация встречи > Отправка реакций

**Опции:**
- Использовать полный набор эмодзи-реакций: Вкл/Выкл

### FR-SET-066: Удаление участника
**Описание:** Принудительное отключение участника от встречи.

**Доступность:** Только для хоста и со-хостов

**Способ:**
1. Панель "Участники"
2. Найти участника
3. Нажать "Удалить из встречи"

**Последствия:**
- Участник немедленно отключается
- Может повторно присоединиться (если не заблокирован)

### FR-SET-067: Назначение со-хоста
**Описание:** Делегирование прав хоста другим участникам.

**Ограничения:**
- Максимум 25 со-хостов на встречу

**Способ назначения:**
1. Панель "Участники"
2. Найти участника
3. Назначить права хоста

**Права со-хоста:**
- Все права хоста, кроме завершения встречи для всех
- Управление участниками
- Контроль демонстрации и чата

### FR-SET-068: Управление доступом к встрече
**Описание:** Контроль над тем, кто может присоединиться к встрече.

**Настройки:**
| Опция | Описание |
|-------|----------|
| Участники из организации | Автоматический вход без одобрения |
| Внешние участники | Требуется одобрение хоста |
| Требовать одобрение для всех | Все участники ждут в "приемной" |

## 8. Настройки записи и транскрипции (Recording & Transcription)

### FR-SET-070: Запись встречи
**Описание:** Создание видеозаписи встречи.

**Доступность:**
- Business Standard и выше
- Education Plus
- Определяется администратором Workspace

**Кто может начать запись:**
- Организатор встречи
- Хост и со-хосты
- Участники из организации (если разрешено администратором)

**Уведомление:**
- Все участники уведомляются о начале записи
- Индикатор записи отображается на экране

### FR-SET-071: Транскрипция встречи
**Описание:** Автоматическое создание текстовой расшифровки встречи.

**Доступность:**
| План | Транскрипция |
|------|--------------|
| Business Standard | Да |
| Business Plus | Да |
| Enterprise Standard/Plus | Да |
| Education Plus | Да |
| Education (студенческая лицензия) | Выключена по умолчанию |

**Кто может включить транскрипцию:**
- При выключенном Host Management: любой из организации хоста
- При включенном Host Management: только хост и со-хосты

**Способ активации:**
1. Три точки > Инструменты встречи (Meeting tools)
2. Транскрипция (Transcripts)
3. Начать транскрипцию (Start Transcription)

**Индикация:**
- Иконка "Transcripts" отображается в левом верхнем углу для всех участников

**Сохранение:**
- Транскрипция сохраняется в Google Drive организатора
- Папка "Meet Recordings"
- Доступ через email-уведомление
- Время обработки: несколько часов (до 24 часов)

**Ограничения для больших встреч:**
- При более чем 200 приглашенных из организации хоста: транскрипция доступна только хосту, со-хостам и инициатору транскрипции

### FR-SET-072: Автоматическая запись и транскрипция
**Описание:** Предустановленные параметры для автоматического запуска записи/транскрипции.

**Настройка администратором:**
- Apps > Google Workspace > Google Meet > Meet video settings
- Automatic recording
- Automatic transcription

**Поведение:**
- Запись/транскрипция начинается автоматически при старте встречи
- Организатор может изменить настройки в приглашении Calendar
- Хосты могут отключить во время встречи

### FR-SET-073: Take Notes for Me (Заметки с Gemini)
**Описание:** Автоматическое ведение заметок с помощью AI.

**Доступность:**
- Business Standard и выше с Gemini
- Gemini for Google Workspace

**Активация:**
1. Нажать "Take notes with Gemini" в правом верхнем углу
2. Все участники уведомляются о ведении заметок
3. Иконка карандаша отображается у всех

**Настройки заметок:**
| Настройка | Опции |
|-----------|-------|
| Длина заметок | Стандартная (краткое резюме) / Длинная (подробные заметки) |
| Доступ к заметкам | Все приглашенные / Только из организации / Только хосты |

**Функционал:**
- Автоматический захват ключевых моментов
- Структурированные заметки в Google Docs
- "Summary so far" для опоздавших участников
- Рекомендуемые следующие шаги

**Поддерживаемые языки:**
- Английский, Французский, Немецкий, Итальянский, Японский, Корейский, Португальский, Испанский

**Ограничения:**
- Рекомендуемая продолжительность: от 15 минут до 8 часов
- Многоязычные встречи не поддерживаются

## Сущности данных

### Профиль настроек пользователя (UserSettingsProfile)
```
UserSettingsProfile {
    user_id: string                    // Идентификатор пользователя

    // Аудио настройки
    audio: {
        selected_microphone_id: string
        selected_speaker_id: string
        noise_cancellation_enabled: boolean
        studio_sound_enabled: boolean  // Только Gemini
    }

    // Видео настройки
    video: {
        selected_camera_id: string
        send_resolution: enum [AUTO, 1080P, 720P, 360P, AUDIO_ONLY]
        receive_resolution: enum [AUTO, 720P, 360P, AUDIO_ONLY]
        video_framing_enabled: boolean
    }

    // Визуальные эффекты
    visual_effects: {
        background_type: enum [NONE, BLUR_LIGHT, BLUR_HEAVY, IMAGE, IMMERSIVE]
        background_image_url: string?
        lighting_adjustment_enabled: boolean
        color_filter: string?
    }

    // Субтитры
    captions: {
        enabled: boolean
        source_language: string
        target_language: string?
        font_size: enum [SMALL, MEDIUM, LARGE]
    }

    // Отображение
    layout: {
        layout_type: enum [AUTO, TILED, SPOTLIGHT, SIDEBAR]
        tile_count: number // 1-49
    }

    // Реакции
    reactions: {
        show_others_reactions: boolean
        animations_enabled: boolean
        sounds_enabled: boolean
        skin_tone: enum [DEFAULT, LIGHT, MEDIUM_LIGHT, MEDIUM, MEDIUM_DARK, DARK]
    }

    // Экономия данных
    data_saving: {
        limit_data_usage: boolean
    }

    // Метаданные
    last_updated: timestamp
    sync_status: enum [SYNCED, PENDING, ERROR]
}
```

### Настройки встречи (MeetingSettings)
```
MeetingSettings {
    meeting_id: string

    // Управление хостом
    host_management_enabled: boolean

    // Модерация
    moderation: {
        chat_enabled: boolean
        screen_share_enabled: boolean
        reactions_full_set_enabled: boolean
        video_enabled: boolean
    }

    // Доступ
    access: {
        auto_admit_organization: boolean
        require_approval: boolean
    }

    // Запись и транскрипция
    recording: {
        auto_record: boolean
```

## Бизнес-правила

### BR-SET-001: Приоритет настроек
Настройки применяются в следующем приоритете (от высшего к низшему):
1. Политики администратора Workspace
2. Политики организационной единицы
3. Настройки организатора встречи (host controls)
4. Персональные настройки пользователя
5. Значения по умолчанию системы

### BR-SET-002: Приватность микрофона
Никто, включая хоста, не может принудительно ВКЛЮЧИТЬ микрофон другого участника. Возможно только отключение и запрос на включение.

### BR-SET-003: Уведомление о записи
При начале записи все участники должны быть уведомлены. Визуальный индикатор записи должен отображаться на протяжении всей записи.

### BR-SET-004: Сохранение настроек
Персональные настройки аудио/видео сохраняются между сессиями и применяются автоматически при следующем входе.

### BR-SET-005: Доступность функций
Функции, недоступные для текущего плана подписки, должны быть скрыты или отмечены как недоступные с указанием требуемого плана.

### BR-SET-006: Время применения политик
Изменения в политиках администратора могут применяться до 24 часов, хотя обычно происходят быстрее.

### BR-SET-007: Наследование политик
Организационные единицы наследуют политики от родительских единиц, если явно не переопределены.

### BR-SET-008: Fallback устройств
При недоступности выбранного устройства система автоматически переключается на системное устройство по умолчанию.

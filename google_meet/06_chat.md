# Модуль чата во встрече (In-Meeting Chat)

## Описание

Модуль "Чат во встрече" в Google Meet обеспечивает текстовую коммуникацию между участниками видеоконференции в режиме реального времени. Начиная с ноября 2025 года, чат во встрече интегрирован с Google Chat, что позволяет сохранять сообщения и продолжать переписку до, во время и после встречи. Модуль поддерживает отправку текстовых сообщений, ссылок, файлов через Google Drive, реакции на сообщения эмодзи, форматирование текста и @-упоминания. Все сообщения видны всем участникам встречи — приватные сообщения между отдельными участниками не поддерживаются. Организатор встречи имеет возможность модерировать чат, включая или отключая возможность отправки сообщений для участников.

## Роли пользователей

| Роль | Описание | Ключевые права |
|------|----------|----------------|
| **Организатор встречи (Host)** | Создатель встречи в Google Calendar или инициатор мгновенной встречи | Полный контроль над настройками чата, включение/отключение отправки сообщений, управление Continuous Meeting Chat |
| **Со-организатор (Co-host)** | Назначенный организатором пользователь с расширенными правами | Доступ к host controls, управление чатом аналогично организатору |
| **Участник встречи (Participant)** | Пользователь, присоединившийся к встрече из той же организации | Отправка и чтение сообщений (если разрешено), реакции, доступ к истории (при Continuous Chat) |
| **Внешний участник (External Guest)** | Пользователь из другой организации или без Google аккаунта | Отправка и чтение сообщений только во время встречи, без доступа к истории после выхода |
| **Зритель трансляции (Live Stream Viewer)** | Пользователь, присоединившийся через ссылку на трансляцию | Просмотр и отправка сообщений в чат (если разрешено организатором) |
| **Гость без авторизации (Unauthenticated Guest)** | Пользователь без входа в Google аккаунт | Ограниченные права, сообщения доступны только во время присутствия на встрече |

## Функциональные требования

### FR-CHAT-001: Отправка текстового сообщения в чат встречи

**Описание:** Система позволяет участникам встречи отправлять текстовые сообщения, которые видят все присутствующие на встрече пользователи.

**Роли:** Организатор встречи, Со-организатор, Участник встречи, Внешний участник

**Предусловия:**
- Пользователь присоединился к активной встрече Google Meet
- Функция отправки сообщений включена организатором
- Пользователь имеет активное интернет-соединение

**Основной сценарий (Компьютер):**
1. Пользователь находится в активной видеовстрече
2. Пользователь нажимает на иконку "Chat" (Чат) в правом нижнем углу экрана
3. Система открывает боковую панель чата
4. Пользователь вводит текст сообщения в поле ввода внизу панели
5. Пользователь нажимает кнопку "Send" (Отправить) или клавишу Enter
6. Система мгновенно доставляет сообщение всем участникам встречи
7. Сообщение отображается в чате с указанием имени отправителя и времени

**Основной сценарий (Мобильное устройство):**
1. Пользователь находится в активной видеовстрече через мобильное приложение
2. Пользователь нажимает "More controls" (Дополнительные элементы управления) внизу экрана
3. Пользователь выбирает "Chat with everyone" (Чат со всеми)
4. Система открывает экран чата
5. Пользователь вводит текст сообщения
6. Пользователь нажимает кнопку "Send" (Отправить)
7. Сообщение доставляется всем участникам

**Альтернативные сценарии:**

*AS-001-A: Отправка сообщений отключена организатором*
1. На шаге 4 поле ввода сообщения недоступно или отсутствует
2. Система отображает уведомление о том, что отправка сообщений отключена
3. Пользователь может только читать существующие сообщения

*AS-001-B: Участник присоединился позже*
1. Пользователь присоединяется к встрече после начала
2. При включенном Continuous Meeting Chat пользователь видит всю историю сообщений
3. При отключенном Continuous Meeting Chat пользователь видит только сообщения, отправленные после его присоединения

*AS-001-C: Участник покинул и вернулся на встречу*
1. Пользователь покидает встречу
2. Сообщения, отправленные в его отсутствие, не будут видны ему (без Continuous Chat)
3. При возвращении пользователь не увидит пропущенные сообщения (без Continuous Chat)

**Бизнес-правила:**
- BR-001: Все сообщения видны всем участникам встречи — приватные сообщения не поддерживаются
- BR-002: Максимальный размер сообщения — 32,000 байт (включая текст и форматирование)
- BR-003: Сообщения доставляются в реальном времени всем активным участникам
- BR-004: Удаление отправленных сообщений невозможно
- BR-005: При Continuous Meeting Chat сообщения сохраняются в Google Chat

**Результат:** Текстовое сообщение отправлено и видно всем участникам встречи.

### FR-CHAT-002: Отправка ссылок в чат встречи

**Описание:** Система позволяет участникам делиться URL-ссылками в чате встречи с автоматическим определением и форматированием ссылок.

**Роли:** Организатор встречи, Со-организатор, Участник встречи, Внешний участник

**Предусловия:**
- Пользователь присоединился к активной встрече
- Панель чата открыта
- Функция отправки сообщений включена

**Основной сценарий:**
1. Пользователь копирует URL-ссылку из любого источника
2. Пользователь вставляет ссылку в поле ввода чата
3. Система автоматически распознает URL-адрес
4. Пользователь нажимает "Send" (Отправить)
5. Система отправляет сообщение со ссылкой
6. Ссылка отображается как кликабельный элемент
7. Участники могут нажать на ссылку для открытия в новой вкладке браузера

**Альтернативные сценарии:**

*AS-002-A: Ссылка на Google Drive файл*
1. Пользователь вставляет ссылку на файл Google Drive
2. Система отображает диалог предоставления доступа
3. Пользователь может выбрать:
   - Предоставить доступ всем участникам встречи
   - Прикрепить файл к событию календаря
   - Отправить ссылку без изменения доступа
4. После выбора сообщение отправляется
5. Участники получают уведомление о предоставленном доступе к файлу

*AS-002-B: Небезопасная ссылка*
1. Система анализирует ссылку на безопасность
2. При обнаружении потенциально опасной ссылки система может предупредить пользователей
3. Ссылки на исполняемые файлы (.exe, .bat и др.) блокируются

**Бизнес-правила:**
- BR-001: URL-адреса автоматически становятся кликабельными
- BR-002: При вставке ссылок на Google Drive появляется предложение предоставить доступ
- BR-003: Ссылки открываются в новой вкладке браузера
- BR-004: Ссылка на файл может быть прикреплена к событию Calendar

**Результат:** Ссылка отправлена в чат и доступна для всех участников.

### FR-CHAT-003: Отправка файлов в чат встречи

**Описание:** Система позволяет участникам делиться файлами через интеграцию с Google Drive и Google Chat.

**Роли:** Организатор встречи, Со-организатор, Участник встречи (только пользователи Google Workspace)

**Предусловия:**
- Пользователь имеет Google Workspace аккаунт
- Continuous Meeting Chat включен
- Пользователь находится в активной встрече

**Основной сценарий:**
1. Пользователь открывает панель чата
2. Пользователь нажимает на иконку прикрепления файла
3. Система предлагает выбор:
   - Загрузить файл с устройства (до 200 МБ)
   - Выбрать файл из Google Drive
4. Пользователь выбирает файл
5. Система загружает файл и отправляет ссылку в чат
6. Участники видят превью файла или название с возможностью скачивания/открытия

**Альтернативные сценарии:**

*AS-003-A: Continuous Meeting Chat отключен*
1. На шаге 2 опция прикрепления файлов может быть недоступна
2. Пользователь может отправить только ссылку на файл вручную
3. Файлы не сохраняются после окончания встречи

*AS-003-B: Файл заблокированного типа*
1. На шаге 4 пользователь выбирает исполняемый файл
2. Система блокирует отправку файла
3. Отображается сообщение о недопустимом типе файла

**Бизнес-правила:**
- BR-001: Максимальный размер файла для загрузки — 200 МБ
- BR-002: Заблокированные типы файлов: ADE, ADP, APK, BAT, CAB, CHM, CMD, COM, CPL, DLL, DMG, EXE, HTA, INS, ISP, JAR, JS, JSE, LIB, LNK, MDE, MSC, MSI, MSP, MST, NSH, PIF, SCR, SCT, SHB, SYS, VB, VBE, VBS, VXD, WSC, WSF, WSH
- BR-003: Файлы хранятся в Google Drive отправителя
- BR-004: При Continuous Chat файлы доступны в истории Google Chat
- BR-005: Внешние участники могут не иметь доступа к функции отправки файлов

**Результат:** Файл отправлен в чат и доступен для скачивания участниками.

### FR-CHAT-004: Отправка изображений в чат встречи

**Описание:** Система позволяет участникам делиться изображениями напрямую в чате встречи при включенном Continuous Meeting Chat.

**Роли:** Организатор встречи, Со-организатор, Участник встречи (Google Workspace пользователи)

**Предусловия:**
- Continuous Meeting Chat включен
- Пользователь находится в активной встрече
- Пользователь имеет изображение для отправки

**Основной сценарий:**
1. Пользователь открывает панель чата
2. Пользователь нажимает на иконку изображения или прикрепления
3. Пользователь выбирает изображение с устройства или из Google Drive
4. Система загружает изображение
5. Изображение отправляется в чат
6. Участники видят превью изображения в чате
7. При нажатии изображение открывается в полном размере

**Бизнес-правила:**
- BR-001: Изображения отображаются как превью в чате
- BR-002: Поддерживаемые форматы: JPEG, PNG, GIF, WebP
- BR-003: Изображения сохраняются в истории Google Chat
- BR-004: Максимальный размер изображения ограничен общим лимитом файлов (200 МБ)

**Результат:** Изображение отправлено и отображается в чате встречи.

### FR-CHAT-005: Реакции на сообщения эмодзи

**Описание:** Система позволяет участникам добавлять реакции-эмодзи к сообщениям в чате при включенном Continuous Meeting Chat.

**Роли:** Организатор встречи, Со-организатор, Участник встречи

**Предусловия:**
- Continuous Meeting Chat включен
- В чате есть сообщения
- Пользователь находится в активной встрече

**Основной сценарий:**
1. Пользователь наводит курсор на сообщение в чате
2. Система отображает иконку добавления реакции
3. Пользователь нажимает на иконку
4. Система отображает панель выбора эмодзи
5. Пользователь выбирает эмодзи
6. Реакция добавляется к сообщению
7. Все участники видят реакцию под сообщением

**Альтернативные сценарии:**

*AS-005-A: Добавление нескольких реакций*
1. К одному сообщению можно добавить несколько разных реакций
2. Система группирует одинаковые реакции от разных пользователей
3. Отображается счетчик количества одинаковых реакций

*AS-005-B: Удаление реакции*
1. Пользователь нажимает на свою реакцию
2. Реакция удаляется
3. Счетчик обновляется

**Бизнес-правила:**
- BR-001: Один пользователь может добавить до 20 уникальных реакций на одно сообщение
- BR-002: Одно сообщение может содержать максимум 50 уникальных реакций от всех пользователей
- BR-003: Реакции видны всем участникам встречи
- BR-004: Реакции сохраняются в истории Google Chat
- BR-005: Без Continuous Chat реакции могут быть недоступны

**Результат:** Реакция добавлена к сообщению и видна всем участникам.

### FR-CHAT-006: Форматирование текста в сообщениях

**Описание:** Система позволяет использовать форматирование текста в сообщениях чата при включенном Continuous Meeting Chat.

**Роли:** Организатор встречи, Со-организатор, Участник встречи

**Предусловия:**
- Continuous Meeting Chat включен
- Пользователь имеет доступ к функциям Google Chat

**Основной сценарий:**
1. Пользователь открывает панель чата
2. Пользователь вводит текст с использованием разметки форматирования:
   - `*текст*` — полужирный
   - `_текст_` — курсив
   - `~текст~` — зачеркнутый
   - `` `текст` `` — моноширинный шрифт
3. Пользователь отправляет сообщение
4. Система преобразует разметку в форматированный текст
5. Участники видят отформатированное сообщение

**Бизнес-правила:**
- BR-001: Форматирование доступно только при Continuous Meeting Chat
- BR-002: Поддерживаются стандартные правила форматирования Google Chat
- BR-003: Форматирование сохраняется в истории сообщений
- BR-004: Без Continuous Chat отправляется только простой текст

**Результат:** Сообщение отправлено с форматированием текста.

### FR-CHAT-007: @-упоминания участников

**Описание:** Система позволяет упоминать конкретных участников в сообщениях чата для привлечения их внимания.

**Роли:** Организатор встречи, Со-организатор, Участник встречи

**Предусловия:**
- Continuous Meeting Chat включен
- На встрече присутствует несколько участников

**Основной сценарий:**
1. Пользователь открывает панель чата
2. Пользователь вводит символ "@" в поле сообщения
3. Система отображает список участников встречи для выбора
4. Пользователь выбирает участника из списка или продолжает вводить имя
5. Выбранное имя выделяется как упоминание
6. Пользователь завершает ввод сообщения и отправляет
7. Упомянутый участник получает выделенное уведомление

**Бизнес-правила:**
- BR-001: @-упоминания работают только при Continuous Meeting Chat
- BR-002: Упоминание выделяется визуально в сообщении
- BR-003: Упомянутый пользователь получает уведомление
- BR-004: Можно упоминать нескольких участников в одном сообщении

**Результат:** Сообщение с @-упоминанием отправлено, участник уведомлен.

### FR-CHAT-008: Continuous Meeting Chat (Непрерывный чат встречи)

**Описание:** Система обеспечивает сохранение сообщений чата и их доступность до, во время и после встречи через интеграцию с Google Chat.

**Роли:** Организатор встречи (управление), Участник встречи (использование)

**Предусловия:**
- Встреча запланирована в Google Calendar
- Пользователи имеют Google Workspace аккаунты (Business или Enterprise)
- Continuous Meeting Chat включен (по умолчанию)

**Основной сценарий:**
1. Организатор создает встречу в Google Calendar
2. Система автоматически создает связанную беседу в Google Chat
3. Участники могут отправлять сообщения до начала встречи
4. Во время встречи сообщения синхронизируются с Google Chat
5. После окончания встречи беседа остается доступной в Google Chat
6. Участники могут продолжить переписку

**Альтернативные сценарии:**

*AS-008-A: Отключение Continuous Meeting Chat организатором*
1. Организатор открывает событие в Google Calendar
2. Организатор нажимает на иконку шестеренки рядом с ссылкой Meet
3. Организатор выбирает "Video call options"
4. В разделе "Chat moderation" организатор отключает "Continuous meeting chat"
5. Сообщения будут доступны только во время встречи

*AS-008-B: Присоединение к встрече с опозданием*
1. Пользователь присоединяется к уже начавшейся встрече
2. Система автоматически загружает историю сообщений
3. Пользователь видит все сообщения, отправленные с начала встречи и до нее

*AS-008-C: Внешний участник*
1. Внешний участник присоединяется к встрече
2. Внешний участник видит и отправляет сообщения только во время присутствия на встрече
3. После выхода из встречи внешний участник теряет доступ к истории
4. Внешний участник не может участвовать в чате до или после встречи

**Бизнес-правила:**
- BR-001: Continuous Meeting Chat включен по умолчанию для запланированных встреч
- BR-002: Недоступен для: мгновенных встреч, встреч по прозвищу, трансляций, встреч с комнатами ожидания, huddles, CSE-встреч, breakout rooms
- BR-003: Внешние участники имеют доступ только во время присутствия на встрече
- BR-004: Сообщения подчиняются политикам хранения данных Google Chat
- BR-005: Сообщения подчиняются правилам DLP (Data Loss Prevention), настроенным для Google Chat
- BR-006: Беседа сохраняется в списке чатов участников

**Результат:** Сообщения чата сохраняются и доступны до, во время и после встречи.

### FR-CHAT-009: Управление доступом к чату (Host Controls)

**Описание:** Система позволяет организатору встречи управлять возможностью участников отправлять сообщения в чат.

**Роли:** Организатор встречи, Со-организатор

**Предусловия:**
- Пользователь является организатором или со-организатором встречи
- Встреча активна
- Host Management включен

**Основной сценарий (во время встречи):**
1. Организатор нажимает на "Host controls" (Элементы управления организатора) в правом нижнем углу
2. Система открывает боковую панель с настройками
3. Организатор находит переключатель "Send chat messages" (Отправка сообщений в чат)
4. Организатор переключает опцию в положение "Off"
5. Система применяет настройку мгновенно
6. Участники теряют возможность отправлять сообщения
7. Существующие сообщения остаются видимыми

**Основной сценарий (до встречи через Calendar):**
1. Организатор открывает событие в Google Calendar
2. Организатор нажимает "Video call options" рядом с ссылкой Meet

3. Система не отправляет уведомление об изменении

**Бизнес-правила:**
- BR-001: Только организаторы и со-организаторы могут управлять настройками чата

- BR-003: Host controls доступны только на веб-версии, не на мобильных устройствах
- BR-004: Для повторяющихся встреч настройки сохраняются
- BR-005: Для разовых встреч настройки сбрасываются после окончания

### FR-CHAT-010: Чтение сообщений чата

**Альтернативные сценарии:**

*AS-010-A: Отправка сообщений отключена*

2. Поступает новое сообщение

4. Пользователь открывает панель и видит новое сообщение

**Бизнес-правила:**
- BR-001: Все участники могут читать все сообщения чата
- BR-002: Чтение сообщений нельзя отключить для участников
- BR-003: Индикатор показывает наличие непрочитанных сообщений
- BR-004: История сообщений зависит от момента присоединения (без Continuous Chat)

### FR-CHAT-012: Сохранение истории чата после встречи

**Предусловия:**
- Встреча завершена
- Continuous Meeting Chat был включен
- Пользователь является внутренним участником организации

2. Внешний участник теряет доступ к истории
3. Внутренние участники продолжают иметь доступ

2. Пользователь выбирает экспорт данных Google Meet
3. Система подготавливает архив с историей встреч
4. Пользователь скачивает архив в формате .zip с CSV-файлами

**Бизнес-правила:**
- BR-001: История сохраняется только при Continuous Meeting Chat
- BR-002: Внешние участники не имеют доступа к истории после встречи
- BR-003: История подчиняется политикам хранения данных организации
- BR-004: Можно экспортировать данные через Google Takeout
- BR-005: Удаленная история не подлежит восстановлению

**Результат:** История чата доступна после окончания встречи.

**Роли:** Участник встречи, Внешний участник

- Встреча уже началась

## Сущности данных

### Сообщение чата (Chat Message)

| Поле | Тип | Описание |
|------|-----|----------|
| message_id | string | Уникальный идентификатор сообщения |
| meeting_id | string | Идентификатор встречи |
| sender_id | string | Идентификатор отправителя (Google Account ID) |
| sender_name | string | Отображаемое имя отправителя |
| sender_email | string | Email отправителя |
| content | string | Текст сообщения (до 32,000 байт) |
| timestamp | datetime | Время отправки сообщения |
| is_external | boolean | Флаг внешнего участника |
| attachments | array | Список вложений (ссылки, файлы) |
| reactions | array | Список реакций на сообщение |
| mentions | array | Список @-упоминаний |

### Вложение (Attachment)

| Поле | Тип | Описание |
|------|-----|----------|
| attachment_id | string | Уникальный идентификатор вложения |
| type | enum | Тип: url, file, image |
| url | string | URL ресурса |
| name | string | Название файла/ссылки |
| size | number | Размер файла в байтах |
| drive_file_id | string | Идентификатор файла в Google Drive (если применимо) |
| preview_available | boolean | Доступно ли превью |

### Реакция на сообщение (Message Reaction)

| Поле | Тип | Описание |
|------|-----|----------|
| reaction_id | string | Уникальный идентификатор реакции |
| message_id | string | Идентификатор сообщения |
| user_id | string | Идентификатор пользователя |
| emoji | string | Эмодзи реакции |
| timestamp | datetime | Время добавления реакции |

### Настройки чата встречи (Meeting Chat Settings)

| Поле | Тип | Описание |

## Состояния и статусы

### Состояния функции чата

| Состояние | Описание | Возможные действия |
|-----------|----------|-------------------|
| **Enabled (Включен)** | Чат полностью функционирует | Чтение, отправка сообщений |
| **Send Disabled (Отправка отключена)** | Организатор отключил отправку | Только чтение сообщений |
| **Continuous (Непрерывный)** | Continuous Meeting Chat активен | Полный функционал + история в Google Chat |
| **Session Only (Только сессия)** | Сообщения доступны только во время встречи | Базовый функционал без сохранения |

### Статусы сообщений

| Статус | Описание |
|--------|----------|
| **Sent (Отправлено)** | Сообщение отправлено на сервер |
| **Delivered (Доставлено)** | Сообщение доставлено участникам |
| **Failed (Ошибка)** | Ошибка отправки сообщения |
| **Blocked (Заблокировано)** | Сообщение заблокировано DLP |

### Статусы участника в чате

| Статус | Описание |
|--------|----------|
| **Active (Активен)** | Участник на встрече, может использовать чат |
| **Read Only (Только чтение)** | Участник может только читать |
| **Disconnected (Отключен)** | Участник покинул встречу |
| **External (Внешний)** | Внешний участник с ограничениями |

## Интеграции с другими модулями

### Интеграция с Google Chat
- Сообщения Continuous Meeting Chat синхронизируются с Google Chat
- Беседа сохраняется в списке чатов пользователя
- Уведомления о сообщениях приходят в Google Chat
- Можно продолжить переписку после встречи

### Интеграция с Google Calendar
- Настройки чата связаны с событием календаря
- Continuous Chat автоматически создается для запланированных встреч
- Файлы можно прикреплять к событию Calendar

### Интеграция с Google Drive
- Файлы можно отправлять из Google Drive
- Ссылки на Drive-файлы автоматически проверяются на доступ
- Система предлагает предоставить доступ участникам

### Интеграция с модулем Host Controls
- Организатор управляет чатом через host controls
- Настройки сохраняются для повторяющихся встреч
- Со-организаторы имеют аналогичные права

### Интеграция с модулем трансляций (Live Stream)
- Зрители трансляции могут участвовать в чате
- Организатор может отдельно управлять чатом зрителей
- Continuous Chat отключается при трансляции

### Интеграция с модулем записи (Recording)
- Сообщения чата не записываются в видеозапись встречи
- Для сохранения чата используется Continuous Meeting Chat
- Экспорт возможен через Google Takeout

### Интеграция с модулем безопасности
- Применяются политики DLP организации
- Применяются политики хранения данных
- Внешние участники имеют ограниченный доступ

## Ограничения для специальных типов встреч

| Тип встречи | Continuous Chat | Особенности |
|-------------|-----------------|-------------|
| Запланированная встреча | Доступен | Полный функционал |
| Мгновенная встреча (Instant) | Недоступен | Только базовый чат |
| Встреча по прозвищу (Nicknamed) | Недоступен | Только базовый чат |
| Трансляция (Live Stream) | Недоступен | Отдельный чат для зрителей |
| Встреча с CSE | Недоступен | Шифрование на стороне клиента |
| Breakout Rooms | Недоступен | Отдельные чаты в комнатах |
| Huddles | Недоступен | Упрощенный формат |
| Комнаты ожидания | Недоступен | Ожидающие не имеют доступа к чату |
